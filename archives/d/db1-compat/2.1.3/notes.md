# db1-compat 2.1.3 HarmonyOS PC 适配说明

## 源码与构建

- 源码取自 GNU 官方 glibc 2.1.3 发布包中的 `db/` 子目录。
- 该目录是 4.4BSD DB 1.85 代码，原始 Makefile 只能在 glibc 构建树内使用。
- 适配补丁增加独立 CMake 构建入口、非 glibc 符号别名和缺失的
  `CIRCLEQ` 兼容定义。
- 无外部依赖；支持静态库与共享库。共享库保持兼容 SONAME `libdb.so.2`。

## 测试覆盖

- B-tree：写入、查询、覆盖保护、顺序遍历、删除与重新打开持久化。
- Hash：大记录读写、删除及重新打开持久化。
- Recno：记录号访问、追加、删除与遍历。
- NDBM：写入、读取、遍历、删除和持久化。
- 错误路径：非法数据库类型必须返回失败并设置 `EINVAL`。
- HarmonyOS 专项：使用 OHOS AArch64 工具链编译，校验目标宏、64 位 ABI，
  并在该 ABI 下调用 `dbopen`、`DB->fd`、`fstat`、同步及持久化读取。

## 本地验证

使用 OHOS SDK Clang 15 为 AArch64 构建并执行消费者测试。共享库、静态库
及仓库质量门禁均全部通过。

# dsocks

dsocks is a SOCKS client wrapper library for dynamically-linked binaries. It intercepts
connect(), gethostbyname(), and getaddrinfo() calls via LD_PRELOAD to route traffic
through a SOCKS4/SOCKS5 or Tor proxy.

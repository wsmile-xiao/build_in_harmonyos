### OHOS 平台契约（独立复核：直接读交付产物字节/ELF 头，以及 NUL 锚定反例）
$ python3 -c "<读 bin/dinit-shutdown 的 ELF 头与字节指纹>"

.codesign=1 .symtab=1
socket(NUL锚定)=1  dinit-reboot(NUL锚定)=1  dinit-soft-reboot(NUL锚定)=1

反例（说明 NUL 锚定比裸子串更强，等长替换构造）：
  等长反例长度一致: True
  裸子串断言 b"/var/run/dinitctl" in b = True   ← True 即误放行
  NUL 锚定断言 b"/var/run/dinitctl\0" in b = False   ← False 即正确拒绝

对照：同一二进制 strip 后 .symtab/.codesign 计数归零且在本平台加载失败（rc=126），未 strip 的产物可用（--help rc=1）。

# DXX-Rebirth

DXX-Rebirth provides modern source ports for Descent and Descent II while preserving the original gameplay.

## OHOS adaptation

- Builds both `d1x-rebirth` and `d2x-rebirth` with the upstream SCons build.
- Uses the published SDL 1.2 compatibility and PhysicsFS Conan dependencies.
- Uses the software renderer and built-in audio path for the initial OHOS port.
- Packages only the engines; users must provide legally obtained game data.

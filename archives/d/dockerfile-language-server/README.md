# dockerfile-language-server

A language server for Dockerfiles powered by NodeJS, TypeScript, and VSCode technologies.

## Description

This is a Language Server Protocol (LSP) implementation for Dockerfiles. It provides features such as:
- Syntax highlighting
- Auto-completion
- Diagnostics and linting
- Hover information
- Code actions

# dominion — GNU 回合制多人策略游戏（empire management）

GNU dominion 2.8.2：玩家扮演君主管理帝国（省份、军队、经济、魔法、外交），
附 dom_make/dom_add/dom_update/dom_print 世界管理与输出工具。
主程序 dominion 为 ncurses 终端界面。

- 上游: https://ftp.gnu.org/gnu/dominion/dominion-2.8.2.tar.gz
- 许可: GPL-1.0-only
- 语言: C（1995-2005 年代代码，依赖 ncurses）
- 本归档: 2.8.2 适配 OHOS aarch64（详见 2.8.2/notes.md 与 test_package/）

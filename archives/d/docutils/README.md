# docutils

Docutils is a modular system for processing documentation in reStructuredText format.

## Description

Docutils -- Python Documentation Utilities -- provides a set of tools for processing reStructuredText (reST) documentation. It includes parsers, writers, and transformation modules that convert reST markup into various output formats (HTML, LaTeX, man pages, ODT, XML, etc.).

## Key Tools

- `rst2html` - Convert reST to HTML
- `rst2html4` - Convert reST to HTML 4
- `rst2html5` - Convert reST to HTML 5
- `rst2latex` - Convert reST to LaTeX
- `rst2man` - Convert reST to man page
- `rst2odt` - Convert reST to ODT (OpenDocument Text)
- `rst2xml` - Convert reST to XML
- `rst2xetex` - Convert reST to XeLaTeX
- `rst2s5` - Convert reST to S5 slideshow

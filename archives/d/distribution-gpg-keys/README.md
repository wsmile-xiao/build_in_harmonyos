# distribution-gpg-keys

## 简介
GPG keys used by various Linux distributions to sign packages.

## 安装路径
/usr/local/share/distribution-gpg-keys/

## 内容
包含以下发行版的 GPG 密钥：
- Fedora, CentOS, RHEL, AlmaLinux
- Alpine Linux, Debian, Ubuntu
- Amazon Linux, Azure Linux
- Docker, Elastic, Element
- 以及更多...

## 使用方法
这些密钥可用于验证软件包的签名。

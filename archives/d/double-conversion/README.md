# double-conversion

**Display**: double-conversion
**Category**: library
**Homepage**: https://github.com/google/double-conversion
**License**: BSD-3-Clause

Binary-decimal and decimal-binary conversion routines for IEEE doubles.

## Overview

double-conversion is a C++ library by Google that provides routines for converting between binary and decimal representations of IEEE doubles. It is used in the V8 JavaScript engine and other projects.

- **System**: cmake
- **Compiler**: clang/clang++

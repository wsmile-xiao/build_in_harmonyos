# MDFLib

ASAM MDF (Measurement Data Format) 数据文件读写库。

## 简介

MDFLib 是一个 C++ 库，用于读取和写入 ASAM MDF 3/4 格式的测量数据文件。MDF 格式广泛应用于汽车行业，用于记录总线数据（CAN、LIN、FlexRay、MOST、Ethernet）和测量信号。

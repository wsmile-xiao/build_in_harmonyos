# msgpack-tools

[msgpack-tools](https://github.com/ludocode/msgpack-tools) 提供 MessagePack 与 JSON
互转的命令行工具，包含 `msgpack2json` 与 `json2msgpack` 两个 CLI。

## 已归档版本

| 版本 | 构建系统 | 说明 |
|------|----------|------|
| 0.6  | CMake    | 无外部依赖（mpack/rapidjson/libb64 均内置于 contrib/） |

## 工具

- `msgpack2json` — 将 MessagePack 文件转换为 JSON
- `json2msgpack` — 将 JSON 文件转换为 MessagePack

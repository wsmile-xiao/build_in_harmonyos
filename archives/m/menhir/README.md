# menhir

Menhir is an LR(1) parser generator for the OCaml language, developed by the
Menhir project at Inria (François Pottier, Yann Régis-Gianas).  It reads a
grammar in `.mly` syntax and produces an OCaml parser module, with a code
back-end, a table back-end, incremental parsing, GLR parsing and inspection
APIs.  Menhir is a standard OCaml ecosystem tool (used to build the OCaml
compiler front-end tooling, `dune`'s menhir stanza, Rocq/Coq tooling, etc.).

## Version 20260209

- Language: OCaml (self-bootstrapping build; no OCaml is shipped with OHOS)
- Build system: Dune (release profile)
- Official source: https://gitlab.inria.fr/fpottier/menhir (archive tag
  `20260209`, URL/checksum consistent with the upstream opam metadata)
- Deliverables: `bin/menhir` plus the runtime/support libraries
  `menhirLib`, `menhirSdk`, `menhirCST`, `menhirGLR` under `lib/`

## Build requirements

Declared as Conan `tool_requires` (OHOS registry), no system OCaml:

- `ocaml/4.14.1.1.4` — compiler toolchain (ocamlc/ocamlopt/ocamllex/ocamlyacc)
- `dune/3.17.0` — build system

## OHOS adaptation notes

- `OCAMLLIB` is exported explicitly from the ocaml package location: the
  packaged compiler keeps a build-time absolute stdlib path that does not
  survive Conan cache relocation (same workaround as the merged `ocaml`,
  `dune` and `pdfsandwich` recipes).
- Bootstrapping works without an existing Menhir installation: stage 1 is
  generated by `ocamlyacc`, then bound as `menhir` for stage 2
  (`driver/stage2/dune`), producing the final executable.
- Rimraf/mktemp-free test harness: consumer tests run under `/bin/sh` with
  explicit interpreter invocation (OHOS rejects direct execution of shebang
  scripts).

## Usage

```sh
conan install --requires=menhir/20260209 -g VirtualRunEnv
menhir --version
menhir --table parser.mly
```

# mlv-smile (SMILE)

SMILE —— 序列中简单/结构化模体（motif）的精确抽取与统计显著性评估工具集。
上游主页 <http://www-igm.univ-mlv.fr/~marsan/smile_english.html>，
本仓经 Debian pool orig tarball 引入（1.47）。

- 版本目录：`1.47/`（配方、消费者测试、报告）
- 交付物：`bin/x-smile`（主程序）、`bin/x-smile_delta`、`bin/e-smile_shuffling`、
  `bin/e-smile_against`、`bin/grep+`，示例数据 `res/examples/`
- 适配要点见软件级 `manifest.yaml` 的 `ohos_adaptation` 与版本级 `notes.md`

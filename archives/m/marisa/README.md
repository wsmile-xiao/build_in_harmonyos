# marisa-trie

marisa-trie is a static trie container for extremely fast associative dictionary lookup.

## Description

marisa-trie (MARISA: Matching Algorithm with Recursively Implemented StorAge) is a C++ library providing a static trie data structure that enables extremely fast associative dictionary lookup. It is particularly useful for natural language processing and other applications requiring efficient prefix matching.

## Features

- Static trie data structure optimized for fast lookup
- Prefix search, common prefix search, predictive search, reverse lookup
- Space-efficient storage using LOUDS (Level-Ordered Unary Degree Sequence)
- C library API and command-line tools included

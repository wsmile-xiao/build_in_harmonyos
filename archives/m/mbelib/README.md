# mbelib

P25 Phase 1 and ProVoice vocoder (IMBE/AMBE voice codec library).

## Description

mbelib is a C library that provides vocoder functionality for P25 Phase 1
and ProVoice digital voice protocols. It implements IMBE (Improved Multi-Band
Excitation) and AMBE (Advanced Multi-Band Excitation) voice codecs used in
APCO P25 and ProVoice radio systems.

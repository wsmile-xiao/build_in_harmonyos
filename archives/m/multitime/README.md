# multitime

Time command execution over multiple executions.

multitime is a tool that runs a command multiple times and displays timing statistics (mean, std dev, min, median, max) for real, user, and system time. It is similar to the standard `time` command but provides statistical analysis across multiple runs.

- **Homepage**: https://tratt.net/laurie/src/multitime/
- **License**: MIT
- **Language**: C
- **Build System**: autotools
- **Dependencies**: None (only requires libc functions)

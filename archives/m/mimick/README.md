# mimick

`mimick` is a portable C mocking library for intercepting and verifying function calls.

- Version: 0.3.0
- Upstream: https://github.com/Snaipe/Mimick
- Conan package: `mimick/0.3.0@ohpcd/stable`

The OpenHarmony PC arm64 adaptation packages the static library and public headers.
The AArch64 ELF compatibility fixes preserve GNU-hash lookup, RELRO protection, and
both GLOB_DAT/JUMP_SLOT reset paths; the AArch64 Clang build also avoids emulated-TLS
allocator recursion.

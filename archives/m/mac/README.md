# Monkey's Audio (MAC) — 无损音频编解码器

Monkey's Audio 是一种无损音频压缩编解码器，可在不损失任何音频质量的前提下对音频数据进行压缩。压缩后的文件可以随时完美还原为原始波形数据。

## 核心特性

- **严格无损**：压缩/解压缩后数据与原始数据逐字节完全一致
- **多种压缩级别**：快速(-c1000)、标准(-c2000)、高(-c3000)、极高(-c4000)、极限(-c5000)
- **NEON SIMD 优化**：在 ARM/aarch64 平台自动启用 NEON 指令集加速
- **APE 标签系统**：支持完整的 APEv2 标签读写和删除
- **BSD-3-Clause 许可证**：可自由使用和分发

## 构建系统

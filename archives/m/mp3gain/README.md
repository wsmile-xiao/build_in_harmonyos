# mp3gain

mp3gain is a tool for analyzing and adjusting the volume of MP3 files. It works by adjusting the mp3 file directly, without decoding and re-encoding, so it's very fast and doesn't lose audio quality.

- **Website**: https://github.com/Sound-Linux-More/mp3gain
- **License**: LGPL
- **Category**: audio
- **Version**: 1.6.2

## Dependencies

- mpg123 (libmpg123)

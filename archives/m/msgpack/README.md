# msgpack

[MessagePack](https://github.com/msgpack/msgpack-c) is a binary-based efficient
object serialization library. This `msgpack-c` recipe packages the C API of the
msgpack-c project, which compiles `libmsgpack-c` (a real C shared/static library,
**not** header-only).

The C++ API lives in a separate `msgpack-c` header-only variant and is not
packaged here.

# mjson

mjson is an embedded-friendly C/C++ JSON parser, emitter, and JSON-RPC engine. It provides a state-machine parser, JSONPath lookup, JSON generation, and JSON-RPC support without external dependencies.

- **Source:** https://github.com/cesanta/mjson
- **License:** MIT
- **Build system:** Makefile

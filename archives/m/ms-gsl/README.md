# ms-gsl

HarmonyOS Conan archives for Microsoft's Guidelines Support Library (the package
name used by Conan Center for this library).

## Versions

- `4.2.1`: header-only C++14 package exporting the upstream `Microsoft.GSL::GSL`
  CMake target, with the upstream GoogleTest suite built and executed through
  ctest inside `build()`.

See the version directory for the recipe, source checksum, patch, test package,
build notes, and test report.

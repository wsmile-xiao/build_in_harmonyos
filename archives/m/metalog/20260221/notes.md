# metalog 20260221

- Fixed source to the upstream GitHub tag `20260221`; SHA-256 is recorded in `conandata.yml`.
- The source archive contains `configure.ac` and Automake inputs but no generated `configure`, so the build bootstraps them with `autoreconf -fi` before configuring and running Make.
- The generated GNU `config.guess` does not recognize HarmonyOS, so its portability patch is applied after `autoreconf`. The Automake 1.18 `config.sub` already accepts the `aarch64-unknown-linux-ohos` triplet; a former patch inserted a case arm into the wrong location and made the script syntactically invalid, so it was removed. On HarmonyOS, a maintained configure patch changes both temporary-directory umasks from 077 to 022 for HMDFS. The recipe reads the old/new lines from that patch and matches the generated file contents, so line offsets may vary by toolchain; Linux builds keep the generated configure script unchanged.
- PCRE2 is required for `libpcre2-8`. zlib is an optional Conan feature controlled by `with_compress` (default `True`); `False` passes upstream `--without-compress`.
- The HarmonyOS CI image provides `autoreconf` but not `aclocal`; `automake/1.18` supplies it as a Conan build tool requirement. Build-folder shims invoke its packaged Perl scripts with the worker's PATH Perl, avoiding the package wrappers' fixed Perl shebang. The OHOS profile injects stale `SHELL` and `CONFIG_SHELL` paths through Conan's `conanbuild` environment, overriding process-level assignments; the recipe now sets both variables directly on the configure command so they take precedence. Linux keeps Conan's default shell. `autoconf-archive/2024.10.16` provides `AX_CHECK_COMPILE_FLAG`, and `pkgconf/3.0.5` provides `pkg.m4` for `PKG_CHECK_MODULES`.
- The consumer tests call the CLI's version/help and configuration-validation paths. They do not start the syslog daemon, bind `/dev/log`, or require root. The HarmonyOS-specific check validates the packaged executable's ELF64 AArch64 machine type.
- Upstream tag has no test suite or test directory. See `test_package/` for the five added adaptation checks.
- CI #67293 reached configure successfully but exposed two OHOS build issues: the explicit configure command ran in the source directory while Conan's `Autotools.make()` runs in the build directory, and generated `make -j20` tried to create a jobserver FIFO on HMDFS (EPERM). The recipe now runs configure in `build_folder` and pins make to `-j1`, so subsequent `make` and `install` use the generated build-tree Makefiles without a jobserver pipe.

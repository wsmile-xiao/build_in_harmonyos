# maxima

**Maxima — 计算机代数系统（CAS）— 符号积分/求解/化简；本包为 ECL（Embeddable Common Lisp）构建**

## 命令行工具

- `maxima`

## 构建

- 构建系统：autotools
- 许可证：GPL-2.0-only
- 上游：https://maxima.sourceforge.io/

## 依赖

- `ecl/24.5.10`

## 版本

| 版本 | 状态 | 说明 |
|---|---|---|
| 5.49.0 | built | 首个鸿蒙 PC conan 配方 |

## 为什么做这个包

passagemath（SageMath 的模块化重打包）在鸿蒙 PC 上的 wheel 需要它作为原生底座。

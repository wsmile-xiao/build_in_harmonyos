## 软件介绍

mdocml（现名 mandoc）是一套 man page 编译器工具，把 `mdoc(7)`（BSD 系统首选的
`roff(7)` 宏语言）与 `man(7)`（UNIX 手册页的历史主流语言）编译为终端、HTML、
Markdown、UTF-8 等多种输出，并提供手册页数据库的生成与检索工具：

| 工具 | 作用 |
|---|---|
| `mandoc` | mdoc/man/roff 解析与格式化主程序（`man`/`apropos`/`whatis`/`makewhatis` 是它的别名） |
| `demandoc` | 宏展开器，输出剔除宏后的纯文本 |
| `soelim` | 处理 `.so` 指令的 include 展开 |
| `libmandoc.a` | 静态库（解析、校验、渲染、字符表、数据库读写） |

## OHOS 适配要点

构建系统是**手写 sh configure**（非 `generated by GNU Autoconf`，源树无
`aclocal.m4` / `configure.ac` / `config.guess` / `config.sub`），因此
**不需要 autoreconf，也没有 config.sub 陈旧三件套族风险**。

所有平台差异都通过上游官方提供的 `configure.local` 注入，**零源码补丁**：

| # | 缺口 | 现象 | 处置 |
|---|---|---|---|
| 1 | `CC="cc"` 找不到 | 全部 `tested *: no (compilation failed)` + `FATAL: no endian conversion functions` | `CC`/`AR` 取 profile `tools.build:compiler_executables`（R33） |
| 2 | HMDFS 无硬链接 | `ln: cannot create hard link ... Operation not permitted` | `LN="cp -f"`（**必须加引号**） |
| 3 | 无 `locale` 命令 | `HAVE_WCHAR=0` → regress 19 个 `utf8:diff` 失败 | `UTF8_LOCALE="en_US.UTF-8"`（设备 setlocale 实测可用） |
| 4 | `-static` 风险 | 上游默认自动探测 `-static` | `STATIC=" "`（官方 example 置空写法） |
| 5 | 无 `install` 命令 | `make install` → `Error 127` | `package()` 直接收纳产物，不走 install 目标 |

## 依赖关系

- 编译依赖: **zlib**（`read.c` 无条件 `#include <zlib.h>`，configure 把
  `-lz` 硬编码进 `LDADD`）。配方显式 `requires("zlib/1.3.1")` 并把 conan
  zlib 的 include/lib 注入 `CFLAGS`/`LDFLAGS`，**不依赖 SDK sysroot 里
  隐式可见的 zlib.h**。
- 运行依赖: 无（交付静态库与可执行件）。
- 测试依赖: **perl**（`regress/regress.pl` 的 shebang `#!/usr/bin/env perl`），
  走 HNP `/data/service/hnp/bin/perl` 5.42.0，不作为 conan `tool_requires`。

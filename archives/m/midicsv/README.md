# midicsv

Convert MIDI audio files to human-readable CSV format.

## 描述

midicsv 是一个将 MIDI 文件转换为可读的 CSV（逗号分隔值）文本格式的工具，
以及其反向工具 csvmidi 将 CSV 格式还原为标准 MIDI 文件。

这两个程序可用于：
- 以人类可读格式检查 MIDI 文件内容
- 用文本编辑器或脚本修改 MIDI 文件
- 创建新的 MIDI 文件（通过编写 CSV 文本）
- 批量处理 MIDI 文件（配合 perl/python 脚本）

# moe — Console text editor for ISO-8859 and ASCII

GNU moe 是一个控制台文本编辑器，支持 ISO-8859 和 ASCII 字符编码。

## 特性

- 无模式、用户友好的界面
- 在线帮助
- 多窗口支持
- 全局搜索/替换（所有缓冲区同时操作）
- 块操作
- 自动缩进
- 自动换行
- 文件名补全
- 目录浏览器
- 提示历史去重
- 定界符匹配
- UTF-8 文本转换
- 罗马化

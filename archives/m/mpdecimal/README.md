# mpdecimal — General Decimal Arithmetic Library

## Description
mpdecimal is a C/C++ library for decimal floating point arithmetic, implementing
the General Decimal Arithmetic Specification (IEEE 754-2008).

It Homepage: https://www.bytereef.org/mpdecimal/

## Versions
- 4.0.1 (published]

## Features
- C library (libmpdec`) for decimal arithmetic
- C++ library`libmpdec++`) for decimal arithmetic
- Static and shared libraries
- pkg-config support

- Thread-safe operations

- __uint128_t` support on a64-bit

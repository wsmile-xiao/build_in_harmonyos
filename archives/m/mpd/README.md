# mpd

MPD (Music Player Daemon) 是一个服务端音频播放器，支持远程控制。

## 描述
MPD 是一个灵活的、强大的服务端音频播放器。通过客户端程序（如 ncmpcpp, mpc）远程控制音乐播放，支持多种音频格式和输出方式。

## 已编译版本
- 0.24.12 (2026-05-25)

## 依赖
- fmt 11.1.1
- glib2 2.84.0

## 特性
- 支持多种音频格式解码
- 支持多种音频输出方式
- 服务端/客户端架构

## 使用方法
```bash
# 启动 mpd 服务
mpd ~/.mpd/mpd.conf

# 查看版本
mpd --version
```

# MiniJinja CLI

A command-line tool for the MiniJinja template engine.

## Description

MiniJinja is a minimal implementation of the Jinja2 template engine for Rust. This CLI tool provides a way to render templates from the command line.

## Homepage

https://github.com/mitsuhiko/minijinja

## License

Apache-2.0

## Usage

```bash
minijinja-cli --version
minijinja-cli template.j2 --data data.json
```

## Available Versions

- **2.20.0** (published, 2026-05-21)

## Installation

Download the precompiled package `minijinja-cli-2.20.0-ohos-aarch64.tar.gz` and extract it.

```bash
tar -xzf minijinja-cli-2.20.0-ohos-aarch64.tar.gz
# The binary will be at bin/minijinja-cli
```

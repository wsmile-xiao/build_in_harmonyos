# Matplot++

Matplot++ is a C++ graphics library for data visualization.

## Description

Matplot++ is a C++ graphics library for data visualization. It provides a simple interface to create plots, charts, and other visualizations using the gnuplot backend.

## Version

- **Latest**: 1.2.0

## Dependencies

- **Runtime**: gnuplot (required for plotting)
- **Optional**: JPEG, TIFF, PNG, ZLIB, OpenCV, FFTW, BLAS, LAPACK

## Build System

- CMake

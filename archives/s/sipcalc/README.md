# sipcalc — Advanced console-based IP subnet calculator

## Description

sipcalc is an advanced console-based IP subnet calculator. It supports IPv4 and IPv6 subnet calculations, providing detailed network information including CIDR notation, network addresses, broadcast addresses, usable address ranges, and more.

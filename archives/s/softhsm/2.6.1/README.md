# Packaging for softhsm 2.6.1

This directory contains the precompiled package.

## Package File

- softhsm-2.6.1-ohos-aarch64.tar.gz

## Installation

Use the cmd-pkgs public installation script:

```bash
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- softhsm 2.6.1
```

## Contents

- bin/softhsm2-util
- bin/softhsm2-keyconv
- bin/softhsm2-dump-file
- lib/softhsm/libsofthsm2.so
- lib/softhsm/libsofthsm2.a
- etc/softhsm2.conf.sample

# span-lite

A C++20-like span for C++98, C++11 and later, single-file header-only library by Martin Moene.

- 上游: https://github.com/martinmoene/span-lite
- 版本: 0.11.0 (tag v0.11.0)
- 许可: BSL-1.0
- 结构: header-only（`include/nonstd/span.hpp`），CMake INTERFACE library（`nonstd::span-lite`）
- 适配状态: 见 `0.11.0/`

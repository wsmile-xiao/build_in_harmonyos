# smp-utils

`smp-utils` is Douglas Gilbert's SAS Management Protocol (SMP) utility suite
from the sg3_utils family: the `libsmputils1` library plus 29 `smp_*`
command-line tools for talking to SAS expanders (REPORT GENERAL, DISCOVER,
PHY CONTROL, zoning, GPIO, ...).

# sdl-mixer

SDL_mixer 1.2.12 is the SDL 1.2 audio mixer library, adapted for HarmonyOS PC aarch64 through the published `sdl12-compat/1.2.68` package.

The package provides the `SDL_mixer` library and SDL 1.2-compatible mixer headers. Optional MOD, Ogg, FLAC, MP3, MIDI, and external-player backends are disabled for the minimal reproducible build.

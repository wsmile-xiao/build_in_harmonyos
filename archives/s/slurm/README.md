# slurm

Yet another network load monitor — 基于 ncurses 的网络流量实时监控工具，在终端界面上显示网络接口的收发统计信息。

## 功能特性
- 实时监控网络接口流量
- 多种显示模式（经典模式、分屏模式、大屏分屏模式）
- 主题支持（可自定义配色方案）
- LED 样式收发指示器

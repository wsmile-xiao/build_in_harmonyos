# sherpa-onnx

Speech recognition, TTS, speaker diarization, and VAD using next-gen kaldi and onnxruntime.

## Versions

- **1.13.7** — First adaptation for HarmonyOS PC (aarch64), with TTS support enabled.

## Dependencies

- onnxruntime/1.27.1 (Conan 制品仓)
- Other sub-dependencies are automatically downloaded via CMake FetchContent.

# shortfin 1.0 适配笔记

## 编译环境
- 构建系统: makefile (custom, generated by Conan recipe)
- 编译日期: 2026-09-04
- 编译器: clang/clang++
- 状态: published

## 编译步骤

1. conan create 使用 ohos-aarch64 profile
2. Conan recipe 生成 config.h (手动生成，替代 autotools configure)
3. Conan recipe 生成 Makefile (手动生成，替代 automake)
4. make -j1 编译所有源文件
5. test_package 验证二进制存在

由于 HarmonyOS PC 上没有 automake/autoconf，Conan recipe 手动生成 config.h 和 Makefile。
使用 AutotoolsToolchain 仅生成编译器环境变量 (CC, CFLAGS, LDFLAGS)。

## 遇到的问题与解决方案

| # | 问题 | 根因 | 解决方案 |
|---|------|------|----------|
| 1 | autotools 不可用 | HarmonyOS PC 无 automake | 手动生成 config.h 和 Makefile |
| 2 | configure 失败 (G0) | 源码使用 autotools 但无法运行 configure | Conan recipe 跳过 configure，直接生成 Makefile |
| 3 | kqueue 不可用 | HarmonyOS 使用 epoll | config.h 不定义 HAVE_SYS_EVENT_H |

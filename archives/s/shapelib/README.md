# Shapelib

> C library for reading and writing ESRI Shapefiles

## 简介

Shapelib 是一个用于读写 ESRI Shapefiles 的 C 库，广泛用于地理信息系统（GIS）数据处理。

## OHOS 适配

- 构建系统：CMake
- 需要 config.guess/config.sub 平台适配补丁
- 编译成功，预编译包可用

## 功能特性

- 读写 ESRI Shapefile 格式
- 支持 .shp、.shx、.dbf 文件
- 简单易用的 C API

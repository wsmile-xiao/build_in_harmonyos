# squashfs-tools-ng

A new generation of SquashFS tools and library (libsquashfs).

Provides CLI tools for creating, inspecting, and extracting SquashFS filesystem
images with support for gzip, xz, lz4, zstd, bzip2, and lzo compression.

## Tools

- **gensquashfs** — create SquashFS images from file listings or directories
- **rdsquashfs** — inspect and unpack SquashFS images
- **sqfs2tar** — convert SquashFS image to tarball
- **tar2sqfs** — convert tarball to SquashFS image
- **sqfsdiff** — compare contents of two SquashFS images

## Library

- **libsquashfs** (libsqfs) — embeddable SquashFS library (LGPLv3)

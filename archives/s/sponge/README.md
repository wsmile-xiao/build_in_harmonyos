# sponge

> Soak up standard input and write to a file

sponge reads standard input and writes it out to the specified file. Unlike a
shell redirect, sponge soaks up all its input before writing the output file.
This allows constructing pipelines that read from and write to the same file.

sponge is part of the [moreutils](https://joeyh.name/code/moreutils/) collection
by Joey Hess.

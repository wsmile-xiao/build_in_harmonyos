# SDL_mixer

SDL_mixer 1.2.12 provides audio mixing support for SDL 1.2 applications.
This HarmonyOS PC adaptation builds the static library against the published
`sdl12-compat/1.2.68` compatibility layer and disables optional backends whose
third-party dependencies are not part of the package.

# stlink

STM32 ST-LINK 调试/烧写工具集与库（st-flash / st-info / st-util / st-trace）。

- 上游: https://github.com/stlink-org/stlink (BSD-3-Clause)
- 适配版本: 1.8.0
- 构建系统: CMake
- 依赖: libusb/1.0.27

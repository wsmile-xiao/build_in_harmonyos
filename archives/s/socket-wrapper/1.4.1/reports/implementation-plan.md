# socket-wrapper 1.4.1 HarmonyOS PC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Produce a reproducible Conan 2 package for socket-wrapper 1.4.1 on HarmonyOS PC aarch64, with evidence-backed source patches, upstream CTest coverage, an end-to-end LD_PRELOAD consumer test, and a passing local CI run.

**Architecture:** Build the official 1.4.1 CMake release as shared interposition libraries. Reapply the platform findings from the validated 1.5.2 branch only after reproducing each 1.4.1 failure, keep source changes in version-specific patches, and make Conan own dependency resolution, ELF signing, upstream tests, installation, and consumer run environments.

**Tech Stack:** C11, CMake, Conan 2.29.1 OHOS build, cmocka/2.0.2, HarmonyOS 6.0 aarch64, Clang/LLVM, CTest, zsh CI scripts.

**Spec:** archives/s/socket-wrapper/1.4.1/reports/design.md

## Global Constraints

- Use socket-wrapper version 1.4.1; the local socket_wrapper-master tree is version 1.5.2 and is reference material only.
- Use https://ftp.samba.org/pub/cwrap/socket_wrapper-1.4.1.tar.gz with SHA256 390cc82a1b2103555cfd803bc1acbfeeed2b68cde081005b92cac78ec76554aa.
- Keep branch feat/socket-wrapper-1.4.1 tracking upstream/main.
- Do not stage, commit, overwrite, or discard local snow, libucontext, kcolorscheme, or libXext changes.
- Limit committed changes to archives/s/socket-wrapper/.
- Do not edit SKILL.md, references/, templates/, scripts/, ci/, index.tsv, or SUMMARY.md.
- Runtime libraries have no third-party dependency; cmocka/2.0.2 is test_requires only after W0 proves its OHOS binary exists.
- Build shared libraries only. Do not create commands.json because no user command is installed.
- Patch additions must not inject __OHOS__; use capability macros or recipe-supplied CMake options.
- Run every registered 1.4.1 upstream test on HarmonyOS at least once. Expected-failure handling requires an independent platform probe.
- .ci-result.json may only be generated by ohc-run.py finish.
- Do not push or create a PR without a separate explicit user request.

- [ ] **Step 2: Implement identity and validation**

~~~python
class SocketWrapperConan(ConanFile):
    name = "socket-wrapper"
    version = "1.4.1"
    package_type = "library"
    settings = "os", "compiler", "build_type", "arch"
    options = {"shared": [True, False], "with_upstream_tests": [True, False]}
    default_options = {"shared": True, "with_upstream_tests": True}

    def validate(self):
        if str(self.settings.os) not in ("Linux", "OHOS"):
            raise ConanInvalidConfiguration(
                "socket-wrapper requires POSIX sockets and LD_PRELOAD"
            )
        if not self.options.shared:
            raise ConanInvalidConfiguration(
                "socket-wrapper builds shared interposition libraries only"
            )
~~~

- [ ] **Step 1: Classify every failure**

- [ ] **Step 2: Add musl prototype capabilities**

Probe under _GNU_SOURCE:

~~~cmake
check_prototype_definition(recvmmsg
  "int recvmmsg(int, struct mmsghdr *, unsigned int, unsigned int, struct timespec *)"
  "-1" "sys/types.h;sys/socket.h" HAVE_RECVMMSG_UNSIGNED_FLAGS)
check_prototype_definition(sendmmsg
  "int sendmmsg(int, struct mmsghdr *, unsigned int, unsigned int)"
  "-1" "sys/types.h;sys/socket.h" HAVE_SENDMMSG_UNSIGNED_FLAGS)
~~~

Declare the two macros in config.h.cmake. In every recvmmsg/sendmmsg typedef, libc wrapper, internal wrapper, and export, add a branch keyed only by those capabilities and use unsigned int flags.

- [ ] **Step 3: Neutralize LFS64 aliases**

Immediately before each matching interposed definition:

~~~c
#ifdef fopen64
#undef fopen64
#endif
#ifdef open64
#undef open64
#endif
#ifdef openat64
#undef openat64
#endif
~~~

Keep each undef adjacent to its function and do not use a platform macro.

- [ ] **Step 4: Honor TMPDIR**

Update tests/torture.c, tests/test_ioctl.c, and tests/test_fcntl_lock.c to read TMPDIR, strip trailing slashes, append the existing mkdtemp suffix, and retain /tmp only as fallback. Use bounded snprintf for fixed arrays and exact heap sizing in torture.c.

- [ ] **Step 5: Fix cmocka 2 range assertion only after RED**

If the imported-target symbol probe fails, include cmocka_version.h and select _assert_uint_in_range when HAVE_ASSERT_UINT_IN_RANGE exists or CMOCKA_VERSION_MAJOR is at least 2.

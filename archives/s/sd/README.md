# sd

Intuitive find & replace CLI (sed alternative).

sd is an intuitive find & replace CLI tool, similar to sed but with a simpler
and more user-friendly syntax. It supports regex and fixed-string replacements,
with features like preview mode and in-place file editing.

## Key Features
- Regex and fixed-string search/replace
- Preview mode for safe editing
- In-place file modification
- Capture group support in replacements

## Installation on HarmonyOS
- Precompiled binary from Alpine Linux (musl dynamic)
- Runtime dependencies: libc.musl-aarch64.so.1, libgcc_s.so.1

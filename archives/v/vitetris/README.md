# vitetris

vitetris is a terminal-based Tetris game. It can be played at the Linux console,
in an xterm, or over a telnet/ssh connection.

## Description
vitetris is a Tetris clone for the terminal that doesn't require X11, making it
suitable for play over SSH or on text-only terminals.

## Links

- ncurses or slang (terminal UI)
- C compiler (gcc/clang)

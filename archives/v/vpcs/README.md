# vpcs — Virtual PC Simulator

VPCS (Virtual PC Simulator) provides a command-line interface to simulate 
multiple virtual PCs for testing IP routing in network simulation environments
like Dynamips or GNS3.

## Features
- Simulate up to 9 virtual PCs
- Ping/traceroute from/to virtual PCs
- Support for ICMP, TCP, UDP packets
- UDP pipe and Unix TAP interface modes
- DHCP, DNS, ARP support
- IPv4 and IPv6 support
- Hypervisor mode for managing multiple instances

# verovio

Command-line MEI music notation engraver for OpenHarmony platform.

## Description

Verovio is a fast, lightweight music notation engraving library that can render MEI (Music Encoding Initiative) files into SVG images. It is developed by the RISM (Répertoire International des Sources Musicales) Digital Center.

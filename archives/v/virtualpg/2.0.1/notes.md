# virtualpg 2.0.1 adaptation notes

## Scope

- Upstream provides `libvirtualpg` and the `mod_virtualpg` SQLite loadable extension.
- The build system is Autotools/Libtool and the release archive includes generated configure files.
- The package is a direct build-time dependency of spatialite-gui 2.1.0-beta1, whose `configure.ac` requires `virtualpg.pc`.

## Dependencies

- Required: `sqlite3/3.49.1` for the SQLite virtual-table API.
- Required: `libpq/18.1` for PostgreSQL client types and loadable-extension symbols.
- Both exact OHOS/armv8 binaries resolve from `ohpcd` with `--build=never`.
- Upstream hard-requires `pg_config`; the recipe supplies a build-only query wrapper derived from the Conan `libpq` package folder.

## Patches

- `0001-config.guess.patch` identifies native aarch64 HarmonyOS as `aarch64-unknown-linux-ohos`.
- `0002-config.sub.patch` accepts the `linux-ohos` kernel/OS pair and canonical OS suffix.
- `0003-configure.patch` changes only the two `confXXXXXX` directory-creation masks from `077` to `022`, preventing HMDFS setgid semantics from making `config.status` temporary directories unwritable.
- The patches were generated by `refresh-patch --auto` in a POSIX runtime because the Windows path-separator defect prevents strict local dry-run.

## Build and packaging

- `AutotoolsDeps` supplies explicit SQLite3 and libpq include/library paths.
- Shared OHOS builds override both Libtool targets with `-avoid-version` so HMDFS produces one real unversioned shared object with matching SONAME.
- Static builds disable the loadable module and package only `libvirtualpg.a`.
- The installed `virtualpg.pc` is rewritten to use a relocatable `${pcfiledir}` prefix.

## Tests

- Upstream registers no Automake `TESTS`; the recipe still executes `make check` and records the zero-test result.
- The Conan consumer test initializes the extension with a complete real libpq vtable, checks the package version, checks the forwarded libpq version, verifies the NULL-vtable error path, and confirms the SQLite module registration call succeeds.

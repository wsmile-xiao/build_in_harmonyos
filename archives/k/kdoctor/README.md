# kdoctor

| 版本 | 状态 | 日期 |
|------|------|------|

## 描述

kdoctor 是一个 Kubernetes 网络诊断工具，用于检测集群网络连通性、DNS 解析、延迟等网络问题。它由 kdoctor-io 团队开发，作为 Kubernetes 控制器运行，提供 agent 和 controller 两个组件。

## 编译信息

- **构建系统**: Go
- **Go 版本**: go1.26.4
- **目标平台**: OpenHarmony aarch64
- **源码**: https://github.com/kdoctor-io/kdoctor

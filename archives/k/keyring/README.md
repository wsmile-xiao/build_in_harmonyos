# keyring

Python keyring library - provides a unified interface for accessing system keyrings (password stores).

This is a pure Python package with no C compilation required.

## Version

- 25.6.0 (built 2026-06-12)

## Build Notes

- Pure Python package - no C compilation needed
- Installed via wheel extraction to site-packages
- Dependencies: jaraco.classes (3.3.1), jaraco.functools (3.7.0), jaraco.context (6.0.1), more-itertools (11.1.0)
- Network issues required manual wheel download from Aliyun PyPI mirror

## OpenHarmony Compatibility

- Works on aarch64/musl (OpenHarmony)
- Python 3.14 compatible

# kuickshow

KDE KuickShow: a fast and versatile image viewer on Qt6 Widgets + KF6
(fast browser, slideshow, flips/rotations, zoom). On HarmonyOS PC it uses
the pure-Qt image backend (no Imlib, no X11).

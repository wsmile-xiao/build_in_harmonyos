## 补充说明

- **关联 OHPCD 任务**：#12692。
- 源码固定到上游 v0.3 tag 对应提交 `de06befe878be061a40540d2127d4273320b35bc`。
- 上游 CMake 项目会执行 `git describe --dirty --tags` 生成版本字符串，因此配方从官方 TI Git 仓库按完整提交克隆，保留 tag 元数据。
- `conandata.yml` 内联补丁将 `--version` 检查移到 SoC/MMIO 初始化前，避免普通鸿蒙 PC 因 `/dev/mem` 不可访问而无法输出版本；硬件诊断命令仍需受支持的 TI K3 主机，CI 不运行这些命令。

# kwalletmanager

KDE Wallet Manager (KDE Gear 26.04.0): password management tool for the
KDE Wallet system — list, create, open and edit KWallet wallets over the
org.kde.KWallet D-Bus interface, on Qt6 Widgets + KF6.

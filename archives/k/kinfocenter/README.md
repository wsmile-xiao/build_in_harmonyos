# kinfocenter

KDE Info Center (Plasma 6.7.2): the system information KCM plugin set —
system tray-less info modules (CPU/memory/PCI/USB/Samba/network...) plus
the private KInfoCenterInternal QML helper library, on Qt6/KF6.

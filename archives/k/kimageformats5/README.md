# kimageformats5

KDE Frameworks 5 image format plugins for Qt — QImageIOHandler plugins for
formats the stock Qt build does not ship (ANI, EXR, HDR, PCX, PIC, PSD, QOI,
RAS, RAW, RGB, TGA, XCF).

This is the KF5 (Qt5) line, tracking the 5.116.0 release under the
`kimageformats5` package name, distinct from the KF6 `kimageformats` archives.

## Versions

- 5.116.0 — KF5 line, depends on qt5-qtbase/5.15.2.

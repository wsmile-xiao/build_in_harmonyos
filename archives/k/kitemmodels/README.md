# kitemmodels

`kitemmodels` is a KDE Frameworks 6 library providing Qt item-model helpers
(`libKF6ItemModels.so`) and, when Qt6Qml is available, the QML module
`org.kde.kitemmodels`.

## Versions

| Version | Status |
| --- | --- |
| 6.18.0 | built |
| 6.18.0.1 | built (enables the QML module `org.kde.kitemmodels`) |

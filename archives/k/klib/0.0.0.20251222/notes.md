## 适配方式

klib 主要以头文件和可直接纳入消费者工程的 C 源文件发布，因此配方将根目录 `.h`、`.c` 与 `cpp/*.hpp` 安装到 `include/klib`，不合成上游不存在的统一二进制库。

上游测试源码保持不变。OHOS 同时定义 `__linux__`，但其 musl libc 不提供 glibc 的 `memmem` 声明；构建测试时用 `-U__linux__` 关闭该基准分支。`kthread.c` 使用 `int64_t` 却未包含 `stdint.h`，构建测试时用 `-include stdint.h` 补齐声明。这两个参数只影响测试编译，不修改上游源码或测试断言。

# kdecoration

KDE Plasma window decoration plugin interface library. Provides the
KDecoration3::KDecoration API used by KWin window decorations (aurorae
etc.): DecorationButton/DecorationButtonGroup/DecorationShadow/
DecoratedWindow/DecorationSettings/DecorationThemeProvider.

- Upstream: https://invent.kde.org/plasma/kdecoration
- License: LGPL-2.1-only OR LGPL-3.0-only OR LicenseRef-KDE-Accepted-LGPL
- CMake package: `KDecoration3` (targets `KDecoration3::KDecoration`,
  `KDecoration3::KDecoration3Private`)
- Libraries: `libkdecorations3`, `libkdecorations3private`

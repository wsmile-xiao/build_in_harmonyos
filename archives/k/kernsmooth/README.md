# kernsmooth

KernSmooth — 函数用于核平滑，支持 Wand & Jones (1995) "Kernel Smoothing"。

- 上游：CRAN R 包 KernSmooth（https://cran.r-project.org/package=KernSmooth）
- 版本：2.23-26
- 许可：Unlimited use and distribution（LICENCE.note）
- 类型：静态库（Fortran 77 数值核心，供 C/C++ 调用）

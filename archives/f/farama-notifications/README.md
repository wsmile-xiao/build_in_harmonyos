# farama-notifications

## Overview

[farama-notifications](https://github.com/Farama-Foundation/farama-notifications)
is a small pure-Python helper package from the Farama Foundation, used by
Gymnasium and other Farama projects to display update notifications.

**Type**: pure Python package — not a C/C++ library.

## Package layout

- `$PREFIX/lib/python3.12/site-packages/farama_notifications/`

## Runtime

Requires Python 3.12 site-packages on `PYTHONPATH`.

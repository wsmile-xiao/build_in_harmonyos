# Foma

Foma is a multi-purpose finite-state toolkit designed for applications ranging
from natural language processing and research in automata theory.

## Features

- Finite-state automata construction and manipulation
- Compatible with Xerox xfst and lexc tools
- Includes library (libfoma) for embedding in applications
- Command-line tools: foma, flookup, cgflookup

## Installation

Pre-compiled packages are available for OpenHarmony aarch64.

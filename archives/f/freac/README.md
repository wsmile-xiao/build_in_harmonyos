# freac — free audio converter

freac (formerly BonkEnc) is a free audio converter and CD ripper with support for various popular formats and encoders. It currently supports MP3, MP4/M4A, WMA, Ogg Vorbis, FLAC, AAC, WAV, and Bonk formats.

## Features
- Converts between multiple audio formats
- CD ripping with CDDB/freedb support
- ReplayGain calculation
- Easy-to-use GUI interface
- Multi-platform support

## Version 1.1.7

- Built on HarmonyOS using custom Makefile build system
- Requires smooth v0.9.x and boca v1.0.x as dependencies
- GUI depends on GTK+3 ecosystem

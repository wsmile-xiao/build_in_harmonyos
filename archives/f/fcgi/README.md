# fcgi

FastCGI protocol library - a high-performance alternative to CGI for web applications.

## Description
fcgi (FastCGI) is a protocol for communicating between web servers and applications. It provides a persistent connection model that avoids the overhead of starting a new process for each request, making it significantly faster than traditional CGI.

# fsm-variant

`fsm-variant` is a header-only C++17 finite-state-machine library based on `std::variant`, adapted for OpenHarmony PC arm64.

- Version: 1.0.0
- Upstream: https://github.com/mpusz/fsm-variant
- Conan package: `fsm-variant/1.0.0@ohpcd/stable`

The package exports the CMake target `mp::fsm` from `find_package(fsm CONFIG REQUIRED)`.

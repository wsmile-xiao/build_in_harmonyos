# findent - Fortran 代码格式化工具

## 软件简介

findent 是一个 Fortran 代码缩进/格式化工具，支持 Fortran 固定格式和自由格式代码的自动缩进处理。它可以将混乱的 Fortran 代码自动格式化为规范缩进形式。

## 版本信息

- 最新版本: 4.3.6
- 源码地址: https://downloads.sourceforge.net/project/findent/findent-4.3.6.tar.gz
- 构建系统: autotools
- 目标平台: HarmonyOS (OpenHarmony) aarch64

## 功能特性

- 支持 Fortran 固定格式和自由格式代码格式化
- 支持从固定格式到自由格式的转换
- 提供 vim/gedit/emacs 编辑器集成脚本（wfindent）
- 可作为独立命令行工具使用
- 支持 Fortran 77、90、95、2003、2008 标准

# foonathan-memory 0.7 Conan package

This directory records the device-side package payload produced by the OHOS
Conan W3 build. The release artifact is generated from the Conan package cache;
the recipe remains the source of truth for reproducible publication.

- Target: HarmonyOS/OpenHarmony PC arm64 (`os=OHOS`, `arch=armv8`)
- Library: `lib/libfoonathan_memory-0.7.0.a`
- Headers: `include/foonathan_memory/`
- Tool: `bin/nodesize_dbg`
- Release archive: `foonathan-memory-0.7-ohos-aarch64.tar.gz`
- Debug archive: `foonathan-memory-0.7-ohos-aarch64-debug.tar.gz`

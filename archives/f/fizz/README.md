# fizz - Facebook TLS 1.3 Library

fizz 是 Facebook 开源的 TLS 1.3 协议实现库，提供安全、高效的加密通信功能。

## 特性

- 完整的 TLS 1.3 协议实现
- 支持 AsyncTLS 异步 API
- 集成 OpenSSL 和 libsodium
- 高性能加密通信

## 版本

- v2026.05.18.00 (2026-05-26)

## 依赖

- folly (Facebook C++ 库)
- openssl
- libsodium
- boost (context, filesystem, program_options, regex)
- fmt
- double-conversion

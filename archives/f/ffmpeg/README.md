# FFmpeg

FFmpeg 是一套完整的跨平台音视频处理工具集，包括：
- ffmpeg：核心音视频处理程序
- ffprobe：媒体文件分析工具
- ffplay：简单媒体播放器（可选）

## 简介

FFmpeg 是领先的多媒体框架，能够解码、编码、转码、mux、demux、流式传输、过滤和播放几乎所有人类和机器创造的内容。它支持最晦涩古老的格式，直到最前沿的格式。

## 使用方法

安装后可使用以下命令：
```bash
ffmpeg -i input.mp4 -c:v libx264 output.mp4  # 视频转码
ffprobe input.mp4                             # 查看媒体信息
```

## 注意事项

1. 需要启用 GPL 许可（--enable-gpl）
2. 二进制文件需要 ELF 签名才能在鸿蒙系统上运行
3. 使用静态编译避免动态库依赖问题

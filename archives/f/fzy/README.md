# fzy — 快速模糊文本选择器

## 简介

fzy 是一个快速的终端模糊文本选择器（fuzzy finder）。它从标准输入读取选项列表，
通过交互式界面让用户进行模糊搜索和选择。与 fzf 等同类工具相比，fzy 使用不同的
匹配算法，优先匹配字符串开头位置，搜索响应更快。

## 核心特性

- **快速模糊匹配算法**：基于评分机制的模糊搜索，优先匹配起始位置
- **终端交互式选择**：实时显示匹配结果，支持键盘选择
- **线程化搜索**：使用多线程并行搜索（-j 参数控制线程数）
- **非交互模式**：支持 `-e` (--show-matches) 模式用于脚本管道
- **MIT 许可证**：开源友好

## 构建信息

- 构建系统：自定义 Makefile（非 autotools/cmake）
- 编程语言：C
- 外部依赖：无（仅链接 libc 和 libpthread）
- 编译器：clang 15.0.4
- 编译选项：`CC=clang CFLAGS="-O2 -fPIC"`
- 目标平台：HarmonyOS aarch64 (musl libc)

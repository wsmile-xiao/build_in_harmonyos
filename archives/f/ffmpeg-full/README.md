# ffmpeg-full

ffmpeg-full 是 ffmpeg 的全功能版本，启用了大量编解码库（freetype/harfbuzz/fribidi/opus/vorbis/theora/openjpeg/mp3lame/soxr/openssl），提供共享库构建。

## 版本

| 版本 | 状态 | 日期 |
|------|------|------|
| 8.1.1 | published | 2026-05-27 |

## 描述

FFmpeg 是领先的多媒体框架，能够解码、编码、转码、混流、过滤和播放几乎所有格式的音视频内容。ffmpeg-full 版本启用了 GPL/版本3/非免费编解码器和多个外部库依赖，提供最全面的功能支持。

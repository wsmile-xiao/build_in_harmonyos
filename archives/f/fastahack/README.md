# fastahack

Fast FASTA file indexing, subsequence and sequence extraction tool.

- Homepage: https://github.com/ekg/fastahack
- Author: Erik Garrison (Marth Lab, Boston College)
- Version: 1.0.0
- License: MIT
- Build system: pure Makefile (no configure script), single CLI executable
- Features: FASTA index (.fai) generation, sequence/subsequence extraction,
  Shannon entropy, dump, stdin region streaming

# freealut

## Description
freealut is a free implementation of the OpenAL Utility Toolkit (ALUT) library. It provides a set of portable, easy-to-use functions for loading audio samples and creating sound effects using OpenAL.

## Website
https://github.com/vitaly-kr/freealut (mirror) / Original: http://www.openal.org/

## Dependencies
- OpenAL (openal-soft) — required at compile time and runtime

# typobuster

Typobuster is a lightweight Python/GTK3 text editor for common text
transformations and typo correction.

Version `1.0.0` is packaged as a Python desktop application. It requires the
target system to provide Python 3, GTK3, GtkSourceView 4, PyGObject and
PyCairo. Gspell and Hunspell dictionaries are optional upstream features.

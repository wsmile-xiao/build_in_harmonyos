# tinycdb

创建和读取常量数据库（CDB 格式）的工具和库。

## 简介

tinycdb 是一个小型、快速、可靠的常量数据库创建和读取工具及子程序库。数据库结构针对快速读取进行了优化：成功的查找通常只需两次磁盘访问。数据库不支持更新，每次变更时需要从头重建。

## 主要特性

- 快速查找：每次查询通常只需两次磁盘访问
- 可靠性：CDB 格式保证崩溃时不会损坏数据
- 内存占用小
- 同时提供命令行工具（`cdb`）和 C 语言库（`libcdb.a`）
- 支持查询、导出、列表、创建和统计功能

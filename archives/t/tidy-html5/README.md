# tidy-html5

HTML Tidy is a tool for checking and correcting HTML markup. It is the
continuation of the original Tidy project by Dave Raggett.

## Description

HTML Tidy acts as a validator and a fixer for HTML documents. It can:
- Detect and report errors in HTML markup
- Correct common coding problems
- Clean up the formatting of the markup
- Generate cleaned-up versions of HTML documents

## Versions

- 5.8.0 (2021-07-16): Latest stable release

## Build System

CMake-based build system.

## Dependencies

None. Standalone build.

# tree-sitter

tree-sitter 是一个增量式解析系统，用于编程工具开发。它提供了一个高效的解析器生成器和一个增量式解析库，可以在编辑过程中快速重新解析源代码。

## 描述
tree-sitter 主要特性：
- 增量解析
- 错误恢复
- 语言无关
- 多语言绑定

## 使用说明
tree-sitter 编译为库文件（无命令行工具）：
- libtree-sitter.a：静态库
- libtree-sitter.so：共享库

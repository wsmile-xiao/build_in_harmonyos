# ttyrec

Terminal interaction recorder and player

## 描述

ttyrec 是一个终端交互录制和播放工具。它可以录制终端会话并保存到文件中，然后使用 ttyplay 回放录制的内容。

## 版本

- 1.0.8 (2026-06-08)

## 功能

- **ttyrec**: 录制终端会话
- **ttyplay**: 回放录制的终端会话
- **ttytime**: 显示录制文件的时间信息

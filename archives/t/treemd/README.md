# treemd

TUI and CLI dual pane markdown viewer with tree-based structural navigation and syntax highlighting.

- **Homepage**: https://github.com/epistates/treemd
- **License**: MIT
- **Language**: Rust
- **Build System**: cargo

## Description

treemd is a modern markdown viewer combining tree-based navigation with interactive TUI.
It provides a dual-pane interface with vim-style navigation, syntax highlighting,
and real-time search. CLI mode allows extracting, filtering, and analyzing markdown structure.

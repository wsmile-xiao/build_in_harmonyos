# tsduck

TSDuck - The MPEG Transport Stream Toolkit（上游：https://github.com/tsduck/tsduck，官网：https://tsduck.io/）。

数字电视 MPEG 传输流的开源参考框架：一组命令行工具（如 `tsp` 流处理器、`tsanalyze`、`tsversion` 等 40 余个）、运行时插件（`tsplugin_*.so`）以及两个 C++ 库（`libtsduck`、`libtscore`，C++20）。

## 版本

- `4676`：对应上游 tag `v3.44-4676`（major 3 / minor 44 / commit 4676），零外部依赖构建（nodep 标志集），BSD-2-Clause。

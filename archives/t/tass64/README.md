# tass64

Multi pass optimizing macro assembler for the 65xx series of processors (6502, 65C02, 65R02, 65816, etc).

## Homepage

https://tass64.sourceforge.net/

## Description

64tass 是一个多遍优化的宏汇编器，支持 65xx 系列处理器（6502, 65C02, 65R02, 65816 等）。主要用于 Commodore 64、NES、Apple II 等复古计算机的软件开发。

## Features

- 多遍优化编译
- 支持宏指令
- 支持条件编译
- 支持多种输出格式（二进制、PRG、CBM 等）
- 详细的错误报告和警告
- 跨平台支持

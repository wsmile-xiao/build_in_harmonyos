# termcolor

Header-only C++11 library for colored output in C++（ANSI 转义序列）。

- 上游：https://github.com/ikalnytskyi/termcolor
- 版本：2.1.0
- 适配路径：路径 A（基础适配）
- 构建系统：CMake（INTERFACE header-only target）
- 鸿蒙特有测试：`archives/t/termcolor/2.1.0/test_package/test.cpp`（5 项 ANSI 断言）

## 目录

- `2.1.0/` — 版本配方目录（conanfile.py + conandata.yml + manifest.yaml + test_package/）

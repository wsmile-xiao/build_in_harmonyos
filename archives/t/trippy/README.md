# trippy

Network diagnostic tool (traceroute/ping) for analyzing network paths.

## Overview

Trippy is a Rust-based network diagnostic tool that combines traceroute and ping functionality. It provides detailed network path analysis with TUI (terminal user interface) visualization.

## Key Features

- Traceroute with multiple protocols (ICMP, TCP, UDP)
- Real-time TUI visualization of network paths
- Network latency and hop analysis

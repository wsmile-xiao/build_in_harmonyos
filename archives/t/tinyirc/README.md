# tinyirc

tinyirc is Nathan Laredo's small terminal IRC client. The HarmonyOS PC recipe
packages the C executable against the published `ncurses/6.6` package.
The pinned author-repository commit carries Debian changelog version
`1:1.1.dfsg.1-1`; it is not byte-identical to Debian's separate
`1.1.dfsg.1.orig.tar.gz`. See the version notes for provenance and tests.

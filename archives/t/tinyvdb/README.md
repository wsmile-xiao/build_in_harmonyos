# tinyvdb

Pure-C11 OpenVDB (.vdb) reader/writer and volumetric geometry toolkit: core I/O
(bundled miniz/lz4/zstd), NanoVDB bridge, and mesh/ops/sample/tsdf/topology/ray
kernels. Upstream: https://github.com/syoyo/tinyvdb (Apache-2.0).

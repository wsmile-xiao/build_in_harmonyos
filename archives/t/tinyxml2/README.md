# tinyxml2

A simple, small, efficient, C++ XML parser that can be easily integrated into other programs.

## 版本

- 10.0.0 (2026-05-21) — published ✅
- 10.1.0 (2026-09-07) — built ✅
- 11.0.0 (2026-07-29) — built ✅

## 描述

tinyxml2 is a compact XML parsing library for C++ that provides a simple API for reading and writing XML data. It is designed to be easy to use and integrate, with no external dependencies.

## 编译信息

- 构建系统: cmake
- 编译器: clang 15.0.4 / clang++ 15.0.4
- 安装产物: 动态库 libtinyxml2.so（默认）或静态库 libtinyxml2.a + 头文件 tinyxml2.h + cmake config + pkg-config

## 使用

```cpp
#include "tinyxml2.h"
// Link with: -ltinyxml2
```

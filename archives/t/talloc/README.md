# talloc

## 简介

talloc 是 Samba 项目开发的层级内存池库，提供：
- 层级内存管理（父子关系）
- 自动释放机制
- 引用计数
- 类型安全
- 高性能内存池

## 关键特性

### 1. 层级内存管理
子对象随父对象自动释放，避免内存泄漏。

### 2. 高性能
内存池模式比 malloc 快 13 倍（5042158 ops/sec）。

### 3. 引用计数
支持多个引用指向同一对象，自动管理生命周期。

### 4. 类型安全
编译时类型检查，减少运行时错误。

## 使用场景

- Samba 文件服务器
- 需要层级内存管理的应用
- 高频内存分配/释放场景
- 多线程环境

# tcpkali

高性能 TCP/WebSocket 负载测试工具，基于 libev 事件循环库，支持多连接并发、消息速率控制、延迟测量、带宽限制、WebSocket (RFC6455) 协议等功能。

> **注意**: 原始上游仓库 (machinezone/tcpkali) 已不可用，当前使用保存的 fork [MumiaiGene/tcpkali](https://github.com/MumiaiGene/tcpkali)。

# 失败测试分析

## 失败原因分类

| 失败原因 | 出现次数 | 说明 |
|----------|----------|------|
| UID 范围超限 | 190+ | `value 20001006 out of uid_t range 0..2097151` |
| Permission denied | 10+ | stdin 读取、符号链接等操作被拒绝 |
| File exists | 3+ | 文件已存在冲突 |

## 主要问题详解

### 1. UID 范围超限

**错误信息**: `tar: value 20001006 out of uid_t range 0..2097151`

**原因**: 鸿蒙系统的用户 UID（20001006）超出了 tar v7 格式支持的 UID 范围（0-2097151）。

**影响**: 影响所有使用 v7 格式的测试。

**解决方案**: 
- 使用 `--owner` 和 `--group` 选项指定较小的 UID/GID
- 或使用 POSIX/PAX 格式而非 v7 格式

### 2. Permission denied

**错误信息**: `tar: -: Cannot open: Permission denied`

**原因**: 鸿蒙系统的安全限制，从 stdin 读取时可能被拒绝。

**影响**: 部分管道操作测试失败。

**解决方案**: 这是系统限制，无法在用户空间解决。

### 3. 符号链接操作

**错误信息**: `tar: symlink: Cannot open: Permission denied`

**原因**: 鸿蒙系统 SELinux 策略限制了用户进程对符号链接的访问。

**影响**: 涉及符号链接的测试失败。

**解决方案**: 使用 toybox 的 tar 命令处理符号链接相关操作。

## 结论

大部分失败是由于：
1. 鸿蒙系统的高 UID 值与 v7 格式不兼容
2. 系统安全策略限制（SELinux）

**核心功能测试**: 基本的归档、解压功能正常工作。

# Aresponses

Asyncio http mocking. Similar to the responses library used for 'requests'.

- Website: https://github.com/CircleUp/aresponses
- Source: https://github.com/CircleUp/aresponses
- License: MIT
- Build system: Python (setuptools)
- Category: Python library / pytest plugin

## Description

Aresponses is an asyncio testing server for mocking external services.
It provides fast mocks using actual network connections, allows mocking
some types of network issues, and works with https requests.

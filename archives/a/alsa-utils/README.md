# alsa-utils

## 简介
ALSA Utilities - Advanced Linux Sound Architecture 用户空间工具集

## 包含命令
- aplay/arecord: 音频播放/录制
- amixer: 混音器控制
- alsamixer: Ncurses 混音器界面
- alsactl: ALSA 控制工具
- speaker-test: 音频测试工具
- alsabat: 音频基准测试工具
- axfer: 音频传输工具

## 版本信息
- 当前编译版本: 1.2.14
- 依赖: alsa-lib >= 1.2.13, ncurses

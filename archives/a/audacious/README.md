# audacious

audacious 是一个先进的开源音频播放器。
## 描述
audacious 支持多种音频格式，具有插件架构和高度可定制性。是 GTK+ 和 Qt 硌代方案（Winamp 风格皮肤）的成功继承者。
## 已编译版本
- 4.5.1 (2026-05-25)
## 依赖
- glib2 2.84.0
## 特性
- 支持多种音频格式（Ogg Vorbis, FLAC, MP3, WAV 等）
- 插件架构支持扩展
- 提供命令行播放核心（libaudcore/libaudtag）
## 使用方法
```bash
# 播放音频文件
audacious /path/to/song.ogg
```

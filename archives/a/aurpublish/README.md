# aurpublish

`aurpublish` is a PKGBUILD management framework for the Arch User Repository (AUR): it publishes git subtrees of a package repository to the AUR, with git hooks to keep sources and `.SRCINFO` in sync.

Upstream: https://github.com/eli-schwartz/aurpublish/

Pure bash script CLI — no compiled artifacts; runtime requires `bash` and `git` only.

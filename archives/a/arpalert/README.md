# arpalert

ARP alert network monitoring tool — monitors ARP traffic to detect new/unknown devices on the network.

## Description

arpalert listens to ARP traffic on a network interface and can trigger alerts when:
- A new MAC address appears on the network
- An IP address changes MAC address
- A MAC address changes IP address
- Unauthorized ARP requests are detected

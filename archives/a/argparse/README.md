# argparse

Feature-rich command line parser for Lua inspired by argparse for Python.

## 项目信息

- **主页**: https://github.com/mpeterv/argparse
- **许可证**: MIT
- **语言**: Lua
- **依赖**: Lua >= 5.1, < 5.4

## 描述

Argparse 是一个功能丰富的 Lua 命令行参数解析器，灵感来自 Python 的 argparse。

支持功能：
- 位置参数
- 选项和标志
- 可选参数
- 子命令
- 自动生成使用帮助和错误消息

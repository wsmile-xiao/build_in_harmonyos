# argparse-manpage

Build manual page from Python's `ArgumentParser` object.

## Description

argparse-manpage is a tool that automatically generates Unix manual pages
from Python's `argparse.ArgumentParser` objects. It takes a Python module
or file containing an `ArgumentParser` instance and produces a properly
formatted man page.

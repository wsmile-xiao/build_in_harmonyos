# ascii — 交互式 ASCII 参考工具

ascii 是一个命令行工具，用于查询 ASCII 字符的多种表示形式：名称、十进制、八进制、十六进制和二进制编码。

## 功能概述

- **字符查询**: 通过字符名、C 转义序列、助记符或数值查询 ASCII 字符信息
- **格式化输出**: 支持十进制(-d)、八进制(-o)、十六进制(-x)、二进制(-b) 表格显示
- **单行模式**: `-t` 参数输出紧凑的单行格式
- **垂直格式**: `-a` 参数配合格式选项输出垂直排列的详细信息
- **版本信息**: `-v` 显示版本号（注意：不支持 `--version`）

## OpenHarmony 适配要点

- **构建系统**: 纯 Makefile 项目，无 configure 脚本，直接使用 `make` 编译
- **编译器**: clang 15.0.4，编译零警告零错误（-Werror 严格模式）
- **依赖**: 仅依赖 musl libc，无其他库依赖
- **无需补丁**: 源码在 OpenHarmony ARM64 上直接编译通过，无需任何修改
- **版本标志**: 使用 `-v` 而非 `--version`（差异行为，测试脚本需注意）
- **man 页面**: 需要手动创建（asciidoctor 在平台上不可用）

## 依赖关系

- **编译依赖**: 无
- **运行依赖**: musl libc (libc.so)

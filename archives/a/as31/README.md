# as31

Intel 8031/8051 Assembler — a self-contained C command-line tool for assembling 8051 microcontroller code.

- Homepage: http://www.pjrc.com/tech/8051/
- Source: https://github.com/Susmit-A/as31
- License: MIT

## Description

as31 assembles 8031/8051 assembly source files (`.asm`) into various output formats including Intel HEX, binary, TDR, and S-record. It is a pure C project with no external dependencies.

# antidote

## 软件简介

antidote 是一个快速、简洁的 Zsh 插件管理器，是 legacy Antibody 和 Antigen 的现代实现。

### 主要特性

- 高性能：快速的插件加载和管理
- 简洁易用：简单的配置和使用方式
- 兼容性：支持 Antibody 和 Antigen 的迁移
- Oh My Zsh 支持：可集成 Oh My Zsh 插件
- 纯脚本：无需编译，跨平台兼容

### 安装方式

antidote 是纯脚本项目，无需编译，直接安装即可使用：

```zsh
# 在 .zshrc 中添加
source /path/to/antidote/antidote.zsh
```

或使用 antidote 安装脚本进行管理。

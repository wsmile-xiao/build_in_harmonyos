# autocutsel

X11 clipboard synchronization tool that keeps the PRIMARY and CLIPBOARD selections in sync.

## Description

autocutsel is a utility for X Window System that synchronizes the CLIPBOARD and PRIMARY selections. It tracks changes in both selections and updates the other one to match, making clipboard behavior consistent across applications that use different selection mechanisms.

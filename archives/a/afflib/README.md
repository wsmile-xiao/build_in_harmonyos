# afflib

AFF (Advanced Forensic Format) 数字取证镜像库。提供 affcat/affcompare/affconvert/affcrypto/affinfo 等 17 个命令行工具，用于数字取证镜像的创建、读取、签名、加密与校验。

- **版本**: 3.7.22
- **上游**: https://github.com/afflib/afflib
- **适配**: HarmonyOS PC (aarch64)
- **配方**: `3.7.22/conanfile.py` + `conandata.yml` + `test_package/`
- **CLI 工具**: 见 `commands.json`

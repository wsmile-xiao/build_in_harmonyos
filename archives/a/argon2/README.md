# Argon2

密码哈希竞赛(PHC)获胜者，提供 Argon2i/Argon2d/Argon2id 三种密码哈希变体。

## 编译指导

在 HarmonyOS/OpenClaw 平台编译时需设置环境变量：
```bash
export KERNEL_NAME=Linux
export LIBRARY_REL=lib
```

HarmonyOS 默认无 install 命令，需手动执行文件复制。

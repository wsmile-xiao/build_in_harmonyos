# appdirs

A small Python module for determining appropriate platform-specific dirs,
e.g. a "user data dir". Pure Python (single-module, stdlib only), no C/C++
code, no runtime dependencies.

- 上游仓库: https://github.com/ActiveState/appdirs
- 版本: 1.4.4 (2020-05, 上游最新 tag)
- 适配说明: 纯 Python noarch 包，无编译；`appdirs.py` 单模块拷贝到
  site-packages，供 HarmonyOS PC 上 Python 3.12 使用。

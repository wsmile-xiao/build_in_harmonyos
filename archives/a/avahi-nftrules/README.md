# avahi-nftrules

nftables firewall rules for Avahi mDNS/DNS-SD service.

## Description

This package provides nftables ruleset configuration files for the Avahi mDNS/DNS-SD daemon, allowing mDNS multicast traffic (port 5353/udp) through the firewall.

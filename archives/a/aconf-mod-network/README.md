# aconf-mod-network

Network administration module of Alpine Configurator (aconf), a web-based
configuration framework for Alpine Linux.

- Upstream: https://gitlab.alpinelinux.org/kunkku/aconf/
- License: BSD-2-Clause
- Build system: pure Lua resource module (no compilation)
- Package type: Alpine `aconf-mod-network` subpackage

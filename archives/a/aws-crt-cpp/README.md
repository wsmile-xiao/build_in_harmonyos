# AWS CRT C++ — OpenHarmony 编译档案

## 软件简介
aws-crt-cpp 是 AWS C 运行时的 C++ 封装库，提供 RAII 内存管理和所有 aws-c-* 库的 C++ API。

## 功能概述
- C++ API 封装
- RAII 内存管理
- 异步操作（C++ 协程）
- MQTT5/S3 C++ 客户端

## 依赖关系
- 编译依赖: 所有 aws-c-* 库
- 被依赖: AWS SDK for C++ v2

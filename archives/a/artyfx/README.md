# ArtyFX

LV2 audio plugin collection (audio effects suite). Includes DSP plugins for bitcrushing, delay, distortion, compression, EQ, reverb, and more.

- Homepage: https://github.com/openAVproductions/openAV-ArtyFX
- License: GPL-2.0
- Build system: CMake
- Language: C++

## Recipe Decisions

- Meson options:
  - `-Ddefault_library=shared`
  - `-Dwrap_mode=nodownload`
  - `-Ddisable_introspection=true`
  - `-Denable_docs=false`
- Introspection is disabled to avoid running `g-ir-scanner` and loading Python extension modules during package build.
- The recipe prepends dependency `bin/` directories to `PATH` so Meson can find GLib code-generation tools.
- The generated `glib-2.0.pc` and `gobject-2.0.pc` files are augmented with GLib code-generation tool variables required by Meson's GNOME module.
- GLib Python tool scripts are invoked through generated Python wrappers because `/usr/bin/env` has been unreliable on tested OHOS devices.
- On OHOS, the recipe links against the `libintl.so` shipped by the selected GLib package to resolve `g_libintl_*` symbols expanded from GLib i18n headers.
- The recipe creates `libatk-1.0.so.0` and `libatk-1.0.so` aliases when Meson cannot create shared-library symlinks on OHOS.
- `TMPDIR`, `TMP`, and `TEMP` are redirected to a build-local writable directory.
- On OHOS, the build environment prepends the SDK `ohos/native/llvm/lib` directory to `LD_LIBRARY_PATH` so SDK `lld` loads its matching `libxml2.so.16` during Meson and CMake linker probes.
- Installed OHOS ELF shared libraries are re-signed after `meson install`.

# j4-dmenu-desktop

`j4-dmenu-desktop` is a fast desktop application launcher compatible with
`dmenu`-style frontends.  This archive packages the command-line application
for HarmonyOS PC (aarch64).

## Versions

- `3.2` — Meson build, inotify backend, upstream Catch2 and pytest suites.

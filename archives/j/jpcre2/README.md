# JPCRE2

C++ wrapper for the PCRE2 library (header-only).

- 上游: https://github.com/jpcre2/jpcre2
- 版本: 10.32.01
- 依赖: pcre2/10.48（8/16/32 位全宽度构建，覆盖 test16/test32）
- 用法: `#include "jpcre2.hpp"`，链接 `jpcre2::jpcre2`（自动传递 PCRE2）

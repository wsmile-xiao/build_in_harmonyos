# jpdfbookmarks

JPdfBookmarks — PDF 书签编辑工具，支持添加、修改、导出 PDF 书签。

## 特性

- GUI 和 CLI 两种模式
- 支持 CJK（中日韩）字体和书签
- 基于 Java 运行，跨平台
- 可批量处理 PDF 文件的书签

## 运行要求

- JDK 17+（推荐 BiSheng JDK 17.0.13）
- JAVA_HOME 环境变量

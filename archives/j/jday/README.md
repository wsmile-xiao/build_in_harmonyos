# jday

Julian date calculator adapted for OpenHarmony: the `jday` / `j2d` / `dbd`
command line tools plus the `libjday` calendar-Julian conversion library.

- Upstream: https://jday.sourceforge.net/
- Version: 2.4
- Current package: `archives/j/jday/2.4`
- Supported OpenHarmony architecture: armv8

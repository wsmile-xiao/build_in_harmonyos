# json-glib

JSON library for GLib/GObject based applications. Provides parsing, generation, serialization, and deserialization of JSON data using GLib data types.

## 已编译版本

- 1.10.8 (本机 OHOS 交叉构建通过；等待 HarmonyOS PC 真机验证)
- 1.10.6 (2026-08-06)

## 依赖

- glib (core library)

## OHOS 适配说明

- meson 构建系统
- libintl 符号通过 glib 的 proxy-libintl 提供

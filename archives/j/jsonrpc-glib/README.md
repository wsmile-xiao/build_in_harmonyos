# jsonrpc-glib

A JSON-RPC library for GLib, part of GNOME.

## Versions

| Version | Status | Build System |
|---------|--------|-------------|
| 3.44.0  | built | meson |

## Description

jsonrpc-glib is a GLib-based JSON-RPC library that provides client and server
components for implementing JSON-RPC 2.0 protocol over GIO streams.

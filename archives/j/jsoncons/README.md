# jsoncons

jsoncons — 一个 C++ 17/20 的 JSON 数据格式库（解析/序列化/JSON Patch/Merge Patch/JMESPath 等），
由 Daniel Parker 开发，header-only 实现（`include/jsoncons/`），提供 CMake INTERFACE 库。

- 官方仓库：https://github.com/danielaparker/jsoncons
- 许可证：BSL-1.0（Boost Software License, Version 1.0）
- 版本：1.9.0（标签 `v1.9.0`，commit `bcb44594c50c495ee1e690602cdd71455942ad0e`）
- 目录结构：`archives/j/jsoncons/{version}/`（conanfile.py + conandata.yml + test_package/ + manifest.yaml + notes.md）

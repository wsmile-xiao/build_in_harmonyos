# joe

Full featured terminal-based screen editor (Joe's Own Editor)

## Description
joe (Joe's Own Editor) is a powerful terminal-based text editor for Unix systems.
It features multi-file editing, search and replace, undo/redo, syntax highlighting,
and many other features. joe emulates several other editors including Emacs (jmacs),
WordStar (jstar), Pico (jpico), and a restricted version (rjoe).

- 4.6

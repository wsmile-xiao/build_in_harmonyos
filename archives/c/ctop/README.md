# ctop

ctop 是一个类似 top 命令的容器指标监控工具，提供实时容器资源使用视图。

## 描述
ctop 提供容器运行时指标的实时视图，包括 CPU、内存、网络 I/O 等数据。支持 Docker 和 runc 容器运行时，提供简洁的终端界面。

## 已编译版本
- 0.7.7 (2026-06-17)

## 依赖
- Go 1.26.0

## 特性
- 实时容器指标监控
- CPU、内存、网络 I/O 显示
- 容器日志查看
- 容器停止/启动控制
- Docker 和 runc 后端支持
- 交互式筛选和排序

## 使用方法
```bash
# 启动容器监控
ctop

# 指定容器运行时
ctop -r docker
```

## 注意事项
- CGO_ENABLED=0 编译，纯静态二进制，无需源码修改

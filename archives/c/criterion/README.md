# Criterion

A cross-platform C and C++ unit testing framework for the 21st century.

## 简介

Criterion 是一个跨平台的 C 和 C++ 单元测试框架，提供了丰富的断言宏、参数化测试、测试夹具等功能。

## 特性

- 自动测试注册，无需手动枚举测试
- 支持参数化测试 (Theories)
- 支持测试夹具 (Fixtures)
- 多种输出格式：标准文本、TAP、JSON、JUnit XML
- 彩色输出
- 测试超时控制
- 进程隔离测试

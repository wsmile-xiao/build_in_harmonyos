# criterion 2.4.3 适配笔记

## 编译环境
- 构建系统: meson
- 编译日期: 2026-08-11
- 编译器: clang/clang++ (OHOS SDK 26.0.0.18)
- 状态: pending CI

## 编译步骤

1. 下载源码: criterion-2.4.3.tar.xz
2. 配置:
   ```bash
   meson setup build \
     -Dtests=disabled \
     -Dsamples=disabled \
     -Ddev=false \
     -Di18n=disabled \
     -Ddiffs=disabled \
     -Dtheories=enabled \
     -Dcxx-support=enabled \
     -Dwrap_mode=default \
     -Dforce_fallback_for=nanomsg,nanopb \
     -Ddefault_library=static
   ```
3. 编译: `meson compile -C build`
4. 安装: `meson install -C build --destdir <prefix>`

## 源码修改

- `0001-meson.build.patch`: 在 HarmonyOS 构建时将 nanomsg/nanopb/libgit2 CMake 子项目映射为 Linux/aarch64。使用 `host_machine.system() == 'harmonyos'` 作为检测条件（Meson 中 OHOS 平台的 system() 返回 'harmonyos'）。libgit2 部分在 diffs=disabled 时不会被触发，保留以备将来需要。

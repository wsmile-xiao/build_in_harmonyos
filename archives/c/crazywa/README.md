# CrazyWa

CrazyWa is H.G. Muller's XBoard/WinBoard engine for chess and shogi variants
with drops. The command is `crazywa`; connect it to an XBoard-compatible GUI,
or send newline-delimited protocol commands on standard input.

Version `0.0.0-git2019.06.13` pins the official Git commit
`055bf038677d879e2bcccae8b6051f60af16b352`. The engine identifies itself as 1.0.5.

# cranium-ml

Cranium — 一个可移植、header-only 的人工神经网络库，用 C99 编写。

- 上游: https://github.com/100/Cranium
- 许可: MIT
- 语言: C99 (header-only)
- 组成: `src/cranium.h`（聚合入口）+ matrix/layer/network/function/optimizer 头文件
- 特性: 前馈神经网络、批量梯度下降、交叉熵/均方误差损失、矩阵运算、模型序列化

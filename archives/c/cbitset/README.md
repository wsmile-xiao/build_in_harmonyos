# cbitset

`cbitset` is a small C bitset library adapted for OpenHarmony PC arm64.

## Version

- Version: 0.4.0
- Upstream: https://github.com/lemire/cbitset
- Build system: CMake
- Conan package: `cbitset/0.4.0@ohpcd/stable`

The recipe enables the upstream CTest unit target, disables benchmarks, and
installs the public headers, static library, and CMake package config.

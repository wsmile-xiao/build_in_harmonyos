# cf — 时间戳转换过滤器

> 将输入中的数字时间戳（UNIX epoch）替换为格式化的日期时间字符串

## 概述

cf（convert timestamps）是 LBNL 开发的实用工具，功能是从输入流中读取数据，
将数字时间戳（UNIX epoch 格式）转换为人类可读的日期/时间字符串。
它作为标准 UNIX 过滤器运行，从 stdin 或指定文件读取数据，输出到 stdout。

## 可执行文件

- `cf` — 从输入中替换数字时间戳为格式化日期时间

## 用法

```
cf [-f fmt] [-lpsu] [文件 ...]
  -f  自定义 strftime 格式
  -l  长格式（包含年份）
  -p  仅显示时间戳部分
  -s  短格式
  -u  UTC 时间
```

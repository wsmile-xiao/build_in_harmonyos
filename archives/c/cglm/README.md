# cglm

cglm 是一个高度优化的 C 语言 2D/3D 数学库，灵感来自 GLM (OpenGL Mathematics)。

## 描述

cglm 提供 OpenGL/GLSL 数学函数的 C 语言实现，支持向量、矩阵、四元数等数学运算。它通过 SIMD 指令优化性能，适合游戏引擎和图形应用。

## 已编译版本

- 0.9.6 (2026-05-30)

## 特性

- GLSL 风格的 C 数学 API
- SIMD 优化（SSE、AVX、NEON）
- 向量、矩阵、四元数运算
- 头文件优先设计

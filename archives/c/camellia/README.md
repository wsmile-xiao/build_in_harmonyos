# camellia

`camellia` (CamelliaLib) is a low-level image processing and computer vision
library written in C with optional C++ wrappers. It uses the IplImage structure
and provides filtering; morphological mathematics; labeling and blob analysis;
warping; keypoints; Hough transforms; watershed segmentation; and PGM/BMP IO.

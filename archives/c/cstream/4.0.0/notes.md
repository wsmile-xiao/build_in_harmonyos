## 编译步骤
1. `AutotoolsToolchain` 传 `--build=aarch64-unknown-linux-gnu --host=aarch64-unknown-linux-ohos`（显式 triplet 绕过 config.guess；configure 内 umask 077 改 022，confstat 临时目录改 TMPDIR）+ `extra_cflags/cxxflags/ldflags` 追加 `--target` + SDK `llvm/lib` 注入 `LD_LIBRARY_PATH`，另经 Environment 固定 `CONFIG_SHELL/SHELL=/bin/sh` 与可写 `TMPDIR/TMP/TEMP`（优先 HMBS 注入值）+ mktemp 回退 PATH（acct 模式，优先 HMBS 能力）
2. `Autotools(self).configure()` + `make -j1`（走 conanbuild 工具链环境，不再手动 `self.run configure`）
3. `make check`（上游 Makefile.am 中 TESTS 已注释，仅保留调用痕迹）+ `sh tests/test1.sh small`（真实上游套件，small 跳过 8GB  soak 测试）
4. 产物复制 `cstream` 到 `bin/`，`cstream.1` 到 `share/man/man1`

## 上游测试审计
- 上游测试文件: tests/test1.sh、tests/vars.sh、tests/test1.log1-4（参照输出）
- 构建文件: Makefile.am 中 `#TESTS = tests/test1.sh` 被注释，`make check` 为空操作；真实测试需手动运行 `sh tests/test1.sh small`

cauchy 0.9.0 上游测试套件执行记录（权威复核 2026-09-10）
========================================================

构建方式（真机 Harmony PC aarch64；主机基线同参数）：
  源码 = 上游 cauchy_0.9.0.orig.tar.bz2 + 本 PR 补丁 0001/0002/0003
  cmake -S <src> -B <build> -DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++ \
    -DCMAKE_POLICY_VERSION_MINIMUM=3.5 -DEIGEN3_INCLUDE_DIR=<eigen3.4.0> -DCAUCHY_BUILD_TESTS=ON
  make -k -j8 ; ctest --output-on-failure

结果（补丁 0001+0002+0003）：
  真机  : 80% tests passed, 47/59 通过, 12 失败
  主机  : 80% tests passed, 47/59 通过, 12 失败   (x86_64 clang 21.1.8 + Eigen 3.4.0)
  → 主机/真机失败清单逐项完全一致（同一 12 项），与 OHOS 平台无关。

计数口径：
  上游 tests/*.m 文件 = 62
    注册进 CTest add_m_test = 57   →  ctest 中通过 46 / 失败 11
    未注册 = 5：add_unknown, global_structure, hugewhile, select, structure
  另 CTest 还含 2 个非 .m 套件：Testm2mmlTest（通过）、TestEigen3（失败）→ ctest 总计 59

12 项失败逐项技术原因（主机/真机一致）：
  [生成代码 _Complex 字面量被现代 C++ 拒绝，编译期]
    - test_complex   : tests/complex.cpp:21-22 `_Complex int -> double`（生成 `2i` 后缀）
    - test_call_diag : tests/call_diag.cpp:20  `_Complex int -> double`
    - test_call_eig  : tests/call_eig.cpp:25   `_Complex double -> double`
    - test_call_fft  : tests/call_fft.cpp:24   `_Complex double -> double`
  [Eigen 3.4 静态断言，编译期]
    - test_for, test_range, test_overrideconstantloop, TestEigen3
      Eigen/src/Core/PlainObjectBase.h:807/808 FLOATING_POINT_ARGUMENT_PASSED__INTEGER_WAS_EXPECTED
  [生成代码 C++ 重载二义，编译期]
    - test_unkwnow    : tests/unkwnow.cpp:20 `Unknown * Unknown` 重载二义
  [上游 cauchymc 解析限制，生成阶段]
    - test_setvalue   : `Error: at 2 : Conflicting type use for variable 'A'`
  [运行期数值断言失败]
    - test_ifelse     : `a is almost equal to -8` 断言失败
    - test_mul        : `L * U is almost equal to (4x4 期望矩阵)` 断言失败

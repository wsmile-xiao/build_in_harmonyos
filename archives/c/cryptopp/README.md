# Crypto++

Crypto++ 是一个免费的 C++ 加密算法库，包含大量加密方案的实现。

## 功能概述

- 对称加密：AES、DES、Blowfish 等
- 非对称加密：RSA、DSA、ECDSA 等
- 哈希函数：SHA、MD5、BLAKE2 等
- 消息认证码：HMAC、CMAC 等
- 数字签名和证书

## OHOS 适配

- 大型加密库（107.6MB 包大小）
- 编译进行中

## 依赖关系

- C++ 编译器

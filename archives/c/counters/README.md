# counters

`counters` is a header-only C++ utility library for performance-counter measurement and benchmark aggregation, adapted for OpenHarmony PC arm64.

- Version: 4.1.0
- Upstream: https://github.com/lemire/counters
- Conan package: `counters/4.1.0@ohpcd/stable`

The package exports the CMake target `Counters::counters` and the public headers under `counters/`.

## 描述

CRF++ 是一个条件随机场（Conditional Random Fields）工具包，用于序列数据的分割和标注。
包含两个主要工具：
- **crf_learn**: CRF 模型训练工具
- **crf_test**: CRF 模型测试/预测工具

以及共享库 libcrfpp 和静态库，可用于开发。

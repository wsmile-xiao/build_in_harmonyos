# connect (ssh-connect)

connect is a simple SOCKS4/5 and HTTP proxy tunnel tool for making
socket connections via proxy servers. It supports SOCKS4, SOCKS5,
and HTTP CONNECT proxy methods.

## What it does

- Makes TCP connections through SOCKS4/5 or HTTP proxy servers
- Useful for tunneling SSH or other protocols through proxy servers
- Can be used as a ProxyCommand for SSH

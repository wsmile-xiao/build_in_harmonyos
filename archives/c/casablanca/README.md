# casablanca (cpprestsdk)

Microsoft C++ REST SDK (casablanca) — cloud-based client-server communication in native code using a modern asynchronous C++ API design.

## 功能

- HTTP 客户端/服务端（基于 Boost.Asio）
- JSON 解析与生成
- WebSocket 客户端
- 异步任务框架（PPLX）
- URI 解析与构建
- OAuth 1.0/2.0 认证

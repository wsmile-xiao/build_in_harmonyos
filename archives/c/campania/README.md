# Campania

Campania is a font for Roman numeral analysis in music theory. It provides contextual substitutions for common figured-bass and chord-analysis notation.

## Package contents

- `fonts/Campania.otf` — OpenType font
- `fonts/Campania.ttf` — TrueType font
- `fonts/Campania.woff` — Web Open Font Format font
- `licenses/LICENSE` — SIL Open Font License 1.1
- `licenses/README.md` — upstream usage documentation

This is a pure data package. It has no native compilation step, runtime library dependency, or command-line executable.

# Cron

Vixie cron scheduler and crontab command for HarmonyOS PC.

## Version

- `3.0pl1`
- Upstream source: https://deb.debian.org/debian/pool/main/c/cron/cron_3.0pl1.orig.tar.gz
- Build system: GNU Make
- Package type: command-line tools

## Commands

- `cron`: cron daemon
- `crontab`: manage per-user crontab entries

The OHOS adaptation replaces unavailable legacy BSD signal/time interfaces with portable POSIX and standard C interfaces. See the version notes and test report for the complete test accounting.

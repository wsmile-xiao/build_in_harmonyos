# chamber

Chamber is a CLI tool for managing secrets in AWS Systems Manager Parameter Store and AWS Secrets Manager. It provides a simple way to store, retrieve, and manage secrets for applications.

## Features

- Store and retrieve secrets from AWS SSM Parameter Store and Secrets Manager
- Export secrets as environment variables
- Execute commands with secrets loaded into the environment
- Import secrets from JSON or YAML files
- View secret history and manage tags

# crunch

crunch 是一个密码字典生成工具，可以根据用户指定的条件和字符集生成各种组合的密码列表。生成的密码列表可以输出到屏幕、文件或其他程序。

## 主要功能

- 支持指定最小/最大长度生成密码
- 支持自定义字符集
- 支持使用内置 charset.lst 字符集文件（包含多种预定义字符集）
- 支持模式生成（-t 参数，使用占位符 @, ,, %, ^）
- 支持输出到文件或管道
- 支持字符集反转、重复等选项

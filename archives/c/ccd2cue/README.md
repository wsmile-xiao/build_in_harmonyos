# GNU ccd2cue

GNU ccd2cue converts CloneCD CCD sheets into CUE sheets.

- Homepage: https://www.gnu.org/software/ccd2cue/
- Source: https://ftp.gnu.org/gnu/ccd2cue/ccd2cue-0.5.tar.gz
- License: GPL-3.0-or-later
- Package: `ccd2cue/0.5`

The package provides the `ccd2cue` command. NLS and optional Doxygen
generation are disabled for the OpenHarmony PC build; GNU argp is supplied by
the published `argp-standalone/1.5.0` package.

# colord

System daemon for managing color devices. Provides libcolord and
libcolordprivate libraries and CLI tools for ICC color profile management.

- **Upstream**: https://github.com/hughsie/colord
- **License**: LGPL-2.1+
- **Build system**: Meson
- **Language**: C

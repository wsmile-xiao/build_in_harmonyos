# charls

C++ JPEG-LS 库实现 (ISO-14495-1 标准)。

JPEG-LS 是一种无损/近无损图像压缩标准，charls 提供了高性能的 C++ 实现。

- 官方仓库: https://github.com/team-charls/charls
- 许可证: BSD-3-Clause
- 构建系统: cmake

# cbonsai

cbonsai is a beautifully random bonsai tree generator for the terminal, written in C using ncurses and panel libraries.

## Description

cbonsai generates random bonsai tree ASCII art in the terminal. It supports live mode, infinite mode, and screensaver mode with customizable growth parameters.

## Features
- Live mode: show each step of tree growth
- Infinite mode: continuously generate new trees
- Screensaver mode
- Customizable leaves, branches, and life parameters
- Message attachment next to the tree

## Dependencies
- ncurses (with wide character support: ncursesw)
- panel (panelw)

## Versions
- 1.4.2 (built)

# cssc — GNU CSSC (Compatibly Structured Source Code)

GNU CSSC 是 GNU 项目的 SCCS 兼容源码版本控制系统 ("Compatibly
Structured Source Code")，提供 `sccs` 命令前端及 admin/get/delta/
prs/prt/unget/sact/cdc/rmdel/val/what/sccsdiff 等 SCCS 工具集，
用于管理 SCCS 格式的历史文件（s-file）。

- 上游: https://www.gnu.org/software/cssc/ (GNU Savannah)
- 许可: GPL-3.0-or-later
- 语言: C++ (autotools 构建，自带 gnulib + 捆绑 googletest 1.6)

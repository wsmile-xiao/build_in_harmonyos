# codonw

CodonW — codon usage analysis package（密码子使用分析命令行工具，GPL-2.0）。

主程序 `codonw`，另附 17 个 argv[0] 分析别名（rscu/cu/aau/raau/tidy/reader/
cutab/cutot/transl/bases/base3s/dinuc/cai/fop/gc3s/gc/cbi/enc），行为与上游
`links` 目标一致（HMDFS 硬链接受限，以副本交付，见 E079）。

- 上游: http://codonw.sourceforge.net （源码托管 SourceForge）
- 版本: 1.4.4（2005）
- 语言/构建: C / 上游手写 Makefile（无 install/check 目标）
- 类型: application（commands.json 已声明）

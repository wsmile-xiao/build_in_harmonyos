# Caddy

Fast, multi-platform web server with automatic HTTPS.

- Website: https://caddyserver.com
- Source: https://github.com/caddyserver/caddy
- License: Apache 2.0
- Build system: Go
- Category: web server

## Description

Caddy is an extensible server platform that uses TLS by default. It is production-ready and capable of serving all kinds of sites, including static sites, dynamic apps, APIs, and more.

# conftest

Declarative tests for Kubernetes. conftest helps you write tests against structured configuration data
using the Open Policy Agent (OPA) Rego query language.

## Overview

conftest is a testing tool for configuration files that uses policies written in Rego.
It can test Kubernetes configurations, Terraform plans, Docker files, and more.

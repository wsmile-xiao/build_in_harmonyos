# conducteo

`conducteo` 是依据 EN 10211 标准计算二维热桥的免费软件（GPLv3）。
本归档将官方 5.0.2 版本以 Qt6 模式适配到 HarmonyOS PC（aarch64），
产出可执行文件 `conducteo`（Qt6 Widgets GUI 应用）。

官方源：SourceForge（https://sourceforge.net/projects/conducteo/）

依赖：qtbase/6.11.1.1.1、eigen/3.4.1、tinyxml/2.6.2、dxflib/3.26.4、
libzip/1.11.4、zlib/1.3.1.1、nlohmann_json/3.12.0、uuid/2.40.1。

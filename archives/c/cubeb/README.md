# cubeb

Cross platform audio library by Mozilla.

## Description

cubeb is a cross-platform audio library developed by Mozilla. It provides a
unified C API for audio playback and recording across multiple backends
(PulseAudio, ALSA, JACK, CoreAudio, WASAPI, OpenSL, etc.).

# cppp-reiconv

A character set conversion library based on GNU LIBICONV (C++ Plus Project).

- 仓库: https://github.com/cppp-project/cppp-reiconv
- 版本: 3.0.0 (LGPL-3.0)
- 构建系统: CMake（需同组织 build-aux + cppp-platform 两个辅助仓库，见配方 conandata.yml）
- 适配平台: HarmonyOS PC (OHOS aarch64, clang 15)
- 详情: 见 [3.0.0/notes.md](3.0.0/notes.md) 与 [3.0.0/reports/](3.0.0/reports/)

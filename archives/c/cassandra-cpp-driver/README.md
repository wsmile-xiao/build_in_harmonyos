# cassandra-cpp-driver

## 简介
DataStax C/C++ driver for Apache Cassandra，用于连接 Cassandra 数据库的客户端库。

## OHOS 适配
- CMake 4.x 要求最低版本 3.5
- 需设置 LIBUV_ROOT_DIR, OPENSSL_ROOT_DIR, ZLIB_ROOT_DIR 环境变量

## 依赖
- libuv >= 1.52.1
- openssl >= 3.0.13
- zlib >= 1.3.1

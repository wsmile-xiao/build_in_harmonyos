# GNU Bool

GNU Bool is a command-line utility for finding files that match boolean expressions. It supports AND, OR, NOT and NEAR expressions, text/context matching, HTML input, and standard output/status controls.

## Upstream

- Homepage: https://www.gnu.org/software/bool/
- Source: https://ftp.gnu.org/gnu/bool/bool-0.2.2.tar.xz
- License: GPL-2.0-or-later

## Available version

- `0.2.2`: `bool/0.2.2`

The package provides the `bool` executable and its `bool(1)` manual page. The version recipe includes the upstream test suite and a consumer test that exercises the installed executable.

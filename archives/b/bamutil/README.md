# bamutil

Utilities for working on SAM/BAM files

## 官方信息

- **主页**: https://github.com/statgen/bamUtil
- **许可证**: GPL-3.0
- **分类**: Bioinformatics / Genomics

## 简介

bamutil 是一套用于操作 SAM/BAM 文件的工具集，包括：
- 转换、验证、过滤、合并 BAM 文件
- 去重、重校准
- 统计分析
- BAM 转 FastQ

由 University of Michigan School of Public Health 的 Center for Statistical Genetics 开发。

# bsdiff — 二进制补丁工具

## 简介

bsdiff 和 bspatch 是用于生成和应用二进制文件补丁的工具。它们使用来自 bzip2 的差异压缩算法，生成的补丁文件通常非常小，尤其适合对大文件进行局部修改的场景。

## 功能说明

- **bsdiff**: 比较两个二进制文件，生成一个补丁文件。补丁文件使用 bzip2 压缩差异部分，体积通常远小于原始文件差异。
- **bspatch**: 将 bsdiff 生成的补丁应用到原始文件，恢复出修改后的文件。

## 使用方法

```bash
# 生成补丁
bsdiff <旧文件> <新文件> <补丁文件>

# 应用补丁
bspatch <旧文件> <新文件> <补丁文件>
```

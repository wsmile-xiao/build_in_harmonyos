# blinker

## 简介

blinker 是一个轻量、快速的 Python 信号分发库，支持对象间和广播式事件通知。

## 版本与平台

- 版本：1.9.0
- 平台：OpenHarmony PC aarch64
- 类型：纯 Python 库
- Python 要求：3.9 及以上

## 依赖

blinker 1.9.0 没有第三方运行时依赖，仅依赖 Python 运行环境。

## 验证

适配保留并执行上游全部 25 个 pytest 测试，结果为 25/25 通过。Conan 配方验证和 W3 本地 CI 模拟均已通过。

# busted

## Overview

Busted is a Lua unit testing framework. This package provides Busted `2.2.0-1`
as the Lua test runner dependency for Vusted and the nvim-lspconfig Path B
validation chain.

## Package Layout

- Lua modules: `$PREFIX/share/lua/5.4/busted/` and `$PREFIX/share/lua/5.4/busted.lua`
- CLI entrypoint: `$PREFIX/bin/busted`
- License: `$PREFIX/licenses/LICENSE`

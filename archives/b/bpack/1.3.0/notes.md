# bpack 1.3.0 Adaptation Notes

## Build Environment

- Build system: pip (Python pure package, setuptools)
- Build date: 2026-09-13
- Compiler: clang/clang++ (not used for pure Python)
- Status: built (pending device preflight)

## Build Steps

1. Download PyPI sdist `bpack-1.3.0.tar.gz` (sha256 `fa609236...5a6f5825`).
2. Copy source tree to `build_folder/bpack-stage` (excluding egg-info,
   docs, examples).
3. Run upstream suite: `python3 -m pytest bpack/tests -q` in `build()`;
   emit `HMBS_UPSTREAM_TEST_RESULT` JSON parsed from pytest summary.
4. Copy `bpack/` package dir to
   `package_folder/lib/python3.12/site-packages/bpack`.
5. Consumer test `test_bpack.py` runs descriptor + calcsize + struct
   decode/encode roundtrip; emits `HMBS_TEST_PACKAGE_RESULT`.

# boost1.84-timer

Boost.Timer 组件拆分包（Boost 1.84.0），为 boost1.84 系列拆分任务的一部分。

## 说明

- 仅交付 Boost.Timer 编译库（libboost_timer.a）与完整 boost 头文件树
- 底稿：`archives/b/boost/1.84.0/` 元包配方（手动编译，绕过 OHOS 不兼容的 b2 构建系统）
- 上游：https://www.boost.org/ （Boost.Timer 文档：https://www.boost.org/doc/libs/1_84_0/libs/timer/）

## 版本

- 1.84.0：首个适配版本，认领人 2404_87638649，平台分支 feat/boost1.84-timer-1.84.0

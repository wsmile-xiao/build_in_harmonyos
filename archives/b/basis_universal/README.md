# basis_universal

## 软件简介

Basis Universal v2.1 是一个开源的超压缩 LDR/HDR GPU 纹理转码系统，支持两种中间文件格式：.KTX2（Khronos 集团的开源标准）和 .basis 文件格式。

## 功能特点

- 支持 7 种压缩模式：ETC1S、UASTC LDR 4x4、UASTC HDR 4x4、ASTC HDR 6x6、UASTC HDR 6x6、ASTC LDR 4x4-12x12、XUASTC LDR 4x4-12x12
- 可快速转码到几乎所有 GPU 纹理格式
- 支持 WebAssembly 编译，可用于浏览器
- 支持多线程和单线程 WASM WASI 构建

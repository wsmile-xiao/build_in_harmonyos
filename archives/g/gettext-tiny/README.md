# gettext-tiny

轻量 gettext 替代（sabotage-linux），提供 msgfmt/msgmerge/xgettext/autopoint CLI 工具
与静态 libintl.a（gettext/dgettext/textdomain/bindtextdomain 等公开 API）。

- 上游: https://github.com/sabotage-linux/gettext-tiny
- 版本: 0.3.3
- 构建: 纯 Makefile（无 configure），R26 仅静态
- 依赖: 无
- 详见 archives/g/gettext-tiny/0.3.3/notes.md

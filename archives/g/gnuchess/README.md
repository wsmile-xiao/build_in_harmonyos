# gnuchess — GNU Chess 国际象棋引擎

GNU Chess 6.2.9：Console 棋盘对弈引擎，附 gnuchessu（UCI 协议）与
gnuchessx（XBoard 协议）包装脚本。引擎核心为 C++，搜索基于 alpha-beta。

- 上游: https://ftp.gnu.org/gnu/chess/gnuchess-6.2.9.tar.gz
- 许可: GPL-3.0-or-later
- 语言: C++（约 82 个源文件）
- 本归档: 6.2.9 适配 OHOS aarch64（详见 6.2.9/notes.md 与 test_package/）

# gmime

GMime is a C/C++ library for parsing and creating MIME messages and RFC822/MIME message formats.

## 鸿蒙适配

- 构建系统: autotools
- 编译器: clang / clang++
- 依赖: glib 2.84.0
- 编译选项: `CC=clang CXX=clang++ --prefix=$PREFIX`

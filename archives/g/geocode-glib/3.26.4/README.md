# geocode-glib 3.26.4 (libsoup3 flavour)

geocode-glib is a GNOME helper library for geocoding and reverse
geocoding, served by Nominatim (OpenStreetMap). This archive carries
the **libsoup3 flavour** (`soup2=false` at build time): library
`libgeocode-glib-2.so`, pkg-config name `geocode-glib-2.0` — the
exact dependency name libgweather 4.6.0 requires.

- Upstream: https://gitlab.gnome.org/GNOME/geocode-glib
- License: LGPL-2.1-or-later
- Imported as a dependency-first package (R36) for libgweather 4.6.0
  (contest card #14281).

# glbinding

C++ binding for the OpenGL API.

## 基本信息

- 主页: https://github.com/cginternals/glbinding
- 许可证: MIT
- 语言: C/C++
- 构建系统: CMake

## 描述

glbinding 是一个 C++ OpenGL API 绑定库，使用 gl.xml 规范生成。它提供了类型安全的 OpenGL 函数绑定，支持所有 OpenGL 版本（GL 1.0 到 GL 4.6）和扩展。

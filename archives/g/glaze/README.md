# Glaze

> 高性能 C++ JSON 库，支持编译时反射

## 简介

Glaze 是一个极致性能的 C++ JSON 库，利用 C++20 的编译时反射特性实现零开销的序列化/反序列化。

## OHOS 适配

- 构建系统：CMake
- Header-only 库，主要提供头文件
- 需要 C++20 编译器支持

## 功能特性

- 编译时反射，无需运行时开销
- 极致的 JSON 序列化/反序列化性能
- 支持 STL 容器和自定义类型
- Header-only，易于集成

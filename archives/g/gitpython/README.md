# GitPython

GitPython is a pure-Python library for interacting with Git repositories —
object model (Repo/Commit/Tree/Blob/Index/Refs) plus a wrapper layer around
the `git` command line.

- Upstream: https://github.com/gitpython-developers/GitPython
- License: BSD-3-Clause
- Conan dependency: `gitdb/4.0.12` (which requires `smmap/5.0.3`)
- Runtime: needs a host `git` executable (>= 2.2)

## Versions

- 3.1.57 — built (2026-09-19), pure Python packaging (`pip install --target --no-deps`)

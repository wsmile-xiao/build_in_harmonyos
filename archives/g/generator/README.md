# generator

`generator` is a single-header C++20 coroutine generator adapted for OpenHarmony PC arm64.

- Version: 0.4.0
- Upstream: https://github.com/TartanLlama/generator
- Conan package: `generator/0.4.0@ohpcd/stable`

The package exports `tl::generator` from `find_package(generator CONFIG REQUIRED)`.

# qqc2-breeze-style

QQC2 Breeze Style — the KDE Plasma QML style for Qt Quick Controls 2,
implementing the KDE Visual Design Group's Breeze vision in pure QML and
Kirigami.

Applications do not link this package directly; they select the style at
runtime with `QT_QUICK_CONTROLS_STYLE=org.kde.breeze` (or
`QQuickStyle::setStyle("org.kde.breeze")`).

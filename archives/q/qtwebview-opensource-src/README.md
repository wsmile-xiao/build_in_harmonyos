# Qt5 WebView

Qt WebView module for Qt5 5.15.15, providing QWebView component for displaying web content in Qt applications.

## Build Notes
- Requires: qt5-qtbase, qt5-qtdeclarative
- Platform: HarmonyOS (aarch64)
- Build system: qmake
- Web backend: null backend (no Qt WebEngine available; null backend is upstream's built-in fallback)
- No source modifications required for HarmonyOS

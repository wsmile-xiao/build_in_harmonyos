# Qt5 3D

Qt 3D module for Qt5 5.15.2, providing 3D rendering, input, logic, animation, and extras.

## Build Notes
- Requires: qt5-qtbase, qt5-qtdeclarative
- Platform: HarmonyOS (aarch64)
- Build system: qmake
- No source modifications required for HarmonyOS
- Produces 12 shared libraries including 3DCore, 3DRender, 3DInput, 3DLogic, 3DAnimation, 3DExtras, and Quick variants

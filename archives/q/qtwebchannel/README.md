# qtwebchannel

Qt WebChannel enables peer-to-peer communication between a C++/QML application
and an HTML/JavaScript client, part of Qt 6.

## Package

- Upstream: https://doc.qt.io/qt-6/qtwebchannel-index.html
- Source: https://download.qt.io/official_releases/qt/6.11/6.11.1/submodules/
- Conan reference: `qtwebchannel/6.11.1`
- Build system: CMake
- Runtime dependencies: `qtbase/6.11.1`, `qtdeclarative/6.11.1` (Quick/QuickTest optional components)
- Required by: `qtwebengine` (WebChannel API hard dependency)

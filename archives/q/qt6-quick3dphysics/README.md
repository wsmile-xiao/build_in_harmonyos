# Qt6 Quick3DPhysics

Qt6 Quick3DPhysics module for HarmonyOS PC (arm64).

QtQuick3DPhysics provides physics simulation capabilities for Qt Quick 3D applications.
It is part of the Qt 6.8.2 release and depends on qtbase, qtdeclarative, qtquick3d,
and qtshadertools.

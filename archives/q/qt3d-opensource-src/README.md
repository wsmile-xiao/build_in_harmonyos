# qt3d-opensource-src

Qt 3D module for Qt5. Provides C++ and QML APIs for 3D graphics, including:
- 3D Core (aspects, entities, transforms)
- 3D Render (materials, meshes, frame graph)
- 3D Input (keyboard, mouse, controller)
- 3D Logic
- 3D Animation
- 3D Extras (geometries, materials, text)
- 3D Quick (QML bindings)
- 3D Quick Render, Input, Animation, Extras, Scene2D

Bundled with assimp for 3D model loading.

Homepage: https://wiki.qt.io/Qt3D

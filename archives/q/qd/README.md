# qd

`qd` is the QD library for double-double (`dd_real`, ~32 significant digits) and
quad-double (`qd_real`, ~64 significant digits) floating-point arithmetic, with a
C interface (`c_dd`/`c_qd`) and installed `qd-config`/`qd.pc` metadata.

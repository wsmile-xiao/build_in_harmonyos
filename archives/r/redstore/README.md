# redstore

Lightweight RDF triplestore powered by Redland (C, Autotools).

- 上游: https://www.aelius.com/njh/redstore/ / https://github.com/njh/redstore
- 版本: 0.5.4
- 构建: Autotools (./configure + make), 二进制 redstore
- 依赖: raptor2, rasqal, redland, check (单元测试框架)
- 测试: make check 共 12 项 (6 redhttp + 1 unit + 5 perl 集成)

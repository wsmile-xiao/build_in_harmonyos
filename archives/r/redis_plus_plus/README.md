# redis_plus_plus

redis-plus-plus 是一个基于 hiredis 的 C++ Redis 客户端库，由 sewenew 开发。

## 基本信息

- **项目主页**: https://github.com/sewenew/redis-plus-plus
- **许可证**: Apache-2.0
- **语言**: C++ (C++11/14/17/20)
- **构建系统**: CMake
- **依赖**: hiredis

## 功能特性

- 支持 Redis 的所有命令
- 支持连接池
- 支持 Redis Cluster
- 支持 Redis Sentinel
- 支持 Pipeline 和 Transaction
- 支持 Pub/Sub
- 可选 TLS 支持

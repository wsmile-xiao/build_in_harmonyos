# rlwrap

rlwrap is a 'readline wrapper' that uses the GNU readline library to allow the editing of keyboard input for any other command.

## Description
rlwrap adds readline support to interactive commands that lack it. It provides:
- Command history
- Line editing
- Completion support

## Version
Current version: 0.47.1

## Dependencies
- readline (>= 8.0)
- ncurses

## Build
This package uses autotools build system.

# ren

ren is a file renaming utility that can rename multiple files in a directory
according to search and replacement patterns, similar to VMS RENAME but more
flexible. It checks for name collisions and handles rename chains gracefully.

Originally written by Vladimir Lanin in 1988 and submitted to comp.sources.unix.
This version (1.0) was adapted for Linux by Rob Schipper in 1997.

## Features

- Wildcard-based pattern matching and replacement
- Collision detection for renamed files
- Rename chain handling
- Multiple deletion modes (ask, quiet, no-delete, abort)
- Verbose mode

# rig - 随机身份生成器

## 软件简介

rig 是一个生成假身份数据的命令行工具，可用于测试、演示或隐私保护场景。它生成包含姓名、地址、城市、州、邮编和电话号码的完整身份信息。

**功能特点**：
- 生成随机美国式身份信息
- 支持按性别筛选（-f 女性，-m 男性）
- 支持批量生成（-c num）
- 支持自定义数据目录
- 数据来源于美国人口普查前 1000 名字

## 使用方法

```bash
# 生成 1 个随机身份
rig

# 生成 5 个随机身份
rig -c 5

# 生成 3 个女性身份
rig -f -c 3

# 生成 3 个男性身份
rig -m -c 3

# 指定数据目录
rig -d /path/to/data -c 1
```

## 输出格式

每个身份包含 4 行：
```
姓名
街道地址
城市,州 邮编
电话号码 (xxx-xxxx)
```

## 数据文件

rig 需要 5 个数据索引文件：
- `fnames.idx` - 女性名字库
- `lnames.idx` - 姓氏库
- `mnames.idx` - 男性名字库
- `locdata.idx` - 城市州邮编库
- `street.idx` - 街道名称库

## 注意事项

1. rig 不支持 `--version` 参数（设计如此）
2. 数据文件路径硬编码在二进制中，安装后需保持路径一致
3. 程序依赖 `/dev/urandom` 生成随机数，OpenHarmony 已支持

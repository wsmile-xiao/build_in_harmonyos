# redict

Redict is a distributed, in-memory key-value database (key-value store) with optional durability. It is the LGPLv3-licensed fork of Redis, the popular open source in-memory data structure store.

Redict provides the same functionality as Redis: strings, hashes, lists, sets, sorted sets, bitmaps, HyperLogLogs, geospatial indexes, and streams. It can be used as a database, cache, and message broker.

## Available Versions

- 7.3.0 (based on Redis 7.2.4, LGPLv3)

# retawq

retawq is an interactive, multi-threaded web browser for text terminals on Unix-like operating systems. Written in C, it is fast, small, and configurable.

- **Homepage**: https://retawq.sourceforge.net/
- **License**: GPL-2.0-or-later
- **Language**: C
- **Build system**: Classical Makefile (custom configure script by itchconfig)

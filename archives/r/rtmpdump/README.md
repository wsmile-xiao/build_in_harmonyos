# rtmpdump

RTMPDump is a toolkit for RTMP streams.

## Description

Tool for downloading RTMP streaming media.

## Features

- rtmpdump: Download RTMP streams
- rtmpgw: RTMP gateway
- rtmpsrv: RTMP server
- rtmpsuck: RTMP sucking tool
- librtmp: Library for RTMP protocol

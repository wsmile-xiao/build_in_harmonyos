# rtptools

RTP 数据和 RTCP 控制流量工具集

## 描述

rtptools 是一组用于处理 RTP（实时传输协议）数据和 RTCP（实时传输控制协议）流量的工具。
包含 RTP 数据包的接收、发送、回放和转发功能。

## 工具列表

- **rtpdump** — 接收 RTP 数据并打印或保存（支持 hex/ascii/rtcp/short/payload/dump/header 格式）
- **rtpplay** — 从文件回放 RTP 数据
- **rtpsend** — 从文件发送 RTP 数据
- **rtptrans** — 在单播和多播之间转发 RTP 数据
- **multidump** — 多播 RTP 转储脚本
- **multiplay** — 多播 RTP 回放脚本

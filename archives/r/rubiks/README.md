# rubiks

`rubiks` 汇总三套 Rubik's Cube 求解实现：Dik Winter 的迭代式求解器（`dikcube`、`size222`）、
Mark Reid 的最优解搜索器（`optimal`）、Eric Dietz 的协议式求解器（`cubex`、`cu2`、`mcube`）。
上游以裸 Makefile 分发，无 configure/autotools。

# rtaudio

A set of C++ classes that provide a common API for realtime audio input/output across Linux (ALSA, JACK, OSS), Macintosh OS X (CoreAudio and JACK), and Windows (DirectSound, ASIO, WASAPI) operating systems.

- **Website**: http://www.music.mcgill.ca/~gary/rtaudio/
- **License**: MIT-like (see RtAudio.h for details)
- **Category**: audio/multimedia

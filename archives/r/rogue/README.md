# rogue

## 软件概述

**rogue** 是经典的地下城探索视频游戏（Dungeon crawling video game），是最早的 roguelike 游戏之一，开创了程序生成地牢和永久死亡的游戏模式。

- **软件名称**: rogue
- **最新版本**: 5.4.4
- **描述**: 经典地下城探索游戏，开创 roguelike 游戏类型的鼻祖
- **主页**: https://github.com/Davidslv/rogue

## 主要功能

- **程序生成地牢**: 每次游戏随机生成独特的地牢布局
- **回合制战斗**: 策略性战斗系统
- **物品系统**: 武器、护甲、药水、卷轴等多种道具
- **永久死亡**: 角色死亡后需要重新开始
- **可视化界面**: 基于 ncurses 的终端图形界面

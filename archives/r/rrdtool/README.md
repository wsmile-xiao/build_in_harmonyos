上游 <https://github.com/oetiker/rrdtool-1.x>（tag v1.9.0 官方 tarball）。

- 版本目录：`1.9.0/`（配方、补丁、消费者测试、报告）
- 交付物：`bin/rrdtool`（多路命令）+ `bin/rrdupdate` `bin/rrdcached` `bin/rrdcgi` + `lib/librrd.so`
- 适配要点见软件级 `manifest.yaml` 的 `ohos_adaptation` 与版本级 `notes.md`

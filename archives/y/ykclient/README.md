# ykclient

Yubico YubiKey OTP validation client library (C), adapted for OpenHarmony PC.

- Upstream: https://github.com/Yubico/yubico-c-client
- Version: 2.15
- Current package: `archives/y/ykclient/2.15`
- Supported OpenHarmony architecture: armv8
- Also installs the `ykclient` command-line tool (see `commands.json`).

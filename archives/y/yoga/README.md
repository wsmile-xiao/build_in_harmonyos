# Yoga

Yoga is an embeddable flexbox layout engine targeting web standards, developed by Meta (Facebook).

## Homepage
https://github.com/facebook/yoga

## License
MIT

## Description
Yoga is a cross-platform layout engine enabling and implementing flexbox. It is designed to be highly optimized for performance and small binary size. Yoga is used in production by React Native and many other frameworks.

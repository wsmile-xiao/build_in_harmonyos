# wchartype

`wchartype` is a pure-Python module for classifying Asian and full-width Unicode characters.

The Conan package installs `wchartype.py` under `lib/python` and provides that location through `PYTHONPATH`. The upstream PyPI metadata declares MIT and no runtime dependencies. Its source ZIP contains no standalone license text; package metadata is retained as documentation.

Upstream project: http://ginstrom.com/code/wchartype.html

# wasmtime

Wasmtime 是一个高效、安全的 WebAssembly 运行时，由 Bytecode Alliance 开发。

## 描述

wasmtime 是一个独立运行的 WebAssembly (WASM) 执行引擎，支持：
- WASI (WebAssembly System Interface)
- 组件模型
- 多种编译策略（Cranelift、Winch）
- 高性能 JIT 编译

## 构建系统

- Cargo (Rust 项目)
- 无传统的 configure/make

## 编译依赖

- rust >= 1.95.0
- cmake >= 4.1.2
- clang >= 15.0.4

## 已编译版本

# wireguard-go

WireGuard userspace implementation in Go. This is the official WireGuard daemon
that runs in userspace on platforms where kernel WireGuard is not available.

- Website: https://www.wireguard.com/
- Source: https://github.com/WireGuard/wireguard-go

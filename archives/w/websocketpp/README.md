# websocketpp

WebSocket++ is a header-only C++ library that implements RFC 6455 (The WebSocket Protocol).

## Description

websocketpp (WebSocket++) is a C++ library that can be used to implement WebSocket functionality. It supports:
- WebSocket protocol versions hybi-00, hybi-07, hybi-08, hybi-13
- Client and server roles
- TLS (wss://) via OpenSSL
- Asio (boost::asio or standalone) transport
- Permessage-deflate extension
- Header-only design (no compiled library needed)

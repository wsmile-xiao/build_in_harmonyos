# xorriso

GNU xorriso - ISO 9660 RockRidge 文件系统镜像创建和操作工具

## 软件简介

xorriso 是 GNU 项目的一部分，是一个功能强大的命令行工具，用于创建、操作和提取 ISO 9660 文件系统镜像，支持 RockRidge 扩展。

## 主要功能

- 创建 ISO 9660 文件系统镜像
- 支持从本地文件系统创建 ISO
- 支持提取 ISO 镜像内容
- 支持 RockRidge 扩展（保留 Unix 文件属性）
- 支持多种压缩格式
- 支持引导镜像创建

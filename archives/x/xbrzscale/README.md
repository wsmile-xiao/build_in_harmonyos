# xbrzscale

基于 xBRZ（"Scale by rules"）算法的图像放大命令行工具，附带可链接的
`libxbrzscale` 静态库。

- 上游：https://github.com/atheros/xbrzscale
- 版本：1.8（上游提交 `#11 Updated xbrz to 1.8`）
- 许可证：GPL-3.0-only
- 产物：`bin/xbrzscale`、`lib/libxbrzscale.a`、`include/*.h`

用法：`xbrzscale <scale_factor 2-6> <input_image> <output_image.png>`

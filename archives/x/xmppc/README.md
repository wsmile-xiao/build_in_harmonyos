# xmppc

`xmppc` is a C command-line XMPP client maintained by Anoxinon e.V. It uses libstrophe for XMPP, GLib for application support, and GPGME for OpenPGP operations.

- Upstream: https://codeberg.org/Anoxinon_e.V./xmppc
- Adapted version: 0.1.0
- Conan reference: `xmppc/0.1.0`
- Build system: GNU Autotools
- Target: HarmonyOS PC AArch64
- License: GPL-3.0-or-later

The package provides the `xmppc` executable. See [`commands.json`](commands.json) for command metadata and [`0.1.0/notes.md`](0.1.0/notes.md) for adaptation and verification details.

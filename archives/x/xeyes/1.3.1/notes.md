# xeyes 1.3.1 适配笔记

## 编译环境
- 构建系统: autotools (configure + make)
- 编译日期: 2026-08-19
- 编译器: clang/clang++（OHOS 系统自带）
- 状态: built（PR 阶段，未 upload）

## 编译步骤

```bash
# conan create 由 CI/hmbs 在 HarmonyOS aarch64 真机执行（profile: ohos-aarch64）
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

1. source(): 从 X.Org 官方发布归档下载 xeyes-1.3.1.tar.gz（sha256 已校验）
2. generate(): AutotoolsToolchain
   - `--x-includes=/storage/Users/currentUser/usr/local/include` / `--x-libraries=.../lib`：指向编译环境预编译 X11 开发栈（同 xterm/410 适配方式）
   - `--build=aarch64-unknown-linux-gnu --host=aarch64-unknown-linux-ohos`：交叉编译模式跳过运行时检测（E007），config.sub 已原生支持 ohos 三元组，无需补丁
   - `PKG_CONFIG_PATH=.../lib/pkgconfig`：PKG_CHECK_MODULES 需要 xi/x11/xt/xext/xmu/xproto 的 .pc 文件
   - xrender/present 按 .pc 探测启用/关闭（configure 的 try 语义下缺包会硬失败）
   - extra_ldflags 追加 -L 与 rpath，保证 configure 测试程序可链接 X11 库
3. build(): ./configure && make -j1
4. package(): make install → bin/xeyes + man/xeyes.1

# xcb-util-keysyms

XCB key symbols convenience library — maps X11 keycodes to keysyms and
provides keyboard-related lookup helpers (keypad/function/cursor/modifier
classification) on top of XCB.

## Versions

| Version | Status | Notes |
|---------|--------|-------|
| 0.4.1  | published | Conan recipe with autotools build, OHOS platform adaptation |

## Dependencies

- libxcb/1.17.0
- xorgproto/2025.1 (xproto.pc)

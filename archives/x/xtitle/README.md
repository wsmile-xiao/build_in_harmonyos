# xtitle

Stephen Kinzler's `xtitle` and `xtctl` POSIX shell tools for xterm-compatible terminal control sequences. The Conan package installs both unmodified upstream scripts in `bin/` and the upstream manual page. Source release: https://kinzler.com/me/xtitle/xtitle-1.0.4.tgz; Debian packaging repository: https://salsa.debian.org/debian/xtitle.git.

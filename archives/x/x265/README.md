# x265 - HEVC Encoder

## Description

x265 is an open source HEVC (H.265) encoder. It offers the highest quality video compression available today.

## Version

- Latest compiled version: 4.2

## Build Information

- Build system: CMake
- Compiler: Clang 15.0.4
- Platform: OpenHarmony (aarch64)

## Dependencies

None (standalone library)

## Usage

```bash
x265 --help
```

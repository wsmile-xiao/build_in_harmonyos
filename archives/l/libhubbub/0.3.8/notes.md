## 编译步骤

1. `source .build-context-libhubbub-0.3.8 && cd $BUILD_SRC_DIR`
2. 替换顶层 Makefile 为 standalone Makefile（原 Makefile include
   `$(NSSHARED)/makefiles/Makefile.tools`，本平台无 netsurf-buildsystem）
3. 生成中间文件：`perl build/make-entities.pl` → `src/tokeniser/entities.inc`；
   `gperf src/treebuilder/element-type.gperf` + sed → `src/treebuilder/autogenerated-element-type.c`
4. `make CC=clang AR=llvm-ar RANLIB=llvm-ranlib -j1` 生成 `libhubbub.a` + `libhubbub.pc`
5. `make install PREFIX=$DEFAULT_PREFIX DESTDIR=$TEST_PREFIX` 验证安装
6. `make test` 编译并驱动上游全部可用 test/*.c（7 个测试程序，1721 断言全过）
7. `conan-init libhubbub 0.3.8` 生成配方并手工修正（autotools 模板 → make 模板）
8. `conan-verify libhubbub 0.3.8` — G1/G2/G3/G4 全部 PASS

## 遇到的问题与解决方案

| # | 问题 | 根因 | 解决方案 |
|---|------|------|----------|
| 1 | 原始 Makefile `include $(NSSHARED)/makefiles/Makefile.tools` 找不到 | NetSurf 组件库使用自有 NSSHARED 构建系统，本平台无 netsurf-buildsystem | 替换为 standalone Makefile（libparserutils 0.2.5 / libwapcaplet 0.4.3 同款方案），保留原编译标志，去除 -Werror 兼容 clang 15 |
| 2 | `src/tokeniser/entities.inc` 不存在 | 由 `build/make-entities.pl` 从 `build/Entities` 生成，不在源码包内 | Makefile 增加生成规则：`perl build/make-entities.pl` |
| 3 | `src/treebuilder/autogenerated-element-type.c` 不存在 | 由 `gperf element-type.gperf` 生成，再 sed `const → static` | Makefile 增加 gperf 生成规则 |
| 4 | 编译期需 libparserutils 头文件 | `src/` 引用 `<parserutils/charset/mibenum.h>`、`<parserutils/input/inputstream.h>` 等 | Makefile 增加 `PARSERUTILS_CFLAGS ?= -I$(PREFIX)/include`，conan 构建时从依赖 cpp_info 注入 |
| 5 | 测试程序链接需 `-lparserutils` | 静态库 libhubbub.a 引用 parserutils 符号 | Makefile 增加 `PARSERUTILS_LIBS ?= -L$(PREFIX)/lib -lparserutils`，test 目标链接时使用 |
| 6 | `make -j2` jobserver mkfifo `Operation not permitted` | HMDFS 禁 FIFO（E074） | make 自动退化为串行；conanfile 固定 `-j1`（R9） |
| 7 | 上游 `make test` 依赖 testrunner.pl（NSTESTTOOLS）+ json-c | 属于 netsurf-buildsystem；tokeniser2/tokeniser3 测试依赖 json-c | standalone Makefile 直接编译上游 test/*.c 测试程序并逐项驱动；tokeniser2/tokeniser3 因 json-c 不可用跳过（如实记录，其余 7 个程序全过） |
| 8 | conan-init 生成的配方是 autotools 模板（configure+make），与 standalone Makefile 不符 | 模板按 BUILD_SYSTEM=autotools 生成 | 手工改写为 libparserutils 同款 make 模板（CC/AR/RANLIB 从 conf 读取，R33），build() 注入 PARSERUTILS_CFLAGS/LIBS |

## 注意事项

- NetSurf 组件库（libparserutils/libwapcaplet/libhubbub 等）均需替换为 standalone Makefile
- 静态库无需 ELF 签名与 RPATH 处理（E018）
- 本包依赖 libparserutils，conanfile `requirements()` 声明 `libparserutils/0.2.5`，
  `package_info()` 用 `cpp_info.requires` 传递链接依赖，test_package 链接时自动带上
- conandata.yml URL 为官方源，sha256 与 tarball 一致（R39）
- conan 构建时依赖 libparserutils 源码需在 conan 下载缓存（已用本地 tarball 预置，
  禁网约束下避免再次网络下载）

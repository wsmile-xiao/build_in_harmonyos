# libsvg

`libsvg` is a C library for parsing SVG (Scalable Vector Graphics) files,
developed as part of the cairographics.org SVG ecosystem. It parses SVG
documents and feeds them to a caller-supplied render engine via callbacks.
It is a prerequisite of `libsvg-cairo`.

## 变更说明

新增 Lua 5.1.5 的 Conan 2.x 静态库配方、消费者测试和测试清单。配方使用 Conan profile 中的 clang 编译上游 C 源码，打包头文件、`liblua.a`、man page 和许可证，不提交上游源码副本或预编译产物。

目标机的系统 `/tmp` 不可写，Lua 5.1.5 原生 `os.tmpname()` 和 `io.tmpfile()` 因此失败。本 PR 包含两个通用 POSIX 补丁：临时文件名从 `TMPDIR` 选择目录；匿名临时文件通过 `mkstemp`、`unlink` 和 `fdopen("w+b")` 创建。补丁没有引入 `__OHOS__` 宏，也没有关闭或跳过产品功能。

## 平台豁免

1. `big.lua:11` 假设 4328521728 字节字符串连接应超过 `MAX_SIZET`。该假设适用于 32 位环境；目标机 `size_t` 为 64 位且有足够内存，Lua 按原生边界检查成功完成连接。诊断输出：`ARCH_BITS=64`、`CONCAT_OK bytes=4328521728 GiB=4.03125`。
2. `files.lua:245` 假设普通文件的行缓冲写入在换行后，无显式 `fflush` 即可被另一 FILE 流读取。HarmonyOS libc 的缓冲可见时机不同；显式刷新或关闭后的数据正确，同文件其余 I/O 测试通过。

豁免依据为 `docs/TEST_QUALITY_SPEC.md §3.3`。四个官方动态 C 测试模块已在目标机编译、签名并通过加载探针；只排除上述两个断言后，完整套件其余 20 个测试组到达 `final OK !!!`。

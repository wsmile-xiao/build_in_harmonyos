# libsigc++

libsigc++ 是一个 C++ 信号/槽库，实现了类型安全的回调机制。

## 描述

libsigc++ 是一个轻量级的 C++ 信号和槽实现，提供了类型安全的回调机制。它是 GTKmm 和其他 GNOME C++ 绑定的核心依赖库。

## 版本

- **2.10.8** (2026-05-21) - 当前版本

## 构建系统

- **meson** - 使用 meson 构建系统

## 依赖

无外部依赖（header-only 库的核心部分）

## 安装产物

- 头文件：`include/sigc++-2.0/`
- 库文件：`lib/libsigc-2.0.so`
- pkg-config 文件：`lib/pkgconfig/sigc++-2.0.pc`

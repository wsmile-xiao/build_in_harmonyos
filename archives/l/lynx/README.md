# lynx

## 简介

Lynx是一个全功能的文本模式Web浏览器，适用于运行cursor-addressable、character-cell显示设备的用户，如vt100终端、vt100模拟器或其他character-cell显示设备。

## 版本信息

- 当前版本: 2.9.2
- 发布日期: 2024-05-31
- 许可证: GPLv2

## 编译信息

- 构建系统: autotools
- 编译器: gcc (clang 15.0.4)
- 目标平台: HarmonyOS aarch64
- 依赖: ncurses 6.4

## 使用方法

```bash
lynx [URL]
lynx --version
```

## 配置文件

- lynx.cfg: 主配置文件
- lynx.lss: 样式文件

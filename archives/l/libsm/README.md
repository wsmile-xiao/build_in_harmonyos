# libSM

X Session Management Library (libSM) - X11 Session Management protocol library.

## Description

libSM provides the client and server-side C libraries for the X Session Management
protocol. This protocol allows applications to participate in session management,
which enables them to save their state when the session is closed and restore it
when the session is reopened.

## Dependencies

- libICE 1.1.1
- libX11 1.8.10 (optional, for some functionality)

## Versions

- 1.2.4 (current)

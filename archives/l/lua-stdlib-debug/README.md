# lua-stdlib-debug

Lua stdlib debug enhancement module (std.debug), built from lua-stdlib source.

## Versions

- [41.2.1](41.2.1/) — Autotools build, pure Lua library

## Description

lua-stdlib-debug provides the `std.debug` module from the lua-stdlib project,
offering Lua debug enhancement functionality (detailed stack traces, variable
inspection, etc.).

## Dependencies

- lua-pc/5.4.7 (Lua interpreter)

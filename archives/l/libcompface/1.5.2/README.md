# libcompface

`libcompface` provides the `compface` library for lossless 48×48×1 face-image compression and the `compface`/`uncompface` command-line filters.

- Upstream version: 1.5.2
- Source mirror: <https://github.com/SvitloLinux-pkgs/compface/tree/1.5.2> (vanilla upstream source files)
- Conan reference: `libcompface/1.5.2`
- Build system: Autotools (`configure` + Makefile)
- HarmonyOS PC target: arm64 (`OHOS`/`armv8`)

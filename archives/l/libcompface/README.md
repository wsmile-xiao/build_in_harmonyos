# libcompface

`libcompface` 1.5.2 provides lossless 48×48×1 face-image compression and decompression.

The Conan package builds the static `libcompface.a` library and installs the
`compface` and `uncompface` command-line filters for HarmonyOS PC arm64.
See the version directory for the recipe, portability patches, and consumer test.

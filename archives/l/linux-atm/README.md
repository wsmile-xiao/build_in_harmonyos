# linux-atm

ATM on Linux user-space tools and libraries, adapted for OpenHarmony.

- Upstream: https://linux-atm.sourceforge.net/
- Version: 2.5.1
- Current package: `archives/l/linux-atm/2.5.1`
- Supported OpenHarmony architecture: armv8

The package ships the `libatm` library and the ATM command line tools:
`atmsigd`, `atmarpd`, `ilmid`, `ilmidiag`, `zeppelin`, `lecs`, `les`, `bus`,
`mpcd`, `br2684ctl`, `atmdump`, `saaldump`, `atmdiag`, `sonetdiag`, `atmaddr`,
`esi`, `atmloop`, `atmtcp`, `enitune`, `zntune`, `hediag` and the `src/test`
helpers.

# libilbc

Packaged version of iLBC codec from the WebRTC project.

iLBC (Internet Low Bitrate Codec) 是一种专为互联网语音传输设计的低码率编解码器，支持 20ms 和 30ms 两种帧模式。

- **主页**: https://github.com/TimothyGu/libilbc
- **许可证**: BSD-3-Clause
- **构建系统**: cmake
- **依赖**: 无

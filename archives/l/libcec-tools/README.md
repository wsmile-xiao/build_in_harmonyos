# libcec-tools

**Description**: Pulse-Eight's libCEC library and the `cec-client` and `cecc-client` tools for HDMI-CEC adapters.

| Item | Value |
|---|---|
| Upstream | https://github.com/Pulse-Eight/libcec |
| License | GPL-2.0-or-later |
| Conan reference | `libcec-tools/7.1.1` |

The Conan package includes the C/C++ headers, `libcec`, `cec-client`, and `cecc-client`. Optional Python bindings and their demo client are disabled because this package targets the C/C++ API. Hardware access still requires a supported CEC adapter and suitable device permissions.

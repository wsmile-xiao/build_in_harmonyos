# libarrow_flight

Apache Arrow Flight RPC — gRPC-based high-performance data transport for Arrow (includes the Arrow Flight SQL extension).

## Versions

- 23.0.1 — Arrow Flight RPC, same source as libarrow (apache-arrow-23.0.1 tag), ARROW_FLIGHT=ON + ARROW_FLIGHT_SQL=ON, gRPC stack from grpc/1.70.0

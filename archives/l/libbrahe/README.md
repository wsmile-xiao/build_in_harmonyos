# libbrahe

`libbrahe` is Scott Robert Ladd's "Brahe" — a heterogenous collection of numeric
tools written in Standard C: pseudo-random number generators (Mersenne Twister,
KISS, CMWC4096, MWC1038, ISAAC), inverse hyperbolic trigonometry, rounding and
significant-digit helpers, GCF/LCM, array statistics, moving average, a simple
FFT with sinusoid synthesis helpers, logarithm helpers and integer
pretty-printing.

# libxt

libXt is the X.Org implementation of the X Toolkit Intrinsics API. It
provides application contexts, event dispatch, resource conversion, widget
class infrastructure, memory helpers, and the `libXt.so.6` ABI used by X11
toolkits.

## OHOS adaptation

- Builds the official 1.3.1 release with its generated Autotools files.
- Keeps XKB enabled and preserves all 33 installed public headers, including
  the two headers generated by the build-time `makestrs` utility.
- Uses a GLib test-only dependency to enable all 20 upstream test paths.
- Uses package-relative pkg-config metadata and omits the obsolete `.la` file.
- Prepares two display-independent installed-package API consumers.
- Uses no source or patch conditional-compilation macro for platform handling.

## Dependencies

- `libx11/1.8.13` supplies the public Xlib and Xrm APIs.
- `libsm/1.2.6` supplies the directly linked session-management API.
- `libice/1.1.2` supplies the directly linked ICE API.
- `xorgproto/2025.1` supplies the xproto and kbproto headers.
- `glib/2.84.0.1` is used only while building and running upstream tests.

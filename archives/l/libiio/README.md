# libiio

Analog Devices **libiio** — Library for interfacing with Linux Industrial
I/O (Industrial Input/Output) devices, plus the `iio_*` command-line
utilities.

- Homepage: https://github.com/analogdevicesinc/libiio
- License: LGPL-2.1-or-later (tools GPL-2.0-or-later)
- Build system: CMake

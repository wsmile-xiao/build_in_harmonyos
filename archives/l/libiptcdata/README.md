# libiptcdata

Library for manipulating the International Press Telecommunications Council
(IPTC) metadata stored within multimedia files such as images.

- Upstream: https://github.com/ianw/libiptcdata
- License: LGPL-2.0-or-later
- Build system: autotools (release tarball ships a pre-generated `configure`)

# libdeflate

## 简介
libdeflate 是优化的 DEFLATE/zlib/gzip 压缩库，提供高性能压缩和解压缩。

## OHOS 适配
- CMake 构建，编译过程简单
- 提供静态库和共享库
- 附带 libdeflate-gzip/libdeflate-gunzip 工具

## 依赖
- 无编译依赖

## 功能验证
```bash
libdeflate-gzip --help
ls -la $HOME/usr/local/lib/libdeflate*
```

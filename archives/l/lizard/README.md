# lizard

圈复杂度分析器（Cyclomatic Complexity Analyzer），支持 30+ 种编程语言。

## 基本信息

| 项目 | 值 |
|------|-----|
| 官网 | http://www.lizard.ws |
| 上游仓库 | https://github.com/terryyin/lizard |
| 许可证 | BSD |
| 构建系统 | Python setuptools |
| 平台要求 | Python 3.8+ |

## 支持的语言

C/C++, C#, Java, JavaScript/TypeScript, Objective-C, Swift, Python, Ruby, TTCN-3, PHP, Scala, GDScript, Golang, Lua, Rust, Fortran 等

## 功能

- 圈复杂度 (CCN) 计算
- 代码行数 (NLOC) 统计
- Token 计数
- 参数计数
- 代码重复检测
- 多种输出格式（表格/CSV/XML/HTML）
- 多线程分析

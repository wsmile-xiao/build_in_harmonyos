# libixion

## 简介

libixion 是一个公式表达式计算库，主要用于 LibreOffice Calc 等电子表格软件的公式解析和计算。

## 主要功能

- 公式表达式解析
- 公式计算引擎
- 公式分词和排序
- 支持 Python 绑定（可选）

## 版本信息

- 当前编译版本：0.19.0
- 许可证：MPL-2.0

## 依赖

- mdds-2.1（header-only 库）
- Boost program_options 1.84

## 编译选项

- `--disable-python`：禁用 Python 绑定
- `--enable-static-boost`：使用静态 Boost 库

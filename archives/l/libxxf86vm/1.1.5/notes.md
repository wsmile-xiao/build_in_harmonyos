## Build design

The recipe uses the release Autotools files generated by autoreconf.
Since the GitLab archive lacks a pre-generated `configure`, `build()`
runs `autoreconf -v --install` after applying the 0001 patch.

### 0001 patch: Remove xorg-macros dependency

The `configure.ac` requires `xorg-macros 1.8` via `XORG_MACROS_VERSION`,
`XORG_DEFAULT_OPTIONS`, and `XORG_CHECK_MALLOC_ZERO`. These macros are
provided by the `util-macros` package which is not installed on the
OHOS build environment. The patch removes these three calls. The macros
are non-essential: `XORG_DEFAULT_OPTIONS` sets compiler warning flags
and man-page generation options; `XORG_CHECK_MALLOC_ZERO` defines
`MALLOC_ZERO_RETURNS_NULL` (harmless if undefined). The core build
functionality (`PKG_CHECK_MODULES`, `AC_PROG_LIBTOOL`,
`AM_INIT_AUTOMAKE`) does not depend on xorg-macros.

### OHOS configure approach

For OHOS builds, the recipe:
1. Runs autoreconf to generate `configure` and `config.sub`/`config.guess`.
2. Creates a build-local `configure-ohos` copy with `umask 077` → `umask 022`
   (HMDFS file system compatibility).
3. Uses `--build=aarch64-unknown-linux-gnu --host=aarch64-unknown-linux-gnu`
   (the GNU triplet) to avoid needing OHOS recognition in `config.sub`.
4. Sets `lt_cv_deplibs_check_method=pass_all` to bypass libtool `.la`
   validation (cross-compile common fix).
5. Sets `XXF86VM_CFLAGS` and `XXF86VM_LIBS` environment variables to
   provide dependency include/lib paths (the `configure.ac` uses
   `PKG_CHECK_MODULES` which may not find all deps on OHOS).

### Linker view technique

The recipe uses the linker-view approach from libxrender: a private
directory in the build folder that contains relocated copies of all
dependency `.so` and `.la` files. The `.la` files are rewritten so
`libdir` and `dependency_libs` point to the linker-view directory,
eliminating stale conan cache paths. `LDFLAGS=-L<linker-view>` is
passed to configure so libtool finds all dependencies there.

## Dependency boundary

- `libx11/6.4.0`: direct linked dependency (X11 core library, conan ABI version matching the cmd-pkgs/HMDFS soname scheme).
- `libxext/6.4.0`: direct linked dependency (X11 extensions library).
- `xorgproto/2025.1`: provides protocol headers (xproto, xextproto,
  xf86vidmodeproto) and pkg-config `.pc` files.

# lunasvg

lunasvg 是一个独立的 C++17 SVG 渲染库,不依赖任何第三方库(2D 渲染核心 plutovg 以
submodule 内嵌)。提供解析 SVG 文档、渲染到 Bitmap、文本/渐变/变换渲染等能力,
适合作为鸿蒙 PC 原生应用的矢量图形渲染组件。

- 上游仓库: https://github.com/sammycage/lunasvg
- 许可证: MIT
- 版本: 3.5.0 (2026-09-16 适配, OHOS aarch64)

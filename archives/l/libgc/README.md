# libgc

Boehm-Demers-Weiser conservative garbage collector for C and C++.

## Available Versions
- 8.2.12 (built)

## Description
libgc provides GC_MALLOC/GC_FREE as drop-in replacements for malloc/free, with
automatic collection of unreachable memory. Same upstream as bdw-gc
(https://github.com/bdwgc/bdwgc).

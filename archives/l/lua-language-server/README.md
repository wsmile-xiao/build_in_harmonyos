# lua-language-server

Lua Language Server - A language server for Lua that offers language support.

## Description

lua-language-server is a language server specifically designed for the Lua programming language. It provides features such as:

- Auto-completion
- Syntax checking
- Hover documentation
- Go to definition
- Find references
- Code formatting
- Diagnostics

## Available Versions

- **3.18.2**: Latest version with full OpenHarmony support
- **3.0.0**: Previous version

## Dependencies

lua-language-server requires the Lua runtime environment but is self-contained.

## Platform Support

- OpenHarmony (aarch64)
- Linux (x86_64, aarch64)
- macOS
- Windows

## Usage

After installation via cmd-pkgs, lua-language-server can be used with any LSP-compatible editor:

```bash
lua-language-server --version
```

For detailed usage, see: https://github.com/LuaLS/lua-language-server

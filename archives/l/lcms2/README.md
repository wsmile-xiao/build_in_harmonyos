# lcms2 (Little CMS 2)

## 简介
lcms2 是一个色彩管理引擎，支持 ICC 配置文件处理，广泛用于图像处理软件。

## OHOS 适配
- autotools 构建，需要更新 config.guess/config.sub 支持 HarmonyOS
- 无特殊平台适配问题

## 依赖
- 无编译依赖

## 功能验证
```bash
ls -la $HOME/usr/local/lib/liblcms2*
```

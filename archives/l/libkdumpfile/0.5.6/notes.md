### 修复摘要（OHOS 平台差异）
1. 死锁: diskdump/elf/sadump 的 *_bmp_cleanup 持 shared->lock 写锁时调 shared_decref(加锁版) 二次加非递归 rwlock → musl 自死锁; 改为 shared_decref_locked
2. tests/*.c: M_PERTURB / malloc_trim 是 glibc 私有, OHOS musl 未定义 → #ifdef 守卫
3. xlat-* 脚本 shebang #!/bin/bash 在 OHOS 无 /bin/bash → #!/usr/bin/env bash
4. dumpdata "file" -o linux(选项在后) 依赖 glibc getopt 重排, musl 不重排 → 调序

# libsixel

## 简介
Sixel graphics encoding library

## OHOS 适配
- 构建系统: meson
- 所有可选功能已启用: gd, gdk-pixbuf2, libcurl, jpeg, png
- 默认静态链接 (OHOS动态链接器限制)
- 补丁: 0001-meson-build-gd-pkgconfig.patch

## 依赖
- libjpeg/10
- libpng/1.6.58
- gd/2.3.3.2
- curl/8.15.0
- gdk-pixbuf/2.44.6

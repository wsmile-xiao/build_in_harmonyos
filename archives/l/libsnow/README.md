# libsnow

A header-only unit testing framework for C (snow).

## Project Information

- **Official Website**: https://github.com/mortie/snow
- **License**: MIT
- **Language**: C
- **Type**: Header-only testing framework

## Description

Snow is a header-only unit testing framework for C. It's designed to be simple, lightweight, and easy to use. Snow provides a clean API for writing tests with support for assertions, test organization, and colored output.

## Features

- Header-only (no compilation required)
- Simple and intuitive API
- Colored output for better readability
- Test organization with describe/it blocks
- Various assertion macros
- C11 compatible

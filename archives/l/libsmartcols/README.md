# libsmartcols

util-linux 的表格输出库（结构化表格渲染——lsblk/findmnt/uuidparse 等工具的底层）。

- 上游：https://kernel.org/pub/linux/utils/util-linux/
- 许可证：LGPL-2.1-or-later
- 语言：纯 C
- 构建系统：autotools（util-linux 树子目录构建）

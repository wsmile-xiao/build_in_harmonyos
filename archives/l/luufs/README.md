# luufs

## Overview

luufs is a lazy man's, user-mode union file system.

It takes two directories and creates a magical directory which shows their
unified contents.

## Features

- Implemented in user-mode via FUSE
- Compile once, run anywhere
- Alternative for Aufs and Unionfs
- Simple design with three rules for security

## Dependencies

- FUSE (Filesystem in Userspace)
- zlib

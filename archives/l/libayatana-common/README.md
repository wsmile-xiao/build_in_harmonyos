# libayatana-common

Ayatana Indicators 公共库，提供 Ayatana 指示器（如 ayatana-indicator-keyboard）共用的
通用工具函数：桌面环境/会话检测、程序存在性检测、命令执行、URL 打开、zenity 交互封装等。

- 上游仓库: https://github.com/AyatanaIndicators/libayatana-common
- 构建系统: CMake
- 依赖: glib-2.0 >= 2.36, gio-2.0 >= 2.36
- 许可证: GPL-3.0

## 版本

- 0.9.13 — 最新稳定版（满足 ayatana-indicator-keyboard 的 libayatana-common>=0.9.11 要求）

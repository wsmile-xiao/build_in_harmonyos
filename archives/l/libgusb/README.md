# libgusb

**描述**: libgusb - GObject wrapper for libusb

**版本**: 0.4.9

**状态**: published

**依赖**: glib-2.0, libusb-1.0

**许可证**: LGPL-2.1+

## 安装

```bash
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- libgusb 0.4.9
```

## 鸿蒙适配说明

- meson 编译器环境变量需要正确设置
- 需要 glib-2.0 和 libusb-1.0 依赖
- 质量门禁验证通过

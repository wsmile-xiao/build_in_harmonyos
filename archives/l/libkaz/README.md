# libkaz (kazlib)

`libkaz` 打包 Kaz Kylheku 维护的 kazlib——一组自包含的 ANSI C 数据结构库：
字典（dict）、哈希表（hash）、双向链表（list）、异常处理（except，可选
POSIX 线程安全）与表达式副作用分析（sfx）。各模块以 `.c/.h` 对发布，既可
整体编成 `libkaz` 链接，也可直接并入宿主工程源码。

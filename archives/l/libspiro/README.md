# libspiro

曲线绘制简化库，使用 Spiro 曲线算法。

## 简介
libspiro 是一个将 Spiro 控制点转换为贝塞尔曲线的库。主要用于字体设计应用，如 FontForge。

## 主页
https://github.com/fontforge/libspiro

## 可用版本
- 20240903 (已编译)

## 依赖
- 无（独立库）

## 使用方法
```bash
pkg-config --cflags libspiro
pkg-config --libs libspiro
```

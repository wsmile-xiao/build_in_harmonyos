# libsvgtiny 0.1.8 适配笔记

## 编译环境
- 构建系统: makefile（NetSurf NSSHARED → standalone Makefile 替换）
- 编译日期: 2026-09-01
- 编译器: clang 15.0.4 (aarch64-linux-ohos, OHOS SDK 26.0.0.18)
- 状态: built

## 编译步骤

1. `source .build-context-libsvgtiny-0.1.8 && cd $BUILD_SRC_DIR`
2. 替换顶层 Makefile 为 standalone Makefile（原 Makefile include
   `$(NSSHARED)/makefiles/Makefile.tools`，本平台无 netsurf-buildsystem）
3. 补丁 0002 提交预生成的 `src/autogenerated_colors.c`（颜色查找表）
4. `make CC=clang AR=llvm-ar RANLIB=llvm-ranlib -j1` 生成 `libsvgtiny.a` + `libsvgtiny.pc`
   （依赖头文件路径由 conanfile 从各依赖 cpp_info 注入）
5. `make install PREFIX=$DEFAULT_PREFIX DESTDIR=$TEST_PREFIX` 验证安装
6. conan 侧 `conan create` + test_package 消费者测试通过

## 遇到的问题与解决方案

| # | 问题 | 根因 | 解决方案 |
|---|------|------|----------|
| 1 | 原始 Makefile `include $(NSSHARED)/makefiles/Makefile.tools` 找不到 | NetSurf 组件库使用自有 NSSHARED 构建系统，本平台无 netsurf-buildsystem | 替换为 standalone Makefile（libparserutils / libwapcaplet / libhubbub / libdom 同款方案），去除 -Werror 兼容 clang 15 |
| 2 | `svgtiny.c` `#include "autogenerated_colors.c"` 需 gperf 生成 | 上游 `src/Makefile` 用 gperf 从 `src/colors.gperf` 生成颜色查找表 | 补丁 0002 提交功能等价的手写 `autogenerated_colors.c`（147 条目，与 colors.gperf 逐条核对值；函数/表 static 同上游）。Makefile 不留 gperf 再生成规则：提交件是唯一事实源，clean 不删、缺失即 "No rule to make target" 快速失败（AI 检视指出"条件再生成"双路径会被 clean 击穿且产物漂移，故改为单路径） |
| 3 | `-Wmissing-prototypes` 报 `svgtiny_color_lookup` 无原型 | 查找表函数定义无前置声明 | 函数声明为 `static`（文件被 #include 进 svgtiny.c，同 TU 内使用，无需导出） |
| 4 | 编译需 `dom/bindings/xml/xmlparser.h` + `libwapcaplet/libwapcaplet.h` | svgtiny.c 直接用 dom XML binding 头与 lwc 类型 | conanfile 依赖声明 libdom + libwapcaplet，build() 从两个 cpp_info 注入 `-I` |
| 5 | `make -j2` jobserver mkfifo `Operation not permitted` | HMDFS 禁 FIFO（E074） | conanfile 固定 `-j1`（R9） |

## 源码修改

| Makefile | NetSurf 构建系统不可用 | 完全替换为独立 Makefile（无 gperf 依赖，生成件单一代码路径） | patches/0001-Makefile.patch |

## 注意事项

- libsvgtiny 是 NetSurf 浏览器 SVG 渲染组件，无平台任务，作为任务 245
  的适配目标（PR 标题带【积分赛】前缀）。
- 静态库无需 ELF 签名与 RPATH 处理（E018）
- conandata.yml URL 为官方源，sha256 与 tarball 一致（R39）
- NetSurf 组件库家族（libparserutils/libwapcaplet/libhubbub/libdom/libsvgtiny）
  均需替换为 standalone Makefile，libsvgtiny 同模式
- L0i 依赖检查需 libdom/0.4.2 已发布到 ohpcd remote（即 PR #6870 合并后
  CI 才绿），与 libxtst 等 libxi 的模式相同

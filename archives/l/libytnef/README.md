# libytnef

HarmonyOS Conan archives for Yerase's TNEF Stream Reader, the library that
decodes TNEF (`winmail.dat`) streams produced by Microsoft Outlook.

## Versions

- `2.1.2`: autotools package providing `libytnef` plus the upstream `ytnef` and
  `ytnefprint` command line tools. The upstream sample-message suite
  (`test-data/test.sh`) runs inside `build()`.

See the version directory for the recipe, source checksum, build notes, test
package and test report.

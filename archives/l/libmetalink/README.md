# libmetalink

Metalink 是一种描述下载资源的文件格式标准（RFC 5854 相关），libmetalink 是其 C 语言解析库实现。

## 功能概述

- 解析 Metalink 版本 3 和版本 4 格式的 XML 文件
- 支持基于 expat 的 XML 解析后端
- 提供结构化的 Metalink 数据类型（文件、资源、校验和等）
- 同时提供动态库 (.so) 和静态库 (.a)

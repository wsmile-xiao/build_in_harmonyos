# libparquet

Apache Parquet is a columnar storage format available to any project in the Hadoop ecosystem, with support for efficient compression and encoding schemes. The C++ implementation is part of the Apache Arrow family (same source tree, `ARROW_PARQUET=ON` component). Parquet provides flat and nested data models, predicate/statistics pushdown, and multiple compression codecs (SNAPPY, ZSTD, LZ4, GZIP, BROTLI).

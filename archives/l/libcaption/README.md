# libcaption

CEA-708/EIA-608 caption library for parsing and generating closed caption data.

- **Website**: https://github.com/szatmary/libcaption
- **Version**: 0.8
- **Build System**: cmake
- **Language**: C/C++
- **Dependencies**: None

## Description

libcaption is a library for parsing, generating, and manipulating CEA-708 and EIA-608 closed caption data. It supports SCC, SRT, and WebVTT subtitle formats, and provides MPEG SEI caption framing.

## Products

- `libcaption.a` — Static library
- `caption/*.h` — Header files (caption.h, cea708.h, eia608.h, eia608_charmap.h, mpeg.h, scc.h, srt.h, utf8.h, vtt.h, xds.h)

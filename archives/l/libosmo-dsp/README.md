# libosmo-dsp

## 简介

Osmocom 信号处理库：GTIB/CPFSK 解调、UDP 消息封装等软件无线电（SDR）
辅助算法，osmo-trx 的直接依赖。

## 主要功能

- GMSK/CPFSK 解调与相关 DSP 原语
- UDP 消息封装辅助
- 无硬件依赖（纯软件算法）

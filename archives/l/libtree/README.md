# libtree

A tool that:
- 🌳 turns `ldd` into a tree
- ☝️ explains how shared libraries are found or why they cannot be located

## Description

libtree is a command-line utility that displays shared library dependencies as a tree structure, making it easier to understand how libraries are resolved and why certain dependencies might be missing.

## Features

- Tree visualization of library dependencies
- Explains library resolution paths
- Shows why libraries cannot be found
- Supports multiple verbosity levels
- Lightweight and fast

## Installation

Prebuilt binaries available for multiple architectures. See the [homepage](https://github.com/haampie/libtree) for more details.

# libguarded

CsLibGuarded (libguarded) is a header-only C++20 library of thread-safe guards for protecting shared data, published by CopperSpice.

- 上游: https://github.com/copperspice/cs_libguarded
- 当前适配版本: 2.0.1
- 构建系统: CMake
- Conan 类型: `header-library`
- 第三方依赖: 无（仅 C++20 标准库与 pthread）
- 许可证: BSD-2-Clause

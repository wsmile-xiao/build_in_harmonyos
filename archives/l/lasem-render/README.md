# lasem-render

Lasem — SVG and MathML rendering library with a DOM-like API, plus the
`lasem-render` command line renderer. Pure C, built on glib/cairo/pango.

Upstream: GNOME lasem (https://gitlab.gnome.org/GNOME/lasem)

## Versions

| Version | Status | Notes |
|---------|--------|-------|
| 0.5.1 | built | MathML/SVG math renderer; 1186 upstream test cases pass |

## Artifacts

- `liblasem-0.6` — core library (DOM API, MathML/SVG rendering, itex2mml)
- `lasem-render-0.6` — CLI: render SVG/MathML to PNG/PDF/SVG/PS

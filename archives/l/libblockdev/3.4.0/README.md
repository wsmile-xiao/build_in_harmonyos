# libblockdev 3.4.0 - HarmonyOS Build

## Overview
libblockdev is a library for manipulating block devices. This build targets
HarmonyOS (16aarch64-unknown-linux-ohos) and includes the core library, utils, and loop plugin only.

## Build Configuration
- Disabled plugins: btrfs, lvm, lvm-dbus, mpath, dm, crypto, escrow, nvdimm, nvme, smart, smartmontools, s390, fs, part, swap, tools, python3, mdraid
- Enabled plugins: loop
- Stub dependencies: libudev (v219), libkmod (v33)

### Known Limitations (not blocking for repo upload)
1. Only loop plugin enabled - other plugins require Linux-specific tools/libraries not available on HarmonyOS
2. Stub libudev/libkmod - minimal API returning NULL/-2, hardware-dependent features won't work
3. **LD_LIBRARY_PATH required**: Runtime must set `export LD_LIBRARY_PATH=~/.usr/local/lib`
4. **PKG_CONFIG_PATH required**: Build-dependent programs must set `export PKG_CONFIG_PATH=~/.er/local/lib/pkgconfig`
5. **glib statically linked**: libbd_utils.so embeds glib, build-dependent programs need `-lintl_glib` flag and `G_INTL_STATIC_COMPILATION` macro
6. **bd_init stuck issue**: Use bd_loop_init() separately to avoid kmod stub init loop in bd_init
7. **libbd_utils.so large size (11MB)**: Due to embedded glib static library, normal for HarmonyOS
8. **NEEDED with absolute path**: libbd_utils.so.3 has NEEDED entry with full path `/storage/.../libudev.so` instead of relative `libudev.so` - needs patchelf fix for portability

# libcss 0.9.2 notes

## Scope

NetSurf 浏览器组件库：CSS 解析与选择（stylesheet 解析 → 字节码 →
select 引擎 computed style 计算）。任务 #14003，taskBranch=feat/libcss-0.9.2。

## Upstream shape (0.9.2-src.tar.gz, 2023-12-27)

- NetSurf 自有构建系统：顶层 Makefile include $(NSSHARED)/makefiles/
  Makefile.tools（本平台无 netsurf-buildsystem 包；官方 git.netsurf-
  browser.org 域名已 404，Debian/GitHub 镜像确证 Makefile.clang 注入
  `-D_ALIGNED=__attribute__((aligned)) -DSTMTEXPR=1`）。
- 源码：184 个一手 .c + 代码生成 119 个 autogenerated_*.c（属性解析器，
  gen_parser 由 properties.gen 生成）+ select/properties/ 127 个 .c。
- select/ 侧 autogenerated_{computed,propget,propset}.h tarball 已预生成
  （无需 select_generator.py）。
- 依赖：libparserutils + libwapcaplet（pkg-config）。
- 测试：test/ 8 个数据驱动测试二进制 + test/data 55 个数据文件 /
  2759 注册用例（#data 块 2619 + select #tree 块 140）。上游 `make
  test` 由 netsurf-buildsystem 的 testrunner.pl（perl）驱动。

## Adaptations（patches/0001-standalone-Makefile.patch）

1. **standalone Makefile**（libwapcaplet 0.4.3 / libparserutils 0.2.5
   历史适配一致的范式替换顶层 Makefile）：
   - 两阶段构建：宿主 BUILD_CC 编译 gen_parser → 由 properties.gen 生成
     119 个 autogenerated_*.c（上游 PRE_TARGETS 规则的手工复刻）；
     311 个 .c（SRC 显式列上游 DIR_SOURCES + wildcard properties 目录）
     编入 libcss.a。
   - 补上 Makefile.clang 注入的 `-D_ALIGNED=__attribute__((aligned))
     -DSTMTEXPR=1`（src/stylesheet.h 的 `struct css_rule {...} _ALIGNED;`
     声明依赖；缺失时 musl 下 `_ALIGNED` 被当作结构标签，多翻译单元
     链接 duplicate symbol `_ALIGNED`）。
   - `-Werror` 移除（clang 15 兼容，libwapcaplet 先例）。
   - install 目标：lib/libcss.a + lib/pkgconfig/libcss.pc +
     include/libcss/*.h（上游 INSTALL_ITEMS 等价）。
2. **配方注入**：CC/AR/RANLIB 从 Conan conf（R33）；DEP_CFLAGS/
   DEP_LIBS 注入 libparserutils/libwapcaplet 包路径（PKG_CONFIG=/bin/false
   关闭 pkg-config 探测）；make -j1（R9）。

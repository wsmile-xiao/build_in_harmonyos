# libbtbb (Bluetooth Baseband Library)

## 简介
libbtbb 是一个蓝牙基带库，用于解码蓝牙基带数据包。由 Great Scott Gadgets 开发，是 Ubertooth 蓝牙分析工具的依赖库。

## OHOS 适配
- cmake 构建系统
- 无特殊平台适配问题

## 依赖
- 无编译依赖

## 功能验证
```bash
ls -la $HOME/usr/local/lib/libbtbb*
```

# libosmium

## 简介
libosmium 是一个快速、灵活的 C++ 库，用于处理 OSM (OpenStreetMap) 数据。它是一个 header-only 库，无需编译即可使用。

## OHOS 适配
- Header-only 库，只需安装头文件即可
- 依赖 Boost 库（已预装）
- CMake 版本需要更新到 3.5 以上

## 依赖
- Boost 1.84.0 (header-only)

# libspeechprovider 1.0.3

- Official tag: `SPEECHPROVIDER_1_0_3` (`07e6a2a4f1df7149966588e57daf43336eba28ed`).
- The upstream Meson project unconditionally builds `speech-provider-1.0` as a shared library and requires GLib >= 2.76.
- On HarmonyOS PC, `glib/2.84.0.1` has a compatible binary. Meson needs the profile's Clang and an explicit `llvm-ar` path.
- Upstream `tests/` defines one Python TAP test program (`test_provider_lib.py`) with two `unittest` cases. It is instantiated only when GI and Python `tap` are available. `conan install --requires=glib/2.84.0.1 --requires=gobject-introspection/1.78.1.1 --build=never` reported missing OHOS binaries for `gobject-introspection/1.78.1.1` and `python/3.12.9` on 2026-09-29; Python `gi` and `tap` imports also failed on the device. Introspection is therefore disabled. The C `test_package` repeats the two public API scenarios with nonblocking pipes and checks the same header, audio, and event results.
- The local native Meson baseline compiled the official archive successfully on 2026-09-29. Meson install rewrites the shared library's RUNPATH, invalidating its OHOS ELF signature (`ctypes.CDLL` returned `Permission denied`). The recipe restores the original linked `.so` into the package after install. On 2026-10-02, clearing RUNPATH from a copy with `patchelf` reproduced the same loader error, so the recipe now removes Meson's absolute `-rpath` linker argument before the shared library is linked.
- `conan create` on HarmonyOS PC with the repository's `ohos-aarch64` profile returned exit code 0 on 2026-09-29. Its consumer test reported `1/1` Meson test passing; the test binary ran both GLib cases (`/speechprovider/bad-header` and `/speechprovider/round-trip`). The upstream Python GI TAP test was not run and is not included in this pass count.
- On 2026-10-02, `conan create` with the repository's `ohos-aarch64` profile returned exit code 0 after the link-stage fix. `llvm-readelf -d` showed no RPATH or RUNPATH in the packaged `.so`; the `test_package` checks this and the consumer passed (`1/1` Meson test, both GLib cases). A direct `ctypes.CDLL` load with GLib supplied through `LD_LIBRARY_PATH` also passed. A separate-device consumer has not yet been tested.

# libdvbpsi

MPEG/DVB PSI decoder and generator library from VideoLAN.

## Description

libdvbpsi is a library designed to decode and generate MPEG/DVB PSI (Program
Specific Information) tables. It supports decoding of PAT, PMT, NIT, SDT, EIT,
CAT, and various descriptor types. It also provides functionality to generate
PSI tables for DVB transport streams.

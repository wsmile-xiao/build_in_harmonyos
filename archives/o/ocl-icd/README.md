# ocl-icd

OpenCL ICD（可安装客户端驱动）加载器 — Khronos 组织规定的 OpenCL ICD 扩展的标准实现。

## 简介

ocl-icd 提供了一个厂商中立的 Installable Client Driver (ICD) 加载器，允许多个不同厂商的 OpenCL 实现共存于同一系统。ICD 加载器动态加载厂商提供的 OpenCL 运行时实现，并将 API 调用分发到相应的驱动程序。

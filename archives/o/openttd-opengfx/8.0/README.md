# OpenGFX 8.0 - OpenTTD Graphics Base Set

OpenGFX 8.0 是 OpenTTD 的开源基础图形集版本 8.0。

## 安装说明

安装路径: $PREFIX/share/openttd/baseset/opengfx/

文件列表:
- ogfx1_base.grf - 基础图形集
- ogfxc_arctic.grf - 极地图形集
- ogfxh_tropical.grf - 热带图形集
- ogfxt_toyland.grf - 玩具乐园图形集
- ogfxi_logos.grf - Logo 图形集
- ogfxe_extra.grf - 额外图形集
- opengfx.obg - 基础图形集元数据文件
- license.txt, changelog.txt, readme.txt - 文档

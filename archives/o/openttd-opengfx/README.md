# OpenGFX - OpenTTD Graphics Base Set

OpenGFX 是 OpenTTD 的开源基础图形集，替代原始 Transport Tycoon Deluxe 图形资源。

## 基本信息

- 软件名: openttd-opengfx
- 版本: 8.0
- 许可证: GPL v2
- 类型: 数据包（游戏图形资源）
- 构建系统: Makefile (NML build framework)

## 描述

OpenGFX 提供了 OpenTTD 所需的所有基础图形资源，包括：
- 地形/地面图形
- 车辆图形（火车、汽车、飞机、船只）
- 建筑/设施图形
- UI 图形元素

这些资源以 .grf (Graphics Resource File) 格式分发，是 OpenTTD 运行的必要数据文件。

# OpenCL C++ Headers (opencl-clhpp-headers)

C++ API header files for the OpenCL API, maintained by the Khronos Group.

This is a header-only library providing `CL/opencl.hpp` and `CL/cl2.hpp` — the C++ wrapper for the OpenCL C API.

## Dependencies

- [opencl-headers](../opencl-headers/) — C language headers for OpenCL API

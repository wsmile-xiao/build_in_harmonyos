# OpenSCAP

OpenSCAP is an open-source SCAP (Security Content Automation Protocol) framework.
It provides a set of tools for security compliance checking, vulnerability scanning,
and configuration assessment.

## Versions

- **1.4.3** - OHOS adaptation with Conan packaging

## Dependencies

- libxml2
- libxslt
- xmlsec1
- openssl
- pcre2
- libgcrypt
- bzip2
- libcurl

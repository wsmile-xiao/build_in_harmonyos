# plyara

Parse YARA rules and operate over them more easily. `plyara` lexes and parses
YARA rule files into a Python dictionary representation, so a corpus of rules
can be filtered, transformed, re-hashed or dependency-analysed programmatically.

Pure Python (no C/C++ code, no runtime third-party dependencies). The lexer and
parser are generated by **PLY** (Python Lex-Yacc), which upstream vendors as a
git submodule (`third_party/ply`) and exposes through the `src/ply` symlink.

- 上游仓库: https://github.com/plyara/plyara
- 版本: 2.2.8（tag `v2.2.8`，上游最新 tag）
- 内嵌 PLY: github.com/plyara/ply @ `5c4dc94d4c6d059ec127ee1493c735963a5d2645`
  （PLY 4.x，`__version__ = 2022.10.27`）
- 许可证: Apache-2.0
- 适配说明: 纯 Python noarch 包，无编译；`plyara` 与内嵌 `ply` 一并安装到
  `lib/python3.12/site-packages/`，并提供 `bin/plyara` 命令行入口，
  供 HarmonyOS PC 上的 Python 3.12 使用。

## 命令行

```bash
plyara rules.yar            # 输出解析结果的 JSON（sort_keys + indent=4）
plyara --log rules.yar      # 附带 debug 日志到 stderr
```

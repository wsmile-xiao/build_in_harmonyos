## 补充说明

- **适配范围**：从零编写 packcc 3.1.0 conan 配方（archives/p/packcc/3.1.0/ + commands.json），供下游 PEG 语法解析器生成场景消费（C/C++ 工具链类）。包目录 slug：`packcc/3.1.0`，分支 `feat/packcc-3.1.0`。
- **OHOS 适配关键点**：
  1. 上游 CMake 原样构建：conan CMakeToolchain 驱动 OHOS SDK clang，产出的 `bin/packcc` 自带 .codesign 签名（HMDFS 可执行，无需手工重签，cdargs 反例对比见 notes）；
  2. CMakeLists 对 GNU/Clang 一律 `-pedantic -Werror`，Release 无 sanitizer；CI 用 ohos-aarch64 Release profile 避开 ASan/UBSan 库依赖；
  3. install：`bin/packcc` + `share/packcc/import`（-I import 语法库）；package 补 MIT LICENSE。
- **上游测试统计核验方式**：解包 release tarball 实读 tests/ 目录（46 个 *.d），README 确认 `--target check` 需 Bats-core 与 Uncrustify；`packcc --version` 与生成文件头标识经源码 grep 核实（PACKCC_VERSION=3.1.0）。
- 与 vala 0.56.19（同样依赖外部 bash/bats 测试框架的工具类）非集成理由一致；若未来 CI 提供 bats 可一行切到 `cmake.build(target="check")`。

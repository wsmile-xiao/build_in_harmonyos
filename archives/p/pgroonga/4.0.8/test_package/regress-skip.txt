# pgroonga 4.0.8 上游 pg_regress 套件排除清单
#
# 格式: <测试名(相对 sql/ 去掉 .sql)> <原因>
# 除下列 2 例外，上游 sql/ 下全部用例均实跑（含 expected/ 下的 _1/_2 备用 oracle）。
#
# 排除原因统一为「OHOS groonga/16.0.8 未编入对应外部插件」：
#   groonga 的插件式 tokenizer / token filter 是独立构建产物（Debian 上分别是
#   groonga-tokenizer-mecab / groonga-token-filter-stem 两个包），不属于 groonga 本体。
#   OHOS groonga 包只带 lib/groonga/plugins/{functions,query_expanders,suggest,
#   token_filters/stop_word}，既无 tokenizers/mecab 也无 token_filters/stem，
#   因此这 2 例在设备上必然拿到 groonga 的 "unsupported tokenizer/filter" 报错，
#   与 pgroonga 适配无关。其余用例用到的 TokenNgram/TokenBigram/NormalizerNFKC*
#   都是 groonga 内置实现，不依赖上述插件。
#
# 需要时可通过传入 groonga 的 mecab/stem 插件并设置 GRN_PLUGINS_DIR 恢复。

function/tokenize/metadata 需要 TokenizerMecab（groonga-tokenizer-mecab 插件），OHOS groonga/16.0.8 未编入
full-text-search/text/options/token-filters/custom 需要 TokenFilterStem（groonga-token-filter-stem 插件），OHOS groonga/16.0.8 未编入

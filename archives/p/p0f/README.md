# p0f 3.09b

p0f is a passive TCP/IP fingerprinting tool that identifies operating systems and network characteristics from observed traffic without actively probing hosts.

- Homepage: https://lcamtuf.coredump.cx/p0f3/
- Dependency: `libpcap/1.10.6`
- Installed commands: `p0f`, `p0f-client`, `p0f-sendsyn`, `p0f-sendsyn6`
- Fingerprint database: `$P0F_DATA_DIR/p0f.fp`

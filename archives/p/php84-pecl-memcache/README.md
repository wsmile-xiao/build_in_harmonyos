# PHP 8.4 PECL Memcache

> PHP memcache extension for PHP 8.4 caching via memcached servers

## 简介

php84-pecl-memcache 是 PHP 8.4 的 memcache 扩展，提供通过 memcached/memcache 服务器的数据缓存功能。

## OHOS 适配要点

- 使用 phpize + configure + make 标准编译流程，无需源码修改

## 依赖

| 依赖 | 版本 | 说明 |
|------|------|------|
| php84 | 8.4 | PHP 运行时 |

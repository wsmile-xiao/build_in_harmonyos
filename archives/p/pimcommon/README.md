# pimcommon

KDE PIM 公共组件库（KDE PIM common libraries）。为 KDE PIM 家族（KMail、KOrganizer、
KAddressBook 等）提供共享的基础设施：通用插件框架（genericplugins）、插件配置
（configureplugins）、模板管理（templatewidgets）、自定义工具视图（customtools）、
分享服务 URL（shareserviceurl）、网络状态（network）、What's New / 版本更新检查
（whatsnew / needupdateversion / verifynewversion）以及一组公共 widget。

- 上游: https://invent.kde.org/pim/pimcommon
- 许可证: GPL-2.0-or-later / LGPL-2.0-or-later（文件级 SPDX 标注）
- 归档版本: 25.12.3（KDE release-service，PIM_VERSION 6.6.3）
- OHOS PC 适配: 核心库 KPim6PimCommon（core-library-only port；pimcommonakonadi /
  pimcommon-activities 依赖未发布的 KPim6 栈，未构建——详见版本目录 notes.md）

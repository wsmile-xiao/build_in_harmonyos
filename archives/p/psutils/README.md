## 软件简介
psutils 是一组 PostScript 文档处理工具，包括：
- epsffit: 将 EPS 文件适配到指定边界
- psbook: 重新排列页面以制作书籍
- psnup: 将多页合并到单张纸上
- psresize: 调整页面尺寸
- psselect: 选择特定页面
- pstops: 执行 PostScript 操作
- 以及多个 Perl 脚本工具（extractres, fixdlsrps 等）

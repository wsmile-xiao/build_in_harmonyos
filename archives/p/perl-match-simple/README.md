# perl-match-simple

match::simple - 简化的 smartmatch 操作符克隆

## 简介

match::simple 提供一个简单的匹配操作符 `|M|`，类似于 Perl 5.18 之前废弃的 smart match 操作符的一个合理子集。与 smart match 不同，匹配的行为完全由右侧操作数决定。

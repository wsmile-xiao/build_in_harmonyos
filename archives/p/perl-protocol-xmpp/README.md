# perl-protocol-xmpp

## 软件描述

Protocol::XMPP — XMPP/Jabber 协议 API (RFC 3920/3921)

纯 Perl 模块，提供 XMPP 协议流处理、SAX 事件处理、XML 元素编解码、JID 解析、消息/联系人/花名册管理、SASL 认证、IQ 请求管理等功能。基于事件驱动架构，支持异步和阻塞两种模式。可用于实现 XMPP 客户端或服务端。

# pdd

pdd 是一个小巧的日期/时间差计算器（含倒计时与秒表）。

## 基本信息

- **上游仓库**: https://github.com/jarun/pdd
- **许可证**: GPLv3
- **语言**: Python >= 3.7（纯 Python，无 C 扩展）

## 版本列表

- 1.7

## 描述

Tiny date, time diff calculator with timers — 支持两个日期/时间之差（y/m/d 与总天数、
h:m:s 与总秒数）、日期/时间加减、星期查询、倒计时与秒表。sdist 内为单文件模块
`pdd.py`，console_scripts 入口 `pdd = pdd:main`；运行时依赖 `python-dateutil`。

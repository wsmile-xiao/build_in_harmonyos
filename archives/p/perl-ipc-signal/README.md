# perl-ipc-signal

IPC::Signal - Utility functions dealing with signals

This module contains utility functions for dealing with signals, providing:
- sig_num: Returns signal number from signal name
- sig_name: Returns signal name from signal number
- sig_translate_setup: Initialize signal translation tables

## Source

- CPAN: https://metacpan.org/pod/IPC::Signal

## Dependencies

- Perl 5.003_94 or later

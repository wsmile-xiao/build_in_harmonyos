# python-gssapi

Python GSSAPI Wrapper - Cython bindings to the GSSAPI C library.

This package provides Python bindings to the Generic Security Services API (GSSAPI)
as defined in RFC 2743, using Cython to generate C extension modules that link
against MIT Kerberos 5 (libgssapi_krb5).

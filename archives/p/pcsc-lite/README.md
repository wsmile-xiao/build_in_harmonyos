# pcsc-lite

Middleware to access a smart card using SCard API (PC/SC).

## Description

pcsc-lite provides a PC/SC IFD (Interface Device) implementation for smart card
access. It includes the `pcscd` daemon, `libpcsclite` client library, and
`pcsc-spy` debugging tool.

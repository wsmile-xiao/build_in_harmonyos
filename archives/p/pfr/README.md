# Boost.PFR

Boost.PFR is a header-only C++14 library that provides tuple-like access and
reflection helpers for aggregate types without macros. The Conan package name
is `pfr` and its CMake consumer target is `boost::pfr`.

The versioned recipe installs the upstream `include/boost` tree and
`LICENSE_1_0.txt`. No compiled library or runtime dependency is produced.

# podofo

PoDoFo 是一个用于处理 PDF 文件的 C++ 库，提供 PDF 文档的创建、解析、修改和渲染功能。

## 主要功能

- PDF 文档解析和创建
- PDF 页面操作（合并、分割、提取页面）
- PDF 加密和解密（RC4、AES-128、AES-256）
- 文本和图像提取
- PDF 签名
- 字体嵌入和管理

## 构建系统

- 构建系统: CMake
- 语言: C++
- 依赖: zlib, freetype, fontconfig (可选), libpng, openssl (可选)

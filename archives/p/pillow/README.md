# Pillow

Pillow is a Python imaging library supporting common image formats and image-processing APIs.

## Conan package

The `pillow/12.3.0` package installs the `PIL` Python package and native extension modules under:

```text
lib/python3.12/site-packages
```

The package is built for HarmonyOS PC aarch64 with zlib and libjpeg-turbo support.

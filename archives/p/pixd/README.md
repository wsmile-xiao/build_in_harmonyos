# pixd

Colourful visualization tool for binary files.

## Description

pixd renders binary data using a colour palette: each octet is drawn as a
coloured square (24-bit SGR escape sequences), in a way akin to a hexdump
tool. It is written in C and has no external dependencies beyond the
standard C library.

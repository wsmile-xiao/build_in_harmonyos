# Lingua::Translit

Perl module for transliterating text between different writing systems.

## Description

Lingua::Translit provides transliteration functionality for converting text from one writing system to another. It supports 24 standard transliteration tables covering various languages including Greek, Russian, Bulgarian, Arabic, and more.

## Features

- 24 standard transliteration tables
- Bidirectional conversion support (for reversible tables)
- Pure Perl implementation (no XS dependencies)
- Command-line tool `translit`

## Supported Transliteration Tables

- ISO 843 (Greek)
- ISO 9 (Russian)
- DIN 31634 (Greek)
- DIN 1460 (Russian, Bulgarian, Ukrainian)
- GOST 7.79 (Russian, Ukrainian)
- Common series (German, Czech, Polish, etc.)
- Greeklish
- And more...

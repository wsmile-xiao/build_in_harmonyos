# protoc-gen-go

Go protobuf code generator plugin for protocol compiler (protoc).

## Description

protoc-gen-go is the Go code generator plugin for the protocol buffer compiler (protoc).
It reads protobuf service definitions and generates Go source code implementing the defined
messages, services, and RPC stubs.

## Source

- Repository: https://github.com/protocolbuffers/protobuf-go
- Go module: google.golang.org/protobuf

# PHP 8.3 PECL MongoDB

> PHP MongoDB driver extension for PHP 8.3

## 简介

php83-pecl-mongodb 是 PHP 8.3 的 MongoDB 驱动扩展，提供与 MongoDB 数据库的连接和操作功能。支持连接池、事务、Change Stream 等现代 MongoDB 特性。

## OHOS 适配要点

- 使用 phpize + configure + make 标准编译流程，无需源码修改

## 依赖

| 依赖 | 版本 | 说明 |
|------|------|------|
| php83 | 8.3 | PHP 运行时 |

# perl-protocol-http2

## 软件描述

Protocol::HTTP2 — HTTP/2 协议实现 (RFC 7540)

纯 Perl 模块，提供 HTTP/2 协议的有状态编解码器，支持帧编解码、HPACK 头部压缩、流控制、连接管理等功能。可用于实现自定义的 HTTP/2 客户端、服务器或中间件。

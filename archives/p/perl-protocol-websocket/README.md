# perl-protocol-websocket

## 软件描述

Protocol::WebSocket — WebSocket 协议实现 (RFC 6455)

纯 Perl 模块，提供 WebSocket 协议的客户端/服务端帧编解码、握手解析与构造、URL 解析、Cookie 处理等功能。支持多种 WebSocket 协议版本（draft-ietf-hybi-17/10/00, draft-hixie-75）。可用于在 HTTP 服务器或客户端中集成 WebSocket 支持。

# pdf2json

PDF to JSON 和 XML 转换器，基于 XPDF 3.02。

## 基本信息
- 名称: pdf2json
- 版本: 0.71
- 描述: PDF 转 JSON/XML 格式转换器
- 许可证: GPL-2.0-only
- 构建系统: autotools
- 语言: C/C++
- 主页: https://github.com/flexpaper/pdf2json

- 依赖: 无外部依赖（内置 XPDF 3.02 库: Goo/fofi/splash/Xpdf）

## 功能特性
- 将 PDF 文件转换为 JSON 格式
- 将 PDF 文件转换为 XML 格式（-xml 参数）
- 支持压缩输出模式（-compress 参数）
- 支持忽略图片（-i 参数）
- 支持指定页范围（-f/-l 参数）
- 支持加密 PDF 文件（-opw/-upw 参数）
- 支持隐藏文本输出（-hidden 参数）
- 支持分页输出（-split 参数）
- 支持指定编码（-enc 参数）

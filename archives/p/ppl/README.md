# ppl

**Parma Polyhedra Library — 凸多面体等数值抽象库 — 约束↔生成元双描述转换、MIP 求解、格点与同余网格**

## 库

- `libppl.so`
- `libppl_c.so`

## 构建

- 构建系统：autotools
- 许可证：GPL-3.0-or-later
- 上游：https://www.bugseng.com/ppl

## 依赖

- `gmp/6.3.0.1`

## 版本

| 版本 | 状态 | 说明 |
|---|---|---|
| 1.2 | built | 首个鸿蒙 PC conan 配方 |

## 为什么做这个包

passagemath（SageMath 的模块化重打包）在鸿蒙 PC 上的 wheel 需要它作为原生底座。

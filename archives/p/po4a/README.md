# po4a

**po4a (PO for anything)** - Maintain the translations of your documentation with ease.

## Description

po4a is a tool to ease the translation of documentation and other content. It extracts the translatable content from the original document, places it into a PO file that is easily handled by translators, and then injects the translations back into the document structure to generate a translated document.

## Supported formats

po4a supports multiple documentation formats:
- POD (Perl documentation)
- man pages
- AsciiDoc
- Dia diagrams
- Guide (GNOME help format)
- LaTeX
- SGML
- TeXinfo
- Text
- XML/DocBook
- YAML
- INI files
- And more...

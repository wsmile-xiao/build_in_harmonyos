# PicoLisp

PicoLisp 是一个简洁高效的 Lisp 编程语言，专为实用性和速度设计。

## 特性
- 简洁的语法和数据结构
- 内置数据库支持
- 高性能（使用 LLVM 后端）
- 适用于 Web 应用和数据处理

## 版本
- 26.3: 当前编译版本

## 依赖
- readline: 交互式输入支持
- libffi: 外部函数接口
- openssl: SSL/TLS 支持
- LLVM: 编译后端

## 使用
```bash
pil  # 启动 REPL
(+ 1 2 3)  # 返回 6
(bye)  # 退出
```

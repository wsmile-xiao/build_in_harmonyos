## 编译步骤

podlators 使用 Perl 的 ExtUtils::MakeMaker 构建系统，不是标准的 autotools。

```bash
# 1. 初始化
cd /storage/Users/currentUser/tmp/builds/pod2man-6.0.2.work
perl Makefile.PL INSTALL_BASE=/storage/Users/currentUser/usr/local

# 2. 构建
make -j1

# 3. 测试
make test
# 结果: PASS (31 个测试文件，391 个测试用例)

# 4. 安装到 staging 目录
make install DESTDIR=/storage/Users/currentUser/tmp/test-install-pod2man-6.0.2

# 5. 安装到本地
make install
```

## 遇到的问题与解决方案

| # | 问题 | 根因 | 解决方案 |
|---|------|------|----------|
| 1 | 源码包名称不同 | pod2man 实际是 podlators 软件包 | 使用正确的 URL: podlators-v6.0.2.tar.xz |
| 2 | 构建系统识别错误 | init-build 自动识别为 autotools | 实际是 ExtUtils::MakeMaker，需要使用 perl Makefile.PL |
| 3 | 质量门禁 G4 失败 | pod2man 是 Perl 脚本，不是 ELF 二进制 | 这是正常情况，跳过 ELF 签名等步骤 |

## 注意事项

1. pod2man 是 Perl 文档生成工具，不是编译的二进制文件
2. 使用 ExtUtils::MakeMaker 构建系统，需要 Perl 环境
3. 质量门禁 G4 会报告"无二进制文件"，这是正常情况
4. 不需要 ELF 签名、RPATH 设置、strip debug 符号等步骤

# pgpdump

PGP packet visualizer — a tool to dump and visualize the structure of PGP packets.

- **Homepage**: https://github.com/kazu-yamamoto/pgpdump
- **License**: BSD-2-Clause
- **Version**: 0.37

## Description

pgpdump is a PGP packet visualizer which displays the structure of PGP files (keys, signatures, etc). It supports:
- PGP 2.x keys
- OpenPGP keys (RFC 4880)
- OpenPGP signatures
- OpenPGP encrypted data

## Dependencies

- zlib (compression support)

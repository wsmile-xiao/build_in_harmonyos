# php-pecl-memcache

PHP PECL memcache extension for interacting with memcached servers via the memcache protocol.

- **Homepage**: https://pecl.php.net/package/memcache
- **Source**: https://pecl.php.net/get/memcache-8.2.tgz
- **Version**: 8.2
- **Build system**: phpize (PHP extension build system)
- **Dependencies**: PHP 8.5+, zlib
- **Status**: Published for HarmonyOS aarch64

## Notes

- This extension requires PHP with session support for the memcache session handler
- Built against PHP 8.5 API (Zend Module API No: 20250925)

# pg_dump

PostgreSQL database dump utility. Part of the PostgreSQL source tree.

Provides:
- `pg_dump` — extract a PostgreSQL database into a script file or other archive
- `pg_dumpall` — extract a PostgreSQL database cluster into a script file
- `pg_restore` — restore a PostgreSQL database from an archive created by pg_dump
- `pg_config` — get information about the installed version of PostgreSQL
- `libpq` — PostgreSQL client library

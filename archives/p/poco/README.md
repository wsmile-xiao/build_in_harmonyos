# poco

POCO C++ Libraries - a collection of C++ class libraries for building network- and internet-based applications.

## Key Features
- Foundation: Core C++ framework (threading, file system, logging, etc.)
- Net: HTTP, FTP, SMTP, and other network protocols
- NetSSL: SSL/TLS network support (OpenSSL)
- Crypto: Cryptographic operations
- Data: Database access framework (SQLite, MySQL)
- XML, JSON: Data serialization
- Util: Application framework and configuration
- MongoDB, Redis: Database clients

## Available Versions
- 1.14.2 (built)

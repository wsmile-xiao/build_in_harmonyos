# plocate

`plocate` is a fast `locate(1)` implementation based on posting lists —
much faster than mlocate with a smaller index. Meson + C++17, zstd-compressed
database, optional io_uring I/O (not usable under HongMeng's seccomp policy;
see the version notes).

# pbc-sig

The PBC_sig library — C library providing implementations of various pairing-based signature schemes:

- Boneh-Boyen signatures
- Boneh-Boyen-Shacham group signatures
- Boneh-Lynn-Shacham signatures
- Cha-Cheon identity-based signatures

Requires the PBC library (http://crypto.stanford.edu/pbc/).

# pan

Pan is a Usenet newsreader: a GTK3 GUI application for reading/posting to
NNTP news servers, with a headless nzb batch mode (`pan --no-gui file.nzb`).

## Description

- C++17 application (107 .cc + 15 .c files), GTK3 GUI
- Message parsing/encoding via GMime 3
- Article yEnc/uudecode via bundled uulib
- Build system: CMake (min 3.25, migrated in 0.165)

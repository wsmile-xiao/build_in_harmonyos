# NcFTP

A set of free application programs implementing FTP.

## Description

NcFTP is a set of free application programs implementing the File Transfer Protocol (FTP). It includes:
- ncftp: The main FTP client program
- ncftpget: A utility for downloading files via FTP
- ncftpput: A utility for uploading files via FTP
- ncftpls: A utility for listing remote directories via FTP
- ncftpbatch: A batch FTP processing utility
- ncftpbookmarks: A bookmark editor for NcFTP

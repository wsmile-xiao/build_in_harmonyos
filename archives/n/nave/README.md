# Nave — Virtual environments for Node.js

nave is a bash script that manages Node.js versions, similar to nvm.
It creates isolated environments with different Node.js versions.

## Upstream
- Homepage: https://github.com/isaacs/nave
- Version: 3.5.6
- License: BlueOak-1.0.0

## Dependencies
- bash (runtime)

## Usage
```bash
nave install 18.13.0
nave use 18.13.0
nave ls
```

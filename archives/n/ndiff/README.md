# ndiff

## 简介

ndiff 是一个数值比较工具，用于比较包含数值数据的文件，并报告数值差异及其相对误差。它可以精确检测浮点数的变化，适用于科学计算和工程数据验证场景。

**注意**: ndiff 是独立的数值比较工具（由 University of Utah 开发），不是 nmap 的一部分。虽然某些系统将 "ndiff" 作为 nmap 的虚拟包提供，但本软件是原版的数值比较工具。

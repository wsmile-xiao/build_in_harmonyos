# nethogs — 按进程分组的网络带宽监控工具

nethogs 是一个小型"网络 top"工具，按进程分组显示带宽使用情况，而非按协议或子网拆分流量。它不依赖特殊的内核模块即可工作。

## 功能特点

- 按进程显示带宽使用量（发送/接收）
- 支持 IPv4 和 IPv6
- 支持多种视图模式：kB/s、总 kB、总字节、总 MB、MB/s、GB/s
- 支持跟踪模式和 promiscuous 模式
- 交互式界面：按键排序、切换视图、显示命令行
- 需要网络抃包权限（root 或 capabilities）

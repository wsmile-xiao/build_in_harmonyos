# noPoll

## 简介

noPoll 是一个纯 C 实现的 WebSocket 工具库（RFC 6455），提供客户端与服务端 API，支持 TLS（OpenSSL）加密连接、流式发送、帧分段处理、cookie/子协议协商等完整 WebSocket 语义。由 Advanced Software Production Line (ASPL) 开发维护，LGPL-2.1 许可。

- 上游官方站点：https://www.aspl.es/nopoll
- GitHub 仓库：https://github.com/ASPLes/nopoll

## 版本信息

- 当前归档版本: 0.4.9.b462（2024-10-22 官网发布，GitHub tag 0.4.9 同源代码）
- 构建系统: autotools
- 依赖: openssl/3.5.6

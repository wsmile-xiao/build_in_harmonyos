# nauty

nauty（No AUTomorphisms, Yes?）是一个用于计算图和有向图自同构群的程序，还可以生成规范标号。

## 可用版本

- 2.9.3（已发布）

## 软件描述

nauty 计算图的自同构群和规范形式。它包含以下工具：
- dreadnaut：交互式命令行界面
- geng：生成给定阶数的所有图
- genbg：生成所有二部图
- shortg：计算规范形式
- labelg：计算规范标号
- 多种库变体（libnauty、libnautyS、libnautyW、libnautyL、libnautyQ）

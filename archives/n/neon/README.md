# neon

HTTP and WebDAV client library with a C interface.

neon is an HTTP and WebDAV client library, with a C interface. It provides
a high-level interface to HTTP and WebDAV operations, supporting SSL/TLS
via OpenSSL, XML parsing via expat or libxml2, and various authentication
methods.

## Features

- HTTP/1.1 and WebDAV protocol support
- SSL/TLS via OpenSSL
- XML parsing (expat or libxml2)
- Basic, Digest, and Negotiate authentication
- Proxy support
- Persistent connections

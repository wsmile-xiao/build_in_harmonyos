# nanoarrow

Helpers for Arrow C Data, C Stream and C Device interfaces — Apache nanoarrow C 库，
为生产与消费 Arrow 列式数据提供轻量高质的 C/C++ 辅助函数。

- 官方仓库: https://github.com/apache/arrow-nanoarrow
- 许可: Apache-2.0
- 形态: CMake 库（`nanoarrow::nanoarrow`，静态默认；可选 `nanoarrow_ipc`）

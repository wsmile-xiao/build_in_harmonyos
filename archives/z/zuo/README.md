# zuo

Zuo: A Tiny Racket for Scripting — 一个极小Scheme/Racket方言解释器，内置文件与进程原语和类 make 的构建 DSL，被 Racket 自举构建使用。

- 上游仓库: https://github.com/racket/zuo
- 许可证: Apache-2.0 OR MIT
- 分类: build-tool
- 产物: `bin/zuo`（命令行工具）+ `lib/zuo/*.zuo`（运行时模块库）

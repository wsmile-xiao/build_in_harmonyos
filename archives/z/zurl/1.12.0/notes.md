# zurl 1.12.0 适配笔记

## 软件身份

- **软件名**: zurl 1.12.0 = fanout/zurl（HTTP/WebSocket client worker，ZeroMQ 接口）
- **上游仓库**: https://github.com/fanout/zurl（tag v1.12.0，2023-10-23，commit 9e773b3）
- **类型**: Qt5 控制台守护进程（TEMPLATE=app），基于 libzmq + libcurl + QtNetwork；非库
- **状态**: built（配方完成，待 HMBS 真机预检：conan create + 上游测试 + test_package）
- **适配路径**: 路径 A（基础适配）

## 编译环境

- 构建系统: qmake（qconf 生成的 configure 封装，`./configure --qtselect=5 && make`，in-source build）
- 编译器: clang 15 / clang++（OHOS aarch64，`QMAKESPEC=linux-clang`，baka 先例）
- Profile: ohos-aarch64，`tools.build:jobs`（hmbs 注入 1；E074 jobserver 教训）
- 并发: `make -j${jobs}` + `QMAKE_STRIP=""`（OHOS 加载器拒绝 stripped ELF，baka 先例）

## 源码结构与关键发现（源码审计结论）

- `zurl.pro` 为 subdirs：`src/libzurl`（内部静态库，无安装规则）→ `src/zurl`（守护进程，`target.path=BINDIR`）→ `tests`（`no_default_install`，随 make 默认构建）。
- GitHub tag 归档中 `src/qzmq/`、`src/common/` 为**空目录**（子模块不随归档发布）；`.pro` 经 `src.pri` 直接引用二者源码 → 必须 vendor：
  `src/qzmq <- jkarneges/qzmq@3ffbcf4`，`src/common <- fanout/common@0fdb3b9`（v1.12.0 gitlink，ableton-link 先例）。
- configure 是 qconf 2.0 生成脚本：编译 `conf` 探测器（需 qmake+moc），依次检查 Qt>=5.2（必需）、libzmq>=2.0（必需）、openssl（可选）、libcurl>=7.49（必需），生成 `conf.pri` 后对 `zurl.pro` 跑 qmake。qmake 发现经 `--qtdir` 直指依赖包，不依赖 PATH 隐式查找。
- HAVE_OPENSSL 控制 https/wss 相关代码（verifyhost/openssl 引用）；curl 传递依赖已含 openssl/3.5.6.1，保持开启以保留完整功能。
- `zurl --version` 打印 `Zurl 1.12.0` 后干净退出（L2 smoke 天然通过；test_package 第一用例）。

## 上游测试情况（真机实测 Totals，非源码函数估算）

- `tests/httprequesttest/`：QtTest，本地 QTcpServer 回环测试 HttpRequest（GET/POST/HEAD/DELETE、chunked、204/304、DNS/连接错误），真机实测 **Totals 16 passed**（源码函数清点 14 为低估，Totals 含数据行展开，以执行证据为准）。
- `tests/websockettest/`：QtTest，本地 QTcpServer 回环测试 WebSocket 握手（成功/拒绝/分片失败模式），真机实测 **Totals 9 passed**（源码函数清点 7 为低估，同上）。
- 合计 **25 个测试（16+9）/ 2 个测试二进制**，全部本地回环、离线可跑（仅 `requestDnsError` 依赖 `nosuchhost` 解析失败，离线环境同样成立）。
- 配方 `_run_upstream_tests` 解析 QtTest `Totals: N passed, M failed, K skipped` 行：`discovered=N+M+K`，`executed=N+M`；MANIFEST `upstream_test_total: 25` 与该口径一致（单一可解析框架，`upstream_test_count_method: auto`）。
- 执行结论（执行数/通过数/通过率）以真机预检日志为准，见 PR 正文「验证结果」。

## test_package（消费者视角，4 检查点）

`test_package/test_zurl.sh`（POSIX sh，conanrun 环境，绝对路径调用包内二进制）：

1. `zurl --version` 输出 `Zurl 1.12.0`（二进制可运行、版本正确）。
2. arm64 ELF 断言（baka 式静态冒烟）。
3. conanrun 环境 ldd 无 `not found`（动态依赖可解析）。
4. tcp 回环配置启动 daemon：日志出现 `started`，SIGTERM 后干净退出（`stopped`），验证 Qt/zmq/curl 运行时链真实可用（不用 ipc：HMBS TMPDIR 前缀使 unix socket 路径约 108 字符超限，bind 失败）。
5. 脚本按实际结果输出 `HMBS_TEST_PACKAGE_RESULT`（discovered/passedCount 为真实计数，共 4 个检查点），任一失败即非零退出。

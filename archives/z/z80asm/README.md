# z80asm

## 软件描述

z80asm 是一个 Zilog Z80 微处理器的汇编器，由 Bas Wijnen (shevek) 开发。

它支持标准 Z80 指令集，能够将 Z80 汇编源码（.asm 文件）编译为机器码二进制文件（.bin）。
同时支持包含文件、标签和表达式等功能。

## 软件信息

- **官网**: https://savannah.nongnu.org/projects/z80asm/
- **源码**: https://download.savannah.gnu.org/releases/z80asm/
- **许可证**: GPL-3.0
- **构建系统**: Makefile
- **语言**: C
- **外部依赖**: 无（仅依赖系统 libc）

# highlight

**Universal source code to formatted text converter**

## Description

Highlight is a universal source code to formatted text converter. It converts source code to HTML, XHTML, RTF, ODT, LaTeX, TeX, SVG, BBCode, ANSI escape sequences, and XML formats with syntax highlighting.

## Features

- Supports 200+ programming languages and file formats
- Multiple output formats (HTML, RTF, LaTeX, etc.)
- Customizable syntax highlighting themes
- Built-in CSS support for HTML output
- Plugins for various integration scenarios
- LSP client support

## Installation

```bash
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- highlight 4.18
```

## Usage

```bash
highlight --version
highlight -S python -o output.html input.py
```

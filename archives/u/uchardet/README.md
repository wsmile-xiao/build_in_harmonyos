# uchardet

uchardet is a charset detection library, which takes a sequence of bytes in an unknown character encoding and attempts to determine the encoding of the text.

## Description

uchardet is a C language binding of the charset detection library from Mozilla. It detects the character encoding of a text file or byte sequence.

## Features

- Detects character encoding automatically
- Supports a wide range of encodings including UTF-8, UTF-16, UTF-32, ISO-8859 series, Windows codepages, EUC-JP, EUC-KR, GB18030, Big5, Shift_JIS, and many more
- Provides both shared and static library
- Includes command-line tool for charset detection

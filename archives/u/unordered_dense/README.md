# unordered_dense

A fast & densely stored hashmap and hashset based on robin-hood backward shift deletion.

- **上游仓库**: https://github.com/martinus/unordered_dense
- **License**: MIT
- **构建系统**: CMake（上游 INTERFACE target `unordered_dense`）/ meson（上游测试）
- **类型**: Header-only C++17 库（INTERFACE target，无 .a/.so 产物）
- **无外部依赖**
- **公开头文件**: `include/ankerl/unordered_dense.h`、`include/ankerl/stl.h`

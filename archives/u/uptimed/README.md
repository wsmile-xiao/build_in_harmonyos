# uptimed

Utility to track your highest uptimes.

## 描述

uptimed 是一个用于跟踪系统最高运行时间（uptime）记录的工具。它后台运行守护进程记录系统启动时间，并提供 `uprecords` 命令查看历史记录。

## 版本

- 0.4.7（当前归档版本）

## 构建系统

autotools（configure.ac + autogen.sh + make）

## 依赖

无外部依赖，仅需标准 C 库。

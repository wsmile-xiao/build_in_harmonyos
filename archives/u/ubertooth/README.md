# ubertooth

Ubertooth is an open source Bluetooth experimentation and development tool.

## Features
- Bluetooth sniffing and analysis
- Bluetooth baseband decoding (with libbtbb)
- Hardware interface via USB

## Dependencies
- libbtbb >= 2020-12-R1
- libusb-1.0 >= 1.0.27
- libpcap >= 1.10.6 (optional)

## Tools Included
- ubertooth-util: Utility functions
- ubertooth-rx: Bluetooth sniffing tool
- ubertooth-dump: Raw Bluetooth symbol stream dump
- ubertooth-specan: Spectrum analyzer output

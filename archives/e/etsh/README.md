# etsh

etsh is an enhanced, backward-compatible port of the V6 Thompson shell
(/bin/sh from the 1975 Sixth Edition UNIX). It produces CLI executables:
etsh, tsh, glob, fd2, goto, if.

## Features

- V6 Thompson shell enhanced port (etsh)
- V6 Thompson shell original port (tsh)
- glob — pattern expansion utility
- fd2 — file descriptor 2 redirection utility
- goto — label jump utility
- if — conditional execution utility

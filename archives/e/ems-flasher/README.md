# ems-flasher

Tool to flash EMS Gameboy USB 64Mbit flash cartridges.

## Description

ems-flasher is a command-line utility for reading from and writing to the
EMS 64 Mbit USB flash cartridge (a Game Boy flash cart). It uses libusb 1.0
to communicate with the USB device.

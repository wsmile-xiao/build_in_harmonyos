# espeak-ng

espeak-ng 是一个开源的语音合成引擎，支持多种语言和语音。

## 描述

eSpeak NG 是一个紧凑的开源软件语音合成引擎，适用于英语和其他语言。它使用"共振峰合成"方法，允许在较小的空间中提供多种语言。这使其适用于嵌入式系统和小型设备。

## 主要特性

- 支持 100+ 种语言和方言
- 紧凑的代码体积，适合嵌入式系统
- SSML（Speech Synthesis Markup Language）支持
- 可调节的语速、音量和音调
- 多种语音风格

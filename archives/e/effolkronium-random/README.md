# effolkronium-random

Random for modern C++ with a convenient API.

- **上游仓库**: https://github.com/effolkronium/random
- **License**: MIT
- **构建系统**: CMake（上游 INTERFACE target `effolkronium_random`）
- **类型**: Header-only C++11 库（INTERFACE target，无 .a/.so 产物）
- **无外部依赖**
- **公开头文件**: `include/effolkronium/random.hpp`

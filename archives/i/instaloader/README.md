# instaloader

Instaloader is a pure-Python command-line tool and library for downloading Instagram pictures, videos, captions, and metadata.

- Upstream: https://github.com/instaloader/instaloader
- Documentation: https://instaloader.github.io/
- License: MIT
- Conan package: `instaloader/4.15.1`
- Runtime: Python >= 3.9 and `requests >= 2.25`

The package is installed under a private Python site-packages directory and exposes the `instaloader` command. The optional `browser-cookie3` extra is intentionally not installed by the base package.

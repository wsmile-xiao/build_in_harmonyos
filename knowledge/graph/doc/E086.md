# E086: struct ucred 在 musl/OpenHarmony 上不可用

## 问题

编译使用 Unix socket 对端凭证的软件（如 libassuan）时报错：

```
error: invalid use of incomplete type 'struct ucred'
error: storage size of 'ucred' isn't known
error: 'struct ucred' undeclared
```

部分软件使用 `struct ucred` 获取 Unix socket 对端凭证（SO_PEERCRED）。

## 根因

OpenHarmony 的 musl libc 不定义 `struct ucred`（该结构定义在 Linux glibc 的
`<sys/socket.h>` 中）。musl 下需条件编译或内联定义 struct ucred。

## 解决方案

### 即时修复

使用 `#ifdef __OHOS__` 守卫，在 __OHOS__ 下内联定义 struct ucred：

```bash
sed -i '/struct ucred/i #ifdef __OHOS__\nstruct ucred { pid_t pid; uid_t uid; gid_t gid; };\n#endif' src/socket-server.c
```

或使用 #ifdef 封装 SO_PEERCRED 相关代码块。

### 备选方案

使用 `--disable-local-socket` 或类似选项禁用 peer credential 功能：

```bash
./configure --prefix=$DEFAULT_PREFIX --disable-local-socket
```

### 影响范围

libassuan 及所有使用 SO_PEERCRED 的软件。

# E087: HMDFS 上文件无执行权限

## 问题

在 HMDFS 文件系统上，Makefile 中直接执行脚本文件失败：

```
./gpg-error-config-test.sh: Permission denied
./script.sh: Permission denied
cannot execute: Permission denied
```

用 `sh ./script.sh` 则可以正常运行。

## 根因

HMDFS 文件系统上 chmod 操作不生效（UID 映射限制），导致新生成的 shell 脚本文件
没有执行权限（0600 而非 0755）。Makefile 中 `./script.sh` 直接执行会报 Permission denied。

## 解决方案

### 即时修复

将 Makefile 中的 `./script.sh` 改为 `sh ./script.sh`，绕过执行权限限制：

```bash
sed -i 's|\./\([^ ]*\.sh\)|sh ./\1|g' Makefile
```

### 备选方案

在 Makefile 中将脚本安装命令从 `cp` 改为 `install -c -m 755`：

```bash
sed -i 's|cp \(.*\.sh\)|install -c -m 755 \1|g' Makefile
```

### 影响范围

所有在 HMDFS 上生成的 shell 脚本（libgpg-error, libtasn1 等）。

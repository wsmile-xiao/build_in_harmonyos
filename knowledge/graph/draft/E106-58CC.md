# E106: HMDFS临时文件创建限制

## 问题现象

编译autotools项目时遇到：
```bash
./config.status[829]: can't create ./confXXXXXX/subs1.awk: Permission denied
```

## 根因

HMDFS (HarmonyOS Distributed File System) 的安全隔离机制阻止在当前目录创建的临时子目录中写入文件。这是分布式文件系统的安全特性，防止跨设备恶意文件注入。

## 解决方案

### 已实施：mktemp wrapper
```bash
# ~/usr/local/bin/mktemp - HMDFS下自动重定向到$TMPDIR
```
效果：解决configure阶段
局限：config.status内部仍有深层限制

### 推荐：在$TMPDIR下编译
修改ohc-run.py使用VPATH构建模式：
```bash
cd $TMPDIR
$BUILD_SRC_DIR/configure --srcdir=$BUILD_SRC_DIR
```

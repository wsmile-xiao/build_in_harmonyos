# E112 — HarmonyOS clang++ 链接器无法找到 libc++/libc++abi

## 错误特征

CMake 配置阶段，C++ 编译器测试失败，报错：
```
The CXX compiler identification is unknown
is not able to compile a simple test program
unable to find library -lc++
unable to find library -lc++abi
```

## 触发条件
- 构建系统: CMake
- 阶段: configuration (cmake try_compile)
- 平台: HarmonyOS
- 影响范围: 所有需要 C++ 链接的 CMake 项目（特别是 header-only 库，编译器测试不需要实际链接）

## 根因分析

HarmonyOS clang++ 的默认链接器配置无法在标准搜索路径中找到 `libc++` 和 `libc++abi` 共享库。这些库位于 OHOS SDK 的 `llvm/lib/aarch64-linux-ohos/` 目录下，但不在默认链接器搜索路径中。

## 解决方案

### 推荐方案

对于 header-only 库或不需要实际链接的 CMake 项目，使用 `-DCMAKE_TRY_COMPILE_TARGET_TYPE=STATIC_LIBRARY` 跳过可执行文件链接测试：

```bash
cmake .. -DCMAKE_TRY_COMPILE_TARGET_TYPE=STATIC_LIBRARY -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX
```

对于需要实际链接的库，创建 toolchain 文件指定 libc++ 路径：

```cmake
# ohos-toolchain.cmake
set(CXX_LIBCXX_LIB "${OHOS_SDK_ROOT}/llvm/lib/aarch64-linux-ohos")
set(CMAKE_EXE_LINKER_FLAGS "${CMAKE_EXE_LINKER_FLAGS} -L${CXX_LIBCXX_LIB}")
set(CMAKE_SHARED_LINKER_FLAGS "${CMAKE_SHARED_LINKER_FLAGS} -L${CXX_LIBCXX_LIB}")
```

### 禁止做法
- ❌ 不要用 `-DCMAKE_CXX_COMPILER=g++` 切换编译器
- ❌ 不要手动创建假的 libc++ 符号链接

## 验证
```bash
# 验证方案1 (header-only)
cmake .. -DCMAKE_TRY_COMPILE_TARGET_TYPE=STATIC_LIBRARY && echo "PASS"

# 验证方案2 (需要链接)
cmake .. -DCMAKE_TOOLCHAIN_FILE=ohos-toolchain.cmake && make && echo "PASS"
```

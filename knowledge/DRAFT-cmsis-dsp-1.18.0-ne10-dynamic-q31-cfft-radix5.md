# NE10 动态 Q31 CFFT 因子5 尺寸在本工具链下输出错误/段错误

- **草稿 ID**: DRAFT-cmsis-dsp-1.18.0-ne10-dynamic-q31-cfft-radix5
- **来源**: cmsis-dsp 1.18.0 R02 返工（NEON 配置全量实例化）
- **分类**: DSP / FFT / NEON / toolchain / runtime / testing / aarch64 / OHOS
- **状态**: 本地草稿（挂路径 B 知识库扩展 PR，与 cmsis-dsp 归档同 PR 交付）

## 问题 / 错误签名

- **错误输出**（NEON 配置测试运行）:
  ```
  E: SNR 5.80879 < 100
  E: SNR 24.1183 < 100
  ...（180 个，SNR 3.4~41.7 dB 均 <100）
  ```
- **独立复现**: 20 点动态 Q31 CFFT 直接段错误 `Signal 11 (core dumped)`。

## 复现与失败特征

- 套件: TransformNeonCQ31（NEON 复数 Q31 CFFT 动态实例），90 CFFT + 90 CIFFT
- **失败尺寸全部含因子 5**: 20, 40, 60, 80, 100, 120, 160, 180, 200, 240, 300, 320, 360, 400, 480
- **通过尺寸全部为 2/3 幂**: 24, 32, 36, 48, 64, 72, 96, 108, 128, 144（无因子 5）
- 失败/通过严格按"是否含因子 5"二分 → 指向 radix-5 蝶形路径

## 根因

1. `arm_cfft_init_dynamic_q31`（NE10 动态路径，仅 `ARM_MATH_NEON` 可用，
   `Include/dsp/transform_functions.h:380` 声明）对含因子 5 长度的蝶形分解/旋转因子
   生成在本工具链（clang 15.0.4 aarch64 OHOS）下不可靠。
2. 源码树无任何 radix5 实现文件；`nm libCMSISDSP.a | grep -c radix5` = 0 → 库无 radix-5 符号。
3. 独立最小复现（20 点动态 Q31 CFFT）段错误，测试框架内表现为 SNR 严重不符。

## 排除项（证据）

- **与注入宏无关**: R01 run1（无任何注入宏的 NEON 构建）与 R02 完全相同的 180 个失败与相同 SNR 值
  （5.80879 / 24.1183 / 5.31342 / 25.6025 / 3.92947 / 25.1685 / 26.1648 / 5.47007 / 22.3204 /
  24.1835 / 3.4482 / 26.4712 …）。
- **非参考数据缺失**: `Patterns/DSP/TransformNeon/TransformNeonQ31/ComplexFFTSamples_Noisy_20_1_q31.txt`
  等模式文件均存在且有效（82 行非空）。
- **非本库配方/补丁可修**: 属上游 NE10 实现与 clang 15 aarch64 的兼容性缺陷。

## 处理方案（执行端）

1. 如实计入双口径台账：NEON 配置 786 执行 / 606 通过 / 180 失败；全量口径 2437/2859（85.2%）。
2. 给出恢复条件: 上游修复 NE10 int32 蝶形因子5 路径，或改用支持因子5 的参考 FFT 实现 /
   更新工具链后重跑 desc_neon 配置。
3. 禁止: 伪造 SNR 通过 / 把失败写成未实例化 / 删除失败用例（审计失真）。

## 验证结果

| 环境 | 结果 |
|------|------|
| NEON 配置全量运行 | 786 执行 / 606 通过 / 180 失败（run-neon-r02.log，SHA-256 23705a60bd73819ec5fcdc1c0991d04ff1a8a209972fdb06f04caa63b5181cb1） |
| 独立 20 点动态 Q31 CFFT | Signal 11（段错误） |
| 通过尺寸（2/3 幂） | 全部通过（SNR ≥100） |

## 适用边界 / 反例

- 适用: aarch64 OHOS / clang 15 上 CMSIS-DSP NEON 动态 Q31 CFFT 因子 5 尺寸。
- 反例: 2/3 幂尺寸（24/32/36/48/64/72/96/108/128/144…）动态 Q31 CFFT 正常通过；
  F32/F16/Q15 NEON 套件（s1/s2/s4）全部通过，缺陷特定于 Q31 因子5 路径。

## 禁止策略

- ❌ 伪造 SNR 通过 / 把失败写成未实例化 / 删除失败用例。
- ❌ 把"参考模式生成受限"套用到本素材（本素材参考文件齐全，属实现缺陷）。

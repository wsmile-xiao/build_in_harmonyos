# E147: source-patch

## 基本信息
- **严重度**: 2
- **类别**: libc|compat|platform
- **触发工具**: cc|clang|configure|make
- **阶段**: compilation|configuration

## 错误特征
```
'CPU_SETSIZE' undeclared|'cpu_set_t' undeclared|'sched_getaffinity' undeclared|'sched_setaffinity' undeclared|'CPU_COUNT' undeclared|'CPU_ZERO' undeclared|'CPU_SET' undeclared|implicit declaration of function 'sched_getaffinity'|implicit declaration of function 'sched_setaffinity'
```

**关键词**: CPU_SETSIZE, cpu_set_t, sched_getaffinity, sched_setaffinity, CPU_COUNT, CPU_ZERO, CPU_SET, CPU affinity, undeclared, musl, __linux__, __OHOS__

## 根因分析
musl libc 未实现 Linux 特有的 CPU 亲和性 API (CPU_SETSIZE, cpu_set_t, sched_getaffinity, sched_setaffinity, CPU_COUNT 等)，这些 API 在 glibc 中存在但 OHOS 使用 musl

**影响范围**: 使用 CPU 亲和性的软件，如 libuv、nginx、redis、系统监控工具等

## 推荐方案
- **方法**: source-patch
- **描述**: 在 __linux__ 条件编译中排除 __OHOS__，使 OHOS 走替代路径
- **命令**: `sed -i 's/#ifdef __linux__/#if defined(__linux__) \&\& !defined(__OHOS__)/g' <file>`
- **自动修复**: true

## 验证
```bash
grep -r "sched_getaffinity\|sched_setaffinity\|cpu_set_t\|CPU_SETSIZE" --include="*.c" --include="*.h" .
```

# E147: source-patch

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, libc
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
'CPU_SETSIZE' undeclared|'cpu_set_t' undeclared|'sched_getaffinity' undeclared|'sched_setaffinity' undeclared|'CPU_COUNT' undeclared|'CPU_ZERO' undeclared|'CPU_SET' undeclared|implicit declaration of function 'sched_getaffinity'|implicit declaration of function 'sched_setaffinity'
```

## 根因分析
musl libc 未实现 Linux 特有的 CPU 亲和性 API (CPU_SETSIZE, cpu_set_t, sched_getaffinity, sched_setaffinity, CPU_COUNT 等)，这些 API 在 glibc 中存在但 OHOS 使用 musl

## 推荐方案
**方法**: source-patch

**说明**: 在 __linux__ 条件编译中排除 __OHOS__，使 OHOS 走替代路径

**验证/命令**:
```
sed -i 's/#ifdef __linux__/#if defined(__linux__) \&\& !defined(__OHOS__)/g' <file>
```

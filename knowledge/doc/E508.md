# E508: intl-wrapper

## 基本信息
- **严重度**: 3
- **类别**: platform, detection, linking
- **作者**: Gjy_joye <f25015203@st.sandau.edu.cn>
- **来源 PR**: !3807

## 错误特征
```
g_libintl_.*|undefined symbol.*g_libintl|host_machine.*harmonyos|implicit declaration.*dgettext
```

## 根因分析
glib libintl.h 将 gettext 宏定义为 g_libintl_*，OHOS musl
                        libintl.so 只导出 libintl_* 符号，glib 静态库引用 g_libintl_*
                        无定义 → 链接 undefined symbol；meson 报 host_machine=harmonyos
                        不匹配 'linux' 条件分支，Linux 特有链接器选项被跳过。

## 推荐方案
**方法**: intl-wrapper

**说明**: 创建 intl-wrapper.c 将 g_libintl_* 符号映射到返回 msgid 的
                        兜底实现（OHOS musl 单域），加入 meson.build 源文件列表，
                        并注入 -Ddgettext(a,b)=((char*)(b)) 避 int 转换；
                        同时 meson.build 的 host_machine.system() == 'linux' 改为
                        in ['linux', 'harmonyos'] 使 Linux 特有链接器选项生效。

**验证/命令**:
```
sed -i "s/if host_machine.system() == 'linux'/if host_machine.system() in ['linux', 'harmonyos']/g" meson.build && echo 'char *g_libintl_gettext(const char *m){return (char*)(m);}' > intl-wrapper.c
```

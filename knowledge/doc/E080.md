# E080: source-patch-try-except

## 错误特征
```
Permission denied.*symlink.*lib64|venv.*Permission denied|os.symlink.*Errno 13|ensure_directories.*link_path
```

## 根因分析
Python 3.9+ 的 venv.EnvBuilder.ensure_directories() 在 64 位 POSIX 系统上强制创建 `lib64 -> lib` 符号链接（Issue #21197）。
                        鸿蒙用户主目录 $HOME 挂载于 HMDFS，HMDFS 不支持符号链接创建（E050），导致 os.symlink() 抛出 OSError(13)。
                        venv 创建流程中断，虚拟环境无法生成。

## 推荐方案
**方法**: source-patch-try-except

**说明**: 在 Lib/venv/__init__.py 的 ensure_directories() 中对 os.symlink() 加 try/except，
                        except 分支用 os.makedirs() 替代 symlink（platlibdir 始终为 'lib'，lib64/ 永远不会被遍历）。

**验证/命令**:
```
|
      os.symlink('lib', link_path)
  except OSError:
      os.makedirs(link_path, exist_ok=True)
```

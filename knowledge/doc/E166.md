# E166: platform_limitation

## 基本信息
- **严重度**: 3
- **类别**: platform_limitation|selinux|hmdfs|go
- **触发工具**: go|link
- **阶段**: linking

## 错误特征
```
link: mapping output file failed: permission denied|Go build failed: link tool permission denied|fork/exec.*link.*permission denied
```

**关键词**: Go,link,permission denied,mapping output file,HMDFS,SELinux,Go build,link tool,ELF 签名

## 根因分析
HMDFS(鸿蒙分布式文件系统)的SELinux强制访问控制(MAC)策略限制了Go link工具的某些操作(如mmap、临时文件创建或文件映射)。即使Go工具链二进制文件已通过ELF签名,仍无法绕过SELinux系统级安全策略。

**影响范围**: 所有Go项目在HMDFS文件系统上的编译。受影响软件:pumba、任何使用go build的项目。

## 推荐方案
- **方法**: platform_limitation
- **描述**: Go link工具在HMDFS上遇到SELinux权限限制,无法正常工作。目前无即时解决方案,需等待鸿蒙系统更新SELinux策略或使用其他编译环境(非HMDFS)。建议记录为平台限制,不阻塞其他软件编译流程。
- **命令**: `无可行修复命令。建议: 1) 记录为平台限制(E046类似问题); 2) 在其他环境(非HMDFS)编译Go项目; 3) 等待鸿蒙系统SELinux策略更新`
- **自动修复**: false

## 验证
```bash
尝试编译任何Go项目(如go build -v ./cmd),观察是否出现"link: mapping output file failed: permission denied"错误。
```

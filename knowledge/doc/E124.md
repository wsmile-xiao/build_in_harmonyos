# E124: use-cgo-linker

## 基本信息
- **严重度**: 3
- **类别**: go-link-permission
- **触发工具**: go
- **阶段**: linking

## 错误特征
```
mapping output file failed: permission denied|link: mapping output file failed
```

**关键词**: go, link, mapping, permission denied, output file

## 根因分析
Go link 工具尝试 mmap 输出文件时被 SELinux 或安全策略拒绝

**影响范围**: Go 语言项目编译（需要 Go 1.25+ 的项目）

## 推荐方案
- **方法**: use-cgo-linker
- **描述**: 启用 CGO 使用系统链接器替代 Go link 工具
- **命令**: `export CGO_ENABLED=1 && export CC=clang && go build -v -o bin/${NAME} ${PKG}`
- **自动修复**: false

## 验证
```bash
export CGO_ENABLED=1 && go build -v 2>&1 | grep "mapping output file"
```

## 错误特征
```
mapping output file failed: permission denied|link: mapping output file failed
```

## 根因分析
Go link 工具尝试 mmap 输出文件时被 SELinux 或安全策略拒绝

## 推荐方案
**方法**: use-cgo-linker

**说明**: 启用 CGO 使用系统链接器替代 Go link 工具

**验证/命令**:
```
export CGO_ENABLED=1 && export CC=clang && go build -v -o bin/${NAME} ${PKG}
```

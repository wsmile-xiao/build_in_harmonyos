## 错误特征
```
use of undeclared identifier 'euidaccess'|error: 'euidaccess' was not declared|undefined reference to 'euidaccess'
```

## 根因分析
OpenHarmony 使用 eaccess 函数替代 GNU 的 euidaccess 函数。
                        euidaccess 是 GNU 扩展，用于检查有效用户 ID 的文件访问权限，
                        而 OpenHarmony 的 unistd.h 中只定义了 eaccess 函数（OHOS API 12+）。
                        需要修改源码将 euidaccess 替换为 eaccess。

## 推荐方案
**方法**: source-code-patch

**说明**: 修改源码，将 euidaccess 替换为 eaccess

**验证/命令**:
```
sed -i 's/euidaccess/eaccess/g' source.cpp
```

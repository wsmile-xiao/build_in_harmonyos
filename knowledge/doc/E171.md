# E171: source-code-patch

## 基本信息
- **严重度**: 3
- **类别**: api-difference|platform-adaptation
- **触发工具**: clang++|clang|gcc|g++
- **阶段**: compilation

## 错误特征
```
use of undeclared identifier 'euidaccess'|error: 'euidaccess' was not declared|undefined reference to 'euidaccess'
```

**关键词**: euidaccess, undeclared identifier, eaccess, unistd.h, OpenHarmony, permission check

## 根因分析
OpenHarmony 使用 eaccess 函数替代 GNU 的 euidaccess 函数。

**影响范围**: 使用 GNU euidaccess 函数的项目（如 incron）

## 推荐方案
- **方法**: source-code-patch
- **描述**: 修改源码，将 euidaccess 替换为 eaccess
- **命令**: `sed -i 's/euidaccess/eaccess/g' source.cpp`
- **自动修复**: true

## 验证
```bash
grep -r "euidaccess" *.cpp *.c 2>/dev/null && echo "Found euidaccess usage" || echo "No euidaccess found"
```

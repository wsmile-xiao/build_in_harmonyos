# E232: Prefix Conan Autotools configure with the native OHOS shell

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, autotools, conan
- **作者**: 2301_80739235 <goblinrs@yeah.net>
- **来源 PR**: source_commit:

## 错误特征
```
/system/bin/sh: .*configure: Permission denied|Error in build\(\) method.*autotools\.configure|ConanException: Error 126 while executing
```

## 根因分析
Conan Autotools.configure emits the source configure path as the first process. CONFIG_SHELL only affects shells started later by Autoconf, so it cannot wrap that initial launch when the native OHOS build executor cannot execute the source script directly.

## 推荐方案
**方法**: native-ohos-shell-prefix

**说明**: Only when settings_build.os is OHOS, invoke /system/bin/sh with the official configure path and the exact arguments generated by Conan. Keep all other build executors on Autotools.configure(), even when settings.os is OHOS.

**验证/命令**:
```
if settings_build.os is OHOS, run /system/bin/sh with the source configure path and autotools._configure_args; otherwise call autotools.configure()
```

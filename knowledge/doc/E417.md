# E417: 图像库按官方 CI 变体声明上游格式覆盖（Autotools CI 口径 AVIF=0/JXL=0）

## 错误特征
```
Format AVIF is not supported|Format JXL is not supported|SKIP: Recognising TGA by magic number is not supported|Assert Summary: Total=742
```

## 根因分析
图像库上游测试按 CI 变体声明格式覆盖：SDL_image 2.6.0 test/main.c formats[] 共 21 条目，LBM/XV 为 #if 0 → 19 个有效格式；官方 CI main.yml 分变体（Autotools 变体 AVIF=0、JXL=0；CMake 变体 JXL=1），本配方按 Autotools 变体构建（AVIF/JXL 后端不编译）。testimage 遍历 19 格式：17 行 "Testing ability to load format" + AVIF/JXL 两处 "Format ... is not supported"；TGA "SKIP:" 是 SDLTest_Log 信息日志（main.c 925 行），非测试跳过。

## 推荐方案
**方法**: declare-format-coverage-by-ci-variant

**说明**: PR/MANIFEST 按官方 Autotools CI 变体口径如实声明：formats[] 21-2(#if0)=19 有效格式、17 主动加载 + AVIF/JXL 按 "not supported" 报告、TGA "SKIP:" 为 SDLTest_Log 信息日志非测试跳过、断言 742/742、Skipped=0。不得把"不支持"写成"跳过"或夸大覆盖数。

**验证/命令**:
```
ctest --output-on-failure（build() 内 testimage）
```

# E546: OHOS 无 gusb/gudev/libudev：meson required:false 解耦 + HAVE_LIBUDEV 配置宏守卫（R8 禁 __OHOS__ 平台宏）

## 基本信息
- **严重度**: 2
- **类别**: portability, ohos, build-system
- **来源事件**: libcolord 1.4.8 HarmonyOS 适配
- **提升日期**: 2026-10-01

## 错误特征
```
dependency .*libudev.*not found|dependency .*gudev.*not found|dependency .*gusb.*not found|libudev\.h.*No such file|cd-edid.*udev
```

## 根因分析
OHOS 无 gusb/gudev/libudev（制品仓未发布且系统无），meson 默认 required 依赖在 configure 阶段直接失败；需 required:false 使其可选，并用配置宏 HAVE_LIBUDEV（而非 __OHOS__ 平台宏，符合 R8）守卫 <libudev.h> include 与 hwdb 查找逻辑，非 OHOS 平台保持原行为。

## 推荐方案
**方法**: config-macro-guard-for-optional-deps

未发布的平台可选依赖用 meson required:false 解耦，平台特定代码用配置宏（HAVE_XXX）而非平台宏守卫，保留非 OHOS 兼容性（R8）

## 实施记录（libcolord 1.4.8）
详见 archives/l/libcolord/1.4.8/notes.md 与 reports/test-report.md。

## 验证
```bash
meson configure -Ddaemon=false -Dtests=false build/ && grep -n HAVE_LIBUDEV lib/colord/cd-edid.c
```

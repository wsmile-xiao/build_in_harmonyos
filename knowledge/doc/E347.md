# E347: GitLab 418 拦截 conan/urllib 源码下载（反爬）

## 基本信息
- **严重度**: 2
- **类别**: network, download, source
- **作者**: xioaxin <3990149441@qq.com>
- **来源 PR**: !5243

## 错误特征
```
GitLab 418 I'm a teapot on conan/urllib source download
```

## 根因分析
gitlab.alpinelinux.org blocks non-curl User-Agents (ohc/1.0, Conan/2.x, Mozilla/5.0) with HTTP 418

## 推荐方案
**方法**: Pre-seed conan source download cache (core.sources:download_cache, keyed by sha256) with a curl-downloaded tarball before conan create; gitlab URLs are official R39 source, cache bypasses the anti-bot 418

**说明**: 用 curl 预下载 tarball，按 sha256 命名放入 conan sources download cache，绕过 gitlab 反爬 418

**验证/命令**:
```
mkdir -p $CONAN_CACHE/s/<sha256> && curl -fsSL <url> -o $CONAN_CACHE/s/<sha256>/file && 生成 .json 元数据
```

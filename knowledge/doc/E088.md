# E088: copy-libs-to-dynload-dir

## 基本信息
- **严重度**: 2
- **类别**: linking, runtime
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
ImportError.*Error loading shared library|
                         dlopen.*cannot open shared object.*libffi|
                         cannot open shared object.*lib-dynload
```

## 根因分析
HarmonyOS musl 动态链接器使用 namespace 配置
                         (/etc/ld-musl-namespace-arm.ini)，完全忽略 ELF
                         RUNPATH/RPATH 和 LD_LIBRARY_PATH 环境变量。
                         只有 namespace 配置的 lib.paths 中的库才能被加载。
                         用户安装的库在 /storage/Users/currentUser/usr/local/lib/，
                         不在任何 namespace 路径中。

## 推荐方案
**方法**: copy-libs-to-dynload-dir

**说明**: 将外部依赖库拷贝到目标模块同目录下（$ORIGIN 是唯一可靠路径），
                         然后签名。不依赖 RUNPATH/RPATH 和 LD_LIBRARY_PATH。

**验证/命令**:
```
cp -L /path/to/usr/local/lib/libffi.so.8 $PREFIX/lib/python3.12/lib-dynload/ &&
                         python3 ohc-run.py sign-elf --batch $PREFIX/lib/python3.12/lib-dynload/
```

# E268: patch-autotools-ohos.pl 对新版 config.sub 误判跳过 linux-ohos 内核校验补丁

## 基本信息
- **严重度**: 2
- **类别**: compat, autotools, patch
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>
- **来源 PR**: source_commit:

## 错误特征
```
Kernel 'linux' not known to work with OS 'ohos'|config.sub.*ohos.*failed|linux-ohos
```

## 根因分析
patch-autotools-ohos.pl step 2.3 以 grep 全文 linux-ohos 判定是否已补丁；新版 config.sub(2024+) 的 basic_os 分支已含 linux-ohos(来自 ohos-linux triplet)，但内核-OS 校验列表 'case kernel-os-obj' 中 linux-uclibc*- 行仍缺 linux-ohos*-，导致 aarch64-unknown-linux-ohos 被拒绝

## 推荐方案
**方法**: patch-source

**说明**: 手动在 config.sub 内核-OS 校验列表 linux-uclibc*- 前追加 '| linux-ohos*-'，或改进补丁脚本检测该列表而非全文 grep

```
可选: 具体命令模板(${VAR}变量引用)
```

# E469: cpp-httplib test_package 中 bind_port() 不存在，需用 bind_to_any_port() 获取已绑定端口

## 基本信息
- **严重度**: 2
- **类别**: header-only-library-server-port-binding
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !7187

## 错误特征
```
"no member named 'bind_port' in 'httplib::Server'"
```

## 根因分析
cpp-httplib 0.18.0 的 httplib::Server 没有 bind_port() 成员；可用 API 是 bind_to_port(host, port) 返回 bool、bind_to_any_port(host) 返回自动分配的端口号 int、listen_after_bind()/listen(host, port) 启动监听。编写本地 HTTP 往返测试时若按"绑定到自动端口 + 读取端口"的思路使用 bind_port() 会编译失败

## 推荐方案
**方法**: use-bind-to-any-port

**说明**: test_package 中本地起 httplib::Server 时使用 bind_to_any_port(host) 获得自动分配端口，用该端口构造 Client 完成 HTTP 往返断言，替代不存在的 bind_port()

**验证/命令**:
```
conan create archives/c/cpp-httplib/0.18.0
```

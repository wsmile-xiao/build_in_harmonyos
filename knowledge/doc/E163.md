# E163: source-patch

## 基本信息
- **严重度**: 2
- **类别**: headers, linking
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
duplicate symbol: __packed|ld.lld: error: duplicate symbol: __packed
```

## 根因分析
OHOS 内核头文件 linux/android/binder.h 和 linux/userfaultfd.h 将 __packed 定义为全局变量（"struct binder_handle_cookie { ... } __packed;"），而非 Linux 标准的宏定义（"#define __packed __attribute__((packed))"）。当多个源文件包含这些头文件时，每个编译单元都会生成一个名为 __packed 的全局符号，导致链接时重复符号错误。

## 推荐方案
**方法**: source-patch

**说明**: 在 #include 前将 __packed 重定义为宏，include 后取消定义，使用 #ifdef __OHOS__ 守卫。

**验证/命令**:
```
|
  #ifdef __OHOS__
  #define __packed __attribute__((packed))
  #endif
  #include <linux/android/binder.h>
  #ifdef __OHOS__
  #undef __packed
  #endif
```

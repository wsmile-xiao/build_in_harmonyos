# E041: bypass-autotools

## 错误特征
```
requires automake.*but.*installed|AM_INIT_AUTOMAKE.*too old|
                         autotools.*version mismatch
```

## 根因分析
上游 tarball 的 configure 用较新 automake 生成,
                         但 configure.ac 声明的版本要求更高; 或 VPATH 构建中源码时间戳更新触发 autotools 重生成

## 推荐方案
**方法**: bypass-autotools

**说明**: 使用 /bin/true 绕过 autotools 重生成工具:
                         ACLOCAL=/bin/true AUTOHEADER=/bin/true AUTOMAKE=/bin/true ./configure

**验证/命令**:
```
ACLOCAL="/bin/true" AUTOHEADER="/bin/true" AUTOMAKE="/bin/true" \
                           ./configure --prefix=$HOME/usr/local && make -j1
```

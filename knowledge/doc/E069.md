# E069: use-gen-perl-script

## 基本信息
- **严重度**: 2
- **类别**: autotools, dependency
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
@am_AUTOCONF@|@am_AUTOMAKE@|unresolved.*Makefile\.in|timestamp.*regenerate|automake.*not found
```

## 根因分析
编译 automake 自身时，make 过程调用尚未构建好的 automake
                         重新生成 Makefile.in，形成循环依赖。
                         config.status 执行后 Makefile 中存在未替换变量(@am_AUTOCONF@等)

## 推荐方案
**方法**: use-gen-perl-script

**说明**: 使用 automake 自带的 gen-all.pl 手动生成所有模板文件，
                         然后手动 sed 修补残留变量

**验证/命令**:
```
|
  # 1. 用 gen-all.pl 预生成模板
  perl gen-all.pl
  # 2. sed 修补残留变量
  sed -i 's/@am_AUTOCONF@/autoconf/g' Makefile
  sed -i 's/@am_AUTOMAKE@/automake/g' Makefile
```

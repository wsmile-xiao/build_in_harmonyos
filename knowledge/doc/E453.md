# E453: Validate HMDFS materialized shared-library modes by security baseline, not exact group bits

## 基本信息
- **严重度**: 1
- **类别**: hmdfs-materialized-shared-library-mode
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !6723

## 错误特征
```
regular alias materialization failed.*\.so|byte-identical shared library.*mode 0?770.*source.*0?750|copymode.*HMDFS.*group-write
```

## 根因分析
HMDFS shared storage can project a newly copied regular shared-library alias with an added group-write bit so adjacent sessions with different numeric UIDs remain writable. shutil.copy2 or copymode can therefore produce mode 0770 from a source at 0750 even when bytes and owner/read/execute semantics are preserved. Exact mode equality confuses this filesystem policy with unsafe permission drift and rejects a valid package.

## 推荐方案
**方法**: security-baseline-mode-comparison

**说明**: Separate executable/readability semantics from filesystem-added group write. Preserve owner rwx and group/other read-execute bits, permit only group-write projection, and retain strict byte, file-type and symlink rejection.

**验证/命令**:
```
stat source alias && sha256sum source alias && validate 0750->0770 PASS, 0750->0660/0700/0777/04750 FAIL
```

## 关键词
HMDFS mode projection, SONAME regular alias, group write, copy2, copymode, byte identical, world writable, setuid, shared library materialization

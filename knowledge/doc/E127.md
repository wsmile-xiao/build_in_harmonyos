# E127: undef-macro

## 基本信息
- **严重度**: 3
- **类别**: platform, api
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
pthread_cancel.*undeclared|pthread_setcanceltype.*undeclared|pthread_setcancelstate.*undeclared
```

## 根因分析
HarmonyOS 内核不支持 POSIX 线程取消机制(pthread_cancel, pthread_setcanceltype, pthread_setcancelstate)，与 Android 类似

## 推荐方案
**方法**: undef-macro

**说明**: 添加条件编译，类似 Android 处理：在定义 KMP_CANCEL_THREADS 的位置添加 #ifdef __OHOS__ 守卫并 undef 该宏

**验证/命令**:
```
在源码中添加: #if defined(__ANDROID__) || defined(__OHOS__) \n#undef KMP_CANCEL_THREADS\n#endif
```

## 关键词
pthread_cancel, pthread_setcanceltype, pthread_setcancelstate, undeclared identifier, HarmonyOS, OpenMP

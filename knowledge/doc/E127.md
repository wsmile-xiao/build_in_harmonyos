# E127: undef-macro

## 基本信息
- **严重度**: 3
- **类别**: platform-api-missing
- **触发工具**: clang|gcc
- **阶段**: compilation

## 错误特征
```
pthread_cancel.*undeclared|pthread_setcanceltype.*undeclared|pthread_setcancelstate.*undeclared
```

**关键词**: pthread_cancel, pthread_setcanceltype, pthread_setcancelstate, undeclared identifier, HarmonyOS, OpenMP

## 根因分析
HarmonyOS 内核不支持 POSIX 线程取消机制(pthread_cancel, pthread_setcanceltype, pthread_setcancelstate)，与 Android 类似

**影响范围**: 使用 pthread_cancel 的多线程软件，特别是 OpenMP 运行时库(libomp)和其他线程管理库

## 推荐方案
- **方法**: undef-macro
- **描述**: 添加条件编译，类似 Android 处理：在定义 KMP_CANCEL_THREADS 的位置添加 #ifdef __OHOS__ 守卫并 undef 该宏
- **命令**: `在源码中添加: #if defined(__ANDROID__) || defined(__OHOS__) \n#undef KMP_CANCEL_THREADS\n#endif`
- **自动修复**: false

## 验证
```bash
grep -r "pthread_cancel\|pthread_setcancel" /data/service/hnp/ohos-sdk.org/*/ohos/native/llvm/sysroot/usr/include/pthread.h || echo "Not found in HarmonyOS pthread.h"
```

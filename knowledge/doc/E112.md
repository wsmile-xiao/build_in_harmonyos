# E112: bypass-mktemp

## 基本信息
- **严重度**: 3
- **类别**: platform, hmdfs
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
can't create ./confXXXXXX/subs1.awk: Permission denied|config\.status: error: could not setup config files machinery
```

## 根因分析
HMDFS 文件系统上，mktemp -d 创建的临时目录权限为 drwx--S--- (2700 + setgid)，
                        导致即使目录 owner 是当前用户，也无法在其中创建文件。这是 HMDFS 的安全限制，
                        chmod 也无法修改权限（参见 E046）。

## 推荐方案
**方法**: bypass-mktemp

**说明**: 在 configure/config.status 运行前，预先创建临时目录（不使用 mktemp），并修改脚本中的 tmp/ac_tmp 变量指向该目录

**验证/命令**:
```
export TMPDIR=/storage/Users/currentUser/tmp && TEMP_DIR=$TMPDIR/fixed-temp-$$ && mkdir -p $TEMP_DIR && sed -i "s|ac_tmp=\$tmp|ac_tmp=$TEMP_DIR|g" configure config.status
```

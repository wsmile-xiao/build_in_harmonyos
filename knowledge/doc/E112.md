# E112: bypass-mktemp

## 基本信息
- **严重度**: 3
- **类别**: platform-hmdfs
- **触发工具**: config.status
- **阶段**: configuration

## 错误特征
```
can't create ./confXXXXXX/subs1.awk: Permission denied|config\.status: error: could not setup config files machinery
```

**关键词**: mktemp, Permission denied, subs1.awk, config.status, HMDFS, temporary directory, autotools

## 根因分析
HMDFS 文件系统上，mktemp -d 创建的临时目录权限为 drwx--S--- (2700 + setgid)，

**影响范围**: 所有使用 autotools 构建系统且依赖 mktemp 创建临时目录的软件

## 推荐方案
- **方法**: bypass-mktemp
- **描述**: 在 configure/config.status 运行前，预先创建临时目录（不使用 mktemp），并修改脚本中的 tmp/ac_tmp 变量指向该目录
- **命令**: `export TMPDIR=/storage/Users/currentUser/tmp && TEMP_DIR=$TMPDIR/fixed-temp-$$ && mkdir -p $TEMP_DIR && sed -i "s|ac_tmp=\$tmp|ac_tmp=$TEMP_DIR|g" configure config.status`
- **自动修复**: false

## 验证
```bash
ls -ld $TMPDIR/conf* 2>/dev/null | grep "drwx--S---"
```

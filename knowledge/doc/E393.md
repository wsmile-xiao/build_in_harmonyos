## 错误特征
```
CMakeAutoGenScript.cmake|CMAKE_MODULE_PATH|selected upstream CTest|.codesign
```

## 根因分析
Conan can expose CMAKE_MODULE_PATH as a list, while the upstream CMake helper treated it as one directory. The full 143-case matrix also contains optional-codec and host-facility cases that are not deterministic in the OHOS package gate.

## 推荐方案
**方法**: resolve-cmake-helper-relative-to-list-dir

**说明**: Resolve CMakeAutoGenScript.cmake from CMAKE_CURRENT_LIST_DIR and keep an explicit inventory of selected and deferred upstream tests.

**验证/命令**:
```
conan create archives/l/libsndfile/1.2.2 --build=missing
```

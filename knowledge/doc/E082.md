# E082: configure-twice

## 基本信息
- **严重度**: 3
- **类别**: autotools, configure, gnulib
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
sed: can't read conftest.c.*No such file or directory|
                         checking for bool, true, false\.\.\. no|
                         checking for stdlib\.h\.\.\. no|
                         checking for stdint\.h\.\.\. no|
                         checking for stdbool\.h\.\.\. no|
                         unknown type name.*bool
```

## 根因分析
gnulib 项目的 configure 使用大量 AC_RUN_IFELSE 运行时检测。
                         首次运行时 conftest 程序触发 HarmonyOS 安全弹窗(E064)，
                         弹窗超时后进程被杀，configure 误判检测结果（如 stdbool.h 不存在）。
                         第二次运行时弹窗已被接受，检测结果恢复正常。
                         这是 E064 在 gnulib 项目中的特异性表现：
                         gnulib 的 AC_RUN_IFELSE 密度远高于普通 autotools 项目，
                         单次弹窗超时会导致数十个检测结果同时出错。

## 推荐方案
**方法**: configure-twice

**说明**: 运行 configure 两次。第一次触发安全弹窗并接受（或超时），
                         第二次获得正确的检测结果。
                         gnulib 项目特有的修复方案，适用于 AC_RUN_IFELSE 密度高的场景。

**验证/命令**:
```
./configure --prefix=$TEST_PREFIX && make distclean && ./configure --prefix=$TEST_PREFIX
```

## 错误特征
```
"Error loading shared library ../.*\\.so|strings .* \\| grep '..\\.\\.*/.*\\.so'"
```

## 根因分析
HarmonyOS平台的CMake在链接同一项目内的库时，使用相对路径作为库名称（如../libheif/libheif.so），而非标准的SONAME（libheif.so）。这是HarmonyOS平台CMake的特殊行为，导致可执行文件无法在任意目录运行。

## 推荐方案
**方法**: manual-workaround

**说明**: |
  **问题分析**：
  1. HarmonyOS CMake使用相对路径链接项目内库
  2. RPATH/RUNPATH设置在此平台上无效
  3. 可执行文件硬编码了../libname/libname.so依赖

  **临时解决方案**（Phase 3可用）：
  1. 创建额外的libname/目录：mkdir -p $PREFIX/libname && cp lib/libname.so libname/
  2. 在bin目录下运行可执行文件：cd $PREFIX/bin && ./tool

  **长期解决方案**（需平台适配）：
  1. 研究HarmonyOS Platform/HarmonyOS.cmake配置
  2. 修改CMake模块处理相对路径依赖
  3. 在打包流程中自动修复非标准依赖路径

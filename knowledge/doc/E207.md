# E207: manual-workaround

## 基本信息
- **严重度**: 2
- **类别**: build_system
- **触发工具**: cmake|ld
- **阶段**: linking

## 错误特征
```
"Error loading shared library ../.*\\.so|strings .* \\| grep '..\\.\\.*/.*\\.so'"
```

**关键词**: HarmonyOS,CMake,相对路径链接,../lib,SONAME缺失,库依赖路径,零介入失败,RPATH无效

## 根因分析
HarmonyOS平台的CMake在链接同一项目内的库时，使用相对路径作为库名称（如../libheif/libheif.so），而非标准的SONAME（libheif.so）。这是HarmonyOS平台CMake的特殊行为，导致可执行文件无法在任意目录运行。

**影响范围**: 所有使用CMake构建的、包含内部库链接的项目（如libheif/examples链接libheif库）

## 推荐方案
- **方法**: manual-workaround
- **描述**: |
- **命令**: `mkdir -p $PREFIX/libname && cp $PREFIX/lib/libname.so $PREFIX/libname/ && echo "临时解决方案：可执行文件需在bin目录运行或创建libname目录"`
- **自动修复**: false

## 验证
```bash
strings $BIN | grep '\.\./.*\.so'
```

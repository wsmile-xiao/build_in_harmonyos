# E253: OCaml 工具链迁移到 HarmonyOS PC 的编译配置、testsuite 驱动与平台限制处理方法

- **来源 PR**: 3767

## 错误特征
```
OHOS_ocaml_build|ocaml_testsuite_migration|ocamltest_hmmac|config_guess_ohos|configure_tmpdir|create_process_EPERM
```

## 根因分析
|
  OCaml 4.14.1.1 在 OHOS PC (aarch64) 上迁移需处理 4 类问题:
  1) config.guess 无法识别 OHOS 平台 (识别为 unknown-unknown-linux-gnu),
     configure 阶段主机三元组判定错误;
  2) configure 生成的 config.status 使用 mktemp -d 创建临时目录,
     OHOS /tmp 为 erofs 只读文件系统导致 Permission denied;
  3) upstream testsuite 入口为 make all (无 make check), 依赖 ocamltest 驱动;
     字节码版 ocamltest/ocamldebug 被 hmmac 拦截 (Operation not permitted),
     ocamldebug 默认 UNIX socket bind 也被 hmmac 拒绝;
  4) Unix.create_process 调用 fork+exec 被 OHOS 安全策略禁止 (EPERM),
     posix_spawn 可替代但相对路径解析行为与 glibc 不同 (ENOENT).

## 推荐方案
**方法**: ohos-toolchain-migration

**说明**: |
  按上述 6 点完成 OHOS 适配后, conan create RC=0, test_package 冒烟通过
  (3 个工具版本断言)。上游 testsuite 真机实测 2951/3144 (93.9%) 通过,
  剩余失败为平台硬限制 (hmmac 拦截字节码可执行文件、UNIX socket bind、
  子进程创建、动态链接器符号解析差异), 已在 MANIFEST.yml fail_analysis
  中逐类归因并按 TEST_QUALITY_SPEC 3.3 声明豁免。通过率必须如实填报,
  禁止虚报 100% (E011 规则)。

**验证/命令**:
```
|
  # 1. 本地 CI 模拟预审
  CI_PACKAGES="archives/o/ocaml/4.14.1.1" CI_BRANCH="feat/ocaml-4.14.1.1" zsh ci/conan/build_and_test.sh
  # 2. 上游 testsuite 真机实测 (入口为 make all)
  cd $B/testsuite && make all
  # 3. 通过率如实填报 2951/3144 (93.9%)
```

# E079: command-substitute

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, linking, runtime, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
cannot create hard link.*Operation not permitted|hard link.*not supported|ln.*Operation not permitted
```

## 根因分析
用户主目录 $HOME 挂载于 HMDFS（分布式文件系统），HMDFS 的 nodev 挂载选项和分布式架构不支持硬链接（跨设备 inode 不具备唯一性）。
                        无 -s 参数的 ln 命令尝试创建硬链接时返回 "Operation not permitted"。
                        受影响操作：make install 安装 man 页别名、git clone --local、ccache 缓存原子替换、pnpm content-addressable store 等。

## 推荐方案
**方法**: command-substitute

**说明**: 将硬链接操作替换为复制（cp）。对于 make install 场景，使用 DESTDIR + 手动安装，或 configure 层面设置 ac_cv_prog_ln_s="cp -p"。

**验证/命令**:
```
|
  # configure 层面禁用硬链接
  ./configure --prefix=$PREFIX ac_cv_prog_ln_s="cp -p"
  # 或 make install 时
  make install DESTDIR=$PWD/staging && cp -rP staging/$PREFIX/* $PREFIX/
```

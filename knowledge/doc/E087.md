# E087: use-sh-prefix

## 基本信息
- **严重度**: 1
- **类别**: platform, hmdfs, permissions
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
Permission denied.*\.sh|
                         cannot execute.*Permission denied|
                         ./.*\.sh.*not found.*Permission|
                         sh.*\.sh.*works but.*\.sh.*fails|
                         gpg-error-config-test\.sh.*fail
```

## 根因分析
HMDFS 文件系统上 chmod 操作不生效（UID 映射限制），
                         导致新生成的 shell 脚本文件没有执行权限（0600 而非 0755）。
                         Makefile 中 `./script.sh` 直接执行会报 Permission denied。
                         解决方法是用 `sh ./script.sh` 替代，或在 Makefile 中
                         使用 `install -c -m 755` 替代 `cp` 来安装脚本。

## 推荐方案
**方法**: use-sh-prefix

**说明**: 将 Makefile 中的 `./script.sh` 改为 `sh ./script.sh`，
                         绕过执行权限限制

**验证/命令**:
```
sed -i 's|\./\([^ ]*\.sh\)|sh ./\1|g' Makefile
```

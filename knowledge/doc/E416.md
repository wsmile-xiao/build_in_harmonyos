# E416: 官方大写元数据目录与新增小写 recipe 目录双 case 并存（L0m-5 slug 门禁 + 大小写不敏感 FS）

## 基本信息
- **严重度**: 3
- **类别**: conan, filesystem, case-insensitive, dual-case, slug
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: !6184

## 错误特征
```
包名目录 'SDL2_image' 不是 conan slug（L0m-5）|L4: Dangerous functions found in patches.*0001-config.guess.patch|already exists in working directory
```

## 根因分析
CI L0m-5（ci/conan/build_and_test.sh 671-749 行，commit 24af454af5）用 re.fullmatch(r"[a-z0-9][a-z0-9._+-]*", ...) 强制包目录/版本为全小写 conan slug；L0m-4 强制 conanfile.name == 目录名。官方 main 34e352d4 既有 12 个含 conanfile.py 的大写包目录（CLI11/SDL2 等）与门禁结构性冲突。SDL2_image 官方大写目录 archives/s/SDL2_image/ 是纯元数据（无 conanfile，CI 不构建，L0m 不触发），新增小写 recipe 目录 archives/s/sdl2_image/ 通过 L0m。大小写不敏感设备 FS 上两目录物理合并，git 树保持双 case 并存；L4 扫描把物理共享的官方大写 patches 当小写目录 patches 报 [warn]。

## 推荐方案
**方法**: add-lowercase-recipe-dir-keep-uppercase-meta

**说明**: 保留官方大写元数据目录不动，新增全小写 recipe 目录（conanfile.py/conandata.yml/test_package + 版本级 manifest/notes 自补），分支名用全小写；大小写不敏感 FS 上两目录物理合并属预期，L4 误扫（候选 patches 为空仍扫到大写基线 patches）如实按 [warn] 披露而非候选缺陷；skip-worktree 由既有碰撞文件共用，不新增；branch 大小写共享物理 loose ref 用 reflog 保留小写分支完整历史。

**验证/命令**:
```
git -C <worktree> status --porcelain && git diff --name-status <base> HEAD
```

# E060: use-tmpfs-workaround

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
config\.status.*Permission denied|mktemp.*failed|confXXXXXX.*cannot create|subs1\.awk.*Permission denied
```

## 根因分析
HMDFS 文件系统对临时目录创建有特殊限制，config.status 使用 `mktemp -d "./confXXXXXX"` 在当前目录创建临时目录可能失败。
                        这与 E002（/tmp 只读）相关，但影响源码目录本身的临时文件操作。

## 推荐方案
**方法**: use-tmpfs-workaround

**说明**: 在 tmpfs 目录（如 $HOME/tmp）中构建，而非直接在 HMDFS 的源码目录中运行 configure。
                        复制源码到 tmpfs 目录，然后在那里运行完整的构建流程。

**验证/命令**:
```
|
  # 检测是否在 HMDFS 上
  mount | grep hmdfs
  # 创建 tmpfs 构建目录
  mkdir -p $HOME/tmp/build-tmpfs
  # 复制源码
  cp -a $BUILD_SRC_DIR $HOME/tmp/build-tmpfs/$(basename $BUILD_SRC_DIR)
  cd $HOME/tmp/build-tmpfs/$(basename $BUILD_SRC_DIR)
  # 在 tmpfs 上运行 configure
  ./configure --prefix=$DEFAULT_PREFIX
```

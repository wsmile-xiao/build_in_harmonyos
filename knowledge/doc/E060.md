# E060: use-tmpfs-workaround

## 基本信息
- **严重度**: 2
- **类别**: filesystem-hmdfs
- **触发工具**: config.status
- **阶段**: configuration

## 错误特征
```
config\.status.*Permission denied|mktemp.*failed|confXXXXXX.*cannot create|subs1\.awk.*Permission denied
```

**关键词**: config.status, Permission denied, mktemp, HMDFS, temporary, confXXXXXX

## 根因分析
HMDFS 文件系统对临时目录创建有特殊限制，config.status 使用 `mktemp -d "./confXXXXXX"` 在当前目录创建临时目录可能失败。

**影响范围**: 所有在 HMDFS 上运行 autotools configure 的项目

## 推荐方案
- **方法**: use-tmpfs-workaround
- **描述**: 在 tmpfs 目录（如 $HOME/tmp）中构建，而非直接在 HMDFS 的源码目录中运行 configure。
- **命令**: `|`
- **自动修复**: false

## 验证
```bash
mount | grep hmdfs && mktemp -d "./confXXXXXX" || echo "HMDFS mktemp failed"
```

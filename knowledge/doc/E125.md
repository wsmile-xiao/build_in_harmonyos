# E125: relocate-build-dir

## 基本信息
- **严重度**: 3
- **类别**: environment
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
can't create .* subs1\.awk.*Permission denied|
```

**关键词**: HMDFS, hmdfs, config.status, Permission denied,

## 根因分析
HMDFS（鸿蒙分布式文件系统）在创建临时子目录时存在权限限制。

**影响范围**: 所有使用 autotools 构建系统的软件，在 HMDFS 挂载目录下编译时

## 推荐方案
- **方法**: relocate-build-dir
- **描述**: 将源码目录移动到 HMDFS 外的可写目录（如 /data/local/tmp，如果可写）
- **命令**: `# 方案 A：尝试使用 /dev/shm（tmpfs）`
- **自动修复**: false

## 验证
```bash
mount | grep hmdfs;
```

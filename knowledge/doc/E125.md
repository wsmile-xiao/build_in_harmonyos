# E125: relocate-build-dir

## 基本信息
- **严重度**: 3
- **类别**: environment
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
can't create .* subs1\.awk.*Permission denied|
                         config\.status.*could not setup config files machinery|
                         \.\/conf[a-zA-Z0-9]+\/.*Permission denied
```

## 根因分析
HMDFS（鸿蒙分布式文件系统）在创建临时子目录时存在权限限制。
                         autotools 的 config.status 使用 mktemp 创建随机命名的临时子目录
                         （如 conf[a-zA-Z0-9]+/），并在其中写入 subs1.awk 等文件。
                         但 HMDFS 的安全策略限制了某些目录下的子目录创建操作，
                         导致即使父目录权限正确，子目录创建仍然失败。
                         这与 E002（/tmp 只读）不同，E002 是挂载点只读问题，
                         而 E081 是 HMDFS 特定的文件系统安全限制。

## 推荐方案
**方法**: relocate-build-dir

**说明**: 将源码目录移动到 HMDFS 外的可写目录（如 /data/local/tmp，如果可写）
                         或使用 tmpfs 挂载点（如 /dev/shm，如果空间足够）。
                         如果以上都不可行，则此问题为平台硬限制，需等待系统更新或使用
                         非HMDFS环境的构建服务器。
                         注意：即使设置 TMPDIR，config.status 仍会在源码目录下创建临时子目录，
                         因此仅设置 TMPDIR 无法解决此问题。

**验证/命令**:
```
# 方案 A：尝试使用 /dev/shm（tmpfs）
                         if mountpoint -q /dev/shm && df -h /dev/shm | grep -q "G"; then
                           cd /dev/shm && cp -r $BUILD_SRC_DIR . && cd libsigrok-* && ./configure ...
                         fi
                         # 方案 B：标记为平台限制，无法编译
                         echo "E081: HMDFS restriction blocks autotools config.status" >> $BUILD_ARCHIVE_DIR/notes.md
```

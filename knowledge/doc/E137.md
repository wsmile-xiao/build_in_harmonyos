# E137: source-patch

## 基本信息
- **严重度**: 3
- **类别**: linking|perl|build-system
- **触发工具**: ld|clang|perl
- **阶段**: linking|compilation

## 错误特征
```
ld\.lld:\s*error:\s*unknown\s*argument\s*['"]?-fstack-protector-strong|This\s+distribution\s+requires\s+a\s+C\s+compiler,\s+but\s+it's\s+not\s+available|ExtUtils::CBuilder\s+not\s+installed\s+or\s+no\s+compiler\s+detected
```

**关键词**: fstack-protector-strong, ldflags, lddlflags, ld.lld, unknown argument, ExtUtils::CBuilder, have_compiler, Module::Build, Perl, cbuilder, config override

## 根因分析
Perl 5.42.0 on OpenHarmony is configured with -fstack-protector-strong in both ccflags (correct, compiler flag) and ldflags/lddlflags (incorrect, these are passed directly to ld.lld which does not recognize compiler flags). When ExtUtils::CBuilder::have_compiler() tries to compile and link a test program, ld.lld rejects -fstack-protector-strong as an unknown argument, causing compiler detection to fail. Module::Build::XSUtil then exits with "This distribution requires a C compiler". Additionally, system libraries (libc, libunwind) and musl C library headers are not in ld.lld's default search paths.

**影响范围**: All Perl XS modules using Module::Build or Module::Build::XSUtil on OpenHarmony. Also affects any Perl module that calls ExtUtils::CBuilder directly or indirectly. Does not affect pure Perl modules without XS compilation.

## 推荐方案
- **方法**: source-patch
- **描述**: Override the cbuilder() method in the Module::Build subclass to create ExtUtils::CBuilder with a modified Config hash copy: (1) Remove -fstack-protector-strong from ldflags and lddlflags via regex. (2) Add -L/system/lib64 -L$HOME/usr/local/lib -lunwind -lc to lddlflags for library search paths. (3) Add -I$HOME/usr/local/include to ccflags for musl headers. (4) Clear the _have_c_compiler cache property after SUPER::new() to force re-evaluation with fixed config. Key insight: ExtUtils::CBuilder reads config values from the hash directly (not through Module::Build::Config->get()), so a plain hash must be passed, not a Module::Build::Config object.
- **命令**: `Override cbuilder() to pass config hash with -fstack-protector-strong removed and -L/-I paths added; clear _have_c_compiler cache after SUPER::new()`
- **自动修复**: false

## 验证
```bash
perl -MModule::Build::XSUtil -e 'my $mb = Module::Build::XSUtil->new(module_name=>"Test",dist_name=>"Test",dist_version=>"0.01",license=>"perl"); print "have_c_compiler: ", $mb->have_c_compiler ? "yes" : "no", "\n"'
```

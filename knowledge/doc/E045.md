## 错误特征
```
MemoryError|ctypes.*CFUNCTYPE|mmap.*PROT_WRITE.*PROT_EXEC.*Invalid argument|
                         W^X|mmap.*RWX
```

## 根因分析
HarmonyOS 内核强制 W^X(Write XOR Execute) 安全策略,
                         禁止同时可写且可执行的内存映射。
                         libffi 创建回调 closure 时需要分配 RWX 内存页存放动态生成的跳转代码

## 推荐方案
**方法**: no-fix-platform-limitation

**说明**: 当前无法在 Python 层修复。需在 libffi 层使用 RW→RX 分步映射:
                         mmap(RW) → memcpy → mprotect(RX)。临时绕过: subprocess 替代进程内回调

**验证/命令**:
```
rec_auto_fix:          false
```

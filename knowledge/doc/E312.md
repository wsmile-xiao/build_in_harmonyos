# E312: groonga 上游 4227 个 .test 用例 grntest Ruby 测试框架依赖链在 OHOS 的完整解决方案

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, testing

## 错误特征
```
grntest|bundle install|gem install|RUBY|run-test.sh|GQTP|stdckdint.h|/usr/bin/install|Permission denied
```

## 根因分析
groonga 上游测试依赖链分五层：① Ruby C 扩展 gem（msgpack/json/pycall）编译需 C23 stdckdint.h（OHOS musl 缺失）；② gem make install 用 /usr/bin/install（OHOS 无此路径）；③ grntest + 6 个附加 Ruby gem 需从 GitHub clone + bundle install；④ 测试需完整 groonga 服务进程（stdio/HTTP 接口）；⑤ groonga 二进制与插件 .so 需 OHOS 签名（binary-sign-tool）才能加载执行。

## 推荐方案
**方法**: full-dependency-chain-solution

**说明**: 逐层解决依赖链：① 补 C23 stdckdint.h 兼容头（usr/local/include）供 gem C 扩展编译（--with-cflags）；② gem 手动 make install（INSTALL 覆盖 /system/bin/install）+ build_complete + specs 注册；③ grntest/6 gem 用 --local 安装并补 pycall 等 C 扩展；④ groonga 服务端用 --interface=http 跑测试（stdio 模式多行 JSON 不兼容）；⑤ groonga 二进制与插件 .so 全部 binary-sign-tool 签名。

**验证/命令**:
```
CFLAGS="-I/usr/local/include" gem install msgpack -- --with-cflags=...; make install INSTALL="/system/bin/install -c"; grntest --interface=http --groonga=... test/command/suite
```

# E063: add-cflags-disable-werror

## 基本信息
- **严重度**: 2
- **类别**: compat, compiler, warnings
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
error:.*\[-W.*\].*warnings and.*errors generated|
                         -Werror.*int-conversion|-Werror.*incompatible-pointer|
                         -Werror.*implicit-function|-Werror.*format-truncation
```

## 根因分析
项目启用了 -Werror(或某些类别如 -Werror=implicit-function-declaration),
                         将所有编译器警告视为错误。musl/clang 组合下产生一些与 glibc 不同的警告:
                         size_t 差异、头文件差异、格式化字符串截断等

## 推荐方案
**方法**: add-cflags-disable-werror

**说明**: 在编译规则中对特定 warning 类别禁用 error 升级:
                         CFLAGS += -Wno-error=int-conversion -Wno-error=incompatible-pointer-types

**验证/命令**:
```
make CFLAGS="$CFLAGS -Wno-error=int-conversion -Wno-error=incompatible-pointer-types"
```

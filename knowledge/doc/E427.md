# E427: shadow CI 隔离 HOME 后不要只改 HOME；需给 Python 保留真实 site-packages 或预装完整 Conan 依赖

## 基本信息
- **严重度**: 2
- **类别**: network, python, conan, environment
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6613

## 错误特征
```
ModuleNotFoundError: No module named 'distro'|Conan not found or broken|pip subprocess.*did not run successfully|ReadTimeoutError.*files.pythonhosted.org
```

## 根因分析
影子 CI 用 env -i + 独立 HOME/CONAN_HOME 可以隔离 Conan cache，但若 PATH 指向真实 conan 入口而 PYTHONPATH 不含真实 ~/.local/site-packages，setup.sh 会认为 Conan broken 并尝试联网安装；受限网络下 pip 可能超时或只装部分依赖，随后 conan 启动缺 distro。

## 推荐方案
**方法**: isolate-cache-keep-python-import-path

**说明**: HOME/CONAN_HOME/TMPDIR 使用 run/job 隔离目录；PATH 保留 REAL_HOME/usr/local/bin 与 REAL_HOME/.local/bin；PYTHONPATH 追加 REAL_HOME/.local/lib/python3.12/site-packages、REAL_HOME/usr/local/lib/python3.12/site-packages 和 shadow python-user site-packages，避免重复联网安装 Conan。

**验证/命令**:
```
env -i HOME="$RUN_HOME" CONAN_HOME="$RUN_HOME/conan-home" PATH="$REAL_HOME/usr/local/bin:$REAL_HOME/.local/bin:/data/service/hnp/bin:/bin:/usr/bin" PYTHONPATH="$REAL_HOME/.local/lib/python3.12/site-packages:$REAL_HOME/usr/local/lib/python3.12/site-packages" conan --version
```

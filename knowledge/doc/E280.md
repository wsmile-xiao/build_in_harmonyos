# E280: OHOS 静态构建下 Thread 未注册 Tcl_StaticPackage 导致子解释器 package require Thread 失败、主线程 vwait 永久等待

## 基本信息
- **严重度**: 3
- **类别**: packaging
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !3200

## 错误特征
```
can't find package Thread exactly 2\.8\.9|dynamic loading is not currently available on this system|thread\.test hang|timeout.*thread\.test|vwait.*never returns|wchan=FUTEX
```

## 根因分析
OHOS 静态构建 (TCL_SHLIB_EXT="") 下，0010 把 Thread_Init 静态链接进 tclsh/tcltest 并仅在 AppInit 主解释器调用，未注册 Tcl_StaticPackage("Thread")。worker 线程内 interp create 创建的子解释器执行 "package require -exact Thread 2.8.9" 失败 ("can't find package Thread exactly 2.8.9")，worker 死亡后主线程 "vwait ::threadIdStarted" 永久等待 → unix/tests/thread.test hang (rc=124, 零输出, 主线程 wchan=FUTEX, worker 线程 wchan=EVENTPOLL)

## 推荐方案
**方法**: static-package-registration-bridge

**说明**: 0013 新增 library/pkgIndex.tcl 静态桥接 (package ifneeded Thread 2.8.9 [list load {} Thread])；0014 在 OhosStaticPkgs_Init 注册 Tcl_StaticPackage(interp, "Thread", Thread_Init, NULL)（镜像 sqlite3 注册方式）；0015 将 pkgs/thread2.8.9/pkgIndex.tcl.in 的 Thread ifneeded 改为静态 load {} 形式，防止 TCLLIBPATH 前置 pkgs 目录时动态 pkgIndex 覆盖静态桥接

**验证/命令**:
```
见补丁 0013/0014/0015；验证: TCL_LIBRARY=<build>/unix/library TCLLIBPATH=<build>/build-release/pkgs timeout 240 <build>/build-release/tcltest unix/tests/thread.test -testdir unix/tests
```

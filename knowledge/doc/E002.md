# E002: set-env-var

## 基本信息
- **严重度**: 3
- **类别**: environment
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
cannot create temporary.*tmp|/tmp.*read-only|
                         erofs|temporary directory.*Permission denied
```

## 根因分析
鸿蒙系统 /tmp 是 erofs 只读挂载,
                         configure/make/install 默认使用 /tmp 做临时文件

## 推荐方案
**方法**: set-env-var

**说明**: 设置 TMPDIR 指向可写目录 (脚本开头已设置)

**验证/命令**:
```
TMPDIR=$HOME/tmp
```

## 关键词
/tmp, temporary, read-only, erofs, TMPDIR,
                         Permission denied, tmp

# E002: 临时目录不可写

> **结构化数据**: [graph/E002.kv](../graph/E002.kv) | **原则**: 无
> **严重度**: 🔴 blocking | **分类**: environment | **自动修复**: ✅ set-env-var

---

## 错误特征

```
cannot create temporary file: /tmp/xxx: Read-only file system
/tmp: Permission denied
erofs: filesystem is read-only
```

## 根因

鸿蒙系统 `/tmp` 是 erofs 只读挂载，`configure`/`make`/`install` 默认使用 `/tmp` 做临时文件。

## 解决方案

```bash
export TMPDIR=$HOME/tmp
mkdir -p $TMPDIR
```

## 涉及软件

几乎所有构建工具（configure、make、install 等都用到临时目录）。

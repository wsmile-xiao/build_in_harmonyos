# E188: use-gnu-coreutils

## 基本信息
- **严重度**: 1
- **类别**: platform_compat
- **触发工具**: install|make
- **阶段**: installation

## 错误特征
```
install: inaccessible or not found|toybox install.*incompatible options|cannot stat.*Permission denied
```

**关键词**: toybox, install, coreutils, compatibility, GNU, 命令兼容

## 根因分析
鸿蒙默认使用 toybox 提供的 install 命令，功能比 GNU coreutils 的 install 简化，缺少某些选项或权限处理不完整。

**影响范围**: ruby-build, 其他使用 install 命令的 shell 脚本工具, autotools 项目, 任何调用 install 命令的构建过程

## 推荐方案
- **方法**: use-gnu-coreutils
- **描述**: 手动复制替代 install（cp bin/* $PREFIX/bin/ && chmod +x），或从 cmd-pkgs 安装 GNU coreutils 9.10 提供完整 install 命令。
- **自动修复**: false

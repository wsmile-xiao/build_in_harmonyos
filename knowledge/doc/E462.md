# E462: OHOS ptrace blocked: locate crashes via SIGSEGV handler + FP-chain + llvm-addr2line (ASan can be silent)

## 基本信息
- **严重度**: 3
- **类别**: ohos, security, debugging
- **作者**: Awstme <awstme@qq.com>
- **来源 PR**: !7064

## 错误特征
```
gdb: ptrace Permission denied; ASan-instrumented binary dies with plain Segmentation fault and no sanitizer report
```

## 根因分析
SELinux/HMMAC blocks ptrace system-wide on HarmonyOS, so gdb/strace cannot attach. A NULL-call crash (PC=0) or handler-reentrancy failure can also leave ASan without any report, removing the usual instrumentation path to a location.

## 推荐方案
**方法**: userland-signal-handler-frame-walk

**说明**: Install a SA_SIGINFO handler in the reproducer; read pc/fp/lr from ucontext (OHOS musl sigcontext exposes regs[] only: fp=regs[29], lr=regs[30]); classify addresses by dladdr dli_fbase against module bases captured via dlsym of known symbols; print module+offset per frame and resolve offline with llvm-addr2line -f -C. Combine with a minimal repro that toggles link mode (.a vs .so) to bisect runtime-state hypotheses without a debugger.

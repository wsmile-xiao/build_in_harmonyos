# E473: Inject missing WebP::webpdemux imported target when libwebp CMakeDeps only exposes WebP::webp and upstream links both under OHOS cross-compile

## 基本信息
- **严重度**: 3
- **类别**: cmake, cross-compile, conan, libwebp, sdl2
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !7112

## 错误特征
```
Target "SDL2_image" links to:.*WebP::webpdemux|but the target was not found|webp/decode.h not found|Findwebp.*module
```

## 根因分析
libwebp 配方 package_info() 仅暴露 WebP::webp（cmake_target_name=WebP::webp），但上游 SDL2_image 2.8.12 在 SDL2IMAGE_WEBP 启用、SDL2IMAGE_DEPS_SHARED=OFF 时 `target_link_libraries(SDL2_image PRIVATE WebP::webp WebP::webpdemux)` 同时链接两个 target；libwebpdemux.so 实际随 libwebp 包分发（lib/libwebpdemux.so.2.0.17），却未作为组件/独立 target 暴露。Conan 2 的 CMakeToolchain 默认 set(CMAKE_FIND_PACKAGE_PREFER_CONFIG ON)，使 find_package(webp) 命中 CMakeDeps 生成的 WebPConfig.cmake（仅定义 WebP::webp），而非上游 cmake/Findwebp.cmake 模块（该模块本会同时定义 WebP::webp 与 WebP::webpdemux 两个 IMPORTED target）→ 配置期报 Target "SDL2_image" links to: WebP::webpdemux but the target was not found。另：Findwebp.cmake 的 find_path(webp_INCLUDE_PATH NAMES webp/decode.h) 需要 include 根（含 webp/ 子目录），错误指到 include/webp 会报 webp/decode.h not found。

## 推荐方案
**方法**: conan-recipe build-module imported-target injection (cmake_build_modules)

**说明**: 在 conanfile.py generate() 中为 libwebp 依赖注入一个 build module（cmake_build_modules），其中定义缺失的 WebP::webpdemux UNKNOWN IMPORTED target，IMPORTED_LOCATION 指向 libwebp 包内 lib/libwebpdemux.so；同时把 webp_INCLUDE_PATH / webpdemux_INCLUDE_PATH 缓存变量指向 libwebp include 根（含 webp/ 子目录）。这样 find_package(webp) 命中 CMakeDeps WebPConfig 时 WebP::webpdemux 已存在，无需改 libwebp 配方或改上游源码。

**验证/命令**:
```
|
  def generate(self):
      deps = CMakeDeps(self)
      webp = self.dependencies["libwebp"]
      if webp.package_folder:
          module = os.path.join(self.generators_folder, "WebP-webpdemux.cmake")
          with open(module, "w", encoding="utf-8") as fh:
              fh.write("if(NOT TARGET WebP::webpdemux)\n")
              fh.write("  add_library(WebP::webpdemux UNKNOWN IMPORTED)\n")
              fh.write("  set_target_properties(WebP::webpdemux PROPERTIES\n")
              fh.write("      IMPORTED_LOCATION \"%s\")\n" % os.path.join(webp.package_folder, "lib", "libwebpdemux.so"))
              fh.write("endif()\n")
          deps.set_property("libwebp", "cmake_build_modules", [module])
      deps.generate()
      tc = CMakeToolchain(self)
      tc.cache_variables["webp_INCLUDE_PATH"] = os.path.join(webp.package_folder, "include")
      tc.cache_variables["webpdemux_INCLUDE_PATH"] = os.path.join(webp.package_folder, "include")
      tc.generate()
```

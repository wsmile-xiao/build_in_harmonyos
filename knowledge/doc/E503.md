# E503: CLI 工具无 --version/--help 长选项导致 L2 smoke test 失败

## 基本信息
- **严重度**: 2
- **类别**: smoke-test
- **作者**: hazel_xyx <1707119571@qq.com>
- **来源 PR**: !5897

## 错误特征
```
unrecognized option|invalid option --|jshn
```

## 根因分析
上游 CLI 工具仅实现 getopt 短选项，--version/--help 落入默认分支调用 usage() 并返回非 0（exit 2）

## 推荐方案
**方法**: 补丁在 main() 开头增加 --version/--help GNU 长选项处理并返回 0（libubox jshn 先例）

**说明**: main() 开头（getopt 循环前）拦截 --version/--help，打印版本/用法后 return 0

**验证/命令**:
```
编辑 jshn.c 后: ohc-run.py track-edit add libubox 2026-06-19 jshn.c && ohc-run.py refresh-patch --auto libubox 2026-06-19
```

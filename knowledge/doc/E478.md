# E478: conan-verify 无法解析点号版本号的 package ID（G4/L2/L4/L5 跳过）

## 基本信息
- **严重度**: 2
- **类别**: conan
- **作者**: goblinrs <goblinrs@yeah.net>
- **来源 PR**: !6862

## 错误特征
```
conan-verify.*无法找到程序包 ID|Package ID not found.*dotted version|G4.*package ID
```

## 根因分析
conan_verify.py G2 用正则 (\w+/\w+@\w+/\w+):(\w+) 从 conan create 日志提取 package ID，\w+ 不匹配含点号的版本号（如 20160310.da66f51），导致 _package_id 为空，G4/L2/L4/L5 因拿不到 cache 路径而跳过

## 推荐方案
**方法**: 版本号含点号时 G4/L2/L4/L5 会被跳过但标记 PASS；需手动用 conan cache path '<ref>:<pkgid>' + readelf/sha256 验证产物完整性（或用 conan list 获取 package id）

**说明**: 版本号含点号（或连字符）时 conan-verify 的 package ID 正则不匹配，G4/L2/L4/L5 被跳过但标记 PASS；需手动验证产物完整性

**验证/命令**:
```
conan cache path asplib/20160310.da66f51@ohpcd/stable:4b977264131a1c74e82bd6bb51b63cc9aadc4cfa
```

# E547: glib2 Conan 包仅提供聚合 glib-2.0.pc：meson 按单模块名查找需在 generate() 补写 gobject/gio/gio-unix/gmodule 薄包装 .pc

## 基本信息
- **严重度**: 2
- **类别**: conan, build-system, pkg-config
- **来源事件**: libcolord 1.4.8 HarmonyOS 适配
- **提升日期**: 2026-10-01

## 错误特征
```
Package 'gobject-2\.0' not found|dependency .*gobject-2\.0.* not found|gio-unix-2\.0.*not found|gmodule-2\.0.*not found
```

## 根因分析
glib2 Conan 包只生成聚合 glib-2.0.pc；meson 的 dependency('gio-2.0'|'gobject-2.0'|'gio-unix-2.0'|'gmodule-2.0') 按单模块名走 pkg-config 查找时找不到对应 .pc 而失败。需在 generate() 针对每个单模块名补写 requires 指向聚合 glib-2.0.pc 的薄包装 .pc（依赖注入走 build_folder 私有 prefix，符合 R49）。

## 推荐方案
**方法**: thin-pc-wrapper-for-gl-submodules

generate() 中为 gobject-2.0/gio-2.0/gio-unix-2.0/gmodule-2.0 补写薄包装 .pc（Requires: glib-2.0），满足 meson 单模块 dependency 查找

## 实施记录（libcolord 1.4.8）
详见 archives/l/libcolord/1.4.8/notes.md 与 reports/test-report.md。

## 验证
```bash
PKG_CONFIG_PATH=$(build_folder)/prefix/lib/pkgconfig pkg-config --exists gobject-2.0 gio-2.0 gio-unix-2.0 gmodule-2.0 && echo ok
```

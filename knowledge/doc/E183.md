# E183: python-script-replace

## 基本信息

## 错误特征
```
cat.*<<.*EOF.*Permission denied|cannot create temp file for here-document|heredoc.*failed|config.mak.*only.*3.*lines
```

## 根因分析
HMDFS 分布式文件系统不支持 shell heredoc（cat << EOF）语法，
                        configure 脚本无法创建配置文件。
                        Python 的文件写入操作不受此限制，
                        可作为通用替代方案。

## 推荐方案
**方法**: python-script-replace

**说明**: 创建 Python 脚本（create_config.py）替代 configure，
                        手动生成 config.h、config.mak、x264.pc 等配置文件，
                        使用 Python 文件写入替代 heredoc。
                        此方案通用性强，适用于任何 heredoc 依赖的项目。

**验证/命令**:
```
python3 create_config.py
                        # 脚本模板见 doc/E109.md
```

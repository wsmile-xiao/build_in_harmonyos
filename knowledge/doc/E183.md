# E183: python-script-replace

## 基本信息
- **严重度**: 2
- **类别**: filesystem|hmdfs|autotools|build-system|python
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
cat.*<<.*EOF.*Permission denied|cannot create temp file for here-document|heredoc.*failed|config.mak.*only.*3.*lines
```

**关键词**: heredoc, cat << EOF, Permission denied, HMDFS, Python script, create_config.py

## 根因分析
HMDFS 分布式文件系统不支持 shell heredoc（cat << EOF）语法，

**影响范围**: 所有使用 heredoc 创建配置文件的 autotools 项目：

## 推荐方案
- **方法**: python-script-replace
- **描述**: 创建 Python 脚本（create_config.py）替代 configure，
- **命令**: `python3 create_config.py`
- **自动修复**: false

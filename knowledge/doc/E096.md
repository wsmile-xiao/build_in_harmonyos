## 错误特征
```
Performing Test.*CXX17.*Failed|CMake Error.*compiler defaults.*C++ < 17|C++ >= 17 is required|System is unknown to cmake
```

## 根因分析
OpenHarmony 平台上 CMake 无法正确检测编译器的 C++ 标准支持能力，CMake 输出 "System is unknown to cmake" 导致编译器 ABI 检测不完整，即使编译器实际支持 C++17，特性检测也会失败

## 推荐方案
**方法**: cmake-cxx-standard-explicit

**说明**: 显式设置 CMAKE_CXX_STANDARD 和 CMAKE_CXX_STANDARD_REQUIRED 强制指定 C++ 标准版本，绕过 CMake 的编译特性自动检测机制

**验证/命令**:
```
cmake .. -DCMAKE_CXX_STANDARD=17 -DCMAKE_CXX_STANDARD_REQUIRED=ON
```

# E240: Split macOS CoreGraphics display tools into OHOS-supported read-only capability and explicit unsupported boundaries

## 基本信息
- **严重度**: 2
- **类别**: platform, api
- **作者**: F72D
- **来源 PR**: !3257

## 错误特征
```
ApplicationServices/ApplicationServices.h|CoreGraphics|CGDisplayCopyDisplayMode|CGConfigureDisplayWithDisplayMode|NativeDisplayManager
```

## 根因分析
Some command-line display tools are built around Apple-only CoreGraphics display APIs. OHOS NativeDisplayManager public C APIs can query default-display width, height, and refresh rate, but they do not provide an equivalent physical display mode setter or a complete switchable mode enumeration in the API surface used by the port.

## 推荐方案
**方法**: capability-split-with-negative-tests

**说明**: Keep the real OHOS capability implemented through NativeDisplayManager for read-only display metrics. Do not fake list/set success; implement unsupported diagnostics and assert those commands fail in test_package.

**验证/命令**:
```
Add an OHOS backend using OH_NativeDisplayManager_GetDefaultDisplayWidth/Height/RefreshRate, return success only for -version/get, and add negative tests for list/set.
```

# E119: macro-guard-skip-header

## 基本信息
- **严重度**: 3
- **类别**: SDK-conflict
- **触发工具**: gcc|clang
- **阶段**: compilation

## 错误特征
```
error: redefinition of 'struct sockaddr_storage'|note: previous definition of 'struct sockaddr_storage' was here|conflicting types for 'sockaddr_storage'
```

**关键词**: sockaddr_storage, redefinition, linux/socket.h, sys/socket.h, OpenHarmony, OHOS

## 根因分析
OpenHarmony SDK 的系统头文件组织问题，linux/socket.h 和 sys/socket.h 都定义了 sockaddr_storage 结构体

**影响范围**: 所有在 OpenHarmony 上编译的软件，当源文件同时包含 linux/socket.h 和 sys/socket.h 时触发

## 推荐方案
- **方法**: macro-guard-skip-header
- **描述**: 使用 #ifdef __OHOS__ 宏守卫，定义 _UAPI_LINUX_SOCKET_H 跳过 linux/socket.h，手动定义 __kernel_sa_family_t
- **命令**: `在 #include <sys/socket.h> 后、#include <linux/if_arp.h> 前插入修复代码块`
- **自动修复**: false

## 验证
```bash
grep -r "sockaddr_storage" /usr/include/linux/socket.h /usr/include/sys/socket.h 2>/dev/null | head -5
```

# E380: Bind a validated memory budget when target CMake cannot parse procfs

## 基本信息
- **严重度**: 3
- **类别**: cmake, memory, capability-binding, test-inventory
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5392

## 错误特征
```
Problem parsing /proc/meminfo|ITK_COMPUTER_MEMORY_SIZE.*empty|ITK_COMPUTER_MEMORY_SIZE is required for runnable OHOS tests|tests passed.*out of 617
```

## 根因分析
A target can expose valid MemTotal data while CMake's platform-specific host-memory parser fails, causing memory-gated tests to disappear from the generated inventory.

## 推荐方案
**方法**: validated-explicit-memory-budget

**说明**: Keep the full expected inventory, prefer a sealed range-checked override when supplied, and otherwise derive the value from local read-only MemTotal only when the target is runnable.

**验证/命令**:
```
Reject missing, duplicate, nonnumeric, zero, too-small, wrong-unit and implausibly large values; divide KiB to MiB before multiplying by 80; never inspect host procfs for non-runnable cross builds; then bind ITK_COMPUTER_MEMORY_SIZE and require the gated test.
```

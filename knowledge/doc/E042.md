# E042: set-rpath-patchelf

## 基本信息
- **严重度**: 2
- **类别**: linking, packaging, runtime
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
ImportError.*_\w+|cannot open shared object|
                         extension module.*library not found|lib-dynload.*NEEDED
```

## 根因分析
打包可移植包时只为主程序和主共享库设置了 RPATH,
                         遗漏了扩展模块(lib-dynload/*.so)的 RPATH 设置。
                         扩展模块如果 NEEDED 外部库, musl 动态链接器沿调用者链搜索 RPATH 不稳健

## 推荐方案
**方法**: set-rpath-patchelf

**说明**: 为扩展模块显式设置 RPATH:
                         EXT_RPATH='$ORIGIN:$ORIGIN/..:$ORIGIN/../external'

**验证/命令**:
```
for so in "$PKGDIR/lib/python3.9/lib-dynload/"*.so; do
                           $PATCHELF --set-rpath "$EXT_RPATH" "$so"
                         done
```

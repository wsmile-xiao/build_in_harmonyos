# E222: 非调试 HarmonyOS 设备在 ptrace 不可用时建立原生崩溃证据链

## 基本信息
- **严重度**: 3
- **类别**: ohos, warnings, runtime, security
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: metrics_success_count:  1

## 错误特征
```
ptrace: Permission denied|DeviceDebuggable:No|A packet returned an error: 8|SIGSEGV\(SEGV_MAPERR\)
```

## 根因分析
ptrace 调试入口不可用不等于无诊断能力；应把 FaultLogger、模块偏移、线程栈、进程映射、符号化、反汇编和证伪探针组合为证据链，避免由顶层 signal 或系统库 frame 直接猜根因。

## 推荐方案
**方法**: faultlogger-evidence-chain

**说明**: ptrace 被拒时优先收集 FaultLogger 与 maps，完成模块偏移符号化和反汇编，并为主要假设保留证伪证据；修复后以完整设备负载确认。

**验证/命令**:
```
采集 FaultLogger；记录 PC/模块/偏移/线程栈/maps；使用 llvm-addr2line 或 llvm-objdump；重复原负载并执行最小反假因探针。
```

## 根因分析
OHOS 适配韩语 NLP 词典数据包时遇到需要固定源码 hash 校验、UTF-8 编码校验、大规模 CSV 文件统计验证、外部 mecab-ko 工具依赖、以及固定样本文本精确分词比对的组合型问题。传统数据包模式（E241）覆盖 JSON/规则清单型但不完全适用 CSV/DEF 词典格式。

## 推荐方案
**方法**: nlp-dictionary-package-pattern

**说明**: |
  NLP 词典数据包核心模式：
  1. settings = None（不依赖编译器/架构）
  2. source() 使用 get() 下载 tarball
  3. build() 中验证数据完整性（CSV/DEF 文件数、条目数、UTF-8 编码）
  4. package() 中复制所有 CSV/DEF/dicrc 及生成的二进制索引文件
  5. test_package 中依次执行：文件存在性 → UTF-8 校验 → 条目统计 → 可选 mecab 分词测试
  6. 外部工具 mecab-ko 需单独安装（非本包源文件）

**验证/命令**:
```
# conanfile.py: settings = None; build() 验证 CSV/DEF/UTF-8; package() 复制数据
```

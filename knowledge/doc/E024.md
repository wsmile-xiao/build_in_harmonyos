# E024: Unix Domain Socket 受限

> **结构化数据**: [graph/E024.kv](../graph/E024.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: selinux/posix/network | **自动修复**: ❌ 需源码修改

---

## 错误特征

```
socket.bind(address) -> PermissionError: [Errno 1] Operation not permitted
```

## 根因

鸿蒙 SELinux 策略限制 Unix domain socket 的 `bind()` 操作。

## 解决方案

将 Unix domain socket 替换为 TCP socket：

```python
# ❌ 失败
listener = multiprocessing.connection.Listener('/tmp/socket')

# ✅ 成功
listener = multiprocessing.connection.Listener(('localhost', 0))
```

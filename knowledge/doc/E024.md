# E024: use-tcp-socket

## 基本信息

- **类别**: selinux, posix, network

## 错误特征
```
PermissionError.*bind.*socket|
                         Operation not permitted.*AF_UNIX|
                         Unix.*domain.*socket.*Permission
```

## 根因分析
鸿蒙 SELinux 策略限制 Unix domain socket 的 bind() 操作,
                         /tmp 目录下的 socket 文件创建受限

## 推荐方案
**方法**: use-tcp-socket

**说明**: 将 Unix domain socket(AF_UNIX)替换为 TCP socket(localhost)

**验证/命令**:
```
rec_auto_fix:          false
```

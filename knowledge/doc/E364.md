# E364: Isolate generated MPI wrappers from Worker-local CPPFLAGS

## 基本信息
- **严重度**: 2
- **类别**: relocatable, autoconf, mpi, openharmony, wrapper
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5510

## 错误特征
```
mpicc contains non-relocatable paths: /storage/Users/currentUser/usr/local
```

## 根因分析
MPICH configure copies the active CPPFLAGS into WRAPPER_CPPFLAGS. The OHOS Conan profile adds the Worker-only $HOME/usr/local/include path, so packaging embeds that absolute path in mpicc and the recipe's relocation guard rejects the package after the long build and upstream test run.

## 推荐方案
**方法**: recipe-owned-wrapper-flags

**说明**: Override CPPFLAGS in the recipe's configure command environment with the minimal target-neutral value required by the package, before configure snapshots WRAPPER_CPPFLAGS. Keep a package-time forbidden-path scan as a fail-closed backstop.

**验证/命令**:
```
Set CPPFLAGS=-DNDEBUG in the isolated MPICH native environment; run py_compile, the wrapper CPPFLAGS poison fixture, Pre-PR contract, independent W4, current-HEAD Review, and exact-current-HEAD CI.
```

# E263: Package tests must resolve runtime helpers from the installed layout contract

## 基本信息
- **严重度**: 2
- **类别**: python, java, packaging, testing
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: #3928

## 错误特征
```
FileNotFoundError:.*native_image_finalizer\.py|fake-java/bin/native_image_finalizer\.py|installed wrapper.*finalizer.*missing
```

## 根因分析
A test helper assumes the wrapper and its support module are source-tree siblings. The installed package deliberately places the public companion under bin and the support module under JAVA_HOME/libexec, so the test passes in the source tree but fails against the packaged artifact.

## 推荐方案
**方法**: layout-aware-helper-resolution

**说明**: Resolve the source-tree sibling first, then derive the installed runtime root through the wrapper's own JAVA_HOME contract and search its libexec support directory; report every searched path on failure.

**验证/命令**:
```
Use wrapper._java_home(wrapper_path) and append libexec/graalvm-ohos/native_image_finalizer.py after the sibling candidate.
```

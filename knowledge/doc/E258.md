# E258: meson.options 与 meson_options.txt 双文件（符号链接物化）导致 meson 拒绝配置

## 基本信息
- **严重度**: 2
- **类别**: meson, filesystem, symlink
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>
- **来源 PR**: source_commit:

## 错误特征
```
meson\.options and meson_options\.txt both exist, but are not the same file
```

## 根因分析
上游源码同时携带 meson.options 与 meson_options.txt（后者是前者的符号链接）。在 HMDFS 等文件系统上复制源码时符号链接被物化为独立普通文件，meson >= 1.5 检测到两份内容相同但非同一 inode 的文件时报错

## 推荐方案
**方法**: delete-duplicate-meson-options

**说明**: 删除 meson_options.txt（或恢复其为 meson.options 的符号链接），使两者为同一文件。meson 0.63+ 支持 meson.options 命名。conan get() 的 tarfile 提取保留符号链接不受影响。

**验证/命令**:
```
rm -f meson_options.txt
```

## 关键词
meson.options, meson_options.txt, both exist, same file, symlink

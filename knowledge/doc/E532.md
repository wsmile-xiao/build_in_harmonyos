# E532: 上游 CMake if(WIN32) elseif(UNIX) else() 平台三分支不识别 HarmonyOS，编译落入 else() 报 Unsupported platform

## 基本信息
- **严重度**: 3
- **类别**: platform, detection, ohos, posix, cmake
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !6204

## 错误特征
```
CMake Error.*Unsupported platform|message\(FATAL_ERROR "Unsupported platform|elseif \(UNIX\)|if \(WIN32 OR MINGW|No transport adapter was selected.*libcurl
```

## 根因分析
CMake 在 OHOS 工具链下将 CMAKE_SYSTEM_NAME 设为 "HarmonyOS"，它不是 WIN32 也不是 UNIX。
                        许多上游项目的 cmake-modules 用
                          if(WIN32 OR MINGW ...)  ...  elseif(UNIX)  ...  else() message(FATAL_ERROR "Unsupported platform.")
                        三分支做平台判定（例如 azure-sdk-for-cpp 的 cmake-modules/AzureTransportAdapters.cmake）。
                        HarmonyOS 平台（POSIX 语义、ELF、libc++）既不满足 WIN32 也不满足 UNIX，落入 else() 直接 FATAL。
                        配置阶段即失败，尚未进入编译。

## 推荐方案
**方法**: harmonyos-into-unix-branch

**说明**: 将平台判定条件由 elseif(UNIX) 扩展为 elseif(UNIX OR CMAKE_SYSTEM_NAME STREQUAL "HarmonyOS")，
                        使 HarmonyOS 落入 POSIX 分支，复用该分支的 curl/libcurl 传输适配与 POSIX 编译选项。
                        若判定语句写成 if(WIN32 ...) / elseif(UNIX ...) 的完整分支结构，仅需最小一处改动；
                        注意以 patch 形式提供，避免改动上游源码管理。

**验证/命令**:
```
sed -i 's/elseif (UNIX)/elseif (UNIX OR CMAKE_SYSTEM_NAME STREQUAL "HarmonyOS")/' cmake-modules/AzureTransportAdapters.cmake
```

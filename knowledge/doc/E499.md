# E499: Conan shared-package consumers need explicit transitive runtime libdirs

## 基本信息
- **严重度**: 2
- **类别**: conan, runtime, environment, shared-library
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !6320

## 错误特征
```
Error loading shared library libminizip\.so\.1|Error 127 while executing
```

## 根因分析
A shared Conan package can link successfully while its direct test consumer fails at execution because VirtualRunEnv does not infer every transitive dependency libdir from cpp_info.requires. The package export must propagate dependency libdirs through runenv_info, otherwise a runtime dependency such as minizip is absent from LD_LIBRARY_PATH even though the producer linked against it.

## 推荐方案
**方法**: export-transitive-runtime-libdirs

**说明**: In package_info(), iterate direct dependency cpp_info.libdirs and prepend each directory to self.runenv_info LD_LIBRARY_PATH. Keep cpp_info.requires for link metadata. Distinguish isolated producer-environment verification from a combined closure where test_package also reconstructs dependency libdirs.

**验证/命令**:
```
for _ref, dependency in self.dependencies.items(): for libdir in dependency.cpp_info.libdirs: self.runenv_info.prepend_path("LD_LIBRARY_PATH", libdir)
```

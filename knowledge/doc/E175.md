# E175: autoreconf-regenerate

## 基本信息
- **严重度**: 2
- **类别**: platform|hmdfs|autotools|filesystem
- **触发工具**: configure|config.status
- **阶段**: configuration

## 错误特征
```
can't create.*confXXXXXX.*Permission denied|mktemp -d.*./conf
```

**关键词**: HMDFS, Permission denied, confXXXXXX, mktemp, config.status

## 根因分析
HMDFS禁止在当前目录创建子目录后再写入文件（分布式一致性要求）

**影响范围**: 所有使用autotools的软件（smartmontools, procps-ng, groff, tmux等）

## 推荐方案
- **方法**: autoreconf-regenerate
- **描述**: 使用autoreconf -fvi重新生成configure脚本（需要automake 1.17+）
- **命令**: `autoreconf -fvi && ./configure --prefix=$DEFAULT_PREFIX`
- **自动修复**: true

## 验证
```bash
mktemp -d "./confXXXXXX" && ls "./confXXXXXX"
```

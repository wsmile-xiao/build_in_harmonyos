# E175: autoreconf-regenerate

## 基本信息
- **严重度**: 2
- **类别**: platform, hmdfs, autotools, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
can't create.*confXXXXXX.*Permission denied|mktemp -d.*./conf
```

## 根因分析
HMDFS禁止在当前目录创建子目录后再写入文件（分布式一致性要求）

## 推荐方案
**方法**: autoreconf-regenerate

**说明**: 使用autoreconf -fvi重新生成configure脚本（需要automake 1.17+）

**验证/命令**:
```
autoreconf -fvi && ./configure --prefix=$DEFAULT_PREFIX
```

HMDFS, Permission denied, confXXXXXX, mktemp, config.status

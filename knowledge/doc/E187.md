# E187: add-cmake-flag

## 基本信息
- **严重度**: 2
- **类别**: build_system
- **触发工具**: cmake
- **阶段**: configuration

## 错误特征
```
cmake_minimum_required VERSION < 3.5.*|Compatibility with CMake < 3.5 has been removed|Update the VERSION argument
```

**关键词**: cmake, cmake_minimum_required, version compatibility, policy version minimum

## 根因分析
CMake 4.x 不支持 cmake_minimum_required VERSION < 3.5，旧项目（如 woff2 1.0.2 要求 2.8.6）会直接报错退出。这是 CMake 版本升级的向后兼容性限制。

**影响范围**: 所有使用老版本 cmake_minimum_required 的项目，如 woff2、brotli 等

## 推荐方案
- **方法**: add-cmake-flag
- **描述**: 添加 CMAKE_POLICY_VERSION_MINIMUM 参数强制兼容。例如 cmake -DCMAKE_POLICY_VERSION_MINIMUM=3.5 ..
- **命令**: `cmake -DCMAKE_POLICY_VERSION_MINIMUM=3.5 ..`
- **自动修复**: false

## 验证
```bash
cmake --version && cmake -DCMAKE_POLICY_VERSION_MINIMUM=3.5 .. 2>&1 | grep -q "Configuring done"
```

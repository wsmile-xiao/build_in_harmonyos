# E187: add-cmake-flag

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
cmake_minimum_required VERSION < 3.5.*|Compatibility with CMake < 3.5 has been removed|Update the VERSION argument
```

## 根因分析
CMake 4.x 不支持 cmake_minimum_required VERSION < 3.5，旧项目（如 woff2 1.0.2 要求 2.8.6）会直接报错退出。这是 CMake 版本升级的向后兼容性限制。

## 推荐方案
**方法**: add-cmake-flag

**说明**: 添加 CMAKE_POLICY_VERSION_MINIMUM 参数强制兼容。例如 cmake -DCMAKE_POLICY_VERSION_MINIMUM=3.5 ..

**验证/命令**:
```
cmake -DCMAKE_POLICY_VERSION_MINIMUM=3.5 ..
```

# E015: configure-libs-option

## 错误特征
```
undefined symbol: libintl_dgettext|undefined reference to `_?dgettext'|undefined reference to `libintl_dgettext'
```

## 根因分析
软件 configure.ac 检测到 libintl.h 后使用 dgettext，
                        但未调用 AM_GNU_GETTEXT 来自动添加 -lintl 到链接标志。
                        当系统中有 gettext/libintl 安装时，源码使用真实的 dgettext（而非 no-op 宏），
                        但链接时缺少 -lintl 导致 undefined symbol。

## 推荐方案
**方法**: configure-libs-option

**说明**: configure 时传 LIBS="-lintl" 显式链接 gettext 库

**验证/命令**:
```
./configure --prefix=$DEFAULT_PREFIX LIBS="-lintl"
```

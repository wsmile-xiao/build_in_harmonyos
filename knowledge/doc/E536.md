## 根因分析
linux-firmware 项目包含各厂商的二进制固件 blob，brcm 子目录为 Broadcom 无线网卡固件。
                        此类资源不含 C/C++ 编译产物、无构建系统、无传统测试框架。Conan 适配为纯资源包模式。

## 推荐方案
**方法**: firmware-resource-package-validation

**说明**: Broadcom 固件资源包的完整验证流程，包括：固定 URL/版本/sha256、许可证验证、
                        文件清单/类型/非空/hash 校验、目录结构验证、无 ELF 检查、资源安装路径验证、
                        package_info 约束、无 Conan 第三方依赖、无硬件功能验证。

**验证/命令**:
```
# conanfile.py 关键模式:
                        #   package_type = "unknown"（无编译产物）
                        #   def build(): pass  # 无编译
                        #   def package(): copy(self, "*", src=..., dst="res/brcm")
                        #   def package_info(): self.cpp_info.resdirs = ["res"]  # 资源包声明
                        # test_package 验证：
                        #   conanfile.py 中 test() 调用 shell 脚本验证文件和路径
```

# E130: change-cxx-standard

## 基本信息
- **严重度**: 3
- **类别**: platform-libcxx-stdlib
- **触发工具**: clang|cmake|make
- **阶段**: compilation

## 错误特征
```
no member named 'nullptr_t' in the global namespace|unknown type name 'nullptr_t'|'__abi_tag__' attribute only applies to
```

**关键词**: nullptr_t, __abi_tag__, libcxx-ohos, c++17, c++11, OHOS SDK

## 根因分析
OHOS SDK (ohos-sdk_26.0.0.18) ships custom libc++ headers at libcxx-ohos/include/c++/v1/ designed for C++17+, projects using -std=c++11 fail with nullptr_t, __abi_tag__, and constexpr errors

**影响范围**: any C++ project compiled with -std=c++11 or lower on OpenHarmony

## 推荐方案
- **方法**: change-cxx-standard
- **描述**: Change -std=c++11 to -std=c++17 in CMakeLists.txt or build config, also disable -Werror
- **命令**: `sed -i 's/-std=c++11/-std=c++17/' CMakeLists.txt && cmake .. -DFAIL_ON_WARNINGS=OFF`
- **自动修复**: false

## 验证
```bash
echo '#include <string>' | clang++ -x c++ -std=c++11 -fno-rtti -isystem ~/usr/local/include - -o /dev/null
```

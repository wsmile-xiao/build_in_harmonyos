# E130: change-cxx-standard

## 基本信息
- **严重度**: 3
- **类别**: platform, libcxx-stdlib
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
no member named 'nullptr_t' in the global namespace|unknown type name 'nullptr_t'|'__abi_tag__' attribute only applies to
```

## 根因分析
OHOS SDK (ohos-sdk_26.0.0.18) ships custom libc++ headers at libcxx-ohos/include/c++/v1/ designed for C++17+, projects using -std=c++11 fail with nullptr_t, __abi_tag__, and constexpr errors

## 推荐方案
**方法**: change-cxx-standard

**说明**: Change -std=c++11 to -std=c++17 in CMakeLists.txt or build config, also disable -Werror

**验证/命令**:
```
sed -i 's/-std=c++11/-std=c++17/' CMakeLists.txt && cmake .. -DFAIL_ON_WARNINGS=OFF
```

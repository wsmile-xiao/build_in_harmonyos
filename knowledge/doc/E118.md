## 错误特征
```
mktemp.*Permission denied|can't create.*conf.*Permission denied|config\.status.*could not setup config files machinery
```

## 根因分析
HMDFS 文件系统对通过 `mktemp -d` 创建的临时目录施加特殊权限限制（setgid 标志），导致即使是目录创建者也无法在其中写入文件。这是 HMDFS 的安全机制，防止临时文件被恶意篡改。

## 推荐方案
**方法**: patch-script

**说明**: 修改 config.status 脚本的临时目录创建逻辑，使用预创建的固定目录替代 mktemp。具体做法是创建 `./config-tmp-fixed` 目录，并修改 config.status 第 588-595 行，将 `mktemp -d "./confXXXXXX"` 替换为直接使用固定目录。

**验证/命令**:
```
mkdir -p ./config-tmp-fixed && chmod 777 ./config-tmp-fixed && # 手动修改 config.status: tmp=./config-tmp-fixed; ac_tmp=$tmp
```

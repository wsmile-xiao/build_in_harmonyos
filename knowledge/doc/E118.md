# E118: patch-script

## 基本信息
- **严重度**: high
- **类别**: platform_restriction
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
mktemp.*Permission denied|can't create.*conf.*Permission denied|config\.status.*could not setup config files machinery
```

**关键词**: HMDFS, mktemp, config.status, autotools, Permission denied, 临时目录, configure

## 根因分析
HMDFS 文件系统对通过 `mktemp -d` 创建的临时目录施加特殊权限限制（setgid 标志），导致即使是目录创建者也无法在其中写入文件。这是 HMDFS 的安全机制，防止临时文件被恶意篡改。

**影响范围**: 所有使用 autotools 构建系统的软件，包括但不限于：autoconf 生成的 configure 脚本、任何调用 mktemp 创建临时目录的构建过程

## 推荐方案
- **方法**: patch-script
- **描述**: 修改 config.status 脚本的临时目录创建逻辑，使用预创建的固定目录替代 mktemp。具体做法是创建 `./config-tmp-fixed` 目录，并修改 config.status 第 588-595 行，将 `mktemp -d "./confXXXXXX"` 替换为直接使用固定目录。
- **命令**: `mkdir -p ./config-tmp-fixed && chmod 777 ./config-tmp-fixed && # 手动修改 config.status: tmp=./config-tmp-fixed; ac_tmp=$tmp`
- **自动修复**: false

## 验证
```bash
./config.status 2>&1 | grep -E "creating|error" && echo "✅ HMDFS workaround successful"
```

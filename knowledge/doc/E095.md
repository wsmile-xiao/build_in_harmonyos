## 错误特征
```
c\+\+: not found|
                         which c\+\+.*no|
                         checking for c\+\+.*no|
                         c\+\+: command not found
```

## 根因分析
部分软件使用自定义 configure 脚本（非 autoconf 生成），
                        脚本中硬编码 c++ 编译器名（如 `c++`、`g++`），
                        而非读取 $CXX 环境变量。
                        在 OpenHarmony 上系统无 `c++` 命令
                        （仅有 `clang++`），导致 configure 阶段
                        找不到 C++ 编译器而失败。

## 推荐方案
**方法**: set-env-var

**说明**: 显式传入 CXX=clang++ 参数给 configure 脚本，
                        覆盖脚本内部的硬编码值。
                        部分自定义脚本支持 CXX 参数但不会自动
                        从环境变量读取。

**验证/命令**:
```
./configure --prefix=$DEFAULT_PREFIX CXX=clang++
```

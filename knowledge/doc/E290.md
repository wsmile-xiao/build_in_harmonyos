# E290: CMake 类型探测不能使用 check_symbol_exists

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, cmake
- **作者**: 2301_79503900 <3308319887@qq.com>
- **来源 PR**: 3009

## 错误特征
```
check_symbol_exists.*typedef|HAVE_.*TYPE.*FALSE|unknown type name.*__kernel_|__kernel_rwf_t
```

## 根因分析
check_symbol_exists 只适合宏、函数和变量；对 typedef 或类型别名会尝试取地址并必然编译失败，使实际存在的目标类型被误判为不存在。

## 推荐方案
**方法**: compile-probe-for-type

**说明**: 用目标编译器编译一个包含目标头文件、声明该类型变量的最小源码，使 HAVE_* 结果与目标头文件中的真实类型定义一致

**验证/命令**:
```
include(CheckCSourceCompiles); check_c_source_compiles("#include <header.h>\nint main(void) { target_type *value = 0; return value != 0; }" HAVE_TARGET_TYPE)
```

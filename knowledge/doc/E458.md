# E458: probe-only-then-publish-deps

## 错误特征
```
add_subdirectory given source.*which does not contain a CMakeLists.txt|Compatibility with CMake < 3\.5 has been removed|unable to openfile.*\.dat|send file data error: 32 \(Broken pipe\)|Signal 11|_unit\.test\.sendfile|read_until: End of file
```

## 根因分析
restinio 0.6.19 官方 release tarball 未打包 bundled 依赖源码
                        （dev/asio、dev/fmt、dev/nodejs/http_parser 的 .c/.h 均缺失，
                        仅含 CMakeLists 骨架，需按 externals.rb 另行下载），CMake 默认路径
                        （RESTINIO_FIND_DEPS=OFF）add_subdirectory 直接失败；必须
                        RESTINIO_FIND_DEPS=ON + RESTINIO_USE_EXTERNAL_HTTP_PARSER=ON 走外部
                        依赖。http-parser 为 restinio 必需依赖且未发布 ohpcd 制品仓
                        → R36 依赖闭环。sendfile 测试在客户端中途断开时（Broken pipe）
                        触发 Signal 11 SIGSEGV，3/3 可复现（EXIT=139），根因待进一步
                        对照上游 issue 与 Linux x86_64 确认是否平台特有。

## 推荐方案
**方法**: probe-only-then-publish-deps

**说明**: header-only 库先以官方 tarball + externals.rb 装配依赖做
                        probe_only_no_upload 最小构建与上游测试，确认真实症状与数据路径；
                        required 依赖（http-parser）未发布时停止正式适配，按 R36 先发布
                        依赖到 ohpcd，再继续 conanfile 归档，不把依赖源码混入 restinio PR。

**验证/命令**:
```
cmake ../src/dev -DRESTINIO_SAMPLE=OFF -DRESTINIO_BENCH=OFF -DRESTINIO_ALLOW_SOBJECTIZER=OFF -DCMAKE_POLICY_VERSION_MINIMUM=3.5 && cmake --build . -j4 && ctest --output-on-failure
```

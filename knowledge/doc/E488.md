# E488: copy-rewrite（复制整个包到可写目录 + open/write 逐字节重写 .so + chmod 777 + rename）

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, ohos, python, permissions, dlopen
- **作者**: xiao921924 <f25015103@st.sandau.edu.cn>
- **来源 PR**: !5346

## 错误特征
```
Error loading shared library .*notmuch2.*|import notmuch2 失败.*Permission denied|dlopen.*permission denied
```

## 根因分析
OHOS HMDFS 文件系统强制文件 owner 为 20001006:file_manager（权限 770）——
  CI 用户 100 不在 owner/组——os.chmod 对非 owner 静默失败（实测 chmod 777 后
  权限仍为 770）——conan 打包/解包保留 owner——Python C 扩展（.so）dlopen 被拒
  （Permission denied）——test_package 直接 import 包目录 .so 失败

## 推荐方案
**方法**: copy-rewrite（复制整个包到可写目录 + open/write 逐字节重写 .so + chmod 777 + rename）

**说明**: copy-rewrite（复制整个包到可写目录 + open/write 逐字节重写 .so + chmod 777 + rename）

**验证/命令**:
```
|
  # 适用前提：源 .so 必须可读（owner 在 euid 组内）——CI 用户 100 无法读
  # owner 20001006 的 770 .so 时第一步（copytree/read 源 .so）也失败——
  # 此方案仅适用于本地/可读环境（euid 在 file_manager 组内）；CI 场景走
  # fallback（如实记录环境限制——申请特权环境）
  tmpdir = tempfile.mkdtemp(prefix="pkg_"); os.chmod(tmpdir, 0o777)
  shutil.copytree(site_pkg + "/<pkg>", tmpdir + "/<pkg>")
  so = tmpdir + "/<pkg>/_capi.abi3.so"; so_tmp = so + ".tmp"
  open(so_tmp,"wb").write(open(so,"rb").read()); os.chmod(so_tmp,0o777)
  os.remove(so); os.rename(so_tmp, so); sys.path.insert(0, tmpdir); import <pkg>
```

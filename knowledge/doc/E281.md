# E281: 资源型语音/音频 Conan 叶子包适配：无编译步骤，用 test_package 做消费者资源完整性验证

## 基本信息
- **严重度**: 2
- **类别**: packaging
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: 3583

## 错误特征
```
festvox|voice.*data|resource.*package|EST_File.*index|kedlpc8k|stub_test_method|strip_root
```

## 根因分析
OHOS 平台上存在一类纯语音/音频资源型 Conan 叶子包（如 Festival diphone voice data），tarball 只有数据文件（.scm/.group/COPYING），无 C/C++ 代码、无编译系统、无上游测试。Conan 适配时若按常规编译流程处理会失败：conan-init 生成错误的构建模板、L0 门禁要求 test() 必须调用 self.run()、strip_root 参数与 package() 路径不一致会导致资源找不到

## 推荐方案
**方法**: resource-package-file-copy

**说明**: conanfile.py 中 build() 为空，package() 直接复制文件到目标安装路径（share/<vendor>/...）；source() 用 strip_root=True 并把 package() 路径同步调整为去掉顶层目录后的相对路径

**验证/命令**:
```
get(self, **self.conan_data["sources"], strip_root=True) && copy(self, "*", src_dir, dst_dir)
```

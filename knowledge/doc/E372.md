# E372: Hash-bound authority HTTP fallback for Conan workers without curl or SSL

## 基本信息
- **严重度**: 3
- **类别**: conan
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5532

## 错误特征
```
\[Errno 2\] No such file or directory: 'curl'|Can't connect to HTTPS URL because the SSL module is not available|Trying another mirror
```

## 根因分析
A worker can lack both curl and Python SSL while its CI pre-download parser also truncates hyphenated archive URLs, leaving Conan unable to fetch an HTTPS-only source even though the recipe and checksum are correct.

## 推荐方案
**方法**: official-https-first-authority-http-fallback

**说明**: Keep the official HTTPS URL first, add only a direct byte-identical authority HTTP mirror second, retain one upstream SHA-256, and exercise the real Conan source fallback path.

**验证/命令**:
```
conan source <isolated-recipe> --output-folder <isolated-source-tree> -v
```

# E273: Installed PETSc metadata retains non-relocatable build paths

## 基本信息
- **严重度**: 2
- **类别**: conan, dependency, relocatable
- **作者**: HouYuxuan <f24011422@st.sandau.edu.cn>
- **来源 PR**: source_commit:

## 错误特征
```
PETSC_DIR does not point to PETSc installation path|No such file or directory.*petscvariables|hardcoded.*python3
```

## 根因分析
PETSc installation metadata embeds build-time absolute prefixes and interpreter paths; downloaded Conan binaries live at a different package path.

## 推荐方案
**方法**: relocate-private-dependency-copy

**说明**: Copy the PETSc package into the consumer build folder and rewrite only text metadata from the recorded prefix to the private copy; never modify the Conan cache.

**验证/命令**:
```
copy PETSc package to build_folder/petsc and replace recorded PREFIXDIR plus unavailable interpreter paths in text metadata
```

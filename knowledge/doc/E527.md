# E527: broadway-backend-native-tools-wrapper

## 基本信息
- **严重度**: 3
- **类别**: platform, meson, pkg-config, display, gnome
- **作者**: openharmory-agent <agent@openharmony.local>
- **来源 PR**: !6057

## 错误特征
```
Dependency ".*" not found|
                    X11 backend.*not found|
                    wayland.*not found.*try.*broadway|
                    Neither x11_backend nor wayland_backend nor broadway_backend is true|
                    Cannot open display|
                    cannot connect to X server|
                    gtk_init.*failed
```

## 根因分析
OHOS PC 无 X11/Wayland/Quartz/Win32 任何原生显示后端，
                    GTK3 的 meson.build 要求至少启用一个后端
                    （x11_backend/wayland_backend/broadway_backend 全 false 时
                    直接 configuration 失败），且默认后端连带依赖 epoxy(GL)、
                    xinerama、cloudproviders 等平台组件；
                    同时运行期 gtk_init() 需要 DISPLAY/连接显示服务，
                    纯编译通过不等于可运行（R40 深度适配边界）。
                    另有两类伴生问题：① glib-mkenums/glib-genmarshal 是构建时
                    Python 工具，交叉编译时必须在 build machine 执行而非 host；
                    ② 上游是 .pc 多文件体系，Conan PkgConfigDeps 只生成声明
                    的主 .pc，消费方 dependency('gtk+-3.0') 会找不到（同 E321）。

## 推荐方案
**方法**: broadway-backend-native-tools-wrapper

**说明**: 三件套组合：① meson 选项切 broadway HTML5 后端
                    （-Dx11_backend=false -Dwayland_backend=false
                    -Dbroadway_backend=true，纯 HTTP/WebSocket 输出无原生显示
                    依赖），同时禁 xinerama/cloudproviders/profiler/introspection/
                    gtk_doc/man/demos/examples/tests；② generate() 里把
                    glib-mkenums/glib-genmarshal 包装为 native 可执行 wrapper
                    （shebang 指向 build machine python3，注入 pkg-config 变量
                    让 meson 找到构建时工具）；③ PkgConfigDeps.generate() 后补
                    转发型别名 .pc（Version 动态继承主 .pc，Requires 主 .pc，
                    同 E321 手法）。运行期标注 R40 partial：需 broadwayd 服务 +
                    浏览器访问，GUI 行为不在 CI 断言范围。

**验证/命令**:
```
|
  # ① meson 选项（conanfile.py layout()/build() 中经 MesonToolchain 注入）
  #   -Dx11_backend=false -Dwayland_backend=false -Dbroadway_backend=true
  #   -Dxinerama=no -Dcloudproviders=disabled -Dintrospection=disabled
  #   -Dgtk_doc=false -Ddemos=false -Dexamples=false -Dtests=false
  # ② 构建 glib-mkenums native wrapper（generate() 内，参考
  #    archives/g/gtk/3.24.43/conanfile.py::_build_python_tool_wrapper）
  #    shebang: #!/usr/bin/env python3 → 指向 build machine 解释器
  # ③ 别名 .pc：_create_pkg_config_alias("gtk+-3.0", ...) 参考
  #    gdk-pixbuf 配方同名函数 / pango 配方 --alias-pc 生成
```

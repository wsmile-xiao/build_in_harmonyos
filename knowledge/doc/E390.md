# E390: 鸿蒙环境无 unzip 命令导致 Java/jar 构建失败

## 基本信息
- **严重度**: 2
- **类别**: build-system, java, environment
- **作者**: hhyxx1 <f24011422@st.sandau.edu.cn>
- **来源 PR**: !5799

## 错误特征
```
FileNotFoundError.*unzip|unzip.*No such file|not found.*unzip
```

## 根因分析
鸿蒙环境无 unzip 命令（Java/jar 构建场景），conanfile.py build() 或 test 脚本若调用 unzip 会报 FileNotFoundError

## 推荐方案
**方法**: 用 Python zipfile.extractall 替代 unzip 解压 jar，或使用 JDK 自带 jar 工具提取 META-INF/MANIFEST.MF

**说明**: 鸿蒙无 unzip 命令，Java/jar 构建中改用 Python zipfile 模块或 JDK jar 工具处理 jar 文件

**验证/命令**:
```
python3 -c "import zipfile; zipfile.ZipFile('lib.jar').extractall('out')" ; jar xf app.jar META-INF/MANIFEST.MF
```

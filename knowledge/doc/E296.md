# E296: Complete an OHOS Meson cross file on a Windows build host

## 基本信息
- **严重度**: 2
- **类别**: platform, build-system, meson, cross-compile
- **作者**: 2301_79503900 <3308319887@qq.com>
- **来源 PR**: 3034

## 错误特征
```
prefix value 'C:/' must be an absolute path|Unable to detect linker.*program not executable|Target: x86_64-w64-windows-gnu
```

## 根因分析
Conan's Meson helper derives the install prefix from the Windows build machine, while Meson validates it for the POSIX OHOS target. A CMake-only OHOS user toolchain is not consumed by Meson, so compiler paths alone retain the SDK clang default x86_64-w64-windows-gnu target and omit the OHOS sysroot and Windows-suffixed LLVM archiver tools.

## 推荐方案
**方法**: complete-meson-cross-machine

**说明**: Use a POSIX target prefix with Meson install staging, derive the SDK sysroot from the structured compiler path, add the OHOS target and sysroot to compile/link args, and inject absolute ar/ranlib paths into the generated Meson cross file.

**验证/命令**:
```
set Meson prefix to /; extend MesonToolchain c_args/cpp_args/c_link_args/cpp_link_args with --target=aarch64-linux-ohos and --sysroot=<sdk>/native/sysroot; set ar and ranlib from the SDK llvm/bin directory
```

## 错误特征
```
sed.*hang|sed.*stuck|Makefile.*garbled|
                         expr.*invalid|config\.status.*corrupt|
                         toybox.*sed.*unsupported
```

## 根因分析
鸿蒙默认的 toybox 工具链(sed/expr)对 POSIX
                         复杂脚本支持不完整, autotools 生成的
                         configure/Makefile 使用了 toybox 不支持的特性

## 推荐方案
**方法**: install-gnu-tools

**说明**: 通过预编译安装脚本安装 GNU sed + GNU coreutils 替代 toybox,
                         并将 $HOME/usr/local/bin 加入 PATH 前端

**验证/命令**:
```
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- sed 4.9 && curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- coreutils 9.10 && export PATH=$HOME/usr/local/bin:$PATH
```

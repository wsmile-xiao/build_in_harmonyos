# E010: toybox 兼容性问题

> **结构化数据**: [graph/E010.kv](../graph/E010.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: tool-compat | **自动修复**: ✅ install-script

## 错误特征

```
# Makefile 中出现乱码
# sed 进程卡住
# config.status 生成的 Makefile 异常
```

## 根因

鸿蒙默认的 toybox 工具链（sed/expr）对 POSIX 复杂脚本支持不完整：

| 特性 | toybox | GNU |
|------|--------|-----|
| 多行命令块 `{...}` | ❌ 不支持 | ✅ |
| 分支命令 `:label` / `b` / `t` 跳转 | ❌ 不支持 | ✅ |
| `expr` 复合正则 `\|` 操作符 | ❌ 乱码 | ✅ |

autotools 生成的 configure/Makefile 大量使用这些特性。

## 验证命令

```bash
# 对比测试 expr
expr X"ncurses/Makefile" : 'X\(.*[^/]\)//*[^/][^/]*/*$' \| . : '\(.\)'
# toybox 输出: 乱码
# GNU expr 输出: ncurses

# 检查当前 sed 版本
sed --version | head -1
# toybox: 无版本信息或显示 toybox
# GNU: GNU sed 4.9
```

## 解决方案

通过预编译安装脚本安装 GNU 工具：

```bash
# 安装 GNU sed 4.9
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/sed/install.sh | sh -s -- 4.9

# 安装 GNU coreutils 9.10（含 expr 等）
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/coreutils/install.sh | sh -s -- 9.10

# 确保 PATH 前端优先
export PATH=$HOME/usr/local/bin:$PATH
```

**适用场景**：ncurses、bash、任何大型 autotools 项目。

## 涉及软件

GNU sed、GNU coreutils（expr）、所有 autotools 构建系统项目。

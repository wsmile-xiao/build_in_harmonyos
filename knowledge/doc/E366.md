# E366: 纯 Emacs Lisp 包需要可复用的 emacs --batch 上游验证链路

## 基本信息
- **严重度**: 2
- **类别**: emacs-lisp-batch-validation-chain

## 错误特征
```
make: emacs: Permission denied|emacs: not found|Cannot open load file.*compat|Cannot open load file.*org|Cannot open load file.*notmuch|batch-byte-compile.*not_run|check-declare.*not_run
```

## 根因分析
OHOS Conan 环境缺少可运行的 packaged emacs batch 执行器，且 pure Elisp 依赖未通过 EMACSLOADPATH 暴露；因此上游 Makefile 中的 byte compile、autoload 生成和 check-declare 无法真实运行，容易退化成文件完整性或 test_package marker 验证

## 推荐方案
**方法**: package-emacs-batch-and-elisp-loadpath

**说明**: 先提供最小可运行的 emacs/29.1 batch 工具包，再把 pure Elisp 依赖作为 Conan package 暴露 lisp 安装目录，由 emacs 包的 buildenv_info/runenv_info 导出 EMACS、EMACSLOADPATH、EMACSDATA、EMACSDOC、EMACSPATH，最后在目标包 build() 中执行上游 batch 测试入口

**验证/命令**:
```
conan create archives/e/emacs/29.1 && conan create archives/c/compat/31.0.0.2 && conan create archives/o/org/9.8.8 && conan create archives/n/notmuch-emacs/0.40 && conan create archives/o/ol-notmuch/2.1.4
```

# E293: 2003 年代旧 C++ 代码在 C++17 标准下动态异常规范 throw(...) 与 register 关键字编译失败

## 基本信息
- **严重度**: 2
- **类别**: c++
- **作者**: runner002 <runner002@localhost>
- **来源 PR**: source_commit:

## 错误特征
```
ISO C\+\+17 does not allow dynamic exception specifications|
                         ISO C\+\+17 does not allow 'register' storage class specifier|
                         -Wdynamic-exception-spec|-Wregister|throw\(AiksaurusException\)
```

## 根因分析
2003 年前后编写的 C++ 代码广泛使用动态异常规范
                         throw(Type)（C++17 移除）和 register 存储说明符
                         （C++17 移除）。OHOS 编译 profile 设置
                         compiler.cppstd=17，clang -std=c++17 下这些特性
                         从 warning 升级为 hard error，导致旧 autotools
                         项目编译中断。知识图谱引擎常误匹配为工具链缺失
                         （E001 cc not found）或 shebang 问题（E165）。

## 推荐方案
**方法**: toolchain-flag

**说明**: 在 conanfile.py generate() 的 AutotoolsToolchain/
                         CMakeToolchain 中追加 -Wno-error=dynamic-exception-spec
                         与 -Wno-error=register，把这两个诊断降级为 warning

**验证/命令**:
```
tc.extra_cxxflags.append("-Wno-error=dynamic-exception-spec"); tc.extra_cxxflags.append("-Wno-error=register")
```

## 根因分析
配方只复制可执行文件而遗漏程序按编译时路径查找的网页、配置模板或数据资源，导致程序可启动但功能降级。

## 推荐方案
**方法**: package-runtime-resource-closure

**说明**: 从上游安装规则和源码路径常量建立运行时资源清单，按相同相对布局打包并测试。

**验证/命令**:
```
copy runtime files to package_folder/share and run packaged binary in an isolated directory
```

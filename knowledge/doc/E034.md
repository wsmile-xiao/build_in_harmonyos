# E034: install-ca-certs

## 错误特征
```
unable to load client CA certificates|SSL certificate verification failed|
                         ca-certificates.*not found|/etc/ssl/certs.*No such file
```

## 根因分析
鸿蒙系统未预装 ca-certificates 包,
                         缺少 /etc/ssl/certs/ca-certificates.crt

## 推荐方案
**方法**: install-ca-certs

**说明**: 通过鸿蒙系统 设置→安装证书→CA证书 导入证书包;
                         或从可信源下载 ca-certificates 并安装到 /etc/ssl/certs/

**验证/命令**:
```
rec_auto_fix:          false
```

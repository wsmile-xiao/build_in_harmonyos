# E034: 系统缺少 CA 证书包

> **结构化数据**: [graph/E034.kv](../graph/E034.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: ssl/packaging/filesystem | **自动修复**: ❌ 手动

---

## 错误特征

```
wget: unable to load client CA certificates
SSL 证书验证失败
```

## 根因

鸿蒙系统未预装 ca-certificates 包，缺少 `/etc/ssl/certs/ca-certificates.crt`。

## 解决方案

```bash
# 方案 1（推荐，永久）：通过鸿蒙系统设置导入
# 设置 → 安装证书 → CA证书 → 导入证书包

# 方案 2（临时，仅可信源）：跳过证书验证
wget --no-check-certificate https://example.com/file
curl -k https://example.com/file
```

## 禁止模式

❌ 在生产环境或不可信网络中使用 `--no-check-certificate` / `-k` → MITM 风险

## 涉及软件

wget 1.19.1、curl、Python requests 等所有 TLS 工具。

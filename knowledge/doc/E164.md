# E164: source-patch                  # 见 DESIGN §5 impl 列表

## 基本信息
- **严重度**: 3
- **类别**: platform-compat
- **触发工具**: gcc|clang|make
- **阶段**: compilation

## 错误特征
```
undefined reference to `adjtime'|error: 'adjtime' was not declared
```

**关键词**: adjtime, adjtimex, time adjustment, syscall

## 根因分析
OpenHarmony 使用 adjtimex syscall 替代 POSIX 标准的 adjtime 函数，adjtime 函数在 libc 中不存在

**影响范围**: 需要调整系统时间的软件（ntp 客户端、时间同步工具等），如 htpdate、ntpdate、chrony 等

## 推荐方案
- **方法**: source-patch                  # 见 DESIGN §5 impl 列表
- **描述**: 添加 OpenHarmony 兼容性补丁，用 adjtimex 替换 adjtime
- **自动修复**: false                         # 需要根据软件具体情况调整补丁

## 验证
```bash
grep -r "adjtime" ${BUILD_SRC_DIR}/*.c || echo "No adjtime usage found"
```

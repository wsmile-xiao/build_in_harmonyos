# E353: CMake static upstream tests must link the real target

## 基本信息
- **严重度**: 1
- **类别**: cmake, static-library, target-identity, upstream-tests
- **作者**: asp1r1n1 <912802346@qq.com>
- **来源 PR**: !3401

## 错误特征
```
cannot find -lgd|No rule to make target.*libgd|GD_LIB.*gd_static|static.*test.*target
```

## 根因分析
Static-only CMake variants can create a different target name than the upstream test helper expects, so the helper falls back to a bare linker name and loses the target dependency.

## 推荐方案
**方法**: test-helper-target-alias

**说明**: When upstream tests are enabled, patch the test helper variable to the actual CMake target produced by the selected static/shared variant.

**验证/命令**:
```
ctest --test-dir ${BUILD_DIR} --output-on-failure
```

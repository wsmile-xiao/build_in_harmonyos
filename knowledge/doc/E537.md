# E537: Conan cache absolute DT_NEEDED leakage and relocatable SONAME/link repair

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, linking, conan, packaging, relocatable
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !6997

## 错误特征
```
DT_NEEDED|NEEDED|\.cache/conan2|\.conan2/p/|unable to find library|
                         Error loading shared library|Permission denied|mmap PROT_EXEC|
                         IMPORTED_SONAME|target_link_directories|SONAME
```

## 根因分析
>
  A KDE Frameworks (KF6) dependency library (e.g. kcoreaddons/karchive/ki18n) is
  published without a DT_SONAME. When the dependent library (e.g. libKF6Package.so)
  is linked against that dependency, CMake passes the dependency's absolute Conan
  cache path (IMPORTED_LOCATION) to the linker. Because the dependency has no
  SONAME, ld records the machine-private absolute path (e.g.
  /storage/Users/currentUser/.conan2/p/... or an older .cache/conan2 layout) into
  the produced DT_NEEDED. On a consumer machine with a different Conan cache
  layout that absolute path does not exist, so the loader cannot resolve the
  dependency and the published artifact is not consumable. A post-build ELF
  rewrite with patchelf can remove the paths, but on the OHOS HMDFS cache
  filesystem the patchelf-rewritten file is refused at runtime with
  "Permission denied" (mmap PROT_EXEC), so the repair must happen at link time.

## 推荐方案
**方法**: link-time-SONAME-basename

**说明**: >
  Do not rewrite the ELF after build. Instead make the linker record the
  dependency by its SONAME-style basename at link time: (1) stamp an
  IMPORTED_SONAME on each KF6 dependency target and clear both generic and
  per-config IMPORTED_NO_SONAME (IMPORTED_NO_SONAME_RELEASE) so CMake passes
  "-L<dir> -l:libKF6CoreAddons.so"; or, more robustly, (2) add
  target_link_directories(KF6Package PUBLIC ${KPACKAGE_DEP_LIB_DIRS}) and link
  the deps by bare "-lKF6CoreAddons" / "-lKF6Archive" / "-lKF6I18n", explicitly
  re-adding Qt6::Core (which keeps its own SONAME) so the Qt runtime link is
  preserved, and copy the deps' INTERFACE_INCLUDE_DIRECTORIES back onto the
  target so headers (QStringList/KJob/QLoggingCategory) remain available. Give
  the produced library a stable SONAME with -Wl,-soname,libKF6Package.so.

**验证/命令**:
```
target_link_directories(KF6Package PUBLIC ${KPACKAGE_DEP_LIB_DIRS})
```

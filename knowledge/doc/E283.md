# E283: Conan library 包的 shared 选项契约

## 基本信息
- **严重度**: 3
- **类别**: conan
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: 2107

## 错误特征
```
Package type is 'library', but no 'shared' option declared
```

## 根因分析
Conan 的 library 包类型要求标准 shared 选项决定包 ID 和链接类型，缺失时配方契约无效。

## 推荐方案
**方法**: declare-shared-contract

**说明**: 声明标准 shared 选项和默认值，并将该选项传递给构建系统。

**验证/命令**:
```
options = {'shared': [True, False]}; default_options = {'shared': False}
```

## 关键词
package_type, library, shared option, default_options

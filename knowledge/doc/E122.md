# E122: add-linux-ohos-to-validation

## 错误特征
```
Invalid configuration.*Kernel.*linux.*not known to work with OS.*ohos|
                         Kernel.*linux.*not known to work with OS.*ohos|
                         linux-ohos.*not recognized
```

## 根因分析
GNU config.sub 脚本的 kernel-os 组合验证（case $kernel-$os-$obj in）
                         只包含 linux-gnu、linux-android、linux-musl 等已知组合，
                         不包含 linux-ohos。当 config.guess 输出 aarch64-unknown-linux-ohos
                         时，config.sub 在最终验证阶段拒绝此三元组。
                         patch-autotools-ohos.pl 脚本只修改了 OS 列表和基本三元组，
                         但未修改 kernel-os 验证列表。

## 推荐方案
**方法**: add-linux-ohos-to-validation

**说明**: 在 config.sub 的 kernel-os 验证列表中添加 linux-ohos*-。
                         定位到 "case $kernel-$os-$obj in" 分支，
                         在 linux-uclibc*- 后添加 linux-ohos*-。

**验证/命令**:
```
sed -i '/linux-uclibc\*- )/a\            | linux-ohos*- )/' build-aux/config.sub
```

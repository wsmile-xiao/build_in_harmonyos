# E122: add-linux-ohos-to-validation

## 基本信息
- **严重度**: 2
- **类别**: autotools-config
- **触发工具**: config.sub
- **阶段**: configuration

## 错误特征
```
Invalid configuration.*Kernel.*linux.*not known to work with OS.*ohos|
```

**关键词**: config.sub, kernel-os, linux-ohos, Invalid configuration,

## 根因分析
GNU config.sub 脚本的 kernel-os 组合验证（case $kernel-$os-$obj in）

**影响范围**: **所有 autotools 项目**（在应用 patch-autotools-ohos.pl 后仍可能遇到）

## 推荐方案
- **方法**: add-linux-ohos-to-validation
- **描述**: 在 config.sub 的 kernel-os 验证列表中添加 linux-ohos*-。
- **命令**: `sed -i '/linux-uclibc\*- )/a\            | linux-ohos*- )/' build-aux/config.sub`
- **自动修复**: false

## 验证
```bash
grep "linux-gnu\*-" build-aux/config.sub;
```

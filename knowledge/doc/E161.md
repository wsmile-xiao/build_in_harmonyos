# E161: avoid-pipe-use-files

## 基本信息
- **严重度**: 3
- **类别**: platform-limitation
- **触发工具**: sort|tail|grep|cat
- **阶段**: configuration

## 错误特征
```
sort: stat failed: -: Permission denied|tail: cannot fstat 'standard input': Permission denied|grep:.*Permission denied
```

**关键词**: sort, tail, grep, stdin, Permission denied, stat failed, fstat, pipe, GNU coreutils, SELinux, HarmonyOS

## 根因分析
GNU coreutils 的 sort/tail/grep 命令在从 stdin（文件描述符 0）读取时，调用 fstat() 或 stat() 检查 stdin 的状态，但鸿蒙系统的 SELinux 或权限管理限制了这一操作，导致 "Permission denied" 错误。

**影响范围**: 所有使用管道（| sort、| tail、| grep）的场景，尤其是 Autotools 构建的软件（configure/config.status 脚本大量使用管道）

## 推荐方案
- **方法**: avoid-pipe-use-files
- **描述**: 使用临时文件代替管道输入。例如：先写入临时文件，再让 sort/tail/grep 读取文件，而不是直接从 stdin 读取。
- **命令**: `|`
- **自动修复**: false

## 验证
```bash
echo "test" | sort
```

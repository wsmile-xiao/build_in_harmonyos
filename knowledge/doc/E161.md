# E161: avoid-pipe-use-files

## 基本信息
- **严重度**: 3
- **类别**: platform, limitation
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
sort: stat failed: -: Permission denied|tail: cannot fstat 'standard input': Permission denied|grep:.*Permission denied
```

## 根因分析
GNU coreutils 的 sort/tail/grep 命令在从 stdin（文件描述符 0）读取时，调用 fstat() 或 stat() 检查 stdin 的状态，但鸿蒙系统的 SELinux 或权限管理限制了这一操作，导致 "Permission denied" 错误。

## 推荐方案
**方法**: avoid-pipe-use-files

**说明**: 使用临时文件代替管道输入。例如：先写入临时文件，再让 sort/tail/grep 读取文件，而不是直接从 stdin 读取。

**验证/命令**:
```
|
  # 验证问题：
  echo "test" | sort  # ❌ 失败
  echo "test" > /tmp/test.txt && sort /tmp/test.txt  # ✅ 成功

  # 在 configure/config.status 中：
  # 修改管道为文件读写（需要手动编辑脚本）
  # 或等待平台修复 SELinux 权限
```

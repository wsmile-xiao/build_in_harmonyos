# E435: gpgrt-config (libgpg-error config script) hangs under OHOS /bin/sh (mksh) — wrap with bash

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, autotools, shell
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>
- **来源 PR**: !6301

## 错误特征
```
gpgrt-config.*hang|read VAR_ <<EOF.*mksh|configure: checking for GPG Error.*hang|gpg-error-config: No such file or directory.*test: integer expected
```

## 根因分析
libgpg-error 的 gpgrt-config POSIX 脚本在 OHOS /bin/sh (/system/bin/sh, mksh) 下执行 read VAR <<EOF 时死循环挂起；同脚本在 bash 下正常。configure 调用 $GPG_ERROR_CONFIG --modversion 时挂死，导致 configure 卡住。

## 推荐方案
**方法**: build-local-bash-wrapper

**说明**: 在构建目录创建 gpgrt-config bash 包装脚本（exec bash 真实 gpgrt-config），prepend PATH 让 configure 找到包装器；同时提供修正后的 gpg-error.pc（依赖包 .pc 的 prefix=/ 错误）

**验证/命令**:
```
printf "#!/bin/sh\nexec /data/service/hnp/bin/bash <pkg>/bin/gpgrt-config \"$@\"\n" > <build>/bin/gpgrt-config && chmod +x <build>/bin/gpgrt-config && PATH=<build>/bin:$PATH ./configure
```

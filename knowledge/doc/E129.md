# E129: sed-replace

## 基本信息
- **严重度**: 3
- **类别**: platform-hmdfs
- **触发工具**: configure|config.status
- **阶段**: configuration

## 错误特征
```
config\.status.*Permission denied.*subs1\.awk|can't create.*conf[A-Za-z0-9]+.*Permission denied|could not setup config files machinery
```

**关键词**: umask 077, Permission denied, config.status, mktemp, subs1.awk, HMDFS, setgid

## 根因分析
HMDFS filesystem always sets setgid bit on new directories; umask 077 creates drwx--S--- which blocks even the owner from writing files inside it

**影响范围**: All autotools software using configure/config.status on HarmonyOS

## 推荐方案
- **方法**: sed-replace
- **描述**: Replace umask 077 with umask 022 in configure and config.status scripts (lines creating temp directories)
- **命令**: `sed -i 's/umask 077/umask 022/g' configure config.status`
- **自动修复**: true

## 验证
```bash
cd ~/tmp && (umask 077 && tmp=$(mktemp -d "./confXXXXXX") && echo test > "$tmp/testfile" && echo FAIL || echo PASS) && rm -rf ./conf*
```

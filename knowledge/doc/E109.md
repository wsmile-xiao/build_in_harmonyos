# E109: use-prebuilt-package

## 基本信息
- **严重度**: 3
- **类别**: build_tool_missing
- **触发工具**: make
- **阶段**: compilation

## 错误特征
```
gfortran: No such file or directory|make\[.*\]: gfortran: No such file or directory|FC=gfortran|\.f\.o:\s+Error\s+127|\.f\s+compilation failed
```

**关键词**: fortran,gfortran,\.f文件,fortran编译器缺失,F77,F90,F95

## 根因分析
OpenHarmony系统未预装Fortran编译器（gfortran），且预编译包仓库中无Fortran编译器预编译包。Fortran项目无法在OpenHarmony平台直接编译，需要交叉编译或等待官方提供编译器支持。

**影响范围**: 所有Fortran项目（源码为.f/.f90/.f95文件），包括qrupdate、BLAS/LAPACK等科学计算库

## 推荐方案
- **方法**: use-prebuilt-package
- **描述**: 1. 交叉编译：在其他支持Fortran的平台编译后移植到OpenHarmony\n2. 等待OpenHarmony官方提供gfortran预编译包\n3. 使用功能替代库（如LAPACK/Eigen提供类似功能）
- **命令**: `无法通过本地命令解决。建议标记为failed，记录到归档notes.md等待官方支持。`
- **自动修复**: false

## 验证
```bash
gfortran --version && which f77 f90 f95
```

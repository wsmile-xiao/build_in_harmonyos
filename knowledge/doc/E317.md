# E317: sed-range-limited-replace

## 基本信息
- **严重度**: 3
- **类别**: ohos, autotools, make, install, shell
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: source_commit:

## 错误特征
```
normalizePath\(R\.home\(.share.\).*No such file or directory|//lib/R/share|R_SHARE_DIR.*固化|R_INCLUDE_DIR.*固化|R_DOC_DIR.*固化
```

## 根因分析
R 的 src/scripts/Makefile.in install 规则用 sed 全局替换 s/\(VAR=\).*/ 处理 R_SHARE_DIR=/R_INCLUDE_DIR=/R_DOC_DIR=，把配方中本应运行时展开的 R_SHARE_DIR="${R_HOME_DIR}/share" shell 变量引用也一并固化为 configure 编译期值（--prefix=/ 时即 //lib/R/share）。移动后该路径不存在。需改为范围限定替换 1,/VAR=/s/\(VAR=\).*/，只替换第一个出现（即 configure 固化的默认行），保留 re-derive 块中的变量引用。

## 推荐方案
**方法**: sed-range-limited-replace

**说明**: 补丁 0009 将 src/scripts/Makefile.in install 规则中 R_SHARE_DIR/R_INCLUDE_DIR/R_DOC_DIR 的 sed 替换从全局 s/\(VAR=\).*/ 改为范围限定 1,/VAR=/s/\(VAR=\).*/，与 R_HOME_DIR 的处理方式对齐。只替换第一个出现（即 configure 固化的默认行），保留后续 re-derive 块中的 R_SHARE_DIR="${R_HOME_DIR}/share" 变量引用，使资源目录在包移动后仍能从运行时验证的 R_HOME_DIR 重新推导。

**验证/命令**:
```
cd $R_HOME && patch -p1 < archives/r/r-base/4.5.1/patches/0009-sed-range-relocatable-resource-dirs.patch && make -j4 && make install DESTDIR=$TEST_PREFIX
```

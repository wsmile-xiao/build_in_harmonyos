# E303: 受限进程不可枚举根目录导致 hostfs 身份探测误判

## 基本信息
- **严重度**: 3
- **类别**: restricted-process-filesystem-probe
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
error: can't open `/': Permission denied[.]?|opendir.*[/].*EACCES
```

## 根因分析
受限运行域可能允许路径搜索和已知文件访问，却拒绝读取根目录项；hostfs 将仅用于确认宿主伪磁盘的 opendir("/") EACCES 当成坏文件名，使真实目标文件尚未检查就提前失败

## 推荐方案
**方法**: scope-root-probe-eacces

**说明**: 仅当 errno 为 EACCES 且探测路径严格等于 / 时，把 hostfs 身份探测视为成功；按运行时能力失败判断而不依赖平台宏，后续实际文件打开仍由原有函数校验并保留所有其他错误

**验证/命令**:
```
patch --dry-run --fuzz=0 -p1 -d "$GRUB_SOURCE_ROOT" -i "$RECIPE_ROOT/patches/0010-grub-core-kern-emu-hostfs.c.patch"
```

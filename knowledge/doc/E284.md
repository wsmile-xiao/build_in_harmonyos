# E284: 交叉构建时生成目标平台配置头而非复用 host 探测结果

## 基本信息
- **严重度**: 2
- **类别**: portability, configure, cross-compile
- **作者**: 2301_79503900 <3308319887@qq.com>
- **来源 PR**: 3006

## 错误特征
```
unknown type name.*u_int16_t|sparseconfig.h|generated.*config.*host|target.*configuration header
```

## 根因分析
Autoconf/CMake 生成的 config.h 类头文件记录运行探测环境的类型、命名空间和功能宏；交叉构建若复用 Windows 或其他 host 生成结果，会把主机能力误当成 OHOS 目标能力。

## 推荐方案
**方法**: generate-target-config-header

**说明**: 根据已验证的目标平台能力显式生成最小配置头，并用目标编译器编译上游测试与真实消费者

**验证/命令**:
```
conan.tools.files.save() 生成目标 config 头；clang++ --target=aarch64-linux-ohos 编译验证
```

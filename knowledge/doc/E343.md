# E343: qtmultimedia 需 qtshadertools 的 Qt6ShaderTools_DIR

## 基本信息
- **严重度**: 2
- **类别**: qt6-module-adapt
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: !5160

## 错误特征
```
Unknown CMake command "qt_internal_add_shaders"
```

## 根因分析
qtmultimedia 的 src/multimedia 用 qt_internal_add_shaders 预编译 shader，需 qtshadertools 包提供的 CMake 宏

## 推荐方案
**方法**: CMakeToolchain 显式设 Qt6ShaderTools_DIR=<qtshadertools 包>/lib/cmake/Qt6ShaderTools + CMAKE_PREFIX_PATH

**说明**: CMakeToolchain 设置 Qt6ShaderTools_DIR 指向 qtshadertools 包 lib/cmake/Qt6ShaderTools，使 qt_internal_add_shaders 宏可用

**验证/命令**:
```
-DQt6ShaderTools_DIR=<qtshadertools>/lib/cmake/Qt6ShaderTools
```

## 关键词
qt_internal_add_shaders, Qt6ShaderTools_DIR, qtshadertools

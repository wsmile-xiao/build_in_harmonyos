## 错误特征
```
System is unknown to cmake|
                         CMAKE_SYSTEM_NAME.*ohos|
                         not find toolchain|
                         harmonyos.*not supported|
                         Unknown system.*harmonyos
```

## 根因分析
CMake 不认识 HarmonyOS 作为目标平台，
                        没有对应的 platform module。
                        当 CMake 检测到系统名称为 harmonyos/ohos 时，
                        无法匹配任何已知平台（Linux, Darwin, Windows 等），
                        导致 configure 阶段失败或生成错误的构建文件。
                        HarmonyOS 基于 Linux 内核，CMake 的 Linux 平台
                        模块通常可以直接使用。

## 推荐方案
**方法**: cmake-toolchain

**说明**: 通过 -DCMAKE_SYSTEM_NAME=Linux 配合 toolchain 文件，
                        让 CMake 将 HarmonyOS 视为 Linux 平台。
                        在 toolchain 文件中设置 CMAKE_SYSTEM_PROCESSOR=aarch64
                        和编译器路径。

**验证/命令**:
```
cmake -B build -DCMAKE_SYSTEM_NAME=Linux -DCMAKE_SYSTEM_PROCESSOR=aarch64 -DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++ --prefix=$DEFAULT_PREFIX
```

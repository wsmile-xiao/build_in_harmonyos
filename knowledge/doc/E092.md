# E092: CMake 不识别 HarmonyOS 平台

> **结构化数据**: [graph/E092.kv](../graph/E092.kv) | **原则**: P-PATCH-001
> **严重度**: 🟡 medium | **分类**: platform_detection|cmake | **自动修复**: ✅ cmake-override

---

## 错误特征

```
CMake Error: System is unknown to cmake
CMAKE_SYSTEM_NAME = harmonyos
```

或 configure 阶段报告：
```
Not find toolchain for harmonyos
harmonyos is not supported
```

## 根因

CMake 构建系统不认识 HarmonyOS 作为目标平台，没有对应的 platform module。
当 CMake 检测到系统名称为 `harmonyos` 或 `ohos` 时，无法匹配任何已知平台
（Linux, Darwin, Windows 等），导致 configure 阶段失败或生成错误的构建文件。

HarmonyOS 基于 Linux 内核，CMake 的 Linux 平台模块通常可以直接使用。

## 影响范围

所有使用 CMake 构建系统的跨平台软件。已知受影响：
- **blosc** — 压缩库
- **zstd** — Zstandard 压缩
- **zopfli** — 压缩算法
- **physfs** — 物理文件系统抽象

## 解决方案

### 方案 1（推荐）：设置 CMAKE_SYSTEM_NAME=Linux

通过 CMake 变量将 HarmonyOS 映射为 Linux 平台：

```bash
cmake -B build \
  -DCMAKE_SYSTEM_NAME=Linux \
  -DCMAKE_SYSTEM_PROCESSOR=aarch64 \
  -DCMAKE_C_COMPILER=clang \
  -DCMAKE_CXX_COMPILER=clang++ \
  -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX
```

配合 toolchain 文件（推荐）：

```cmake
# toolchain-ohos.cmake
set(CMAKE_SYSTEM_NAME Linux)
set(CMAKE_SYSTEM_PROCESSOR aarch64)
set(CMAKE_C_COMPILER clang)
set(CMAKE_CXX_COMPILER clang++)
```

```bash
cmake -B build --toolchain toolchain-ohos.cmake -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX
```

### 方案 2：手动设置关键变量

```bash
cmake -B build \
  -DCMAKE_SYSTEM_NAME=Linux \
  -DCMAKE_SYSTEM_PROCESSOR=aarch64 \
  -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX
```

## 验证

```bash
# 检查 CMake 系统信息
cmake --system-information 2>&1 | grep CMAKE_SYSTEM_NAME

# 确认构建成功
cmake --build build -j$(nproc)
```

## ⛔ 禁止

- **不要**将 `CMAKE_SYSTEM_NAME` 设为 `ohos` 或 `HarmonyOS`，CMake 不认识此平台名称，
  会导致无法加载任何平台模块，构建系统完全失效。

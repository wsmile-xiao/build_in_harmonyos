# E178: autoreconf-regenerate

## 基本信息
- **严重度**: 0
- **类别**: platform|toolchain|resolved
- **触发工具**: configure|autoreconf
- **阶段**: configuration

## 错误特征
```
automake not found|autoreconf: failed
```

**关键词**: autoreconf, automake, coreutils, new toolchain

## 根因分析
旧工具链缺少automake导致无法使用autoreconf重新生成configure

**影响范围**: 所有autotools项目（8+软件）

## 推荐方案
- **方法**: autoreconf-regenerate
- **描述**: 新工具链提供automake 1.17，可用autoreconf -fvi重新生成configure
- **命令**: `autoreconf -fvi && ./configure --prefix=$DEFAULT_PREFIX`
- **自动修复**: true

## 验证
```bash
autoreconf --version && automake --version
```

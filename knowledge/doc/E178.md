## 错误特征
```
automake not found|autoreconf: failed
```

## 根因分析
旧工具链缺少automake导致无法使用autoreconf重新生成configure

## 推荐方案
**方法**: autoreconf-regenerate

**说明**: 新工具链提供automake 1.17，可用autoreconf -fvi重新生成configure

**验证/命令**:
```
autoreconf -fvi && ./configure --prefix=$DEFAULT_PREFIX
```

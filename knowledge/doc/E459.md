# E459: Prune a bundled database client graph for OHOS CMake cross builds

## 基本信息
- **严重度**: 3
- **类别**: cmake, cross-compile, conan, client-library, openharmony
- **作者**: 2301_79503900 <3308319887@qq.com>
- **来源 PR**: !5751

## 错误特征
```
FindCurses|MYSQL_CHECK_RPC|cannot execute.*target|Permission denied.*symlink|try_run
```

## 根因分析
A large CMake database source tree keeps server-oriented checks, bundled helper targets, convenience symlinks, and target executables in a client-only cross-build graph. OHOS CMake and HMDFS expose these assumptions as configure, build, or packaging failures.

## 推荐方案
**方法**: semantic-client-graph-pruning

**说明**: Keep the target OS module selected by upstream CMake, disable server-only features, skip unused RPC/configure probes, resolve build tools with TARGET_FILE, avoid HMDFS convenience symlinks, provide explicit dependency cache variables, make each helper target own its compile dependencies, and mirror platform include conditions in unit-test targets.

**验证/命令**:
```
cmake -S . -B build -DCMAKE_SYSTEM_NAME=Linux -DOHOS=ON -DWITHOUT_SERVER=ON -DWITH_ROUTER=OFF -DWITH_NDB=OFF
```

# E117: create_cmake_template

## 基本信息
- **严重度**: 2
- **类别**: cmake_template
- **触发工具**: cmake
- **阶段**: configuration

## 错误特征
```
CMake Error: File .*config-cmake\.h\.in does not exist|PACKAGE_STRING undeclared|use of undeclared identifier 'PACKAGE_STRING'
```

**关键词**: config-cmake.h.in, PACKAGE_STRING, cmake CONFIGURE_FILE, undeclared identifier PACKAGE

## 根因分析
cmake 项目 CMakeLists.txt 使用 CONFIGURE_FILE(config-cmake.h.in ...) 但模板文件缺失或使用了 autotools @...@ 语法而非 cmake ${...} 语法,导致 cmake configure 失败或编译时 PACKAGE_STRING 等宏未定义

**影响范围**: 所有包含 cmake CONFIGURE_FILE 指令的 C 项目,特别是同时支持 cmake 和 autotools 的双构建系统项目

## 推荐方案
- **方法**: create_cmake_template
- **描述**: 创建或修复 config-cmake.h.in 文件,使用 cmake ${...} 变量语法替换 autotools @...@ 语法,确保 PACKAGE/VERSION/PACKAGE_STRING 等宏定义完整
- **命令**: `cat > config-cmake.h.in << 'EOF'\n#ifndef CONFIG_H\n#define CONFIG_H\n#cmakedefine WORDS_BIGENDIAN\n#define SIZEOF_LONG ${SIZEOF_LONG}\n#define PACKAGE "${PACKAGE}"\n#define VERSION "${VERSION}"\n#define PACKAGE_STRING "${PACKAGE_STRING}"\n#endif\nEOF`
- **自动修复**: false

## 验证
```bash
grep CONFIGURE_FILE CMakeLists.txt && cmake --build build && grep PACKAGE_STRING build/config.h
```

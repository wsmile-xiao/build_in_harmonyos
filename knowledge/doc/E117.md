# E117: create_cmake_template

## 基本信息

- **类别**: cmake
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
CMake Error: File .*config-cmake\.h\.in does not exist|PACKAGE_STRING undeclared|use of undeclared identifier 'PACKAGE_STRING'
```

## 根因分析
cmake 项目 CMakeLists.txt 使用 CONFIGURE_FILE(config-cmake.h.in ...) 但模板文件缺失或使用了 autotools @...@ 语法而非 cmake ${...} 语法,导致 cmake configure 失败或编译时 PACKAGE_STRING 等宏未定义

## 推荐方案
**方法**: create_cmake_template

**说明**: 创建或修复 config-cmake.h.in 文件,使用 cmake ${...} 变量语法替换 autotools @...@ 语法,确保 PACKAGE/VERSION/PACKAGE_STRING 等宏定义完整

**验证/命令**:
```
cat > config-cmake.h.in << 'EOF'\n#ifndef CONFIG_H\n#define CONFIG_H\n#cmakedefine WORDS_BIGENDIAN\n#define SIZEOF_LONG ${SIZEOF_LONG}\n#define PACKAGE "${PACKAGE}"\n#define VERSION "${VERSION}"\n#define PACKAGE_STRING "${PACKAGE_STRING}"\n#endif\nEOF
```

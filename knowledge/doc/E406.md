# E406: scout/recipe 创建期 SHA-256 必须多网络路径交叉验证

## 基本信息
- **严重度**: 2
- **类别**: dependency, download, scout, sha256
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: !5959

## 错误特征
```
sha256 hash failed.*Provided.*Computed|hash.*mismatch|scout.*sha256
```

## 根因分析
scout 或 recipe 创建阶段只走单一网络路径（直连或某一代理）采集
                    上游源码 SHA-256 时，若该路径返回被改动的内容，采集到的 hash
                    会偏离官方字节；错误 hash 写进 conandata.yml/manifest，
                    直到 CI 下载校验才暴露。

## 推荐方案
**方法**: multi-path-cross-verify

**说明**: 创建期 hash 必须多网络路径交叉验证：官方 codeload/直连 + 独立本机
                    路径 + 至少 1 个代理；对比字节与 hash，一致才可写入 conandata.yml。

**验证/命令**:
```
curl -fsSL <official-tar.gz> | sha256sum; 对第二网络路径重复，比对一致
```

# E285: OpenAL 类音频库在无音频设备环境下关闭外部后端并以 Null/loopback 完成构建与替代验证

## 基本信息
- **严重度**: 2
- **类别**: portability
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: source_commit:

## 错误特征
```
No Output|ALC_SOFT_loopback|alcRenderSamplesSOFT|ALSOFT_TESTS|audio backend|ALSA|PulseAudio|PipeWire|sign-elf|no audio device
```

## 根因分析
OHOS PC / 无真实音频设备环境缺少 ALSA/PulseAudio/PipeWire 等外部音频后端依赖与硬件；默认配置会因缺依赖失败，上游测试与运行验证依赖真实设备而无法直接执行，需要显式关闭外部后端并保留源码内置 Null/loopback 后端，同时把上游 ctest 与替代验证分开统计

## 推荐方案
**方法**: disable-external-backends-keep-null-loopback

**说明**: CMake 配置时显式关闭全部外部音频后端（ALSA/PulseAudio/PipeWire/JACK/OSS/Solaris/SndIO/PortAudio/SDL2/SDL3/WaveFile/Oboe/OpenSL/CoreAudio）并关闭 DLOPEN/Modules/Utils/Examples，仅保留源码内置 Null/loopback 后端；单独以 ALSOFT_TESTS=ON 构建 OpenAL_Tests 并运行 ctest；无真实设备时用 No Output null 后端与 ALC_SOFT_loopback+alcRenderSamplesSOFT 作替代验证，两者分开统计

**验证/命令**:
```
cmake -S . -B build-tests -DALSOFT_TESTS=ON -DALSOFT_UTILS=OFF -DALSOFT_EXAMPLES=OFF -DALSOFT_DLOPEN=OFF -DALSOFT_ENABLE_MODULES=OFF -DALSOFT_BACKEND_WAVE=OFF -DALSOFT_BACKEND_ALSA=OFF -DALSOFT_BACKEND_PULSEAUDIO=OFF -DALSOFT_BACKEND_PIPEWIRE=OFF -DALSOFT_BACKEND_JACK=OFF -DALSOFT_BACKEND_OSS=OFF -DALSOFT_BACKEND_SOLARIS=OFF -DALSOFT_BACKEND_SNDIO=OFF -DALSOFT_BACKEND_PORTAUDIO=OFF -DALSOFT_BACKEND_SDL2=OFF -DALSOFT_BACKEND_SDL3=OFF && cmake --build build-tests -j4 && ctest --test-dir build-tests --output-on-failure -V
```

# E262: Reserved scratch aliases must be classified before strict parent resolution

## 基本信息
- **严重度**: 3
- **类别**: runtime, filesystem, permissions, security, symlink
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: #3928

## 错误特征
```
FileNotFoundError:.*\.t|Native Image output directory is missing:.*scratch|Native Image output must not use scratch path|scratch-alias
```

## 根因分析
An output path can traverse a symlink into a reserved scratch tree whose final parent does not yet exist. Strict resolution fails with FileNotFoundError before the safety policy classifies the alias, so a security rejection is misreported as an ordinary missing-directory error.

## 推荐方案
**方法**: policy-first-nonstrict-resolution

**说明**: When strict parent resolution fails, walk components with a bounded non-strict policy resolver, follow links explicitly, detect loops, and classify whether the destination resolves into the reserved scratch tree before emitting the ordinary missing-parent error.

**验证/命令**:
```
Resolve the candidate parent and cwd/.t with the policy-only resolver, then pass scratch aliases to the existing safe-destination gate.
```

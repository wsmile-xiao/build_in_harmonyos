# E108: patch-makefile-in-ginstall

## 基本信息
- **严重度**: 2
- **类别**: platform, install
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
install: No such file or directory|install.*not found|
                         make.*install.*Error 127|install -d.*No such file|
                         install -m.*No such file
```

## 根因分析
HarmonyOS 缺少 GNU install 命令，Makefile.in 中硬编码 install 导致 make install 失败

## 推荐方案
**方法**: patch-makefile-in-ginstall

**说明**: 在 Makefile.in 源文件中将硬编码 install 替换为 ginstall（R6铁律：修改源文件而非生成文件）

**验证/命令**:
```
sed -i 's/install -d/ginstall -d/g; s/install -m0755/ginstall -m0755/g' tools/Makefile.in
```

# E108: patch-makefile-in-ginstall

## 基本信息
- **严重度**: 2
- **类别**: platform-install
- **触发工具**: make
- **阶段**: installation

## 错误特征
```
install: No such file or directory|install.*not found|
```

**关键词**: install, ginstall, GNU install, HarmonyOS,

## 根因分析
HarmonyOS 缺少 GNU install 命令，Makefile.in 中硬编码 install 导致 make install 失败

**影响范围**: 所有在 Makefile.in 中硬编码 install 命令的 autotools 项目

## 推荐方案
- **方法**: patch-makefile-in-ginstall
- **描述**: 在 Makefile.in 源文件中将硬编码 install 替换为 ginstall（R6铁律：修改源文件而非生成文件）
- **命令**: `sed -i 's/install -d/ginstall -d/g; s/install -m0755/ginstall -m0755/g' tools/Makefile.in`
- **自动修复**: false

## 验证
```bash
which install; which ginstall
```

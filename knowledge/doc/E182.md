# E182: manual-workaround

## 基本信息
- **严重度**: 1
- **类别**: platform_compat
- **触发工具**: install|make
- **阶段**: installation

## 错误特征
```
install: inaccessible or not found|toybox install.*incompatible|cannot stat.*Permission denied
```

**关键词**: shell script, install, ruby-build, no compilation, toybox, coreutils

## 根因分析
Shell 脚本工具（如 ruby-build）不需要传统编译流程，但安装命令可能因 toybox 兼容性问题失败。toybox 提供的 install 命令功能简化，缺少某些选项或权限处理不完整。

**影响范围**: ruby-build, pyenv, nodenv, 其他使用 install 命令的 shell 脚本工具和 autotools 项目

## 推荐方案
- **方法**: manual-workaround
- **描述**: 手动复制文件替代 install 命令（cp bin/* $PREFIX/bin/ && chmod +x $PREFIX/bin/*），或安装 GNU coreutils 9.10 提供完整 install 命令。Shell 脚本工具无需 ELF 签名，直接复制即可。
- **自动修复**: false

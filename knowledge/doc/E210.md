# E210: add-cmake-flag

## 基本信息
- **严重度**: 3
- **类别**: "build-system"
- **触发工具**: cmake|make
- **阶段**: runtime

## 错误特征
```
"Segmentation fault|进程退出，代码 killed|SIGKILL"
```

**关键词**: "mimalloc,MI_OVERRIDE,段错误,killed,malloc覆盖,内存分配器"

## 根因分析
"mimalloc 的 MI_OVERRIDE 选项尝试覆盖系统 malloc/free，与鸿蒙系统的内存管理机制冲突，导致测试程序段错误"

**影响范围**: "使用 mimalloc 的所有软件，在鸿蒙系统上编译时"

## 推荐方案
- **方法**: add-cmake-flag
- **描述**: "在鸿蒙系统上使用 mimalloc 时，必须禁用 MI_OVERRIDE 选项，将其作为独立内存分配库使用，而非系统 malloc 替代品。启用 MI_LIBC_MUSL 选项以支持 musl libc 环境。"
- **命令**: `"cmake -DCMAKE_BUILD_TYPE=Release -DMI_LIBC_MUSL=ON -DMI_OVERRIDE=OFF .."`
- **自动修复**: false

## 验证
```bash
"cd build && ./mimalloc-test-api"
```

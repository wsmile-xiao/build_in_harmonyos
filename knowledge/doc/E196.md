# E196: source-patch

## 错误特征
```
std::size_t.*not declared|no member named.*size_t|size_t.*not a member of std|undeclared identifier.*std::size_t
  no type named 'size_t' in namespace 'std'; did you mean simply 'size_t'?
  'std::size_t' has not been declared
```

## 根因分析
musl libc 的 C++ 头文件不提供 std::size_t。在标准 C++ 中，size_t 应该在 <cstddef> 中定义为 std::size_t，但 musl 的实现直接使用 C 的 size_t（来自 <stddef.h>），不提供 std:: 前缀版本。这是 musl 的设计选择，为了保持轻量级和 C 兼容性。

## 推荐方案
**方法**: source-patch

**说明**: 全局替换 std::size_t 为 size_t，使用 sed -i 's/std::size_t/size_t/g' 批量修改源文件。确保文件包含 <stddef.h> 或 <cstddef>。size_t 在 C++ 中仍然有效（来自 C 头文件）。
[E196]

**验证/命令**:
```
grep -r "std::size_t" src/
```

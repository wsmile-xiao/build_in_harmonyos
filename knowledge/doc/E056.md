## 错误特征
```
IndentationError.*unexpected indent|skipIf.*reason.*wrap|
                         @unittest.skipIf.*multiline.*IndentationError
```

## 根因分析
编辑器/补丁工具将多行 reason 的后续行放到装饰器声明之前,
                         导致 Python 解析器将后续行的 def 识别为缩进错误。
                         每次修改测试文件后必须 py_compile 验证

## 推荐方案
**方法**: source-patch

**说明**: 将多行 reason 改为单行或用括号包裹保持在一行内;
                         修改后必须 py_compile 验证语法正确性

**验证/命令**:
```
python3 -m py_compile <modified_test_file>
```

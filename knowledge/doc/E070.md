# E070: reconfigure-disable-feature

## 基本信息
- **严重度**: 2
- **类别**: compat, architecture
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
m32.*personality|32-bit.*compat|cannot create .*32 bit|invalid arch.*m32|-m32.*unsupported
```

## 根因分析
部分软件默认启用 32 位兼容支持(m32 personality)，
                         鸿蒙是纯 aarch64 系统，无 32 位兼容层

## 推荐方案
**方法**: reconfigure-disable-feature

**说明**: 通过 --disable-mpers 或类似选项禁用 32 位兼容支持

**验证/命令**:
```
./configure --disable-mpers --prefix=$HOME/usr/local
```

## 关键词
m32, 32-bit, personality, aarch64, multiarch, cross compile, strace, --disable-mpers

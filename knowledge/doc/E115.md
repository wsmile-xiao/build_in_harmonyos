# E115: source-patch

## 基本信息
- **严重度**: 2
- **类别**: platform, headers, runtime
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
use of undeclared identifier 'FALLOC_FL_ZERO_RANGE'|FALLOC_FL_INSERT_RANGE|FALLOC_FL_UNSHARE_RANGE
```

## 根因分析
鸿蒙平台的内核头文件缺少部分 Linux fallocate(2) 的常量定义，这些常量在 Linux 内核 <fcntl.h> 中定义，但鸿蒙平台的头文件可能未同步更新

## 推荐方案
**方法**: source-patch

**说明**: 在源码中添加 #ifdef __OHOS__ 守卫，为鸿蒙平台补充缺失的常量定义

**验证/命令**:
```
|添加 #ifdef __OHOS__\n#ifndef FALLOC_FL_ZERO_RANGE\n#define FALLOC_FL_ZERO_RANGE 0x10\n#endif\n#endif
```

## 关键词
fallocate,FALLOC_FL_ZERO_RANGE,FALLOC_FL_INSERT_RANGE,FALLOC_FL_UNSHARE_RANGE,undeclared identifier,__OHOS__

# E061: gnulib stdbool.h 模块缺失

> **结构化数据**: [graph/E061.kv](../graph/E061.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: gnulib/compat/compilation | **自动修复**: ❌ 手动

## 错误特征

```
./config.h:2555:6: error: "<stdbool.h> does not exist on this platform. Use gnulib module 'stdbool-c99' instead of gnulib module 'stdbool'."
```

## 根因

GNU 软件使用 gnulib 提供 POSIX 兼容层。gnulib 的 `stdbool` 模块在较新版本中 deprecated，应使用 `stdbool-c99` 替代。但 configure 检测时如果 **conftest 无法执行（E064）**，会回退到错误的默认值。

**问题链**：
```
configure 运行 conftest 测试 → 弹窗超时/SELinux → conftest 无法执行
    → 检测结果默认为"不可用" → gnulib 选了 fallback 模块(bool 而非 bool-c99)
    → 编译报错：模块不兼容当前平台
```

## 解决方案

**方案 1（治本）**：先解决 E064（conftest 弹窗确认），让 configure 正确检测。

**方案 2（源码修改）**：configure.ac 中 `gl_STDBOOL_H` → `gl_STDLIB_H`。

**方案 3（环境变量绕过）**：
```bash
export gl_cv_header_stdbool_h=yes
```

## 错误特征
```
stdbool\.h.*does not exist|gnulib.*stdbool.*module|

```

## 根因分析
gnulib 的 stdbool 模块在新版本中被标记为 deprecated,
                         应使用 stdbool-c99 替代。但 configure 检测时如果 conftest 无法执行(E064),
                         会回退到错误的默认值, 选择 fallback 模块(stdbool 而非 stdbool-c99)

## 推荐方案
**方法**: fix-conftest-first

**说明**: 根因是 E064(conftest 无法执行), 先解决弹窗确认问题让 configure 正确检测;
                         或在 configure.ac 中将 gl_STDBOOL_H 改为 gl_STDLIB_H(源码级修改)

**验证/命令**:
```
rec_auto_fix:          false
```

## 错误特征
```
permission denied.*go.*|sign.*elf.*failed.*go|zsh.*permission denied.*go/bin/go
```

## 根因分析
Go 编译器二进制文件需要 ELF 签名才能在鸿蒙上执行，但 binary-sign-tool 签名 Go 失败

## 推荐方案
**方法**: use-prebuilt-package

**说明**: 使用预编译的 Go 编译器（已签名），或使用交叉编译在其他平台为鸿蒙编译 Go 项目

**验证/命令**:
```
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- go <version>
```

# E052: modify_tmpdir

## 基本信息
- **严重度**: 2
- **类别**: platform, limitation
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
config\.status: error creating temporary directory|can't create \./confXXXXXX/subs1\.awk: Permission denied
```

## 根因分析
HMDFS 文件系统对 config.status 的临时文件创建有特殊限制，即使使用 mktemp -d 创建的目录也可能失败。这是 E002（/tmp 只读）的补充情况，发生在 configure 生成的 config.status 脚本执行时。

## 推荐方案
**方法**: modify_tmpdir

**说明**: 修改 config.status 使用固定临时目录（$HOME/tmp/configure.$$），避开 HMDFS 限制

**验证/命令**:
```
sed -i 's|tmpdir=.*|tmpdir=$HOME/tmp/configure.$$|g' config.status && mkdir -p $HOME/tmp
```

# E076: source-patch-ifdef

## 错误特征
```
fstat.*EACCES|lseek.*EACCES|fstat.*EPERM|lseek.*EPERM|Bad file descriptor|cannot seek
```

## 根因分析
鸿蒙内核对管道(pipe)、终端(tty)、套接字(socket)等非文件描述符的 fstat() 和 lseek() 系统调用返回 EACCES/EPERM，
                        而非 Linux 的正常行为（fstat 返回有效信息，lseek 返回 ESPIPE）。
                        GNU coreutils 的 cat/head/tail/dd 等工具在处理管道输入时调用 fstat(STDIN_FILENO)
                        或 lseek 判断输入类型，因 EACCES 导致报错或输出异常。

## 推荐方案
**方法**: source-patch-ifdef

**说明**: 在源码中用 #ifdef __OHOS__ 守卫，对 fstat/lseek 的 EACCES/EPERM 返回值做兼容处理。

**验证/命令**:
```
|
  # 标准修复模板：在调用 fstat(fd, &st) 处替换为 OHOS_FSTAT 宏
  # 参见 doc/E076.md 中的 harmonyos-fstat-compat.h 模板
```

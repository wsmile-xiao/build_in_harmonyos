# E076: fstat()/lseek() 对非文件 fd 返回 EACCES

> **类别**: filesystem/syscall/runtime-behavior | **严重度**: 🟡 | **触发**: cc/coreutils | **阶段**: runtime/compilation
> **来源**: harmonyos-specifics.md §9 + coreutils 9.10 补丁

---

## 错误现象

```
$ cat somefile | head -5
head: cannot seek to offset 0: Bad file descriptor

$ dd if=/dev/urandom of=test bs=1k count=5
dd: 'standard input': cannot seek: Invalid argument
```

关键特征：
- **管道输入**时触发（stdin 是 pipe），普通文件输入正常
- `fstat()` 返回 `-1`，`errno = EACCES` 或 `EPERM`
- `lseek()` 同样返回 `EACCES`
- 影响 GNU coreutils：cat, head, tail, dd, split, tee 等

## 根因分析

**Linux 行为 vs HarmonyOS 行为**：

| fd 类型 | Linux fstat() | HarmonyOS fstat() | Linux lseek() | HarmonyOS lseek() |
|---------|--------------|-------------------|---------------|-------------------|
| 普通文件 | ✅ 正常 | ✅ 正常 | ✅ 正常 | ✅ 正常 |
| 管道 (pipe) | ✅ 返回 FIFO 信息 | ❌ **EACCES** | ❌ ESPIPE | ❌ **EACCES** |
| 终端 (tty) | ✅ 返回 CHAR 设备信息 | ❌ **EACCES** | ❌ ESPIPE | ❌ **EACCES** |
| 套接字 (socket) | ✅ 返回 SOCK 信息 | ❌ **EACCES** | ❌ ESPIPE | ❌ **EACCES** |

鸿蒙内核对非文件 fd 的 fstat/lseek 返回权限错误而非"非法 seek"（ESPIPE）。
GNU coreutils 的 elseek 函数依赖 lseek 的返回值判断是否可 seek，
收到意外的 EACCES 后输出错误信息。

## 解决方案

### 方案 1（推荐）：源码补丁 — fstat 兼容模板

```c
/* harmonyos-fstat-compat.h */
#ifdef __OHOS__

static inline int
ohos_fstat_compat(int fd, struct stat *st)
{
    if (fstat(fd, st) == 0)
        return 0;
    if (errno == EACCES || errno == EPERM) {
        memset(st, 0, sizeof(*st));
        st->st_blksize = 4096;      /* Default I/O block size */
        st->st_mode = S_IFIFO;      /* Treat as pipe/FIFO */
        return 0;
    }
    return -1;
}

#define OHOS_FSTAT(fd, st) ohos_fstat_compat((fd), (st))

#else /* !__OHOS__ */

#define OHOS_FSTAT(fd, st) fstat((fd), (st))

#endif /* __OHOS__ */
```

### 方案 2（配套）：lseek 兼容模板

```c
/* 在 lseek 调用处添加守卫 */
if (lseek(fd, offset, whence) < 0) {
#ifdef __OHOS__
    if (errno == EACCES || errno == EPERM)
        return -1;  /* 不可 seek，静默返回 */
#endif
    error(0, errno, "%s", filename);
    return -1;
}
```

### 方案 3：shell 场景 fallback

```bash
# 使用 toybox 版本（已内置兼容）
alias cat='/bin/cat'
alias head='/bin/head'
alias tail='/bin/tail'
```

## 受影响软件

| 软件 | 受影响函数 | 症状 |
|------|-----------|------|
| **coreutils: cat** | fstat(stdin) | 管道输入时可能行为异常 |
| **coreutils: head** | lseek(stdin) | "cannot seek to offset 0" |
| **coreutils: tail** | lseek(stdin) | 类似 head |
| **coreutils: dd** | fstat/lseek | "cannot seek" 错误 |
| **coreutils: split** | fstat | 分割管道输入失败 |
| **coreutils: tee** | fstat | 多路输出异常 |

## 排查流程

```
命令在管道中表现异常
    │
    ├─ Step 1: 直接对文件运行（无管道）→ 正常？
    │       是 → 问题与管道/fd 类型相关
    │       不是 → 不是 E076
    │
    ├─ Step 2: strace 观察系统调用
    │       strace -e fstat,lseek <command>
    │       看到 fstat(0, ...) = -1 EACCES → **确认是 E076**
    │
    └─ Step 3: 检查是否 GNU coreutils
            which cat → 如果是 GNU 版本 → 用方案 1 打补丁或方案 3 切换 toybox
```

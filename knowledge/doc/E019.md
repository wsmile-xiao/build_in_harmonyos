# E019: set-ld-library-path

## 基本信息
- **严重度**: 3
- **类别**: linking, runtime
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
error while loading shared libraries.*cannot open|
                         cannot open shared object file.*lib.*\.so|
                         ld.so.*lib.*\.so.*not found
```

## 根因分析
运行时动态链接器(ld.so)在标准搜索路径中
                         找不到所需的共享库(.so),
                         即便编译时设置了 -Wl,-rpath,$ORIGIN/../lib,
                         运行时也不会展开 $ORIGIN 为实际路径。

## 推荐方案
**方法**: set-ld-library-path

**说明**: 设置 LD_LIBRARY_PATH 包含库所在目录

**验证/命令**:
```
export LD_LIBRARY_PATH=$HOME/usr/local/lib:$LD_LIBRARY_PATH
```

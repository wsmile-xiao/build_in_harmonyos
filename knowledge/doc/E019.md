# E019: 库加载失败（运行时）

> **结构化数据**: [graph/E019.kv](../graph/E019.kv) | **原则**: 无
> **严重度**: 🔴 blocking | **分类**: runtime/linking | **自动修复**: ✅ set-env-var

---

## 错误特征

```
error while loading shared libraries: libxxx.so: cannot open shared object file
ld.so: libxxx.so: not found
```

## 根因

运行时动态链接器（ld.so）在标准搜索路径中找不到所需的共享库（.so）。

## 验证命令

```bash
# 检查二进制依赖哪些库
llvm-readelf -d /path/to/binary | grep NEEDED

# 检查库文件是否存在
ls -la $HOME/usr/local/lib/libxxx.so*

# 检查运行时链接搜索
ldd /path/to/binary
```

## 解决方案

### 方案1：LD_LIBRARY_PATH（推荐，即时生效）

```bash
export LD_LIBRARY_PATH=$HOME/usr/local/lib:$LD_LIBRARY_PATH
```

### 方案2：编译时设置 rpath（更持久）

```bash
export LDFLAGS="-Wl,-rpath,\$ORIGIN/../lib $LDFLAGS"
```

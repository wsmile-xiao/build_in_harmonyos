# E031: /proc 文件系统 SELinux 访问限制

> **结构化数据**: [graph/E031.kv](../graph/E031.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: selinux/filesystem/runtime | **自动修复**: ❌ 手动

---

## 错误特征

```
htop: Cannot open /proc/stat: Permission denied
```

## 根因

鸿蒙 SELinux 策略限制普通用户访问 `/proc` 文件系统。htop 等工具通过解析 `/proc/stat`、`/proc/meminfo` 等获取系统信息，在普通用户下被 SELinux 拦截。

## 解决方案

```bash
# 方案 1（推荐）：sudo 运行
sudo -E TERM=xterm-256color htop

# 方案 2（开发场景）：改用 syscall 接口替代 /proc 解析
# 用 sysinfo()、sysconf() 等 POSIX 接口获取系统信息
```

## 涉及软件

htop 3.4.1、其他直接读取 /proc 的监控/诊断工具。

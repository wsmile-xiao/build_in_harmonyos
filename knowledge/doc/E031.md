# E031: sudo-run

## 基本信息
- **严重度**: 2
- **类别**: selinux, runtime, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
Cannot open /proc/stat.*Permission denied|
                         /proc/.*Permission denied.*selinux
```

## 根因分析
鸿蒙 SELinux 策略限制普通用户访问 /proc 文件系统,
                         导致读取 /proc/stat、/proc/meminfo 等失败

## 推荐方案
**方法**: sudo-run

**说明**: 使用 sudo 运行程序, 继承终端环境变量

**验证/命令**:
```
sudo -E TERM=xterm-256color htop
```

## 关键词
/proc, Permission denied, SELinux, htop,
                         proc/stat, proc/meminfo, cannot open

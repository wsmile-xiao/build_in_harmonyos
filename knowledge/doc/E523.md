# E523: Go 链接器 fallocate() 在 HMDFS/tmpfs 上返回 EACCES 导致链接失败

## 基本信息
- **严重度**: 3
- **类别**: toolchain
- **作者**: ZACH_123 <ZACH_123@noreply.gitcode.com>
- **来源 PR**: !1669

## 错误特征
```
mapping output file failed: permission denied|fallocate.*EACCES|go tool link.*permission denied
```

## 根因分析
Go 链接器 (cmd/link) 在写入输出文件时调用 fallocate() 预分配空间。OHOS 的 HMDFS 和 tmpfs 文件系统不支持 fallocate，返回 EACCES (errno=13)。Go 链接器只忽略 ENOTSUP/EPERM，不忽略 EACCES，导致链接失败。

## 推荐方案
**方法**: toolexec-wrapper

**说明**: 创建 toolexec 包装器脚本，拦截 go build 的链接步骤，将链接器输出重定向到 /dev/shm（支持 fallocate），链接完成后再复制回原路径

**验证/命令**:
```
go build -toolexec $HOME/tmp/toolexec_wrapper.sh -o <binary> <package>
```

## 根因分析
musl 默认启用 BIND_NOW 标志,
                         dlopen() 加载 .so 时要求所有符号在加载时即可解析,
                         扩展模块(.so)的 NEEDED 只有 libc.so(无 libpython),
                         导致 Python API 符号无法解析 → ImportError

## 推荐方案
**方法**: modify-ldshared

**说明**: 修改 LDSHARED 添加主库链接(-L. -lpython),
                         让扩展模块在链接时记录对 libpython 的依赖

**验证/命令**:
```
rec_auto_fix:          false
```

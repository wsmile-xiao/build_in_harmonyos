# E193: skip-case-sensitive-tests

## 基本信息
- **严重度**: 2
- **类别**: platform|hmdfs|filesystem|testing
- **触发工具**: test|make check
- **阶段**: testing

## 错误特征
```
case.insensitive.*FAIL|case_sensitive.*FAIL|3d2.*/boo|BOO.*boo.*same inode|case.insensitive.filesystem
```

**关键词**: case-insensitive, HMDFS, filesystem, BOO, boo,

## 根因分析
HMDFS (鸿蒙分布式文件系统) 是大小写不敏感的。

**影响范围**: 所有在 HMDFS 上运行 make check 的软件，

## 推荐方案
- **方法**: skip-case-sensitive-tests
- **描述**: 检测到 HarmonyOS 系统时，跳过大小写敏感测试用例。
- **命令**: `'`
- **自动修复**: true

## 验证
```bash
touch BOO && touch boo && stat -c '%i' BOO boo | sort -u | wc -l
```

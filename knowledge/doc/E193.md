# E193: skip-case-sensitive-tests

## 基本信息
- **严重度**: 2
- **类别**: platform, hmdfs, testing, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
case.insensitive.*FAIL|case_sensitive.*FAIL|3d2.*/boo|BOO.*boo.*same inode|case.insensitive.filesystem
```

## 根因分析
HMDFS (鸿蒙分布式文件系统) 是大小写不敏感的。 
                        创建不同大小写的文件名（如 BOO 和 boo）时，
                        它们指向同一个 inode（共享相同 inode 编号）。
                        这与 macOS 的 APFS/HFS+ 行为一致，但与 Linux 
                        标准 ext4/xfs 不同。
                        许多开源测试套件会创建不同大小写的文件来测试
                        大小写区分能力，在 HMDFS 上这些测试会失败。

## 推荐方案
**方法**: skip-case-sensitive-tests

**说明**: 检测到 HarmonyOS 系统时，跳过大小写敏感测试用例。
                        参考 macOS (Darwin) 上的相同处理策略。

**验证/命令**:
```
'
                        # 在测试脚本中添加 HarmonyOS 检测：
                        case_insensitive_fs=false
                        if uname -a | grep -qi "HarmonyOS"; then
                            case_insensitive_fs=true
                        fi
                        for t_file in ...; do
                            if $case_insensitive_fs && [[ $t_file == */case_*sensitive ]]; then
                                continue   # 跳过大小写敏感测试
                            fi
                            ...
                        done
                        '
```

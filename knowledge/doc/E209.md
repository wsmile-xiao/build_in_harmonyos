# E209: manual-workaround

## 基本信息
- **严重度**: 2
- **类别**: build_tools
- **触发工具**: autogen.sh|libtoolize
- **阶段**: configuration

## 错误特征
```
autogen\.sh.*required file.*ltmain\.sh.*not found|libtoolize.*ltmain\.sh
```

**关键词**: ltmain.sh,autogen.sh,libtool,autotools,configure.ac

## 根因分析
autogen.sh 运行时 libtoolize 无法正确复制 ltmain.sh 到源码目录，可能是因为目录结构不匹配或 libtool 版本问题

**影响范围**: autotools 项目，尤其是使用 AC_PROG_LIBTOOL 的旧版本 configure.ac

## 推荐方案
- **方法**: manual-workaround
- **描述**: 手动复制 libtool 的 ltmain.sh 文件到源码目录根目录，然后重新运行 autogen.sh
- **命令**: `cp $HOME/usr/local/share/libtool/build-aux/ltmain.sh . && ./autogen.sh`
- **自动修复**: false

## 验证
```bash
ls -la ltmain.sh && test -x configure
```

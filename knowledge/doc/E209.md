# E209: manual-workaround

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
autogen\.sh.*required file.*ltmain\.sh.*not found|libtoolize.*ltmain\.sh
```

## 根因分析
autogen.sh 运行时 libtoolize 无法正确复制 ltmain.sh 到源码目录，可能是因为目录结构不匹配或 libtool 版本问题

## 推荐方案
**方法**: manual-workaround

**说明**: 手动复制 libtool 的 ltmain.sh 文件到源码目录根目录，然后重新运行 autogen.sh

**验证/命令**:
```
cp $HOME/usr/local/share/libtool/build-aux/ltmain.sh . && ./autogen.sh
```

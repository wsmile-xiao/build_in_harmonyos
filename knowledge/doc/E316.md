# E316: copy-soname-entity

## 错误特征
```
Error loading shared library libopenblas\.so\.0|Error relocating.*zgemm_.*symbol not found|needed by.*exec/R
```

## 根因分析
R 的 exec/R ELF NEEDED 记录的是 OpenBLAS 的 SONAME libopenblas.so.0，但 Conan 包的 _prepare_relocatable_runtime 只复制了 libopenblas.so（开发者符号链接）。OpenBLAS Conan 包内 libopenblas.so 与 libopenblas.so.0 均是指向 libopenblas_armv8p-r0.3.33.so 的符号链接；动态链接器按 SONAME 查找，缺 .so.0 实体即失败。

## 推荐方案
**方法**: copy-soname-entity

**说明**: 在 conanfile.py 的 _prepare_relocatable_runtime 中，复制库文件时必须同时提供 SONAME 实体。使用 shutil.copy2 跟随符号链接复制实体文件，确保 libopenblas.so 和 libopenblas.so.0 两份均为实体（或采用等价方式保证 SONAME 文件存在）。打包日志应出现 Packaged ... libopenblas.so.0。

**验证/命令**:
```
shutil.copy2(os.path.join(openblas_folder, "lib", "libopenblas.so"), os.path.join(rlib, "libopenblas.so")) && shutil.copy2(os.path.join(openblas_folder, "lib", "libopenblas.so.0"), os.path.join(rlib, "libopenblas.so.0"))
```

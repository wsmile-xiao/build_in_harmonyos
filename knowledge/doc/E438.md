# E438: Qt6 子模块复用 qtbase 的 Qt6Config 与 harmonyos-clang mkspec

## 基本信息
- **严重度**: 2
- **类别**: cmake
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: !5139

## 错误特征
```
Qt 子模块构建找不到 harmonyos-clang mkspec / Qt6Config
```

## 根因分析
qtbase 包已安装完整 Qt6Config.cmake 与 harmonyos-clang mkspec，下游 Qt 子模块无需重复打 mkspec 补丁

## 推荐方案
**方法**: CMakeToolchain 设 Qt6_DIR=qtbase 包 lib/cmake/Qt6 + QT_QMAKE_TARGET_MKSPEC=harmonyos-clang + CMAKE_FIND_ROOT_PATH_MODE_PACKAGE=BOTH

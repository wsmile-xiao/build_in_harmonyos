# E338: OHOS getpwuid() 返回 NULL 导致 homedir() 为 NULL，程序启动 SIGSEGV

## 基本信息
- **严重度**: 3
- **类别**: platform, runtime, passwd
- **作者**: hhyxx1 <f24011422@st.sandau.edu.cn>
- **来源 PR**: !5164

## 错误特征
```
getpwuid\(\) returns NULL|homedir\(\) NULL|configdir\(\) NULL|SIGSEGV|Signal 11|core dumped|getpwnam|pw_dir|ROSWELL_HOME
```

## 根因分析
OHOS 系统无 /etc/passwd 条目（getpwuid/getpwnam 返回 NULL），依赖 homedir() 的软件在 configdir() 返回 NULL 后对 NULL 做字符串拼接直接 SIGSEGV

## 推荐方案
**方法**: 首选运行时设置软件官方支持的环境变量（如 ROSWELL_HOME）注入绝对路径；若需源码适配，用 __OHOS__ 守卫在 homedir() 为 NULL 时回退到固定路径（须含实质回退逻辑，符合 R8，禁止空壳 stub）

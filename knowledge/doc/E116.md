# E116: compile-automake-from-source

## 基本信息
- **严重度**: 3
- **类别**: compat, autotools, packaging
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
Can't locate Automake/Config.pm in @INC|bad interpreter: .*perl: no such file or directory
```

## 根因分析
预编译包的 automake 脚本(aclocal/automake)是用 Perl 编写的，依赖 Automake::Config 等 Perl 模块。
                        预编译包打包时，Perl 模块安装在特定路径(如 ~/usr/local/share/automake-1.17)，而系统的 Perl 搜索路径(@INC)不包含该路径，
                        导致预编译包的 automake 无法工作。

## 推荐方案
**方法**: compile-automake-from-source

**说明**: 编译 perl 预编译包或从源码编译 automake，确保 Perl 模块路径匹配系统 Perl 的 @INC

**验证/命令**:
```
# 步骤1: 编译 perl（如无预编译包）
                        # 步骤2: 从源码编译 automake（git clone https://git.savannah.gnu.org/git/automake.git）
                        # 步骤3: 验证 aclocal --version 正常工作
```

## 关键词
Automake::Config, automake perl, aclocal perl module, precompiled package incompatible, perl @INC

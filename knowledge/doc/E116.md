# E116: compile-automake-from-source

## 基本信息
- **严重度**: 3
- **类别**: autotools|precompiled-package|compatibility
- **触发工具**: automake|aclocal|autoreconf|perl
- **阶段**: configuration

## 错误特征
```
Can't locate Automake/Config.pm in @INC|bad interpreter: .*perl: no such file or directory
```

**关键词**: Automake::Config, automake perl, aclocal perl module, precompiled package incompatible, perl @INC

## 根因分析
预编译包的 automake 脚本(aclocal/automake)是用 Perl 编写的，依赖 Automake::Config 等 Perl 模块。

**影响范围**: 所有依赖 automake 的项目，尤其是需要运行 autogen.sh 的 Git 源码包

## 推荐方案
- **方法**: compile-automake-from-source
- **描述**: 编译 perl 预编译包或从源码编译 automake，确保 Perl 模块路径匹配系统 Perl 的 @INC
- **命令**: `# 步骤1: 编译 perl（如无预编译包）`
- **自动修复**: false

## 验证
```bash
~/usr/local/bin/aclocal --version 2>&1 | grep -i "Can't locate Automake/Config.pm"
```

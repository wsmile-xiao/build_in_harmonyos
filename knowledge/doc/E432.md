# E432: Release native error outputs and range-check external coordinates before narrowing

## 基本信息
- **严重度**: 2
- **类别**: native-api-contract
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !6534

## 错误特征
```
native API failure returns non-null owned output or external coordinate overflows signed target type
```

## 根因分析
Native API status, output ownership, and numeric representability are independent contracts. A nonzero status does not prove an output pointer is null, while floating-point offsets and signed deltas can exceed the consumer coordinate range before or during arithmetic.

## 推荐方案
**方法**: ownership-and-checked-narrowing

**说明**: Release every non-null owned output on all status paths. Reject non-finite values, check rounded offsets against origin-adjusted int32 bounds, perform addition in int64, and narrow only after the final range check.

**验证/命令**:
```
add scoped or explicit native cleanup; add checked coordinate helpers and boundary tests
```

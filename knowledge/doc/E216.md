# E216: glib/libxml2 CMakeDeps 组件头文件传播失效

## 基本信息
- **严重度**: 1
- **类别**: cmake, cross-compile, conan
- **作者**: Libres <liud1@mails.neu.edu.cn>
- **来源 PR**: 3274

## 错误特征
```
glib.h: No such file or directory|libxml/xmlversion.h: No such file|list sub-command LENGTH requires two arguments|Unknown arguments specified
```

## 根因分析
Conan 2.29 + glib 2.84.0/libxml2 2.15.3 的 CMakeDeps 生成文件不传播 components 的 INTERFACE_INCLUDE_DIRECTORIES。team ohpcd glib recipe 不使用 components 子目标而是 flat cpp_info.libs,生成的 CMake target 是 aggregate glib::glib。libxml2 recipe 设置 cmake_file_name="LibXml2" 大小写敏感。

## 推荐方案
**方法**: glob-fallback-with-empty-guard

**说明**: test_package/CMakeLists.txt 中显式 file(GLOB) 找 conan cache 中的 glib.h / glibconfig.h / libxml2 xmlversion.h,匹配 p/b/<pkg>/b/... 和 p/<pkg>/p/... 双布局。foreach 循环体内通过 `set(_VAL "${${_var}}")` 将变量值捕获到临时普通变量,后续操作 `_VAL` 避免 semicolon 在 list() / get_filename_component() 参数中被误解析为分隔符。空 GLOB 守卫: if(_VAL STREQUAL "") continue(),多匹配检测:string(FIND) + FATAL_ERROR。

**验证/命令**:
```
foreach(_var IN ITEMS _GLIB_H_FILES ...) set(_VAL "${${_var}}") if(_VAL STREQUAL "") continue() endif() string(FIND "${_VAL}" ";" _SEMI_POS) if(_SEMI_POS GREATER_EQUAL 0) message(FATAL_ERROR ...) endif() get_filename_component(_DIR "${_VAL}" DIRECTORY)
```

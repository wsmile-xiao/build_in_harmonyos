# E202: skip-test

## 基本信息
- **严重度**: 1
- **类别**: platform, limitation
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
PTHREAD_KEYS_MAX|pthread_key_create.*fail|key_create.*failed
```

## 根因分析
musl libc has PTHREAD_KEYS_MAX=128 vs glibc 1024+, causing pthread_key_create failures for tests creating >128 keys

## 推荐方案
**方法**: skip-test

**说明**: Skip the failing test and record as musl platform limitation, not a library defect

**验证/命令**:
```
echo "SKIP: musl PTHREAD_KEYS_MAX=128 platform limit"
```

# E202: skip-test

## 基本信息
- **严重度**: 1
- **类别**: platform-limitation
- **触发工具**: runtime
- **阶段**: runtime

## 错误特征
```
PTHREAD_KEYS_MAX|pthread_key_create.*fail|key_create.*failed
```

**关键词**: PTHREAD_KEYS_MAX, pthread_key_create, musl, OHOS

## 根因分析
musl libc has PTHREAD_KEYS_MAX=128 vs glibc 1024+, causing pthread_key_create failures for tests creating >128 keys

**影响范围**: Any software using pthread_key_create extensively on OHOS/musl

## 推荐方案
- **方法**: skip-test
- **描述**: Skip the failing test and record as musl platform limitation, not a library defect
- **命令**: `echo "SKIP: musl PTHREAD_KEYS_MAX=128 platform limit"`
- **自动修复**: false

## 验证
```bash
grep -r PTHREAD_KEYS_MAX /usr/include/ 2>/dev/null || echo "musl default: 128"
```

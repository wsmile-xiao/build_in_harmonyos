# E301: Conan CMake.test cli_args are build arguments, not CTest arguments

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, testing
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
cmake --build.*--target test.*--output-on-failure|Unknown argument --output-on-failure
```

## 根因分析
In Conan 2, CMake.test() runs cmake --build with the test target, so its cli_args are routed to cmake --build; only CMake.ctest() routes cli_args to ctest.

## 推荐方案
**方法**: use-cmake-ctest-helper

**说明**: Use cmake.ctest(cli_args=[...]) for CTest options after cmake.build(); reserve cmake.test() for invoking the build system test target with build arguments.

**验证/命令**:
```
Replace cmake.test(cli_args=["--output-on-failure"]) with cmake.ctest(cli_args=["--output-on-failure"]).
```

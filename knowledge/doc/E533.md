# E533: libarchive/bsdtar 3.7.7 HarmonyOS PC 适配: autotools 跨平台 + hmdfs 权限 + 依赖边界 + 测试套件分类

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, ohos, portability, autotools, dependency
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !6811

## 错误特征
```
config.guess.*HarmonyOS|Permission denied.*tmp|assertion_file_mode|umask 077|hmfs.*mode|setgid|owner-bits-only|R_AARCH64_ADR_PREL_PG_HI21.*z_errmsg|fPIC|liblzma.*runtime.*load|make check.*failed
```

## 根因分析
>
  1. config.guess 缺乏 HarmonyOS 识别分支，configure 无法推断 aarch64-unknown-linux-ohos
     triplet，导致构建系统类型检测失败。libarchive 3.7.7 内置的 config.guess 是 2021-10-26
     版本，无 HarmonyOS 条目。
  2. hmdfs（HarmonyOS Distributed File System）强制 setgid 位、裁剪 group/other 权限位，
     且 mkdir 默认 umask 077 在大赛中因平台原因生效（非容器环境），导致 configure 临时目录
     创建失败（Permission denied）以及测试套件中 assertion_file_mode 精确 0755 断言失败。
  3. 实际链接依赖仅 zlib + liblzma(xz)（bzip2/zstd/lz4/openssl/libxml2 在 OHOS 上
     configure 未检测到），但 zlib 官方制品仓的 libz.a 未以 -fPIC 编译，链接共享库时触发
     R_AARCH64_ADR_PREL_PG_HI21 重定位错误；xz 的 pkg-config 优先指向 harmonybrew 系统
     共享库导致运行时 .so 加载失败。
  4. 上游 `make check` 5 套件合计 801 条用例，因平台已知限制（hmdfs 硬链接不支持、
     权限位差异、未编译加密 backend）产生 39 failed + 226 skipped，非库本身缺陷。

## 推荐方案
**方法**: autotools-hmdfs-dependency-boundary-test-classification

**说明**: >
  1. config.guess 增强：在 `case $UNAME_MACHINE:$UNAME_SYSTEM:$UNAME_RELEASE:$UNAME_VERSION`
     分支前插入 HarmonyOS 条目，将 aarch64 映射为 ${MACHINE}-unknown-linux-ohos。
  2. hmdfs 权限兼容：configure 临时目录创建 umask 从 077 改为 002；test_main.c 中
     assertion_file_mode 比较改为 owner-bits-only（0700 掩码比较），容忍 setgid 和
     其他位差异。
  3. 依赖冻结：声明 zlib/1.3.1.1（-fPIC 重建版）和 xz/5.6.2 为唯一强制依赖；
     configure 传 `--without-xml2` 禁用可选 libxml2；generate() 中通过
     extra_cflags/extra_ldflags 将 conan 依赖的 include/lib 路径置前以覆盖 pkg-config
     的 harmonybrew 系统路径。
  4. 测试分类：`make check` 保留全部 5 套件 801 条注册项，不接受平台宏整体跳过；
     已知 hmdfs 硬链接失败（E079）、权限位失败（E011/E129）和加密 backend 未编译失败
     作为独立类别记录，不阻塞适配结论。
  5. test_package 验证：执行 bsdtar --version 确认工具和依赖版本字符串，内存 tar 读取
     验证 libarchive 库 API，tar 创建-提取往返验证 CLI 完整性。

**验证/命令**:
```
apply patches 0001-0003, configure --build=aarch64-unknown-linux-gnu --without-xml2, make, make check, make install
```

# E225: CMakeToolchain source-side preset 与 Conan test-package 临时布局

## 基本信息
- **严重度**: 3
- **类别**: conan, packaging, testing, security
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: 4606

## 错误特征
```
CMakeUserPresets\.json|Invalid configuration:.*BUILD_DIR|test_package requires external BUILD_DIR
```

## 根因分析
CMakeToolchain 默认可能向 test_package source 写入 CMakeUserPresets.json；recipe 若依赖非标准 shell BUILD_DIR，标准 conan create 不提供该变量，会在官方 CI 的 test_package layout 阶段失败。

## 推荐方案
**方法**: conan-managed-temporary-test-layout

**说明**: 在已实测支持该特殊值的 Conan 版本中，保留 CMakeToolchain user_presets_path=False，并使用 cmake_layout(self, build_folder="$TMP")；当前证据限定 Conan 2.29.1，其以 tempfile.mkdtemp 创建遵循 TMPDIR 的每次调用唯一临时根。

**验证/命令**:
```
先在目标 Conan 版本以 unset BUILD_DIR 的 graph/test 探针验证 "$TMP" 语义；确认支持后使用 cmake_layout(self, build_folder="$TMP")，并在 generate() 设置 tc.user_presets_path=False。
```

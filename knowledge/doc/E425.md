# E425: pico-sdk Debian orig tarball 的外部 submodule 可保持空目录，但需明确限定当前包功能范围

## 基本信息
- **严重度**: 2
- **类别**: dependency, embedded-sdk, source-scope
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6613

## 错误特征
```
tinyusb|cyw43-driver|lwip|mbedtls|btstack|\.gitmodules|empty submodule|No such file or directory.*lib/tinyusb
```

## 根因分析
pico-sdk 2.2.0 的 Debian orig tarball 保留 lib/tinyusb、lib/cyw43-driver、lib/lwip、lib/mbedtls、lib/btstack 等 submodule 目录但内容为空。pioasm 子项目不依赖这些目录；完整 SDK USB/Wi-Fi/network/Bluetooth 功能才需要它们。

## 推荐方案
**方法**: scope-current-package-and-preserve-placeholders

**说明**: 当前 PR 明确只提供 pioasm + SDK source tree，打包时创建空 submodule 占位目录以保持路径形状；不下载、不 vendoring、不把外部 submodule 适配混入本库 PR。

**验证/命令**:
```
mkdir -p share/pico-sdk/lib/{tinyusb,cyw43-driver,lwip,mbedtls,btstack}
```

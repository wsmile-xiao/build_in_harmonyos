# E032: _GNU_SOURCE 未定义导致 dirent API 不完整

> **结构化数据**: [graph/E032.kv](../graph/E032.kv) | **原则**: [P-CFLAGS-001](../graph/principles.kv)
> **严重度**: 🟡 medium | **分类**: libc/compat/headers | **自动修复**: ✅ set-env-var

---

## 错误特征

```
error: unknown type name 'DIR'
error: call to undeclared function 'opendir'
```

## 根因

musl 需要 `_GNU_SOURCE` 而非 `_BSD_SOURCE` 来暴露完整 dirent API，部分软件使用 `_BSD_SOURCE` 不足以在 musl 下获得完整接口。

## 解决方案

```bash
# 方案 1（推荐）：通过 CFLAGS 添加
export CFLAGS="-D_GNU_SOURCE $CFLAGS"

# 方案 2：修改源码中的 _BSD_SOURCE 为 _GNU_SOURCE
sed -i 's/_BSD_SOURCE/_GNU_SOURCE/g' 源文件
```

## 禁止模式

❌ 在 musl 目标平台上使用 `_BSD_SOURCE` 替代 `_GNU_SOURCE` 来获取 dirent API → 编译失败

## 涉及软件

gawk 5.3.0 及其他使用 dirent API 且依赖 glibc 宏定义的软件。

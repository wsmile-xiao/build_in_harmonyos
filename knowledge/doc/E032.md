# E032: add-cflags

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, headers
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
unknown type name 'DIR'|call to undeclared function 'opendir'|
                         undeclared.*opendir|undeclared.*readdir
```

## 根因分析
musl 需要 _GNU_SOURCE 而非 _BSD_SOURCE 来暴露完整 dirent API,
                         部分软件使用 _BSD_SOURCE 不足以在 musl 下获得完整接口

## 推荐方案
**方法**: add-cflags

**说明**: 通过 CFLAGS 添加 _GNU_SOURCE 宏定义

**验证/命令**:
```
export CFLAGS="-D_GNU_SOURCE $CFLAGS"
```

## 关键词
_GNU_SOURCE, _BSD_SOURCE, DIR, opendir, readdir,
                         dirent, unknown type, undeclared, musl, gawk

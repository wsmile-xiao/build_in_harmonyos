```
libexif/exif-data.h.*No such file or directory|

```

## 根因分析
**fbida 的 GNUmakefile 中 exiftran 和 thumbnail.cgi 目标缺少 libexif 的 pkg-config 配置**。
                         1. libexif 库已安装，头文件和库文件都存在
                         2. 但 GNUmakefile 中的 exiftran 和 thumbnail.cgi 目标没有添加 libexif 的编译和链接选项
                         3. 需要在相应的目标规则中添加：CFLAGS += $(shell $(PKG_CONFIG) --cflags libexif) 和 LDFLAGS += $(shell $(PKG_CONFIG) --libs libexif)
                         这是 fbida 构建脚本的一个缺陷。

## 推荐方案
**方法**: patch-gnu-makefile

**说明**: 修改 GNUmakefile，为 exiftran 和 thumbnail.cgi 目标添加 libexif 的 pkg-config 配置。这是最直接的解决方案，确保编译和链接正确。

**验证/命令**:
```
# Step 1: 备份原文件：cp GNUmakefile GNUmakefile.orig;# Step 2: 添加 libexif 配置（exiftran 目标）：sed -i '/^exiftran:/{n;s/CFLAGS :=/CFLAGS := $(shell $(PKG_CONFIG) --cflags libexif) /}' GNUmakefile;# Step 3: 添加 libexif 配置（thumbnail.cgi 目标）：sed -i '/^thumbnail.cgi:/{n;s/CFLAGS :=/CFLAGS := $(shell $(PKG_CONFIG) --cflags libexif) /}' GNUmakefile;# Step 4: 验证修改：grep -A2 "exiftran:" GNUmakefile | grep libexif
```

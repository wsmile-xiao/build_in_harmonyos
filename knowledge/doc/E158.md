# E158: patch-gnu-makefile

## 基本信息
- **严重度**: 2
- **类别**: build_system|dependency|fbida
- **触发工具**: make|gcc|pkg-config
- **阶段**: compilation

## 错误特征
```
libexif/exif-data.h.*No such file or directory|
```

**关键词**: fbida, libexif, pkg-config, exif-data.h, exiftran, thumbnail.cgi, GNUmakefile, CFLAGS, missing header

## 根因分析
**fbida 的 GNUmakefile 中 exiftran 和 thumbnail.cgi 目标缺少 libexif 的 pkg-config 配置**。

**影响范围**: fbida 2.14 及相关版本、所有编译 exiftran 和 thumbnail.cgi 的项目。

## 推荐方案
- **方法**: patch-gnu-makefile
- **描述**: 修改 GNUmakefile，为 exiftran 和 thumbnail.cgi 目标添加 libexif 的 pkg-config 配置。这是最直接的解决方案，确保编译和链接正确。
- **命令**: `# Step 1: 备份原文件：cp GNUmakefile GNUmakefile.orig;# Step 2: 添加 libexif 配置（exiftran 目标）：sed -i '/^exiftran:/{n;s/CFLAGS :=/CFLAGS := $(shell $(PKG_CONFIG) --cflags libexif) /}' GNUmakefile;# Step 3: 添加 libexif 配置（thumbnail.cgi 目标）：sed -i '/^thumbnail.cgi:/{n;s/CFLAGS :=/CFLAGS := $(shell $(PKG_CONFIG) --cflags libexif) /}' GNUmakefile;# Step 4: 验证修改：grep -A2 "exiftran:" GNUmakefile | grep libexif`
- **自动修复**: true

## 验证
```bash
# 1. 检查 libexif 是否安装：pkg-config --exists libexif && echo "libexif found";# 2. 检查头文件路径：pkg-config --cflags libexif;# 输出: -I/usr/local/include;# 3. 检查库文件路径：pkg-config --libs libexif;# 输出: -L/usr/local/lib -lexif;# 4. 查看编译错误：make exiftran 2>&1 | grep "exif-data.h"
```

# E388: Boost.Math long-double promotion can break numerical convergence on HarmonyOS PC

## 基本信息
- **严重度**: 2
- **类别**: platform, compiler, boost, numerical
- **作者**: elklu02 <f25015115@st.sandau.edu.cn>
- **来源 PR**: !5794

## 错误特征
```
boost::math::evaluation_error|halley_iterate.*root|non_central_chi_squared.*converge|series.*converge
```

## 根因分析
HarmonyOS PC aarch64 long-double ABI and precision behavior differs from the environment assumed by some Boost.Math promotion paths. Promoting double calculations to long double can make root-finding and non-central chi-squared series evaluation fail to converge.

## 推荐方案
**方法**: disable-boost-math-double-promotion

**说明**: Define BOOST_MATH_PROMOTE_DOUBLE_POLICY=0 in the affected Conan/CMake consumer configuration so Boost.Math keeps double calculations on the double path instead of promoting them to long double. Keep the upstream test suite enabled and verify that the full suite passes.

**验证/命令**:
```
|
  # Conan CMakeToolchain recipe configuration.
  tc.preprocessor_definitions["BOOST_MATH_PROMOTE_DOUBLE_POLICY"] = "0"
  # Then execute the complete upstream test suite; do not mask its exit code.
  cmake --build .
  ctest --output-on-failure
```

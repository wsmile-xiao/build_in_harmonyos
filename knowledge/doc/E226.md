# E226: Capture child output as bytes when HarmonyOS os.popen text decoding fails

## 基本信息
- **严重度**: 2
- **类别**: python
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
TypeError: can't concat str to bytes|process_output = pipe\.read\(\)
```

## 根因分析
The validated HarmonyOS Python 3.12 os.popen text wrapper feeds a str fragment into a codec path expecting bytes, so pipe.read raises TypeError before the caller can inspect child output or exit status.

## 推荐方案
**方法**: capture-subprocess-bytes-explicitly

**说明**: Replace only the os.popen text wrapper with subprocess.PIPE byte capture, then decode once explicitly while preserving the command and return-code failure semantics.

**验证/命令**:
```
subprocess.Popen(cmd, shell=True, stdout=subprocess.PIPE, stderr=subprocess.STDOUT).communicate()[0].decode('utf-8', errors='replace')
```

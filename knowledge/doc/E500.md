# E500: OHOS musl libc 无 glibc MAX_INPUT 宏导致编译失败

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, headers
- **作者**: hhyxx1 <f24011422@st.sandau.edu.cn>
- **来源 PR**: !5162

## 错误特征
```
use of undeclared identifier 'MAX_INPUT'|MAX_INPUT.*undeclared
```

## 根因分析
OHOS musl libc 无 glibc 的 MAX_INPUT 宏; 需用 _POSIX_MAX_INPUT 兼容定义

## 推荐方案
**方法**: 源文件加 #ifndef MAX_INPUT #define MAX_INPUT _POSIX_MAX_INPUT #endif

**说明**: 源文件加 #ifndef MAX_INPUT #define MAX_INPUT _POSIX_MAX_INPUT #endif

# E144: manual-build-mode-b

## 基本信息
- **严重度**: 3
- **类别**: cmake-modules-missing
- **触发工具**: cmake
- **阶段**: configuration

## 错误特征
```
Could not find.*BuildVersion\.cmake|include.*BuildVersion.*could not be loaded|CMake Error.*include\(BuildVersion\)
```

**关键词**: cmake module missing, BuildVersion.cmake, ParseVersion.cmake, MongoPlatform.cmake, MongoSettings.cmake, mongo-c-driver, libbson, .work re-initialization

## 根因分析
ohc-run.py build管线重新初始化.work目录时清空build/cmake子目录，导致后续cmake配置无法找到必要的cmake模块文件

**影响范围**: mongo-c-driver/libbson及所有使用嵌套build/cmake目录结构的项目

## 推荐方案
- **方法**: manual-build-mode-b
- **描述**: 使用模式B（手动cmake/make）编译，避免build管线重初始化.work目录；若.work已被重初始化，从.orig复制build/cmake/目录恢复cmake模块
- **命令**: `cp -r $BUILD_SRC_ORIG_DIR/build/cmake $BUILD_SRC_DIR/build/cmake && cd $BUILD_SRC_DIR && cmake -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX -DCMAKE_SYSTEM_NAME=Linux <其他选项> .`
- **自动修复**: false

## 验证
```bash
ls $BUILD_SRC_DIR/build/cmake/BuildVersion.cmake
```

# E072: patch-autotools-script

## 基本信息
- **严重度**: 3
- **类别**: autotools, configure
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
configure: error: invalid triplet.*ohos|config\.sub: invalid configuration.*ohos|cannot guess build type|unknown vendor|unknown operating system
```

## 根因分析
config.sub 未识别 ohos 作为合法操作系统值，导致三元组 aarch64-*-linux-ohos 验证失败。
                        与 E007（config.guess 无法识别系统名）互补：E007 负责"猜出"三元组，E072 负责"验证"三元组合法性。

## 推荐方案
**方法**: patch-autotools-script

**说明**: 在 config.sub 中做 3 处修改（完整方案）：
                        1. 在 android-linux 分支后添加 ohos-linux → basic_os=linux-ohos 映射
                        2. 在 OS 白名单（case $os in）中添加 ohos*
                        3. 在 kernel-os 白名单（case $kernel-$os in）中添加 linux-ohos*
                        缺少第 3 处会导致 "Kernel 'linux' not known to work with OS 'ohos'" 错误。

**验证/命令**:
```
|
  # 修改1: basic_os 映射 — 找到 android-linux 分支，在其后添加：
  #   ohos-linux)
  #       basic_machine=$field1-unknown
  #       basic_os=linux-ohos
  #       ;;
  #
  # 修改2: OS 白名单 — 在 case $os in 中找到 gnu* | android* | bsd* 行，添加 ohos* ：
  #   ohos* | gnu* | android* | bsd* | mach* | minix* ...
  #
  # 修改3: kernel-os 白名单 — 找到 linux-gnu* | linux-dietlibc* | linux-android* 行，
  #   在 linux-musl* 之后添加 linux-ohos* ：
  #   linux-gnu* | linux-dietlibc* | linux-android* | linux-newlib* \
  #       | linux-musl* | linux-ohos* | linux-relibc* | linux-uclibc* )
```

# E525: OHOS 下 make 应统一 -j1：仓库 Makefile 模板（如 7zip）仍用 -j$(nproc) 需修正

## 基本信息
- **严重度**: 2
- **类别**: selinux, build-system, filesystem
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: !5959

## 错误特征
```
make.*-j.*hang|make.*stuck|FIFO.*Permission denied|make.*-j.*nproc
```

## 根因分析
鸿蒙 SELinux 策略禁止用户进程创建 FIFO，GNU make jobserver 依赖
                    FIFO 传递并行令牌，make -j>1 会卡住或报错（E074）。仓库部分
                    Makefile 型 recipe 模板（archives/7/7zip/23.01 与 25.01
                    conanfile.py）仍用 make -j$(nproc)，新 recipe 照抄会踩 FIFO 坑。

## 推荐方案
**方法**: force-j1

**说明**: Makefile 型 recipe 的 self.run 统一 make -j1；E074 增补模板不一致提示。

**验证/命令**:
```
make lib -j1
```

make -j, nproc, -j1, FIFO, jobserver, 7zip, Makefile, OHOS, 并行构建

# E504: CMake install 期 RPATH_CHANGE 重写 .so 后 OHOS musl loader 无法加载

## 基本信息
- **严重度**: 3
- **类别**: cmake, install
- **作者**: hazel_xyx <1707119571@qq.com>
- **来源 PR**: !5897

## 错误特征
```
Error loading shared library|RPATH_CHANGE|Error in test() method|Error 127 while executing
```

## 根因分析
CMake install 期 RPATH_CHANGE 重写链接了依赖库的 .so，改写产物 OHOS musl loader 无法加载（即使 LD_LIBRARY_PATH 指向也失败）

## 推荐方案
**方法**: conanfile.py generate() 设 CMAKE_SKIP_INSTALL_RPATH=TRUE，并在 package() 中用构建产物覆盖 install 产物（libubox 先例）

**说明**: 跳过 install 期 RPATH 改写，package() 内用 build 目录原始 .so/jshn 覆盖安装产物，保证 loader 可加载

**验证/命令**:
```
conanfile.py 中 generate() 加 tc.cache_variables["CMAKE_SKIP_INSTALL_RPATH"]="TRUE"；package() 中 shutil.copy2 覆盖
```

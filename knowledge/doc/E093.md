# E093: musl 缺 getpass() GNU 扩展

> **结构化数据**: [graph/E093.kv](../graph/E093.kv)
> **严重度**: 🟡 medium | **分类**: libc-compat|musl | **自动修复**: ❌ source-patch

---

## 错误特征

编译阶段：
```
warning: implicit declaration of function 'getpass' is invalid in C99
```

链接阶段：
```
undefined reference to 'getpass'
```

## 根因

`getpass()` 是 GNU 扩展函数（POSIX.1-2001 中已标记为废弃），用于从终端读取密码（关闭回显）。
musl libc 不实现此函数。当软件源码中直接调用 `getpass()` 时，musl 环境下无此符号声明和定义，
导致编译报 "implicit declaration" 或链接报 "undefined reference"。

## 影响范围

需要终端密码输入的命令行工具。已知受影响：
- **wavpack** — 音频编解码工具

## 解决方案

### 方案 1（推荐）：添加 getpass() 替代实现

在源码中用 `#ifdef __OHOS__` 守卫，提供基于 `fgets` 的简单替代：

```c
#ifdef __OHOS__
static char *getpass(const char *prompt) {
    static char buf[256];
    fprintf(stderr, "%s", prompt);
    fflush(stderr);
    if (fgets(buf, sizeof(buf), stdin) == NULL) return NULL;
    buf[strcspn(buf, "\n")] = '\0';
    return buf;
}
#endif
```

> **注意**：此实现不关闭终端回显，仅作为功能替代。鸿蒙上通常不需要安全密码输入。

修改后需 `track-edit add` 记录。

### 方案 2：禁用相关功能

如果密码输入功能不是必需的：
```bash
./configure --prefix=$DEFAULT_PREFIX --disable-password
# 或类似选项，视具体软件而定
```

## 验证

```bash
# 确认 musl 无此函数
echo '#include <unistd.h>
int main(){getpass("x");}' | cc -xc - -c 2>&1 | grep getpass

# 编译通过即修复成功
make -j$(nproc)
```

## ⛔ 禁止

- **不要**使用 `-DHAVE_GETPASS` 强制声明函数存在，musl 无此符号会导致链接失败。

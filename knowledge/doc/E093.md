## 错误特征
```
implicit declaration of function.*getpass|
                         undefined reference to.*getpass
```

## 根因分析
getpass() 是 GNU 扩展函数（POSIX 已标记为废弃），
                        musl libc 不实现此函数。
                        软件源码中直接调用 getpass() 时，
                        musl 环境下无此符号声明，导致编译报
                        "implicit declaration" 或链接时报 "undefined reference"。

## 推荐方案
**方法**: source-patch

**说明**: 添加 getpass() 的简单实现，或通过 --disable-feature
                        绕过密码输入功能。实现方式：在源码中用
                        #ifdef __OHOS__ 守卫，提供基于 fgets 的替代实现。

**验证/命令**:
```
|
                        #ifdef __OHOS__
                        static char *getpass(const char *prompt) {
                            static char buf[256];
                            fprintf(stderr, "%s", prompt);
                            fflush(stderr);
                            if (fgets(buf, sizeof(buf), stdin) == NULL) return NULL;
                            buf[strcspn(buf, "\n")] = '\0';
                            return buf;
                        }
                        #endif
```

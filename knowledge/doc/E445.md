# E445: Neovim runtime plugins need a packaged Vusted/Busted chain for Path B upstream tests

## 基本信息
- **严重度**: 2
- **类别**: lua, testing, busted, neovim, path-b
- **作者**: zxyAtom <alhvrlVUxiGd6QEv.zxyAtom@noreply.gitcode.com>
- **来源 PR**: !3752

## 错误特征
```
vusted ./test|make test -> vusted ./test|nvim --headless|0/9 actual upstream Vusted tests executed
```

## 根因分析
Neovim runtime-plugin upstream tests can require a real headless Neovim plus Vusted/Busted Lua test harness; package-layout or Python consumer checks do not execute the upstream Vusted cases and must not be counted as upstream passes.

## 推荐方案
**方法**: path-b-packaged-neovim-vusted-chain

**说明**: Use Path B when the upstream test harness needs packaged Neovim/Vusted prerequisites; package the upstream test tree, run the real vusted command from the installed plugin root, and keep adapted consumer layout checks separate from upstream-test accounting.

**验证/命令**:
```
conan create archives/n/nvim-lspconfig/2.5.0 --build=missing; cd <package>/share/nvim-lspconfig && vusted ./test
```

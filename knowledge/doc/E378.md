# E378: Run Conan source probes only from an isolated recipe copy

## 基本信息
- **严重度**: 2
- **类别**: platform, conan2, source-folder, worktree-contamination
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5392

## 错误特征
```
Calling source\(\) in .*archives.*|conan source.*unrecognized arguments.*output-folder
```

## 根因分析
Conan 2.29.1 does not accept conan source --output-folder and an absolute recipe path still sets source_folder to the recipe directory, so get(strip_root=True) extracts into the worktree.

## 推荐方案
**方法**: isolated-recipe-copy-source-probe

**说明**: Treat the current recipe directory as the source output of conan source, so every source probe must execute from a disposable isolated recipe copy.

**验证/命令**:
```
Create a new evidence/case/recipe directory, copy the recipe metadata, run conan source . with a case-local Conan home, and compare the original worktree before and after.
```

## 关键词
conan source, source_folder, output-folder, absolute recipe path, strip_root

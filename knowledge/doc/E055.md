## 根因分析
Python 3.12 subprocess.py 在 musl/HarmonyOS 上 _USE_POSIX_SPAWN=True,
                         所有子进程通过 os.posix_spawn() 启动而非 fork()+exec():
                         errpipe 机制失效(父进程直接报错)、shell 内建命令不可直接 exec

## 推荐方案
**方法**: skip-test

**说明**: 运行时检测 subprocess._USE_POSIX_SPAWN 并 skip 受影响测试

**验证/命令**:
```

```

# E005: 静态库链接共享库失败 (-fPIC)

> **结构化数据**: [graph/E005.kv](../graph/E005.kv) | **原则**: P-CFLAGS-001
> **严重度**: 🟡 medium | **分类**: linking | **自动修复**: ✅ set-env-var

---

## 错误特征

```
relocation R_AARCH64_ABS32 against symbol `xxx' can not be used when making a shared object; recompile with -fPIC
cannot be used when making a shared object; recompile with -fPIC
```

## 根因

静态库（.a）编译时未使用 `-fPIC`，链接到共享库（.so）时 aarch64 要求位置无关代码。

## 解决方案

```bash
export CFLAGS="-fPIC $CFLAGS"
# 然后重新编译
make clean && make
```

## 涉及软件

使用静态库链接到共享库的 autotools 项目。

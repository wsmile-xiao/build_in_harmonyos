# E005: add-cflags

## 基本信息
- **严重度**: 2
- **类别**: linking
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
relocation R_AARCH64.*recompile with -fPIC|
                         -fPIC.*shared library|cannot be used.*-fPIC
```

## 根因分析
静态库编译时未使用 -fPIC,
                         链接到共享库时 aarch64 要求位置无关代码

## 推荐方案
**方法**: add-cflags

**说明**: 添加 -fPIC 到 CFLAGS 重试编译

**验证/命令**:
```
CFLAGS="-fPIC $CFLAGS"
```

## 关键词
-fPIC, relocation, R_AARCH64, PIC,
                         static library, shared library, position independent

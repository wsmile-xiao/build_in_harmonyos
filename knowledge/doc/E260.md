# E260: A fixed interpreter launcher must execute the validated file descriptor

## 基本信息
- **严重度**: 3
- **类别**: java, security, launcher
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: #3928

## 错误特征
```
native-image.*(126|127)|fixed Python launcher selected a shell wrapper|not an ELF executable|validated Python path was replaced before exec
```

## 根因分析
A signed launcher that validates a fixed Python path but later executes the pathname separates the checked object from the executed object. An executable shell wrapper can pass stat plus X_OK, and a same-UID writer can atomically replace a real ELF after validation but before path-based exec.

## 推荐方案
**方法**: descriptor-bound-elf-launch

**说明**: Keep the absolute allow-list, open each candidate read-only, bind path and open identities, require ELF magic, retain the descriptor through exec, and launch it with fexecve or an equivalent fd-bound API.

**验证/命令**:
```
Add an open_elf_executable helper that returns a validated descriptor and pass that descriptor directly to fexecve.
```

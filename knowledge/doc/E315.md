# E315: authoritative-param-probe-with-tzdir-priority

## 错误特征
```
(converted from|UTC offset|tzcode|zoneinfo|localtime).*Asia/Shanghai| Olson|IANA|TZDIR|persist\.time\.timezone|param get
```

## 根因分析
HarmonyOS 不通过传统 /etc/localtime 链暴露权威本地时区。设备只读调查确认 /usr/bin/param get persist.time.timezone 返回 Asia/Shanghai（权威 IANA 名称）；系统 /system/etc/zoneinfo/tzdata 为 OpenHarmony 打包格式，不是 R 可直接遍历的 Olson 目录。/etc/zoneinfo 目录虽存在但没有 Asia/Shanghai 展开文件，会遮蔽 R internal zoneinfo。R 官方源码自带 src/extra/tzone/zoneinfo.zip（含 zoneinfo/Asia/Shanghai），因此需启用 --with-internal-tzcode 以 R 自带版本固定的 IANA 数据库作为 TZDIR 能力来源。

## 推荐方案
**方法**: authoritative-param-probe-with-tzdir-priority

**说明**: 补丁 0003 在 datetime.R 的 Sys.timezone() 中，传统发现链前插入 HarmonyOS 专用探测块：(1) 仅当 param 命令存在时执行 param get persist.time.timezone；(2) 返回单一非空 IANA 名称后，按 R internal zoneinfo → 显式 TZDIR → 标准系统目录的候选优先级，仅选择真实包含该 IANA 文件的候选目录；(3) 将选中目录写入 TZDIR 环境变量，调用 cacheIt 缓存时区名称并返回。configure 阶段启用 --with-internal-tzcode 确保 R 自带 IANA 数据库可用。未硬编码 Asia/Shanghai 或 UTC。

**验证/命令**:
```
./configure --prefix=/ --with-internal-tzcode && patch -p1 < patches/0003-authoritative-timezone-param.patch && make -j4 && make install DESTDIR=$TEST_PREFIX
```

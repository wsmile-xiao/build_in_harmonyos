# E126: use_precompiled_package          # 见 DESIGN §5 impl 列表

## 基本信息
- **严重度**: 3
- **类别**: platform_limitation
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
can't create ./conf[a-zA-Z0-9]+/subs[0-9]+\.awk: Permission denied|config\.status.*Permission denied|HMDFS.*temporary file
```

**关键词**: HMDFS, config.status, Permission denied, temporary file, autotools

## 根因分析
HarmonyOS HMDFS 文件系统不支持 GNU autotools 的 config.status 创建临时目录和文件（confXXXX/subs1.awk 等），导致 configure 生成的 config.status 无法执行

**影响范围**: 所有使用 GNU autoconf 的软件编译，包括 MPFR、GMP、openssl 等 autotools 项目

## 推荐方案
- **方法**: use_precompiled_package          # 见 DESIGN §5 impl 列表
- **描述**: 使用预编译包替代手动编译（R18 预编译包优先原则）
- **命令**: `curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- {software} {version}`
- **自动修复**: true                  # 引擎能否自动执行

## 验证
```bash
df -h ~/tmp | grep hmdfs
```

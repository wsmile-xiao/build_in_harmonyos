# E065: fix-cppflags-or-reconfigure

## 基本信息
- **严重度**: 2
- **类别**: headers, compilation, gnulib
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
undeclared identifier.*xzalloc|unexpected type name.*size_t|
                         undeclared.*xmemdup|gnulib.*symbol.*undeclared|
```

## 根因分析
gnulib 提供的头文件之间有依赖顺序要求。
                         xzalloc() 定义在 lib/xalloc.h, size_t 需要 <stddef.h>。
                         如果 .c 文件的 #include 顺序不符合 gnulib 预期,
                         或者 gnulib 替换头文件未正确覆盖系统头文件, 就会导致符号未声明。
                         这通常是 E064(conftest 失败)的二级后果: config.h 包含了错误的 #define 配置

## 推荐方案
**方法**: fix-cppflags-or-reconfigure

**说明**: 确保 CPPFLAGS 包含必要路径(-I$BUILD_SRC_DIR/lib -I$BUILD_SRC_DIR);
                         或在受影响 .c 文件显式包含所需头文件;
                         或清理后重新 configure(解决 E064 后通常会顺带解决)

**验证/命令**:
```
export CPPFLAGS="-I$BUILD_SRC_DIR/lib -I$BUILD_SRC_DIR"
```

# E090: Meson host_system == 'linux' 不匹配 HarmonyOS

## 基本信息
- **严重度**: 3 (blocking)
- **类别**: platform_detection
- **触发工具**: meson
- **阶段**: configure, linking
- **首次发现**: glib 2.88.0 编译 (2026-04-21)

## 错误签名

configure 阶段:
```
Build machine: operating system: harmonyos
```

linking 阶段:
```
ld.lld: error: undefined symbol: _g_fd_is_journal
>>> referenced by glib/gjournal-private.c
```

## 根因分析

Meson 构建系统在 HarmonyOS 上检测到 `host_system = 'harmonyos'`，而非 `'linux'`。
许多 Linux 软件的 meson.build 使用 `if host_system == 'linux'` 条件来包含 Linux 特有源文件。
由于 harmonyos ≠ linux，这些源文件被跳过，但代码中引用了其中的函数，导致链接失败。

HarmonyOS 基于 Linux 内核，Linux 特有功能（systemd journal、netlink socket、epoll 等）通常适用。

## 受影响范围

所有使用 meson 构建系统且有 `host_system == 'linux'` 条件判断的软件。
已知受影响:
- glib (gjournal-private.c, gio-launch-desktop, musl detection, mkostemp check)
- systemd（预期）
- 其他检查 host_system 的 meson 项目

## 解决方案

### 方案 1（推荐）：sed 替换 host_system 检查

```bash
# 全局替换所有 meson.build 文件
find . -name meson.build -exec sed -i "s/if host_system == 'linux'/if host_system in ['linux', 'harmonyos']/g" {} +

# 每个 meson.build 文件需要 track-edit add 记录
```

### 验证

```bash
grep -rn "host_system in \['linux', 'harmonyos'\]" meson.build **/meson.build
# 应看到所有之前 host_system == 'linux' 的位置已替换
```

# E090: sed-replace

## 基本信息
- **严重度**: 3
- **类别**: platform, detection, meson
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
undefined symbol: _g_fd_is_journal|host_system.*harmonyos|meson.*host_system.*linux|Platform.*harmonyos.*not.*linux
```

## 根因分析
Meson 检测 HarmonyOS 为 'harmonyos' 而非 'linux'，
                        导致 meson.build 中 `host_system == 'linux'` 条件检查失败，
                        Linux 特有源文件（如 glib 的 gjournal-private.c）未被编译，
                        产生 undefined symbol 链接错误。
                        HarmonyOS 基于 Linux 内核，Linux 特有功能（systemd journal、netlink 等）通常适用。

## 推荐方案
**方法**: sed-replace

**说明**: 将所有 meson.build 中的 host_system == 'linux' 替换为
                        host_system in ['linux', 'harmonyos']，
                        使 Linux 特有代码路径在 HarmonyOS 上也可用。
                        需要对每个 meson.build 文件执行 track-edit add 记录。

**验证/命令**:
```
find . -name meson.build -exec sed -i "s/if host_system == 'linux'/if host_system in ['linux', 'harmonyos']/g" {} +
```

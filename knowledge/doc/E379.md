clang-format-Windows.*file\(DOWNLOAD\)|Object CID=.*not found.*No ExternalData_URL_TEMPLATES given|missing binary patch data|100% tests passed out of

## 根因分析
A complete upstream test graph can consume formatting tools, compiler-specific support libraries, auxiliary source projects, and content-addressed baselines outside the main source archive; a Conan recipe that validates a task-local store but does not export it still fails on a clean CI worker, while a PR checkout service that applies a text-only diff cannot transport newly added raw binary baselines even when Git stores them correctly.

## 推荐方案
**方法**: manifest-bound-complete-test-input-closure

**说明**: Preserve the upstream test inventory while exporting every required auxiliary source and content object, validating the complete manifest, using canonical text transport when the PR service cannot carry binary patch payloads, and binding the exact ExternalData hash-store root for runnable builds.

**验证/命令**:
```
Store each binary object as canonical line-wrapped Base64 text when required by the PR transport, decode only inside export_sources, verify decoded path/bytes/SHA-256 against the unchanged manifest, export only the manifest plus original bytes, default runnable builds to source_folder/test-data/Objects while preserving a validated non-empty explicit override, normalize an empty override to the default, ignore host overrides for non-runnable builds, reject links and missing/extra objects, set ExternalData_NO_SYMLINKS, disable URL fallback, then execute the full CTest inventory.
```

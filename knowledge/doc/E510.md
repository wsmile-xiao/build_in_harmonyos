# E510: toybox patch 无法处理带路径层级/fuzz 的上游补丁，需前置 harmonybrew GNU patch

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, patch
- **作者**: 2401_87095818 <zhaowenxiang06@outlook.com>
- **来源 PR**: !4753

## 错误特征
```
Hunk.*FAILED|patch.*succeeded.*with fuzz|can't find file to patch|does not exist in index
```

## 根因分析
鸿蒙系统 /usr/bin/patch 或 /system/bin/patch 是 toybox 实现，
            缺少 GNU patch 的 fuzz tolerance（上下文偏移容差）和路径
            层级自动剥离能力。带 bundled C 补丁的 Rust crate（如
            libquickjs-sys 的 stack-overflow-signed.patch）的 hunks 上下文
            与 vendored 源码有偏移，toybox patch 直接报 "Hunk #1 FAILED"，
            而 GNU patch 能用 fuzz 2 容差成功应用（"Hunk #1 succeeded
            at 1587 with fuzz 2 (offset -145)"）。

## 推荐方案
**方法**: prepend-harmonybrew-gnu-patch

**说明**: 在 conanfile.py build() 开头将 harmonybrew 的 GNU patch
                 （~/.harmonybrew/bin/patch）前置到 PATH，确保 cargo build
                 调用 build script 中的 patch 命令时用 GNU patch 而非 toybox。
                 若 harmonybrew 未安装 gpatch，先通过 brew install gpatch。

**验证/命令**:
```
|
  import os, shutil
  brew_bin = os.path.expanduser("~/.harmonybrew/bin")
  gpatch = os.path.join(brew_bin, "patch")
  if not (os.path.isfile(gpatch) and os.access(gpatch, os.X_OK)):
      brew = os.path.join(brew_bin, "brew")
      if os.path.isfile(brew):
          self.run(f"{brew} install gpatch", env="conanbuild")
  if os.path.isfile(gpatch) and os.access(gpatch, os.X_OK):
      os.environ["PATH"] = brew_bin + ":" + os.environ.get("PATH", "")
```

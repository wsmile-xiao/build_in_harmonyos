# E051: source-patch

## 基本信息
- **严重度**: 3
- **类别**: compat, kernel, syscall, security
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
exit code 159|SIGSYS|killed.*signal 31|
                         setreuid.*killed|setregid.*SIGSYS|unimplemented syscall
```

## 根因分析
鸿蒙内核对未实现的 syscall 发送 SIGSYS 信号(signal 31),
                         但其行为与 Linux seccomp SIGSYS 完全不同:
                         部分 syscall(setreuid/setregid)的 SIGSYS 不可捕获,
                         进程直接被终止, 信号处理方案完全不可行

## 推荐方案
**方法**: source-patch

**说明**: 在 C 源码中用 #ifdef __OHOS__ 守卫,
                         在 syscall 调用前直接返回 errno=ENOSYS 并 return -1,
                         完全跳过未实现的 syscall 调用

**验证/命令**:
```
rec_auto_fix:          false
```

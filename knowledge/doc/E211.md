## 错误特征
```
undeclared identifier.*pthread_getaffinity_np|undeclared identifier.*pthread_setaffinity_np|did you mean.*sched_setaffinity
```

## 根因分析
musl libc 缺少 glibc 的 pthread affinity 扩展函数,
                        pthread_getaffinity_np / pthread_setaffinity_np 在 musl 中未实现,
                        OpenHarmony 使用 musl libc 因此受影响

## 推荐方案
**方法**: replace-with-sched-api

**说明**: 用 sched_getaffinity/sched_setaffinity 替代 pthread affinity 函数,
                        sched_* 是标准 POSIX API, musl 完整实现, pid=0 表示当前线程/进程,
                        需确保 cpu_set_t 类型通过 sched.h 可用

**验证/命令**:
```
sed -i 's/pthread_getaffinity_np(/sched_getaffinity(0, /g; s/pthread_setaffinity_np(/sched_setaffinity(0, /g'
```

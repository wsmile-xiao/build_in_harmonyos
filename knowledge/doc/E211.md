# E211: replace-with-sched-api

## 基本信息
- **严重度**: 2
- **类别**: platform_compat
- **触发工具**: cc
- **阶段**: compilation

## 错误特征
```
undeclared identifier.*pthread_getaffinity_np|undeclared identifier.*pthread_setaffinity_np|did you mean.*sched_setaffinity
```

**关键词**: pthread_getaffinity_np, pthread_setaffinity_np, musl, affinity,

## 根因分析
musl libc 缺少 glibc 的 pthread affinity 扩展函数,

**影响范围**: 使用 pthread affinity API 的软件 (OpenImageDenoise, TBB, OpenMPI 等)

## 推荐方案
- **方法**: replace-with-sched-api
- **描述**: 用 sched_getaffinity/sched_setaffinity 替代 pthread affinity 函数,
- **命令**: `sed -i 's/pthread_getaffinity_np(/sched_getaffinity(0, /g; s/pthread_setaffinity_np(/sched_setaffinity(0, /g'`
- **自动修复**: false

## 验证
```bash
echo -e '#include <pthread.h>\nint main(){pthread_getaffinity_np(0,0,0);return 0;}' | clang -x c -c - -o /dev/null 2>&1
```

# E309: 直拷源码漏掉构建阶段生成的公共头

## 基本信息
- **严重度**: 2
- **类别**: headers, cross-compile, packaging
- **作者**: 1catmint1
- **来源 PR**: source_commit:

## 错误特征
```
fatal error: .*\.h.*file not found|missing generated public header|package.*installed header.*missing
```

## 根因分析
自定义 Conan 配方只复制源码树中已有的 *.h，却没有核对 CMake/Meson/Autotools 的安装清单；由 configure_file 或编译器特性探测生成的公共头只存在于构建目录，因此不会进入包。若生成内容依赖目标 libc、ABI 或工具链，同时清空 package ID 会把错误头复用于不兼容目标。

## 推荐方案
**方法**: reproduce-generated-install-output

**说明**: 先从所有上游构建系统的安装定义枚举静态和生成公共头；运行上游配置步骤，或用 Conan profile 声明的目标编译器复现最小特性探测，再从原始模板生成并打包公共头。保留影响生成内容的 package ID 设置，并增加会展开生成宏或访问被探测成员的消费者测试。

**验证/命令**:
```
audit upstream install definitions; compile target feature probes; configure the header template; package and compile a substantive consumer
```

## 错误特征
```
tar.*Error is not recoverable|tar.*Cannot open|refresh-patch.*tar.*fail|
                         \.tar\.xz.*not supported|unsupported tar format
```

## 根因分析
refresh-patch.sh 内部硬编码 tar xzf 解压原始 tarball,
                         只支持 .tar.gz 格式。GNU 软件越来越多使用 .tar.xz(xz 压缩率更高),
                         导致解压失败和补丁管线中断

## 推荐方案
**方法**: source-patch

**说明**: 修改 refresh-patch.sh 按 tarball 扩展名选择解压方式:
                         *.tar.gz→tar xzf, *.tar.xz→tar xJf, *.tar.bz2→tar xjf, 其他→tar xf(自动检测)

**验证/命令**:
```
rec_auto_fix:          true
```

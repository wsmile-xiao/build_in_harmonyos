# E033: add-cflags

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, headers
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
unknown type name 'cchar_t'|call to undeclared function 'setcchar'|
                         undeclared.*cchar_t|undeclared.*setcchar|ncurses.*wide
```

## 根因分析
musl 下 ncurses 宽字符接口需要显式定义 _XOPEN_SOURCE_EXTENDED
                         才能暴露 cchar_t 等类型和 setcchar 等函数

## 推荐方案
**方法**: add-cflags

**说明**: 通过 CFLAGS 添加 _XOPEN_SOURCE_EXTENDED 和 _XOPEN_SOURCE=600

**验证/命令**:
```
export CFLAGS="-D_XOPEN_SOURCE_EXTENDED -D_XOPEN_SOURCE=600 $CFLAGS"
```

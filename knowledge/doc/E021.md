# E021: skip-configure-test

## 基本信息
- **严重度**: 1
- **类别**: configure, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
BUILDEXEEXT=\.exe|BUILDPYTHON.*\.exe|
                         .*\.exe.*should not have.*extension
```

## 根因分析
configure 脚本通过检测文件系统是否大小写不敏感来
                         设置 BUILDEXEEXT, 鸿蒙 HMFS 在边界检测中可能误判,
                         导致可执行文件名被附加 .exe 后缀

## 推荐方案
**方法**: skip-configure-test

**说明**: 在 configure.ac 中为 HarmonyOS 跳过此检测(从源头避免误判),
                         或通过传参/patch 让 configure 不设置 BUILDEXEEXT=.exe

**验证/命令**:
```
rec_auto_fix:          false
```

## 关键词
BUILDEXEEXT, .exe, case insensitive, conftestdir,
                         file system, build exe, extension, Makefile

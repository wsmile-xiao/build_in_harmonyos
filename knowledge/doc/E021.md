# E021: BUILDEXEEXT 异常（.exe 后缀误判）

> **结构化数据**: [graph/E021.kv](../graph/E021.kv) | **原则**: 无
> **严重度**: 🟢 low | **分类**: configure/filesystem | **自动修复**: ❌ 需源码补丁 / ✅ sed 回退

---

## 错误特征

```
BUILDEXE=.exe
BUILDPYTHON= python3.9.exe   # 应该是 python3.9
```

## 根因

configure 脚本通过检测文件系统是否大小写不敏感来设置 `BUILDEXEEXT`：

```bash
mkdir conftestdir
if test -d conftestdir; then
    BUILDEXEEXT=.exe  # 认为大小写不敏感
fi
```
鸿蒙 HMFS 在边界检测中可能误判。

## 解决方案

**优先级1：跳过 configure 检测（推荐）**

在 `configure.ac` 中为 HarmonyOS 跳过此检测。

**回退方案：sed 修正 Makefile**

```bash
sed -i 's/BUILDEXEEXT=.exe/BUILDEXEEXT=/' Makefile
```

## 涉及软件

Python 3.9.0、其他使用 BUILDEXEEXT 的 autotools 项目。

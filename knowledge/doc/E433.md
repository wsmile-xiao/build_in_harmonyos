# E433: 打包的 gpgme-config 过滤 -I/include 且不含自身 include 目录 → setup.py 找不到 gpgme.h

## 基本信息
- **严重度**: 1
- **类别**: autotools, conan
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>
- **来源 PR**: !6301

## 错误特征
```
gpgme.h not found|gpgme-config --cflags 缺自身 include 目录|找不到 gpgme.h
```

## 根因分析
gpgme 包的 gpgme-config 由 --with-libgpg-error-prefix 构建，自身 cflags="-I/include" 被脚本运行时过滤（skip=yes），且不含 GPGME 自身 include 目录；gpg-error 包无 gpg-error-config（仅 gpgrt-config，其在 OHOS mksh 下挂起）。configure 的 AM_PATH_GPGME 取 GPGME_CFLAGS=$GPGME_CONFIG --cflags，传给 setup.py 后 include_dirs 缺 <gpgme>/include → gpgme.h 找不到。

## 推荐方案
**方法**: config-overrides-wrapper

**说明**: 在 build 内 config-overrides/bin 自建 gpgme-config/gpg-error-config 包装：--cflags 输出 -I<gpgme>/include -I<assuan>/include -I<gpg-error>/include，--libs 输出 -L... -lgpgme -lassuan -lgpg-error；gpgrt-config 不放 PATH（避免 mksh 挂起）用自建 gpg-error-config 替代；注意 conan Environment.prepend_path 顺序（先 prepend 依赖 bin，最后 prepend config-overrides/bin）

**验证/命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

# E269: Python 2 测试 runner 在 OHOS Python 3 环境中无法执行

## 基本信息
- **严重度**: 2
- **类别**: testing
- **作者**: tianyi_wang <tianyiwang58@gmail.com>
- **来源 PR**: source_commit:

## 错误特征
```
SyntaxError: Missing parentheses in call to print|#!/usr/bin/env python2|Python 2.*runner|print .*SyntaxError
```

## 根因分析
上游测试 runner 使用 Python 2 的 print 语句或其他仅 Python 2 支持的语法；HarmonyOS CI 仅提供 Python 3，导致语法检查或测试执行失败。

## 推荐方案
**方法**: port-python-script

**说明**: 对于不依赖 Python 2 C 扩展或 Python 2 专有第三方包的测试 runner，保持测试语料和断言语义不变，将 shebang 改为 python3、print 语句改为函数调用，并将 subprocess.check_output 返回的 bytes 在展示错误时显式 decode。将迁移后的 runner 纳入构建或测试阶段，以目标二进制和完整上游语料执行验证。

**验证/命令**:
```
python3 -m py_compile run_tests.py && LD_LIBRARY_PATH=<build_folder> python3 run_tests.py
```

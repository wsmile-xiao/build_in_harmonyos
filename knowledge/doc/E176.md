# E176: static-build-with-static-data

## 基本信息
- **严重度**: 3
- **类别**: platform|harmonyos|icu|bootstrap
- **触发工具**: make|icupkg
- **阶段**: build

## 错误特征
```
Error loading shared library libicudata.so.*|Error relocating.*icudt.*_dat: symbol not found|cannot load stubdata
```

**关键词**: ICU, stubdata, libicudata, dynamic linker, bootstrap, static, data packaging

## 根因分析
HarmonyOS 动态链接器对 ICU 的 stubdata 共享库有特殊限制，无法正常加载空 stubdata 库用于 bootstrap 过程。ICU 构建系统依赖 bootstrap：工具需要库运行，库需要工具构建数据。在 HarmonyOS 上，动态链接器拒绝加载只包含空符号的 stubdata 库。

**影响范围**: 所有 ICU 版本（78+）在 HarmonyOS 上的编译

## 推荐方案
- **方法**: static-build-with-static-data
- **描述**: 使用静态编译模式，将数据嵌入静态库，避免动态链接器依赖。configure 参数：--disable-shared --enable-static --with-data-packaging=static
- **命令**: `./configure --prefix=$DEFAULT_PREFIX --disable-shared --enable-static --with-data-packaging=static && make -j4 && make install DESTDIR=$TEST_PREFIX`
- **自动修复**: true

## 验证
```bash
ls -lh lib/libicudata.so.* && LD_LIBRARY_PATH=lib bin/icupkg --version
```

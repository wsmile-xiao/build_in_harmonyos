# E179: configure-option

## 基本信息
- **严重度**: 3
- **类别**: platform-limitation
- **触发工具**: python
- **阶段**: runtime

## 错误特征
```
ImportError: Error loading shared library.*Permission denied
```

**关键词**: ELF签名, Python扩展模块, Permission denied, ImportError

## 根因分析
鸿蒙系统要求 ELF 文件签名才能执行，HMDFS + SELinux 限制导致 Python 无法加载自定义编译的扩展模块

**影响范围**: 所有包含 Python 扩展模块（.so）的软件

## 推荐方案
- **方法**: configure-option
- **描述**: 禁用需要加载 Python 扩展模块的功能
- **命令**: `添加构建选项: -Dbuild_introspection_data=false (meson) 或 --disable-introspection (autotools)`
- **自动修复**: true

## 验证
```bash
python3 -c "import _module" 2>&1 | grep "Permission denied"
```

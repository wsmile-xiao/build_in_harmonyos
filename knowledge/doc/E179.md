# E179: configure-option

## 基本信息
- **严重度**: 3
- **类别**: platform, limitation
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
ImportError: Error loading shared library.*Permission denied
```

## 根因分析
鸿蒙系统要求 ELF 文件签名才能执行，HMDFS + SELinux 限制导致 Python 无法加载自定义编译的扩展模块

## 推荐方案
**方法**: configure-option

**说明**: 禁用需要加载 Python 扩展模块的功能

**验证/命令**:
```
添加构建选项: -Dbuild_introspection_data=false (meson) 或 --disable-introspection (autotools)
```

## 关键词
ELF签名, Python扩展模块, Permission denied, ImportError

# E133: temp-move-musl-headers

## 基本信息
- **严重度**: 3
- **类别**: platform, musl, header-conflict
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
no member named 'nullptr_t' in the global namespace|pthread_cond_clockwait|target of using declaration conflicts|unable to find library -lc\+\+
```

## 根因分析
cmake adds -isystem ~/usr/local/include for dependency headers, which causes musl libc headers (stddef.h, stdlib.h, pthread.h etc.) to shadow compiler built-in headers and OHOS SDK sysroot headers

## 推荐方案
**方法**: temp-move-musl-headers

**说明**: Temporarily move conflicting musl headers from ~/usr/local/include/ during compilation, restore after build

**验证/命令**:
```
mkdir -p ~/tmp/musl_backup && for h in stddef.h stdint.h stdlib.h string.h stdio.h pthread.h time.h unistd.h wchar.h wctype.h ctype.h errno.h fcntl.h signal.h limits.h float.h locale.h setjmp.h math.h stdarg.h stdbool.h; do mv ~/usr/local/include/$h ~/tmp/musl_backup/ 2>/dev/null; done && for d in bits sys netinet net linux arpa; do mv ~/usr/local/include/$d ~/tmp/musl_backup/ 2>/dev/null; done
```

# E037: shebang-fix

- **类别**: compat, portability, filesystem, shell

- **来源 PR**: source_commit:

## 错误特征
```
/usr/bin/env.*bad interpreter.*No such file|
                         /usr/bin/env.*No such file or directory|shebang.*env.*fail
```

## 根因分析
鸿蒙系统没有 /usr/bin/env, 使用 #!/usr/bin/env xxx shebang 的脚本无法执行。
                         同时, 硬编码解释器绝对路径(如 #!/data/service/hnp/bin/perl) 导致不可移植。

## 推荐方案
**方法**: shebang-fix

**说明**: 分两步处理:
                         1) 先检查目标系统是否存在 /usr/bin/env, 若存在则用 #!/bin/env xxx (可移植优先)
                         2) 若不存在(如鸿蒙), 则降级为直接 shebang: #!/bin/sh, #!/bin/bash, #!/usr/bin/perl 等
                         对于已安装的包, 批量 sed 替换修复

**验证/命令**:
```
# 检测并批量修复
                         if [ ! -e /usr/bin/env ]; then
                           find $PREFIX -type f -exec sed -i 's|#!/usr/bin/env \([^ ]*\)|#!/\1|g' {} +
                         fi
```

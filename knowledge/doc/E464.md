# E464: MyGUI Dummy 后端资源注册缺失与 DataStream read EOF 契约导致无头测试自旋（SIGKILL Error 137）

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, build-system, testing, graphics
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !7092

## 错误特征
```
MyGUI_Core\.xml not found|addResourceLocation|DummyDataManager|getDataPath|DataStream::read|min\(size\(\), _count\)|Error 137 while executing|Signal 9
```

## 根因分析
MyGUI Dummy 渲染后端（MYGUI_RENDERSYSTEM=1）的 addResourceLocation 为空实现、
  DummyDataManager 五个 DataManager 虚接口全空返回，导致无头环境下 ResourceManager 无法解析
  MyGUI_Core.xml 等资源；且 DataStream::read() 返回 min(size(),_count) 而非实际读取字节
  （忽略 gcount），EOF 后仍返回非 0，标准 read-until-0 消费循环在 EOF 后无限自旋（CPU 忙循环），
  进程被调度层 SIGKILL（Conan Error 137）

## 推荐方案
**方法**: mygui-dummy-resource-registration-headless

**说明**: 镜像 OpenGL/OpenGLES 契约实现 DummyDataManager addResourceLocation/getData/getDataPath/isDataExist/getDataListNames（scanFolder 递归），BaseManager 接线；测试 T3 按 st->size() 一次读取适配 DataStream::read() 契约，T4 递归 mask 用 basename

**验证/命令**:
```
patch 0002-dummy-resource-registration.patch（3 文件）+ test_headless T3/T4 修正；经 ohpc_compile_worker finish 重建后 conan create 内 test() 运行
```

# E424: Conan application/CLI 工具包即使版本目录完整，也必须在软件级目录提供 commands.json

## 基本信息
- **严重度**: 3
- **类别**: conan, cli-tool, metadata
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6613

## 错误特征
```
L0k: CLI tool detected but commands.json missing|commands_json_r38|package_type.*application|bindirs
```

## 根因分析
CI 的 L0k 会通过 package_type="application"、bindirs 或 bin 安装逻辑识别 CLI 工具包，并要求 archives/<letter>/<name>/commands.json 存在且 type=tool、name 包含包名、versions 包含当前版本。pico-sdk 构建 bin/pioasm，因此缺 commands.json 会在构建前失败。

## 推荐方案
**方法**: add-software-level-commands-json

**说明**: 在 archives/p/pico-sdk/commands.json 声明 name=pico-sdk、type=tool、versions[2.2.0].ref=pico-sdk/2.2.0；保持在软件级目录而不是版本目录。

**验证/命令**:
```
cp templates/commands.json.template archives/p/pico-sdk/commands.json
```

# E159: cmake-cache-preset

## 基本信息
- **严重度**: 3
- **类别**: cmake-cross-compile
- **触发工具**: cmake
- **阶段**: configuration

## 错误特征
```
CMake Error: TRY_RUN\\(.*\\) failed to compile|cannot run test executables on this platform|The test executable was not built|TRY_RUN not supported in cross-compiling mode
```

**关键词**: TRY_RUN, cross-compiling, cmake, configuration, cache file

## 根因分析
CMake 检测到交叉编译模式(CMAKE_SYSTEM_NAME != host)时，TRY_RUN() 宏会尝试编译并运行测试程序，但目标平台二进制无法在宿主机执行

**影响范围**: 使用 CMake 构建且检测为交叉编译的所有软件，特别是 OHOS/musl 平台

## 推荐方案
- **方法**: cmake-cache-preset
- **描述**: 创建 TryRunResults-<platform>.cmake 缓存文件，预先设置所有 TRY_RUN 变量的结果值，避免实际执行测试程序
- **命令**: `cmake -C TryRunResults-ohos.cmake -DCMAKE_SYSTEM_NAME=Linux ..`
- **自动修复**: false

## 验证
```bash
grep -r "TRY_RUN" CMakeLists.txt && cmake --system-information | grep CMAKE_SYSTEM_NAME
```

# E062: FLEXIBLE_ARRAY_MEMBER 未定义

> **结构化数据**: [graph/E062.kv](../graph/E062.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: gnulib/c99/compat/headers | **自动修复**: ✅ set-env-var

---

## 错误特征

```
lib/dfa.h:42:13: error: use of undeclared identifier 'FLEXIBLE_ARRAY_MEMBER'
```

## 根因

C99 的灵活数组成员（Flexible Array Member）在某些平台上需要宏定义。gnulib 的 `flexmember.h` 提供可移植实现，但如果头文件包含顺序错误或 gnulib 检测失败（通常是 **E064 conftest 失败**的二级后果），该宏未被定义。

## 解决方案

```bash
# 方案 1（推荐）：让 configure 正确检测
export gl_cv_flexmember=yes

# 方案 2：在受影响的 .c 文件顶部添加
#if !defined(FLEXIBLE_ARRAY_MEMBER)
#if __STDC_VERSION__ >= 199901L
#define FLEXIBLE_ARRAY_MEMBER // C99: 空（FAM 直接用 []）
#else
#define FLEXIBLE_ARRAY_MEMBER 1  // C89: 大小为 1
#endif
#endif
```

## 涉及软件

sed 4.9（lib/dfa.h）、其他使用 gnulib FAM 的软件。

# E375: Select Windows positively and unknown systems by concrete POSIX capability

## 基本信息
- **严重度**: 3
- **类别**: platform, portability, cmake, selection
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5392

## 错误特征
```
ProcessWin32\.c.*windows\.h|tif_win32\.c.*windows\.h
```

## 根因分析
Treating the absence of CMake UNIX as proof of Windows misclassifies unknown target systems and selects Windows-only sources without proving their API contract.

## 推荐方案
**方法**: positive-win32-and-posix-capability-selection

**说明**: Reserve Windows sources for WIN32; otherwise accept UNIX or a narrow compile-and-link probe for the exact POSIX API set; fail configuration when neither contract is proven.

**验证/命令**:
```
Replace if(NOT UNIX) with WIN32 plus an exact POSIX compile-link capability probe and a fatal fallback.
```

NOT UNIX, WIN32, ProcessWin32.c, ProcessUNIX.c, tif_win32.c, tif_unix.c, capability probe

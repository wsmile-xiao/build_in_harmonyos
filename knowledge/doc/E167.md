## 错误特征
```
config.status.*can't create.*subs1.awk|Permission denied.*conf.*subs1.awk
```

## 根因分析
autotools 生成的 config.status 脚本在 HarmonyOS 环境下尝试在当前目录动态创建临时目录（如 ./confXXXXXX），但由于某些系统限制（可能是 HMDFS 文件系统权限问题或 shell 管道操作限制），脚本无法在动态创建的临时目录中写入文件（如 subs1.awk）。

## 推荐方案
**方法**: patch-script

**说明**: 修改 config.status 脚本，将 `ac_tmp=$tmp` 改为使用固定的临时目录路径（如 ./fixed_tmp_for_config_status），并在运行前手动创建该目录。这是因为动态创建的临时目录在某些 HarmonyOS 环境下可能无法正常写入文件。

**验证/命令**:
```
sed -i 's|ac_tmp=$tmp|ac_tmp=./fixed_tmp_for_config_status|g' config.status && mkdir -p ./fixed_tmp_for_config_status
```

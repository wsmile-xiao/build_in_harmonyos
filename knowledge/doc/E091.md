# E091: define-guard

## 基本信息
- **严重度**: 2
- **类别**: kernel, headers
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
redefinition of 'sockaddr_storage'|linux/socket.h.*redef|sys/socket.h.*previous definition|conflicting types.*sockaddr_storage
```

## 根因分析
OHOS 内核头文件 linux/socket.h 定义了 struct sockaddr_storage，
                        与 musl libc 的 sys/socket.h 冲突。
                        当源码同时包含 sys/socket.h（通过系统头文件链）和
                        linux/netlink.h（间接包含 linux/socket.h）时产生重定义错误。
                        这是 OHOS 内核头文件与 musl libc 的不一致。

## 推荐方案
**方法**: define-guard

**说明**: 在 #include <linux/netlink.h> 前用 #define 将 sockaddr_storage
                        重命名为 __linux_sockaddr_storage，include 后 #undef 恢复。
                        用 #ifdef __OHOS__ 守卫，不影响其他平台。

**验证/命令**:
```
|
                        #ifdef HAVE_LINUX_NETLINK_H
                        #ifdef __OHOS__
                        #define sockaddr_storage __linux_sockaddr_storage
                        #endif
                        #include <linux/netlink.h>
                        #include <linux/rtnetlink.h>
                        #ifdef __OHOS__
                        #undef sockaddr_storage
                        #endif
                        #endif
```

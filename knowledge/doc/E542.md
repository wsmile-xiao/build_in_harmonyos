# E542: "Qt 子模块无独立源码：provider 配方复用已发布父模块制品（Qt6LinguistTools 案例）"

## 基本信息
- **严重度**: 2
- **类别**: conan, dependency-graph, provider, qt-module
- **作者**: unknown

## 错误特征
```
>
  Could NOT find Qt6LinguistTools|Could not find a package configuration file
  provided by "Qt6LinguistTools"|Qt6LinguistToolsConfig\.cmake.*does NOT exist|
  requires Qt6LinguistTools \(not published
```

## 根因分析
>
  Qt6LinguistTools 在 Qt 6 中不是独立源码模块：其实体（lrelease/lupdate/
  lconvert/lcheck/ltext2id 等工具 + Qt6LinguistToolsConfig.cmake /
  Qt6::LinguistTools 宏模块）由 qttools 构建产生。消费者（如 KDE kdnssd 的
  ECM ECMPoQmTools.cmake:155）执行 find_package(Qt6 COMPONENTS LinguistTools)
  依赖 Qt6LinguistToolsConfig.cmake；此前 ohpcd 未发布任何提供该配置的包，
  KDE 库（karchive/kauth/kbookmarks/kcodecs/kcompletion 等）只能把
  ecm_install_po_files_as_qm(poqm) 注释掉（"requires Qt6LinguistTools (not
  published to ohpcd)"）。若按常规方式为 Qt6LinguistTools 重新下载编译
  qttools 全部源码，会重复已发布的 qttools/6.11.1.1 制品且违反 R36 先例。

## 推荐方案
**方法**: >
  provider 配方复用已发布父模块制品：conanfile.py name=qt6linguisttools
  （slug 全小写 L0m-5），requires(qttools, qtbase)，build() 仅
  apply_conandata_patches，package() 从 qttools 依赖包复制
  lib/cmake/Qt6LinguistTools/* 与 bin/{lrelease,lupdate,lconvert,lcheck,
  ltext2id}，package_info 暴露 linguisttools 组件（Qt6::LinguistTools）+
  env_info.PATH。

**说明**: >
  通用模式：独立归档库实为已发布父模块子组件时——(1) conan download
  --only-recipe 核验父模块制品含目标 CMake 组件；(2) provider 配方复用，
  禁止重新下载父模块源码编译（R36）；(3) 归档目录名=conan slug 全小写。

# E313: Ruby C 扩展 gem（msgpack/json/pycall）在 OHOS musl libc 缺 C23 stdckdint.h 与 /usr/bin/install 的解决方案

## 基本信息
- **严重度**: 3
- **类别**: musl, headers

## 错误特征
```
stdckdint.h|msgpack|extconf|ruby/internal/stdckdint.h|C23|/usr/bin/install
```

## 根因分析
① OHOS musl libc 缺少 C23 头文件 stdckdint.h，msgpack/json/pycall 等 C 扩展 gem extconf 编译 ruby/internal/stdckdint.h 时失败；② gem make install 阶段 Makefile 硬编码 /usr/bin/install（OHOS 无此路径，仅有 /system/bin/install）。

## 推荐方案
**方法**: stdckdint-shim-plus-install-override

**说明**: ① 创建 C23 兼容 stdckdint.h（基于 __builtin_*_overflow 实现 ckd_add/ckd_sub/ckd_mul）放入用户可写 include 目录，gem 编译传 --with-cflags 或 CFLAGS 补头；② make install 阶段用 INSTALL="/system/bin/install -c" 覆盖 Makefile 的 /usr/bin/install；③ 手动完成 .so 复制 + gem.build_complete + specifications 注册。

**验证/命令**:
```
CFLAGS="-I/storage/Users/currentUser/usr/local/include" gem install msgpack -- --with-cflags=...; make DESTDIR= sitearchdir=./.gem.install sitelibdir=./.gem.install install INSTALL="/system/bin/install -c"
```

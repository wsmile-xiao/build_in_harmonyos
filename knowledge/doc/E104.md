# E104: libolm Makefile 缺少 version_script.ver

**分类**: L3 软件特化（libolm）
**严重性**: 🔴 阻塞
**影响软件**: libolm (olm 3.2.16)

## 问题现象

```
ld.lld: error: cannot find version script version_script.ver
```

## 根因分析

libolm 的 Makefile 构建依赖 `version_script.ver` 控制符号导出。PyPI 的 python-olm 包含 libolm 子目录源码但**不包含**此文件。

## 解决方案

手动创建 version_script.ver：

```bash
cat > version_script.ver << 'EOF'
{
    global:
        olm_*;
        _olm_*;
    local:
        *;
};
EOF
```

然后继续 `make`。

## 注意事项

- **libolm 已于 2024-07-31 官方弃用**，建议考虑 vodozemac (Rust) 等替代方案
- 如需编译，从 PyPI python-olm 获取源码或从 GitLab 获取完整源码

# E104: create-version-script

## 基本信息
- **严重度**: 3
- **类别**: build-system, linking, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
ld\.lld: error: cannot find version script.*version_script\.ver|cannot open version script file
```

## 根因分析
libolm 的 Makefile 构建依赖 version_script.ver 文件来控制符号导出。PyPI 的 python-olm 包含 libolm 子目录源码但不包含此文件，导致链接失败

## 推荐方案
**方法**: create-version-script

**说明**: 手动创建 version_script.ver 文件，定义 olm_* 和 _olm_* 为导出符号

**验证/命令**:
```
cat > version_script.ver << 'EOF'\n{\n    global:\n        olm_*;\n        _olm_*;\n    local:\n        *;\n};\nEOF
```

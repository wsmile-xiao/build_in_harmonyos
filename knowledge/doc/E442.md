# E442: Preserve the host ABI contract when packaging a host-loaded plugin independently

## 基本信息
- **严重度**: 2
- **类别**: linking, packaging, plugins, runtime-contract
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6462

## 错误特征
```
-no-undefined.*plugin|undefined reference.*host|cannot find.*host.*library|plugin.*dlopen.*undefined
```

## 根因分析
An upstream plugin target is normally linked inside the full host application build, so its build rules require the in-tree host library and reject unresolved symbols. A standalone package that builds only the plugin has no such host library, while the real runtime contract expects the host process to resolve those symbols when loading the module.

## 推荐方案
**方法**: model-host-as-runtime-contract

**说明**: Build only the plugin target, remove the fully-resolved-link policy only for that module, omit unavailable in-tree host linkage, and document the exact host ABI/version expected at load time.

**验证/命令**:
```
readelf -h plugin.so && readelf --dyn-syms -W plugin.so
```

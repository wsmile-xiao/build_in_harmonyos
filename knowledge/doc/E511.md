# E511: HarmonyOS 上 Meson 版本化共享库软链接缺失

## 基本信息
- **严重度**: 3
- **类别**: hmdfs, ohos, meson, packaging, symlink
- **作者**: asp1r1n1 <912802346@qq.com>
- **来源 PR**: !3016

## 错误特征
```
cannot find -l[^ ]+|lib[^ ]+\.so(\.[0-9]+)? not found|No such file or directory.*\.so|failed to load.*\.so
```

## 根因分析
Meson 以 libfoo.so.X.Y.Z 实体和 libfoo.so.X、libfoo.so 软链接发布共享库；HarmonyOS 目标文件系统可能拒绝创建或读取这些软链接，导致上游测试、链接器或运行时只看到版本化实体而无法按 ABI 或开发者库名解析。

## 推荐方案
**方法**: materialize-versioned-so-aliases

**说明**: 仅在 OHOS 上，于 meson.build() 后、meson.test() 前扫描实际 Meson 输出目录，并于 meson.install() 后扫描 package_folder/lib；对真实 libfoo.so.X.Y.Z 缺失时复制为 libfoo.so.X 与 libfoo.so，跳过 *.so.*.p 对象目录且不覆盖已有文件。

**验证/命令**:
```
for each actual libfoo.so.X.Y.Z in build output and package lib: copy it to libfoo.so.X and libfoo.so only when those paths are absent
```

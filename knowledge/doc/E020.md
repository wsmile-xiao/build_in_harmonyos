# E020: musl FILE 结构差异

> **结构化数据**: [graph/E020.kv](../graph/E020.kv) | **原则**: P-PATCH-001
> **严重度**: 🟡 medium | **分类**: libc/compat | **自动修复**: ❌ 需源码补丁

---

## 错误特征

```
error: incomplete definition of type 'struct _IO_FILE'
error: '_IO_read_ptr' undeclared
error: '_IO_write_ptr' undeclared
```

## 根因

musl 的 `FILE` 是**不透明类型**，内部字段不可直接访问；glibc 允许直接访问 `_IO_read_ptr` 等内部字段。

| 系统 | FILE 结构 |
|------|-----------|
| glibc | 可访问 `_IO_read_ptr` / `_IO_write_ptr` 等字段 |
| musl | **不透明类型**，内部结构不可访问 |

## 解决方案

添加条件编译分支，用公开 API 替代内部字段访问：

```c
#if defined(__OHOS__) || (defined(__linux__) && !defined(__GLIBC__))
  // musl 兼容代码：使用公开 API
  return 0;  // 安全回退
#else
  // glibc 原始代码：访问 _IO_read_ptr 等字段
#endif
```

**参考实现**：`archives/c/coreutils/9.10/`

## 禁止策略

❌ **禁止强制转换绕过**：
```c
// ❌ 错误做法
struct _IO_FILE *f = (struct _IO_FILE *)fp;
f->_IO_read_ptr;  // 段错误风险
```
原因：musl 内部结构可能随版本变化，强转导致段错误或数据损坏。

## 涉及软件

coreutils、bash、任何直接操作 FILE 内部字段的 C 项目。

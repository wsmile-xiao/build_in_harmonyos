## 根因分析
musl 的 FILE 结构是不透明类型,
                         内部字段(_IO_read_ptr/_IO_write_ptr等)不可访问;
                         glibc 允许直接访问这些内部字段

## 推荐方案
**方法**: source-patch

**说明**: 添加 #ifdef __OHOS__ 或 !__GLIBC__ 条件编译分支,
                         用公开 API 替代内部字段访问

**验证/命令**:
```
rec_auto_fix:          false
```

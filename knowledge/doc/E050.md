# E050: copy-replace-symlink

## 基本信息
- **严重度**: 3
- **类别**: hmdfs, linking, runtime, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
unable to find library.*-l|ld\.lld.*error.*library|
                         cannot open shared object|symbol link.*not found
```

## 根因分析
HMDFS 文件系统不正常跟踪符号链接。
                         os.path.exists() 对符号链接返回 False,
                         动态链接器(ld.lld)通过符号链接搜索库文件时也无法找到目标

## 推荐方案
**方法**: copy-replace-symlink

**说明**: 用文件副本(cp)替代符号链接(ln):
                         rm libpython3.9.so && cp libpython3.9.so.1.0 libpython3.9.so
                         对于 make install, 将 \$(LN_FORCE) 改为 \$(HARDLINK)(鸿蒙上为 cp -p)

**验证/命令**:
```
rm /usr/local/lib/libpython3.9.so;
                         cp /usr/local/lib/libpython3.9.so.1.0 /usr/local/lib/libpython3.9.so
```

# E235: Select an OHOS-compatible OpenSSL entropy source

## 基本信息
- **严重度**: 3
- **类别**: ohos, libc, toolchain, security
- **作者**: 2301_79503900 <3308319887@qq.com>
- **来源 PR**: 3047

## 错误特征
```
undefined symbol: __fd_chk|libdefault-lib-rand_unix.o.*__fd_chk|rand_unix.c.*__fd_chk
```

## 根因分析
OpenSSL's default OS random seeding enables both getrandom and a DEVRANDOM_WAIT fallback.
                        The fallback compiles FD_SET in rand_unix.c; the OHOS SDK lowers that operation to the
                        private fortified helper __fd_chk, but the target SDK libraries do not export the helper.
                        A shallow consumer that never calls RAND_bytes can leave rand_unix.o unlinked and miss the defect.

## 推荐方案
**方法**: select-supported-getrandom-seed

**说明**: Configure OpenSSL with --with-rand-seed=getrandom so the supported kernel entropy syscall
                        remains enabled while the unsupported DEVRANDOM_WAIT and FD_SET fallback is excluded.
                        Verify the result through a RAND_bytes consumer.

**验证/命令**:
```
perl ./Configure linux-aarch64 --with-rand-seed=getrandom no-asm no-shared -fPIC; make build_sw build_tests
```

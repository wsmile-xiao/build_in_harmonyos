# E199: source-patch

## 基本信息
- **严重度**: 1
- **类别**: c++|macro|compiler-warning
- **触发工具**: clang|make
- **阶段**: compilation

## 错误特征
```
expected.*';'.*after|missing.*';'.*U16_NEXT|U16_NEXT.*expected
```

**关键词**: U16_NEXT, expected semicolon, missing semicolon, ICU macro, unicode

## 根因分析
U16_NEXT 是 ICU 库的多行宏，在某些使用场景中宏调用后未加分号，导致编译器报缺少分号错误

**影响范围**: 使用 ICU/unicode U16_NEXT 宏的 C/C++ 项目（如 libfreehand, libcdr 等 LibreOffice 系列）

## 推荐方案
- **方法**: source-patch
- **描述**: 在 U16_NEXT 宏调用后补充分号
- **命令**: `sed -i '/U16_NEXT/s/$/;/' src/lib/libfreehand_utils.cpp`
- **自动修复**: true

## 验证
```bash
grep -n "U16_NEXT" src/lib/libfreehand_utils.cpp
```

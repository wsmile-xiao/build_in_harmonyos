# E199: source-patch

## 基本信息
- **严重度**: 1
- **类别**: c++, warnings, runtime
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
expected.*';'.*after|missing.*';'.*U16_NEXT|U16_NEXT.*expected
```

## 根因分析
U16_NEXT 是 ICU 库的多行宏，在某些使用场景中宏调用后未加分号，导致编译器报缺少分号错误

## 推荐方案
**方法**: source-patch

**说明**: 在 U16_NEXT 宏调用后补充分号

**验证/命令**:
```
sed -i '/U16_NEXT/s/$/;/' src/lib/libfreehand_utils.cpp
```

## 关键词
U16_NEXT, expected semicolon, missing semicolon, ICU macro, unicode

# E348: forwarding-pc-in-generate

## 基本信息
- **严重度**: 2
- **类别**: build-system, dependency, pkg-config, glib2
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: !5288

## 错误特征
```
Run-time dependency gobject-2\.0 found: NO|
                    dependency.*gobject-2\.0.*not found|
                    pkg-config.*gobject-2\.0.*not found in pkg-config search path|
                    No package 'gobject-2\.0' found
```

## 根因分析
Conan 2 的 PkgConfigDeps 按依赖包 cpp_info 组件的 pkg_config_name
                    逐一生成 .pc；本仓 glib2 配方（archives/g/glib2/2.88.0）只声明
                    根组件一个 pkg_config_name="glib-2.0"，故只生成 glib-2.0.pc。
                    而 GNOME/GLib 家族上游是 .pc **多文件体系**（glib-2.0 /
                    gobject-2.0 / gio-2.0 … 各一个 .pc）。
                    消费方 meson.build 用 dependency('gobject-2.0') 检测时，
                    pkg-config 在 generators 目录搜不到 gobject-2.0.pc → 检测失败
                    （graphene 1.10.8 的 graphene-gobject 类型需要 gobject）。
                    这是 conan PkgConfigDeps 的"每包单 .pc 输出"与上游多 .pc
                    体系的通用落差，不是单一库的问题。

## 推荐方案
**方法**: forwarding-pc-in-generate

**说明**: 在**消费方配方**的 generate() 里，PkgConfigDeps.generate() 之后
                    补写一个转发型 <副>.pc（如 gobject-2.0.pc）到
                    self.generators_folder：Version 从主 .pc（glib-2.0.pc）的
                    Version 行**动态继承**（不写死）；Requires: <主.pc>（路径/Cflags
                    /Libs 全部由被转发的 glib-2.0.pc 提供，转发型 .pc 不写 prefix）。
                    前提：依赖声明用 transitive_headers=True, transitive_libs=True
                    让 glib 头/库透传给下游。这是 pango 1.56.4 配方
                    【skill: --alias-pc 生成】（cairo-ft=cairo,freetype2 /
                    cairo-fc=cairo,fontconfig）的同款手法。

**验证/命令**:
```
|
  # graphene 1.10.8 配方 generate() 实例（archives/g/graphene/1.10.8/conanfile.py）
  # def generate(self):
  #     PkgConfigDeps(self).generate()
  #     self._forward_gobject_pc()
  def _forward_gobject_pc(self):
      _src = os.path.join(self.generators_folder, "glib-2.0.pc")
      if not os.path.isfile(_src):
          self.output.warning("gobject-2.0 forward: glib-2.0.pc not generated, skip")
          return
      _ver = "0"
      with open(_src, encoding="utf-8") as _f:
          for _line in _f:
              if _line.startswith("Version:"):
                  _ver = _line.split(":", 1)[1].strip()
                  break
      _dst = os.path.join(self.generators_folder, "gobject-2.0.pc")
      if os.path.isfile(_dst):
          return
      with open(_dst, "w", encoding="utf-8") as _f:
          _f.write(
              "Name: gobject-2.0\n"
              "Description: forwarding .pc generated by graphene recipe (Requires glib-2.0)\n"
              "Version: %s\n"
              "Requires: glib-2.0\n" % _ver
          )
  # 依赖声明：self.requires("glib2/2.88.0", transitive_headers=True, transitive_libs=True)
```

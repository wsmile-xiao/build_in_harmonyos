# E295: sign-elf 缺失导致 ELF 证据降级为 probe-only（无法证明鸿蒙签名门禁满足）

## 基本信息
- **严重度**: 2
- **类别**: toolchain
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: source_commit:

## 错误特征
```
command -v sign-elf|sign-elf:.*not found|sign-elf:.*inaccessible|探针 ELF.*未完成可交付签名门禁|codesign.*签名段
```

## 根因分析
执行环境没有 sign-elf（command -v sign-elf 无输出），未安装也未伪造签名工具；鸿蒙 ELF 需含有效 .codesign 签名段才能被内核加载（E077），缺少签名工具时编译、上游测试、Conan test_package、Null/loopback 运行结果只能作为探针证据，不能证明可交付 ELF 已满足鸿蒙签名门禁

## 推荐方案
**方法**: record-sign-elf-missing-probe-only

**说明**: 记录 sign-elf 缺失状态：编译/测试/运行结果仅作探针证据；允许做静态检查（readelf/检查 .codesign 段存在性）但不得宣称交付门禁完成；恢复条件为官方执行环境提供 sign-elf 或框架认可的等价工具后重新签名并重跑相关测试、打包和门禁

**验证/命令**:
```
command -v sign-elf && echo PRESENT || echo MISSING; readelf -S libopenal.so | grep -i codesign || echo "无 .codesign 段（未签名）"
```

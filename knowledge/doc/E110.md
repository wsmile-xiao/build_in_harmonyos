# E110: use_alternate_build_dir

## 基本信息
- **严重度**: 3
- **类别**: platform, limitation
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
config.status: can't create ./confXXXXXX/subs1.awk: Permission denied|could not setup config files machinery
```

## 根因分析
HMDFS (HarmonyOS Distributed File System) restricts temporary file creation in source directories. Autoconf config.status script needs to create temp directories like ./confXXXXXX in the source tree, which fails due to HMDFS permission restrictions.

## 推荐方案
**方法**: use_alternate_build_dir

**说明**: Use VPATH build (build outside source tree) or compile in non-HMDFS location

**验证/命令**:
```
mkdir -p ~/tmp/build && cd ~/tmp/build && ../source/configure --prefix=$DEFAULT_PREFIX
```

## 关键词
HMDFS, config.status, Permission denied, confXXXXXX, temp file, autotools

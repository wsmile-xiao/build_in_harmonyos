# E110: use_alternate_build_dir

## 基本信息
- **严重度**: 3
- **类别**: platform_limitation
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
config.status: can't create ./confXXXXXX/subs1.awk: Permission denied|could not setup config files machinery
```

**关键词**: HMDFS, config.status, Permission denied, confXXXXXX, temp file, autotools

## 根因分析
HMDFS (HarmonyOS Distributed File System) restricts temporary file creation in source directories. Autoconf config.status script needs to create temp directories like ./confXXXXXX in the source tree, which fails due to HMDFS permission restrictions.

**影响范围**: All autotools-based software (cannot compile on HMDFS without workaround)

## 推荐方案
- **方法**: use_alternate_build_dir
- **描述**: Use VPATH build (build outside source tree) or compile in non-HMDFS location
- **命令**: `mkdir -p ~/tmp/build && cd ~/tmp/build && ../source/configure --prefix=$DEFAULT_PREFIX`
- **自动修复**: false

## 验证
```bash
cd $HOME/tmp && echo 'AC_INIT([test],[1.0]) AM_INIT_AUTOMAKE AC_CONFIG_FILES([Makefile]) AC_OUTPUT' > configure.ac && autoreconf -i && ./configure 2>&1 | grep -i permission || echo "configure works"
```

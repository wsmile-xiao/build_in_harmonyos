# E017: GitHub 下载慢/超时

> **结构化数据**: [graph/E017.kv](../graph/E017.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: network | **自动修复**: ✅ url-rewrite (ghfast/mirror)

---

## 错误特征

```
wget: connect: Operation timed out
curl: (28) Connection timed out
github.com: could not resolve host
```

## 根因

GitHub 在中国大陆网络环境下访问不稳定，DNS 解析慢或连接超时。

## 解决方案（按优先级排序）

### 1. ghfast.top 加速链接（推荐）

```bash
# 原始 URL
wget https://github.com/openssl/openssl/releases/download/openssl-3.3.0/openssl-3.3.0.tar.gz

# 加速 URL
wget https://ghfast.top/https://github.com/openssl/openssl/releases/download/openssl-3.3.0/openssl-3.3.0.tar.gz
```

### 2. 国内镜像源

| 镜像 | 地址 | 说明 |
|------|------|------|
| 清华源 | `mirrors.tuna.tsinghua.edu.cn` | 高校镜像 |
| 阿里源 | `mirrors.aliyun.com` | 云厂商镜像 |
| 华为源 | `repo.huaweicloud.com` | 云厂商镜像 |
| gitcode | `gitcode.com` | 搜索对应项目镜像 |

> ⚠️ gitcode 不是固定组织路径，需在 gitcode 上搜索具体项目。

### 3. 代理（回退）

```bash
export https_proxy=http://proxy:port
export http_proxy=http://proxy:port
```

## 禁止策略

❌ **禁止下载开发分支**：不得使用 master/main/develop 分支的源码包，必须使用 release 版本。

- ❌ `https://github.com/xxx/archive/master.tar.gz`
- ✅ `https://github.com/xxx/releases/download/v1.2.3/xxx-1.2.3.tar.gz`

## 涉及软件

所有需要从 GitHub 下载源码的构建过程。

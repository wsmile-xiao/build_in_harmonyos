# E405: OHOS 下 python subprocess 裸名命令不搜索 PATH（_IS_HARMONYOS 强制 posix_spawn → Errno 2）

## 基本信息
- **严重度**: 2
- **类别**: python, shell, integration, path
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: !5959

## 错误特征
```
FileNotFoundError: [Errno 2] No such file or directory: '<bare-name>'|
                    subprocess.*posix_spawn|_USE_POSIX_SPAWN|_IS_HARMONYOS
```

## 根因分析
HarmonyOS 的 python3 subprocess.py 通过 _IS_HARMONYOS 强制裸名
                    命令也走 os.posix_spawn()，而 posix_spawn 不做 PATH 搜索（非
                    posix_spawnp），裸名可执行文件直接抛 FileNotFoundError Errno 2。

## 推荐方案
**方法**: use-absolute-path-or-shell-or-which

**说明**: 裸名命令改用绝对路径、shell=True，或先 shutil.which() 解析；测试兼容沿用 E055 skip-test。

**验证/命令**:
```
subprocess.run(['/usr/bin/curl','--version']); subprocess.run('curl --version', shell=True); subprocess.run([shutil.which('curl'),'--version'])
```

# E472: Sign and headless-run Conan test_package executable tests on OHOS (SDL dummy drivers + self.run for L0d gate)

## 基本信息
- **严重度**: 3
- **类别**: ohos, cmake, conan, testing, elfsign
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !7114

## 错误特征
```
test_package .* Error in test\(\) method|self\.run.*失败|stub_test_method|SDL_.*Driver.*init|binary not found|codesign
```

## 根因分析
SDL_kitchensink 1.0.13 的 test_package 生成可执行测试 test_sdl_kitchensink（调用 Kit_GetVersion/Kit_GetSDLAudioFormatString/Kit_Init/Kit_Quit）。在 OHOS aarch64 + Conan 2 下：(1) OHOS 要求 ELF 代码签名（binary-sign-tool sign -selfSign 1）后才可加载执行，未签名则测试无法运行； (2) 测试调用 SDL 初始化，CI/无显示无声卡环境需显式 SDL_VIDEODRIVER=dummy / SDL_AUDIODRIVER=dummy 走 stub 后端； (3) CI L0d 门禁要求 test() 内含 self.run() 实际执行逻辑，否则判 stub_test_method 空壳拦截； (4) 测试若用 AUDIO_S16LSB 等 SDL 宏需显式 #include <SDL_audio.h>，且 sdl2 头在 include/SDL2/ 需由配方 cpp_info.includedirs 透传。

## 推荐方案
**方法**: sign-elf-and-sdl-dummy-headless-test

**说明**: test_package/conanfile.py 的 build() 内用 llvm-objcopy --remove-section .codesign（容忍失败）+ binary-sign-tool sign -selfSign 1 对测试 ELF 签名并移回、chmod 755；test() 内 os.environ 设 SDL_VIDEODRIVER=dummy / SDL_AUDIODRIVER=dummy，然后 self.run("'<bin>'", env="conanrun") 实际执行签名后二进制（真实调用库 API 做版本/格式字符串/初始化断言）；测试源显式 #include <SDL_audio.h>（用 AUDIO_S16LSB 等宏时），SDL include 路径由配方 cpp_info.includedirs 追加 sdl2 的 include/SDL2 透传（sdl2_image 先例）。

**验证/命令**:
```
|
  def build(self):
      cmake = CMake(self); cmake.configure(); cmake.build()
      self._sign_elf(os.path.join(self.cpp.build.bindirs[0], "test_sdl_kitchensink"))
  def _sign_elf(self, path):
      self.run('{oc} --remove-section .codesign "{f}" 2>/dev/null'.format(oc="/data/service/hnp/bin/llvm-objcopy", f=path), ignore_errors=True)
      tmp = path + ".signed"
      self.run('{sg} sign -inFile "{f}" -outFile "{t}" -selfSign 1'.format(sg="/data/service/hnp/bin/binary-sign-tool", f=path, t=tmp))
      if os.path.exists(tmp):
          shutil.move(tmp, path)
      os.chmod(path, 0o755)
  def test(self):
      os.environ["SDL_VIDEODRIVER"] = "dummy"
      os.environ["SDL_AUDIODRIVER"] = "dummy"
      self.run(f"'{os.path.join(self.cpp.build.bindirs[0], 'test_sdl_kitchensink')}'", env="conanrun")
```

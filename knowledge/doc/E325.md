# E325: Conan test_package 在 OHOS 上应先解析可用 shell 再跑脚本

## 基本信息
- **严重度**: 2
- **类别**: portability, testing, shell, tmpdir
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !7151

## 错误特征
```
sh: bash: inaccessible or not found|Read-only file system|mktemp:.*Read-only file system
```

## 根因分析
目标机的 OHOS shell 环境可能没有把 bash 放进默认 PATH，
                        而 test_package 若直接执行 `bash test.sh` 就会在真正验证前
                        失败；同时 `mktemp` 默认落到 `/tmp`，在只读环境里也会失败。

## 推荐方案
**方法**: shell-discovery-and-writable-tmpdir

**说明**: 先尊重 `CONFIG_SHELL`，再尝试 PATH 中的 bash，最后回退到
                        `/data/service/hnp/bin/bash`；临时文件统一放到 `$HOME/tmp`
                        或 `TMPDIR`，不要依赖 `/tmp` 默认值。

**验证/命令**:
```
TMPDIR=$HOME/tmp CONFIG_SHELL=/data/service/hnp/bin/bash /data/service/hnp/bin/bash test.sh
```

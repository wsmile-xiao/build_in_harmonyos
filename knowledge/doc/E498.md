# E498: Clear Conan's default include directory for a headerless library

## 基本信息
- **严重度**: 3
- **类别**: cmake, conan, packaging, api, headerless-library
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5839

## 错误特征
```
imported target.*non-existent.*include|INTERFACE_INCLUDE_DIRECTORIES.*does not exist|CMakeDeps.*include.*does not exist
```

## 根因分析
Conan defaults cpp_info.includedirs to include even when a package intentionally installs no public headers, so CMakeDeps exports a usage requirement for a directory that does not exist.

## 推荐方案
**方法**: explicit-empty-public-include-contract

**说明**: Set self.cpp_info.includedirs to an empty list while preserving the real public libraries, transitive requirements, target names, and system libraries.

**验证/命令**:
```
Add self.cpp_info.includedirs = [] in package_info() and rerun a CMakeDeps imported-target consumer.
```

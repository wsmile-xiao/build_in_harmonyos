# E369: Identity-bound acquisition and coherent publication for signed execution trees

## 基本信息
- **严重度**: 2
- **类别**: transactional-elf-signing
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5532

## 错误特征
```
signed execution root publication identity|foreign replacement preserved during cleanup|mv -n.*existing directory|signing transaction cleanup incomplete|identity changed during acquisition|signing transaction interrupted by TERM
```

## 根因分析
A global cleanup flag cannot prove ownership of individual paths; create, inode capture, and owner publication can also be interrupted before cleanup authority becomes visible, independent final flags can split root/evidence commit, and mv -n without -T can move pending state inside a foreign directory.

## 推荐方案
**方法**: per-object-identity-bound-no-clobber-publication

**说明**: Hold acquisition objects by FD, defer and replay signals until identity-bound ownership is visible, publish with mv -nT, establish destination ownership before releasing source ownership, and use one committed state so root and evidence are cleaned or preserved as a pair.

**验证/命令**:
```
stat -c '%d:%i' "/proc/$owner_pid/fd/$fd" && mv -nT "$pending" "$final" && test "$(stat -c '%d:%i' "$final")" = "$held_identity"
```

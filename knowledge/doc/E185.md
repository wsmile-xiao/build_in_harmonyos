## 错误特征
```
SSL certificate problem: unable to get local issuer certificate|certificate verify failed|curl: \(60\) SSL certificate problem|wget: ERROR: cannot verify certificate
```

## 根因分析
鸿蒙系统可能缺少 CA 证书包，或证书过期，导致 HTTPS 下载失败。系统未预装 ca-certificates 包，curl/wget/git 等工具无法验证 HTTPS 服务器证书。

## 推荐方案
**方法**: set-env-var

**说明**: 临时方案：使用 curl -k 跳过证书验证，或使用 git clone 替代下载。长期方案：安装 CA 证书包到系统目录。不验证证书存在安全风险，仅用于测试环境。

**验证/命令**:
```
# verify with: conan create . --build=missing
```

# E086 — struct ucred 在 musl/OpenHarmony 上不可用

## 错误特征

```
assuan-socket-server.c: error: invalid use of incomplete type 'struct ucred'
assuan-socket-server.c: error: storage size of 'cred' isn't known
```

## 触发条件

- 构建系统: autotools
- 阶段: compilation
- 平台: OpenHarmony（musl libc）

## 根因分析

glibc 在 `<sys/socket.h>` 中定义了 `struct ucred`（包含 pid_t, uid_t, gid_t），用于 `SO_PEERCRED` 获取 Unix socket 对端凭证。OpenHarmony 使用 musl libc，不提供此结构体定义。

受影响的典型代码模式：
```c
struct ucred cred;
socklen_t len = sizeof(cred);
getsockopt(fd, SOL_SOCKET, SO_PEERCRED, &cred, &len);
```

## 解决方案

### 推荐方案：条件编译 + 内联定义

```c
#ifdef __OHOS__
struct ucred {
    pid_t pid;
    uid_t uid;
    gid_t gid;
};
#endif
```

在需要使用 `struct ucred` 的源文件头部添加上述守卫。

### 回退方案：禁用 peer credential

```bash
./configure --prefix=$DEFAULT_PREFIX --disable-local-socket
```

## 验证

```bash
# 验证编译通过
make -j$(nproc)

# 验证 pkg-config
pkg-config --modversion libassuan
```

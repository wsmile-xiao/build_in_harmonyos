# E086: ohos-guard-ucred

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, musl, socket
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
struct ucred.*incomplete|
                         storage size of.*ucred.*isn't known|
                         invalid use of incomplete type.*ucred|
                         ucred.*undeclared|
                         SOCKCREDSIZE
```

## 根因分析
OpenHarmony 的 musl libc 不定义 `struct ucred`
                         （定义在 Linux glibc 的 <sys/socket.h> 中）。
                         部分软件（如 libassuan）使用 `struct ucred`
                         获取 Unix socket 对端凭证（SO_PEERCRED）。
                         musl 下需条件编译或内联定义 struct ucred。

## 推荐方案
**方法**: ohos-guard-ucred

**说明**: 使用 `#ifdef __OHOS__` 守卫，在 __OHOS__ 下内联定义
                         struct ucred（pid_t, uid_t, gid_t 三个字段），
                         或使用 #ifdef 封装 SO_PEERCRED 相关代码块

**验证/命令**:
```
sed -i '/struct ucred/i #ifdef __OHOS__\nstruct ucred { pid_t pid; uid_t uid; gid_t gid; };\n#endif' src/socket-server.c
```

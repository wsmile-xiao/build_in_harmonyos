# E186: patchelf-fix-runpath

## 基本信息
- **严重度**: 3
- **类别**: toolchain, rust
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
Error loading shared library libz\.so.*needed by.*cargo.*Error relocating.*cargo.*zlibVersion: symbol not found
```

## 根因分析
OHOS musl ldso使用namespace机制解析库路径,LD_LIBRARY_PATH对非标准路径的二进制无效,cargo的RUNPATH($ORIGIN/../lib)中缺少libz.so

## 推荐方案
**方法**: patchelf-fix-runpath

**说明**: 复制cargo到可写目录,用patchelf修改RUNPATH添加用户lib路径,再用sign-elf签名

**验证/命令**:
```
cp ${HNP_CARGO} ~/tmp/cargo-local && patchelf --set-rpath '$ORIGIN/../lib:/storage/Users/currentUser/usr/local/lib' ~/tmp/cargo-local && ohc-run.py sign-elf ~/tmp/cargo-local
```

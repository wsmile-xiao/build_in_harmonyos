# E186: patchelf-fix-runpath

## 基本信息
- **严重度**: 3
- **类别**: rust-toolchain
- **触发工具**: ld
- **阶段**: runtime

## 错误特征
```
Error loading shared library libz\.so.*needed by.*cargo.*Error relocating.*cargo.*zlibVersion: symbol not found
```

**关键词**: cargo, libz.so, Error loading shared library, musl ldso, RUNPATH, patchelf

## 根因分析
OHOS musl ldso使用namespace机制解析库路径,LD_LIBRARY_PATH对非标准路径的二进制无效,cargo的RUNPATH($ORIGIN/../lib)中缺少libz.so

**影响范围**: 所有Rust项目编译（cargo命令本身无法运行）

## 推荐方案
- **方法**: patchelf-fix-runpath
- **描述**: 复制cargo到可写目录,用patchelf修改RUNPATH添加用户lib路径,再用sign-elf签名
- **命令**: `cp ${HNP_CARGO} ~/tmp/cargo-local && patchelf --set-rpath '$ORIGIN/../lib:/storage/Users/currentUser/usr/local/lib' ~/tmp/cargo-local && ohc-run.py sign-elf ~/tmp/cargo-local`
- **自动修复**: false

## 验证
```bash
/storage/Users/currentUser/tmp/cargo --version
```

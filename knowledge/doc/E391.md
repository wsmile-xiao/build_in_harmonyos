# E391: CI L0p 门禁要求 conanfile settings 声明全部四项

## 基本信息
- **严重度**: 2
- **类别**: conanfile, settings
- **作者**: hhyxx1 <f24011422@st.sandau.edu.cn>
- **来源 PR**: !5799

## 错误特征
```
missing_setting_compiler|missing_setting_build_type|L0p: settings 缺少
```

## 根因分析
CI L0p 门禁要求 conanfile.py settings 声明全部四项 os/compiler/build_type/arch，即使 JVM 应用（如 gradle/aladin）仅需 os/arch 也会被拒绝

## 推荐方案
**方法**: conanfile.py settings 声明全部四项 os/compiler/build_type/arch；JVM 应用不受影响（构建时不使用编译器设置）

**说明**: CI L0p 门禁要求 settings 含全部四项，即使 JVM 应用仅需 os/arch 也须声明，参照 gradle 8.12 先例

**验证/命令**:
```
settings = "os", "compiler", "build_type", "arch"
```

# E282: 多源码 Conan 配方必须为每个补丁声明独立 base_path

## 基本信息
- **严重度**: 2
- **类别**: conan, patch, filesystem
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
Failed to apply patch:|Failed to parse patch:|target file not found|can't find file to patch
```

## 根因分析
recipe 把主源码和配套源码下载到 source_folder 的不同子目录，却用单一硬编码补丁根目录处理全部 conandata 条目，导致某些补丁在错误源码树中查找目标文件；Conan 2 的 apply_conandata_patches 会把每条元数据作为 patch() 参数，原生支持逐条 base_path

## 推荐方案
**方法**: conandata-per-patch-base-path

**说明**: 在 conandata.yml 每个 patch 条目声明相对 self.source_folder 的 base_path，并统一调用 apply_conandata_patches(self)；export_conandata_patches 仍负责导出 patch_file

**验证/命令**:
```
python3 -c "import yaml; d=yaml.safe_load(open('conandata.yml')); assert all(p.get('base_path') for p in d['patches'])"
```

# E447: Bridge Conan SDL2 family include/link requirements into vendored FindSDL2* module consumers under OHOS cross-compile

## 基本信息
- **严重度**: 3
- **类别**: cmake, cross-compile, conan, sdl2
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !6719

## 错误特征
```
SDL_audio.h file not found|SDL_gamecontroller.h file not found|undefined symbol: WebPGetFeaturesInternal|undefined symbol: TIFFClientOpen|undefined symbol: pb_decode|No rule to make target .*msg\.pb\.c
```

## 根因分析
cdogs-sdl 1.0.0 ships vendored FindSDL2.cmake / FindSDL2_image.cmake / FindSDL2_mixer.cmake (build/cmake/). 在 OHOS aarch64 交叉编译 + Conan 2 CMakeDeps 下： (1) 若启用 CMAKE_FIND_PACKAGE_PREFER_CONFIG=TRUE，find_package(SDL2) 走 CMakeDeps CONFIG，只定义 sdl2::sdl2 target，不设置 SDL2_INCLUDE_DIRS 变量 → 上游 include_directories(${SDL2_INCLUDE_DIRS}) 为空 → SDL_audio.h/SDL_gamecontroller.h not found； (2) 若关闭 PREFER_CONFIG 保持 MODULE（含 generators=CMakeDeps 时），MODULE 的 find_path/find_library 在交叉编译环境找不到 Conan 包内头文件，或返回裸库路径而不含传递依赖（libwebp/libtiff/zlib）→ 链接期 undefined symbol； (3) 上游自身依赖 nanopb 的 nanopb_generate_cpp 宏（需要 protoc + Python google.protobuf + pkg_resources），交叉环境工具缺失。 全套问题不能靠参数开关/粒度替换解决——需要显式缓存变量桥接。

## 推荐方案
**方法**: conan-recipe cache-variable bridge (E300 扩展)

**说明**: 在 conanfile.py generate() 中遍历 self.dependencies[sdl2/sdl2_image/sdl2_mixer]，将 cpp_info.includedirs（含 include/SDL2 子目录）与 cpp_info.libs 映射为上游 vendored Find 模块期望的缓存变量（SDL2_INCLUDE_DIRS/SDL2_LIBRARY/SDL2_IMAGE_* 等），经 CMakeToolchain cache_variables 注入；库变量直接指向 Conan CMakeDeps imported target（sdl2::sdl2 等）以携带 INTERFACE_LINK_LIBRARIES 传递依赖。不设置 CMAKE_FIND_PACKAGE_PREFER_CONFIG（避免 MODULE→CONFIG 变量丢失回归）。

**验证/命令**:
```
|
  def generate(self):
      tc = CMakeToolchain(self)
      tc.cache_variables["CMAKE_POLICY_VERSION_MINIMUM"] = "3.5"
      for dep, prefix in ((self.dependencies["sdl2"], "SDL2"),
                          (self.dependencies["sdl2_image"], "SDL2_IMAGE"),
                          (self.dependencies["sdl2_mixer"], "SDL2_MIXER")):
          inc = "".join(...)  # cpp_info.includedirs + include/SDL2 子目录
          tc.cache_variables[f"{prefix}_INCLUDE_DIR"] = inc
          tc.cache_variables[f"{prefix}_INCLUDE_DIRS"] = inc
          tgt = dep.ref.name + "::" + dep.ref.name
          tc.cache_variables[f"{prefix}_LIBRARY"] = tgt
          tc.cache_variables[f"{prefix}_LIBRARY_TEMP"] = tgt
          tc.cache_variables[f"{prefix}_LIBRARIES"] = tgt
      tc.generate()
  # build() 中再对源做三处补丁：
  #  (a) 顶层 CMakeLists.txt 注入 find_package(sdl2/sdl2_image/sdl2_mixer/nanopb CONFIG QUIET)
  #      + add_definitions(-Wno-implicit-const-int-float-conversion)（clang 15 RAND_MAX 转换）
  #  (b) src/proto/CMakeLists.txt：msg.pb.c/.h 已预生成时跳过 nanopb_generate_cpp
  #      （避免 protoc/Google protobuf 依赖），并给 cdogs_proto 追加
  #      target_link_libraries(cdogs_proto nanopb::nanopb)
  #  (c) src/cdogs 与 src/tests 的 target_link_libraries 保留上游 MODULE 变量并追加
  #      CMakeDeps targets（sdl2::sdl2 sdl2_image::sdl2_image ...）
```

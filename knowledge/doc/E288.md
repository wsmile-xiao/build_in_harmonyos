# E288: CMake 双库目标收敛为单一可选产物

## 基本信息
- **严重度**: 2
- **类别**: cmake, packaging
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: 2105

## 错误特征
```
package contains both .*\.a and .*\.so|BUILD_SHARED_LIBS.*ignored
```

## 根因分析
上游显式定义 STATIC 和 SHARED 两个目标时 BUILD_SHARED_LIBS 不参与目标类型选择，包会同时安装两类库。

## 推荐方案
**方法**: single-cmake-library-target

**说明**: 将双目标改为一个未显式指定类型的 add_library 目标，让 BUILD_SHARED_LIBS 决定产物。

**验证/命令**:
```
cmake -S . -B build -DBUILD_SHARED_LIBS=OFF
```

## 关键词
CMake, BUILD_SHARED_LIBS, static, shared, single artifact

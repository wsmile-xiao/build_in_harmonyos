# E038: groff 宏文件缺失

> **结构化数据**: [graph/E038.kv](../graph/E038.kv) | **原则**: 无
> **严重度**: 🟢 low | **分类**: packaging/compat/man | **自动修复**: ❌ 手动编辑

---

## 错误特征

```
man man
# <standard input>:1: warning: macro 'g' not defined (diversion on)
# <standard input>:1: warning: macro 'safe' not defined (diversion on)
# <standard input>:1: warning: macro 'padj' not defined (diversion on)
```

## 根因

groff 1.23.0 相较于旧版本移除了 `g.tmac`、`safe.tmac` 和 `padj.tmac`。man-db 的 man_db.conf 中 nroff 定义仍引用这些已移除的宏。

| 宏 | 旧版 groff | groff 1.23.0 | man_db.conf 参数 |
|----|-----------|-------------|-----------------|
| g.tmac | ✅ | ❌ 移除 | `-mg` |
| safe.tmac | ✅ | ❌ 移除 | `-msafe` |
| padj.tmac | ✅ | ❌ 移除 | `-mpadj` |
| s.tmac | ✅ | ✅ | `-ms` |

## 解决方案

修改 man_db.conf 中的 nroff 定义：

```bash
# 修改前
DEFINE  nroff  groff -Tutf8 -mg -msafe -mpadj -mandoc

# 修改后（groff 1.23.0 兼容）
DEFINE  nroff  groff -Tutf8 -mandoc
```

## 禁止模式

❌ groff 1.23.0+ 的 nroff 配置中引用 `-mg`/`-msafe`/`-mpadj` → 宏未定义警告

## 涉及软件

man-db 2.13.1（搭配系统预装的 groff 1.23.0）。

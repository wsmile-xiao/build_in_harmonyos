# E038: config-patch

## 基本信息
- **严重度**: 1
- **类别**: compat, packaging
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
macro 'g' not defined|macro 'safe' not defined|
                         macro 'padj' not defined|groff.*warning.*diversion
```

## 根因分析
groff 1.23.0 移除了 g.tmac(getopt宏)、safe.tmac(安全子集宏)、
                         padj.tmac(段落调整宏); man-db 的 man_db.conf 中 nroff 定义仍引用这些已移除的宏

## 推荐方案
**方法**: config-patch

**说明**: 修改 man_db.conf 中的 nroff 定义, 移除不兼容的宏参数:
                         DEFINE nroff groff -Tutf8 -mandoc (去掉 -mg -msafe -mpadj)

**验证/命令**:
```
rec_auto_fix:          false
```

groff, macro, g.tmac, safe.tmac, padj.tmac, man-db,
                         man_db.conf, nroff, diversion, warning, mandoc

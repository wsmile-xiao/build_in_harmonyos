# E138: disable-posix-timer

## 基本信息
- **严重度**: 3
- **类别**: posix-compatibility|ohos-porting|time-functions
- **触发工具**: gcc|clang|make|cmake
- **阶段**: compilation

## 错误特征
```
error: 'CLOCK_REALTIME' undeclared|error: 'CLOCK_MONOTONIC' undeclared|error: implicit declaration of function 'clock_gettime'|error: storage size of 'ts' isn't known
```

**关键词**: CLOCK_REALTIME, CLOCK_MONOTONIC, clock_gettime, timespec, time.h, POSIX timer

## 根因分析
OHOS SDK 的 sysroot 中 time.h 定义了 clock_gettime，但 CLOCK_REALTIME/CLOCK_MONOTONIC 等常量需要特定的宏定义或头文件包含顺序

**影响范围**: 使用 POSIX timer 的跨平台库（如 raylib、SDL 等）

## 推荐方案
- **方法**: disable-posix-timer
- **描述**: 禁用 POSIX timer 功能，使用替代计时方案（如 gettimeofday）
- **命令**: `cmake .. -DSUPPORT_POSIX_TIMERS=OFF -DUSE_POSIX_TIMERS=OFF`
- **自动修复**: false

## 验证
```bash
echo '#include <time.h>\nint main() { return CLOCK_REALTIME; }' | clang -E -dM - | grep CLOCK
```

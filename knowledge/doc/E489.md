# E489: OHOS 上 CTest 必须在执行前签名构建树的完整 ELF 加载闭包

## 基本信息
- **严重度**: 3
- **类别**: testing, security, dynamic-loading
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !4234

## 错误特征
```
CTest.*(Failed|Permission denied|Operation not permitted)|dlopen.*(Permission denied|Operation not permitted|failed)|Error loading shared library.*Permission denied
```

## 根因分析
Conan 的 build() 在 package() 之前执行；若只在 package() 中签名安装产物，CTest 实际运行的构建树 ELF 仍未签名。动态测试的运行闭包不只包含测试可执行文件，还可能包含 LD_PRELOAD 库、普通共享库和运行时 dlopen 的 MODULE/plugin。只签测试入口或只签 package_folder 都会遗漏加载对象并在运行期失败。

## 推荐方案
**方法**: sign-build-tree-runtime-closure

**说明**: 在调用 CTest 前枚举测试入口及其构建树加载闭包，仅选择普通 ELF 文件，先移除已有 .codesign 段再统一签名；签名工具缺失或任一文件签名失败时立即终止。签名完成后使用私有可写 TMPDIR 执行完整 CTest。

**验证/命令**:
```
llvm-objcopy --remove-section .codesign <elf> && binary-sign-tool sign -inFile <elf> -outFile <elf> -selfSign 1 && TMPDIR=<writable-dir> ctest --output-on-failure --verbose -j1
```

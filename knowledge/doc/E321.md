# E321: martinmoene lite 系 header-only 库：Conan 1.x 配方迁移 2.x 与 INTERFACE 消费/上游测试入口恢复

## 基本信息
- **严重度**: 2
- **类别**: ohos, headers, cmake, conan, packaging
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !7220

## 错误特征
```
from conans import ConanFile, CMake|conans import.*error|
                        No module named conans|header-only|INTERFACE library|
                        CMakePackageConfigHelpers|find_package.*byte-lite|
                        package_type.*header-library|cmake_layout|strip_root
```

## 根因分析
>
  martinmoene/nonstd-lite 系（byte-lite/any-lite/optional-lite/span-lite/expected-lite
  等）是单文件 header-only C++ 库：include/nonstd/*.hpp + CMake INTERFACE library
  （如 nonstd::byte-lite），上游自带 Conan 1.x 配方（from conans import ConanFile, CMake，
  依赖 CMake(self)/cmake.configure() 的 Conan 1 风格），在 Conan 2.x（本项目基线 2.29.1）
  下无法直接复用：Conan 1 API 已移除（No module named conans）、CMake helper 调用方式
  不同、需要显式 package_type=header-library、cmake_layout、CMakeToolchain 与
  cpp_info.set_property("cmake_file_name"/"cmake_target_name") 才能让下游 find_package
  解析到 INTERFACE target。版本号仅由 git tag 表达（byte.hpp 无版本宏），CMake 选项
  {NAME}_OPT_BUILD_TESTS/_OPT_BUILD_EXAMPLES 决定是否带上游测试入口。

## 推荐方案
**方法**: header-only-lite-conan2-migration

**说明**: >
  (1) conanfile.py 用 Conan 2 风格重写：from conan import ConanFile，
  package_type="header-library"，settings=os/compiler/build_type/arch，
  layout()=cmake_layout(self)，export_sources()=export_conandata_patches(self)，
  source()=get(self, **self.conan_data["sources"], strip_root=True)
  + apply_conandata_patches(self)，generate()=CMakeToolchain + OHOS 映射
  （settings.os in ("Linux","OHOS") 时设 CMAKE_SYSTEM_NAME=Linux、
  CMAKE_SYSTEM_PROCESSOR=aarch64）+ 打开 {NAME}_OPT_BUILD_TESTS=ON 保持上游测试入口，
  build()=CMake.configure/build/test，package()=CMake.install，
  package_info() 用 cpp_info.set_property("cmake_file_name", "byte-lite") 与
  cpp_info.set_property("cmake_target_name", "nonstd::byte-lite")，libs=[]。
  (2) test_package/conanfile.py 用 CMakeDeps 生成器、find_package(byte-lite) 链接
  nonstd::byte-lite，test() 实际调用被测库 API（to_integer/位运算/比较）。
  (3) 版本号仅来自 git tag：conandata.yml sources.url 指向官方 release tarball、
  sha256 实测填写；conan-verify G1 要求 test_package/MANIFEST.yml（CI L0e）。
  (4) 上游测试入口恢复：CMake 选项 BYTE_LITE_OPT_BUILD_TESTS=ON 时 CTest 4 个可执行
  （test-cpp98/11/14/17），本地 ctest 全过即证明头文件在 C++98~17 下均可编译。

**验证/命令**:
```
>
  conanfile.py 骨架见 archives/b/byte-lite/0.3.0/conanfile.py（Conan 2.x 重写版）；
  test_package 见 archives/b/byte-lite/0.3.0/test_package/；重建验证：
  python3 scripts/ohc-run.py conan-verify byte-lite 0.3.0 --profile ohos-aarch64。
```

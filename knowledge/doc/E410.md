## 根因分析
adapt 1.0.0 的上游测试文件使用非标准模块命名，pytest test 默认不会发现它们；只运行一个模块或只检查 import 无法覆盖上下文管理、实体展开、Trie 和意图确定等语义路径。

## 推荐方案
**方法**: expand-upstream-modules-and-assert-intent-semantics

**说明**: 从已校验的上游归档中展开 run_tests.sh test 实际匹配的八个模块逐项执行，并在 Conan test_package 中注册实体、构造 IntentBuilder、检查意图名称、槽位和 confidence，确保验证的是打包后的运行时语义。

**验证/命令**:
```
pytest test/ContextManagerIntegrationTest.py test/ContextManagerTest.py test/DomainIntentEngineTest.py test/EntityExpanderTest.py test/EntityTaggerTest.py test/IntentEngineTest.py test/IntentTest.py test/TrieTest.py -q
```

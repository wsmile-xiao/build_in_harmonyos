# E413: Keep target-ABI conditional upstream skips visible in the full inventory

## 基本信息
- **严重度**: 2
- **类别**: limitation, portability, testing
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5975

## 错误特征
```
ok .* # SKIP|expected skip.*counted as PASS|tests must be fully executed and pass N/N
```

## 根因分析
A fixed upstream inventory can contain cases that are
                        intentionally inapplicable on a target ABI. Treating a
                        TAP skip as PASS inflates coverage, while shrinking the
                        denominator hides registered tests. Registered, passed,
                        skipped, failed, and nonfailed counts are distinct facts.

## 推荐方案
**方法**: hashed-expected-skip-outcome-contract

**说明**: Preserve the full registered denominator, accept a skip
                        only when its stable ID, path, and diagnostic match the
                        hashed allowlist, reject unexpected skips or passes, and
                        publish passed, skipped, failed, total, and nonfailed.

**验证/命令**:
```
Validate TAP or JUnit output against a hashed inventory and expected-skip allowlist.
```

# E382: Materialize immutable cross-package resources when HMDFS cannot preserve dangling links

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, conan, packaging, filesystem, resource-overlay
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !5240

## 错误特征
```
dangling symbolic link|PermissionError.*symlink|Operation not permitted.*symlink|missing.*shared.*view
```

## 根因分析
The upstream deployment model overlays independently built packages, so a resource link is intentionally dangling until another package supplies its target; isolated Conan roots plus HMDFS link restrictions can silently omit the resource.

## 推荐方案
**方法**: dependency-graph-resource-materialization

**说明**: Resolve an explicit resource mapping from the declared dependency package, enforce source/destination containment, copy into a regular file, and verify byte identity against the resolved dependency version.

**验证/命令**:
```
use os.path.realpath/commonpath, os.path.lexists/unlink, shutil.copy2, filecmp.cmp(shallow=False), and consumer cmp plus test ! -L
```

# E368: Meson allocator fault-injection build contract

## 基本信息

- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5532

## 错误特征
```
Checking for function .*reallocarray.*NO|undefined reference to .*strndup|api-oom-spdxtool.*FAIL|TEST_ASSERT_NULL.*was
```

## 根因分析
Capability-gated GNU ld --wrap tests can be omitted when support APIs are missing; forcing the tested library static expands wrapping into library internals, while MinGW dllimport calls can bypass wrapper symbols.

## 推荐方案
**方法**: capability-bound-fault-injection

**说明**: Preserve the upstream tested-library link boundary, supply only missing test-environment APIs, make wrapped calls direct, and bind the final registered inventory plus expected terminal states.

**验证/命令**:
```
meson setup build source && meson introspect --tests build && meson test -C build --num-processes 1 --print-errorlogs
```

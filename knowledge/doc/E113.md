# E113: add-cflags

## 基本信息
- **严重度**: 2
- **类别**: platform_compat
- **触发工具**: cc|clang|cmake|make
- **阶段**: compilation

## 错误特征
```
"unknown type name 'u_int'|unknown type name 'u_long'|unknown type name 'u_char'|unknown type name 'caddr_t'"
```

**关键词**: u_int,u_long,u_char,caddr_t,BSD类型,compat头文件,OHOS

## 根因分析
"OpenHarmony/HarmonyOS系统头文件不含BSD风格类型定义(u_int/u_long/u_char/caddr_t)，POSIX标准未要求这些类型"

**影响范围**: "任何包含BSD代码的C库（如usrsctp/libevent/ncurses等）"

## 推荐方案
- **方法**: add-cflags
- **描述**: 创建ohos_compat.h头文件，定义缺失的BSD类型和宏(IFNAMSIZ/timercmp/timeradd/timersub)，通过CMAKE_C_FLAGS=-include ohos_compat.h或CFLAGS=-include ohos_compat.h注入。补丁内容使用#if平台检测而非#ifdef __OHOS__
- **自动修复**: false

## 验证
```bash
"grep -r 'u_int\\|u_long\\|u_char\\|caddr_t' deps/"
```

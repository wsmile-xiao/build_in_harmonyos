# E113: add-cflags

## 基本信息
- **严重度**: 2
- **类别**: platform, compat
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
"unknown type name 'u_int'|unknown type name 'u_long'|unknown type name 'u_char'|unknown type name 'caddr_t'"
```

## 根因分析
"OpenHarmony/HarmonyOS系统头文件不含BSD风格类型定义(u_int/u_long/u_char/caddr_t)，POSIX标准未要求这些类型"

## 推荐方案
**方法**: add-cflags

**说明**: 创建ohos_compat.h头文件，定义缺失的BSD类型和宏(IFNAMSIZ/timercmp/timeradd/timersub)，通过CMAKE_C_FLAGS=-include ohos_compat.h或CFLAGS=-include ohos_compat.h注入。补丁内容使用#if平台检测而非#ifdef __OHOS__

**验证/命令**:
```
"grep -r 'u_int\\|u_long\\|u_char\\|caddr_t' deps/"
  - 1: "创建ohos_compat.h头文件，定义缺失的BSD类型和宏(IFNAMSIZ/timercmp/timeradd/timersub)"
  - 2: "cmake项目通过CMAKE_C_FLAGS=-include ohos_compat.h注入；autotools项目通过CFLAGS=-include注入"
  - 3: "补丁内容使用#if平台检测(#if !defined(__FreeBSD__)&&!defined(__APPLE__)&&!defined(_WIN32))而非#ifdef __OHOS__"
  - 4: "⚠️ compat类型定义不能放在#if defined(__APPLE__)块内——在OHOS上__APPLE__未定义，整个块被跳过"
```

## 根因分析
系统中的 Rust 工具链（rustc/cargo）是为 Linux 编译的 ELF 二进制，

**影响范围**: 所有 Rust 项目：procs, bottom, yazi, ripgrep, bat, exa, fd, starship 等

## 推荐方案
- **方法**: wait-for-platform-support   # 见 DESIGN §5 impl 列表
- **描述**: 标记为平台限制，等待鸿蒙原生 Rust 工具链或 musl 静态链接版本可用
- **命令**: `# 无命令，仅记录 PROGRESS.md: "阻塞原因: Rust 工具链不可用"`

# E047: relax-assertion

## 错误特征
```
assertionError.*440.*413|assertionError.*432.*292|
                         file permission.*other.*read.*masked|mode.*diff.*004
```

## 根因分析
HarmonyOS 文件系统(HMDFS)在文件创建时会额外清除
                         "other read" 权限位(0o004), 与 umask 设置无关

## 推荐方案
**方法**: relax-assertion

**说明**: 放宽权限断言容差: 在鸿蒙上允许 other-read 位差异
                         expected_mode &= ~0o004

**验证/命令**:
```
rec_auto_fix:          true
```

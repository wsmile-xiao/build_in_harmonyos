# E331: OHOS HMDFS 构建 CMake 版本化共享库时需避免符号链接链

## 基本信息
- **严重度**: 3
- **类别**: hmdfs, cmake, linking, shared-library
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !5081

## 错误特征
```
Error creating symbolic link.*libopenjp2\.so|Operation not permitted.*libopenjp2\.so|cmake_symlink_library.*failed
```

## 根因分析
CMake 为带 VERSION/SOVERSION 的共享库生成真实版本文件和未版本化符号链接；OHOS 真机的 HMDFS 工作目录拒绝创建这些符号链接，导致库已链接完成但构建在 cmake_symlink_library 阶段失败。

## 推荐方案
**方法**: ohos-only-unversioned-shared-library

**说明**: 给上游 CMake 增加默认关闭的选项，仅在 OHOS 配方中跳过 VERSION/SOVERSION target properties，直接生成未版本化共享库；其他平台保持上游 SONAME 和符号链接布局。

**验证/命令**:
```
cmake -DOPENJPEG_NO_VERSIONED_SONAME=ON ...
```

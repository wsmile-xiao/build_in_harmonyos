# E530: X11 客户端库无 X server 时用强类型活重定位 + ABI 布局固定做消费者测试

## 基本信息
- **严重度**: 3
- **类别**: ohos, packaging, testing, abi, x11
- **作者**: zhangbowl-JW <406099677@qq.com>
- **来源 PR**: !6704

## 错误特征
```
undefined reference to .Xinerama|No such file or directory.*X11|make check.*no tests|Xvfb|:0.*Cannot open display
```

## 根因分析
X11 扩展客户端库上游通常无自动化测试（make check 为空），
                        而真实函数调用需要 X server。空 test_package 只验证链接、
                        不验证导出符号集合与类型/常量契约，ABI 退化时无声。
                        OHOS CI worker 无 Xvfb，无法运行上游 X 测试。

## 推荐方案
**方法**: strong-typed-relocation-plus-abi-pinning

**说明**: api_surface.c 用 __typeof__(&name) + volatile 取地址对每个导出符号生成
                        活重定位（链接期即校验签名与存在性）；version_contract.c 用 CHECK 宏
                        钉死协议版本常量与公开结构体 offsetof/sizeof；CMake 加 -Wall -Wextra
                        -Werror；test_package 用 explicit test_type，OHOS 上签名后逐个运行。

**验证/命令**:
```
CI_PACKAGES="archives/l/libxinerama/1.1.6" zsh ci/conan/build_and_test.sh
```

## 关键词
api_surface, version_contract, DECLARE_SYMBOL, __typeof__, offsetof, XineramaScreenInfo, display-independent, Xvfb, strong typed relocation

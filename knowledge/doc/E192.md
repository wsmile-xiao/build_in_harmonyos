# E192: source-patch

## 基本信息
- **严重度**: error
- **类别**: musl_compat
- **触发工具**: cc|clang|make
- **阶段**: compilation

## 错误特征
```
|
```

**关键词**: pthread_mutexattr_setrobust, PTHREAD_MUTEX_ROBUST, musl, robust mutex, HarmonyOS

## 根因分析
musl libc（HarmonyOS 使用）不支持 POSIX robust mutex 功能。pthread_mutexattr_setrobust() 和 PTHREAD_MUTEX_ROBUST 宏在 musl 中未实现，因为 robust mutex 需要内核支持 owner-death 检测，而 musl 设计目标是轻量级实现。

**影响范围**: 使用跨进程 robust mutex 的软件（libpisp, 涉及共享内存互斥锁的项目）

## 推荐方案
- **方法**: source-patch
- **描述**: 条件编译排除 robust mutex 功能，使用 #ifdef __OHOS__ 定义 PISP_NO_ROBUST_MUTEX 宏，在代码中用 #ifndef 守卫跳过 pthread_mutexattr_setrobust 调用，降级为普通 PTHREAD_PROCESS_SHARED mutex
- **自动修复**: false

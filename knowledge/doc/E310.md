# E310: CLI 版本测试不得臆测品牌前缀

## 基本信息
- **严重度**: 2
- **类别**: testing, api, cli
- **作者**: 2301_80739235 <2047361658@qq.com>

## 错误特征
```
version output missing product prefix|version output missing brand prefix|version output lacks product prefix|version output lacks brand prefix|expected product prefix|expected brand prefix
```

## 根因分析
消费者测试没有先核对生产者对 --version 的实际输出契约，而是同时要求版本号和产品名、品牌前缀或描述文本；当工具合法地只输出纯版本号时，测试会把可用制品误判为失败。

## 推荐方案
**方法**: assert-documented-version-contract

**说明**: 先从目标版本的上游文档、测试或实现确认输出契约；只去除契约允许的首尾空白，再将解析结果与包管理器已解析的期望版本比较。若上游输出包含固定前缀，应按该已证实格式解析；若只输出版本号，则精确比较纯版本号。

**验证/命令**:
```
<tool> --version > version.txt 2>&1; test "$(tr -d '\r' < version.txt | sed -e 's/^[[:space:]]*//' -e 's/[[:space:]]*$//')" = "<expected-version>"
```

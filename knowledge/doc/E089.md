# E089: replace-pkginstalldir

## 基本信息
- **严重度**: 2
- **类别**: platform, build-system, autotools
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
@am_AUTOM4TE@ inaccessible or not found|aclocal: error: @am_AUTOM4TE@ failed with exit status|WARNING.*aclocal.*is missing|'pkgconfig_DATA' is used but 'pkgconfigdir' is undefined
```

## 根因分析
OHOS 预装的 aclocal 脚本中 @am_AUTOM4TE@ 占位符未被替换为实际 autom4te 路径，
                        导致 aclocal 执行时调用字面字符串作为命令失败。
                        configure 生成时缺少 pkgconfigdir 变量定义，
                        automake 报 "pkgconfig_DATA is used but pkgconfigdir is undefined"。
                        release tarball 通常已包含完整 aclocal.m4。

## 推荐方案
**方法**: replace-pkginstalldir

**说明**: 在 configure.ac 中删除 PKG_INSTALLDIR() 调用，
                        手动用 AC_SUBST([pkgconfigdir], [\${libdir}/pkgconfig]) 替代。
                        同时在 Makefile.am 中显式定义 pkgconfigdir = $(libdir)/pkgconfig。

**验证/命令**:
```
sed -i 's/PKG_INSTALLDIR/AC_SUBST([pkgconfigdir], [\\${libdir}\\/pkgconfig])/' configure.ac && echo 'pkgconfigdir = $(libdir)/pkgconfig' >> Makefile.am
```

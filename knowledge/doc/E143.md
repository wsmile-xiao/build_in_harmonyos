# E143: fix-shebang-plus-env

## 基本信息
- **严重度**: 2
- **类别**: platform-runtime
- **触发工具**: runtime|python
- **阶段**: runtime

## 错误特征
```
/usr/bin/python3: no such file or directory|
```

**关键词**: bscalc, ctypes, dlopen, Permission denied,

## 根因分析
bscalc 是 Python 脚本（#!/usr/bin/python3），HarmonyOS 上 /usr/bin/python3 不存在；且 bytesize.py 通过 ctypes.CDLL("libbytesize.so.1") 加载共享库时，HarmonyOS 动态链接器拒绝非系统信任路径的未签名库

**影响范围**: 所有通过 Python ctypes dlopen 加载自定义共享库的脚本工具

## 推荐方案
- **方法**: fix-shebang-plus-env
- **描述**: 1) 修改 bscalc shebang 为 /data/service/hnp/python.org/python_3.12/bin/python3.12；2) 设置 PYTHONPATH 和 LD_PRELOAD 环境变量运行
- **命令**: `PYTHONPATH=$PREFIX/lib/python3.12/site-packages LD_PRELOAD=$PREFIX/lib/libintl_glib.so /data/service/hnp/bin/python /path/to/bscalc`
- **自动修复**: false

## 验证
```bash
/data/service/hnp/bin/python -c "import ctypes; ctypes.CDLL('/path/to/lib.so')" 2>&1
```

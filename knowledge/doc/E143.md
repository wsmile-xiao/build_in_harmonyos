## 错误特征
```
/usr/bin/python3: no such file or directory|
                         ctypes.CDLL.*Permission denied|
                         OSError.*Error loading shared library.*Permission denied|
                         bad interpreter.*python3
```

## 根因分析
bscalc 是 Python 脚本（#!/usr/bin/python3），HarmonyOS 上 /usr/bin/python3 不存在；且 bytesize.py 通过 ctypes.CDLL("libbytesize.so.1") 加载共享库时，HarmonyOS 动态链接器拒绝非系统信任路径的未签名库

## 推荐方案
**方法**: fix-shebang-plus-env

**说明**: 1) 修改 bscalc shebang 为 /data/service/hnp/python.org/python_3.12/bin/python3.12；2) 设置 PYTHONPATH 和 LD_PRELOAD 环境变量运行

**验证/命令**:
```
PYTHONPATH=$PREFIX/lib/python3.12/site-packages LD_PRELOAD=$PREFIX/lib/libintl_glib.so /data/service/hnp/bin/python /path/to/bscalc
```

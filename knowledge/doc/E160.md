# E160: config-guess-harmonyos-patch

## 基本信息
- **严重度**: 3
- **类别**: platform
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
config.guess: unable to guess system type|cannot guess build type|uname -s = HarmonyOS
```

**关键词**: HarmonyOS, config.guess, unable to guess system type, HongMeng Kernel

## 根因分析
标准config.guess脚本无法识别HarmonyOS系统，因为它是一个新系统且不在GNU config项目的已知系统列表中

**影响范围**: 所有使用autotools构建系统的软件，在HarmonyOS上首次编译时

## 推荐方案
- **方法**: config-guess-harmonyos-patch
- **描述**: 修改config/config.guess添加HarmonyOS检测分支，将其识别为Linux系统(LIBC=musl)
- **命令**: `sed -i '/case $UNAME_SYSTEM in/a HarmonyOS|HongMeng) UNAME_SYSTEM=Linux; LIBC=musl; ;;' config/config.guess`
- **自动修复**: true

## 验证
```bash
uname -s | grep HarmonyOS && ./config/config.guess
```

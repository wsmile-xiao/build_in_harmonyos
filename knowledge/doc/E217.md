# E217: check-cmake-header-install-subdir

## 基本信息
- **严重度**: 2
- **类别**: headers, cmake, conan
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>
- **来源 PR**: source_commit:          5d92d237f

## 错误特征
```
fatal error: '.+\.h' file not found|test_package.*\.c:\d+:\d+: fatal error
```

## 根因分析
上游 CMake 用 install(FILES ${c_headers} DESTINATION include/${PROJECT_NAME}) 把头文件
                        装进 include/<subdir>，但 conan-init 生成的模板配方 package_info() 默认 includedirs=["include"]，
                        test_package 的 #include <xxx.h> 找不到头文件，G2 在 test_package 阶段失败。
                        知识图谱仅匹配到 E001（找不到编译器），根因完全不同，属误匹配。

## 推荐方案
**方法**: check-cmake-header-install-subdir

**说明**: 先读上游 CMakeLists 确认 install(FILES ... DESTINATION) 目标目录，再把
                        package_info() 的 cpp_info.includedirs 指向实际子目录（如 ["include/libairspyhf"]），
                        与上游工具源码的 #include <airspyhf.h> 保持一致

**验证/命令**:
```
grep -rn "DESTINATION include" <src>/CMakeLists.txt && 修改 conanfile.py package_info() includedirs
```

## 错误特征
```
Can't locate.*\.pm in @INC|perl Makefile.PL|No such file.*Makefile.PL
```

## 根因分析
纯 Perl 模块使用 ExtUtils::MakeMaker (Makefile.PL) 构建，不涉及 C 编译器。
                        Perl 安装在 /data/service/hnp，@INC 不包含用户安装路径 ~/usr/local。
                        需通过 PERL5LIB 环境变量提供依赖模块路径。
                        部分模块源码 URL 可能 404（如 savannah.nongnu.org），需使用 CPAN backpan 替代。

## 推荐方案
**方法**: perl-pure-module-build

**说明**: 使用 PERL5LIB 指定依赖路径，PREFIX/INSTALL_BASE=$DEFAULT_PREFIX 控制安装路径，DESTDIR 模式 staging

**验证/命令**:
```
export PERL5LIB=$HOME/usr/local/lib/site_perl/5.42.0:$HOME/usr/local/lib/5.42.0 && perl Makefile.PL PREFIX=$DEFAULT_PREFIX && make && make install DESTDIR=$TEST_PREFIX && make test
```

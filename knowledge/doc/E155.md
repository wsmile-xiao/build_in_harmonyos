# E155: perl-pure-module-build

## 基本信息
- **严重度**: 1
- **类别**: build-system|perl
- **触发工具**: perl|make|test
- **阶段**: configuration|installation|testing

## 错误特征
```
Can't locate.*\.pm in @INC|perl Makefile.PL|No such file.*Makefile.PL
```

**关键词**: Makefile.PL, ExtUtils::MakeMaker, PERL5LIB, pure Perl, CPAN, backpan, PREFIX, INSTALL_BASE, Pod::Coverage, Devel::Symdump, Pod::Parser

## 根因分析
纯 Perl 模块使用 ExtUtils::MakeMaker (Makefile.PL) 构建，不涉及 C 编译器。

**影响范围**: 所有纯 Perl 模块（Pod::Coverage, PHP::Serialization, PDF::API2 等）

## 推荐方案
- **方法**: perl-pure-module-build
- **描述**: 使用 PERL5LIB 指定依赖路径，PREFIX/INSTALL_BASE=$DEFAULT_PREFIX 控制安装路径，DESTDIR 模式 staging
- **命令**: `export PERL5LIB=$HOME/usr/local/lib/site_perl/5.42.0:$HOME/usr/local/lib/5.42.0 && perl Makefile.PL PREFIX=$DEFAULT_PREFIX && make && make install DESTDIR=$TEST_PREFIX && make test`
- **自动修复**: true

## 验证
```bash
perl -MPod::Coverage -e 'print $Pod::Coverage::VERSION, "\n"'
```

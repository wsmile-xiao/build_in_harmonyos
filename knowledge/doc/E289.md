# E289: HELP2MAN=true 未生成手册页但 Automake 仍安装 man_MANS 导致失败

## 基本信息
- **严重度**: 3
- **类别**: autotools, install
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
install: cannot stat .*\.[1-9].*: No such file or directory|No rule to make target .*\.[1-9].*install-man
```

## 根因分析
把 HELP2MAN 设置为 true 只会让生成命令成功返回而不产生手册页；Automake 生成的 man_MANS 安装清单仍非空，install-man 目标因此读取不存在的文件并失败

## 推荐方案
**方法**: clear-automake-man-list

**说明**: 禁用 help2man 时，在 make install 命令行显式传入 man_MANS=，使 Automake 不执行缺失手册页的安装规则

**验证/命令**:
```
make install DESTDIR="$DESTDIR" man_MANS=
```

# E430: Bind source archives to the current GitHub Release asset digest

## 基本信息
- **严重度**: 2
- **类别**: security
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !6427

## 错误特征
```
Downloaded release archive SHA-256 conflicts with a third-party catalog checksum
```

## 根因分析
Third-party package indexes are snapshots and can retain a checksum that does not identify the current uploaded release asset.

## 推荐方案
**方法**: official-asset-digest-binding

**说明**: Use the current GitHub Releases API asset digest as the integrity authority and require the local file to match it exactly.

**验证/命令**:
```
curl the exact release tag API; select the exact asset name; compare size and sha256 digest
```

GitHub Release API, asset digest, sha256, Homebrew checksum, release archive

# E421: SourceForge 主站 sourceforge.net 受 Cloudflare JS challenge / I

## 基本信息
- **严重度**: 2
- **类别**: network, download-mirror
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>
- **来源 PR**: !6301

## 错误特征
```
403 Forbidden|404 Not Found|Just a moment|Cloudflare|sourceforge\.net|downloads\.sourceforge\.net
```

## 根因分析
SourceForge 主站 sourceforge.net 受 Cloudflare JS challenge / IP 限流保护，脚本 UA 在
  部分网络环境持续 403；downloads.sourceforge.net 对不含真实子目录的路径返回 404，真实文件路径
  藏在 301 Location 中（例如 accrete 实际在 /project/accrete/accrete/1.0/accrete-1.0.tar.gz）

## 推荐方案
**方法**: 用 curl 请求 downloads.sourceforge.net 的短路径，从 301 Location 得到真实子目录路径，
  再用真实路径 HTTP/HTTPS 直接下载；最后用 sha256 校验（可与 FreeBSD ports astro/<pkg>/distinfo
  交叉核对，确认与上游同字节）

**说明**: 用镜像 301 跳转揭示真实下载路径后直连下载并校验 sha256

**验证/命令**:
```
curl -sSI "http://downloads.sourceforge.net/{proj}/{file}" | grep -i location && curl -sSL "http://downloads.sourceforge.net/project/{proj}/{subdir}/{file}" -o {file} && sha256sum {file}
```

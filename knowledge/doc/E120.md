# E120: env-library-path

## 基本信息
- **严重度**: 3
- **类别**: ohos, toolchain, linking, environment
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
error while loading shared libraries: libxml2\.so\.16|cannot open shared object file: libxml2\.so\.16|lld: error:.*libxml2
```

## 根因分析
OHOS SDK 的 lld 动态链接到 libxml2.so.16，但系统库路径未包含该路径

## 推荐方案
**方法**: env-library-path

**说明**: 设置 LD_LIBRARY_PATH 包含 OHOS SDK 的 lib 目录

**验证/命令**:
```
export LD_LIBRARY_PATH=/data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/lib:$LD_LIBRARY_PATH
```

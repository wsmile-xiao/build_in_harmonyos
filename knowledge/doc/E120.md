# E120: env-library-path

## 基本信息
- **严重度**: 3
- **类别**: environment|linking|ohos-sdk
- **触发工具**: ld|clang|cmake|make
- **阶段**: linking

## 错误特征
```
error while loading shared libraries: libxml2\.so\.16|cannot open shared object file: libxml2\.so\.16|lld: error:.*libxml2
```

**关键词**: libxml2.so.16, lld, shared libraries, LD_LIBRARY_PATH, OHOS SDK

## 根因分析
OHOS SDK 的 lld 动态链接到 libxml2.so.16，但系统库路径未包含该路径

**影响范围**: 使用 OHOS SDK 26.0.0+ 的所有编译，尤其是链接阶段

## 推荐方案
- **方法**: env-library-path
- **描述**: 设置 LD_LIBRARY_PATH 包含 OHOS SDK 的 lib 目录
- **命令**: `export LD_LIBRARY_PATH=/data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/lib:$LD_LIBRARY_PATH`
- **自动修复**: true

## 验证
```bash
ldd /data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/bin/lld | grep libxml2
```

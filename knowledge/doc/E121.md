# E121: add_compile_definition

## 基本信息
- **严重度**: 3
- **类别**: api-missing|platform-limitation
- **触发工具**: ld|clang
- **阶段**: linking

## 错误特征
```
undefined symbol: setutxent|undefined symbol: pututxline|undefined symbol: endutxent|did you mean: setutent|did you mean: pututline|did you mean: endutent
```

**关键词**: setutxent,pututxline,endutxline,utmpx,OMIT_UTMP

## 根因分析
OHOS 系统只提供 utmp API（setutent/pututline/endutent），不提供 utmpx API（setutxent/pututxline/endutxent），导致链接失败

**影响范围**: 使用 utmpx.h 和 utmp 记录功能的程序（如 SSH 服务器、终端工具）

## 推荐方案
- **方法**: add_compile_definition
- **描述**: 添加 OMIT_UTMP 编译定义，禁用 utmp 记录功能（对非桌面终端程序核心功能非必需）
- **命令**: `target_compile_definitions(target PRIVATE OMIT_UTMP)`
- **自动修复**: false

## 验证
```bash
grep -r "setutxent|pututxline|endutxent" *.c
```

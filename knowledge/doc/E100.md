# E100: add-cmake-flag

## 错误特征
```
ld\.lld: error: undefined symbol: jsimd_can_|CMake Warning.*SIMD extensions not available for this CPU \(unknown\)
```

## 根因分析
CMake 无法识别当前平台（输出 "unknown"），导致 SIMD 扩展未被编译，但 simdcoverage 测试程序仍尝试链接 SIMD 函数符号，产生链接错误。

## 推荐方案
**方法**: add-cmake-flag

**说明**: 禁用 SIMD 扩展（WITH_SIMD=0）和测试套件（WITH_TESTS=0）。SIMD 扩展在未识别平台上不可用，禁用后不影响核心 JPEG 编解码功能，仅牺牲性能加速。

**验证/命令**:
```
cmake -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX -DCMAKE_BUILD_TYPE=Release -DWITH_SIMD=0 -DWITH_TESTS=0 ..
```

# E266: lld 链接器缺少 libxml2.so.16 依赖导致 clang 链接失败

## 基本信息
- **严重度**: 3
- **类别**: linking, dependency
- **作者**: lz6688 <yhwork66@163.com>

## 错误特征
```
Error loading shared library libxml2.so.16.*needed by.*lld|xmlFreeDoc: symbol not found|clang.*error: unable to execute command: No such file or directory|clang.*error: linker command failed due to signal
```

## 根因分析
ohos-sdk 自带的 lld 链接器是动态链接的 ELF，运行时依赖 libxml2.so.16，但系统默认库搜索路径中找不到该库，导致 lld 无法启动，clang 链接阶段失败

## 推荐方案
**方法**: use-alternative-linker

**说明**: 使用 -fuse-ld=/data/service/hnp/bin/ld 指定 GNU ld 2.45 替代有问题的 lld

**验证/命令**:
```
clang -fuse-ld=/data/service/hnp/bin/ld -o output source.c $(CFLAGS) $(LDFLAGS) -lssl -lcrypto
```

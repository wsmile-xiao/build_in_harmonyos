# E189: manual-compile              # 见 DESIGN §5 impl 列表

## 基本信息
- **严重度**: 3
- **类别**: build-system-qmake
- **触发工具**: qmake
- **阶段**: configuration

## 错误特征
```
Cannot find feature spec_pre.prf|Could not find qmake spec
```

**关键词**: qmake, spec_pre.prf, features, Qt, mkspecs

## 根因分析
Qt 安装不完整,缺少 mkspecs/features 目录和 spec_pre.prf 等配置文件

**影响范围**: 所有使用 qmake 构建系统的 Qt 项目

## 推荐方案
- **方法**: manual-compile              # 见 DESIGN §5 impl 列表
- **描述**: 手动编译:使用 flex/bison 生成解析器,然后用 clang++ 编译源码并链接
- **命令**: `cd src && bison -v -d -o parser.cpp datalang.y && flex -o tokens.cpp datalang.l && clang++ -std=c++14 -fPIC -c *.cpp && clang++ -shared -o libiodata-qt5.so *.o -lQt5Core`
- **自动修复**: false                      # 引擎能否自动执行

## 验证
```bash
find $QT_HOST_DATA -name "features" -type d && find $QT_HOST_DATA -name "spec_pre.prf"
```

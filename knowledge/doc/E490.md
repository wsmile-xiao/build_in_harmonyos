# E490: Restore Autotools helper execute bits before configure

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, conan, filesystem, execute-permission
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !4602

## 错误特征
```
Permission denied|configure.*cannot execute|config\.guess.*Permission denied|config\.sub.*Permission denied
```

## 根因分析
Autotools helper scripts are executable programs, but some HarmonyOS PC adaptation paths preserve source content without preserving POSIX execute mode bits. The build can fail before compilation even though the generated scripts are otherwise valid.

## 推荐方案
**方法**: restore-known-autotools-script-modes

**说明**: Before configure, walk the recipe, source, and build folders and add owner/group/other execute bits only to known Autotools helper scripts. Then run configure and make check as part of the recipe build.

**验证/命令**:
```
chmod +x configure config.guess config.sub install-sh missing; ./configure; make -j1; make -j1 check
```

## 错误特征
```
link: mapping output file failed: permission denied|go build.*link.*permission denied
```

## 根因分析
Go linker uses mmap syscall to efficiently write ELF output files. On HMDFS (HarmonyOS Distributed File System) or SELinux-restricted filesystems, mmap write operations may be denied even when normal file write permissions exist. TMPDIR workaround does not help because the issue is with mmap permissions, not /tmp access.

## 推荐方案
**方法**: set-env-var

**说明**: Go linker fails to create output binary due to mmap permission restrictions on HMDFS. This is a platform-specific limitation that cannot be fixed by environment variables alone.

**验证/命令**:
```
|Try alternative approaches:
  1. CGO_ENABLED=1 with -linkmode=external -extld=clang (uses external linker)
  2. Build in different filesystem (non-HMDFS directory)
  3. Check SELinux policies for mmap restrictions
  4. Use pre-compiled Go binaries from upstream releases
  5. Report as platform limitation if no workaround found
```

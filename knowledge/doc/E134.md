# E134: set-env-var

## 基本信息
- **严重度**: 3
- **类别**: platform|filesystem|mmap|Go
- **触发工具**: go|go build
- **阶段**: linking

## 错误特征
```
link: mapping output file failed: permission denied|go build.*link.*permission denied
```

**关键词**: go build,link,mapping output file,permission denied,mmap,HMDFS,Go linker

## 根因分析
Go linker uses mmap syscall to efficiently write ELF output files. On HMDFS (HarmonyOS Distributed File System) or SELinux-restricted filesystems, mmap write operations may be denied even when normal file write permissions exist. TMPDIR workaround does not help because the issue is with mmap permissions, not /tmp access.

**影响范围**: All Go projects compiled on HMDFS filesystems (croc, Go tools, etc.)

## 推荐方案
- **方法**: set-env-var
- **描述**: Go linker fails to create output binary due to mmap permission restrictions on HMDFS. This is a platform-specific limitation that cannot be fixed by environment variables alone.
- **命令**: `|Try alternative approaches:`
- **自动修复**: false

## 验证
```bash
go build -v -x -ldflags="-s -w" -o test_binary . 2>&1 | grep "mapping output file"
```

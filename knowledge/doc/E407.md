# E407: Probe pthread_cancel and document PortAudio no-device testing on OHOS

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, audio, pthread
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6024

## 错误特征
```
pthread_cancel|PTHREAD_CANCELED|paqa_errs|host_apis=0
```

## 根因分析
Target libc capability is a configure-time property; PTHREAD_CANCELED alone does not prove pthread_cancel links. Most upstream targets require audio backends or loopback hardware unavailable in the base OHOS gate.

## 推荐方案
**方法**: configure-feature-probe

**说明**: Generate HAVE_PTHREAD_CANCEL with AC_CHECK_FUNCS and gate cancellation calls on that generated feature macro; keep the 48 hardware-dependent targets explicitly deferred.

**验证/命令**:
```
AC_CHECK_FUNCS([pthread_cancel])
```

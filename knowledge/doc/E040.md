# E040: config-patch

## 基本信息
- **严重度**: 3
- **类别**: runtime, security, memory
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
mandb.*SIGSEGV|mandb.*exit code 139|
                         MAN_OWNER.*null.*dereference|segfault.*man_owner
```

## 根因分析
man-db 的 get_man_owner() 在鸿蒙上找不到 man 系统用户返回 NULL,
                         但调用方直接解引用 man_owner->pw_uid 未做 NULL 检查, 导致段错误。

## 推荐方案
**方法**: config-patch

**说明**: 在 config.h 中取消 MAN_OWNER 定义:
                         sed -i 's/^#define MAN_OWNER "man"/\/\* #undef MAN_OWNER \*\//' config.h;
                         然后 make clean && make

**验证/命令**:
```
grep MAN_OWNER config.h  # 应看到: /* #undef MAN_OWNER */
```

# E494: lld --gc-sections 裁剪 __start_/__stop_ 封装符号导致链接失败

## 基本信息
- **严重度**: 2
- **类别**: linking, gc-sections, lld
- **作者**: hhyxx1 <f24011422@st.sandau.edu.cn>
- **来源 PR**: !5162

## 错误特征
```
undefined symbol: __start___debug|undefined symbol: __stop___debug|__start___debug.*gc-sections
```

## 根因分析
lld 15 的 --gc-sections 会裁剪 __start_/__stop_ 封装符号, 导致引用这些符号的代码链接失败

## 推荐方案
**方法**: LDFLAGS 增加 -Wl,-z,nostart-stop-gc

**说明**: 在链接参数中增加 -z nostart-stop-gc, 保留 __start_/__stop_ 封装符号

**验证/命令**:
```
make LDFLAGS="-Wl,--gc-sections -Wl,-z,nostart-stop-gc"
```

## 关键词
__start___debug, __stop___debug, gc-sections, nostart-stop-gc, undefined symbol

# E544: fix-g0a-count-with-dir-check

## 基本信息
- **严重度**: 3
- **类别**: ci-gate|shell|build-system

## 错误特征
```
G0a: knowledge/graph/draft/ 目录存在|G0_DRAFT_COUNT|ls -1.*\.kv\(N\).*wc -l
```

## 根因分析
ci/conan/build_and_test.sh 的 G0a 门禁用 `ls -1 "${GRAPH_DIR_G0}/draft"/*.kv(N) 2>/dev/null | wc -l` 统计草稿数。zsh 的 null-glob 后缀 `(N)` 在无匹配（目录为空、没有 *.kv）时会把整条 glob 单词移除，于是 `ls -1` 退化为无参数调用、回退列出当前工作目录；`wc -l` 就把 cwd 顶层条目数（如仓库根 31 个条目）误当成草稿数，>0 即判定 G0a 失败。而 `ohc graph add --draft` 会 `mkdir(exist_ok=True)` 创建空的 knowledge/graph/draft/，只要该目录存在（即便为空）就进入 `[ -d ]` 分支触发本 bug。该目录框架本就不应存在（G0a 语义要求草稿放 knowledge/drafts/），但空目录也会被 `[ -d ]` 判定为存在。

# E132: set-environment-path

## 基本信息
- **严重度**: 3
- **类别**: environment
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
Toolchain is unable to link executables|Error loading shared library libxml2.so|ld.lld: symbol not found
```

**关键词**: LD_LIBRARY_PATH, libxml2, lld, linker, unable to link, Toolchain, ohos-sdk

## 根因分析
OHOS SDK 的 lld 链接器依赖 libxml2.so.16，但运行时 LD_LIBRARY_PATH 未包含 SDK 的 llvm/lib 路径。

**影响范围**: 使用 OHOS SDK LLVM 工具链编译的所有软件

## 推荐方案
- **方法**: set-environment-path
- **描述**: 在编译前设置 LD_LIBRARY_PATH 包含 OHOS SDK 的 llvm/lib 路径。
- **命令**: `|`
- **自动修复**: false

## 验证
```bash
ldd /data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/bin/lld | grep libxml2
```

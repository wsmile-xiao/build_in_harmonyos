# E132: set-environment-path

## 基本信息
- **严重度**: 3
- **类别**: environment
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
Toolchain is unable to link executables|Error loading shared library libxml2.so|ld.lld: symbol not found
```

## 根因分析
OHOS SDK 的 lld 链接器依赖 libxml2.so.16，但运行时 LD_LIBRARY_PATH 未包含 SDK 的 llvm/lib 路径。
                        导致 configure 测试链接时失败。

## 推荐方案
**方法**: set-environment-path

**说明**: 在编译前设置 LD_LIBRARY_PATH 包含 OHOS SDK 的 llvm/lib 路径。

**验证/命令**:
```
|
  export LD_LIBRARY_PATH="/data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/lib:${LD_LIBRARY_PATH:-}"
  # 或创建 hints/environment.sh 文件固化依赖
```

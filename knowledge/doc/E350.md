# E350: Desktop wrapper hard-codes KDE/X11 services unavailable on OpenHarmony

## 基本信息
- **严重度**: 2
- **类别**: portability, desktop-integration, provider-abstraction
- **作者**: huangqicheng2 <14683402+huangqicheng2@user.noreply.gitee.com>
- **来源 PR**: !5120

## 错误特征
```
Requirement plasma-activities-cli missing|xdpyinfo: not found|kdialog: not found
```

## 根因分析
Linux desktop wrapper hard-codes KDE Activities, X11 geometry and GUI dialog commands; OpenHarmony and other non-KDE desktops expose neither the same activity service nor the same display utilities.

## 推荐方案
**方法**: explicit-context-provider

**说明**: Preserve native desktop auto-discovery when available, but move identity resolution behind a provider boundary and accept explicit ID/name inputs from OpenHarmony launchers or system-parameter bridges; restrict path-bearing IDs to a documented safe alphabet and length; make display/dialog helpers optional; test both resolution and the wrapped application flow.

**验证/命令**:
```
patch -p1 < patches/0001-activityfirefox.patch && bash test_activity_context.sh /path/to/packaged/activityfirefox
```

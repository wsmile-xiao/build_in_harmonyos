## 错误特征
```
upstream_test_fs_image_compatibility|valgrind_not_available|OHOS_no_valgrind
```

## 根因分析
OHOS 的 /tmp 是 erofs 只读文件系统，上游测试硬编码 /tmp 路径导致 mkdir 失败；缺少 dosfstools/valgrind；grep 不支持 -oP；locale 排序规则与 Linux 不同；无 valgrind 时不能伪造 valgrind 测试通过

## 推荐方案
**方法**: 1) 覆盖 SHELL/TMPDIR/FS_IMG 绕过 /tmp 只读限制；2) 用 sed -nE 替代 grep -oP；3) 无 valgrind 时用 clang ASan/UBSan（-fsanitize=address,undefined）替代内存检查，单独统计通过率，不能伪造 valgrind 通过；4) 设置 LC_ALL=C 匹配 OHOS locale；5) 在 OHOS 上重新生成 expected 输出文件

**说明**: |
  OHOS 的 /tmp 是 erofs 只读文件系统，所有硬编码 /tmp 路径的上游测试需通过 TMPDIR/FS_IMG 覆盖到可写目录；
  SHELL 需覆盖为 OHOS 上存在的 bash 路径；grep -oP 需替换为 sed -nE；
  valgrind 专用测试（如 tc_pos_valgrind_*）在 OHOS 无可用 valgrind 时必须标记为 skip，禁止伪造通过；
  替代内存检查使用 clang 的 -fsanitize=address,undefined（ASan+UBSan），需按以下步骤验证：
  a) 确认 sanitizer runtime 存在：libclang_rt.asan.so / libclang_rt.asan.a、libclang_rt.ubsan_standalone.so / libclang_rt.ubsan_standalone.a
  b) 最小 ASan/UBSan 程序编译+运行通过
  c) fatsort 以 -fsanitize=address,undefined 构建成功
  d) 确认二进制包含 ASan/UBSan 符号（readelf -s | grep -i asan 等）
  e) fatsort -v / -h 运行通过
  f) 注意：该验证为编译+smoke 验证，未覆盖真实数据流；需单独统计，不能与上游测试通过率合并
  locale 需设置为 C 并重新生成 expected 输出

**验证/命令**:
```
|
  # 1. 验证 sanitizer runtime
  ls /data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/lib/clang/15.0.4/libclang_rt.asan.*
  ls /data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/lib/clang/15.0.4/libclang_rt.ubsan_standalone.*
  # 2. 最小 ASan/UBSan 程序
  echo 'int main() { int a[10]; a[20] = 42; return 0; }' | /data/service/hnp/bin/clang -x c - -fsanitize=address,undefined -o /storage/Users/currentUser/tmp/test_asan
  /storage/Users/currentUser/tmp/test_asan 2>&1 | grep -q 'heap-buffer-overflow' && echo 'ASan OK'
  # 3. 构建 fatsort with ASan/UBSan
  make -C src CC=/data/service/hnp/bin/clang LD=/data/service/hnp/bin/clang CFLAGS="-fPIC -O2 -D__LINUX__ -fsanitize=address,undefined" LDFLAGS="-fsanitize=address,undefined"
  # 4. 确认符号
  readelf -s src/fatsort | grep -i asan
  # 5. 运行验证
  src/fatsort -v
  src/fatsort -h
  # 6. 运行上游测试（除 valgrind 外）
  make tests SHELL=/data/service/hnp/bin/bash TMPDIR=/storage/Users/currentUser/tmp FS_IMG=/storage/Users/currentUser/tmp/fs.img FATSORT=../src/fatsort LC_ALL=C
```

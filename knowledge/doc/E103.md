# E103: bump-cmake-minimum-version

## 基本信息
- **严重度**: 3
- **类别**: compat, build-system, cmake
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
CMake Error.*Compatibility with CMake.*3\.5 has been removed|cmake_minimum_required.*VERSION.*3\.[0-4]
```

## 根因分析
CMake 4.x 移除了对 3.5 之前版本的兼容模式支持。使用 cmake_minimum_required(VERSION 3.4) 或更低版本的 CMakeLists.txt 会直接报错退出

## 推荐方案
**方法**: bump-cmake-minimum-version

**说明**: 修改 CMakeLists.txt 中的 cmake_minimum_required VERSION 为 3.5 或更高

**验证/命令**:
```
sed -i 's/cmake_minimum_required(VERSION 3\.[0-4])/cmake_minimum_required(VERSION 3.5)/' CMakeLists.txt
```

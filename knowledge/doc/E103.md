# E103: CMake minimum_required VERSION < 3.5 与 CMake 4.x 不兼容

**分类**: L2 模式经验（构建系统兼容）
**严重性**: 🔴 阻塞
**影响软件**: olm 3.2.16 及其他使用旧 CMake 版本要求的项目

## 问题现象

```
CMake Error at CMakeLists.txt:1 (cmake_minimum_required):
  Compatibility with CMake < 3.5 has been removed from CMake.
```

## 根因分析

CMake 4.x 移除了对 3.5 之前版本的兼容模式。项目中的 `cmake_minimum_required(VERSION 3.4)` 会触发错误。

## 解决方案

修改 CMakeLists.txt：

```cmake
# 修改前
cmake_minimum_required(VERSION 3.4)

# 修改后
cmake_minimum_required(VERSION 3.5)
```

或用 sed：
```bash
sed -i 's/cmake_minimum_required(VERSION 3\.[0-4])/cmake_minimum_required(VERSION 3.5)/' CMakeLists.txt
```

## 验证

```bash
cmake .. -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX
```

---
**发现于**: olm 3.2.16 编译

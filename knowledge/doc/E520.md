# E520: qsb 宿主工具需 LD_LIBRARY_PATH

## 基本信息
- **严重度**: 2
- **类别**: qt6-module-adapt
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: !5160

## 错误特征
```
qsb: Error relocating symbol not found
```

## 根因分析
Qt Shader Baker（qsb）构建期运行加载 libQt6ShaderTools/libQt6Core 需依赖包 lib 路径

## 推荐方案
**方法**: build() 中用 cmake -E env LD_LIBRARY_PATH=<qtbase lib>:<qtshadertools lib> cmake --build

**说明**: cmake -E env 注入 qtbase/qtshadertools 的 lib 到 LD_LIBRARY_PATH 后执行 cmake --build

**验证/命令**:
```
cmake -E env LD_LIBRARY_PATH=$LD_LIBRARY_PATH cmake --build <build_dir>
```

# E264: Bridge legacy *-config probes with a metadata-derived signed ELF adapter

## 错误特征
```
configure: error: .*config.*not found|Permission denied.*-config|cannot execute.*-config|could not run.*-config
```

## 根因分析
A legacy configure script may require an executable *-config helper even when the Conan dependency exposes only structured CMake or pkg-config metadata. A shell shim in the package cache is not a reliable executable contract on HMDFS, while hard-coded include and library paths bind the recipe to one cache layout.

## 推荐方案
**方法**: metadata-derived-native-config-adapter

**说明**: Generate a minimal C helper in the build folder from the resolved dependency cpp_info values, compile it with the active Conan C compiler, sign the resulting target ELF when the executor requires signed binaries, and pass its absolute path through the upstream --with-<name>config option. Implement only the query surface actually consumed by upstream and fail closed for unsupported arguments or absent metadata.

**验证/命令**:
```
|
  dep = self.dependencies["<name>"].cpp_info
  # Fail if required include or library metadata is absent.
  # Escape values as C string literals, generate one small query program,
  # compile it with tools.build:compiler_executables, sign the final ELF,
  # and pass --with-<name>config=<absolute helper path> to configure.
```

# E027: configure-disable-feature

## 基本信息
- **严重度**: 2
- **类别**: linking, nls

## 错误特征
```
undefined symbol.*libintl_gettext|
                         undefined symbol.*libintl_bindtextdomain|
                         libintl.*not found|-lintl.*undefined
```

## 根因分析
GNU 软件默认启用 NLS(Native Language Support)国际化,
                         依赖 libintl(gettext 库), 鸿蒙系统未预装该库

## 推荐方案
**方法**: configure-disable-feature

**说明**: 通过 ./configure --disable-nls 禁用国际化支持(推荐)

**验证/命令**:
```
./configure --disable-nls
```

# E027: libintl_gettext 链接失败

> **结构化数据**: [graph/E027.kv](../graph/E027.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: linking/nls | **自动修复**: ✅ reconfigure

---

## 错误特征

```
ld.lld: error: undefined symbol: libintl_gettext
ld.lld: error: undefined symbol: libintl_bindtextdomain
```

## 根因

GNU 软件默认启用 NLS（Native Language Support）国际化，依赖 `libintl`（gettext 库），鸿蒙系统未预装该库。

## 解决方案

```bash
./configure --disable-nls --prefix=$HOME/usr/local
make && make install
```

## 涉及软件

gdbm 1.23、tar 1.35、coreutils 等 GNU 工具链项目。

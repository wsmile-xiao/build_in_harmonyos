# E157: manual-jpeg-ver

## 基本信息
- **严重度**: 2
- **类别**: dependency|configuration|fbida
- **触发工具**: make|sh|cpp
- **阶段**: configuration

## 错误特征
```
jpeg-version.sh.*failed|
```

**关键词**: JPEG_VER, jpeg-version.sh, cpp, libjpeg, libjpeg-turbo, JPEG_LIB_VERSION, jpeg version detection

## 根因分析
**fbida 的 jpeg-version.sh 脚本需要 cpp 预处理器来检测 JPEG 库版本**。

**影响范围**: fbida、所有依赖 jpeg-version.sh 或类似版本检测脚本的项目。

## 推荐方案
- **方法**: manual-jpeg-ver
- **描述**: 手动设置 JPEG_VER 环境变量。对于 libjpeg-turbo 3.x，JPEG_LIB_VERSION=62，所以设置 JPEG_VER=62。可以在 Make.config 中设置，或在 make config 时通过环境变量设置。
- **命令**: `# Step 1: 确定版本：grep JPEG_LIB_VERSION /usr/local/include/jpeglib.h | head -1;# Step 2: 手动设置（示例）：export JPEG_VER=62;# Step 3: 运行配置：make config;# Step 4: 验证配置：grep JPEG_VER Make.config`
- **自动修复**: true

## 验证
```bash
# 1. 检查 cpp 是否存在：which cpp;# 输出: /usr/bin/cpp 或 "not found";# 2. 测试版本检测脚本：scripts/jpeg-version.sh 2>&1;# 输出: 失败信息;# 3. 检查 libjpeg 版本：grep JPEG_LIB_VERSION /usr/local/include/jpeglib.h 2>&1 | head -3
```

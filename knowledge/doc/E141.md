# E141: use-empty-string

## 基本信息
- **严重度**: 2
- **类别**: packaging
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
no closing quote|configure_options.*\[\]|
                         /bin/sh.*no closing quote|YAML list.*regex parse
```

## 根因分析
clean_verify.py 用 regex 解析 manifest.yaml 的 configure_options 字段，YAML 空列表 [] 被解析为字面字符串 "[]" 并拼到 shell 命令行导致 quoting 错误

## 推荐方案
**方法**: use-empty-string

**说明**: 将 configure_options 从 YAML 列表 [] 改为空字符串 ""，避免 regex 解析错误

**验证/命令**:
```
在 manifest.yaml 中设置 configure_options: ""
```

## 关键词
configure_options, YAML list, regex, [],
                         no closing quote, shell argument, manifest.yaml

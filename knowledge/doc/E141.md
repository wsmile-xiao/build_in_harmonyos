# E141: use-empty-string

## 基本信息
- **严重度**: 2
- **类别**: manifest-yaml
- **触发工具**: clean_verify
- **阶段**: verification

## 错误特征
```
no closing quote|configure_options.*\[\]|
```

**关键词**: configure_options, YAML list, regex, [],

## 根因分析
clean_verify.py 用 regex 解析 manifest.yaml 的 configure_options 字段，YAML 空列表 [] 被解析为字面字符串 "[]" 并拼到 shell 命令行导致 quoting 错误

**影响范围**: 所有 configure_options 为 YAML 列表格式的软件归档

## 推荐方案
- **方法**: use-empty-string
- **描述**: 将 configure_options 从 YAML 列表 [] 改为空字符串 ""，避免 regex 解析错误
- **命令**: `在 manifest.yaml 中设置 configure_options: ""`
- **自动修复**: false

## 验证
```bash
python3 -c "import re; m=re.search(r'configure_options:\s*[\"\']?(.*?)[\"\']?\n', open('manifest.yaml').read()); print(repr(m.group(1)))"
```

# E081: source-patch

## 基本信息

- **类别**: compat, libc

## 错误特征
```
secure_getenv.*undeclared|implicit function declaration.*secure_getenv|
                         __libc_secure_getenv|incompatible integer to pointer.*secure_getenv
```

## 根因分析
musl libc 未实现 secure_getenv() 函数（glibc 扩展）。
                         部分软件（如含 gnulib 模块的项目）在非 _LIBC 构建中
                         通过 #define __libc_secure_getenv secure_getenv 调用此函数。
                         musl 中该函数不存在，导致编译报 "undeclared" 或
                         "incompatible integer to pointer conversion" 错误。

## 推荐方案
**方法**: source-patch

**说明**: 将 secure_getenv 降级为 getenv。两者功能类似（getenv 不做
                         setuid 安全检查），在鸿蒙上无 setuid 场景，降级安全。
                         修改方式：将 #define __libc_secure_getenv secure_getenv
                         改为 #define __libc_secure_getenv getenv

**验证/命令**:
```
sed -i 's/# define __libc_secure_getenv secure_getenv/# define __libc_secure_getenv getenv/' lib/tmpdir.c
```

## 错误特征
```
BASH_SOURCE.*empty|PYTHON_DIR.*empty|
                         environment variable.*not set.*activate
```

## 根因分析
鸿蒙 HiShell 的 /bin/sh 是 toybox ash,
                         不支持 bash 特有的 ${BASH_SOURCE} 变量。
                         脚本中 $(dirname "${BASH_SOURCE[0]}") 返回空值, 导致 PYTHON_DIR 为空

## 推荐方案
**方法**: source-patch

**说明**: POSIX 兼容方式: "$(cd "$(dirname "$0")" && pwd)" 替代
                         "$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

**验证/命令**:
```
rec_auto_fix:          true
```

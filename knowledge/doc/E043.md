# E043: activate.sh 中 ${BASH_SOURCE} 在 HiShell 不可用

> **结构化数据**: [graph/E043.kv](../graph/E043.kv) | **原则**: 无
> **严重度**: 🟢 low | **分类**: shell/compat/portability | **自动修复**: ✅ batch-sed

---

## 错误特征

```
source activate.sh
# 脚本执行但不报错，但环境变量未生效
# PYTHON_DIR 为空，后续的 PATH/LD_LIBRARY_PATH 设置全部指向错误路径
```

## 根因

鸿蒙 HiShell 的 `/bin/sh` 是 **toybox ash**，不支持 bash 特有的 `${BASH_SOURCE}` 变量。`${BASH_SOURCE[0]}` 在 toybox ash 下为空。

## 解决方案

```bash
# ❌ 不兼容 toybox ash
PYTHON_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

# ✅ 兼容 toybox ash / bash / dash
PYTHON_DIR="$(cd "$(dirname "$0")" && pwd)"
```

**原理**：`$0` 在所有 POSIX shell 中都可用，包含调用脚本时使用的路径。

## 禁止模式

❌ 鸿蒙目标平台脚本中使用 `${BASH_SOURCE}` → 值为空 → 所有路径变量失效

## 涉及软件

通用（所有为鸿蒙编写 shell 脚本时都需要注意）。

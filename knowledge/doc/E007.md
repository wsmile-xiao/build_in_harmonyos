# E007: patch-autotools-script

## 基本信息

- **类别**: autotools, configure

- **来源 PR**: source_commit:

## 错误特征
```
cannot guess build type|unable to guess system type|
                         config.guess.*unable|cannot guess.*build type|
                         Invalid configuration.*guess|invalid triplet.*ohos|
                         OS ohos not recognized
```

## 根因分析
GNU config.guess 脚本不包含 HarmonyOS/__OHOS__ 检测分支。
                         uname -s 返回 HarmonyOS 无法匹配任何已知系统模式,
                         configure 在第一阶段就中断编译流程。
                         若用 --build/--host 绕过则误判为交叉编译,
                         导致 AC_RUN_IFELSE 等全部跳过, 生成错误 config.h

## 推荐方案
**方法**: patch-autotools-script

**说明**: 用内置补丁脚本 patch-autotools-ohos.pl 一键打补丁:
                         config.guess 两处修改(§2.1 LIBC检测 + §2.2 系统识别case分支),
                         config.sub 三处修改(§3.1 ohos-linux + §3.2 OS列表 + §3.3 内核列表)。
                         否则会报 "OS ohos not recognized" 错误。
                         输出标准三元组 aarch64-unknown-linux-ohos

**验证/命令**:
```
perl ${SKILL_ROOT}/scripts/patch-autotools-ohos.pl \
                           build-aux/config.guess build-aux/config.sub
```

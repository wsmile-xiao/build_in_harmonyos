# E003: 找不到 pthread

> **结构化数据**: [graph/E003.kv](../graph/E003.kv) | **原则**: P-CFLAGS-001
> **严重度**: 🟡 medium | **分类**: linking | **自动修复**: ✅ set-env-var(-pthread)

---

## 错误特征

```
undefined reference to `pthread_create`
undefined reference to `pthread_mutex_lock`
ld.lld: error: undefined symbol: pthread_create
```

## 根因

链接阶段未传递线程库标志。`-pthread` 同时作用于编译阶段（定义 `_REENTRANT` 等宏）和链接阶段（添加 `-lpthread`），是 POSIX 标准推荐方式。

## 验证命令

```bash
# 检查目标文件是否引用 pthread
nm libxxx.a | grep pthread
readelf -d ./binary | grep NEEDED | grep pthread
```

## 解决方案

### 方案 1（推荐，优先级 1）：添加 `-pthread` 到 CFLAGS

```bash
export CFLAGS="-pthread $CFLAGS"
```

`-pthread` 是 POSIX 标准推荐方式，同时处理：
- **编译期**：定义 `_REENTRANT`、`_THREAD_SAFE` 等宏
- **链接期**：自动添加 `-lpthread`

### 方案 2（回退）：仅链接期添加 `-lpthread`

```bash
export LDFLAGS="-lpthread $LDFLAGS"
```

**权衡**：只解决链接问题，不处理编译期宏定义。某些代码可能因为缺少 `_REENTRANT` 宏而行为异常。

## 涉及软件

所有使用 POSIX 线程的 C/C++ 项目。

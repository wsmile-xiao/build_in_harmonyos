```
undefined reference.*pthread_create|

```

## 根因分析
链接阶段未指定线程库依赖,
                         鸿蒙 clang 需要显式传递 -pthread 标志
                         (同时影响编译器预定义和链接器搜索)

## 推荐方案
**方法**: add-cflags

**说明**: 添加 -pthread 到 CFLAGS (编译+链接双效)

**验证/命令**:
```
CFLAGS="-pthread $CFLAGS"
```

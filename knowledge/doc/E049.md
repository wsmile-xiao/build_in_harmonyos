# E049: shebang-portable-fix

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, shell
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
shebang.*hardcoded.*path|interpreter.*not found.*shebang|
                         #!.*/data/service/|#!.*/usr/local/
```

## 根因分析
构建脚本(如 automake 的 gen-all.pl)在生成输出脚本时,
                         将解释器路径硬编码到 shebang 中。
                         生成的 bin/automake、bin/aclocal 等第一行变成硬编码路径, 换机即失效

## 推荐方案
**方法**: shebang-portable-fix

**说明**: 两步修复:
                         1) 已有硬编码 shebang → 改为 #!/bin/env xxx (可移植格式)
                         2) 新生成脚本 → 确保 gen-all.pl 等生成器输出 #!/bin/env 格式

**验证/命令**:
```
sed -i 's|^#!.*perl.*$|#!/usr/bin/env perl|' bin/automake bin/aclocal
```

# E376: Bind an empty CMake library cache only when target math symbols need no separate libm

## 基本信息
- **严重度**: 3
- **类别**: cmake, toolchain, linking, cache, libm
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5392

## 错误特征
```
NIFTI_SYSTEM_MATH_LIB.*NOTFOUND|linked by target.*ITKniftiio.*NOTFOUND
```

## 根因分析
An upstream find_library(m) assumption leaves a NOTFOUND cache entry on targets where required math symbols link without a separate discoverable libm, poisoning a target link interface.

## 推荐方案
**方法**: target-evidence-bound-empty-library-cache

**说明**: Prefer a narrow recipe or toolchain cache binding to an upstream platform patch after exact target evidence proves the required symbols link without a separate library.

**验证/命令**:
```
Set only the affected CMake cache variable to the empty string for the proven target configuration and rerun configure plus the real link.
```

# E371: Validate directory-rooted readback archives by exact member type sets

## 基本信息
- **严重度**: 2
- **类别**: readback-archive-contract
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5532

## 错误特征
```
terminal readback tar closure invalid|unsafe or duplicate readback member|archive directory set drift
```

## 根因分析
Archiving a result directory by name emits mandatory root and subdirectory records, but a regular-file-only predicate or pathname regex can reject those valid directory members after the target and release already completed.

## 推荐方案
**方法**: exact-directory-and-regular-file-whitelists

**说明**: Separate directory and regular-file contracts, require canonical unique in-root names, verify sizes and hashes only for regular files, and preserve the consumed failure while reconciling a proven postrelease PASS without relaunch.

**验证/命令**:
```
python -B validate_readback.py --tar result-readback.tar --attempt-root attempt --claim-root claim --output reconciliation.json
```

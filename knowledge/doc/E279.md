# E279: 跨补丁引擎的上下文锚定补丁

## 基本信息
- **严重度**: 2
- **类别**: portability, patch
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: 2103

## 错误特征
```
config\.guess: line [0-9]+:.*HarmonyOS|cannot guess build type
```

## 根因分析
零上下文补丁块只依赖行号，GNU patch 与 patch-ng 可能将其插入不同语法层级。

## 推荐方案
**方法**: context-anchored-patch

**说明**: 补丁块同时包含修改点前后的稳定上下文并使用两种补丁引擎验证。

**验证/命令**:
```
patch --fuzz=0 -p1 < fix.patch && sh -n config.guess
```

## 关键词
patch-ng, zero-context hunk, config.guess, context anchor

# E165: shebang-fix

## 基本信息
- **严重度**: 3
- **类别**: platform
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
bad interpreter: /bin/bash: no such file or directory|configure 失败 \(exit 127\)|#!/bin/bash|^#! /bin/bash
```

**关键词**: shebang, bash, interpreter, configure failed, exit 127, bin/bash, bin/sh, OpenHarmony, HongMeng

## 根因分析
OpenHarmony 系统没有传统的 /bin 目录，bash 位于 /data/service/hnp/bin/bash，sh 位于 /system/bin/sh。脚本 shebang 指向不存在的路径导致脚本无法执行。

**影响范围**: 所有使用 #!/bin/bash 或 #!/bin/sh 作为 shebang 的脚本文件，特别是 configure、install.sh、shorewall 等构建和运行脚本

## 推荐方案
- **方法**: shebang-fix
- **描述**: 修改脚本 shebang：/bin/bash -> /data/service/hnp/bin/bash，/bin/sh -> /system/bin/sh
- **命令**: `sed -i '1s|#!/bin/bash|#!/data/service/hnp/bin/bash|' configure; sed -i '1s|#!/bin/sh|#!/system/bin/sh|' install.sh shorewall uninstall.sh wait4ifup`
- **自动修复**: true

## 验证
```bash
head -1 configure install.sh shorewall | grep -E "hnp/bin/bash|system/bin/sh"
```

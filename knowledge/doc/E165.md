# E165: shebang-fix

## 基本信息
- **严重度**: 3
- **类别**: platform
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
bad interpreter: /bin/bash: no such file or directory|configure 失败 \(exit 127\)|#!/bin/bash|^#! /bin/bash
```

## 根因分析
OpenHarmony 系统没有传统的 /bin 目录，bash 位于 /data/service/hnp/bin/bash，sh 位于 /system/bin/sh。脚本 shebang 指向不存在的路径导致脚本无法执行。

## 推荐方案
**方法**: shebang-fix

**说明**: 修改脚本 shebang：/bin/bash -> /data/service/hnp/bin/bash，/bin/sh -> /system/bin/sh

**验证/命令**:
```
sed -i '1s|#!/bin/bash|#!/data/service/hnp/bin/bash|' configure; sed -i '1s|#!/bin/sh|#!/system/bin/sh|' install.sh shorewall uninstall.sh wait4ifup
```

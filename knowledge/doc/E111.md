## 错误特征
```
"krb5-config: inaccessible or not found|ModuleNotFoundError: No module named 'gssapi'|pip install requests_gssapi.*failed"
```

## 根因分析
"Python包（如requests_gssapi、python-ldap等）依赖系统C库进行编译，而非纯Python包。这些包需要系统提供对应的开发库（如krb5、ldap等）才能成功编译安装。缺少系统库会导致pip安装失败，即使使用国内镜像也无法解决。"

## 推荐方案
**方法**: add-deps

**说明**: "Python包依赖系统库的情况需要先编译系统库依赖。解决方案：1) 检查cmd-pkgs是否有预编译的系统库；2) 如果没有，创建子任务编译系统库（如krb5）；3) 系统库安装完成后，再编译Python绑定包（如gssapi）；4) 最后才能编译目标Python包（如cepces）。"

**验证/命令**:
```
"python3 scripts/ohc-run.py resolve-deps --list-available --refresh | grep krb5; 如果没有预编译包，通知主任务创建子任务编译 krb5"
```

# E204: fix-tarball-and-specify-target

## 基本信息
- **严重度**: 2
- **类别**: build-system

## 错误特征
```
build/make/configure.sh.*No such file|Unknown target
```

**关键词**: libvpx, configure.sh, target, arm64-linux-gcc, custom configure

## 根因分析
libvpx 使用自定义 configure 脚本（非标准 autotools），需要指定 --target 参数。

**影响范围**: libvpx 所有版本

# E204: fix-tarball-and-specify-target

## 基本信息

## 错误特征
```
build/make/configure.sh.*No such file|Unknown target
```

## 根因分析
libvpx 使用自定义 configure 脚本（非标准 autotools），需要指定 --target 参数。
                        GitHub tarball 可能缺少 build/make/ 目录。

## 推荐方案
**方法**: fix-tarball-and-specify-target

**说明**: 1. 检查 build/make/ 目录是否存在，缺失则从 orig 复制
  2. 使用 --target=arm64-linux-gcc 参数（不是 --host/--build）

**验证/命令**:
```
|
  # Step 1: 修复缺失目录
  if [ ! -d "build/make" ]; then
    cp -r "$BUILD_SRC_ORIG_DIR/build" ./
  fi
  
  # Step 2: configure
  ./configure --prefix=$DEFAULT_PREFIX --target=arm64-linux-gcc
```

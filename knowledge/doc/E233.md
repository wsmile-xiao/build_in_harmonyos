# E233: Gate unsupported RDHUP early-close advertisement on HarmonyOS poll and epoll

## 基本信息
- **严重度**: 2
- **类别**: ohos, socket, runtime
- **作者**: 2301_80739235 <goblinrs@yeah.net>
- **来源 PR**: source_commit:

## 错误特征
```
test-closed__|regress__|simpleclose_close|simpleclose_shutdown|EV_FEATURE_EARLY_CLOSE
```

## 根因分析
HarmonyOS headers define POLLRDHUP and EPOLLRDHUP, while libevent derives the poll feature and hard-codes the epoll feature; the tested native backends do not deliver the corresponding half-close semantics.

## 推荐方案
**方法**: ohos-rdhup-capability-gate

**说明**: Under __OHOS__, define the poll and epoll RDHUP feature values as zero and use the derived value in each backend feature table.

**验证/命令**:
```
Patch poll.c and epoll.c under __OHOS__ guards, rebuild from the official archive, and rerun targeted plus complete native suites.
```

# E482: zsh heredoc 用 $TMPPREFIX（默认 /tmp/zsh）创建临时文件，/tmp 只读时失败

## 基本信息
- **严重度**: 2
- **类别**: environment
- **作者**: MakeBlackSheepGreat <yzj876762330@163.com>
- **来源 PR**: !5848

## 错误特征
```
can't create temp file for here document|read-only file system|here document
```

## 根因分析
鸿蒙系统 /tmp 是只读，而 zsh 的 heredoc（<<'EOF'）临时文件目录由
                        $TMPPREFIX 决定（默认 /tmp/zsh），**不随 $TMPDIR 变化**。
                        只设 TMPDIR 无法解决 zsh heredoc 失败；症状是脚本静默退出
                        （set -e 下），报 "can't create temp file for here document: read-only file system"。

## 推荐方案
**方法**: set-env-var

**说明**: 同时设置 TMPDIR 与 TMPPREFIX 指向可写目录

**验证/命令**:
```
TMPDIR=$HOME/tmp TMPPREFIX=$HOME/tmp/zsh zsh build_and_test.sh
```

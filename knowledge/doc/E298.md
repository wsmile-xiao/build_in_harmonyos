# E298: Conan test_package 的显式运行与环境

## 基本信息

- **作者**: 2301_80739235 <2047361658@qq.com>

## 错误特征
```
Error loading shared library|
                         cannot open shared object file|
                         shared library not found|
                         command not found
```

## 根因分析
cmake.test() 把执行委托给 CTest，配方无法显式控制和审计 conanrun 环境；
                         消费者需要包内动态库或 CLI 时可能因运行时搜索路径缺失而失败。

## 推荐方案
**方法**: virtual-run-env-explicit-run

**说明**: 生成 VirtualRunEnv，并在 test() 中使用 self.run(..., env='conanrun') 显式执行消费者。

**验证/命令**:
```
generators = 'CMakeDeps', 'CMakeToolchain', 'VirtualRunEnv'; self.run(f'"{test_bin}"', env='conanrun', cwd=self.build_folder)
```

## 根因分析
OHOS 沙箱/无硬件环境（无 JTAG ICE/USB 调试器等外设）——库（avarice——
  AVR JTAG ICE 调试器——连接 GDB 与 Atmel AVR JTAG ICE）依赖硬件外设库
  （libusb-0.1——USB 接口——libusb_open/usb_get_string_simple 等）——
  configure 的 AC_CHECK_LIB([usb], [usb_get_string_simple]) 检查不硬失败（无
  AC_MSG_ERROR——configure 能过）——但编译（jtag2usb.cc——#include <usb.h>——
  15 个 usb_* API）需要外设库的头文件 + 链接符号——无硬件环境下外设库依赖
  无法满足（libusb-compat 无配方/不在制品仓——无法直接依赖）

## 推荐方案
**方法**: stub 绕过（生成 stub 外设头（声明外设 API）+ stub 实现（返回
  -1/0——无硬件——功能不实际使用）——CPPFLAGS -I stub + 编译 stub 对象 +
  链接追加（make LIBS/LDFLAGS））

**说明**: >
  stub 绕过（生成 stub 外设头（声明外设 API）+ stub 实现（返回 -1/0——无硬件——功能不实际使用）——CPPFLAGS -I stub + 编译 stub 对象 + 链接追加（make LIBS/LDFLAGS））

**验证/命令**:
```
|
  # 生成 stub 头（声明外设 API——libusb-0.1 的 15 个 usb_*）+ stub 实现
  # （返回 -1/0——无硬件——功能不实际使用——R9/R34 合规如实记录）
  stub_dir = os.path.join(build_folder, "stub"); os.makedirs(stub_dir, exist_ok=True)
  # stub usb.h：typedef struct usb_device usb_dev_handle; + usb_init/usb_find_busses/
  #   usb_find_devices/usb_get_busses/usb_open/usb_close/usb_get_string_simple/
  #   usb_bulk_read/usb_bulk_write/usb_claim_interface/usb_release_interface/
  #   usb_resetep/usb_set_configuration/usb_error/usb_daemon 声明
  # stub usb_stub.c：各函数返回 0/-1（无硬件）
  clang -c stub/usb_stub.c -I stub -o stub/usb_stub.o
  CPPFLAGS += -I stub_dir          # 编译源文件找到 stub 头
  make LIBS='... {stub_dir}/usb_stub.o'   # 链接满足 usb_* 符号
```

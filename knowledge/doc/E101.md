# E101: set-env-var

## 基本信息
- **严重度**: 2
- **类别**: platform, compat
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
fatal: detected dubious ownership in repository at|dubious ownership|safe.directory
```

## 根因分析
git 2.35+ 引入的安全特性检查仓库目录 owner 是否与当前用户一致，HMDFS 文件系统的 UID 映射机制导致目录 owner 和当前用户不一致，git 检测到不匹配后拒绝执行命令

## 推荐方案
**方法**: set-env-var

**说明**: 创建系统级 gitconfig 文件配置 safe.directory = *，或通过预编译包内置 etc/gitconfig 配置文件自动解决此问题

**验证/命令**:
```
# verify with: conan create . --build=missing
```

## 关键词
git, safe.directory, dubious ownership, HMDFS, UID, permission

# E101: git safe.directory 权限检查在 HMDFS 上失败

## 错误特征
```
fatal: detected dubious ownership in repository at '...'
To add an exception for this directory, call:
    git config --global --add safe.directory ...
```

## 根因
git 2.35+ 检查仓库目录 owner 与当前用户是否一致。HMDFS 的 UID 映射导致不匹配。

## 解决方案
创建 `~/usr/local/etc/gitconfig`：
```
[safe]
    directory = *
```
预编译包应内置此配置。

## 受影响软件
所有在 HMDFS 上的 git 仓库

---
**发现于**: git 2.49.0，HMDFS 文件系统

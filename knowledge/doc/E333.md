# E333: ci/conan/build_and_test.sh 的 pre-download 脚本用正则 [^\s"'-]+ 提取

## 基本信息
- **严重度**: 2
- **类别**: python, ci-script, package, url-truncation
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>
- **来源 PR**: !4958

## 错误特征
```
FileNotFoundError: \[Errno 2\] No such file or directory: '.*predl_cache.*\.tar\.gz'|conan create failed|NoSuchKey
```

## 根因分析
ci/conan/build_and_test.sh 的 pre-download 脚本用正则 [^\s"'-]+ 提取 conandata.yml 源码 URL，
  该字符类排除连字符 '-'，导致 PyPI 文件名含连字符的 sdist URL（aiven_client-4.16.0.tar.gz）被截断为
  .../aiven_client。若截断 URL 返回 >100 字节 body（PyPI 哈希目录 URL 返回 359 字节 NoSuchKey XML），
  CI 误判"下载成功"并改写 conandata.yml 为 file://.../predl_cache/{hash}_{截断名}-版本.tar.gz
  （指向不存在的文件）→ conan create FileNotFoundError。若截断 URL 返回 0 字节
  （/packages/source/ 形式 URL），CI 判定失败、不改写 conandata.yml，conan 用官方 URL 直接下载成功。

## 推荐方案
**方法**: url_form（conandata.yml 改用 /packages/source/ 官方 URL，sha256 与哈希目录 sdist 完全一致）

**说明**: >
  将 conandata.yml 源码 URL 改用 PyPI 官方 /packages/source/ 形式 URL，规避 CI pre-download 正则对连字符文件名的截断误判

**验证/命令**:
```
"https://files.pythonhosted.org/packages/source/{letter}/{name}/{name}-{version}.tar.gz"
```

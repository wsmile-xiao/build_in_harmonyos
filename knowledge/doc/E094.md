## 根因分析
pthread_attr_setaffinity_np() 是 GNU 扩展函数，
                        用于设置线程的 CPU 亲和性（affinity）。
                        musl libc 不实现此函数（不带 _np 后缀的
                        POSIX 标准版也不存在）。
                        软件源码中直接调用此函数时，
                        musl 环境下无此符号声明和定义，
                        导致编译或链接失败。

## 推荐方案
**方法**: source-patch

**说明**: 使用 #ifdef __OHOS__ 条件编译跳过
                        pthread_attr_setaffinity_np() 调用，
                        或使用 sched_setaffinity() 替代。
                        在 HarmonyOS 上线程亲和性通常不是必需功能，
                        跳过调用不影响正确性。

**验证/命令**:
```
|
                        #ifndef __OHOS__
                            pthread_attr_setaffinity_np(&attr, sizeof(cpu_set_t), &cpuset);
                        #else
                            /* thread affinity not supported on OHOS/musl */
                        #endif
```

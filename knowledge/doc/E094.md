# E094: musl 缺 pthread_attr_setaffinity_np()

> **结构化数据**: [graph/E094.kv](../graph/E094.kv)
> **严重度**: 🟡 medium | **分类**: libc-compat|musl|threading | **自动修复**: ❌ source-patch

---

## 错误特征

编译阶段：
```
warning: implicit declaration of function 'pthread_attr_setaffinity_np' is invalid in C99
```

链接阶段：
```
undefined reference to 'pthread_attr_setaffinity_np'
```

## 根因

`pthread_attr_setaffinity_np()` 是 GNU 扩展函数（`_np` 后缀表示 non-portable），
用于设置线程的 CPU 亲和性（CPU affinity），即将线程绑定到特定 CPU 核心上运行。

musl libc 不实现此函数。软件源码中直接调用此函数时，musl 环境下无此符号声明和定义，
导致编译或链接失败。

## 影响范围

需要设置线程 CPU 亲和性的软件。已知受影响：
- **blosc** — 高性能压缩库（使用线程亲和性优化压缩并行度）

## 解决方案

### 方案 1（推荐）：条件编译跳过

使用 `#ifdef __OHOS__` 守卫，跳过 `pthread_attr_setaffinity_np()` 调用：

```c
#ifndef __OHOS__
    pthread_attr_setaffinity_np(&attr, sizeof(cpu_set_t), &cpuset);
#else
    /* thread affinity not supported on OHOS/musl */
#endif
```

在 HarmonyOS 上线程亲和性通常不是必需功能，跳过调用不影响程序正确性。
修改后需 `track-edit add` 记录。

### 方案 2：使用 sched_setaffinity 替代

如果确实需要 CPU 亲和性功能，可以使用 `sched_setaffinity()` 替代：

```c
#ifndef __OHOS__
    pthread_attr_setaffinity_np(&attr, sizeof(cpu_set_t), &cpuset);
#else
    cpu_set_t cpuset;
    CPU_ZERO(&cpuset);
    CPU_SET(core_id, &cpuset);
    sched_setaffinity(0, sizeof(cpuset), &cpuset);
#endif
```

### 方案 3（快速）：CFLAGS 宏替代

```bash
CFLAGS="$CFLAGS -Dpthread_attr_setaffinity_np\\(a,b,c\\)=0"
```

## 验证

```bash
# 确认 musl 无此函数
echo '#include <pthread.h>
int main(){pthread_attr_setaffinity_np(NULL,0,NULL);}' | cc -xc - -c 2>&1 | grep pthread_attr_setaffinity

# 编译通过即修复成功
make -j$(nproc)
```

## ⛔ 禁止

- **不要**使用 `-DHAVE_PTHREAD_ATTR_SETAFFINITY_NP` 强制声明函数存在，musl 无此符号会导致链接失败。

## 补充：CPU 亲和性 API 完整缺失列表

musl libc 不仅缺少 `pthread_attr_setaffinity_np()`，还缺少整套 Linux CPU 亲和性相关的
宏定义、类型和函数声明。以下是完整缺失列表：

### 缺失的宏/类型

| 宏/类型 | 用途 | 定义来源(glibc) |
|---------|------|----------------|
| `CPU_SETSIZE` | cpu_set_t 中的 CPU 位数上限 | `<sched.h>` |
| `cpu_set_t` | CPU 亲和性掩码结构体 | `<sched.h>` |
| `CPU_ZERO()` | 清零掩码 | `<sched.h>` |
| `CPU_SET()` | 设置指定 CPU 位 | `<sched.h>` |
| `CPU_CLR()` | 清除指定 CPU 位 | `<sched.h>` |
| `CPU_ISSET()` | 测试指定 CPU 位 | `<sched.h>` |
| `CPU_COUNT()` | 统计掩码中 CPU 数量 | `<sched.h>` |
| `CPU_AND()` / `CPU_OR()` / `CPU_XOR()` | 位运算 | `<sched.h>` |
| `CPU_EQUAL()` | 比较两个掩码 | `<sched.h>` |

### 缺失的函数

| 函数 | 用途 |
|------|------|
| `pthread_attr_setaffinity_np()` | 设置线程属性中的 CPU 亲和性 |
| `pthread_attr_getaffinity_np()` | 获取线程属性中的 CPU 亲和性 |
| `sched_setaffinity()` | 设置进程/线程 CPU 亲和性 |
| `sched_getaffinity()` | 获取进程/线程 CPU 亲和性 |

### 受影响软件扩展

- **blosc** — 使用 `pthread_attr_setaffinity_np()` 优化压缩并行度
- **libuv** — Node.js 底层事件循环库，使用 `CPU_SET`/`CPU_ZERO` 等宏
- **nginx** — 使用 `sched_setaffinity()` 绑定 worker 进程到 CPU 核心
- **redis** — 使用 `sched_getaffinity()`/`sched_setaffinity()` 进行 CPU 亲和性优化

### ⛔ 禁止手动定义

不要在源码中自行 `typedef cpu_set_t` 或 `#define CPU_SETSIZE` 等。这些定义与内核
`<sched.h>` 中的原始布局必须精确匹配，否则会导致 ABI 问题（掩码大小不一致，
`sched_setaffinity()` 系统调用可能截断或越界访问）。

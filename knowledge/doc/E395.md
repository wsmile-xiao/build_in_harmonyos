# E395: Remove dangling package aliases with explicit symlink detection

## 基本信息
- **严重度**: 2
- **类别**: python, conan, symlink, package-integrity
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5822

## 错误特征
```
dangling symbolic link remains after target removal|broken symlink survives package cleanup|Path.is_file returns false for dangling symlink
```

## 根因分析
Python Path.is_file() follows a symbolic link and returns false after its target has been removed. Cleanup code guarded only by is_file() therefore skips a dangling alias even though the directory entry remains and may still be recorded in the package manifest.

## 推荐方案
**方法**: explicit-file-or-symlink-unlink

**说明**: For each prohibited package path, unlink it when Path.is_file() or Path.is_symlink() is true. Keep the path list explicit, then validate both normal files and deliberately dangling aliases with a negative package-integrity test.

**验证/命令**:
```
|
  path = Path(package_folder, "lib", "obsolete-alias")
  if path.is_file() or path.is_symlink():
      path.unlink()
```

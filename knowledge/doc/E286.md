# E286: OHOS SDK LLVM 15 缺失完整 LLVM 插件/lit/TableGen 组件，导致 enzyme 等 LLVM pass/plugin 类库无法完整构建与运行上游测试

## 基本信息
- **严重度**: 3
- **类别**: ohos, cmake, toolchain, llvm, testing
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: 2786

## 错误特征
```
Library.*LLVMExports.*not found|LLVMDemangle.*not found|symbol not found.*_ZN4llvm|Error relocating.*libLLVMEnzyme|handleBLAS.*undeclared|attributeTablegen.*undeclared|tablegen stub failed|llvm-tblgen.*not found|FileCheck.*not found|lit.*not found|LLVMConfig.cmake.*FATAL_ERROR|add_llvm_library|configure_lit_site_cfg|llvmGetPassPluginInfo
```

## 根因分析
OHOS SDK LLVM 15 (/data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/) 仅提供单体共享库 libLLVM-15.so 与基本 clang/lld，但缺失 LLVM AutoDiff 插件类库所需的完整组件：(1) LLVMExports.cmake 引用不存在的 .a stub 文件（LLVMDemangle.a/LLVMSupport.a/LLVMCore.a 等），CMake 在 find_package(LLVM) 时触发 FATAL_ERROR；(2) 无 llvm-tblgen 二进制，导致 Enzyme 的 TableGen 描述（BlasDerivatives.td/CallDerivatives.td 等）无法生成 .inc 文件，编译时 handleBLAS/attributeTablegen 等 undeclared；(3) 无 lit/FileCheck/llvm-lit，上游 1523 个 lit 测试用例无法执行；(4) 单体 libLLVM-15.so 未导出部分 LLVM C++ API 符号（如 llvm::cl::Option::setArgStr），导致 dlopen 加载 Enzyme 插件库时 symbol not found。现有知识库 E120/E132 仅覆盖 lld/libxml2/LD_LIBRARY_PATH 类运行时路径问题，未覆盖 LLVMExports .a stub/LLVMDemangle/TableGen/tblgen/lit/FileCheck/符号导出 的组合问题。

## 推荐方案
**方法**: cmake-overlay-with-stub-tblgen-and-skip-lit

**说明**: 1) 提供 cmake-overlay/LLVMConfig.cmake 覆盖 OHOS SDK 的 LLVMConfig.cmake，跳过引用不存在 .a stub 的 LLVMExports.cmake，改为创建指向单体 libLLVM-15.so 的 IMPORTED target（LLVM/LLVMDemangle/LLVMSupport/LLVMCore/LLVMTransformUtils/LLVMAnalysis）；2) 提供 cmake-overlay/AddLLVM.cmake stub 实现 tablegen()/add_llvm_library()/add_public_tablegen_target()/configure_lit_site_cfg()/get_llvm_lit_path() 等 Enzyme 构建所需的 LLVM CMake 函数；3) 提供 cmake-overlay/stub-tblgen.sh（需 chmod +x）生成最小 .inc 桩文件，为 BlasDerivatives.inc 提供 return false 的 handleBLAS、为 BlasAttributor.inc 提供 return false 的 attributeTablegen 等，使源码编译通过；4) build() 中跳过 enzyme/test 子目录（lit 测试体系无法在 OHOS 上运行）；5) conanfile.py export_sources/source() 复制 overlay 到源码树，generate() 设 LLVM_DIR 指向 overlay；6) test_package 用 dlopen(libLLVM-15.so, RTLD_GLOBAL) 预加载 LLVM 符号 + dlopen(libLLVMEnzyme-15.so) + dlsym(llvmGetPassPluginInfo) + 实际调用验证插件入口可执行；7) runtime 加载仍可能因单体 .so 未导出部分 C++ 符号而 symbol not found——此为 OHOS SDK LLVM 工具链缺口，记录为路径 C 候选需官方确认。

**验证/命令**:
```
conan create archives/e/enzyme/0.0.284 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing --user=ohpcd --channel=stable
```

# E339: Bundled Waf 2.0.x uses removed Python imp module

## 基本信息
- **严重度**: 2
- **类别**: compat, build-system, python, waf
- **作者**: asp1r1n1 <912802346@qq.com>
- **来源 PR**: !3482

## 错误特征
```
ModuleNotFoundError: No module named 'imp'|AttributeError: module 'imp' has no attribute 'new_module'|waflib/Context\.py.*imp
```

## 根因分析
Older bundled Waf releases import imp and call imp.new_module(), but Python 3.12 removed the imp module. The build fails before project configuration although the project source and compiler are otherwise valid.

## 推荐方案
**方法**: replace-imp-new-module

**说明**: Patch only the bundled Waf module loader: replace imp.new_module(name) with types.ModuleType(name), retain the existing exec() and module-cache behavior, and syntax-check the patched module with the target Python.

**验证/命令**:
```
sed -i 's/import os, re, imp, sys/import os, re, sys\\nfrom types import ModuleType/; s/imp.new_module(WSCRIPT_FILE)/ModuleType(WSCRIPT_FILE)/' waflib/Context.py && python3 -m py_compile waflib/Context.py
```

## 错误特征
```
assembler error.*unknown instruction|
                         selected processor does not support|
                         invalid instruction.*ARM|
```

## 根因分析
项目内嵌的汇编代码使用了目标平台(aarch64)
                         不支持的指令集或编码方式,
                         或 configure 未正确识别目标架构导致选错汇编路径

## 推荐方案
**方法**: reconfigure-no-asm

**说明**: 禁用汇编优化, 回退到纯 C 实现

**验证/命令**:
```
./configure --disable-asm (通用) 或 ./Configure no-asm (OpenSSL)
```

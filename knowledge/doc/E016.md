# E016: 汇编代码错误

> **结构化数据**: [graph/E016.kv](../graph/E016.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: asm/compat | **自动修复**: ✅ reconfigure

---

## 错误特征

```
assembler error: unknown instruction
Error: selected processor does not support ARM mode
```

## 根因

项目内嵌的汇编代码使用了目标平台（aarch64）不支持的指令集或编码方式。

## 解决方案

```bash
# 通用 autotools 项目
./configure --disable-asm

# OpenSSL 特例 (详见 E006)
./Configure ... no-asm
```

## 关系图

- **causes → [E006](E006.md)**：本模式在 OpenSSL 上表现为 BAD_SIGNATURE 运行时错误
- **similar_to → [E006](E006.md)**：同为 asm 兼容问题

## 涉及软件

OpenSSL、libx264、任何包含手写 ARM 汇编的 C/C++ 库。

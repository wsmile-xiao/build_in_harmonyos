# E006: reconfigure-no-asm

## 基本信息
- **严重度**: 3
- **类别**: asm, security
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
SSL.*BAD_SIGNATURE.*bad signature|
                         RSA_verify_PKCS1_PSS_mgf1.*last octet invalid|
                         tls_process_cert_verify.*bad signature
```

## 根因分析
OpenSSL 的 ARM64 汇编优化代码在 RSA-PSS
                         签名验证时存在 bug，导致签名校验失败，
                         影响 pip/https 下载等所有 TLS 连接

## 推荐方案
**方法**: reconfigure-no-asm

**说明**: 使用 no-asm 重新编译 OpenSSL，禁用汇编优化

**验证/命令**:
```
./Configure --prefix=$HOME/usr/local --openssldir=$HOME/usr/local/ssl no-asm && make clean && make && make install
```

OpenSSL, BAD_SIGNATURE, RSA_verify, PSS,
                         no-asm, ARM64, assembly, ssl.SSLError,
                         cert_verify, last octet invalid

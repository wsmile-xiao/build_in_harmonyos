# E152: add-cflags

## 基本信息
- **严重度**: 2
- **类别**: libc|compat|posix
- **触发工具**: cc|clang|cmake
- **阶段**: compilation

## 错误特征
```
undeclared identifier 'CLOCK_REALTIME'|undeclared identifier 'CLOCK_MONOTONIC'|call to undeclared function 'clock_gettime'
```

**关键词**: CLOCK_REALTIME,CLOCK_MONOTONIC,clock_gettime,undeclared identifier,musl,POSIX timer

## 根因分析
musl libc 需要显式包含 time.h 头文件并可能需要 _GNU_SOURCE 宏来启用 POSIX 定时器常量（CLOCK_REALTIME=0, CLOCK_MONOTONIC=1）。glibc 会自动定义这些常量，但 musl 更严格。

**影响范围**: 使用 POSIX 定时器 API 的软件（glfw, sdl, 等图形库；需要高精度定时器的应用）

## 推荐方案
- **方法**: add-cflags
- **描述**: 添加 #include <time.h> 到源文件，并添加 -D_GNU_SOURCE 到编译器标志（CMake: -DCMAKE_C_FLAGS="-D_GNU_SOURCE"，Autotools: CFLAGS="-D_GNU_SOURCE"）
- **命令**: `在 posix_time.c 或类似文件中添加 #include <time.h>`
- **自动修复**: false

## 验证
```bash
grep -n "time.h" src/posix_time.c && grep "GNU_SOURCE" CMakeLists.txt || grep "GNU_SOURCE" configure.ac
```

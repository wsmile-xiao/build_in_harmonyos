## 错误特征
```
make.*-j.*hang|make.*stuck|FIFO.*Permission denied|jobserver.*fifo|cannot make pipe|pipe.*failed
```

## 根因分析
鸿蒙 SELinux 策略禁止用户进程创建 FIFO（命名管道）。
                        GNU make 的 jobserver 机制依赖 FIFO 在父子进程间传递并行任务令牌，
                        FIFO 创建失败导致 make -j 卡住或报错退出。

## 推荐方案
**方法**: env-var-override

**说明**: 强制单线程编译，绕过 jobserver FIFO 机制。

**验证/命令**:
```
make -j1
```

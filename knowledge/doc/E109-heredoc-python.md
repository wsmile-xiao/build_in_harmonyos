## 错误特征

```bash
# configure 使用 heredoc 创建配置文件
cat > config.mak << EOF
PREFIX=/usr/local
EOF

# HMDFS 上报错
./configure: cannot create temp file for here-document: Permission denied
# 或生成的文件内容不完整（只有几行）
```

## 根因

HMDFS 不支持 shell heredoc（`cat << EOF`）语法，但 Python 的文件写入操作不受限制。
利用 Python 作为替代方案，可绕过 HMDFS 的 heredoc 限制。

## 影响范围

所有使用 heredoc 创建配置文件的 autotools 项目：
- x264、ffmpeg、libav、smartmontools 等
- 任何 `configure + Makefile` 项目

## 解决方案（⭐ 推荐）

### Python 替代脚本模板

```python
#!/usr/bin/env python3
"""
create_config.py — 替代 configure 的 heredoc 部分
适用于 HMDFS 等不支持 heredoc 的文件系统
"""

import os
import sys

# 从环境变量获取安装前缀
prefix = os.environ.get('DEFAULT_PREFIX', '~/usr/local')
if prefix.startswith('~'):
    prefix = os.path.expanduser(prefix)

print(f"Creating configuration files for prefix={prefix}")

# ═══ Step 1: 创建 config.h ═══
config_h_content = f"""/* Generated by create_config.py for HMDFS */
#define HAVE_MALLOC_H 1
#define HAVE_MMAP 1
#define HAVE_VLA 1
#define HAVE_INTTYPES_H 1
#define HAVE_STDINT_H 1
#define HAVE_STRING_H 1
#define HAVE_STDLIB_H 1
#define HAVE_STDIO_H 1

#define ARCH_AARCH64 1
#define SYS_LINUX 1
#define HAVE_POSIX_THREAD 1

#define PREFIX "{prefix}"
#define X264_BUILD 165
#define X264_VERSION "0.165.x"
"""

with open('config.h', 'w') as f:
    f.write(config_h_content)
print("✓ Created config.h")

# ═══ Step 2: 创建 config.mak ═══
config_mak_content = f"""# Generated by create_config.py for HMDFS
PREFIX={prefix}
CC=clang
CFLAGS=-O2 -fPIC -Wall
LDFLAGS=-L{prefix}/lib
ARCH=aarch64
SYS=LINUX
SO=.so
LIBX264=libx264.a

# Enable all bit depths
BIT_DEPTH=all
"""

with open('config.mak', 'w') as f:
    f.write(config_mak_content)
print("✓ Created config.mak")

# ═══ Step 3: 创建 x264.pc (pkg-config 文件) ═══
x264_pc_content = f"""prefix={prefix}
exec_prefix=${prefix}
libdir=${prefix}/lib
includedir=${prefix}/include

Name: x264
Description: H.264/AVC video encoder
Version: 0.165
Libs: -L${libdir} -lx264
Cflags: -I${includedir}
"""

with open('x264.pc', 'w') as f:
    f.write(x264_pc_content)
print("✓ Created x264.pc")

# ═══ Step 4: 创建 x264_config.h ═══
x264_config_h_content = """/* x264 configuration header */
#define X264_CHROMA_FORMAT_ALL 1
#define X264_BIT_DEPTH_ALL 1
"""

with open('x264_config.h', 'w') as f:
    f.write(x264_config_h_content)
print("✓ Created x264_config.h")

print("\nConfiguration files created successfully!")
print("Now run: make -j$(nproc)")
```

### 使用步骤

```bash
# 1. 下载并解压源码
tar xf x264-latest.tar.gz
cd x264-*

# 2. 运行 Python 替代脚本
python3 create_config.py

# 3. 编译
make -j$(nproc)

# 4. 安装到 staging 目录
make install DESTDIR=$TEST_PREFIX PREFIX=$DEFAULT_PREFIX

# 5. 打包和验证
# 使用 ohc-run.py package 或手动打包
```

## 通用模板（适配其他项目）

```python
# generic_create_config.py — 通用模板
import os

prefix = os.environ.get('DEFAULT_PREFIX', '~/usr/local')

# 根据 configure.in 或 configure.ac 分析需要的宏
# 使用 Python 替代所有 cat << EOF 的部分

def create_file(filename, content):
    """替代 heredoc 的通用函数"""
    with open(filename, 'w') as f:
        f.write(content)
    print(f"✓ Created {filename}")

# 分析 configure 脚本，提取 heredoc 内容
# heredoc 模式：cat > file << EOF ... EOF
# 手动提取并转换为 Python write() 调用
```

## 优缺点

| 优点 | 缺点 |
|------|------|
| ⭐ 通用性强，适用所有项目 | 需要分析 configure 需要的宏 |
| Python 文件写入不受 HMDFS 限制 | 需要手动编写脚本 |
| 可复现性好 | 每个项目需要定制配置内容 |
| G0 干净构建验证可通过 | 需要理解项目配置结构 |

## 适用判断

```
项目是否使用 heredoc？
├─ 是 → HMDFS 环境？
│   ├─ 是 → 使用 Python 替代脚本（本方案）
│   └─ 否 → 正常 configure
└─ 否 → 正常 configure
```

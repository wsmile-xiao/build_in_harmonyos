# E208: set-env-var

## 基本信息
- **严重度**: 1
- **类别**: build-system
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
ld.lld: error: unable to find library -lc|clang: error: linker command failed with exit code 1|fatal error: 'sys/types.h' file not found
```

## 根因分析
Perl XS 模块编译时，Perl 的构建系统（ExtUtils::MakeMaker）使用默认的链接参数，无法找到 musl 的 libc 库文件。同时，XS 模块的 C 代码需要 musl 的头文件（sys/types.h 等），但默认的 CPATH 未设置。

## 推荐方案
**方法**: set-env-var

**说明**: 在 Makefile.PL 中添加 dynamic_lib 配置，并设置 CPATH 和 LIBRARY_PATH 环境变量指向 musl 的头文件和库文件路径。

**验证/命令**:
```
export CPATH=/storage/Users/currentUser/usr/local/include && export LIBRARY_PATH=/storage/Users/currentUser/usr/local/lib && 在 Makefile.PL 添加 dynamic_lib => { OTHERLDFLAGS=>q[-nostartfiles -nodefaultlibs -lc] }
```

## 关键词

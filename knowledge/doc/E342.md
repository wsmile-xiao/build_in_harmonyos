# E342: Separate test-only bootstrap downloads from an offline package build

## 基本信息

## 错误特征
```
Each download failed.*googletest|google/googletest/archive.*failed|Performing download step.*googletest|BUILD_TESTING.*GoogleTest
```

## 根因分析
Some CMake projects fetch a test framework during configure as soon as BUILD_TESTING is enabled. The production library has no such runtime requirement, but an offline or rate-limited CI worker cannot even configure the package while the test-only bootstrap is active.

## 推荐方案
**方法**: disable-networked-upstream-tests-and-run-consumer-test

**说明**: Keep the package build deterministic by setting BUILD_TESTING=OFF when enabling it performs a network bootstrap. Retain an executable Conan test_package that links the installed target and exercises representative public API behavior. Record any host-side upstream-suite result separately and do not transfer it to the target CI result.

**验证/命令**:
```
CMakeToolchain(self).variables['BUILD_TESTING'] = 'OFF'; conan create .; conan test test_package <reference>
```

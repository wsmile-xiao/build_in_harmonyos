# E247: Static C API archive omits its C++ runtime from pkg-config metadata

## 基本信息
- **严重度**: 2
- **类别**: linking, pkg-config, static-library, api
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
undefined symbol: std::__n1|undefined symbol: operator new|undefined symbol: __cxa_begin_catch
```

## 根因分析
A static archive contains C++ implementation objects behind a C API, but its installed pkg-config Libs.private field omits the C++ runtime, so pure C consumers use the C linker without required ABI libraries.

## 推荐方案
**方法**: propagate-static-cxx-runtime-in-pkg-config

**说明**: Add the selected C++ runtime and other private system libraries to the installed .pc Libs.private field for static packages, while keeping Conan cpp_info.system_libs consistent.

**验证/命令**:
```
validate pkg-config --static output, then compile and run a C consumer without manual C++ flags
```

Libs.private, pkg-config --static, C API, C++ objects, libc++, operator new, std::__n1

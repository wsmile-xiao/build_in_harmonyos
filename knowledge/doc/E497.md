# E497: Keep Git metadata on a native filesystem for HMDFS worktrees

## 基本信息
- **严重度**: 2
- **类别**: git-filesystem-compat
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5862

## 错误特征
```
fatal: cannot stat '<HMDFS worktree>/.git/branches'|fatal: detected dubious ownership in repository
```

## 根因分析
Process-local safe.directory configuration resolves only Git's ownership guard. A Git metadata directory created directly under an HMDFS /storage worktree can still fail native metadata probes such as stat of .git/branches. Git maintenance may also fail on the same filesystem. The worktree content and Git metadata therefore need separate filesystem placements.

## 推荐方案
**方法**: native-separate-git-dir

**说明**: Set safe.directory for the exact worktree through process-local GIT_CONFIG_COUNT variables, initialize the worktree with git init --separate-git-dir=<task-private native /data path> <HMDFS worktree>, then disable automatic maintenance and garbage collection in that repository before staging and committing the frozen snapshot.

**验证/命令**:
```
GIT_CONFIG_NOSYSTEM=1 GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=safe.directory GIT_CONFIG_VALUE_0=<worktree> git init --separate-git-dir=<native-data-gitdir> <worktree>; git config maintenance.auto false; git config gc.auto 0
```

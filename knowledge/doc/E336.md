# E336: ACF (Alpine Configuration Framework) 系列纯 Lua 模块包为 makefile 安装型：make al

## 错误特征
```
ACF 模块 make all 无操作 / make install DESTDIR 复制布局
```

## 根因分析
ACF (Alpine Configuration Framework) 系列纯 Lua 模块包为 makefile 安装型：make all 空目标 + make install DESTDIR 复制脚本到 /usr/share/acf/app/{name}

## 推荐方案
**方法**: conanfile.py: build() 只跑 make all 校验语法，package() 跑 make install DESTDIR，package_info 用 cpp_info.resdirs 暴露 usr/share/acf/app/{name}

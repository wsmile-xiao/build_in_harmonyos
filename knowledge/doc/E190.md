## 错误特征
```
errno.h.*file not found|sys/types.h.*file not found|crti.o.*No such file|crtbeginS.o.*No such file|libunwind.a.*No such file
```

## 根因分析
Perl XS 模块使用 Makefile.PL 而非 configure，默认参数不包含 HarmonyOS 系统所需路径。
            Perl 编译时使用的 clang 版本可能与当前版本不匹配，导致系统头文件路径未包含。
            ld.lld 默认搜索路径不含本地 lib 目录，且可能链接 libunwind.a（musl 系统中不存在）。

## 推荐方案
**方法**: perl-xs-build-params

**说明**: 在 Makefile.PL 调用时显式添加 CCFLAGS 和 LDDLFLAGS 参数

**验证/命令**:
```
|
  # 生成 Makefile
  perl Makefile.PL PREFIX=$DEFAULT_PREFIX \
    CCFLAGS="-D_GNU_SOURCE -fno-strict-aliasing -pipe -fstack-protector-strong -D_LARGEFILE_SOURCE -D_FILE_OFFSET_BITS=64 -I$DEFAULT_PREFIX/include" \
    LDFLAGS="-L$DEFAULT_PREFIX/lib"

  # 编译（关键：使用 -nostdlib 绕过 libunwind）
  make LDDLFLAGS="-shared -nostdlib -B$DEFAULT_PREFIX/lib -L$DEFAULT_PREFIX/lib -lc"
```

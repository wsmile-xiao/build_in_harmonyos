# E190: perl-xs-build-params

## 基本信息
- **严重度**: 3
- **类别**: perl_xs|build-parameters|musl
- **触发工具**: make|clang|ld
- **阶段**: compilation|linking

## 错误特征
```
errno.h.*file not found|sys/types.h.*file not found|crti.o.*No such file|crtbeginS.o.*No such file|libunwind.a.*No such file
```

**关键词**: Perl XS,Makefile.PL,CCFLAGS,LDDLFLAGS,nostdlib,errno.h,crti.o

## 根因分析
Perl XS 模块使用 Makefile.PL 而非 configure，默认参数不包含 HarmonyOS 系统所需路径。

**影响范围**: 所有 Perl XS 模块（使用 Makefile.PL 构建的 Perl 扩展）

## 推荐方案
- **方法**: perl-xs-build-params
- **描述**: 在 Makefile.PL 调用时显式添加 CCFLAGS 和 LDDLFLAGS 参数
- **命令**: `|`
- **自动修复**: false

# E506: Keep compiler-enabled NEON call sites aligned with CMake implementation sources

## 基本信息
- **严重度**: 3
- **类别**: cmake, linking, arm-neon, source-selection
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5392

## 错误特征
```
undefined symbol:.*png_.*_neon|undefined reference to.*png_.*_neon
```

## 根因分析
The target compiler enables NEON declarations and call sites while CMake relies only on a processor-name string, so unknown cross-system processor metadata omits the matching implementation sources.

## 推荐方案
**方法**: compiler-capability-backed-neon-source-selection

**说明**: Preserve known platform selectors and append architecture implementation sources only when the target compiler can compile a real intrinsic probe; preserve a negative case that selects none.

**验证/命令**:
```
Use CheckCSourceCompiles with arm_neon.h and a real intrinsic, then append all implementation files required by the enabled headers.
```

# E311: Verify Conan source-folder isolation before diagnosing build-time mutation

## 基本信息
- **严重度**: 2
- **类别**: conan
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
Copying sources to build folder|no_copy_source.*True|replace_in_file.*self.source_folder
```

## 根因分析
With Conan 2's default no_copy_source=False, Conan copies sources into each package build folder and remaps self.source_folder before build(); treating that path as the shared cache creates a false contamination diagnosis. no_copy_source=True and editable workflows can have different sharing semantics and require explicit verification.

## 推荐方案
**方法**: verify-or-enforce-source-isolation

**说明**: First resolve the actual build-time self.source_folder and Conan copy policy. If the default per-package copy is present, record that evidence; when an explicit invariant is preferable, reset a nested copy under build_folder, edit only it, and configure from that path.

**验证/命令**:
```
Confirm Copying sources to build folder and distinct build paths; optionally use rmdir/copy plus cmake.configure(build_script_folder=build_source).
```

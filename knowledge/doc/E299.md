## 错误特征
```
Could not download from the URL|
                         sha256 hash failed for|
                         curl: (28)|
                         403 Forbidden|
                         404 Not Found|
                         Could not resolve host|
                         SSL certificate problem|
                         TLS handshake failed|
                         Connection refused|
                         Connection reset
```

## 根因分析
网络超时、URL 错误和 SHA256 不匹配都发生在 source() 阶段，
                         但根因和修复动作不同；仅按“下载失败”摘要会产生误诊。

## 推荐方案
**方法**: classify-source-failure

**说明**: 先按传输、HTTP 状态和完整性校验分层，再分别修复网络、URL 或可信 SHA256，始终保留官方源或权威镜像。

**验证/命令**:
```
conan source <recipe> -v; sha256sum <official-release-archive>
```

Conan source, get(), download, timeout, mirror,
                         sha256, computed hash, provided hash, 404,

# E174: manual-install

## 基本信息
- **严重度**: 2
- **类别**: tool-missing|platform-limitation
- **触发工具**: make|install
- **阶段**: installation

## 错误特征
```
make: install: No such file or directory|install: command not found|make\[\d+\]: install: No such file or directory
```

**关键词**: install, No such file or directory, make, coreutils, installation failed

## 根因分析
OpenHarmony 缺少 GNU coreutils 的 install 命令。

**影响范围**: 使用 Makefile install 目标的项目，依赖 install 命令的安装脚本

## 推荐方案
- **方法**: manual-install
- **描述**: 手动使用 cp + chmod 替代 install 命令进行文件安装
- **命令**: `# 示例：手动安装二进制文件`
- **自动修复**: false

## 验证
```bash
which install || echo "install command missing"
```

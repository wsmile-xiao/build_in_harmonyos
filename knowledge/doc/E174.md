# E174: manual-install

## 错误特征
```
make: install: No such file or directory|install: command not found|make\[\d+\]: install: No such file or directory
```

## 根因分析
OpenHarmony 缺少 GNU coreutils 的 install 命令。
                        install 命令是 GNU coreutils 的一部分，用于安装文件到指定位置并设置权限。
                        OpenHarmony 的工具集不包含完整的 GNU coreutils，导致 make install 失败。
                        需要使用 cp + chmod 手动安装，或制作 Makefile 补丁。

## 推荐方案
**方法**: manual-install

**说明**: 手动使用 cp + chmod 替代 install 命令进行文件安装

**验证/命令**:
```
# 示例：手动安装二进制文件
                        cp binary ~/usr/local/bin/
                        chmod 0755 ~/usr/local/bin/binary

                        # 示例：创建目录并安装
                        mkdir -p ~/usr/local/share/man/man1
                        cp doc/manpage.1 ~/usr/local/share/man/man1/
                        chmod 0644 ~/usr/local/share/man/man1/manpage.1
```

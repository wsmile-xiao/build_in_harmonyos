# E053: set-env-var

## 错误特征
```
cc1plus.*error.*unrecognized|cc1plus.*not found|
                         CXX compiler cannot create executables|configure.*CXX.*fail
```

## 根因分析
鸿蒙 SDK 工具链不提供 cc1plus(GCC 的 C++ 编译器前端)。
                         鸿蒙使用 LLVM/Clang 工具链, clang++ 是 C++ 编译器,
                         但部分 autotools 项目的 configure 脚本或 Makefile 硬编码调用 cc1plus,
                         或 configure 的 C++ 编译器检测逻辑在 clang++ 上误判

## 推荐方案
**方法**: set-env-var

**说明**: 显式指定 CXX=clang++ 并确保在 configure 前设置:
                         export CC=clang CXX=clang++

**验证/命令**:
```
export CC=clang; export CXX=clang++;
                         ./configure --prefix=$HOME/usr/local CXX=clang++
```

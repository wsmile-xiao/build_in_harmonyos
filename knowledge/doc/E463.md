# E463: Build GTK 3.24 with Broadway and validate consumers without a display

## 基本信息
- **严重度**: 2
- **类别**: ohos, meson, filesystem, broadway, gtk
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6810

## 错误特征
```
broadway|X11|Wayland|HMDFS|shebang|libffi.so.8|GtkWindow
```

## 根因分析
The base OHOS runner has neither X11/Wayland nor the prerequisites required by the upstream GTK GUI tests. Ambient GLib tools can load an incompatible device-global libffi ABI, while pinned compiled tools copied from a Conan cache require HarmonyOS self-signing before execution.

## 推荐方案
**方法**: broadway-headless-consumer-probe

**说明**: Use the gtk Conan slug, enable Broadway, overwrite generated pkg-config tool variables with signed private copies of pinned compiled GLib tools, pair them with dependency library paths, and run a no-display consumer probe.

**验证/命令**:
```
-Dx11_backend=false -Dwayland_backend=false -Dbroadway_backend=true
```

# E409: Preserve runtime location, empty arguments, and flushed output in BLACS CTest

## 基本信息
- **严重度**: 3
- **类别**: cmake, fortran, runtime, ctest, mpi
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5839

## 错误特征
```
list sub-command APPEND requires at least two arguments|error while loading shared libraries|DONE BLACS_GRIDEXIT.*missing|BLACS.*test.*failed
```

## 根因分析
The upstream harness can copy a test ELF away from its $ORIGIN RUNPATH, remove an empty CMake list argument through unquoted expansion, and lose the final Fortran marker when MPI_Abort terminates before buffered stdout is flushed.

## 推荐方案
**方法**: preserve-runtime-quote-empty-flush-before-abort

**说明**: Execute the test binary from its original runtime directory, quote any potentially empty CMake list element, and flush the Fortran output unit immediately before the intentional MPI abort path.

**验证/命令**:
```
Replace the copied executable invocation with ${RUNTIMEDIR}/${TEST_PROG}, use list(APPEND tmp "${TESTSTRING}"), and add FLUSH(OUTNUM) after the completion WRITE.
```

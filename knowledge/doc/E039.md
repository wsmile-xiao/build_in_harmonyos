# E039: musl iconv 不支持 //IGNORE 后缀

> **结构化数据**: [graph/E039.kv](../graph/E039.kv) | **原则**: [P-PATCH-001](../graph/principles.kv)
> **严重度**: 🟡 medium | **分类**: libc/compat/encoding | **自动修复**: ❌ patch

---

## 错误特征

```
mandb: iconv_open ("UTF-8//IGNORE", "utf-8"): Invalid argument
mandb: iconv_open ("UTF-8//IGNORE", "iso-8859-1"): Invalid argument
```

## 根因

glibc 的 iconv 支持特殊后缀 `//IGNORE`（忽略不可转换字符）和 `//TRANSLIT`（音译），但 musl libc 的 iconv 实现不支持这些 glibc 扩展后缀。

| 特性 | glibc | musl libc (鸿蒙) |
|------|-------|------------------|
| 基本字符集转换 | ✅ | ✅ |
| `//IGNORE` 后缀 | ✅ | ❌ |
| `//TRANSLIT` 后缀 | ✅ | ❌ |

**影响范围**：man-db 的 `manconv` 工具受影响，`apropos`/`whatis` 搜索失效。`man` 命令本身不受影响。

## 解决方案

```c
#ifdef __OHOS__
  char *to_code = "UTF-8";    // musl: 去掉 //IGNORE
#else
  char *to_code = "UTF-8//IGNORE";  // glibc: 保留
#endif
  iconv_t cd = iconv_open(to_code, from_code);
```

## 禁止模式

❌ 使用 `iconv_open("...//IGNORE", ...)` 或 `"...//TRANSLIT"` → musl 下 Invalid argument

## 涉及软件

man-db 2.13.1 及其他使用 glibc iconv 扩展后缀的软件。

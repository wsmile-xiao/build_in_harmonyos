# E203: source-patch

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, libc, headers
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
getprogname.*is not available on this platform|sys/poll.h.*redirect.*incorrect.*include|poll\.h.*-W#warnings
```

## 根因分析
OpenHarmony 使用 musl libc，不提供 getprogname() 和 program_invocation_name，但提供 __progname（与 Android 类似）。同时 musl 的 sys/poll.h 是一个 redirect header，会触发 #warning 导致 -Werror 编译失败。

## 推荐方案
**方法**: source-patch

**说明**: 使用 __progname 替代 getprogname()（需 #ifdef __OHOS__ 守卫）；用 #include <poll.h> 替代 #include <sys/poll.h>（需 #ifdef __OHOS__ 守卫）

**验证/命令**:
```
在 getprogname shim 中添加 #elif defined(__OHOS__) return (char *)__progname; 在 poll include 中添加 #ifdef __OHOS__ #include <poll.h>
```

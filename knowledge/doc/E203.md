# E203: source-patch

## 基本信息
- **严重度**: 2
- **类别**: libc|compat|headers|ohos
- **触发工具**: clang|cmake|make
- **阶段**: compilation

## 错误特征
```
getprogname.*is not available on this platform|sys/poll.h.*redirect.*incorrect.*include|poll\.h.*-W#warnings
```

**关键词**: getprogname,__progname,musl,poll.h,sys/poll.h,redirect,OpenHarmony,OHOS,-W#warnings

## 根因分析
OpenHarmony 使用 musl libc，不提供 getprogname() 和 program_invocation_name，但提供 __progname（与 Android 类似）。同时 musl 的 sys/poll.h 是一个 redirect header，会触发 #warning 导致 -Werror 编译失败。

**影响范围**: 使用 getprogname() 或 sys/poll.h 的所有软件（libdispatch, 以及其他 Apple/BSD 源码移植项目）

## 推荐方案
- **方法**: source-patch
- **描述**: 使用 __progname 替代 getprogname()（需 #ifdef __OHOS__ 守卫）；用 #include <poll.h> 替代 #include <sys/poll.h>（需 #ifdef __OHOS__ 守卫）
- **命令**: `在 getprogname shim 中添加 #elif defined(__OHOS__) return (char *)__progname; 在 poll include 中添加 #ifdef __OHOS__ #include <poll.h>`
- **自动修复**: false

## 验证
```bash
clang -D__OHOS__ -c test.c 2>&1 | grep -E "error|warning"
```

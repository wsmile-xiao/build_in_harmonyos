# E234: 静态 Autotools 库的 Conan fPIC 映射与共享链接回归

## 基本信息
- **严重度**: 2
- **类别**: autotools, linking
- **作者**: goblinrs <goblinrs@yeah.net>
- **来源 PR**: source_commit:

## 错误特征
```
Please, do not enable PIC \(--with-pic\) for static library|static.*relocation.*recompile with -fPIC
```

## 根因分析
部分上游将 Libtool 的 --with-pic 配置项与纯静态模式定义为互斥，但 Conan 标准 fPIC 选项已通过 CFLAGS/CXXFLAGS 注入 -fPIC；将两种机制同时传入会在 configure 阶段失败，去掉所有 PIC 标志又会让静态对象无法整体链接进共享 ELF

## 推荐方案
**方法**: preserve-conan-fpic-and-prune-project-conflict

**说明**: 保留标准 shared/fPIC 选项；仅在 static+fPIC 时精确处理上游不接受的 --with-pic 配置项，并机械确认 toolchain 仍产生唯一 -fPIC；把整体链接检查并入既有制品工作流，不新增测试编号

**验证/命令**:
```
conan create . -o '&:shared=False' -o '&:fPIC=True' && grep generated-toolchain && clang -fPIC -shared -Wl,-z,defs -Wl,--whole-archive libfoo.a -Wl,--no-whole-archive
```

# E139: compile-gmp-shared

## 基本信息
- **严重度**: 2
- **类别**: dependency-library
- **触发工具**: configure|ld
- **阶段**: configuration|linking

## 错误特征
```
libgmp\.so.*not found|cannot find -lgmp|
```

**关键词**: GMP, gmp, shared library, static library,

## 根因分析
cmd-pkgs 预编译包的 GMP 只提供静态库（libgmp.a），缺少共享库（libgmp.so），configure 检测需要共享库版本

**影响范围**: 所有需要 GMP 共享库的软件（libbytesize, mpfr 等）

## 推荐方案
- **方法**: compile-gmp-shared
- **描述**: 从源码编译 GMP 6.3.0 --enable-shared，提供共享库版本
- **命令**: `./configure --prefix=$DEFAULT_PREFIX --enable-shared && make -j1 && make install`
- **自动修复**: false

## 验证
```bash
ls $DEFAULT_PREFIX/lib/libgmp.so* && pkg-config --modversion gmp
```

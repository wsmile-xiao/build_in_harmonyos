## 根因分析
cmd-pkgs 预编译包的 GMP 只提供静态库（libgmp.a），缺少共享库（libgmp.so），configure 检测需要共享库版本

## 推荐方案
**方法**: compile-gmp-shared

**说明**: 从源码编译 GMP 6.3.0 --enable-shared，提供共享库版本

**验证/命令**:
```
./configure --prefix=$DEFAULT_PREFIX --enable-shared && make -j1 && make install
```

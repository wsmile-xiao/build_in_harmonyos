# E440: qttools Qt6Help 组件缺失时 test_package 用实际产出组件

## 基本信息
- **严重度**: 2
- **类别**: ohos
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: !6540

## 错误特征
```
Failed to find required Qt component "Help"|Qt6Help_DIR
```

## 根因分析
qttools 的 Help 模块依赖 Widgets 桌面组件，OHOS 构建部分跳过；test_package 引用 Qt6::Help 失败

## 推荐方案
**方法**: test_package 改用实际产出的 Qt6::UiTools（QUiLoader）+ find_package(Qt6 COMPONENTS UiTools)

**说明**: test_package 改用实际产出的 Qt6::UiTools（QUiLoader）+ find_package(Qt6 COMPONENTS UiTools)

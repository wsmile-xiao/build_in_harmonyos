# E326: Shadow CI 只看 git archive HEAD 快照，dirty worktree 不会自动进入验证

## 基本信息
- **严重度**: 2
- **类别**: git, workflow
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !7151

## 错误特征
```
No packages to build|Path in CI_PACKAGES has no conanfile.py|shadow.*exit_code=1
```

## 根因分析
Shadow CI 运行脚本会先执行 `git archive --format=tar HEAD`，
                        再在远端解包成干净源码树。未提交的 worktree 改动不会进入
                        这个快照，因此本地看起来已改好的包，远端可能还是旧版本。

## 推荐方案
**方法**: snapshot-before-shadow-ci

**说明**: 在跑 shadow CI 前，先把目标包改动提交到临时快照，或者复制成
                        一个干净的临时仓库再验证；不要直接指望 dirty worktree 被自动带上。

**验证/命令**:
```
git add archives/o/ostra && git commit -m "shadow snapshot for ostra" && sh "$HOME/bin/run-ohos-shadow-ci.sh" archives/o/ostra/0.000709606481481482
```

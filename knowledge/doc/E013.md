# E013: add-ldflags

## 基本信息
- **严重度**: 2
- **类别**: linking
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
undefined reference.*dlopen|
                         undefined reference.*dlsym|
                         undefined reference.*dlclose|
```

## 根因分析
链接阶段未指定 libdl 依赖,
                         dlopen/dlsym/dlclose 是 POSIX 动态加载 API,
                         需要显式链接 -ldl (musl 中 dl 功能在 libc 但符号在 libdl)

## 推荐方案
**方法**: add-ldflags

**说明**: 添加 -ldl 到 LDFLAGS

**验证/命令**:
```
LDFLAGS="-ldl $LDFLAGS"
```

## 关键词
dlopen, dlsym, dlclose, -ldl, libdl,
                         dynamic linking, undefined reference,
                         shared library loading

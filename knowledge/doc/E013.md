# E013: 动态链接错误（-ldl 缺失）

> **结构化数据**: [graph/E013.kv](../graph/E013.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: linking | **自动修复**: ✅ set-env-var

---

## 错误特征

```
undefined reference to `dlopen`
undefined reference to `dlsym`
undefined reference to `dlclose`
```

## 根因

链接阶段未指定 `libdl` 依赖。`dlopen`/`dlsym`/`dlclose` 是 POSIX 动态加载 API，在 musl 中需要显式链接 `-ldl`。

## 解决方案

```bash
# 方案1：添加 -ldl 到 LDFLAGS（推荐）
export LDFLAGS="-ldl $LDFLAGS"

# 方案2：在 configure 中设置
./configure ... LDFLAGS="-ldl"
```

## 涉及软件

使用动态加载机制的 C/C++ 项目（插件系统、模块加载器等）。

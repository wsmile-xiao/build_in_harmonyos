# E028: configure-static-only

## 基本信息
- **严重度**: 3
- **类别**: linking, packaging
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
shared library.*conflict|system library crash|
                         symbol link incomplete|ncurses.*crash|
                         lib.*\.so.*override.*system
```

## 根因分析
用户编译的共享库(.so)版本覆盖了系统版本但符号链接不完整,
                         导致依赖系统库的程序崩溃

## 推荐方案
**方法**: configure-static-only

**说明**: 只编译静态库(--without-shared), 避免覆盖系统共享库

**验证/命令**:
```
./configure --without-shared --prefix=$HOME/usr/local
```

shared library, conflict, system crash, --without-shared,
                         static only, ncurses, symbol link, override,
                         LD_LIBRARY_PATH, rpath, version mismatch

# E028: 用户编译的共享库与系统库冲突

> **结构化数据**: [graph/E028.kv](../graph/E028.kv) | **原则**: 无
> **严重度**: 🔴 blocking | **分类**: packaging/linking | **自动修复**: ✅ reconfigure

---

## 错误特征

```
ncurses 共享库安装后，系统 zsh 崩溃，所有终端不可用
```

## 根因

用户编译的共享库版本（如 `libncursesw.so.6.4`）覆盖了系统版本但符号链接不完整，导致依赖系统 ncurses 的程序崩溃。

## 解决方案

**推荐：只编译静态库**

```bash
./configure --without-shared --prefix=$HOME/usr/local
make && make install
```

**如需共享库**：确保符号链接完整，且安装到用户目录而非系统目录。

## 禁止策略

❌ 禁止将用户编译的 `.so` 安装到 `/usr/lib` 或 `/usr/lib64`。这会破坏系统程序。

## 涉及软件

ncurses 6.4、任何编译为共享库的系统依赖型项目。

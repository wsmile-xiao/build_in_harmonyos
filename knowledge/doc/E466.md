# E466: init_build._promote_nested_source 仅按 C/C++ 构建标记(configure/CMakeLists.t

## 基本信息
- **严重度**: 2
- **类别**: python, extract, init-build, sdist
- **作者**: wingsluo <wingsluo@noreply.gitcode.com>
- **来源 PR**: !7091

## 错误特征
```
嵌套源码检测: 找到源码在|\.work 目录只有 docs 内容|cp: .*Operation not permitted
```

## 根因分析
init_build._promote_nested_source 仅按 C/C++ 构建标记(configure/CMakeLists.txt/Makefile/meson.build)识别源码子目录；Python sdist(如 chardet)顶层无这些标记，递归误命中含 Sphinx Makefile 的 docs/ 目录，把 docs/ 提升为源码根。另外 HMDFS 文件系统禁止创建硬链接(cp -al 报 Operation not permitted)。

## 推荐方案
**方法**: Python 包(sdist)适配时若发现 .work 只有 docs 内容: 1) rm -rf 两个目录; 2) mkdir .orig && tar xzf --strip-components=1 -C .orig; 3) cp -a .orig/. .work/(勿用硬链接); 4) 写入 .tarball-sha256 校验; 5) 配方 build() 走 pip install 路径，不依赖 init-build 目录推断

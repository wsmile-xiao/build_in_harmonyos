# E496: OHOS 沙箱 setsockopt(SO_PRIORITY) 返回 EPERM 被误判为致命错误

## 基本信息
- **严重度**: 2
- **类别**: socket, linking, permissions
- **作者**: hhyxx1 <f24011422@st.sandau.edu.cn>
- **来源 PR**: !5162

## 错误特征
```
setsockopt\(.*SO_PRIORITY.*Operation not permitted|Operation not permitted.*SO_PRIORITY
```

## 根因分析
OHOS 沙箱无 CAP_NET_ADMIN 权限, SO_PRIORITY setsockopt 返回 EPERM; 若代码将其视为致命错误会导致连接/会话建立失败

## 推荐方案
**方法**: setsockopt 调用对 EPERM/EACCES 视为尽力而为(不致命), 与 ENOTSOCK 同等处理

# E515: conan patch 默认 strip=0，refresh-patch a/b 前缀补丁需显式 strip:1

## 基本信息
- **严重度**: 3
- **类别**: conan, packaging, patch
- **作者**: wanderlust_0823 <wanderlust_0823@noreply.gitcode.com>
- **来源 PR**: !7077

## 错误特征
```
Failed to apply patch.*source/target file does not exist|Patch file does not exist
```

## 根因分析
refresh-patch 生成的补丁是 Git 风格 a/xxx b/xxx（需 -p1 剥离），但 conan 的 apply_conandata_patches() 默认 strip=0 不剥离前缀，patch_ng 找不到 a/xxx 文件报 source/target file does not exist（信息不指向 strip 问题）。conandata.yml 每个 patch 条目需显式 strip:1。

# E318: HarmonyOS 上 go test 临时 ELF 未签名导致测试无法执行

## 基本信息
- **严重度**: 3
- **类别**: ohos, go, testing, security
- **作者**: xuguowei <1070622207@qq.com>
- **来源 PR**: 3797

## 错误特征
```
fork/exec.*\.test.*permission denied|go test.*permission denied|operation not permitted.*\.test|exec format error.*\.test
```

## 根因分析
go test 默认在临时目录编译包级测试 ELF 并立即执行；HarmonyOS 会拒绝加载未签名 ELF。即使测试 ELF 已在非 HMDFS 目录成功链接，未经签名仍会在进入测试代码前失败。

## 推荐方案
**方法**: compile-sign-run-go-tests

**说明**: 按 package 使用 go test -c 将测试 ELF 输出到非 HMDFS 目录，移除旧 .codesign 后自签并恢复执行权限，最后从该 package 的原源码目录执行，保留相对资源路径、包级初始化和原测试判定。

**验证/命令**:
```
go test -c -o "$TEST_ROOT/pkg.test" ./pkg && (llvm-objcopy --remove-section .codesign "$TEST_ROOT/pkg.test" 2>/dev/null || true) && binary-sign-tool sign -inFile "$TEST_ROOT/pkg.test" -outFile "$TEST_ROOT/pkg.test.signed" -selfSign 1 && mv "$TEST_ROOT/pkg.test.signed" "$TEST_ROOT/pkg.test" && chmod +x "$TEST_ROOT/pkg.test" && (cd pkg && "$TEST_ROOT/pkg.test" -test.v -test.count=1)
```

# E150: manual-download

## 基本信息
- **严重度**: 3
- **类别**: packaging
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
framework.*not found|submodule.*missing|fatal: not a git repository|framework/exported\.make.*No such file
```

## 根因分析
Release tarball from GitHub/Gitee does not include submodule contents (only contains .gitmodules file)

## 推荐方案
**方法**: manual-download

**说明**: Download submodule repository separately and copy to source directory

**验证/命令**:
```
git clone --depth=1 https://github.com/Mbed-TLS/mbed-framework.git framework && cd framework && git checkout <commit-hash>
```

## 关键词
submodule, framework, git, tarball, missing directory

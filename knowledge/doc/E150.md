# E150: manual-download

## 基本信息
- **严重度**: 3
- **类别**: source-package
- **触发工具**: cmake
- **阶段**: configuration

## 错误特征
```
framework.*not found|submodule.*missing|fatal: not a git repository|framework/exported\.make.*No such file
```

**关键词**: submodule, framework, git, tarball, missing directory

## 根因分析
Release tarball from GitHub/Gitee does not include submodule contents (only contains .gitmodules file)

**影响范围**: Software packages with git submodules (especially mbedtls, projects with framework/ or external dependencies)

## 推荐方案
- **方法**: manual-download
- **描述**: Download submodule repository separately and copy to source directory
- **命令**: `git clone --depth=1 https://github.com/Mbed-TLS/mbed-framework.git framework && cd framework && git checkout <commit-hash>`
- **自动修复**: false

## 验证
```bash
ls -la framework/ 2>/dev/null && test -f framework/exported.make || echo "Submodule missing"
```

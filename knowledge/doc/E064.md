## 错误特征
```
cannot run C compiled programs|conftest.*inaccessible or not found|
                         configure.*cross compile|config.log.*exit 127|conftest.*Permission denied
```

## 根因分析
autotools configure 通过编译并运行小测试程序(conftest)来检测平台能力。
                         鸿蒙上首次执行非系统二进制需要安全确认弹窗(E054), 弹窗超时未点则进程被杀,
                         configure 误判为"此平台不能运行编译出的程序"→ 错误地进入交叉编译模式,
                         导致大量检测使用硬编码默认值而非实际检测结果

## 推荐方案
**方法**: trigger-security-dialog

**说明**: 手动触发弹窗后再跑 configure:
                         先跑一次 configure(会卡在弹窗) → 快速点击所有弹窗 → 等 configure 完成;
                         如果超时被杀则重新跑(此时弹窗已确认过)

**验证/命令**:
```
rec_auto_fix:          false
```

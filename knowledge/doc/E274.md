# E274: create-soname-symlink

## 基本信息
- **严重度**: 2
- **类别**: linking, packaging, runtime
- **作者**: AtomCode
- **来源 PR**: source_commit:

## 错误特征
```
Error loading shared library.*\(needed by.*\)|
                         Error relocating.*symbol not found
```

## 根因分析
Makefile 使用 -Wl,-soname,lib.so.X.Y 编译共享库，
                        但 conanfile.py 的 package() 只复制了 lib.so 文件，
                        未创建版本化 SONAME 符号链接 lib.so.X.Y → lib.so。
                        运行时动态链接器解析 ELF 的 NEEDED 条目时找不到
                        版本化 SONAME 文件，导致加载失败。

## 推荐方案
**方法**: create-soname-symlink

**说明**: 在 conanfile.py 的 package() 方法中，
                        复制 lib.so 后创建 SONAME 符号链接：
                        os.symlink("lib.so", "lib.so.X.Y")

**验证/命令**:
```
os.symlink("libjanet.so", "libjanet.so.1.41")
```

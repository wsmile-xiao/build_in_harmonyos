## 错误特征
```
grep.*match fail|grep.*regex metacharacter|
                         grep.*fixed string.*parenthesis|GNU sed.*version.*grep.*empty
```

## 根因分析
grep 默认使用基本正则表达式(BRE)模式。
                         当待匹配字符串含正则元字符( ()[]$ )时,
                         这些字符被当作正则元字符处理导致匹配失败。
                         这是 AI 编程疏忽, 不是平台问题

## 推荐方案
**方法**: use-grep-F-or-case

**说明**: 匹配固定字符串时使用 grep -F(强制固定字符串模式);
                         或使用 shell 原生 case 模式匹配(无元字符问题):
                         case "$var" in *pattern*) ;; esac

```
rec_auto_fix:          true
```

# E213: l64a() missing in OHOS libc (musl)

## 基本信息
- **严重度**: 2
- **类别**: api
- **作者**: lz6688 <yhwork66@163.com>
- **来源 PR**: source_commit:

## 错误特征
```
undefined reference to .l64a.|cannot find -l.*l64a
```

## 根因分析
OHOS libc (musl) does not provide l64a() function, which converts a long value to a radix-64 string

## 推荐方案
**方法**: implement-locally

**说明**: Implement l64a() in a project source file and add extern declaration before usage to prevent implicit int return on aarch64

**验证/命令**:
```
# Add to misc.c: char *l64a(long value) { static char buf[7]; ... } and add extern char *l64a(long); in calling file
```

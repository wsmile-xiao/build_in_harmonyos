## 根因分析
OpenHarmony PC 适配中遇到没有 C/C++ 源码、不需要编译、没有传统测试套件的数据/规则清单型上游库。这类库的核心价值在于提供固定版本的权威数据（JSON/规则清单）和可编程查询接口。传统 CMake/Autotools 模板不适用，需要专门的数据包适配模式。

## 推荐方案
**方法**: data-package-pattern

**说明**: |
  数据包核心模式：
  1. settings = None（不依赖编译器/架构）
  2. 不设置 package_type（避免触发 CLI 工具命令检查）
  3. source() 使用 get() 下载 tarball
  4. build() 中验证数据完整性（版本号、总数、hash）
  5. package() 复制数据到 res/ 目录
  6. test_package 使用独立 .py 脚本 + self.run() 调用
  7. test_package 输出固定 JSON 摘要供精确比对

**验证/命令**:

# E243: Protocol-data packages need per-document generator tests

## 基本信息

- **类别**: packaging, testing, api
- **作者**: 1catmint1
- **来源 PR**: source_commit:

## 错误特征
```
protocol generator validation failed|installed XML, Python, or pkg-config metadata is incomplete or non-relocatable|module output callback order is incorrect
```

## 根因分析
A data-only protocol package can contain the expected file count and pass one schema command while still being unusable: imports may be missing, generator semantic resolution may fail, Python modules may be installed outside the exported search path, or pkg-config variables may point outside the package. File inventory, schema validity, generator behavior, and installed discovery are separate contracts.

## 推荐方案
**方法**: per-document-generator-plus-discovery-matrix

**说明**: Lock the upstream document and module inventories. Preserve the upstream schema test, but also run every installed protocol input through the real generator registration and semantic-resolution API in a separate process. Add unique fixtures for public semantic branches and verify that pkg-config and language search paths resolve inside the installed package.

**验证/命令**:
```
conan create <recipe> -pr:h=<target-profile> -pr:b=<target-profile> --build='*'
```

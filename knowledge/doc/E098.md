# E098: cp-chmod-replace

## 基本信息
- **严重度**: 1
- **类别**: ohos, install, shell
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
install: command not found|sh: install: inaccessible or not found
```

## 根因分析
鸿蒙系统使用toybox提供基础命令，toybox不包含install命令。Makefile中的install目标调用install命令失败。

## 推荐方案
**方法**: cp-chmod-replace

**说明**: 用cp + chmod组合替代install命令。install命令本质是cp + chmod + strip的组合，可手动实现

**验证/命令**:
```
mkdir -p $DESTDIR/$PREFIX/bin && cp program $DESTDIR/$PREFIX/bin/ && chmod 755 $DESTDIR/$PREFIX/bin/program
```

## 关键词
install,command not found,toybox,缺失命令

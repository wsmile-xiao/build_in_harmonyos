## 错误特征
```
regrtest.*parallel.*worker|load avg.*high|
                         locale was modified by test|flaky.*re-run|cpu_count
```

## 根因分析
regrtest 默认按 os.cpu_count() 开启 worker(鸿蒙=18),
                         与 MAKEFLAGS=-j1 独立: make 编译串行化(必需,FIFO 限制),
                         但 regrtest 测试仍并行, 导致全局状态污染和资源争用

## 推荐方案
**方法**: env-var-override

**说明**: 显式限制 regrtest worker 数为 1:
                         MAKEFLAGS="-j1" make test TESTOPTS="-j1 --ignore=smtpnet ..."

**验证/命令**:
```
MAKEFLAGS="-j1" make test TESTOPTS="-j1"
```

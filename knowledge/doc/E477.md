# E477: CNB Conan 制品仓对不存在/未发布包返回 "system acceleration policy not enabled"，CI L0i 误判为网络异常而非依赖未发布 (R36)

- **类别**: detection, network, conan
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>

## 错误特征
```
system acceleration policy not enabled|registry unreachable for:|registry_unreachable|Connecting to remote 'ohpcd' anonymously ERROR|conan could not reach/query the remote
```

## 根因分析
CNB (cnb.cool) Conan 制品仓对"匿名下载不存在/未发布的 recipe"返回的错误文本是 "ERROR: error:system acceleration policy not enabled"，而不是标准 "not found/404"。
            ci/conan/build_and_test.sh 的 L0i 门禁用 conan download -r=ohpcd --only-recipe 探测依赖，
            仅把 "unable to find|does not exist|not found|404" 识别为"真未发布 (R36)"，
            该 CNB 特有文本落入"网络/认证异常 (registry_unreachable)"分支，导致诊断误导
            （提示"修复 worker 网络"，实际是依赖尚未发布）。

## 推荐方案
**方法**: verify-registry-with-conan-list

**说明**: 用 conan list -r=ohpcd 核实依赖是否已发布；若未发布先合入/发布该依赖 (R36)，再 /rebuild 触发 PR CI；不要误判为网络故障

**验证/命令**:
```
conan list "<dep>/<ver>" -r=ohpcd && conan download "<dep>/<ver>" -r=ohpcd --only-recipe
```

# E455: OHOS clang 拒绝 -stdlib=libstdc++（Conan profile libcxx 误配导致编译器检查 broken）

## 基本信息
- **严重度**: 2
- **类别**: platform, toolchain, conan, libcxx
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !6885

## 错误特征
```
invalid library name in argument '-stdlib=libstdc++'|
                         Check for working CXX compiler.*broken|
                         is not able to compile a simple test program|
                         clang-15: error: invalid library name
```

## 根因分析
Conan profile 中 compiler.libcxx=libstdc++11（或任意 libstdc++ 变体）时，
                         CMakeToolchain 生成 conan_toolchain.cmake 注入 "-stdlib=libstdc++"；
                         OHOS 工具链 clang 15 只提供 libc++，拒绝该 flag：
                         "clang-15: error: invalid library name in argument '-stdlib=libstdc++'"
                         导致 CMake TryCompile 失败 → "Check for working CXX compiler ... broken"。
                         修复: 使用 repository 预置 OHOS profile（compiler.libcxx=libc++）。

## 推荐方案
**方法**: use-ohos-profile-libcxx

**说明**: 改用仓库预置 OHOS profile（compiler.libcxx=libc++）；不要用 detect 生成的
                         默认 profile（libstdc++11）。CMakeToolchain 将注入 -stdlib=libc++，
                         编译器 TryCompile 通过，conan create 与 test_package 正常运行。

**验证/命令**:
```
conan create . --build=missing \
                         -pr:h=ci/conan/profiles/ohos-aarch64 \
                         -pr:b=ci/conan/profiles/ohos-aarch64
```

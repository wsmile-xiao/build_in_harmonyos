# E539: zlib test_package should build a shared-library PIC probe

## 基本信息
- **严重度**: 2
- **类别**: conan, test-package-pic-probe
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6617

## 错误特征
```
zlib_pic_probe|R_AARCH64_ADR_PREL_PG_HI21|relocation|SHARED|libz.a
```

## 根因分析
A normal compress/uncompress round trip proves the zlib API works, but it does not prove that static libz.a was built from PIC objects. The non-PIC failure only appears when the archive is linked into a shared object on AArch64.

## 推荐方案
**方法**: api-roundtrip-plus-shared-library-link

**说明**: Keep a runtime API smoke test for compress/uncompress, and add a second CMake target that builds a SHARED library linked against zlib::zlib. The shared target catches non-PIC static archives during test_package build, before downstream consumers hit the same relocation.

**验证/命令**:
```
add_library(zlib_pic_probe SHARED pic_probe.c); target_link_libraries(zlib_pic_probe zlib::zlib)
```

official source archive SHA256 mismatch|official source member set mismatch|official source member SHA256 mismatch|test discovery source is not bound to verified archive

## 根因分析
runner 只独立校验压缩包哈希，却允许从另一棵可指定源码树发现和编译测试，或让 discovery-only 在来源校验前返回，导致报告中的官方来源声明没有绑定实际消费字节

## 推荐方案
**方法**: discover-tests-from-verified-archive

**说明**: 先校验官方压缩包 SHA256，从已校验 tar 的规范化普通文件成员字节流生成动态源码清单，再在 runner 管理的临时目录自行解包，并只从该解包树动态发现和编译测试；discovery-only 与完整执行共用同一来源路径，不在 HMDFS 上用目标 Python 遍历和逐文件哈希

**验证/命令**:
```
python archives/l/libffi/3.5.2/validate_upstream_runner.py --archive <official-archive>
```

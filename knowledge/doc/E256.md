# E256: 二进制文件提交导致 CI PR diff patch 应用失败

## 基本信息
- **严重度**: 3
- **类别**: patch
- **作者**: source_pr:              5056
- **来源 PR**: 5056

## 错误特征
```
missing binary patch data.*\.tar\.gz|error: binary patch does not apply to.*packaging|patch does not apply.*packaging.*\.tar\.gz|PR.*diff.*无法应用.*冲突
```

## 根因分析
PR 分支中提交了二进制构建产物（如 packaging/*.tar.gz）或构建过程标记文件（如 .staging-verified），CI checkout 流程通过 `git apply pr.diff` 应用 PR diff 时，git 无法处理缺少 binary patch data 的二进制文件，导致 patch 应用失败

## 推荐方案
**方法**: remove-binary-from-commit

**说明**: 从分支中删除二进制构建产物和空标记文件，amend 提交并 force push

**验证/命令**:
```
git rm archives/h/hidapi/0.12.1/packaging/*.tar.gz archives/h/hidapi/0.12.1/.staging-verified && git commit --amend --no-edit && git push origin feat/xxx --force-with-lease
```

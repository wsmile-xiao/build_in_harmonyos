# E023: locale 支持不完整

> **结构化数据**: [graph/E023.kv](../graph/E023.kv) | **原则**: 无
> **严重度**: 🟢 low | **分类**: posix/compat | **自动修复**: ✅ set-env-var

---

## 错误特征

```
test_strcoll_with_diacritic ... FAIL
test_complex_formatting ... FAIL
```

## 根因

鸿蒙 locale 支持不如 Linux 完整，缺少 `en_US.UTF-8` 等常用 locale。

```bash
locale -a
# 可能缺少 en_US.UTF-8 等常用 locale
```

## 解决方案

```bash
# 跳过 locale 相关测试
python3 -m test -x test_locale test_c_locale_coercion

# 使用默认 locale
export LC_ALL=C
```

## 涉及软件

Python 3.9.0（test_locale、test_c_locale_coercion）

# E377: Bind test-only ExternalProject sources locally without reducing the upstream test inventory

## 基本信息
- **严重度**: 3
- **类别**: cmake, externalproject, offline-source, upstream-tests
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5392

## 错误特征
```
Performing download step \(git clone\) for 'KWStyle'|KWStyle-download.*Command failed
```

## 根因分析
Enabling a project's real upstream tests may activate a test-tool ExternalProject whose build-time Git clone is unavailable on the target even though the main source is frozen.

## 推荐方案
**方法**: checksum-bound-local-externalproject-source

**说明**: Keep the upstream test entry enabled, fetch the fixed auxiliary revision during recipe source acquisition, and bind the extracted local directory into ExternalProject with downloads forbidden.

**验证/命令**:
```
Set a project-specific local source directory, enable the no-download gate, and require generated ExternalProject dirinfo to report method=source_dir with an empty command.
```

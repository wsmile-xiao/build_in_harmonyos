# E250: OHOS 原生环境不含 Go 工具链，go build 失败

## 基本信息
- **严重度**: 3
- **类别**: toolchain, go
- **作者**: goblinrs <goblinrs@yeah.net>
- **来源 PR**: source_commit:

## 错误特征
```
go.*inaccessible or not found|go: command not found|make.*go.*not found|go: No such file or directory|go not found
```

## 根因分析
OpenHarmony PC 原生环境未预装 Go 工具链（/bin/sh: go: inaccessible or not found），导致所有 Go 语言项目的编译步骤失败。PATH 中不包含 go 二进制。

## 推荐方案
**方法**: download-go-sdk

**说明**: 在 conanfile.py build() 中自动下载 Go SDK 二进制发布版，解压后设置 GOROOT 和 PATH，然后执行 go build。使用 conan.tools.files.get() 下载并验证 SHA256。

**验证/命令**:
```
get(self, url=f"https://go.dev/dl/go{go_version}.linux-arm64.tar.gz", sha256=go_sha256, destination=go_dest, strip_root=False)  # 设置 os.environ["GOROOT"] 和 os.environ["PATH"]
```

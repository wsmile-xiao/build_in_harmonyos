# E030: 鸿蒙无 32 位兼容层导致编译失败

> **结构化数据**: [graph/E030.kv](../graph/E030.kv) | **原则**: 无
> **严重度**: 🟢 low | **分类**: architecture/configure | **自动修复**: ✅ reconfigure

---

## 错误特征

```
configure 阶段 m32 personality 检测失败
m32.*personality.*fail|32-bit.*not supported
```

## 根因

strace 等工具默认启用 32 位程序追踪支持（m32 personality），鸿蒙系统仅有 aarch64 架构，无 32 位兼容层。

## 解决方案

```bash
./configure --disable-mpers --prefix=$HOME/usr/local
make && make install
```

## 涉及软件

strace 6.19 及其他需要多架构支持的调试/追踪工具。

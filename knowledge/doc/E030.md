# E030: configure-disable-feature

## 基本信息
- **严重度**: 1
- **类别**: configure, architecture
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
m32.*personality.*fail|32-bit.*not supported|
                         --disable-mpers|aarch64.*only
```

## 根因分析
某些工具(strace 等)默认启用 32 位程序追踪支持(m32 personality),
                         鸿蒙系统仅有 aarch64 架构, 无 32 位兼容层

## 推荐方案
**方法**: configure-disable-feature

**说明**: 禁用 32 位支持(--disable-mpers), 仅保留 aarch64 支持

**验证/命令**:
```
./configure --disable-mpers --prefix=$HOME/usr/local
```

## 关键词
m32, 32-bit, personality, strace, aarch64 only,
                         --disable-mpers, cross compile, architecture mismatch

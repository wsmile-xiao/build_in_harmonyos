# E059: use-stable-release

## 基本信息
- **严重度**: 3
- **类别**: autotools
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
@am_AUTOM4TE@.*inaccessible|sh: @am_AUTOM4TE@.*not found|aclocal.*error.*@am_AUTOM4TE@
```

## 根因分析
aclocal.m4 文件在打包时未正确处理 automake 宏变量，导致 @am_AUTOM4TE@ 占位符未被替换为实际路径。
                        这是打包脚本或 autotools 配置文件的问题，而非源码本身的问题。

## 推荐方案
**方法**: use-stable-release

**说明**: 使用稳定版本的源码包（包含完整的 aclocal.m4），避免开发版本打包不完整的问题。

**验证/命令**:
```
|
  # 检查 aclocal.m4 是否包含占位符
  grep "@am_" aclocal.m4
  # 如果有占位符，说明源码包不完整，应使用稳定版本
  cd ..
  curl -LO <stable-version-url>
  tar xf <stable-version.tar>
  cd <stable-version>
  ./configure --prefix=$DEFAULT_PREFIX
```

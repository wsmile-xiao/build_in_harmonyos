# E059: use-stable-release

## 基本信息
- **严重度**: 3
- **类别**: autotools-bootstrap
- **触发工具**: aclocal/autogen.sh
- **阶段**: configuration

## 错误特征
```
@am_AUTOM4TE@.*inaccessible|sh: @am_AUTOM4TE@.*not found|aclocal.*error.*@am_AUTOM4TE@
```

**关键词**: AUTOM4TE, aclocal.m4, placeholder, automake, bootstrap, configure.ac

## 根因分析
aclocal.m4 文件在打包时未正确处理 automake 宏变量，导致 @am_AUTOM4TE@ 占位符未被替换为实际路径。

**影响范围**: 所有包含不完整 aclocal.m4 的 Autotools 项目

## 推荐方案
- **方法**: use-stable-release
- **描述**: 使用稳定版本的源码包（包含完整的 aclocal.m4），避免开发版本打包不完整的问题。
- **命令**: `|`
- **自动修复**: false

## 验证
```bash
grep "@am_AUTOM4TE@" aclocal.m4 || grep "@am_" aclocal.m4
```

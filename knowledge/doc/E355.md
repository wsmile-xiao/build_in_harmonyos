## 错误特征
```
Unsupported platform|Dependency .* not found|file not found|prefix=/|failed to map segment
```

## 根因分析
OHOS 上 meson 的 host_machine.system() 返回 harmonyos（非 linux/darwin/windows），meson 子项目（如 luajit）的平台检测报 Unsupported platform，需映射到 linux 分支；conan 制品 .pc 的 prefix=/ 错误导致 -I//include 空前缀需修正；boost 制品裁剪 interprocess/locale/asio/charconv 模块头与 libboost_locale 编译库需从 GitHub 补全+手工编译

## 推荐方案
**方法**: patch-meson-platform

**说明**: OHOS meson 适配三步：①host_machine.system() 返回 harmonyos 时映射 linux 分支（LUAJIT_OS_LINUX + elfasm）解决子项目 Unsupported platform；②修正 conan 制品 .pc 的 prefix=/（freetype/harfbuzz/fontconfig/icu/boost/wx-baseu/fftw3）；③补全 boost 制品裁剪模块头（interprocess/locale/asio/charconv 从 GitHub 下载）+ 手工编译 libboost_locale.a（15 共享源 + ICU/STD 后端，NO_POSIX/NO_WINAPI_BACKEND 避开 glibc 专有 strfmon_l）

**验证/命令**:
```
grep -n "host_machine.system" <src>/meson.build && 在子项目平台检测处把
                        harmonyos/ohos 并入 linux 分支（如 luajit: if host_machine.system() in
                        ['linux','harmonyos','ohos']）+ 修正 conan 制品 .pc 的 prefix=/ +
                        补全 boost 裁剪模块头并手工编译 libboost_locale.a
```

# E351: AbiWord 导出方向插件（GsfOutput）需要扩展 compat shim：可增长内存缓冲 gsf-output.h + IE_Exp 导出框架；并补齐上游被禁用的 xxx_UT_DEBUGMSG 宏

## 错误特征
```
xxx_UT_DEBUGMSG.*undeclared|gsf_off_t.*unknown type|UT_ASSERT.*undeclared identifier|GsfOutput.*no member|recognizeSuffix.*GsfOutput
```

## 根因分析
AbiWord 插件若含导出方向（IE_Exp），上游代码依赖 libgsf GsfOutput API（gsf_output_write/seek/tell）与 AbiWord IE_Exp 框架。clarisworks 版 compat shim 只覆盖导入方向（GsfInput+IE_Imp）。此外上游 ie_exp_PalmDoc.cpp 使用永久禁用的调试宏 xxx_UT_DEBUGMSG、ie_impexp_PalmDoc.cpp 经 ie_imp.h 传递使用 UT_ASSERT，ut_debugmsg.h/ie_imp.h 若不补齐则编译报 undeclared identifier；gsf_off_t 在 gsf-input.h/gsf-output.h 各自 typedef 需要统一守卫。

## 推荐方案
**方法**: extend-compat-shim-export-direction

**说明**: compat/ 新增 gsf/gsf-output.h（可增长内存缓冲 + gsf_output_write/seek/tell/get_data/get_size 测试钩子）、ie_exp.h（IE_ExpSniffer/IE_Exp 导出框架 + registerExporter）、ie_exp_Text.h（文本导出基类，遍历 PD_Document 文本 span 调 _writeBytes）；glib.h 增加 gsf_off_t 统一守卫 typedef、GObject ref/unref、g_ascii_strcasecmp；ut_debugmsg.h 补齐 xxx_UT_DEBUGMSG；ie_imp.h include ut_assert.h；新增源码走 conanfile.py export_sources（不生成 new-file 补丁，E258 草稿）。

**验证/命令**:
```
cp -r archives/a/abiword-plugin-clarisworks/3.0.8/compat compat && (按上述描述扩展 compat 后) autoreconf -fi && ./configure --prefix=$DEFAULT_PREFIX --build=aarch64-unknown-linux-ohos --host=aarch64-unknown-linux-ohos && make -j1 && make check -j1
```

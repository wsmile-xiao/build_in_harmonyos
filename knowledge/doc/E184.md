```
ant.*command not found|mvn.*command not found|gradle.*command not found|Cannot run program "ant"
```

## 根因分析
鸿蒙平台未预装Java构建工具(Ant/Maven/Gradle),cmd-pkgs无预编译包,需手动安装

## 推荐方案
**方法**: manual-install-ant

**说明**: 从Apache官方下载Ant二进制发布版,解压并配置环境变量

**验证/命令**:
```
curl -k -L https://archive.apache.org/dist/ant/binaries/apache-ant-1.10.14-bin.tar.gz -o ~/downloads/ant.tar.gz && tar -xzf ~/downloads/ant.tar.gz -C ~/usr/local/ && export ANT_HOME=~/usr/local/apache-ant-1.10.14 && export PATH=$ANT_HOME/bin:$PATH
```

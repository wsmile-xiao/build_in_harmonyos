# E184: manual-install-ant

## 基本信息
- **严重度**: 2
- **类别**: environment|build_tool_missing
- **触发工具**: ant|maven|gradle|java
- **阶段**: configuration

## 错误特征
```
ant.*command not found|mvn.*command not found|gradle.*command not found|Cannot run program "ant"
```

**关键词**: ant, maven, gradle, java, build.xml, pom.xml, build.gradle, command not found

## 根因分析
鸿蒙平台未预装Java构建工具(Ant/Maven/Gradle),cmd-pkgs无预编译包,需手动安装

**影响范围**: 所有Java项目(Tomcat,Hadoop,Spring等使用Ant/Maven/Gradle构建的软件)

## 推荐方案
- **方法**: manual-install-ant
- **描述**: 从Apache官方下载Ant二进制发布版,解压并配置环境变量
- **命令**: `curl -k -L https://archive.apache.org/dist/ant/binaries/apache-ant-1.10.14-bin.tar.gz -o ~/downloads/ant.tar.gz && tar -xzf ~/downloads/ant.tar.gz -C ~/usr/local/ && export ANT_HOME=~/usr/local/apache-ant-1.10.14 && export PATH=$ANT_HOME/bin:$PATH`
- **自动修复**: false

## 验证
```bash
ant -version 2>&1 || echo "Ant not installed"; mvn -version 2>&1 || echo "Maven not installed"
```

# E519: out-of-source 构建 install-data-am 的 $(EXTRA_DIST) 相对路径找不到源文件

## 基本信息
- **严重度**: 2
- **类别**: autotools, conan, packaging
- **作者**: wanderlust_0823 <wanderlust_0823@noreply.gitcode.com>
- **来源 PR**: !7077

## 错误特征
```
ginstall: cannot stat '[a-z-]+\.txt': No such file or directory
```

## 根因分析
conan 默认 out-of-source 构建（build-release 子目录），install-data-am 直接用 $(EXTRA_DIST) 安装文件，相对路径从 build 目录解析找不到源文件（如 vars-pl.txt）。需改为 $(addprefix $(srcdir)/,$(EXTRA_DIST))，contrib/docs 的 $(DOCS)/themes/* 同理。

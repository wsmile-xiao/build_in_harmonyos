# E014: 系统调用不可用

> **结构化数据**: [graph/E014.kv](../graph/E014.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: syscall/compat | **自动修复**: ✅ set-env-var / ❌ 需源码补丁(hilog)

---

## 错误特征

```
undefined reference to `syslog`
undefined reference to `getrandom`
```

## 根因

鸿蒙内核未实现某些 POSIX 系统调用，或 musl 未导出对应符号。

## 解决方案

**优先级1：禁用功能（自动修复）**

```bash
export CFLAGS="-DNO_SYSLOG $CFLAGS"
```

**回退方案：用鸿蒙 hilog 接口替代 syslog**

```c
// 替代 syslog(LOG_INFO, "msg") → OH_LOG_INFO
#include <hilog/log.h>

#ifdef __OHOS__
#define LOG_INFO(tag, fmt, ...) OH_LOG_INFO(LOG_APP, fmt, ##__VA_ARGS__)
#else
#include <syslog.h>
#define LOG_INFO(tag, fmt, ...) syslog(LOG_INFO, fmt, ##__VA_ARGS__)
#endif
```

## 涉及软件

使用 syslog 日志、getrandom 随机数等 API 的项目。

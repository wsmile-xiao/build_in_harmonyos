# E254: toybox patch --dry-run 真实应用 new-file 补丁，破坏补丁管线

## 基本信息
- **严重度**: 3
- **类别**: compat, toolchain, patch
- **作者**: mkz--mkz <ak74A3WKxU__vozN.mkz--mkz@noreply.gitcode.com>
- **来源 PR**: source_commit:

## 错误特征
```
patch.*dry-run|creating .*\.patch|source/target file does not exist|Failed to apply patch:.*\.patch
```

## 根因分析
鸿蒙默认 /usr/bin/patch 是 toybox 0.8.12。其 `patch --dry-run`
                        对 new-file 补丁（--- /dev/null → +++ b/...）会真实创建文件
                        （输出 "creating new.txt"），忽略 --dry-run 语义。
                        refresh-patch 的 dry-run 校验因此污染 orig 目录：
                        下一轮扫描把该文件误判为 MOD（diff_files），生成的补丁带
                        a/ b/ 前缀，patch_ng（conan apply_conandata_patches 内部）
                        无法解析/应用，conan create 在 source() 阶段失败。

## 推荐方案
**方法**: avoid-new-file-patches

**说明**: 补丁只保留修改文件（modified-file diff），新增源码文件通过
                        conanfile.py export_sources 传递，彻底避免 toybox new-file
                        dry-run 污染路径。toybox 对修改文件 diff 的 dry-run 不真实应用。

**验证/命令**:
```
|
  # conanfile.py: 新增源码不写补丁，走 export_sources
  def export_sources(self):
      export_conandata_patches(self)
      copy(self, "*", src=os.path.join(self.recipe_folder, "compat"),
           dst=os.path.join(self.export_sources_folder, "compat"))
  # conandata.yml: 只列修改文件补丁
  #   - patch_file: "patches/0001-Makefile.am.patch"
```

## 关键词
toybox, patch, dry-run, new-file, 污染, orig 目录, refresh-patch, patch_ng, 无法应用

## 错误特征
```
CMAKE_SYSTEM_NAME=OHOS|CMAKE_SYSTEM_NAME=HarmonyOS|CMAKE_SYSTEM_NAME:STRING=OHOS|CMAKE_SYSTEM_NAME:STRING=HarmonyOS|System is unknown to cmake|OS_LINUX not defined
```

## 根因分析
OpenHarmony toolchains do not use CMAKE_SYSTEM_NAME=Linux consistently: the official SDK uses OHOS while the adapted Conan toolchain may use HarmonyOS, so Linux-only or single-spelling platform guards silently miss one build path

## 推荐方案
**方法**: add-harmonyos-cmake-detection

**说明**: Match both official spellings with CMAKE_SYSTEM_NAME MATCHES "^(OHOS|HarmonyOS)$" for OpenHarmony-specific routing; when source behavior depends on that decision, inject a project-local PRIVATE feature macro into the target that actually compiles the source, including the underlying object-library target created by build helpers

**验证/命令**:
```
grep -R -E 'CMAKE_SYSTEM_NAME.*(OHOS|HarmonyOS)|target_compile_definitions' CMakeLists.txt cmake 2>/dev/null
```

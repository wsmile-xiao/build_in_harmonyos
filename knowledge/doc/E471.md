# E471: OHOS PC 无任何原生显示后端；gtkmm 4.0.0 tests/meson.build 的「可执行测试」(exe

## 基本信息
- **严重度**: 3
- **类别**: platform, meson, testing, binding, display
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !7140

## 错误特征
```
Failed to open display|
                    Gtk-WARNING.*Failed to open display|
                    Fontconfig error: Cannot load default config file|
                    gtk_init.*failed|
                    gtk4-broadwayd.*Operation not permitted|
                    exit status 1.*display
```

## 根因分析
OHOS PC 无任何原生显示后端；gtkmm 4.0.0 tests/meson.build
                    的「可执行测试」(execute=true) 与「GUI 测试」标志不等价——
                    4 个 execute=true 测试中 3 个仍调用 gtk_init()（需显示服务
                    器），无显示环境下 gtk_init() 失败、进程 exit 1；gtk_init()
                    前置 fontconfig 在无 /etc/fonts/fonts.conf 的 OHOS 上也失败；
                    提供显示服务的 gtk4-broadwayd 在 OHOS 因签名约束不可执行
                    (EPERM)。这些是真实显示依赖而非库缺陷，需按显示依赖分类，
                    不能写成库测试失败或强行 headless 假装通过。

## 推荐方案
**方法**: display-test-classification-and-no-display-api-probes

**说明**: ① tests/meson.build 把真实调用 gtk_init()/建窗口的测试标记
                    failing suite（suite:['failing']），CI/构建统一
                    meson test --no-suite=failing 排除并记录真实原因（glibmm
                    E215 同款）；② build() 运行 meson test 前注入 fontconfig
                    包真实配置 FONTCONFIG_FILE/PATH（否则无显示 API 测试也因
                    fonts.conf 缺失失败）；③ 新增不依赖显示器的公开 API 探针
                    （Gdk::RGBA set_rgba_u/get_red_u、Gdk::Rectangle、sigc++-3.0
                    连接）作为鸿蒙特有测试并单独统计；④ 显示依赖测试不可运行
                    （broadwayd EPERM）时如实记录「需 Broadway 服务或真实显示
                    环境」，禁止跳过填 100% 或将 EPERM 写成构建失败。

**验证/命令**:
```
|
  # tests/meson.build（0003 补丁同款）
  if ex[4]
    if ex_name in ['bitset_iterator_test', 'object_move_test', 'tree_model_iterator_test']
      test(ex_name, exe_file, suite: ['failing'])
    else
      test(ex_name, exe_file)
    endif
  endif
  # conanfile.py build()（fontconfig 注入）
  #   os.environ["FONTCONFIG_FILE"] = f"{fontconfig_pkg}/etc/fonts/fonts.conf"
  #   os.environ["FONTCONFIG_PATH"] = f"{fontconfig_pkg}/etc/fonts"
  # 测试运行：
  #   meson test -v -C {build} --timeout-multiplier=16 --no-rebuild --no-suite=failing
  #   测试统计口径：真实运行 / 显示依赖不可运行(failing 排除) / 构建但不执行
```

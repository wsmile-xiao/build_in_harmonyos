# E180: rust-native-compile

## 基本信息
- **严重度**: 0
- **类别**: toolchain|rust|resolved
- **触发工具**: cargo|rustc|rust
- **阶段**: configuration|compilation

## 错误特征
```
cargo: No such file or directory|rustc: command not found|ld-linux-aarch64.so.1: No such file
```

**关键词**: rust, cargo, rustc, glibc, musl, OHOS target

## 根因分析
新HNP工具链已添加Rust 1.95.0，支持OHOS target

**影响范围**: 50+ Rust项目（ripgrep, fd, bat, htop, procs等）

## 推荐方案
- **方法**: rust-native-compile
- **描述**: 直接使用rustc/cargo编译，默认target已是aarch64-unknown-linux-ohos
- **命令**: `rustc main.rs -o hello || cargo build --release`
- **自动修复**: true

## 验证
```bash
rustc --version && cargo --version
```

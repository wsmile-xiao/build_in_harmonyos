# E239: Preserve complete diagnostics across multi-case Conan test_package runs

## 基本信息
- **严重度**: 2
- **类别**: conan
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
first failing self.run stops remaining consumer cases|non-zero consumer result has no failure output
```

## 根因分析
Conan self.run raises ConanException on the first non-zero command by default, so a plain loop never executes later independent cases. If the consumer also returns non-zero without printing its case and result, the surviving exception identifies only the command and hides the program-level failure context.

## 推荐方案
**方法**: catch-record-continue-then-raise

**说明**: Catch only ConanException around each self.run call, append the case name and unchanged exception text, continue through the full case list, then raise one ConanException containing every failure. Make the consumer print FAIL plus its case name and result code for recognized non-zero results while returning the same code.

**验证/命令**:
```
Accumulate f"{case}: {error}" for each ConanException and raise once after the loop; emit "FAIL <case> result=<code>" before returning a recognized non-zero result.
```

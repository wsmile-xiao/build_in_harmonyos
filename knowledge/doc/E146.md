# E146: use_precompiled_package

## 基本信息
- **严重度**: 2
- **类别**: dependency_handling
- **触发工具**: configure|make
- **阶段**: configuration|compilation

## 错误特征
```
checking for .*... no|Package '.*' not found|cannot find -l.*|fatal error: .*: No such file
```

**关键词**: dependency, missing, precompiled, external, Alpine, cmd-pkgs

## 根因分析
编译过程中发现缺少库依赖（如 libpcap/zlib/openssl），但本地编译遇到工具链限制（如 bison/flex pipe 问题）

**影响范围**: 编译流程中依赖处理阶段

## 推荐方案
- **方法**: use_precompiled_package
- **描述**: 从 cmd-pkgs 获取预编译包，避免本地编译工具链问题
- **命令**: `curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- <name> <ver>`
- **自动修复**: true

## 验证
```bash
ls ~/usr/local/lib/lib*.a | grep <dependency_name>
```

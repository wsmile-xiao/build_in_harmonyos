# E191: approach-identifier          # 见 DESIGN §5 impl 列表

## 基本信息
- **严重度**: 2
- **类别**: linking|platform
- **触发工具**: cmake|clang|ld
- **阶段**: configuration|linking

## 错误特征
```
unable to find library -lc\+\+|unable to find library -lc\+\+abi|is not able to compile a simple test program
```

**关键词**: libc++, libc++abi, clang++, unable to find library, CXX compiler, broken

## 根因分析
HarmonyOS clang++ default linker configuration cannot find libc++ and libc++abi shared libraries in standard search paths

**影响范围**: All C++ CMake projects on HarmonyOS where linking is not needed (header-only libraries)

## 推荐方案
- **方法**: approach-identifier          # 见 DESIGN §5 impl 列表
- **描述**: For header-only or CMake libraries, use -DCMAKE_TRY_COMPILE_TARGET_TYPE=STATIC_LIBRARY to bypass the executable link test
- **命令**: `cmake .. -DCMAKE_TRY_COMPILE_TARGET_TYPE=STATIC_LIBRARY -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX`
- **自动修复**: true|false                  # 引擎能否自动执行

## 验证
```bash
cmake .. -DCMAKE_TRY_COMPILE_TARGET_TYPE=STATIC_LIBRARY
```

# E107: create-intermediate-library

## 基本信息
- **严重度**: 3
- **类别**: linking
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
undefined reference to.*g_libintl_|g_libintl_bind_textdomain_codeset|libintl.a.*符号缺失
```

## 根因分析
GLib 编译为静态库时依赖 libintl.a 中的 g_libintl_* 符号，
                        但系统预编译的 gettext 只提供标准 libintl.so，
                        缺少这些 GLib 特有的封装符号

## 推荐方案
**方法**: create-intermediate-library

**说明**: 创建中间共享库，将 libintl.a 中的 g_libintl_* 符号导出为动态符号，解决 GLib 静态库依赖 libintl 动态库的符号缺失问题。具体步骤：1) 用 objcopy 从 libintl.a 提取所需符号创建中间 .o 文件；2) 链接为共享库 libintl_shim.so；3) 在链接命令中添加该中间库。

                        所有依赖 GLib 静态库的共享库链接此中间库

**验证/命令**:
```
nm libintl.so | grep g_libintl; nm libintl.a | grep g_libintl
```

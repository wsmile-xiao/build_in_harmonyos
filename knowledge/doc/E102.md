# E102: mmsg API 缺失 (struct mmsghdr, recvmmsg, sendmmsg)

## 错误特征
```
storage size of 'mmsghdr' isn't known
incomplete type 'struct mmsghdr'
undeclared identifier 'recvmmsg'
undeclared identifier 'sendmmsg'
```

## 根因
OHOS 使用 musl libc，未实现 Linux 批量消息 API。源码用 `__linux__` 宏判断平台但误将 OHOS 识别为 Linux。

## 解决方案
在 mmsg API 代码块前排除 OHOS：
```c
#if defined(__linux__) && !defined(__OHOS__)
  // mmsg code
#endif
```

## 受影响软件
高性能网络库（libuv, libevent, nginx, redis）

## 禁止做法
- ❌ 启用 `--enable-mmsg` 或 `--with-mmsg` 选项

---
**发现于**: libuv 1.52.1 编译

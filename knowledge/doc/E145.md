# E145: source-patch

## 基本信息
- **严重度**: 3
- **类别**: meson|variable_undefined|subdir_order
- **触发工具**: meson
- **阶段**: configuration

## 错误特征
```
ERROR: Unknown variable "have_arm_intrinsics_or_asm"
```

**关键词**: meson, Unknown variable, have_arm_intrinsics_or_asm, subdir, silk, celt, opus

## 根因分析
meson.build 的 subdir() 调用顺序错误, silk/meson.build 使用了在 celt/meson.build 中定义的变量 have_arm_intrinsics_or_asm, 但 silk 在 celt 之前被调用导致变量未定义

**影响范围**: opus 1.4 及其他 meson 构建系统中存在跨 subdir 变量依赖的项目

## 推荐方案
- **方法**: source-patch
- **描述**: 在主 meson.build 的第一个 subdir() 调用之前添加变量定义, 将 celt/meson.build 中的变量定义移到主文件中
- **命令**: `sed -i '/subdir('include')/i # Define have_arm_intrinsics_or_asm before silk subdir\nhave_arm_intrinsics_or_asm = have_arm_ne10\nif (intrinsics_support.length() + asm_optimization.length() + inline_optimization.length()) > 0\n  have_arm_intrinsics_or_asm = true\nendif\n' meson.build`
- **自动修复**: true

## 验证
```bash
grep -n "have_arm_intrinsics_or_asm" */meson.build
```

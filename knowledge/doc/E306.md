# E306: Replace negative-radius std::polar calls with explicit complex components

## 基本信息
- **严重度**: 2
- **类别**: c++
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: source_commit:

## 错误特征
```
std::polar.*negative|polar=nan,nan|Pole to add is NaN
```

## 根因分析
The C++ std::polar contract requires a non-negative finite radius. Passing a negative radius has undefined behavior; libstdc++ may return the expected finite components while HarmonyOS libc++ returns NaN components.

## 推荐方案
**方法**: construct-complex-components

**说明**: Preserve the intended signed complex value by constructing rho*cos(theta) and rho*sin(theta) explicitly, or normalize the sign into a pi angle offset before calling std::polar.

**验证/命令**:
```
Replace std::polar(rho, theta) for negative rho with complex_t(rho * cos(theta), rho * sin(theta)).
```

```
Permission denied.*binary|make check.*all fail|

```

## 根因分析
鸿蒙安全机制要求用户确认非系统预装二进制的执行权限。
                         首次执行时弹出安全确认弹窗, 若超时未点则进程被杀。
                         导致 make install 后产物无法立即使用, make check 全部误判为功能问题

## 推荐方案
**方法**: batch-trigger-execution

**说明**: make install 后批量触发所有二进制的首次执行以完成安全确认:
                         find $PREFIX/bin -type f -exec {} --version \;
                         或在 make check 前确保所有产物已确认

**验证/命令**:
```
find $PREFIX/bin -type f -exec {} --version \; 2>/dev/null
```

# E054: 外来二进制首次执行被安全确认弹窗阻止

> **严重度**: 🟡 medium | **分类**: security/runtime/harmonyos | **自动修复**: ✅ batch-command

## 错误特征

- 编译产物在 `make install` 后 Permission denied
- `make check` 中测试用例全部失败（误判为功能问题）
- 首次手动执行后问题消失

## 根因

鸿蒙安全机制要求用户确认非系统预装二进制的执行权限。首次执行时弹出安全确认弹窗。

## 解决方案

```bash
# 方案 1（推荐）：make install 后批量触发确认
find $PREFIX/bin -type f -exec {} --version \;

# 方案 2：单个二进制手动触发
$PREFIX/bin/program --version

# 方案 3：make check 前确保所有产物已完成确认
```

# E307: Conan test_package 缺少 CMake 时使用 profile 编译器直编

## 基本信息
- **严重度**: 2
- **类别**: headers, build-system, conan, testing
- **作者**: 1catmint1
- **来源 PR**: source_commit:

## 错误特征
```
cmake: inaccessible or not found|cmake: not found|CMake.configure.*Error 127|test package.*cmake.*not found
```

## 根因分析
Header-only 或协议头包只需要编译消费者对象，但通用 test_package 引入 CMakeToolchain/CMakeDeps 后，会把目标机未安装的 CMake 变成不必要的运行前置；包本身可用，测试却在 CMake 启动前以 127 失败。

## 推荐方案
**方法**: profile-compiler-direct-compile

**说明**: 在 test_package.build() 中从 tools.build:compiler_executables 读取 C/C++ 编译器，对每个独立公共头生成单独源文件并执行 compile-only；配置缺失时明确失败，不依赖 CC/CXX 或裸 cc/clang 回退。

**验证/命令**:
```
self.conf.get("tools.build:compiler_executables", default={}, check_type=dict)
```

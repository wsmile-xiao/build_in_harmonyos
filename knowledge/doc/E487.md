# E487: qt6linguisttools-tool-require-plus-pin-DIR

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, kf6, linguisttools, qt6
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: !7134

## 错误特征
```
Could NOT find Qt6LinguistTools (missing: Qt6LinguistTools_DIR)|
                         Failed to find required Qt component "LinguistTools"|
                         Expected Config file at .*lib/cmake/Qt6LinguistTools/Qt6LinguistToolsConfig.cmake.* does NOT exist|
                         ECMPoQmTools\.cmake:155 \(find_package\)|
```

## 根因分析
KF6 上游（ECMPoQmTools.cmake:155）在 configure 阶段调用
                         find_package(Qt6 COMPONENTS LinguistTools) 做 poqm 翻译。
                         qtbase 包不提供 Qt6::LinguistTools 组件（LinguistTools 实体
                         由 qttools 构建产生：lrelease/lupdate/lconvert +
                         Qt6LinguistToolsConfig.cmake）。Qt6Config.cmake 的组件解析
                         锚定 Qt6_DIR（qtbase 的 lib/cmake/Qt6）相对路径，因此
                         单独发布安装的 qt6linguisttools 包不会被自动发现，
                         即使其 builddirs 已加入 CMAKE_PREFIX_PATH，configure 仍报
                         "Failed to find required Qt component LinguistTools"。

## 推荐方案
**方法**: qt6linguisttools-tool-require-plus-pin-DIR

**说明**: >
  1) 将 qt6linguisttools/6.11.1（ohpcd 已发布，revision 021a6867…，与 Qt 6.11.1 匹配）
  作为构建期 tool_requires 声明；
  2) generate() 中显式设置 CMakeToolchain 变量
  Qt6LinguistTools_DIR = <qt6linguisttools 包>/lib/cmake/Qt6LinguistTools，让
  ECMPoQmTools 的 find_package(Qt6 COMPONENTS LinguistTools) 直接命中独立包；
  3) 在 conan_cmakedeps_paths.cmake 追加其 lib/cmake 与 lib/cmake/Qt6LinguistTools
  到 CMAKE_PREFIX_PATH/CMAKE_MODULE_PATH。禁止 --build=missing 从源码重编 qttools。

**验证/命令**:
```
self.tool_requires("qt6linguisttools/6.11.1")  +  tc.variables["Qt6LinguistTools_DIR"]=os.path.join(ltt.package_folder,"lib","cmake","Qt6LinguistTools")
```

# E009: SELinux 域转换限制

> **结构化数据**: [graph/E009.kv](../graph/E009.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: selinux/security | **自动修复**: ✅ pipe-bypass

---

## 错误特征

```
clang --version  → exit code: 1 (Permission denied)
subprocess 调用编译器失败
```

## 根因

鸿蒙 SELinux 策略限制域转换：

```
Shell 进程 (hishell_hap:s0)
    │
    └─ 执行用户二进制（如 Python）
        │
        └─ 域转换为 adhoc_bin:s0
            │
            └─ 无法执行 hnp_file 类型文件（SDK 工具）
```

## 验证命令

```bash
# Python subprocess 测试（最易复现的场景）
python3 -c "import subprocess; r=subprocess.run(['clang','--version']); print(f'rc={r.returncode}')"
# 失败: rc=1

# 管道绕过测试
python3 -c "import subprocess; r=subprocess.run('clang --version | cat', shell=True); print(f'rc={r.returncode}')"
# 成功: rc=0
```

## 解决方案

使用管道语法绕过：

```python
# ❌ 失败
os.system("clang --version")          # exit code: 1

# ✅ 成功
os.system("clang --version | cat")    # exit code: 0
os.system("clang --version 2>&1 | cat")  # 推荐（同时捕获 stderr）
```

**原理**：管道强制 shell 创建有权限的子进程。

**适用场景**：Python `os.system()` / `subprocess`、Makefile 中调用 SDK 工具、shell 脚本子进程。

## 涉及软件

Python、任何通过 subprocess/Makefile 调用 clang/gcc 的构建系统。

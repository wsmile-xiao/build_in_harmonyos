# E009: pipe-bypass

## 基本信息
- **严重度**: 2
- **类别**: selinux, security
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
Permission denied.*clang|
                         subprocess.*exit code.*1.*clang|
                         cannot execute.*hnp_file|
                         adhoc_bin.*hnp_file
```

## 根因分析
鸿蒙 SELinux 策略限制域转换:
                         Shell 进程(hishell_hap:s0)执行用户二进制时
                         域转换为 adhoc_bin:s0, 后者无权执行
                         hnp_file 类型的 SDK 工具(如 clang)

## 推荐方案
**方法**: pipe-bypass

**说明**: 使用管道语法绕过 SELinux 域限制:
                         将 "cmd" 改为 "cmd | cat" 或 "cmd 2>&1 | cat"

**验证/命令**:
```
rec_auto_fix:          true
```

## 错误特征
```
fatal error: 'argp\.h' file not found|argp\.h: No such file or directory
```

## 根因分析
OpenHarmony 系统缺少 GNU argp.h 头文件。argp.h 是 GNU C 库的一部分，
                        用于命令行参数解析，但 OpenHarmony 使用 musl libc，不包含此头文件。
                        需要安装 argp-standalone 库或手动安装相关文件。

## 推荐方案
**方法**: install-prebuilt-package

**说明**: 安装 argp-standalone 预编译包（包含 argp.h 和 libargp.a）

**验证/命令**:
```
curl -k -LO https://example.com/argp-standalone-1.5.0-ohos-aarch64.tar.gz &&
                        tar -xzf argp-standalone-1.5.0-ohos-aarch64.tar.gz -C ~/usr/local
```

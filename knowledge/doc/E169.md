# E169: install-prebuilt-package

## 基本信息
- **严重度**: 3
- **类别**: missing-header|platform-limitation
- **触发工具**: clang|clang++|gcc|g++
- **阶段**: compilation

## 错误特征
```
fatal error: 'argp\.h' file not found|argp\.h: No such file or directory
```

**关键词**: argp.h, fatal error, file not found, GNU argp, command-line parsing

## 根因分析
OpenHarmony 系统缺少 GNU argp.h 头文件。argp.h 是 GNU C 库的一部分，

**影响范围**: 使用 GNU argp 进行命令行参数解析的项目（如 incron, util-linux 部分工具）

## 推荐方案
- **方法**: install-prebuilt-package
- **描述**: 安装 argp-standalone 预编译包（包含 argp.h 和 libargp.a）
- **命令**: `curl -k -LO https://example.com/argp-standalone-1.5.0-ohos-aarch64.tar.gz &&`
- **自动修复**: false

## 验证
```bash
test -f ~/usr/local/include/argp.h && echo "argp.h exists" || echo "argp.h missing"
```

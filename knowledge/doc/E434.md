# E434: automake copystamp 目标 in-tree 构建时 cp 同文件失败（须 VPATH 构建）

## 基本信息
- **严重度**: 2
- **类别**: autotools
- **作者**: yanjiaxin <yanjiaxin@noreply.gitcode.com>
- **来源 PR**: !6301

## 错误特征
```
copystamp: Error 1|cp: bad '.*MANIFEST.in': No such file or directory|cp: '.*' and '.*' are the same file
```

## 根因分析
上游 Makefile.am 的 copystamp 执行 cp $(srcdir)/$f ./（为 distutils/setuptools 非 VPATH-aware 拷贝文件）；in-tree 构建时 srcdir==builddir，cp 同文件报 "same file"；若先用 make distclean 还会删除源里这些 COPY_FILES。

## 推荐方案
**方法**: vpath-build

**说明**: VPATH 构建：configure 在独立 build dir 运行（sh <src>/configure），make 也在 build dir；配方里 build_folder 天然是独立目录

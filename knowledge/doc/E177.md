# E177: source-patch

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **触发工具**: python

## 错误特征
```
ImportError: No module named 'distutils.msvccompiler'
```

**关键词**: distutils, msvccompiler, Python3.12, ImportError

## 根因分析
Python 3.12 移除了 distutils 模块，setuptools 提供的兼容层将 msvccompiler 重命名为 _msvccompiler

**影响范围**: 所有使用 distutils.msvccompiler 的软件（autotools 构建系统）

## 推荐方案
- **方法**: source-patch
- **描述**: 添加 try/except 导入 distutils._msvccompiler
- **命令**: `修改导入语句为 try/except 形式`
- **自动修复**: true

```bash
grep -r "from distutils.msvccompiler import" source/
```

# E181: manual-makefile-modify

## 基本信息
- **严重度**: 2
- **类别**: filesystem|hmdfs|autotools|build-system
- **触发工具**: configure|make
- **阶段**: configuration

## 错误特征
```
cat.*<<.*EOF.*Permission denied|cannot create temp file for here-document|heredoc.*failed|config.mak.*incomplete
```

**关键词**: heredoc, cat << EOF, Permission denied, HMDFS, config.mak, configure

## 根因分析
HMDFS 分布式文件系统不支持 shell heredoc（cat << EOF）语法，

**影响范围**: 所有使用 heredoc 创建配置文件的 autotools 项目：

## 推荐方案
- **方法**: manual-makefile-modify
- **描述**: 手动修改 Makefile，添加缺失的目标和变量定义，
- **命令**: `# 分析 Makefile 结构，添加缺失的定义：`
- **自动修复**: false

## 验证
```bash
cat > test.h << EOF
```

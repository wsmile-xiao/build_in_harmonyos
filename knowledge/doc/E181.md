## 错误特征
```
cat.*<<.*EOF.*Permission denied|cannot create temp file for here-document|heredoc.*failed|config.mak.*incomplete
```

## 根因分析
HMDFS 分布式文件系统不支持 shell heredoc（cat << EOF）语法，
                        configure 脚本无法创建配置文件（config.h、config.mak 等），
                        导致生成的配置文件内容不完整（只有 3 行而非几十行）。

## 推荐方案
**方法**: manual-makefile-modify

**说明**: 手动修改 Makefile，添加缺失的目标和变量定义，
                        强制编译所有需要的模块（如 8-bit、10-bit）。
                        适用于 Makefile 结构清晰、可手动补全的项目。

**验证/命令**:
```
# 分析 Makefile 结构，添加缺失的定义：
                        # OBJS += $(SRCS_X:%.c=%-8.o) $(SRCS_X:%.c=%-10.o)
                        # 强制编译 threadpool：SRCS += common/threadpool.c
                        make -j$(nproc)
```

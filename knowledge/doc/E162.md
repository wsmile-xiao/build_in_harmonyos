## 错误特征
```
use of undeclared identifier 'SSL_OP_NO_RENEGOTIATION'|use of undeclared identifier 'SSL_trace'|call to undeclared function 'SSL_get1_peer_certificate'
```

## 根因分析
OpenSSL 3.5.6 移除/重命名了部分 API：SSL_OP_NO_RENEGOTIATION 改为 SSL_OP_NO_CLIENT_RENEGOTIATION，SSL_get1_peer_certificate 不存在（应使用 SSL_get_peer_certificate），SSL_trace 函数被移除

## 推荐方案
**方法**: source-patch

**说明**: 应用 OpenSSL 3.5 兼容性补丁：替换已移除的 API

**验证/命令**:
```
# 修复 SSL_OP_NO_RENEGOTIATION
  sed -i 's/SSL_OP_NO_RENEGOTIATION/SSL_OP_NO_CLIENT_RENEGOTIATION/g' {源码文件}
  # 修复 SSL_get1_peer_certificate
  sed -i 's/SSL_get1_peer_certificate/SSL_get_peer_certificate/g' {源码文件}
  # 修复 SSL_trace（禁用 trace 功能）
  sed -i 's/SSL_CTX_set_msg_callback(ctx->ssl, SSL_trace)/SSL_CTX_set_msg_callback(ctx->ssl, NULL)/g' {源码文件}
```

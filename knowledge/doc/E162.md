# E162: source-patch

## 基本信息
- **严重度**: 2
- **类别**: api-compatibility|openssl
- **触发工具**: gcc|clang
- **阶段**: compilation

## 错误特征
```
use of undeclared identifier 'SSL_OP_NO_RENEGOTIATION'|use of undeclared identifier 'SSL_trace'|call to undeclared function 'SSL_get1_peer_certificate'
```

**关键词**: SSL_OP_NO_RENEGOTIATION, SSL_trace, SSL_get1_peer_certificate, OpenSSL 3.5, undeclared identifier

## 根因分析
OpenSSL 3.5.6 移除/重命名了部分 API：SSL_OP_NO_RENEGOTIATION 改为 SSL_OP_NO_CLIENT_RENEGOTIATION，SSL_get1_peer_certificate 不存在（应使用 SSL_get_peer_certificate），SSL_trace 函数被移除

**影响范围**: 使用旧版 OpenSSL API 的软件（ustream-ssl 等 OpenWrt 相关库）

## 推荐方案
- **方法**: source-patch
- **描述**: 应用 OpenSSL 3.5 兼容性补丁：替换已移除的 API
- **自动修复**: false

## 验证
```bash
grep -E "SSL_OP_NO_RENEGOTIATION|SSL_trace|SSL_get1_peer_certificate" {源码目录}/*.c
```

# E294: 共享包使用第二个静态构建树恢复完整上游测试

## 基本信息
- **严重度**: 2
- **类别**: cmake, cross-compile, testing
- **作者**: 2301_79503900 <3308319887@qq.com>
- **来源 PR**: 3013

## 错误特征
```
BUILD_SHARED_LIBS.*tests.*missing|shared.*only.*public.*tests|internal.*symbols.*static|upstream.*test.*targets.*not built
```

## 根因分析
部分 CMake 项目在 BUILD_SHARED_LIBS=ON 时只启用公共 API 测试，依赖内部符号的完整测试仅在静态构建中生成。直接把正式包改为静态会改变交付契约；直接关闭测试则丢失上游回归覆盖。交叉构建时还必须区分测试目标编译链接与目标端实际执行。

## 推荐方案
**方法**: dual-cmake-build-tree

**说明**: 正式构建树保持 shared 和 install；第二个不安装的构建树复用同一 Conan toolchain，设置 BUILD_SHARED_LIBS=OFF、测试 ON、安装 OFF，构建完整上游测试。can_run 为 true 时执行 CTest，为 false 时只记录编译链接证据。

**验证/命令**:
```
cmake -S . -B build-tests -DCMAKE_TOOLCHAIN_FILE=conan_toolchain.cmake -DBUILD_SHARED_LIBS=OFF -DBUILD_TESTING=ON -DCMAKE_SKIP_INSTALL_RULES=ON && cmake --build build-tests --parallel
```

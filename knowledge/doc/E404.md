# E404: OHOS zsh 5.9 missing standard autoload functions (is-at-least, compinit)

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, shell
- **作者**: ningyu <405888464@qq.com>
- **来源 PR**: !5710

## 错误特征
```
is-at-least:.*function definition file not found|compinit:.*function definition file not found|zsh:.*function definition file not found
```

## 根因分析
OHOS zsh 5.9 (aarch64-unknown-linux-musl) is installed without the standard autoload function files directory. Functions like is-at-least and compinit are part of zsh's standard distribution but the function files are not installed in the fpath on OHOS, causing any zsh script using autoload -Uz to fail.

## 推荐方案
**方法**: create-missing-zsh-function

**说明**: Create the missing is-at-least autoload function file in a directory on the zsh fpath (e.g., ~/.local/share/zsh/site-functions/). The function is a simple version comparison that can be recreated from the zsh source.

**验证/命令**:
```
mkdir -p ~/.local/share/zsh/site-functions && cat > ~/.local/share/zsh/site-functions/is-at-least << 'EOF'\nemulate -L zsh\nlocal i\nif [[ "$1" == *.* ]]; then\n  local IFS=.\n  local -a v1 v2\n  v1=(${=1})\n  v2=(${=ZSH_VERSION})\n  for ((i = 1; i <= ${#v1}; i++)); do\n    if (( ${v2[i]:-0} > ${v1[i]:-0} )); then return 0; elif (( ${v2[i]:-0} < ${v1[i]:-0} )); then return 1; fi\n  done\n  return 0\nelse\n  [[ ${ZSH_VERSION} -ge $1 ]]\nfi\nEOF
```

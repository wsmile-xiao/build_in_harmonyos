# E197: source-patch

## 基本信息
- **严重度**: 2
- **类别**: c++|compiler-warning|platform
- **触发工具**: clang|make
- **阶段**: compilation

## 错误特征
```
error: conflicting declaration.*struct|error: conflicting declaration.*class|-Wmismatched-tags
```

**关键词**: Wmismatched-tags, conflicting declaration, struct, class, forward declaration, FHTransform

## 根因分析
头文件中前向声明使用 class X，但实际定义使用 struct X（或相反），clang -Wmismatched-tags 将其视为错误

**影响范围**: 使用 clang 编译的 C++ 项目，前向声明与实际定义不一致的情况（如 libfreehand, libcdr 等 LibreOffice 系列）

## 推荐方案
- **方法**: source-patch
- **描述**: 将前向声明的 class 改为 struct（或反之），使其与实际定义一致
- **命令**: `sed -i 's/class FHTransform/struct FHTransform/' src/lib/FHPath.h`
- **自动修复**: true

## 验证
```bash
grep -rn "class FHTransform\|struct FHTransform" src/lib/FHPath.h src/lib/FHTransform.h
```

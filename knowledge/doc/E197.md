# E197: source-patch

## 基本信息
- **严重度**: 2
- **类别**: platform, c++, warnings
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
error: conflicting declaration.*struct|error: conflicting declaration.*class|-Wmismatched-tags
```

## 根因分析
头文件中前向声明使用 class X，但实际定义使用 struct X（或相反），clang -Wmismatched-tags 将其视为错误

## 推荐方案
**方法**: source-patch

**说明**: 将前向声明的 class 改为 struct（或反之），使其与实际定义一致

**验证/命令**:
```
sed -i 's/class FHTransform/struct FHTransform/' src/lib/FHPath.h
```

## 关键词
Wmismatched-tags, conflicting declaration, struct, class, forward declaration, FHTransform

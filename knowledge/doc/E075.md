# E075: env-var-remove

## 错误特征
```
pkg-config.*--cflags.*empty|No such file or directory.*\.h|cannot find.*header|fatal error:.*\.h: No such file
```

## 根因分析
设置了 C_INCLUDE_PATH 环境变量后，pkg-config 将其视为"系统头文件路径"，
                        在返回 --cflags 时过滤掉所有匹配的 -I 标志（认为冗余）。
                        结果是 configure/cmake 通过 pkg-config 获取不到 -I 路径，
                        编译时报 xxx.h: No such file or directory。
                        这是一个配置陷阱：C_INCLUDE_PATH 本意是帮助找到头文件，
                        反而导致构建系统找不到头文件。

## 推荐方案
**方法**: env-var-remove

**说明**: 从 shell 配置中移除 C_INCLUDE_PATH 和 LIBRARY_PATH，
                        仅使用 PKG_CONFIG_PATH 让构建系统自动发现依赖路径。

**验证/命令**:
```
|
  unset C_INCLUDE_PATH
  unset CPLUS_INCLUDE_PATH
  unset LIBRARY_PATH
  export PKG_CONFIG_PATH=$HOME/usr/local/lib/pkgconfig:$PKG_CONFIG_PATH
```

# E035: header-only-install

## 基本信息
- **严重度**: 3
- **类别**: compat, build-system
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
match-command-output.*exited with error code|SHELL.*version.*failed|clang++ --version.*error
```

## 根因分析
Boost.Build 的 SHELL 执行机制与鸿蒙 shell 不兼容，无法正确执行版本检测等命令

## 推荐方案
**方法**: header-only-install

**说明**: 仅安装 Boost 的 header-only 部分，无需编译，直接复制 boost/ 头文件目录

**验证/命令**:
```
cp -r boost $DEFAULT_PREFIX/include/
```

boost, b2, bjam, SHELL, version, error code, match-command-output

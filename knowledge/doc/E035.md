# E035: header-only-install

## 基本信息
- **严重度**: 3
- **类别**: build-system-compatibility
- **触发工具**: b2|bjam|boost-build
- **阶段**: configuration

## 错误特征
```
match-command-output.*exited with error code|SHELL.*version.*failed|clang++ --version.*error
```

**关键词**: boost, b2, bjam, SHELL, version, error code, match-command-output

## 根因分析
Boost.Build 的 SHELL 执行机制与鸿蒙 shell 不兼容，无法正确执行版本检测等命令

**影响范围**: 所有需要使用 b2/bjam 构建的软件（boost, boost-dependent libraries）

## 推荐方案
- **方法**: header-only-install
- **描述**: 仅安装 Boost 的 header-only 部分，无需编译，直接复制 boost/ 头文件目录
- **命令**: `cp -r boost $DEFAULT_PREFIX/include/`
- **自动修复**: false

## 验证
```bash
./b2 --version 2>&1 | grep -E "(exited with error|match-command-output)"
```

# E441: actiona 需要 Qt6::Sql/Qt6::DBus 时补 qtbase Sql/DBus 变体

## 基本信息
- **严重度**: 2
- **类别**: ohos, porting
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: !5241

## 错误特征
```
Failed to find required Qt component "Sql"|Qt6Sql_DIR|Qt6DBus_DIR
```

## 根因分析
actiona 的 actions/data 链接 Qt6::Sql、actions/system 链接 Qt6::DBus，制品仓 qtbase/6.11.1 未开 FEATURE_sql/FEATURE_dbus

## 推荐方案
**方法**: 创建 qtbase-sql-dbus/6.11.1 变体（FEATURE_sql=ON、FEATURE_dbus=ON + dbus/1.14.10 依赖，参照 qtbase-gui 变体先例）

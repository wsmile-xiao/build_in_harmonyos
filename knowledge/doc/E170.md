# E170: add-compat-field

## 基本信息
- **严重度**: 1
- **类别**: toolchain
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
manifest 缺少 build_system|
                        G4 Archive FAIL.*manifest|
                        verify_build.*build_system
```

## 根因分析
verify_build.py 在 G4 检查中查找 build_system: 字段（顶级），
                        但版本级 manifest.yaml 规范使用 build.system:（嵌套结构），
                        导致检查失败

## 推荐方案
**方法**: add-compat-field

**说明**: 在版本级 manifest.yaml 中添加顶级 build_system: 字段作为兼容性方案

**验证/命令**:
```
sed -i '/^status:/a build_system: cmake' archives/{letter}/{name}/{version}/manifest.yaml
```

verify_build, manifest, build_system, G4, archive,

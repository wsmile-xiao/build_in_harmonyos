# E170: add-compat-field

## 基本信息
- **严重度**: 1
- **类别**: tool
- **触发工具**: verify_build
- **阶段**: verify

## 错误特征
```
manifest 缺少 build_system|
```

**关键词**: verify_build, manifest, build_system, G4, archive,

## 根因分析
verify_build.py 在 G4 检查中查找 build_system: 字段（顶级），

**影响范围**: 所有使用版本级 manifest.yaml 的软件

## 推荐方案
- **方法**: add-compat-field
- **描述**: 在版本级 manifest.yaml 中添加顶级 build_system: 字段作为兼容性方案
- **命令**: `sed -i '/^status:/a build_system: cmake' archives/{letter}/{name}/{version}/manifest.yaml`
- **自动修复**: true

## 验证
```bash
grep -n "build_system:" archives/*/manifest.yaml; grep -n "build:" archives/*/manifest.yaml
```

# E140: add-harmonyos-cmake-detection

## 基本信息
- **严重度**: 2
- **类别**: platform-cmake-detection
- **触发工具**: cmake
- **阶段**: configuration

## 错误特征
```
CMAKE_SYSTEM_NAME.*HarmonyOS|System is unknown to cmake.*HarmonyOS|OS_LINUX.*not defined
```

**关键词**: CMAKE_SYSTEM_NAME, HarmonyOS, OS_LINUX, platform detection, __OHOS__

## 根因分析
On OpenHarmony, uname -s returns HarmonyOS and CMAKE_SYSTEM_NAME is HarmonyOS, CMakeLists.txt platform blocks checking for Linux don't match, causing OS_LINUX to not be defined

**影响范围**: any cmake project with platform detection using CMAKE_SYSTEM_NAME MATCHES Linux

## 推荐方案
- **方法**: add-harmonyos-cmake-detection
- **描述**: Add elseif(CMAKE_SYSTEM_NAME MATCHES HarmonyOS) block to define OS_LINUX, or add || defined(__OHOS__) to source #if guards
- **命令**: `sed -i '/elseif(CMAKE_SYSTEM_NAME MATCHES "Linux")/,/add_definitions(-DOS_LINUX)/{ /add_definitions(-DOS_LINUX)/a elseif(CMAKE_SYSTEM_NAME MATCHES "HarmonyOS")\n  add_definitions(-DOS_LINUX) }' CMakeLists.txt`
- **自动修复**: false

## 验证
```bash
cmake -P -E echo ${CMAKE_SYSTEM_NAME} || uname -s
```

# E140: add-harmonyos-cmake-detection

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, cmake
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
CMAKE_SYSTEM_NAME.*HarmonyOS|System is unknown to cmake.*HarmonyOS|OS_LINUX.*not defined
```

## 根因分析
On OpenHarmony, uname -s returns HarmonyOS and CMAKE_SYSTEM_NAME is HarmonyOS, CMakeLists.txt platform blocks checking for Linux don't match, causing OS_LINUX to not be defined

## 推荐方案
**方法**: add-harmonyos-cmake-detection

**说明**: Add elseif(CMAKE_SYSTEM_NAME MATCHES HarmonyOS) block to define OS_LINUX, or add || defined(__OHOS__) to source #if guards

**验证/命令**:
```
sed -i '/elseif(CMAKE_SYSTEM_NAME MATCHES "Linux")/,/add_definitions(-DOS_LINUX)/{ /add_definitions(-DOS_LINUX)/a elseif(CMAKE_SYSTEM_NAME MATCHES "HarmonyOS")\n  add_definitions(-DOS_LINUX) }' CMakeLists.txt
```

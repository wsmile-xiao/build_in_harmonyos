# E373: Route build-tool introspection through the Conan build environment

## 基本信息
- **严重度**: 2
- **类别**: conan, environment
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !5532

## 错误特征
```
FileNotFoundError: \[Errno 2\] No such file or directory: 'meson'|self.run.*meson.*succeeds.*subprocess.run.*meson.*fails
```

## 根因分析
Conan applies generated conanbuild environment files around ConanFile.run in build scope, while a direct Python subprocess inherits the recipe process environment and can lose profile-provided build-tool PATH entries.

## 推荐方案
**方法**: conan-self-run-captured-introspection

**说明**: Format the argv safely, execute through ConanFile.run in the conanbuild build scope with StringIO capture, reject nonzero status, and parse and validate the captured JSON fail-closed.

**验证/命令**:
```
self.run(formatted_command, stdout=stdout, stderr=stderr, ignore_errors=True, env="conanbuild", scope="build")
```

# E154: install-rust-prebuilt

## 基本信息
- **严重度**: 3
- **类别**: toolchain|platform|rust
- **触发工具**: cargo|rustc|make|configure
- **阶段**: configuration|compilation

## 错误特征
```
rustc not found|cargo not found|command not found: rustc|command not found: cargo|unrecognized OS type: HarmonyOS|no such file: Cargo.toml parser
```

**关键词**: rustc, cargo, rustup, Rust, Cargo.toml, unrecognized OS type

## 根因分析
HarmonyOS 不在 Rust 官方支持平台列表中, rustup 无法识别操作系统类型, 且系统中未预装 Rust/Cargo 工具链

**影响范围**: 所有 Rust 项目 (使用 Cargo.toml 构建的软件), 包括 gleam, ripgrep, fd, bat 等

## 推荐方案
- **方法**: install-rust-prebuilt
- **描述**: 安装预编译的 Rust 工具链包 (需先将其加入 cmd-pkgs 仓库)
- **命令**: `curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- rust 1.81.0`
- **自动修复**: false

## 验证
```bash
which rustc && which cargo && rustc --version && cargo --version
```

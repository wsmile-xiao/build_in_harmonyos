# E154: install-rust-prebuilt

## 错误特征
```
rustc not found|cargo not found|command not found: rustc|command not found: cargo|unrecognized OS type: HarmonyOS|no such file: Cargo.toml parser
```

## 根因分析
HarmonyOS 不在 Rust 官方支持平台列表中, rustup 无法识别操作系统类型, 且系统中未预装 Rust/Cargo 工具链

## 推荐方案
**方法**: install-rust-prebuilt

**说明**: 安装预编译的 Rust 工具链包 (需先将其加入 cmd-pkgs 仓库)

**验证/命令**:
```
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- rust 1.81.0
```

rustc, cargo, rustup, Rust, Cargo.toml, unrecognized OS type

# E428: pico-sdk test_package 的 Python 子脚本应接收 bin/pioasm 绝对路径，避免 OHOS bash 环境丢 PATH

## 基本信息
- **严重度**: 3
- **类别**: conan, packaging, testing, cli-tool, runtime-env
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6613

## 错误特征
```
FileNotFoundError: \[Errno 2\] No such file or directory: 'pioasm'|PICO_SDK_PATH missing|bash: /etc/profile: Permission denied
```

## 根因分析
test_package/conanfile.py 使用 self.run(..., env="conanrun") 能注入 PICO_SDK_PATH/PATH，但当它再通过 bash -lc 调 Python，Python 子脚本内 subprocess.run(["pioasm", ...]) 仍可能找不到工具。OHOS 的 bash 登录包装还会打印 /etc/profile: Permission denied，进一步说明不应依赖登录 shell PATH。

## 推荐方案
**方法**: pass-packaged-tool-absolute-path

**说明**: 在 test_package/conanfile.py 中从 dep.package_folder/bin 计算 pioasm 绝对路径，确认文件存在后作为参数传给 smoke.py；smoke.py 使用该绝对路径运行 --version 和 .pio->.h，不再依赖 PATH 解析。

**验证/命令**:
```
pioasm_path = os.path.join(dep.package_folder, "bin", "pioasm"); self._run_tool([sys.executable, smoke_script, pioasm_path, smoke_pio, smoke_header])
```

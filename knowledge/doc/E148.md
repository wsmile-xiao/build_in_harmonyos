# E148: exclude-ohos-from-linux-conditionals

## 基本信息
- **严重度**: 2
- **类别**: platform, libc, network
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
storage size of .*mmsghdr.*isn.t known|incomplete type.*struct mmsghdr|undeclared.*recvmmsg|undeclared.*sendmmsg|implicit declaration.*recvmmsg|implicit declaration.*sendmmsg
```

## 根因分析
OHOS 使用 musl libc，未实现 Linux 特有的批量消息 API (struct mmsghdr, recvmmsg, sendmmsg)，源码使用 __linux__ 宏判断平台但误将 OHOS 识别为 Linux

## 推荐方案
**方法**: exclude-ohos-from-linux-conditionals

**说明**: 在使用 mmsg API 的代码块前添加 #if defined(__linux__) && !defined(__OHOS__) 条件编译，排除 OHOS 平台

**验证/命令**:
```
sed -i 's/#if defined(__linux__)/#if defined(__linux__) \&\& !defined(__OHOS__)/g' <source_file>
```

# E148: exclude-ohos-from-linux-conditionals

## 基本信息
- **严重度**: 2
- **类别**: libc|network|platform
- **触发工具**: cc|clang|make
- **阶段**: compilation

## 错误特征
```
storage size of .*mmsghdr.*isn.t known|incomplete type.*struct mmsghdr|undeclared.*recvmmsg|undeclared.*sendmmsg|implicit declaration.*recvmmsg|implicit declaration.*sendmmsg
```

**关键词**: mmsghdr, recvmmsg, sendmmsg, batch message, UDP, high performance, incomplete type, undeclared, musl, __linux__, __OHOS__

## 根因分析
OHOS 使用 musl libc，未实现 Linux 特有的批量消息 API (struct mmsghdr, recvmmsg, sendmmsg)，源码使用 __linux__ 宏判断平台但误将 OHOS 识别为 Linux

**影响范围**: 高性能网络库 (libuv, libevent, nginx, redis 等) 在启用批量消息功能时受影响

## 推荐方案
- **方法**: exclude-ohos-from-linux-conditionals
- **描述**: 在使用 mmsg API 的代码块前添加 #if defined(__linux__) && !defined(__OHOS__) 条件编译，排除 OHOS 平台
- **命令**: `sed -i 's/#if defined(__linux__)/#if defined(__linux__) \&\& !defined(__OHOS__)/g' <source_file>`
- **自动修复**: true

## 验证
```bash
grep -r "mmsghdr\|recvmmsg\|sendmmsg" --include="*.c" --include="*.h" .
```

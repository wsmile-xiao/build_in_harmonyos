# E392: Raw makefile Conan 配方的三个通用陷阱：BadZipFile 编码器误选 / compiler_executables 字典获取 / make 默认 cwd 错误

## 基本信息
- **严重度**: 2
- **类别**: ohos, make, compiler, conan, packaging
- **作者**: bellaaa_ <bellaaa_@noreply.gitcode.com>
- **来源 PR**: !5785

## 错误特征
```
BadZipFile.*File is not a zip file|conan.*get.*BadZipFile|No targets specified.*No makefile found|make.*No rule to make target|KeyError.*compiler_executables|AttributeError.*str.*has no attribute.*get|tools\.build:compiler_executables
```

## 根因分析
Raw makefile（非 autotools/cmake/meson 生成）软件适配 Conan 时有三个通用陷阱：(1) codeload URL 末段是 tag 名无扩展名，Conan get() 按末段推断文件名默认用 zip 解码器解压 tar.gz 报 BadZipFile；(2) OHOS profile 的 tools.build:compiler_executables 是字典 {'c':...,'cpp':...} 而非单独键，直接用 conf.get 取值返回字符串或报错无法 .get()；(3) raw makefile 的 Makefile 在 source_folder，self.run("make") 默认在 build_folder 执行找不到 Makefile。

## 推荐方案
**方法**: raw-makefile-conan-recipe-pattern

**说明**: Raw makefile Conan 配方采用三要素模式：(1) get() 显式传 filename="软件名-版本.tar.gz" 避免编码器误选；(2) 用 check_type=dict 整体获取 compiler_executables 字典再 .get("c") 取编译器；(3) self.run("make ...") 必须加 cwd=self.source_folder。三者缺一不可。

**验证/命令**:
```
get(self, **self.conan_data["sources"], strip_root=True, filename="<name>-<ver>.tar.gz")  # 修复1
```

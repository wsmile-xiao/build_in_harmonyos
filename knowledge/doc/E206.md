# E206: patch-script

## 基本信息
- **严重度**: 2
- **类别**: build_environment
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
can't create.* conf.*. Permission denied|config\.status\[1523\]: can't create temporary file
```

**关键词**: HMDFS,umask 077,Permission denied,config.status,conf*,temporary directory,autotools

## 根因分析
On HMDFS filesystem, when config.status creates a temp directory using `(umask 077 && mktemp -d "./confXXXXXX")`, the directory inherits parent owner uid (20001006) via setgid bit, but current uid (20020101) is not the directory owner, so cannot't write files inside the 0700-permission temp dir. The umask 077 strips group and other permissions, leaving only non-owner users without "other" category with zero permissions.

**影响范围**: All autotools-based projects on HMDFS filesystem

## 推荐方案
- **方法**: patch-script
- **描述**: Change umask 077 to umask 022 in configure and config.status scripts' temp directory creation code. This ensures temp dirs get group-readable permissions, allowing non-owner users to write files inside them.
- **命令**: `sedsed -i 's/umask 077/umask 022/g' configure config.status``
- **自动修复**: false

## 验证
```bash
`grep -c "umask 077" configure config.status`
```

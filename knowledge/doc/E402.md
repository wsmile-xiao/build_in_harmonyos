# E402: OHOS toybox gzip 仅支持短选项 [-19cdfkt]，GNU 长选项 --force/--best 导致 make install/package 失败

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, toolchain
- **作者**: GoliWie <GoliWie@noreply.gitcode.com>
- **来源 PR**: !5084

## 错误特征
```
gzip: unrecognized option|gzip: Unknown option|--force.*not supported
```

## 根因分析
OHOS /usr/bin/gzip 为 toybox 实现（readlink -f /usr/bin/gzip 指向 /system/bin/toybox），仅支持短选项 [-19cdfkt]，不支持 GNU gzip 的长选项 --force/--best。上游 MLton Makefile 在 GZIP_MAN=true 分支执行 "$(GZIP) --force --best $(MAN_PAGES)"（Makefile 第 425 行），package() 的 install-no-strip 阶段报 gzip: Unknown option 'force' → rc=1 → make: *** [Makefile:425: install-no-strip] Error 1 → ConanException。设备端 /data/service/hnp/bin 亦无 GNU gzip，无 infra 级零配方改动方案，属上游平台工具链能力差异（上游假定 GNU gzip）。

## 推荐方案
**方法**: recipe-patch-gzip-short-options

**说明**: 配方补丁把 install-no-strip 的 gzip 长选项改为 toybox 兼容短选项：$(GZIP) --force --best $(MAN_PAGES) → $(GZIP) -f -9 $(MAN_PAGES)，并在 conandata.yml 注册补丁。保留 GZIP_MAN=true 语义（man 页仍压缩），不跳过安装、不关闭 man 压缩、不改上游默认交付物。

**验证/命令**:
```
patch 0003 将 Makefile 第 425 行 `cd "$(TMAN)" && $(GZIP) --force --best $(MAN_PAGES);` 改为 `cd "$(TMAN)" && $(GZIP) -f -9 $(MAN_PAGES);`；验证：make install-no-strip 后 5 个 .gz 生成且 gzip -t 全部通过，"gzip: Unknown option" 计数=0。
```

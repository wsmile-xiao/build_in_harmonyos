# E249: 未初始化所有权标志导致清理函数释放调用者栈对象

## 基本信息
- **严重度**: 3
- **类别**: memory
- **作者**: tianyi_wang <tianyiwang58@gmail.com>
- **来源 PR**: source_commit:

## 错误特征
```
Signal 11 \(core dumped\)|exit_code=139|AddressSanitizer: attempting free on address which was not malloc\(\)-ed
```

## 根因分析
构造函数把调用者持有的对象指针交给子对象却未初始化 shared/owned 标志；清理函数读取不确定值并可能按独占所有权关闭后 free 该指针，造成 invalid free/SIGSEGV

## 推荐方案
**方法**: initialize-borrowed-ownership

**说明**: 在构造共享子对象时明确设置 shared/borrowed 标志，并保持调用者作为唯一释放方；添加能走到该清理分支的确定性回归测试

**验证/命令**:
```
track-edit add ${SOFTWARE} ${VERSION} ${SOURCE_FILE} && refresh-patch --auto ${SOFTWARE} ${VERSION}
```

Signal 11, exit 139, attempting free, not malloc, shared ownership, stack object

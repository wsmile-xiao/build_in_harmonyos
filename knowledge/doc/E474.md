# E474: Separate auxiliary observers from the native consumer terminal contract

## 基本信息
- **严重度**: 2
- **类别**: consumer-observer-separation
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !7109

## 错误特征
```
native consumer stages are present but an auxiliary snapshot or management acknowledgement is missing; a loose validator changes the four-consumer result
```

## 根因分析
A surface snapshot and a management acknowledgement are observation or transaction-control contracts, while core, invalid-input, audio, and video are product consumers. Treating an observer as a fifth consumer, or accepting locally printed stage fields without an authoritative terminal receipt, makes a missing observer look like a consumer failure or a consumer success.

## 推荐方案
**方法**: typed-consumer-and-observer-receipts

**说明**: Define the exact consumer set and denominator first. Emit each stage only after the production native operation, record optional observers as NOT_REQUIRED or NOT_RUN, and accept consumers_passed/consumers_total only from a terminal receipt bound to the same run identity and input snapshot.

**验证/命令**:
```
validate source contract; compile and run a host fixture; verify ordered core_pass invalid_pass audio_pass video_pass markers; assert snapshot=NOT_REQUIRED or a separate required receipt; preserve upstream=0/0 NOT_RUN for a consumer-only run
```

# E201: manual-test-execution

## 基本信息
- **严重度**: 1

## 错误特征
```
test_run\.sh|/bin/bash.*not found|strace.*not available
```

## 根因分析
test_run.sh requires /bin/bash (not at standard path on OHOS) and strace (not available on OHOS)

## 推荐方案
**方法**: manual-test-execution

**说明**: Run test binaries directly instead of through test_run.sh wrapper

**验证/命令**:
```
LD_PRELOAD=$DEFAULT_PREFIX/lib/libXXX.so ./test_binary
```

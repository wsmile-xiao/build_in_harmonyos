# E201: manual-test-execution

## 基本信息
- **严重度**: 1
- **类别**: testing-limitation
- **触发工具**: runtime
- **阶段**: runtime

## 错误特征
```
test_run\.sh|/bin/bash.*not found|strace.*not available
```

**关键词**: test_run.sh, /bin/bash, strace, OHOS

## 根因分析
test_run.sh requires /bin/bash (not at standard path on OHOS) and strace (not available on OHOS)

**影响范围**: All autotools-based test suites using test_run.sh on OHOS

## 推荐方案
- **方法**: manual-test-execution
- **描述**: Run test binaries directly instead of through test_run.sh wrapper
- **命令**: `LD_PRELOAD=$DEFAULT_PREFIX/lib/libXXX.so ./test_binary`
- **自动修复**: false

## 验证
```bash
test -x /bin/bash && which strace
```

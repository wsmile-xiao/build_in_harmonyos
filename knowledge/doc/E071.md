# E071: bypass-autotools-env

## 基本信息
- **严重度**: 2
- **类别**: autotools, version
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
requires automake .* but .* installed|automake version.*too old|AUTOMAKE_VERSION mismatch
```

## 根因分析
上游 tarball 的 configure.ac 声明需要的 automake 版本
                         高于系统已安装版本；或时间戳不一致触发 autotools 重生成

## 推荐方案
**方法**: bypass-autotools-env

**说明**: 将 autotools 工具设为 /bin/true 绕过调用
                         （前提：tarball 已包含正确生成的 Makefile.in）

**验证/命令**:
```
ACLOCAL="/bin/true" AUTOHEADER="/bin/true" AUTOMAKE="/bin/true" \
                         ./configure --prefix=$HOME/usr/local && make -j1
```

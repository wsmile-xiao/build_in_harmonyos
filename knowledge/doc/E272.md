# E272: arm-none-eabi-binutils 2.46.1：OHOS DejaGNU 交叉工具链测试迁移

## 基本信息
- **严重度**: 2
- **类别**: ohos, toolchain, cross-compile, dejagnu-testing
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: 2991

## 错误特征
```
/bin/stty: inaccessible or not found|Cannot link: Permission denied|tmpfile.*EACCES|UNRESOLVED: strip|objcopy.*bintest.o
```

## 根因分析
1) expect 5.45.4 每次 spawn 内部调用 /bin/stty 做终端初始化，OHOS 缺少 /bin/stty（/system/bin 只读 erofs），噪音污染 DejaGNU exec_output，导致 binutils_assemble_flags 误判、objcopy_test 误删 bintest.o、strip UNRESOLVED；2) OHOS libc tmpfile() 忽略 TMPDIR 并尝试系统临时目录（/data/local/tmp）返回 EACCES(13)，导致 libctf ctf_link_write（ctf-compressed 测试）失败

## 推荐方案
**方法**: spawn-nottyinit-plus-tmpfile-shim

**说明**: 1) 通过 DEJAGNU 全局配置 site-stty-fix.exp 包装 expect spawn 自动注入 -nottyinit，跳过终端初始化，从源头消除 /bin/stty 噪音；2) 测试阶段编译 tmpfile-shim.so（mkstemp 到 TMPDIR + unlink + fdopen，设置 FD_CLOEXEC）并通过 LD_PRELOAD 注入，修复 OHOS libc tmpfile() EACCES；两者均为测试环境兼容文件，不进入生产 package

**验证/命令**:
```
make -k -j1 check
```

# E275: OHOS shell grep -v 空结果触发 set -e 退出

## 基本信息
- **严重度**: 2
- **类别**: compat, shell
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>
- **来源 PR**: source_commit:

## 错误特征
```
grep -Fv.*>.*authorized_list|ConanException: Error 1 while executing|set -e.*grep.*-v
```

## 根因分析
在 set -e 脚本中使用 grep -v 过滤空文件或全量匹配内容时，grep 返回 1 表示没有输出；该返回码属于正常过滤结果，但会被 shell 当成失败导致脚本提前退出。

## 推荐方案
**方法**: allow-empty-grep-result

**说明**: 对 grep -v 清理步骤追加 || :，把无输出场景视为正常结果；同时保留后续文件写入逻辑。

**验证/命令**:
```
grep -Fv -- "$pattern" input > output || :
```

## 根因分析
HarmonyOS 不在 Rust 官方支持平台列表中，rustup 无法识别操作系统类型。系统中若有 Linux 编译的 Rust 工具链，期望动态链接器路径 /lib/ld-linux-aarch64.so.1，鸿蒙系统缺少此路径。

**方法**: wait-for-platform-support

**说明**: 标记为平台限制，等待鸿蒙原生 Rust 工具链或 musl 静态链接版本可用

# E105: wait-for-platform-support

## 基本信息
- **严重度**: 3
- **类别**: toolchain|rust|platform-limitation
- **触发工具**: cargo|rustc|rust
- **阶段**: configuration|compilation

## 错误特征
```
no such file or directory.*rustc|no such file or directory.*cargo|command not found.*rustc|command not found.*cargo|ELF.*interpreter /lib/ld-linux-aarch64.so.1.*No such file|unrecognized OS type: HarmonyOS
```

**关键词**: rust, cargo, rustc, Rust, toolchain, ELF, dynamic linker, ld-linux-aarch64.so.1, unrecognized OS type

## 根因分析
HarmonyOS 不在 Rust 官方支持平台列表中，rustup 无法识别操作系统类型。系统中若有 Linux 编译的 Rust 工具链，期望动态链接器路径 /lib/ld-linux-aarch64.so.1，鸿蒙系统缺少此路径。

**影响范围**: 所有 Rust 项目：sccache, procs, bottom, yazi, ripgrep, bat, exa, fd, starship 等

## 推荐方案
- **方法**: wait-for-platform-support
- **描述**: 标记为平台限制，等待鸿蒙原生 Rust 工具链或 musl 静态链接版本可用
- **命令**: `# 无命令，仅记录: "阻塞原因: Rust 工具链不可用"`
- **自动修复**: false

## 验证
```bash
which rustc && rustc --version && which cargo && cargo --version || echo "Rust toolchain not available"
```

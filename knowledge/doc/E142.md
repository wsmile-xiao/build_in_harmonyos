# E142: link-libintl_glib

## 基本信息
- **严重度**: 3
- **类别**: platform, runtime
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
g_libintl_dgettext: symbol not found|
                         Error relocating.*g_libintl_dgettext|
                         undefined reference.*g_libintl_dgettext
```

## 根因分析
libbytesize.so 编译时启用 NLS（-DENABLE_NLS），gnulib gettext 重命名规则将标准 dgettext 重命名为 g_libintl_dgettext。该符号不在标准 libintl.so.8 中，而是在 libintl_glib.so（GLib 的 gettext 包装器）中提供

## 推荐方案
**方法**: link-libintl_glib

**说明**: 运行使用 libbytesize.so 的程序时，必须链接 libintl_glib.so（-lintl_glib）以满足 g_libintl_dgettext 符号依赖

**验证/命令**:
```
clang ... -lbytesize -lintl_glib -lintl -lgmp -lmpfr
```

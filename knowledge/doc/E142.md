# E142: link-libintl_glib

## 基本信息
- **严重度**: 3
- **类别**: platform-runtime
- **触发工具**: ld|runtime
- **阶段**: runtime

## 错误特征
```
g_libintl_dgettext: symbol not found|
```

**关键词**: g_libintl_dgettext, libintl_glib, gettext,

## 根因分析
libbytesize.so 编译时启用 NLS（-DENABLE_NLS），gnulib gettext 重命名规则将标准 dgettext 重命名为 g_libintl_dgettext。该符号不在标准 libintl.so.8 中，而是在 libintl_glib.so（GLib 的 gettext 包装器）中提供

**影响范围**: 所有启用 NLS 且使用 gnulib gettext 重命名的软件（libbytesize, libbd_utils, libostree 等）

## 推荐方案
- **方法**: link-libintl_glib
- **描述**: 运行使用 libbytesize.so 的程序时，必须链接 libintl_glib.so（-lintl_glib）以满足 g_libintl_dgettext 符号依赖
- **命令**: `clang ... -lbytesize -lintl_glib -lintl -lgmp -lmpfr`
- **自动修复**: false

## 验证
```bash
nm -D /path/to/libintl_glib.so | grep g_libintl_dgettext
```

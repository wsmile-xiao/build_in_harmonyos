# E029: bash 内置 malloc 与 musl 不兼容

> **结构化数据**: [graph/E029.kv](../graph/E029.kv) | **原则**: 无
> **严重度**: 🟡 medium | **分类**: libc/compat/memory | **自动修复**: ✅ reconfigure

---

## 错误特征

```
编译成功但运行时内存异常
```

## 根因

bash 默认使用内置 `malloc` 实现，与 musl libc 的内存管理机制不兼容。

## 解决方案

```bash
./configure --without-bash-malloc --prefix=$HOME/usr/local
make && make install
```

## 涉及软件

bash 5.3、其他有内置 malloc 替代的项目。

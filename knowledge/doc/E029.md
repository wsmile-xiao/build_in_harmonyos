# E029: configure-disable-feature

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, memory
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
memory.*abnormal|malloc.*incompatible|
                         bash-malloc.*musl|runtime.*memory error
```

## 根因分析
bash 默认使用内置 malloc 实现,
                         与 musl libc 的内存管理机制不兼容,
                         导致运行时出现内存异常(编译不报错)

## 推荐方案
**方法**: configure-disable-feature

**说明**: 禁用内置 malloc, 使用系统(musl)的 malloc

**验证/命令**:
```
./configure --without-bash-malloc --prefix=$HOME/usr/local
```

## 关键词
bash, malloc, musl, incompatible, --without-bash-malloc,
                         memory management, runtime crash, glibc allocator

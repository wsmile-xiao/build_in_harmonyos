# E198: source-patch

## 基本信息
- **严重度**: 2
- **类别**: c++|compiler-warning|platform
- **触发工具**: clang|make
- **阶段**: compilation

## 错误特征
```
is deprecated.*uses deprecated.*copy|-Wdeprecated-copy|implicitly declared.*deprecated
```

**关键词**: Wdeprecated-copy, deprecated copy, assignment operator, implicitly declared, FHTransform

## 根因分析
类定义了自定义的赋值运算符(operator=)，编译器隐式生成的拷贝构造函数在 C++11+ 中被标记为 -Wdeprecated-copy 警告，配合 -Werror 变为错误

**影响范围**: 使用 clang -Werror 编译的 C++ 项目，类有自定义赋值运算符但无显式拷贝构造函数（如 libfreehand, libcdr 等 LibreOffice 系列）

## 推荐方案
- **方法**: source-patch
- **描述**: 添加显式的拷贝赋值运算符声明和实现，用 #ifdef __OHOS__ 守卫，使编译器不再隐式生成
- **自动修复**: false

## 验证
```bash
grep -n "operator=" src/lib/FHTransform.h
```

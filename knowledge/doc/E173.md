# E173: patch-build-file

## 基本信息
- **严重度**: 3
- **类别**: musl, linking, perl
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
cannot open crti.o|cannot open crtbeginS.o|cannot open crtendS.o|cannot open crtn.o|cannot find library -lc
```

## 根因分析
OpenHarmony 使用 musl libc，不提供标准 CRT 启动文件（crti.o、crtbeginS.o、crtendS.o、crtn.o）。XS 模块（Perl/C）使用 ExtUtils::MakeMaker 构建，默认 LDDLFLAGS 包含 -shared，期望标准 CRT 文件存在，导致链接阶段失败。

## 推荐方案
**方法**: patch-build-file

**说明**: 修改 Makefile 的 LDDLFLAGS，添加 -nostartfiles 跳过 CRT 文件，并显式指定 libc 路径（OpenHarmony musl libc 位于 ~/usr/local/lib/libc.so）

**验证/命令**:
```
sed -i 's/^LDDLFLAGS = -shared/LDDLFLAGS = -shared -nostartfiles -L/storage/Users/currentUser/usr/local/lib -lc/' Makefile
```

# E173: patch-build-file

## 基本信息
- **严重度**: 3
- **类别**: linking|xs|perl|musl
- **触发工具**: ld.lld|clang|make
- **阶段**: linking

## 错误特征
```
cannot open crti.o|cannot open crtbeginS.o|cannot open crtendS.o|cannot open crtn.o|cannot find library -lc
```

**关键词**: XS, Perl, CRT, crti.o, crtbeginS.o, musl, nostartfiles, LDDLFLAGS, shared library, linking, Pari.so

## 根因分析
OpenHarmony 使用 musl libc，不提供标准 CRT 启动文件（crti.o、crtbeginS.o、crtendS.o、crtn.o）。XS 模块（Perl/C）使用 ExtUtils::MakeMaker 构建，默认 LDDLFLAGS 包含 -shared，期望标准 CRT 文件存在，导致链接阶段失败。

**影响范围**: 所有 Perl XS 模块（包含 C 代码的 Perl 扩展），以及使用 -shared 链接的其他模块。典型场景：Math::Pari、Crypt::OpenSSL::Random、Crypt::OpenSSL::RSA、DBI、DBD::Pg 等。

## 推荐方案
- **方法**: patch-build-file
- **描述**: 修改 Makefile 的 LDDLFLAGS，添加 -nostartfiles 跳过 CRT 文件，并显式指定 libc 路径（OpenHarmony musl libc 位于 ~/usr/local/lib/libc.so）
- **命令**: `sed -i 's/^LDDLFLAGS = -shared/LDDLFLAGS = -shared -nostartfiles -L/storage/Users/currentUser/usr/local/lib -lc/' Makefile`
- **自动修复**: false

## 验证
```bash
file blib/arch/auto/Math/Pari/Pari.so; llvm-readelf -h blib/arch/auto/Math/Pari/Pari.so
```

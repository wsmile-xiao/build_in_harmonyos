# E036: 平台字符串含空格导致构建路径错误

> **结构化数据**: [graph/E036.kv](../graph/E036.kv) | **原则**: [P-PATCH-001](../graph/principles.kv)
> **严重度**: 🟡 medium | **分类**: python/platform/filesystem | **自动修复**: ❌ patch

## 错误特征

```
No module named '_sysconfigdata__ohos_aarch64'
构建路径含空格
```

## 根因

`uname -r` 返回 `"HongMeng Kernel 1.11.0"`（含空格），Python 的 `get_platform()` 将其拼入路径，导致模块路径解析失败。

## 解决方案

```python
# 修改 sysconfig.py / distutils/util.py
# 跳过 release 字段，使用 "ohos-aarch64" 作为平台标识
```

## 禁止模式

❌ 直接拼接 `uname -r` 输出到路径中不做空格过滤 → 路径解析失败 / ImportError

## 涉及软件

Python 3.9.0 及依赖 `sysconfig.get_platform()` 的工具链。

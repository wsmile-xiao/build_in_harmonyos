# E156: standard-fbida-config

## 基本信息
- **严重度**: 2
- **类别**: build_system|autotools|fbida
- **触发工具**: make|autoconf|configure
- **阶段**: configuration

## 错误特征
```
GNUmakefile.*mk/Autoconf.mk|
```

**关键词**: fbida, Autoconf.mk, GNUmakefile, make config, custom build system, non-standard configure

## 根因分析
**fbida 使用自定义的 autoconf 系统（mk/Autoconf.mk），不是标准的 autotools**。

**影响范围**: fbida 及其衍生项目、所有使用类似自定义 autoconf 系统的项目。

## 推荐方案
- **方法**: standard-fbida-config
- **描述**: 使用 fbida 标准的配置命令 `make config`。这会生成 Make.config 文件，包含编译配置。如果需要自定义配置，可以手动编辑 Make.config 或设置环境变量。
- **命令**: `# Step 1: 运行配置：make config;# Step 2: 检查生成的配置：cat Make.config;# Step 3: 如需修改，编辑 Make.config 或设置环境变量：export HAVE_LINUX_FB_H=no && make config`
- **自动修复**: false

## 验证

# E025: CAN socket 宏未定义

> **结构化数据**: [graph/E025.kv](../graph/E025.kv) | **原则**: 无
> **严重度**: 🟢 low | **分类**: kernel/headers | **自动修复**: ❌ 需源码修改

---

## 错误特征

```
error: use of undeclared identifier 'CAN_RAW_FD_FRAMES'
error: use of undeclared identifier 'CAN_RAW_JOIN_FILTERS'
```

## 根因

configure 检测阶段认为宏存在（通过简单预编译测试），但实际编译时鸿蒙内核头文件中未定义该宏，导致 `pyconfig.h` 中错误地 `#define` 了 `HAVE_XXX`。

## 解决方案

**正确做法：在代码中使用条件编译守卫**

```c
// ❌ 错误：直接使用 configure 检测的宏（可能不准）
#ifdef HAVE_LINUX_CAN_RAW_FD_FRAMES
    // 使用 CAN_RAW_FD_FRAMES → 编译失败！
#endif

// ✅ 正确：双重守卫（configure 检测 + 实际可用性验证）
#if defined(HAVE_LINUX_CAN_RAW_FD_FRAMES) && defined(CAN_RAW_FD_FRAMES)
    // 安全使用
#endif
```

**或修正 configure 检测逻辑**：

```m4
# 在 configure.ac 中，用更严格的检测替代简单预编译
AC_CHECK_DECL([CAN_RAW_FD_FRAMES], [
  AC_DEFINE([HAVE_LINUX_CAN_RAW_FD_FRAMES], [1],
            [Define to 1 if you have CAN_RAW_FD_FRAMES])
], [], [[#include <linux/can/raw.h>]])
```

> ⚠️ 不要用 `sed` 事后修改 `config.h`/`pyconfig.h`，这是治标不治本。

## 涉及软件

Python 3.9.0（pyconfig.h）

# E025: fix-configure-detection

## 基本信息
- **严重度**: 1
- **类别**: kernel, headers
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
undeclared.*CAN_RAW_FD_FRAMES|
                         undeclared.*CAN_RAW_JOIN_FILTERS|
                         CAN.*socket.*macro.*undefined
```

## 根因分析
configure 检测阶段认为宏存在(通过简单预编译测试),
                         但实际编译时鸿蒙内核头文件中未定义该宏,
                         导致 pyconfig.h 中错误地 #define 了 HAVE_XXX

## 推荐方案
**方法**: fix-configure-detection

**说明**: 修正 configure 检测逻辑或在代码中使用正确的条件编译守卫,
                         而非事后 sed 修改 config.h

**验证/命令**:
```
rec_auto_fix:          false
```

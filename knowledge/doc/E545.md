# E545: colord 客户端库（libcolord）作为纯库包单独适配：daemon=false 且跳过 client/ 子目录，产物无 bin/，按 R38 无需 commands.json

## 基本信息
- **严重度**: 2
- **类别**: build-system, packaging, portability
- **来源事件**: libcolord 1.4.8 HarmonyOS 适配
- **提升日期**: 2026-10-01

## 错误特征
```
skip.*client.*subdir|daemon=false.*libcolord|colord.*client.*library
```

## 根因分析
colord 上游同一仓库同时产出 daemon、客户端 CLI 工具（colormgr、cd-iccdump 等，位于 client/）与客户端库 libcolord；纯库适配需 daemon=false 并跳过 client/ 子目录，避免引入需要 D-Bus / 构建期 ELF 签名二进制的 CLI 产物。产物仅 lib/+include/+pkgconfig，无 bin/ 可执行文件，按 R38 不需要 commands.json。

## 推荐方案
**方法**: pure-library-subset-packaging

适配 colord 客户端库时 -Ddaemon=false 并跳过 client/ 子目录，纯库包无需 commands.json（R38）；与同源 colord 包共用 meson 选项与补丁方案

## 实施记录（libcolord 1.4.8）
详见 archives/l/libcolord/1.4.8/notes.md 与 reports/test-report.md。

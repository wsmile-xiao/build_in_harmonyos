# E131: unset-env-var

## 基本信息
- **严重度**: 2
- **类别**: environment
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
Error loading shared library.*\.so.*Permission denied|Can't load.*\.so.*Permission denied
```

## 根因分析
Setting LD=<value> as environment variable causes musl's dynamic linker to fail loading .so files via dlopen() with "Permission denied". The LD variable is interpreted by the linker subsystem and interferes with normal .so resolution. This particularly affects Perl XS modules where CC=cc LD=cc are set during compilation (to override Perl's default clang 18 without sysroot) but must be unset at runtime.

## 推荐方案
**方法**: unset-env-var

**说明**: Unset LD (and CC) environment variables before runtime/test operations

**验证/命令**:
```
env -u CC -u LD perl -Mmodule -e '...'
```

## 关键词
Permission denied, loading shared library, LD environment variable, dlopen, Perl XS, DynaLoader

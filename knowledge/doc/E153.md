# E153: use-cmake-build

## 基本信息
- **严重度**: 3
- **类别**: build-system|platform
- **触发工具**: b2|bjam|boost-build
- **阶段**: configuration|compilation

## 错误特征
```
clang\+\+ --version.*exit code 1|cannot deduce architecture|unable to find parent of|aarch64-unknown-linux-ohos not recognized
```

**关键词**: b2, bjam, Boost.Build, boost, clang++ --version, Jamroot, user-config.jam, architecture detection, compiler detection, exit code 1, OHOS, aarch64-unknown-linux-ohos

## 根因分析
b2 构建系统无法识别 OHOS 平台，编译器版本检测失败(执行 clang++ --version 退出码为 1)，平台架构检测失败(无法匹配 aarch64-unknown-linux-ohos)，b2 内部创建目录失败

**影响范围**: Boost 库中需要编译二进制文件的组件(asio, filesystem, system, thread, python, test 等)，header-only 组件不受影响(smart_ptr, tuple, mpl, spirit 等)

## 推荐方案
- **方法**: use-cmake-build
- **描述**: Boost 1.90+ 支持 CMake 构建，绕过 b2 构建系统，直接生成 Ninja/Make 文件
- **命令**: `mkdir -p build && cd build && cmake .. -DBOOST_INCLUDE_LIBRARIES="system;filesystem" -DCMAKE_INSTALL_PREFIX=$DEFAULT_PREFIX && cmake --build . && cmake --install .`
- **自动修复**: true

## 验证
```bash
cd boost源码目录 && ./b2 --debug-configuration 2>&1 | grep -E "(exit code 1|cannot deduce architecture|unable to find parent)"
```

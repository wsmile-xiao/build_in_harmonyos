# E008: source-patch

## 错误特征
```
fstat.*failed.*Permission denied|
                         fstat.*errno=13|fstat.*EACCES|
                         lseek.*Permission denied.*pipe|
                         standard output.*Permission denied
```

## 根因分析
鸿蒙 SELinux 策略限制用户进程对非普通文件
                         (管道/终端/套接字)的 fstat()/lseek() 调用,
                         返回 EACCES 而非正常结果

## 推荐方案
**方法**: source-patch

**说明**: 编写 C 兼容层补丁, fstat/lseek 失败时回退为安全默认值

**验证/命令**:
```
rec_auto_fix:          false
```

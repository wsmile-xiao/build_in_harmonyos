# E008: fstat/lseek 返回 EACCES

> **结构化数据**: [graph/E008.kv](../graph/E008.kv) | **原则**: P-PATCH-001
> **严重度**: 🟡 medium | **分类**: syscall/compat | **自动修复**: ❌ 需 C 源码补丁

---

## 错误特征

```
cat: standard output: Permission denied
fstat(STDOUT_FILENO) failed: errno=13, Permission denied
lseek: Permission denied (管道/终端输入时)
```

## 根因

鸿蒙 SELinux 策略限制用户进程对非普通文件的 `fstat()` / `lseek()` 调用，返回 EACCES。

| 文件描述符类型 | fstat() 结果 | write() 结果 |
|---------------|-------------|--------------|
| 普通文件 | ✅ 成功 | ✅ 成功 |
| 管道 | ❌ EACCES | ✅ 成功 |
| 终端 | ❌ EACCES | ✅ 成功 |
| 套接字 | ❌ EACCES | ✅ 成功 |

## 验证命令

```bash
strace -e fstat cat /dev/null 2>&1 | grep EACCES
```

## 解决方案

编写 C 兼容层补丁，`fstat`/`lseek` 失败时回退为安全默认值：

```c
#ifdef __OHOS__
static inline int
ohos_fstat_compat (int fd, struct stat *st)
{
  if (fstat (fd, st) == 0)
    return 0;
  if (errno == EACCES || errno == EPERM)
    {
      memset (st, 0, sizeof (*st));
      st->st_blksize = 4096;
      st->st_mode = S_IFIFO;
      return 0;
    }
  return -1;
}
#define OHOS_FSTAT(fd, st) ohos_fstat_compat ((fd), (st))
#else
#define OHOS_FSTAT(fd, st) fstat ((fd), (st))
#endif
```

**⚠️ 禁止事项**：不能简单忽略 `fstat` 的 EACCES 错误——必须提供正确的回退值（如 `S_IFIFO + st_blksize=4096`），否则后续代码可能使用未初始化的 stat 结构体。

**参考补丁**：`archives/c/coreutils/9.10/patches/0002-fix-fstat-for-harmonyos.patch`

coreutils、make、sed、grep 等 POSIX 工具链。

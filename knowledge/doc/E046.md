# E046: skip-test

## 基本信息
- **严重度**: 1
- **类别**: selinux, testing, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
chmod.*not effective|os\.chmod.*no effect|
                         permission.*assertion.*fail.*chmod|test.*chmod.*fail
```

## 根因分析
HarmonyOS 的 SELinux 或 HMDFS 文件系统忽略了 POSIX chmod() 调用。
                         chmod() 返回成功但不实际修改文件权限。
                         所有依赖 chmod() 创建受限权限文件的测试逻辑都会失效

## 推荐方案
**方法**: skip-test

**说明**: 对于测试代码, 跳过依赖 chmod 的测试:
                         检测 chmod 是否生效, 不生效则 raise unittest.SkipTest

**验证/命令**:
```
rec_auto_fix:          true
```

```
Fatal Python error.*init_sys_streams|ModuleNotFoundError.*encodings|

```

## 根因分析
Python 使用 PYTHONHOME 环境变量定位标准库目录(lib/python3.x/)。
                         如果不设置, Python 使用编译时硬编码路径, 可移植包解压到其他位置时找不到标准库

## 推荐方案
**方法**: env-var-activate

**说明**: 在 activate.sh 中必须设置 export PYTHONHOME="$PYTHON_DIR"

**验证/命令**:
```
PYTHON_DIR="$(cd "$(dirname "$0")" && pwd)"
                         export PYTHONHOME="$PYTHON_DIR"
                         export PATH="$PYTHON_DIR/bin:$PATH"
                         export LD_LIBRARY_PATH="$PYTHON_DIR/lib:$PYTHON_DIR/lib/external${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
```

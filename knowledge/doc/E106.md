# E106: path_adjustment

## 基本信息
- **严重度**: 3
- **类别**: platform_limitation
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
cat: standard output: Permission denied|configure: caught signal 13|SIGPIPE
```

**关键词**: GNU cat, stdout permission, SIGPIPE, configure failure, config.status, coreutils, toybox cat, PATH order

## 根因分析
GNU coreutils cat (9.10) on HarmonyOS has stdout permission restriction due to SELinux/HMDFS filesystem constraints. Toybox cat (/bin/cat) works normally. PATH order causes GNU cat to be used during configure, leading to SIGPIPE when config.status writes to stdout via cat pipe.

**影响范围**: All autotools-based software compilation (configure scripts using cat pipe operations)

## 推荐方案
- **方法**: path_adjustment
- **描述**: Adjust PATH to ensure system native commands (toybox /bin) are prioritized over GNU coreutils during configure execution
- **命令**: `export PATH=/bin:$PATH && ./configure --prefix=$DEFAULT_PREFIX`
- **自动修复**: false

## 验证
```bash
echo "test" | cat && echo "cat stdout works" || echo "cat stdout fails"
```

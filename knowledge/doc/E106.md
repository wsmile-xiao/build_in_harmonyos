# E106: path_adjustment

## 错误特征
```
cat: standard output: Permission denied|configure: caught signal 13|SIGPIPE
```

## 根因分析
GNU coreutils cat (9.10) on HarmonyOS has stdout permission restriction due to SELinux/HMDFS filesystem constraints. Toybox cat (/bin/cat) works normally. PATH order causes GNU cat to be used during configure, leading to SIGPIPE when config.status writes to stdout via cat pipe.

## 推荐方案
**方法**: path_adjustment

**说明**: Adjust PATH to ensure system native commands (toybox /bin) are prioritized over GNU coreutils during configure execution

**验证/命令**:
```
export PATH=/bin:$PATH && ./configure --prefix=$DEFAULT_PREFIX
```

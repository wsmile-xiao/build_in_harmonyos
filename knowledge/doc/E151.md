# E151: manually-add-have-defines

## 基本信息
- **严重度**: 2
- **类别**: cmake|platform-detection
- **触发工具**: cmake|cc|clang
- **阶段**: configuration|compilation

## 错误特征
```
check_c_source_compiles.*failed|check_function_exists.*failed|HAVE_SNPRINTF.*not found|HAVE_DECL_ISNAN.*undefined|macro redefined.*HAVE_|config\.h.*missing HAVE_
```

**关键词**: check_c_source_compiles, check_function_exists, HAVE_SNPRINTF, HAVE_DECL_ISNAN, cmake detection, config.h, platform detection, musl, undefined, macro redefined

## 根因分析
CMake 的 check_c_source_compiles 和 check_function_exists 检测函数在 OHOS 平台上可能因 musl libc 与检测逻辑不兼容而失败，导致 config.h 缺少必要的 HAVE_* 定义

**影响范围**: 使用 CMake 构建的 C 库（如 json-c, libxml2, curl 等），特别是使用 check_c_source_compiles/check_function_exists 进行特性检测的项目

## 推荐方案
- **方法**: manually-add-have-defines
- **描述**: 手动在 config.h 添加缺失的 HAVE_* 定义，绕过 CMake 检测失败问题
- **命令**: `echo '#define HAVE_SNPRINTF 1' >> config.h && echo '#define HAVE_DECL_ISNAN 1' >> config.h`
- **自动修复**: true

## 验证
```bash
grep -E "HAVE_SNPRINTF|HAVE_DECL_ISNAN" config.h || echo "HAVE_* defines missing"
```

# E136: patch-script

- **类别**: platform, configure, permissions

## 错误特征
```
config.status: error: could not setup config files machinery|Permission denied.*confXXXXXX|cannot create a temporary directory in .
```

## 根因分析
HarmonyOS上umask 077 + SGID导致mktemp创建的临时目录权限为drwx--S---，当前用户无法写入。configure脚本使用umask 077创建临时目录，且使用相对路径./confXXXXXX，在SGID环境下导致权限不足。

## 推荐方案
**方法**: patch-script

**说明**: 在configure脚本中强制设置TMPDIR为可写目录，修改umask 077为umask 022，使用绝对路径$TMPDIR/confXXXXXX而非相对路径./confXXXXXX，确保临时目录可写。使用make -e确保环境变量传递给子进程。

**验证/命令**:
```
sed -i 's/^  tmp=.*umask 077.*mktemp.*&/: "${TMPDIR:=/tmp}"\n{\n  tmp=`(umask 022 \&amp;\&amp; mktemp -d "\$TMPDIR/confXXXXXX") 2>/dev/null` \&amp;/' configure
```

## 基本信息
- **严重度**: 3

## 错误特征
```
ar.*command not found|ar.*invalid option|
                         llvm-ar.*not found|RANLIB.*not found
```

## 根因分析
使用 GNU ar 而非 LLVM ar,
                         鸿蒙 SDK 只提供 LLVM 工具链, 没有 binutils

## 推荐方案
**方法**: set-env-var

**说明**: 设置 AR/RANLIB/NM/STRIP 为 LLVM 版本

**验证/命令**:
```
AR=llvm-ar RANLIB=llvm-ranlib NM=llvm-nm STRIP=llvm-strip
```

ar command not found, llvm-ar, RANLIB,
                         LLVM toolchain, NM, archive, invalid option

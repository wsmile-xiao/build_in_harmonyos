# E271: Uncompressed single-file release asset is treated as an archive

## 基本信息
- **严重度**: 2
- **类别**: packaging
- **作者**: AtomCode (gpt-5.6-sol) <noreply@atomgit.com>
- **来源 PR**: source_commit:

## 错误特征
```
not a gzip file|tar: Not tar|gzip: .* not in gzip format
```

## 根因分析
The official release URL serves one uncompressed executable script without an archive suffix, while generic source initialization infers an archive format and invokes gzip or tar on the plain file.

## 推荐方案
**方法**: Use a custom Conan application recipe to download the official single-file asset with SHA256 verification, validate it directly, and install it under package/bin without extraction.

**说明**: Treat the release artifact as a verified file instead of an archive.

**验证/命令**:
```
download(self, url=source["url"], filename="tool", sha256=source["sha256"])
```

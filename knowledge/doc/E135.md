# E135: sign-elf-library

## 基本信息
- **严重度**: 3
- **类别**: platform-elf-signature
- **触发工具**: ld|runtime
- **阶段**: runtime|linking

## 错误特征
```
Error loading shared library libintl\.so\.8|libintl\.so\.8.*not found|
```

**关键词**: libintl, ELF signature, signing,

## 根因分析
HarmonyOS 动态链接器要求所有 .so 文件必须经过 ELF 签名，未签名的库即使路径正确也会被拒绝加载

**影响范围**: 所有依赖 gettext/libintl 的软件在 HarmonyOS 上运行

## 推荐方案
- **方法**: sign-elf-library
- **描述**: 使用 ohc-run.py sign-elf 对 libintl.so.8 及相关 gettext 库进行 ELF 签名
- **命令**: `python3 $SKILL_ROOT/scripts/ohc-run.py sign-elf /path/to/libintl.so.8`
- **自动修复**: true

## 验证
```bash
LD_LIBRARY_PATH=$DEFAULT_PREFIX/lib msgmerge --version
```

# E135: sign-elf-library

## 基本信息
- **严重度**: 3
- **类别**: security
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
Error loading shared library libintl\.so\.8|libintl\.so\.8.*not found|
                         symbol not found.*libintl_gettext|dlopen.*libintl\.so
```

## 根因分析
HarmonyOS 动态链接器要求所有 .so 文件必须经过 ELF 签名，未签名的库即使路径正确也会被拒绝加载

## 推荐方案
**方法**: sign-elf-library

**说明**: 使用 ohc-run.py sign-elf 对 libintl.so.8 及相关 gettext 库进行 ELF 签名

**验证/命令**:
```
python3 $SKILL_ROOT/scripts/ohc-run.py sign-elf /path/to/libintl.so.8
```

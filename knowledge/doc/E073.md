# E073: configure-static-only

## 基本信息
- **严重度**: 3
- **类别**: hmdfs, linking, runtime, filesystem
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
error while loading shared libraries.*lib.*\.so|cannot open shared object file.*No such file
```

## 根因分析
鸿蒙 HMDFS 文件系统对 .so 符号链接的运行时加载支持不完整。
                        ln -s 创建可能成功（区别于 E018 的创建阶段 Permission denied），
                        但进程 dlopen 该符号链接时无法解析到实际库文件。

## 推荐方案
**方法**: configure-static-only

**说明**: 编译时只生成静态库（.a），彻底避免 .so 符号链接的运行时加载问题。

**验证/命令**:
```
./configure --enable-static --disable-shared LDFLAGS=-static
```

# E276: Conan get() 对 codeload tar.gz URL basename 误判为 zip 报 BadZipFile

## 基本信息
- **严重度**: 2
- **类别**: build-system, conan
- **作者**: goblinrs <goblinrs@yeah.net>
- **来源 PR**: source_commit:

## 错误特征
```
BadZipFile: File is not a zip file|Uncompressing <name> to .|codeload.github.com/.../tar.gz/refs/tags/vX.Y.Z
```

## 根因分析
Conan get() 按 os.path.basename(url) 推断下载文件名再按扩展名选解压算法;codeload.github.com 的 tar.gz URL stem 是 .../tar.gz/refs/tags/vX.Y.Z,basename 得到无扩展名的 vX.Y.Z → unzip() 按无扩展名误判为 zip → 报 BadZipFile: File is not a zip file。源码 tarball 本身合法(tar xzf 能解,SHA256 校验通过),非配方/补丁错误。

## 推荐方案
**方法**: 在 source() 的 get() 调用显式传 filename='<软件>-<版本>.tar.gz',让 conan 按扩展名正确识别为 tar.gz 解压;URL 保持官方源(R39)不变,只改下载文件名。

**说明**: conanfile.py source() 改为: get(self, **self.conan_data['sources'], strip_root=True, filename='egl-1.0.5.tar.gz')。原理:get() 的 filename 参数覆盖 basename 推断,Uncompressor2 按 .tar.gz 扩展名走 tar.gz 解压器而非 unzip。无需改 URL,无需改 conandata.yml 的 sha256。

**验证/命令**:
```
sed -i "s/get(self, \*\*self.conan_data\[\"sources\"\], strip_root=True)/get(self, \*\*self.conan_data[\"sources\"], strip_root=True, filename=\"egl-1.0.5.tar.gz\")/" archives/e/egl/1.0.5/conanfile.py
```

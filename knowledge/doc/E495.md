# E495: Qt 6 模块 CMake 构建报 "You need to set QT_HOST_PATH to cross compile Qt"

## 基本信息
- **严重度**: 2
- **类别**: cmake, cross-compile, qt-module, qt6
- **作者**: Gjy_joye <f25015203@st.sandau.edu.cn>
- **来源 PR**: !5421

## 错误特征
```
You need to set QT_HOST_PATH to cross compile Qt
```

## 根因分析
Qt 6 模块用 CMake 构建时检测到交叉编译（CMAKE_SYSTEM_NAME 已设置），要求 QT_HOST_PATH 指向含 moc/rcc 等 host 工具的 Qt 安装前缀

## 推荐方案
**方法**: 本机同架构（如 OHOS aarch64 host=target）时设 QT_HOST_PATH=qtbase 前缀；conan 配方中改用 CMAKE_PREFIX_PATH 指向 qtbase 包 + QT_QMAKE_TARGET_MKSPEC=harmonyos-clang 即可，无需 QT_HOST_PATH

**说明**: 本机同架构编译设 QT_HOST_PATH；conan 配方用 CMAKE_PREFIX_PATH+harmonyos-clang mkspec 规避

**验证/命令**:
```
cmake -S . -B build -DCMAKE_PREFIX_PATH=${QTPFX} -DQT_HOST_PATH=${QTPFX} -DQT_QMAKE_TARGET_MKSPEC=harmonyos-clang
```

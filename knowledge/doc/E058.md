# E058: use-stable-release

## 基本信息
- **严重度**: 3
- **类别**: autotools-config
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
configure: No such file or directory|autoconf: possibly undefined macro|autogen.sh.*failed
```

**关键词**: configure, missing, autoconf, autogen, autotools, bootstrap, development snapshot

## 根因分析
源码包是开发版本或打包不完整，缺少预生成的 configure、aclocal.m4、Makefile.in 等构建系统文件。

**影响范围**: 所有使用 Autotools 但打包不完整的 C/C++ 项目

## 推荐方案
- **方法**: use-stable-release
- **描述**: 使用稳定版本的源码包（如 libfm-1.3.2），而非开发版本（libfm-1.4.0）。
- **命令**: `|`
- **自动修复**: false

## 验证
```bash
ls -l configure && wc -l configure.ac && test -f aclocal.m4 && test -f Makefile.in
```

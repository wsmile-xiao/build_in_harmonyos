# E058: use-stable-release

## 基本信息

- **类别**: autotools, configure

## 错误特征
```
configure: No such file or directory|autoconf: possibly undefined macro|autogen.sh.*failed
```

## 根因分析
源码包是开发版本或打包不完整，缺少预生成的 configure、aclocal.m4、Makefile.in 等构建系统文件。
                        对比稳定版（configure ~500KB）vs 开发版（configure ~150KB 或不存在）可判断。

## 推荐方案
**方法**: use-stable-release

**说明**: 使用稳定版本的源码包（如 libfm-1.3.2），而非开发版本（libfm-1.4.0）。
                        稳定版通常包含完整的构建系统文件（configure ~500KB、Makefile.in、aclocal.m4）。

**验证/命令**:
```
|
  # 检查当前源码包是否完整
  ls -l configure configure.ac aclocal.m4 Makefile.in
  # 对比稳定版本
  curl -LO https://download.savannah.nongnu.org/releases/libfm/libfm-1.3.2.tar.gz
  tar xzf libfm-1.3.2.tar.gz
  cd libfm-1.3.2
  ./configure --prefix=$DEFAULT_PREFIX --disable-old-actions --disable-nls
```

## 错误特征
```
SubprocessError.*ldconfig.*127|find_library.*SubprocessError|
                         /sbin/ldconfig.*not found|_findSoname_ldconfig.*fail
```

## 根因分析
HarmonyOS 没有 /sbin/ldconfig(Linux 标准的共享库缓存管理工具)。
                         ctypes.util.find_library() 内部调用 _findSoname_ldconfig() 时
                         直接执行 ldconfig -p, 因命令不存在触发 SubprocessError

## 推荐方案
**方法**: source-patch

**说明**: 在 Lib/ctypes/util.py 的 _findSoname_ldconfig() 函数头部,
                         检测鸿蒙平台后直接 return None 跳过 ldconfig 调用

**验证/命令**:
```
rec_auto_fix:          false
```

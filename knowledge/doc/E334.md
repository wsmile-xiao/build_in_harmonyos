# E334: Gate Linux packet-capture backends for first-pass OHOS network daemons

- **类别**: syscall, network, dependency-closure

## 错误特征
```
if_packet.h|if_xdp.h|bpf|libpcap|libbpf|AF_PACKET|AF_XDP
```

## 根因分析
Network monitoring daemons often bind to Linux packet capture APIs and optional
                        telemetry/control stacks that are not portable to the first OHOS packaging pass.
                        Enabling all collectors at once expands the dependency closure and makes CI
                        failures hard to isolate.

## 推荐方案
**方法**: feature-gate-private-network-backends

**说明**: Start with protocol parsers and daemon core that can be built without Linux-only
                        capture backends, then explicitly disable AF_PACKET, AF_XDP/libbpf, Netmap,
                        libpcap mirror capture, plugin runners, and heavyweight API/database closures.
                        Add a consumer smoke test for installed CLI/help behavior, and document which
                        packet paths need real-device validation before enabling them.

**验证/命令**:
```
-DENABLE_AFPACKET_SUPPORT=OFF -DENABLE_AF_XDP_SUPPORT=OFF -DENABLE_PCAP_SUPPORT=OFF
```

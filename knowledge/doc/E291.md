## 错误特征
```
STEP_FAILED: Step6|W4.*知识图谱完整性检查发现|graph validate 报告问题|finish.*退出码.*1|non-standard fields|unknown principle
```

## 根因分析
仓库 knowledge/graph 的既有正式条目（E213/E214 等）存在 non-standard fields / unknown principle 等 graph validate 问题，W4 知识图谱完整性检查因此报告 1 类问题；即使当前库自身 conan create=0、conan-verify=0、W3 本地 CI 通过且 .ci-result.json 由框架生成，finish 顶层退出码仍为 1（STEP_FAILED: Step6），内部知识整理 EXIT_CODE=0 不能替代 finish 顶层通过

## 推荐方案
**方法**: record-repository-baseline-blocked

**说明**: 记录 repository_baseline_blocked 状态：保存 graph validate 命令、退出码、首个错误、finish 日志和恢复条件；不把 W3 或 .ci-result.json 单独写成 finish 通过；不把 E213/E214 修复混入当前库 PR

**验证/命令**:
```
python3 scripts/ohc-run.py graph validate > validate.log 2>&1; echo rc=$?; python3 scripts/ohc-run.py finish <软件> <版本> built > finish.log 2>&1; echo rc=$?
```

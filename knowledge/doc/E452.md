# E452: Re-sign task-private OHOS shared-library copies even when an old codesign exists

## 基本信息
- **严重度**: 1
- **类别**: task-private-shared-elf-signing
- **作者**: 2301_80739235 <2047361658@qq.com>
- **来源 PR**: !6723

## 错误特征
```
Error loading shared library.*task-private runtime|\.codesign count is one.*loader rejects|copied shared ELF.*RC 127
```

## 根因分析
A unique .codesign section proves only structural presence. Copying an already-signed provider ELF or its materialized SONAME aliases into a task-private runtime root changes the execution artifact boundary, and the target loader can reject the copy even when bytes, mode, RPATH and LD_LIBRARY_PATH are otherwise correct. An existing-section fast path therefore bypasses the only operation that establishes a current target signature for the private copy.

## 推荐方案
**方法**: force-resign-private-runtime-copies

**说明**: Preserve the provider cache as read-only. For every task-private ELF copy, reject duplicate sections and stale temporaries, remove one old .codesign from a private temporary, sign that temporary, verify the signed output, restore owner execute, atomically publish it over the private copy, and clean only invocation-owned temporaries on failure.

**验证/命令**:
```
llvm-objcopy --remove-section .codesign private.unsigned && binary-sign-tool sign -inFile private.unsigned -outFile private.signed -selfSign 1 && llvm-readelf -SW private.signed
```

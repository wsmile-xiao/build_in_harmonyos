# E195: restore-from-tarball

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
CMakeLists.txt: No such file or directory|include.*No such file or directory|../include.*not found|Cannot find include directory
```

## 根因分析
init-build 的 _promote_nested_source 函数检测到 src/ 子目录有构建文件(CMakeLists.txt)后，将 src/ 内容提升到顶层，但会删除所有非点号开头的同级目录(如 include/、testcase/)，导致 CMakeLists.txt 中引用的 ../include 等路径失效

## 推荐方案
**方法**: restore-from-tarball

**说明**: 从原始 tarball 重新解压，将丢失的同级目录(如 include/、testcase/)复制到工作目录，并修改 CMakeLists.txt 中的路径从 ../include 改为 include

**验证/命令**:
```
tar xzf $BUILD_TARBALL -C $HOME/tmp/ && cp -r $HOME/tmp/<extracted>/include $BUILD_SRC_DIR/ && cp -r $HOME/tmp/<extracted>/testcase $BUILD_SRC_DIR/ && sed -i 's|../include|include|g; s|../testcase|testcase|g' $BUILD_SRC_DIR/CMakeLists.txt
```

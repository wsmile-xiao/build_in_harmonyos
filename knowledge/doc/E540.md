# E540: zlib Makefile shadow CI needs /data/service/hnp/bin in PATH

## 基本信息
- **严重度**: 2
- **类别**: ohos, runner-tool-path
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !6617

## 错误特征
```
make: inaccessible or not found|/system/bin/sh: make|/data/service/hnp/bin|exit 127
```

## 根因分析
The OHOS Conan profile can point CC/CXX to /data/service/hnp/bin/clang, so configure succeeds, while later recipe commands such as make -j1 still resolve through PATH. If runner PATH lacks /data/service/hnp/bin, Makefile packages fail at the first make invocation.

## 推荐方案
**方法**: runner-path-prepend

**说明**: Before single-package shadow CI, prepend /data/service/hnp/bin to PATH through the runner --path option. For CMake-based test_package builds, also include the active HNP CMake directory when present.

**验证/命令**:
```
EXTRA_PATH=/data/service/hnp/bin:/data/service/hnp/cmake.org/cmake_4.1.2/bin:$HOME/usr/local/bin:$HOME/.local/bin:$HOME/ohpc-ci-shadow/python-user/bin; sh $HOME/bin/ohos-test-runner.sh --path "$EXTRA_PATH" -- zsh ci/conan/build_and_test.sh archives/z/zlib/1.3.1.1.1
```

# E357: Allowlist informational daemon probes before mandatory global configuration loading

## 基本信息
- **严重度**: 2
- **类别**: configure, testing, cli, daemon, fail-closed
- **作者**: wxjshr <wxjshr@noreply.gitcode.com>
- **来源 PR**: !5226

## 错误特征
```
Can't open options file.*No such file|unable to open.*(system|global).*(options|config)|--version.*(failed|exit)|--help.*(failed|exit)
```

## 根因分析
A privileged or system daemon loads mandatory global configuration before dispatching command-line informational options, so a packaged binary cannot answer version/help in an undeployed consumer environment even though those requests need no configuration, device or privilege.

## 推荐方案
**方法**: early-informational-option-allowlist

**说明**: Before mandatory global configuration, recognize only argc==2 with an exact allowlist of side-effect-free information options; delegate to the upstream parser/handler so output and exit semantics are preserved, and leave every other argv shape on the original path.

**验证/命令**:
```
Add a platform-guarded argc==2 allowlist before configuration loading, call the existing argument parser, then test version, help, and a missing explicit config negative control.
```

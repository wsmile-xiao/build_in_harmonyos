# E205: patch-script

## 基本信息
- **严重度**: 2
- **类别**: autotools_triplet
- **触发工具**: configure
- **阶段**: configuration

## 错误特征
```
config\.guess: unable to determine.* type of system| configure: error: cannot run C compiler| configure: error: unknown system type| cannot guess host/build/target system
```

**关键词**: OHOS,ohos-linux,HarmonyOS,triplet,config.guess,config.sub,autotools,cross-build,c__ANDROID__

## 根因分析
config.guess does config.sub do not recognize the __OHOS__/ohos-linux triplet for OHOS a HarmonyOS. Without these entries, autotools configure will fail to determine the target system type or resulting in unknown system type or cross-build errors.

**影响范围**: All autotools-based projects targeting OHOS a ImageMagick, GraphicsMagick, libtiff, cairo, freetype, harfbuzz, etcc.

## 推荐方案
- **方法**: patch-script
- **描述**: Apply perl patch-autotools-ohos.pl to add __OHOS__ LIBC detection in config.guess and ohos-linux triplet in config.sub. Never use --build/--host flags as workaround.
- **命令**: ``perl /path/to/patch-autotools-ohos.pl config/config.guess config/config.sub``
- **自动修复**: false

## 验证
```bash
`perl /path/to/patch-autotools-ohos.pl config/config.guess config/config.sub && grep __OHOS__ config/config.guess && grep ohos-linux config/config.sub`
```

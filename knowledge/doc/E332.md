# E332: Prefer an upstream native standalone runner before disabling or vendoring a test framework

## 基本信息
- **严重度**: 2
- **类别**: network, build-system, cmake, conan, testing
- **作者**: asp1r1n1 <912802346@qq.com>
- **来源 PR**: !3398

## 错误特征
```
BUILD_TESTING.*googletest|GoogleTest.*download|gtest_discover_tests
```

## 根因分析
Some upstream projects provide a GTest-compatible native runner but leave it disabled by default, so a normal test configuration tries to bootstrap or link GoogleTest unnecessarily.

## 推荐方案
**方法**: enable-native-standalone-test-runner

**说明**: Enable the maintained upstream standalone runner together with its test and CTest switches. Run it only on a runnable target and report its result independently from the consumer test.

**验证/命令**:
```
CMakeToolchain(self).variables['HWY_TEST_STANDALONE'] = 'ON'; CMake(self).test(cli_args=['--output-on-failure', '--no-tests=error'])
```

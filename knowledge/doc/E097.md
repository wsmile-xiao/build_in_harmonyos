## 错误特征
```
No rule to make target.*install|No configure script found|make:.*mk/SingleUnix.mk.*No such file
```

## 根因分析
BearSSL 使用自定义 Makefile 构建系统（mk/*.mk, conf/*.mk），不支持 autotools/cmake 标准流程，需手动创建平台配置文件并手动安装

## 推荐方案
**方法**: custom-config-mk

**说明**: 创建 conf/Ohos.mk 配置文件，指定 clang/llvm-ar，禁用共享库（API 不稳定），手动安装头文件和静态库

**验证/命令**:
```
cat > conf/Ohos.mk << 'EOF'\ninclude conf/Unix.mk\nCC = clang\nCFLAGS = -W -Wall -Os -fPIC\nAR = llvm-ar\nDLL = no\nEOF\nmake CONF=Ohos
```

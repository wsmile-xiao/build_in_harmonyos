# E097: BearSSL 自定义 Makefile 构建系统

**分类**: L2 模式经验（自定义构建系统）
**严重性**: 🟡 中等
**影响软件**: BearSSL, 其他使用类似构建系统的 TLS/加密库

## 问题现象

BearSSL 没有标准的 `configure` 脚本或 CMake 支持。目录结构含 `mk/`、`conf/`，Makefile 引用 `mk/SingleUnix.mk`。直接 `make install` 失败。

## 根因分析

BearSSL 使用自定义 Makefile 构建系统，通过 `conf/*.mk` 定义平台配置。不支持 autotools/cmake 的标准三步流程。

## 解决方案

### 创建 OHOS 平台配置

```mk
# conf/Ohos.mk
include conf/Unix.mk
CC = clang
CFLAGS = -W -Wall -Os -fPIC
AR = llvm-ar
DLL = no  # API 不稳定，禁用共享库
```

### 编译

```bash
make CONF=Ohos
```

### 手动安装（DESTDIR 模式）

```bash
mkdir -p $DESTDIR/$PREFIX/include/bearssl
mkdir -p $DESTDIR/$PREFIX/lib
mkdir -p $DESTDIR/$PREFIX/bin

cp inc/*.h $DESTDIR/$PREFIX/include/bearssl/
cp build/libbearssl.a $DESTDIR/$PREFIX/lib/
cp build/brssl $DESTDIR/$PREFIX/bin/
```

### 测试

```bash
./testcrypto all && ./testx509
```

## 注意事项

- BearSSL 是小型 TLS 库，静态库为主，适合嵌入式场景
- 构建产物在 `build/` 目录
- `DLL = no` 禁用共享库（API 不稳定）

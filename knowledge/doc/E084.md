# E084: Java/JNI 库手动编译模式（JNA 为例）

## 严重度: 🟡 2 (中 — Java 库编译模式参考)

## 触发场景

需要在鸿蒙上编译包含 JNI native 层的 Java 库（如 JNA），但无 ant/maven 等构建工具。

## 构建流程

### 1. 修改版本号

JNA 的 `Version.java` 使用 `TEMPLATE` 占位符（由 ant 替换），手动编译需先替换：

```java
// src/com/sun/jna/Version.java
String VERSION = "5.19.0";         // 原: "TEMPLATE"
String VERSION_NATIVE = "5.19.0";  // 原: "TEMPLATE"
```

### 2. 编译 Java 层 + 生成 JNI 头文件

```bash
javac -d build/classes -h build/jni-headers \
  -sourcepath src \
  $(find src/com/sun/jna -name "*.java")
```

`-h` 参数自动为含 `native` 方法的类生成 JNI C 头文件。

### 3. 编译 Native 层

```bash
clang -O2 -fPIC -fno-omit-frame-pointer -fno-strict-aliasing \
  -D_REENTRANT -DHAVE_PROTECTION -DNO_JAWT \
  -DJNA_JNI_VERSION='"5.19.0"' -DCHECKSUM='"0"' \
  -I$JAVA_HOME/include \
  -I$JAVA_HOME/include/linux \
  -I$FFI_HOME/include \
  -Ibuild/jni-headers \
  -Inative/ \
  -c native/dispatch.c -o build/dispatch.o

clang ... -c native/callback.c -o build/callback.o
```

关键宏：
- `-DNO_JAWT` — 禁用 AWT（鸿蒙无 X11）
- `-DHAVE_PROTECTION` — 启用 signal handler 保护
- `-DJNA_JNI_VERSION` — 必须与 Java 层 Version.java 一致

### 4. 链接（静态链接 libffi）

```bash
clang -shared -o build/libjnidispatch.so \
  build/dispatch.o build/callback.o \
  $FFI_HOME/lib/libffi.a    # 静态链接，仅依赖 libc.so
```

**推荐静态链接 libffi**，避免运行时依赖 `libffi.so`。

### 5. 打包 JAR

```bash
mkdir -p build/classes/com/sun/jna/harmonyos-aarch64/
cp build/libjnidispatch.so build/classes/com/sun/jna/harmonyos-aarch64/
cd build/classes && jar cf dist/jna.jar com/sun/jna/
```

⚠️ 鸿蒙上 JNA 检测为 `harmonyos-aarch64`（不是 `linux-aarch64`），JAR 中必须包含对应路径的 native library。

### 6. 签名

```bash
python3 $SKILL_ROOT/scripts/ohc-run.py sign-elf build/libjnidispatch.so
```

## 运行

```bash
# 需使用已签名的 JDK 副本（见 E083）
$HOME/usr/local/bishengjdk17/bin/java -cp jna.jar:app.jar Main
```

JNA 会自动从 JAR 中解压 `harmonyos-aarch64/libjnidispatch.so` 并加载。

## 已验证功能

| 功能 | 状态 | 备注 |
|------|------|------|
| dlopen/dlsym 动态加载 | ✅ | Native.load("c", CLib.class) |
| FFI 函数调用 | ✅ | abs/sqrt/puts/getenv 等 |
| Pointer 内存操作 | ✅ | malloc/free/setInt/getInt |
| ffi_closure 回调 | ✅ | qsort 排序，用 Pointer.getInt(0) 解引用 |
| JAR 自动解压加载 | ✅ | 无需外部 .so |

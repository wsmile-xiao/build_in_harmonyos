# E229: 缺失 libc API 时独立测试未链接库内 fallback 对象

## 基本信息
- **严重度**: 2
- **类别**: libc, linking, runtime, testing
- **作者**: 1catmint1 <goblinrs@yeah.net>
- **来源 PR**: source_commit:

## 错误特征
```
undefined reference to [`']?(explicit_bzero|[a-zA-Z0-9_]+)[`']?.*test|symbol not found.*fallback
```

## 根因分析
目标 libc 缺少某 API 时，上游会把 fallback 实现编入主库并可能设为 hidden；独立测试目标若只链接公共测试对象而不链接主库或准确的 fallback 对象，链接器仍找不到该符号。共享库中的 hidden fallback 也不能作为外部符号满足测试目标。

## 推荐方案
**方法**: link-exact-fallback-object

**说明**: 确认失败测试真实调用链和 fallback 对象来源，把准确的 libtool object 加入该测试目标 LDADD；若 CI 使用发布 tarball 且不运行 autoreconf，同步对应 Makefile.in。随后执行完整 make check，保持原断言和 SKIP 规则。

**验证/命令**:
```
test_target_LDADD = lib/libname_la-fallback.lo $(COMMON_TEST_OBJECTS)
```

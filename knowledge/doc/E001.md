# E001: 找不到编译器

> **结构化数据**: [graph/E001.kv](../graph/E001.kv) | **原则**: P-TOOLCHAIN-001
> **严重度**: 🔴 blocking | **分类**: toolchain | **自动修复**: ✅ set-env-var

---

## 错误特征

```
C compiler cannot create executables
cc: not found
clang: command not found
configure: error: C compiler cannot create executables
```

## 根因

PATH 中没有 `cc` 软链接，只有 `clang` 可用。autotools 的 `configure` 默认查找 `cc`，在鸿蒙上找不到。

## 解决方案

```bash
export CC=clang
export CXX=clang++
```

## 涉及软件

所有 autotools 项目（configure 阶段）。

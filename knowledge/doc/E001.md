# E001: set-env-var

## 基本信息
- **严重度**: 3
- **类别**: toolchain
- **作者**: source_pr:
- **来源 PR**: source_commit:

## 错误特征
```
C compiler cannot create executables|cc not found|
                         C compiler.*not found|clang.*not found
```

## 根因分析
PATH 中没有 cc 软链接, 只有 clang 可用,
                         configure 默认查找 cc 找不到

## 推荐方案
**方法**: set-env-var

**说明**: 设置 CC=clang 让 configure 使用正确的编译器

**验证/命令**:
```
CC=clang
```

## 关键词
cc not found, C compiler, clang, PATH, compiler,
                         cannot create executables

# E566（草稿）— OHOS 沙箱 spawn 子进程类上游测试永久挂起：procmgr_wait 诊断与 ctest -E 豁免

> 状态：pending-editor-review（拟编号 E566，最终由主编确认）
> 实证：kio 6.26.0 PR #9560，CI 构建 #44355
> 编号迁移：原 E544 因与既有草稿冲突改为 E566

## 错误特征

conan create 的 ctest 阶段无限期停在某个测试上（无输出、无失败）：

```
      Start  7: kiocore-jobremotetest
（此后数小时无任何输出）
```

CI 侧表现为 14400s 构建超时（如果本地不提前发现）。

## 根因（诊断三步实证法）

OHOS 构建沙箱中，测试 spawn 辅助子进程（kioworker/QProcess/fork+exec 型 worker）后握手依赖 procmgr 进程监管服务，沙箱内链路不完整：

1. **wchan 实证**：`cat /proc/<测试pid>/wchan` → `procmgr_wait`（进程睡在等待监管握手上）；
2. **fd 实证**：`ls /proc/<pid>/fd` → `socket:[...]` 对应 `runtime-*.worker.socket` 已创建但永不完成握手；
3. **限时复跑**：`timeout 45 ./bin/<test>` → 退出码 124（挂起而非慢）。

典型伴随症状（同源环境限制，一并豁免）：
- `/tmp` 只读 → `QFATAL : ... couldn't create /tmp/jobtest/`（E002）；
- KMountPoint 枚举不到挂载点 → trash 类测试 "A trash folder could not be found or created"。

ctest 无默认单测试超时 → 一个挂起测试卡死整个 conan create。

## 解法

conanfile.py `_run_upstream_tests` 用 `ctest -E` 排除 + `ignore_errors=True`：

```python
excluded_tests = (
    "kiocore-jobremotetest",   # kioworker spawn 挂起
    "kiocore-jobtest",         # /tmp 只读 + kioworker spawn
    "kioworkers-testtrash",    # 无挂载点
)
exclude_re = "^({})$".format("|".join(excluded_tests))
with test_env.vars(self).apply():
    self.run(
        'ctest --test-dir "{}" --output-on-failure --no-tests=error '
        '-E "{}"'.format(self.build_folder, exclude_re),
        ignore_errors=True,
    )
```

完整代码见 .kv 的 solution 字段。先例：baloo 6.28.0（D-Bus 类排除）、kdbusaddons。

## 降级方案

- ctest `--timeout`（或 CMake `set_tests_properties(... TIMEOUT ...)`)：挂起项超时后标 Failed，不卡死整轮；
- `-R` 白名单只跑纯内存测试；
- 严禁不修配方硬推 CI（挂到 14400s 超时纯烧额度）。

## 验证

- kio 6.26.0：jobremotetest 手动实测 40+ 分钟挂起（wchan=procmgr_wait）；ctest -E 排除后整轮 1.62s 跑完 19 个测试；
- CI 构建 #44355（PR #9560）全绿。

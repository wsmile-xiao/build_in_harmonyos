# E2144 draft - Run Redis upstream Tcl suites on OHOS

> Status: DRAFT | Source: Redis 8.2.7 PR #5315
> Related: E077 (ELF signing), E060 and E046 (HMDFS temporary files and permissions)

## Problem

Redis official tests are target integration suites. They launch freshly built
`redis-server` processes, load modules, create multi-node topologies, and write
transient state. A package smoke test can pass while none of these paths runs.

Four OHOS constraints interact:

1. Source-tree target executables must be signed before Tcl launches them.
2. Archived launchers may be readable but not directly executable on HarmonyFS.
3. Test state must use executable user-cache storage, not the source tree.
4. The user session accepts SIGSTOP but does not actually suspend the process.

## Recommended design

Use a separately adapted `tcl/8.6.16` build requirement. Build Redis, remove any
stale signing section, sign all six commands, and then run every official entry
point serially through `sh`:

```sh
REDIS_TEST_TMPDIR=/data/storage/el2/base/cache/redis-test-$$ sh ./runtest
REDIS_TEST_TMPDIR=/data/storage/el2/base/cache/redis-test-$$ sh ./runtest-moduleapi
REDIS_TEST_TMPDIR=/data/storage/el2/base/cache/redis-test-$$ sh ./runtest-sentinel
REDIS_TEST_TMPDIR=/data/storage/el2/base/cache/redis-test-$$ sh ./runtest-cluster
```

Package the same signed binaries. Keep an independent consumer test for core
commands, persistence, replication, failover, Sentinel, Cluster, ACLs,
scripting, corruption rejection, and negative paths.

## Capability accounting

Do not skip complete files when only process suspension is unavailable. Detect
direct and coupled pause cases at the test wrapper, increment native skip
counters, print the reason, and make the pause helper fail if an unaccounted call
escapes. This converts a syntactically successful but semantically ineffective
SIGSTOP into an explicit platform boundary.

## Dependency boundary

Tcl remains a separate library adaptation and PR. Redis may consume a published
package or a checksum-verified isolated cache for Shadow evidence, but must not
copy the Tcl recipe into the Redis PR.

## Do not do this

- Do not report the 212 Tcl source files as 212 one-to-one assertions.
- Do not sign after running tests.
- Do not repeatedly chmod unreadable launchers; invoke a readable script via sh.
- Do not write test state into a non-executable source filesystem.
- Do not silently treat acknowledged SIGSTOP as actual suspension.
- Do not skip whole suites to avoid one unavailable process capability.

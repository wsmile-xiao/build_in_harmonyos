# E215 — 鸿蒙环境无 unzip 命令（Java/jar 构建场景）

## 错误特征
```
FileNotFoundError: [Errno 2] No such file or directory: 'unzip'
```
或 conanfile.py build() 中调用 unzip 解压 jar 时报错，导致 conan create 失败。

## 触发条件
- 构建系统: custom (Java/ant/jar)
- 阶段: build / packaging
- 场景: conanfile.py 或 test 脚本中调用 `unzip` 命令处理 .jar（zip 格式）文件

## 根因分析
鸿蒙环境（HarmonyOS PC）未预装 unzip 命令，且 cmd-pkgs 无 unzip 预编译包。
Java 项目构建中若用 `subprocess.run(["unzip", ...])` 合并/解压 jar 依赖，
会直接 FileNotFoundError 导致构建失败。

## 解决方案

### 推荐方案
- Python 配方内用标准库 `zipfile.ZipFile(j).extractall(dir)` 替代 unzip 命令
  （conanfile.py 内 subprocess.run 改为 zipfile 模块）
- 测试脚本读取 jar 内容时改用 JDK 自带工具：
  `jar xf <jar> META-INF/MANIFEST.MF`（提取单个条目）或 `unzip -p` 的替代
- 避免依赖任何未在 profile buildenv 中声明的 shell 命令

### 禁止做法
- ❌ 在 conanfile.py 中调用 unzip/jar 之外的宿主命令而不做可用性检查
- ❌ 用 `apt-get install unzip`（鸿蒙不支持）

## 验证
```bash
python3 -c "import zipfile; zipfile.ZipFile('x.jar').extractall('out')"
```

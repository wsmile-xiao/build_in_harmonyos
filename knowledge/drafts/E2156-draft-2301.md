# E2156 - Preserve BLACS Runtime, Empty Arguments, and Abort Output

## Symptom

An upstream BLACS executable builds successfully but its CTest entry fails in
one of three ways:

- the executable is copied to an output directory and cannot find a shared
  dependency that was reachable through its original `$ORIGIN` RUNPATH;
- `list(APPEND tmp ${TESTSTRING})` becomes a one-argument CMake command when
  `TESTSTRING` is empty; or
- the program writes `DONE BLACS_GRIDEXIT` and intentionally calls
  `MPI_Abort`, but the output file does not contain the marker.

## Root Cause

The harness treats executable location, optional argument construction, and
Fortran output durability as incidental details. They are observable parts of
the test contract. Moving an ELF changes `$ORIGIN`, unquoted CMake expansion
removes an empty argument, and `MPI_Abort` can discard buffered Fortran output.

## Resolution

1. Run `${RUNTIMEDIR}/${TEST_PROG}` directly and do not copy the test ELF away
   from the build location that owns its RUNPATH.
2. Preserve an empty argument with
   `list(APPEND tmp "${TESTSTRING}")`.
3. Add `FLUSH(OUTNUM)` immediately after the completion `WRITE` and before the
   intentional abort path.
4. Retain both output and error files. Judge success from CTest status plus the
   required marker, not from non-empty MPI abort stderr alone.

## Validation

ScaLAPACK 2.2.3 r10 used input SHA-256
`2c51a5d00154b616ae98c6b5bcce9eb857ef6378899905d0ea300efc4360d9e5`.
The complete upstream suite passed 100/100. Both `xCbtest` and `xFbtest` output
files contained `DONE BLACS_GRIDEXIT`; `LastTest.log` SHA-256 was
`64d7de3901c80decadaa30259d598930c04fd9558a1098714a76138db3794fe0`.

## Negative Checks

- Restoring the executable copy must be rejected when the binary depends on
  its original relative RUNPATH.
- Removing the quotes around an empty `TESTSTRING` must reproduce the CMake
  arity failure.
- Removing `FLUSH(OUTNUM)` must not be accepted solely because the numerical
  work completed.
- Suppressing `MPI_Abort`, discarding stderr, or running only the two BLACS
  entries cannot replace the full upstream inventory.

## 问题：硬编码对照表的两个结构性缺陷

`test_package` 里对"编解码 / 双向映射"类工具最常见的写法是抄几个期望输出：

```c
/* ❌ 覆盖由作者想象力决定，且期望值可能是从错误运行结果反抄来的 */
expect(strstr(out, "Lunar : 1999.11.25.0") != NULL, "公历2000-01-01");
expect(strstr(out, "Lunar : 2024.1.1.0")   != NULL, "2024春节");
```

两个问题：

1. **覆盖盲区**。只有你**想到**的输入被验证。区间边界、跨世纪、闰年/闰月附近的
   输入全部没有覆盖——而边界恰好是这类工具最容易写错的地方。
2. **判据可能自我固化 bug**。如果期望字面量是从一次**错误的**运行结果里"反抄"
   回来的，测试会忠实地把这个 bug 固化成"期望行为"，绿得非常稳定。

## 方案：让被测程序自证自洽

对**可逆**转换（`A(x) → y`，`B(y) → x`），判据应该是：

```
对每个采样点 x:  A(x) → 解析出 y → B(y) → 断言结果 == x
```

这带来三个性质：

| 性质 | 说明 |
| --- | --- |
| **覆盖只受采样点数量限制** | 不再受作者想象力限制；采样点可跨越整个支持区间 |
| **两侧互相牵制** | 编码侧的缺陷会被解码侧暴露，反之亦然；无法靠"抄错误输出"掩盖 |
| **免对照表** | 不依赖任何外部数据/权威表，判据完全由被测程序闭合 |

## 三个必须做到的细节

### ① 采样点必须覆盖区间端点

lunar 的支持区间是公历 **1900-01-31**（农历 1900 正月初一）到 **2049-12-31**。
往返遍历取 12 个点，**两端必须是区间上下界**：

```c
static const int sweep[][3] = {
    { 1900, 1, 31 }, { 1955, 6, 15 }, { 1976, 9, 9 }, { 1984, 2, 2 },
    { 1997, 7, 1 },  { 2001, 10, 1 }, { 2008, 8, 8 }, { 2012, 12, 21 },
    { 2020, 1, 25 }, { 2024, 2, 10 }, { 2033, 5, 1 }, { 2049, 12, 31 },
};
```

实测 12/12 全部回到原点（`1900.01.31 → 农历 1900.1.1 → 1900.01.31`，
…，`2049.12.31 → 农历 2049.12.7 → 2049.12.31`）。

### ② 解析用 `sscanf` 抽字段，不要用 shell 切字符串

```c
/* ✅ 直接按格式抽，解析失败可被识别 */
sscanf(strstr(out, "Lunar :"), "Lunar : %d.%d.%d.%d", &ly, &lm, &ld, &lh);

/* ❌ sed/awk 切分依赖 locale 与分隔符恰好为 '.'；
      切失败时表现为"断言不相等"，把解析问题伪装成程序问题 */
```
```
$ lunar 2024 2 10 | sed -n 's/^Lunar : \([0-9.]*\)\..*/\1/p'   # 输出随 locale 变化
```

### ③ 不可逆输入**显式枚举并打印 SKIP**——绝不能静默跳过

lunar 的**闰月**就是典型不可逆分支：农历 `2023.2Leap.20` 反查需要额外的 `-l`：

```
$ lunar -i 2023 2 20       → Solar : 2023.3.11.0      （普通二月二十，不是闰月）
$ lunar -i -l 2023 2 20    → Solar : 2023.4.10.0      （闰二月二十）
$ lunar 2023 4 10          → Lunar : 2023.2Leap.20.0  （往返落在 Leap 上）
```

往返遍历拿到 `2023.2Leap.20` 后直接喂 `-i 2023 2 20` 会得到 **2023.3.11**，
**不相等**。若不排除，就会把"测试自己构造的输入不可解"误报成"程序不一致"。

```c
/* ✅ 显式排除，并留下可见痕迹 */
snprintf(leappos, sizeof(leappos), "Lunar : %d.", ly);
lp = strstr(buf, leappos);
if (lp && strstr(lp, "Leap") && (strstr(lp, "Leap") - lp) < 40) {
    printf("  [SKIP] 往返 %d.%d.%d: 闰月，需 -l，已由独立用例覆盖\n", y, mo, d);
    continue;                    /* 打印而不是静默 continue */
}
```

★ **排除动作必须伴随独立用例**，否则"排除"就变成了真正的覆盖缺口：

```c
case_expect("-i -l 2023 2 20", 0, c_leap1, 3);   /* Solar : 2023.4.10.0 */
case_expect("-i -l 2023 2 1",  0, c_leap2, 2);   /* Solar : 2023.3.22.0 */
```

## 与既有规范的衔接（不能因为用了属性测试就放松）

往返判据**不替代**本仓库已确立的 `test_package` 硬约束，两者叠加：

| 约束 | 理由 |
| --- | --- |
| `expect()` 计数，不用 `assert()` | NDEBUG（Release）下 assert 被整体编译掉，测试静默变空壳 |
| `popen` 内存直读，不落盘 | OHOS `/tmp` 只读，落盘判据会与程序无关地失败 |
| `pclose==-1 \|\| !WIFEXITED \|\| code∈{126,127} \|\| code>=128` 判"跑不起来" | popen 经 `/bin/sh` 中转，信号死亡被转写成 128+signum |
| 循环读到 EOF 再 `pclose` | 单次 fread 后立刻 pclose 会让输出超缓冲的子进程 SIGPIPE/死锁 |

## 可套用的范围

| 适用（可逆） | 不适用（有损/有状态） |
| --- | --- |
| 历法换算（lunar）、base64/uuencode、`xxd`+revert、Morse、ROT-N | 有损压缩、哈希/摘要、随机化输出 |
| 单位换算（ifmetric）、坐标变换 | 带全局状态/计数器的协议 |
| tar/cpio 打包↔解包、序列化↔反序列化 | 需要外部密钥的加密（除非密钥也是测试输入）|

不适用场景仍应用硬编码向量，但**必须写明有损性**，不要让人误以为往返失败是 bug。

# E7003: Gate upstream CTest registration by target capability

## Symptom

An OHOS cross-build with the upstream CTest option enabled fails while
compiling one conformance target. The source calls an API such as
`oneapi::tbb::task::suspend`, `resume`, or `suspend_point`, but the target
headers do not expose those names. Keeping the target registered either fails
the build or tempts a recipe to count a no-op test as passed.

## Root cause

CTest registration is a build-graph decision, while API availability is a
target capability decision. In oneTBB 2023.1.0, `__TBB_RESUMABLE_TASKS` is false
when `__linux__` is defined without `__GLIBC__`; OHOS therefore has no public
resumable-task aliases. The upstream `test/CMakeLists.txt` nevertheless adds
`conformance_resumable_tasks` unconditionally.

## Fix

1. Keep the upstream test option enabled and identify the exact capability
   macro and CMake registration line.
2. Add one platform condition around only the unsupported registration, using
   the target CMake system identity (`OHOS` in this case).
3. Preserve every other upstream test and record both the source inventory and
   the target-supported inventory, including the skipped test and reason.
4. Run the remaining CTest inventory and use its target denominator for the CI
   result; do not treat a source-only or consumer smoke test as a substitute.

## Validation

Buildbot #41450 reached 80% before reporting 13 errors in
`conformance_resumable_tasks.cpp`. The current candidate adds an OHOS-only
CMake registration gate, leaving the source inventory at 139 and the OHOS
supported inventory at 138. A minimal fixture confirmed that the patch applies
cleanly and that the OHOS condition omits only this target.

## Applicability and safety boundaries

This applies when the upstream capability contract demonstrably excludes one
test on the target. It does not justify turning off the complete test suite,
silently changing test sources, or counting an empty/no-op target as a pass.
If the capability is available, the test must remain registered and included in
the complete target inventory.

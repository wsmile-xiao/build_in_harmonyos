# 上游 CTest 与交叉构建真机 consumer 的边界

## 现象或适配场景
上游项目提供 CTest，但交叉编译出的测试程序不能在 Windows 构建机直接运行。

## 根因
主机测试和 OHOS 目标测试属于不同执行环境。它们可共享源码和断言意图，但不能共享运行结果。

## 修复步骤
在独立主机配置中启用并完整执行上游 CTest，冻结真实测试清单和 1/1 结果；目标 profile 只构建
安装包与最小公共 API consumer，随后在授权真机运行并记录 RC、退出和清理证据。

## 验证方式
主机 CTest 全量通过；目标 consumer 实际解析 XML、执行 XPath，进程以 RC=0 退出。

## 适用范围和安全边界
适用于所有有上游测试且需要交叉编译的 C/C++ 库；主机 CTest 不得冒充目标运行，consumer 也不得
改变上游测试分母。

# E580 — conandata.yml 注释含 https URL 被 build_and_test.sh pre-download 正则误提取为下载源

## 错误特征

`conan create` 阶段报：

```
ERROR: libdroplet/2.0: Error in source() method
	NotADirectoryError: [Errno 20] Not a directory:
	'/.../.build-cache/predl_cache/598926c6_Droplet/archive/v2.0.tar.gz'
```

或镜像前缀叠加产生的无效 URL：

```
WARN: Could not download from the URL https://gh-proxy.com/file:///.../predl_cache/...: Not found
```

## 触发条件

- 构建系统: autotools / 任意 conan 包（与构建系统无关）
- 阶段: finish Step 5/10 本地 CI 模拟（W3）→ build_and_test.sh → conan create → source()
- 本质条件: `conandata.yml` 中**注释行**（或其他非 sources 段）出现带 scheme 的 `https://` 完整 URL

典型触发写法：

```yaml
# conandata.yml — libdroplet 2.0
# upstream: https://github.com/scality/Droplet (tag v2.0)   ← 这行触发
```

## 根因分析

`ci/conan/build_and_test.sh` 的 pre-download 脚本（W3 预下载源码到 `.build-cache/predl_cache/`）用正则对 `conandata.yml` **全文**做 `re.findall` 提取 URL：

```python
url_pattern = r'(?:^|\s)(?:url:?\s*)?["\']?-?\s*(https?://[^\s"\']+)'
urls = re.findall(url_pattern, raw, re.MULTILINE)
```

该正则不区分 YAML 的注释/配置段，`(?:^|\s)` 可匹配注释文本中的空白，从而把：

- `# upstream: https://github.com/scality/Droplet (tag v2.0)`
- 中的 `https://github.com/scality/Droplet`（到空格前）

也当作一个 "源码 URL" 抓取。随后：

1. 对误抓 URL 执行 curl 下载 → 得到仓库主页 HTML 等非 tarball 内容，落盘为 `predl_cache/598926c6_Droplet`
2. `content.replace(url, 'file://...')` 把 `https://github.com/scality/Droplet` 这个**前缀**替换进完整 URL
   `https://github.com/scality/Droplet/archive/v2.0.tar.gz` 的头部
   → 拼出 `file://.../predl_cache/598926c6_Droplet/archive/v2.0.tar.gz`
3. `598926c6_Droplet` 是文件而非目录 → conan get() 抛 `NotADirectoryError`；
   镜像列表中 gh-proxy 前缀再叠加在 `file://` 上 → 无效 URL

全仓实证：237 个 `conandata.yml` 注释含 `https://`，均为潜在触发源。

## 解决方案

### 推荐方案
`conandata.yml` 的注释行**不得书写带 scheme 的 https URL**，改用纯文本描述：

```yaml
# upstream: scality/Droplet (tag v2.0)
```

官方 URL 只保留在 `sources.url` 正式字段（CI 镜像改写/恢复逻辑只处理该字段）。

### 禁止做法
- ❌ 在 sources 段或注释中书写 `https://` 完整 URL（会被全文正则误抓）

## 验证

```bash
# 诊断：确认 conandata.yml 被误提取出非 sources 字段 URL
python3 -c "
import re
raw = open('archives/l/libdroplet/2.0/conandata.yml').read()
p = r'(?:^|\s)(?:url:?\s*)?[\"\']?-?\s*(https?://[^\s\"\']+)'
urls = list(dict.fromkeys(re.findall(p, raw, re.M)))
print('URLs:', len(urls))
for u in urls: print(' ', u)
"
# 修复前输出 3 个（含注释 URL），修复后仅 1 个（官方 sources.url）

# 验证：finish W3 本地 CI 模拟通过
python3 scripts/ohc-run.py finish libdroplet 2.0 built
```

实测（libdroplet 2.0）：修复前 3 个 URL（含注释 `https://github.com/scality/Droplet`，md5=598926c6），
W3 失败 NotADirectoryError；删除注释 URL 后解析 1 个，W3 全过（L0/L1-L5 PASS）。

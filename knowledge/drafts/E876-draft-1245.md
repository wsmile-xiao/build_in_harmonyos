# E876 草稿：shunit2 runner 通过 tee 掩盖上游测试失败

## 错误特征

`make test` 返回 0，但日志同时出现 `FAILED (failures=4)` 和 `7 tests, 12 failures, 0 skipped`。

## 根因与作用域

`unfoo` 的 `tests/runner` 对每个套件执行 `( exec ${shell} ./${suite} 2>&1 | tee results/...)`，只输出汇总、不传播失败。缺可选命令 `unace`、`unrar` 时，ACE/RAR 格式的三个测试套件各有四个断言失败，命令的返回码仍为 0。适用于使用 shunit2 + tee、并依赖可选外部工具的 shell 项目。

## 推荐处理

逐套件读取 `Ran`/`OK`/`FAILED` 与末尾汇总；检查缺失工具；如实申报实际通过率和未验证格式，不以 `make test` 状态码断言全绿。另以真正使用 Conan 包的消费者测试验证可用格式，缺失可选格式须单独说明。

## 验证证据

```bash
cd /root/tmp/builds/unfoo-1.0.8.work
make test > /data/harmony-compact/unfoo-upstream.log 2>&1
# exit 0；尾行 /bin/bash: 7 tests, 12 failures, 0 skipped
# 前四个 case 通过，三个 case 的 ACE/RAR 各报 FAILED (failures=4)
```

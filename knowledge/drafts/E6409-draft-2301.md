# E6409 - Repair an incomplete generated component pkg-config contract

## Symptom

Meson finds `opusfile/0.12`, but the target C++ build fails with:

```text
fatal error: 'opusfile.h' file not found
```

After the nested include is repaired, the same class of failure can move to
the provider's public dependency:

```text
fatal error: 'ogg/ogg.h' file not found
```

The package contains `include/opus/opusfile.h` and `lib/libopusfile.so`. The
compile command receives only the package root `include` directory.

## Root Cause

The provider exposes `opusfile` as a Conan component. The component has
`libs = ["opusfile"]` and its public header includes Ogg. `PkgConfigDeps`
therefore needs both the nested `include/opus` Cflags and a visible `ogg`
provider edge. A helper that returns early whenever the component already has
valid include/lib metadata still leaves the generated `Requires` edge absent.

Changing a temporary dependency root `cpp_info.includedirs` object in the
consumer is not sufficient: component generation can still consume the
original component metadata. A successful dependency lookup proves neither
header visibility nor the final link contract.

## Fix

1. Validate the exact header and library below the dependency package root.
2. Run `PkgConfigDeps.generate()` normally.
3. Strictly parse only the affected generated `.pc`. Reject BOM, CR, NUL,
   missing terminal LF, duplicate/missing fields and identity drift.
4. Change `includedir` to the capability-proven nested directory and add the
   exact missing `-l` flag once.
5. Preserve the Conan-generated `Name` and `Version`; require the exact public
   component edge rather than accepting a silently incomplete `Requires` set.

For opusfile the resulting semantic lines are:

```text
includedir=${prefix}/include/opus
Libs: -L"${libdir}" -lopusfile
Cflags: -I"${includedir}"
Requires: ogg opus
```

## Validation

- Rewrite and fail-closed matrix: 15/15.
- Fresh offline `conan install --build=never`: RC0.
- Generated `opusfile.pc`: exact nested include, one `-lopusfile`, preserved
  `Requires: ogg opus`, UTF-8 without BOM/CR and terminal LF.
- Applying the rule to SDL2 was rejected and removed; the repair is scoped to
  the exact broken provider.
- A complete `opusfile` include/lib record with `required_pkgconfigs=("ogg",)`
  still produces a repair descriptor, the no-edge case keeps the fast path,
  and an old `Requires: opus` line is rejected (3/3 directed checks).
- Target r67 completed one coherent OHOS transaction: upstream 24/24
  (23 `OK`, one `EXPECTEDFAIL`) and the installed-package flow 1/1. The exact
  candidate HEAD was `226472fc71c00d0d73a2a5604665fce3fda8e02b`.

## Safety Boundaries

- Do not patch upstream include statements or add platform-name conditionals.
- Do not inject global compiler/linker flags for a single provider defect.
- Do not guess transitive `Requires` edges; preserve Conan's component output.
- A generator PASS does not replace target execution. The r67 result supplies
  that separate evidence; Review, CI, and submission remain separate gates.

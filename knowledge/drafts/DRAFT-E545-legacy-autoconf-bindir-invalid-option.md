# E545 — 1994 年 autoconf configure 拒绝 Conan AutotoolsToolchain 追加的 --bindir/--libdir 等现代选项

## 错误特征

```
./configure --prefix=/ --bindir=${prefix}/bin --sbindir=${prefix}/sbin ...
configure: error: --bindir=${prefix}/bin: invalid option
```

1990s 年代（autoconf 2.0 时代）生成的 configure 脚本只识别 `--prefix`、`--srcdir` 等少量选项，
对 Conan `AutotoolsToolchain` 默认自动追加的 `--bindir/--sbindir/--libdir/--includedir/
--oldincludedir/--datarootdir` 直接报 `invalid option` 并中止，导致 conan create 失败。

## 触发条件

- 构建系统: autotools
- 阶段: configuration
- 特征: configure 脚本头部带 `Generated by GNU Autoconf 2.x`（x 为 0/1/3 等旧版）或缺少
  `--bindir`/`--libdir` 的 AC_ARG_WITH 声明

## 根因分析

Conan 2 的 `AutotoolsToolchain.generate()` 会为 GNU 安装目录约定自动追加
`--bindir/--sbindir/--libdir/--includedir/--oldincludedir/--datarootdir` 等 flag，
这是现代 autoconf 的标准行为。但 1994 年前后的 configure（autoconf 2.0）的选项解析
硬编码只支持极少量 `--xxx` 选项，任何未声明的选项都会触发
`configure: error: ... invalid option` 退出。

## 解决方案

### 推荐方案

在 `conanfile.py` 的 `generate()` 中裁剪掉 AutotoolsToolchain 自动追加的安装目录 flag，
仅保留 `--prefix=/`：

```python
def generate(self):
    tc = AutotoolsToolchain(self)
    for flag in ("--bindir", "--sbindir", "--libdir", "--includedir",
                 "--oldincludedir", "--datarootdir"):
        tc.configure_args = [a for a in tc.configure_args if not a.startswith(flag)]
    tc.generate()
```

### 禁止做法

- ❌ 不要用 `--host=...`/`--build=...` 等参数绕过（R15：native 编译禁用，应改
  config.guess/config.sub）。
- ❌ 不要修改 1994 configure 的选项解析代码来"学习"接受现代 flag（改动面大、
  易破坏其它旧选项）。

## 验证

```bash
conan create archives/r/rsynth/2.0 -pr:h=ci/conan/profiles/ohos-aarch64 \
    -pr:b=ci/conan/profiles/ohos-aarch64 --user=ohpcd --channel=stable 2>&1 | \
    grep -E "configure.*--prefix=/|invalid option"
# 期望: 无 "invalid option"，configure 以 --prefix=/ 通过
```

# 上游断言在 64 位 OHOS 必失败：浮点→无符号 UB（aarch64 饱和=0）+ 32 位字长期望 → 白名单闸不凑绿

> Draft: E719
> Stem: `E719-opt-3.19-aarch64-unsigned-ub-known-test-fail-gate` — pairs with the same-stem `.kv`

## 基本信息

- **ID**: E719
- **严重度**: 3
- **类别**: upstream-test-known-broken
- **触发工具**: conan|make|sh
- **阶段**: testing

## 错误特征

```
grep 65535|grep 4294967295|is not a valid positive integer, will use \[0\]|[0-9] of [0-9] tests failed
```

上游 `checkopt` 有两条断言在 64 位 OHOS 上**结构性必失败**，且改测试=凑绿、
改库也救不回：

- `testtypes -n -1 | grep 65535`（期望 unsigned short 回绕成 65535）
- `testtypes -o -1 | grep 4294967295`（期望 unsigned long = 2^32-1）

根因链：

1. 库里 `opt_atou()` 是 `x = (unsigned long)atof(s)`；`atof("-1") = -1.0`，
   **浮点 → 无符号整型转换是 C 未定义行为**；
2. aarch64 的 `fcvtzu` 走**饱和语义 → 0**（x86-64 才会回绕），所以 `-1` 变成 0，
   程序打印 `OPT Warning: … will use [0]` 且值为 0；
3. 期望值 `4294967295 = 2^32-1` 是**32 位字长写死**，64 位 `unsigned long` 永远
   打印不出它。

**第三方佐证**：Debian `opt_3.19-4` 的 `debian/rules` 原文
`override_dh_auto_test: dh_auto_test || true`（带 "FIXME: Hiding eyes from test failure"），
即官方打包对同一组失败选择容忍而非修断言。

## 解决方案

**主方案**: known-failure-whitelist-gate-with-two-stage-cross-check

配方口径（把「不写全绿」做成机器可执行的闸）：

1. **逐 TEST 单跑留档 rc**（`{ cmd; rc=$?; echo HMBS_TEST_RC name=$rc; exit $rc; } > log 2>&1`），
   rc 从日志回读，读不到就抛错（判据缺失）；
2. 再跑 `make check` 取框架 `PASS:/FAIL:` 视角，**两阶段判读必须一致**（rc=0 假绿双阶段核对）；
3. 断言计数：点计数必须剔除上游脚本内嵌 `make: … is up to date.` 的句点噪声，
   `Error:` 行数 = 失败断言数；
4. **白名单闸**：失败断言集合必须 ⊆ {USHORT error, ULONG error}，非零 TEST 只允许
   checkopt；出现其它任何失败、缺 TEST、两阶段不一致 → `ConanException` 阻断；
5. 结果用 `HMBS_UPSTREAM_TEST_RESULT` 标记如实上报 `failed=N`，notes/PR 正文写真实
   通过率——**不改断言、不改库、不写 PASS**。

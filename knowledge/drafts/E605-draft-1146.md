# E605 — Cross-built OHOS test binaries require a native host harness and bounded fixtures

## 错误特征
- Meson runs the cross-built test executables and reports `exit status 77` or WSL reports `Exec format error` because the files are OHOS/aarch64 ELF binaries.
- A legacy upstream test that calls an external HTTP service reaches its timeout, for example `TIMEOUT ... killed by signal 15`; no assertion result is available.
- A native target with only `GDummyTlsBackend` reports `TLS support is not available` before an external HTTPS-backed test reaches its request/response assertions.
- A loopback test intermittently reports `Could not connect to 127.0.0.1: Connection refused` when it starts a raw server thread on a fixed port and connects before the server has completed `listen()`.
- A packaged shared-library consumer compiles and links but exits with code 127 for an indirect SONAME such as `libjson-glib-1.0.so.0`, even when its package directory is visibly present late in the printed `LD_LIBRARY_PATH`.
- The test summary can misleadingly show `Skipped: 10` with return code 0 from a wrapper, or one timeout among otherwise passing tests.

## 触发条件
- 构建系统: Meson/GLib (the same boundary applies to other cross-build test runners)
- 阶段: upstream testing after an OHOS cross build
- Environment: host is x86_64 WSL/Linux, target executables are aarch64 OHOS, and at least one test depends on a public service or TLS backend outside the package's control.

## 根因分析
The cross build produces valid target artifacts, but the host kernel cannot execute their architecture and ABI. Meson therefore records a skip/format error before the test body runs. Separately, a network-backed test is not deterministic: a dead or blocked public endpoint turns a real assertion into a timeout, and a target without a GIO TLS backend fails before request construction and response parsing can be exercised. A local server still races if a raw thread is detached without a condition-variable readiness handshake; fixed ports also introduce collision risk. Finally, a successful package link does not prove the consumer's runtime closure: Conan's generated run environment can omit a component-backed transitive directory, while some native OHOS workers also stop resolving indirect SONAMEs from later entries in a long path even when the directory is printed. None of these outcomes is evidence of a passing upstream suite or consumer, and changing the denominator to exclude them obscures the missing coverage.

## 解决方案

### 推荐方案
1. Keep the frozen target build and its W3 evidence untouched.
2. Supply host-only dependencies in a task-private prefix and configure a fresh native build with the complete upstream test inventory.
3. If the target lacks a TLS backend, add a narrowly scoped test-only patch that replaces only the external HTTPS transport with a task-local loopback HTTP fixture. Keep every registered test, request method and parameter, response shape, parser path and assertion unchanged. Do not install the fixture or test server into the package.
4. Start loopback services through one shared helper that binds an ephemeral port, checks the listen error, and signals a condition variable only after the listener is ready. Obtain the URI from the bound server and pass it as test data instead of using a fixed port or sleep-based retry.
5. Rebuild the full cross-test inventory and run it on the target. Separately run the native suite with `--no-rebuild`, record the exact `N/N PASS` summary, and hash the logs. A loopback fixture proves the retained request/response semantics, not TLS interoperability.
6. Treat `test_package` as an independent runtime boundary. Enumerate host dependencies in stable order with the tested package first, aggregate component `libdirs`, resolve and validate every SONAME/alias beneath its package root, then copy the conflict-checked closure into one task-local loader-first directory. On a native OHOS worker, remove stale signatures and self-sign the critical copied roots at that final path. Prepend the short staged directory to `LD_LIBRARY_PATH` while retaining `env="conanrun"`; keep the original dependency directories only as diagnostic fallback entries.

### 禁止做法
- Do not count `exit 77`, `Skipped`, `Exec format error`, or a timeout as a pass.
- Do not delete or disable the network test merely to obtain a green denominator.
- Do not delete or skip the network-backed test because TLS is unavailable.
- Do not install fixture code into the packaged library or claim that loopback HTTP validates TLS. A formal recipe may carry a test-only patch when its scope is limited to the upstream test source and the full target test inventory is still executed in W3/CI.
- Do not repair a server-start race with an arbitrary sleep or a fixed retry count; use a readiness handshake tied to successful `listen()` and a dynamically allocated port.
- Do not infer consumer executability from compile/link success, `VirtualRunEnv`, or a printed long loader path; verify the single staged closure, final-path signatures and the real consumer exit code.

## 验证
```bash
PYTHONPATH=<task>/meson-runtime python3 -m mesonbuild.mesonmain test \
  -C <task>/host-native-build --no-rebuild --print-errorlogs --num-processes 2
# Require: N/N PASS, skipped=0, timeout=0, fail=0; hash raw output and fixture request log.
# Separately require the packaged consumer to print its semantic success result and exit 0
# with a logged tested-package-first transitive LD_LIBRARY_PATH.
```

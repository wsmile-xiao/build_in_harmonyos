# E553 — Qt5 模块私有 prefix 构建组合：private_tests 解锁上游私有测试 + reduce_exports 只挪不删 + 外来 pri 剪枝

> 来源：qt5-qtwebsockets 5.15.2 适配（PR !14826，j669539，鸡屁股队）
> 状态：pending-editor-review（拟提升编号 E553，最终由主编确认）

## 一、适用场景

用 conan + qmake 构建 **Qt5 附加模块**（qtwebsockets/qtwebchannel/qtserialport 等
`qt*-everywhere-src` 子模块包），依赖已发布的 qt5-qtbase，需要在适配中**全量执行
上游自动测试**（含私有 API 测试目录）时。前提模式：私有可写 Qt prefix 镜像 qtbase
（qt5-qtcharts / qtmultimedia 先例）。

## 二、错误特征（三层，均可独立命中）

### 1. 私有测试目录静默丢失（无报错！最隐蔽）

```
# make check 只执行 3 个公开套件，tests/auto/websockets 下的
# websocketprotocol/dataprocessor/websocketframe/handshakerequest/
# handshakeresponse/qdefaultmaskgenerator 6 个目录根本没构建
```

- **根因**：模块级 `websockets.pro` 用 `qtConfig(private_tests)` 包裹私有测试目录的
  SUBDIRS 条目；qtbase 包的 `mkspecs/qmodule.pri` 中
  `QT.global_private.disabled_features` 含 `private_tests`（默认发布态）时条件为假，
  目录静默跳过——**没有任何报错**，测试面直接缩水且极易漏察觉。

### 2. 私有测试链接失败

```
undefined reference to `QWebSocketFrame::...'
undefined reference to `QWebSocketHandshakeRequest::...'
```

- **根因**：`reduce_exports` 特性开启（发布态默认）时非公开类符号默认隐藏。

### 3. 误删特性名 → qmake 中止

```
Project ERROR: Could not find feature reduce_exports
```

- **根因**：直接把特性名从 enabled 列表**删除**（而非挪到 disabled 列表）。
  特性列表是 qtConfig() 查询的注册表，删名=查询悬空。

### 4. 构建拉入未声明依赖（外来 pri 污染）

```
Unknown module(s) in QT: qml
Unknown module(s) in QT: quick
```

- **根因**：本地 conan 缓存中的 qt5-qtbase 包被同仓其他 Qt5 模块构建污染——
  `mkspecs/modules/qt_lib_qml*.pri` 等外来 pri 指向**其他 conan 缓存包**的绝对路径
  （qt5-qtwebsockets 5.15.2 实测：86 个 pri 中 34 个外来）。qmake 解析镜像 prefix 时
  静默拉入 qml/quick/declarative 等未声明依赖。
- **行为差异**：原始 CI 下载的 qtbase 包无此污染（剪枝为空操作）——本地缓存与
  CI 纯净包的表现不一致，属"本地能过/CI 不过"或反之的典型来源。

## 三、解决方案（组合，可直接复制）

镜像 mkspecs 的 `_prepare_mkspecs()` 三步（qt5-qtwebsockets 5.15.2 conanfile.py
L102-L186 实测）：

### 步骤 1：私有可写 prefix 镜像 + build-dir 引用重写

顶层目录 symlink、`bin/` 复制（构建工具需可写），并把 mkspecs 中 `.pri` 残留的
`.../\.conan2/p/b/qt*/b` build-dir 引用重写为 qtbase 包真实路径。

### 步骤 2：特性翻转（**只挪不删**）

```python
enabled  = re.search(r"QT\.global_private\.enabled_features = ([^\n]*)", content)
disabled = re.search(r"QT\.global_private\.disabled_features = ([^\n]*)", content)
en  = [w for w in enabled.group(1).split()  if w != "reduce_exports"]
dis = [w for w in disabled.group(1).split() if w != "private_tests"]
if "private_tests"  not in en:  en.insert(0, "private_tests")    # 解锁 6 个私有测试目录
if "reduce_exports" not in dis: dis.insert(0, "reduce_exports")  # 等效 Qt developer-build
# （重新拼接写回 qmodule.pri）
```

- `private_tests` 挪入 enabled：websockets.pro 把 6 个私有测试目录纳入 SUBDIRS；
- `reduce_exports` 挪入 disabled：私有类符号导出，私有测试可链接；
- **安全边界**：特性名必须保留在两个列表之一，删除会使 `qtConfig()` 报
  "Could not find feature" 中止 qmake。

### 步骤 3：外来模块 pri 剪枝（构建封闭性）

```python
foreign = any(not m.group(1).startswith(qtbase_pkg)
              for m in _CONAN_PATH_PATTERN.finditer(content))
if foreign:
    os.remove(pri_path)   # pri 含非 qtbase 的 conan2 绝对路径即删除
```

扫描 `mkspecs/modules{,-inst}/` 下全部 `.pri`；qtbase 纯净包场景此步为空操作
（本地缓存污染防御），因此**不会破坏 CI 纯净环境**。

### 配套（防虚报，强烈建议）

- 测试日志**强制校验**：预期套件数（如 9）+ 失败白名单（`_ALLOWED_FAILURES`）；
  白名单外任何失败 → 构建失败。防止"私有测试没构建出来也算过"的虚报；
- `tst_*` 可执行文件先 `binary-sign-tool sign -selfSign 1` 签名再回环执行
  （OHOS ELF 签名机制，coinutils 先例）；
- `make install STRIP=true`（qmake strip --strip-unneeded 破坏动态符号表致 dlopen 失败）；
- 打包后重写 `.prl/.la/.pc` 残留 build-dir/source-dir 路径为 package_folder。

## 四、降级方案（fallback）

- qmodule.pri 缺失/不可写 → 只执行公开套件，**文档化缩减的测试覆盖**，严禁伪造
  私有测试结果；
- 特性翻转受阻 → 不要删除特性名（会中止 qmake）；整体跳过对应私有测试目录并在
  日志显式标注；
- 剪枝不可行 → 改用隔离的干净 conan 缓存（独立 `CONAN_HOME`）或 CI 纯净下载路径
  构建，保证封闭性。

## 五、验证证据（qt5-qtwebsockets 5.15.2）

- 本地 conan create：G0-G4 门禁全绿（HarmonyOS PC arm64 / clang 15）；
- 上游测试：9 套件 / 7322 数据用例 → **7321 通过 + 1 环境限制白名单**
  （`tst_QWebSocket::tst_errorString`：环境 DNS 对任意域名返回 fake-IP 198.18.0.101，
  预期 HostNotFoundError 实得 RemoteHostClosedError；同套件其余 20 用例含真实回环
  连接全过）；
- test_package 1/1 PASS（127.0.0.1 回环 RFC 6455 echo 往返）；
- 打包 `.so` binary-sign-tool 签名成功。

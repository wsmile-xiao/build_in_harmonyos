# E552：上游自带特性宏守卫的 Qt PrintSupport 缺失适配——QT_NO_PRINTER 一行定义启用原生降级 + 导出配置去依赖 + 任务卡元数据世代甄别

> 草稿状态：pending-editor-review（编号 E552，最终由主编确认）
> 载体：PR #14653（archives/k/kdiagram/3.0.1，KChart6 + KGantt6，Qt6/OHOS arm64）
> 类别：cmake | conan | dependency | packaging | ohos
> 触发器：① OHOS 平台差异（无打印栈）+ ④ 构建系统组合方案（split-package 消费链）

## 适用场景（一句话）

qtbase/6.11.1 线 PrintSupport=OFF 时适配 KDE/Qt 上游模块——若上游源码自带
`#ifndef QT_NO_PRINTER` 类特性守卫，一行宏定义即可启用原生降级，不必手写 no-op；
配套需处理导出配置的 `find_dependency(Qt6PrintSupport)` 与裸目标名，以及任务卡
元数据世代甄别。

## 错误特征（error_signature）

```
CMake Error at CMakeLists.txt:XX (find_package):
  Could NOT find Qt6PrintSupport (missing: Qt6PrintSupport_DIR)
    —— 上游顶层 find_package(Qt6 ... PrintSupport) REQUIRED，configure 第一步即失败

CMake Error ... find_dependency(Qt6PrintSupport @QT_REQUIRED_VERSION@)
    —— 库本体裁剪成功后，消费端 find_package(KGantt6) 仍炸在导出配置

Target "KChart6" links to: ... but the target was not found
    —— 消费端误用带命名空间目标名（上游 install(EXPORT) 无 NAMESPACE）
```

## 根因（root_cause）——三层

1. **平台层**：OHOS 无打印栈，已发布 qtbase/6.11.1 线 PrintSupport=OFF（4 个本地
   变体的 cmake/ 目录均无 Qt6PrintSupport Config、无 libQt6PrintSupport.so、无
   QPrinter 头文件；kgraphviewer 26.04.0 先例确认），而 KDE 上游模块普遍
   `find_package(Qt6 ... PrintSupport)` REQUIRED。
2. **库源码层**：KGantt 自带 HAVE_PRINTER 宏守卫
   （src/KGantt/kganttgraphicsscene.cpp:36-44：`#ifndef QT_NO_PRINTER` →
   `#define HAVE_PRINTER`），所有打印入口已按守卫分流——上游为无打印环境预留的
   原生降级路径。顶层 `add_definitions(-DQT_NO_PRINTER)` 一行即整体启用，API
   签名完整保留（源码级兼容）。对照重路径：kgraphviewer 26.04.0 无守卫，被迫
   手写 13 对源文件 no-op patch。
3. **导出层 + 元数据层**：`KGantt6Config.cmake.in` 携带
   `find_dependency(Qt6PrintSupport)`，库本体裁掉后消费端 find_package 仍失败；
   上游 `install(EXPORT)` 无 NAMESPACE，导出裸目标名 `KChart6`/`KGantt6`（非
   `KChart6::KChart6`）；另任务卡元数据可能写错世代——kdiagram 3.0.1 任务卡列
   Qt5 依赖（qt5-qtbase/kcoreaddons5/ki18n5），源码实证为 Qt6/KF6 世代
   （QT_REQUIRED_VERSION "6.5.0"、KF_MIN_VERSION "5.245.0"、ECM-only、全树零
   KF6 框架链接）。

## 修复方案（solution）

① 一行宏定义启用原生降级（patch 顶层）：

```diff
-find_package(Qt6 ${QT_REQUIRED_VERSION} CONFIG REQUIRED COMPONENTS Core Gui Widgets Svg PrintSupport)
+find_package(Qt6 ${QT_REQUIRED_VERSION} CONFIG REQUIRED COMPONENTS Core Gui Widgets Svg)
+add_definitions(-DQT_NO_PRINTER)
```

前置侦察——判断本库走原生降级还是手写 no-op：

```bash
grep -rn 'QT_NO_PRINTER\|HAVE_PRINTER' src/ | head
# 有守卫 → 原生降级（本条路径）；无守卫 → 手写 no-op（kgraphviewer 先例）
```

② 导出配置去依赖（防消费端炸）：

```diff
 # src/KGantt/KGantt6Config.cmake.in
 find_dependency(Qt6Core @QT_REQUIRED_VERSION@)
 find_dependency(Qt6Widgets @QT_REQUIRED_VERSION@)
-find_dependency(Qt6PrintSupport @QT_REQUIRED_VERSION@)
```

③ 消费端按裸目标名链接：

```cmake
find_package(KChart6 REQUIRED)    # 裸目标名，非 KChart6::KChart6
find_package(KGantt6 REQUIRED)
target_link_libraries(consumer KChart6 KGantt6)
```

④ 世代甄别（源码实证优先于任务卡元数据）：

```bash
grep -E 'QT_REQUIRED_VERSION|KF[56]_MIN_VERSION' CMakeLists.txt
grep -rh 'find_package(' --include=CMakeLists.txt | sort -u
# kdiagram 3.0.1 → QT_REQUIRED_VERSION "6.5.0" → Qt6 栈：
#   qtbase/6.11.1 + qtsvg/6.11.1 + ecm/6.26.0(tool_requires)，勿引 kcoreaddons/ki18n
```

## 降级方案（fallback）

上游无守卫的库：手写 no-op 函数体 patch（kgraphviewer 26.04.0 先例，13 对源
文件，保持 API 签名不变）；导出配置不可改时由消费者侧自写前置 Config 屏蔽
find_dependency；世代存疑且源码无明确版本宏时按 find_package 实际解析回退，
并报平台主 agent 裁决换栈（本件先例：任务卡 Qt5 清单 → 源码实证 Qt6 → 换栈后
23/23 全绿）。

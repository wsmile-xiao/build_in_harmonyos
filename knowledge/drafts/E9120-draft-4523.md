# E9120 — 旧 C 源码的冗余 `sys/unistd.h` 引用

## 触发与根因

pwnat 0.3.0 在 OHOS aarch64 编译时报 `fatal error: 'sys/unistd.h' file not found`。该头路径不是可移植 POSIX 接口；本版 `packet.h` 后文已有标准的 `<unistd.h>`。因此本例是冗余引用，不是缺少系统调用实现。

## 可复用处理

先检查源码实际使用的声明是否由 `<unistd.h>` 提供，并核对两处 include 在指定文件各只出现一次。仅修改 Conan 的临时构建副本，移除非标准引用；若上游布局改变或需要私有声明，则停止自动修复，逐一移植 API。不要在 sysroot 中制造空壳 `sys/unistd.h`。

## 验证与边界

任务 `pwnat/0.3.0` 的初次真机事务 `pwnat-w3-20261006T080641Z` 在该头报错；后继事务 `pwnat-w3-20261006T082327Z` 编译、签名及消费者 `pwnat -h` 测试通过，完整 12/12 收据。上游注册测试为 0，消费者断言 1/1。本验证不证明原始 ICMP 套接字或 NAT 穿透功能。

现有知识中未找到 `sys/unistd.h` 精确问题；本条不是通用“忽略缺头文件”建议。

# 上游站已死的 2004 时代包取源改道 Debian/Ubuntu pool：四源法 + 双 .dsc 佐证 + PF7 classify=None

## 错误特征

```
search_url.*(404|could not resolve)|PF7.*(Debian 下游重打包源|明文 http 源)|vanished upstream
```

上游项目主页下线（例如 OPT 的 `http://nis-www.lanl.gov/~jt/Software/opt/`，
Debian copyright 原文 "vanished upstream as of 2011-04-28"），`search_url` 找不到可用
URL，或随手抓的 URL 被 **PF7 源 URL 闸**拦下。本包实测的 PF7 双坑：

- `http://deb.debian.org/...` → `明文 http 源（R39 要求 https）`
- `https://deb.debian.org/...` → `Debian 下游重打包源`（deb.debian.org/snapshot/security/archive 在黑名单）

即 **deb.debian.org 无论 http 还是 https 都进不了 conandata**，必须换 host；
而 Debian/Ubuntu pool 的**同名文件**往往就是唯一权威副本。

## 解决方案

**主方案**: four-source-same-sha-plus-dual-dsc-plus-pf7-none

配方/取数口径（OPT 3.19 落地形态）：

1. **四源法**：`ftp.debian.org`（Debian pool 主张）、`archive.ubuntu.com`
   （universe 同名文件）+ 两个**名单外镜像**（mirrors.ustc.edu.cn /
   mirrors.tuna.tsinghua.edu.cn）——4 条 URL 全部下载比 sha256，
   `sort -u` 计数必须 = 1（distinct=1），证据写进 notes。
2. **curl + urllib 双栈**：两条栈各取一次并记录 `Content-Encoding`（为 None 即无
   gzip 透明解码失配，先例 #3 同族排查），避免 conandata sha 与实际下载不符。
3. **双 .dsc 佐证**：抓 Debian 与 Ubuntu 的 `.dsc`，比对 `Checksums-Sha256`
   段里 orig tar 的哈希与 size（两份应完全一致）——**离线可复核**的权威证据。
4. **PF 模拟 classify=None 才定 URL**：`from ohc.preflight import _pf7_classify`
   逐条打印，四条全 None 才写进 conandata，同时把被拦的两条留作反证。
5. 版本内证同步取（`configure.in` 的 AM_INIT_AUTOMAKE、`version.texi`、`NEWS`）。

## 验证

```sh
# 四源同 sha（distinct 必须为 1）
sh -c 'for u in https://ftp.debian.org/debian/pool/main/o/opt/opt_3.19.orig.tar.gz \
  https://archive.ubuntu.com/ubuntu/pool/universe/o/opt/opt_3.19.orig.tar.gz \
  https://mirrors.ustc.edu.cn/debian/pool/main/o/opt/opt_3.19.orig.tar.gz \
  https://mirrors.tuna.tsinghua.edu.cn/ubuntu/pool/universe/o/opt/opt_3.19.orig.tar.gz; do \
  curl -sS -m 60 "$u" | sha256sum; done | sort -u'      # 预期：1 行 9feb44c0…5acc
# PF7 模拟（预期 None）
python3 -c 'import sys; sys.path.insert(0, "/storage/Users/currentUser/ws/build_in_harmonyos/scripts");
from ohc.preflight import _pf7_classify;
print(_pf7_classify("https://ftp.debian.org/debian/pool/main/o/opt/opt_3.19.orig.tar.gz"))'
```

## 错误特征

```
combi-test: command not found          # CI test_package 从 PATH 找不到 auxiliary 程序
divvy-test: command not found          # （10 个 auxiliary 全部 command not found）
fuzzpuzz-setup 无法生成存档            # fuzzpuzz 也不在 bin/
puzzles/20260720.3c36322: package(): Packaged 41 files   # 本机 create 只有 41 文件（缺 15 个辅助程序）
```

症状：`conan create` 成功（无任何报错），包内 `bin/` 只有官方程序（puzzles 为 40 个），
CI test_package 阶段所有 auxiliary 测试程序 `command not found`，L1 门禁 FAIL。

## 根因分析

conan 2 的 `cmake_layout(self)` 单配置构建把 CMake 输出放在 **build 根下的
`build/Release`**，并且生成器把 `self.build_folder` 属性指向 **该 CMake 输出目录本身**
（形如 `~/.conan2/p/b/puzzlXXX/b/build/Release`），而不是 build 根。因此：

1. `os.path.join(self.build_folder, "Release")` 与 `.../build/Release` 都不存在；
2. `conan copy()` 对不存在的 src **静默跳过**（无告警、不报错），包内缺文件但
   `conan create` 仍然成功——缺陷延迟到 CI test_package 才暴露；
3. 上游 CMake 通常不 install auxiliary/cliprogram 类测试程序（cliprogram 宏无
   install 规则），必须由 recipe 的 `package()` 显式搬运。

## 解决方案

**主方案**: shutil-copy2-absolute-src-in-package

```python
def package(self):
    cmake = CMake(self)
    cmake.install()
    # cmake_layout 下 self.build_folder 即 CMake 输出目录（.../b/build/Release）
    aux_src = os.path.join(self.build_folder, "auxiliary")
    for tool in ("combi-test", "divvy-test", "findloop-test", ...):
        src = os.path.join(aux_src, tool)
        if os.path.isfile(src):
            shutil.copy2(src, os.path.join(self.package_folder, "bin"))
    fuzzpuzz_src = os.path.join(self.build_folder, "fuzzpuzz")  # 顶层目标
    if os.path.isfile(fuzzpuzz_src):
        shutil.copy2(fuzzpuzz_src, os.path.join(self.package_folder, "bin"))
```

要点：

- 不要猜 `build_folder/Release` 或 `build_folder/build/Release`——先打印
  `self.build_folder` 实测确认（本机打印即 `.../b/build/Release`）；
- 每个复制前 `os.path.isfile` 检查，缺哪个明确失败而非静默；
- `shutil.copy2` 用绝对 src，不依赖 conan copy() 的 glob/目录语义。

## 回退方案

glob-recursive-locate-artifact（E340 同款）：`glob.glob(os.path.join(root, "**",
"auxiliary", tool), recursive=True)` 在 build/source_folder 下递归定位。适用
basic_layout/cargo 等路径不确定场景；cmake_layout 单配置路径可确定时优先直接路径。

## 禁止做法

| 做法 | 原因 | 后果 |
|---|---|---|
| `copy(self, tool, src=os.path.join(self.build_folder, "Release"))` | 路径不存在（CMake 输出在 self.build_folder 本身） | copy() 静默跳过 → 包缺 auxiliary → CI L1 FAIL |
| `copy(self, tool, src=os.path.join(self.build_folder, "build", "Release"))` | 多套一层 build 也不存在 | 同上 |
| 依赖 conan copy() 的目录 src 语义 | 多级 build 布局下易错位且缺失不报错 | "Packaged N files" 但 bin/ 缺文件，本机通过 CI 失败 |

# E6411 - Re-sign installed OHOS ELF after Meson install

The DOSBox r52 target transaction completed all 24 upstream Meson entries
(23 `OK` and one `EXPECTEDFAIL`) and created the package, but its installed
`bin/dosbox` consumer returned RC126 with target stderr `Operation not
permitted` despite a regular `0755` file. The package path was signed before
the final install copy, and the helper trusted an existing `.codesign` section.

The successor calls the helper with `force=True` after `Meson.install()`. That
path removes the old section, signs the post-install bytes through a sibling
temporary, verifies exactly one new `.codesign`, applies the `0755` mask, and
atomically replaces the installed file. Build/test ELF callers retain the
existing fast path. A local mocked signer regression passed, and target r67
completed the same-snapshot upstream suite 24/24 plus the installed-package
flow 1/1 from HEAD `226472fc71c00d0d73a2a5604665fce3fda8e02b`.

# E543: R47 语言预检判定与 lang_hold 终态上报（JS/webextension 等非 C/C++ 包模板）

## Symptom

一个默认按 cpp 语言派发的适配任务，在 checkout 后的语言预检阶段即被拦截：
`lang-preflight` 以退出码 2 结束，判定 `detected_language` 与任务默认语言
`expected=cpp` 不匹配（实测为 `mixed`），随后任务以 `env_unsupported` 终态
上报，平台转入 `lang_hold` 挂起等待生态，而非失败。日志特征与
error_signature 正则一致：

```
语言不匹配: task=cpp, detected=mixed ... env_unsupported
detected_language.*(javascript|mixed|go|rust|python)
```

这类包往往没有 C/C++ 编译需求，却因为「只有顶层 Makefile、没有更强
manifest」被检测器推入 c/cpp 族，属于典型的检测面误判路径。

## Trigger conditions

- 构建系统: make（仅 zip 打包，无 configure/configure.ac、无 CMakeLists.txt）
- 阶段: configuration（R47 语言预检，checkout 后第一步）
- 任务默认语言: cpp（派发器按默认语言分配）
- 源码构成: JS/webextension/Go/Rust/Python 等，零 C/C++ 文件
- manifest: manifest_version=webextension，或仅顶层 Makefile 无更强 manifest

## Root cause

任务默认语言 cpp 与源码实际语言不匹配。检测器按 manifest 规则推断：
当源码树没有 CMakeLists.txt / configure.ac，只有顶层 Makefile 且其仅为
zip 打包目标时，manifest 证据被推为 c/cpp 族（build_system=make）；
而源码统计显示主体语言完全为 nodejs/JS。边界规则规定「manifest 与
统计矛盾判 mixed」——mixed 不等于 cpp，预检因此以退出码 2 立即终态。

R47 冻结协议：checkout 后必须先跑 lang-preflight；不匹配时立即终态
`env_unsupported`，平台转 `lang_hold` 挂起等生态（非失败），禁止硬着
头皮做 C/C++ conan 适配。

## Fix

推荐方案：lang_hold 终态上报（必须与 dependency_missing 严格区分）。

1. 语言不匹配时：`result --status env_unsupported`，必带
   `--detected-language`（协议枚举值，禁止自由文本）+ 三项证据参数
   `--ev-build-system` / `--ev-manifest` / `--ev-source-stats`
   （每项 ≤200 字符）。
2. dependency_missing 是缺依赖、可换源解决；语言不匹配换网络/换机器
   无用，属平台生态挂起，二者不得混报。
3. 终态同时可产出 upstream-test-inventory + 补充 JS 单测作为生态数据
   （见 E544）。

result 命令参数模板（实测命令，debianbuttons 2.3）：

```bash
python3 /storage/Users/currentUser/pr8610-work/scripts/ohc-run.py result \
  debianbuttons 2.3 --status env_unsupported \
  --detected-language mixed \
  --ev-build-system 'make (仅 zip 打包)' \
  --ev-manifest '顶层 Makefile (无更强 manifest)' \
  --ev-source-stats 'nodejs:2, 主体占比 100%' \
  --failed-reason '非 C/C++ 语言，R47 转 lang_hold' \
  --out /storage/Users/currentUser/ohpcd-ai-worker-result.json
```

## Evidence and validation

debianbuttons 2.3（icedeb webextension）实测记录（summary.md 第 1 节）：

- 命令: `python3 scripts/ohc-run.py lang-preflight debianbuttons 2.3
  --src /storage/Users/currentUser/tmp/icedeb-2.3-6afb2a1`
- 退出码: 2（语言不匹配），符合预期（JS/other ≠ cpp）
- 判定结果:
  - expected = cpp（任务默认语言）
  - detected_language = mixed
  - language_evidence:
    - build_system = make
    - manifest = 顶层 Makefile（无更强 manifest）
    - source_stats = 源文件 2 个（nodejs:2），主体占比 100%
  - notes = 冲突: manifest=c 但统计 nodejs 占 100% → mixed
- 终态: status=env_unsupported（R47 终态，平台转 lang_hold 挂起，非失败）
- 落盘: /storage/Users/currentUser/ohpcd-ai-worker-result.json
  （R46 兜底路径，draft=false）

说明：源码无 CMakeLists.txt/configure.ac，只有顶层 Makefile（仅 zip 打
包 .xpi），检测器按 manifest 规则推为 c/cpp 族；而源码统计 100% 为
nodejs（icedeb.js + icedeb-content.js），按边界规则判 mixed。
mixed ≠ cpp → exit 2 → 立即终态 env_unsupported，全程未硬做 conan 适配。

检测语言与三项证据均已由工具写入终态（detected_language 枚举 + 三项
≤200 字符 evidence），无协议违规；graph validate 全部通过。

## Applicability and safety boundaries

适用于被按默认 cpp 语言派发、但实际为非 C/C++ 语言（JS/webextension/
Go/Rust/Python 等）的三方包适配任务。lang_hold 挂起与 dependency_missing
必须区分：前者换网络/换机器无用，属生态挂起；后者可换源解决。禁止把
lang_hold 记为失败、禁止修改共享包缓存、禁止在语言不匹配时硬做 C/C++
conan 适配。若预检证据无法成立（detected_language 缺失或三项 evidence
不全），fail closed 重新预检后再上报终态。

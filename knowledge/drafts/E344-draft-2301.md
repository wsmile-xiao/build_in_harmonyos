# E344 — 老版 config.sub 的 `-linux* -> linux-gnu` 改写：ohos 补丁需在 `-linux*)` 前插入 `-linux-ohos*)`

## 错误特征

OHOS 交叉编译 autotools 库时，configure 对 `--build`/`--host` 三元组调用
config.sub 做 canonical 化。libXres 1.2.1 自带的 config.sub 是 2018-02-22 版，
对 `aarch64-unknown-linux-ohos` 报
`machine 'aarch64-unknown-linux' not recognized`，对 `aarch64-linux-ohos` 报
`system 'ohos' not recognized`。

## 触发条件

- 构建系统: Autotools，且 release tarball 内置**老版** config.sub/config.guess
  （libXres 1.2.1：config.sub 2018-02-22、config.guess 2018-02-24）。
- 需要 OHOS 交叉三元组：`--build=aarch64-unknown-linux-ohos`、
  `--host=aarch64-linux-ohos`（build ≠ host 进入 cross 模式，works-check 只链接
  不运行，避开原生模式运行 conftest 被沙箱拦截的陷阱）。

## 根因分析

- autoconf 用 config.sub 把 `--build`/`--host` 三元组 canonical 化。
- 2018 版 config.sub 的 OS 处理末尾仍有
  `-linux*)  os=`echo $os | sed -e 's|linux|linux-gnu|'`` 改写：把任何
  `-linux*` OS 统一改成 `-linux-gnu`。因此只把 `linux-ohos*` 加进 KERNEL-OS
  列表、把 `-linux-ohos*` 加进 OS 校验列表还不够——os 最终仍会被改写为
  `-linux-gnu-ohos`。
- 2021+ 版 config.sub 已移除该改写（libxdamage/libxpm 的 config.sub 为 2021/2023），
  所以它们的补丁只有两个 hunk（KERNEL-OS 列表 + OS 校验/OS 名单）。

## 解决方案

### 推荐方案：按 config.sub 版本决定 hunk 数

先判定版本与改写是否存在：`grep -n '\-linux\*)' config.sub`。

2018- 老版需要**三个 hunk**：

1. KERNEL-OS 列表（`case $maybe_os in`）加 `linux-ohos*`
   （使 `aarch64-unknown-linux-ohos` 正确切分为 machine=aarch64-unknown、
   os=-linux-ohos）。
2. OS 校验列表加 `-linux-ohos*`。
3. 在 `-linux-dietlibc)` 之后、`-linux*)` 之前插入空 case：
   ```
   -linux-ohos*)
       ;;
   ```
   保住 os=-linux-ohos，不被 sed 改写为 linux-gnu。

config.guess：在
`case "$UNAME_MACHINE:$UNAME_SYSTEM:$UNAME_RELEASE:$UNAME_VERSION" in`（2018
带引号）或 `case $UNAME_MACHINE:$UNAME_SYSTEM:$UNAME_RELEASE:$UNAME_VERSION in`
（2021+）前插入：
```
*:HarmonyOS:*:*)
    case $UNAME_MACHINE in
        aarch64|arm64) echo aarch64-unknown-linux-ohos; exit ;;
        *) echo "$0: unsupported HarmonyOS machine $UNAME_MACHINE" >&2; exit 1 ;;
    esac
    ;;
```

补丁必须用 unified diff（`--- a/...` / `+++ b/...` 头），conandata 用 list
格式（L0f 门禁要求 patch_file/patch_description/patch_type）。

验证：
```
./config.sub aarch64-unknown-linux-ohos   # -> aarch64-unknown-linux-ohos
./config.sub aarch64-linux-ohos           # -> aarch64-unknown-linux-ohos
./config.sub aarch64-linux-gnu            # -> aarch64-unknown-linux-gnu（回归不变）
```

### 分类判定表

| config.sub 版本 | 改写 `-linux*→linux-gnu` | 需要的 hunk 数 |
|---|---|---|
| 2018-（libXres 1.2.1）| 有 | 3（KERNEL-OS 列表 / OS 校验 / 空 case）|
| 2021+（libxdamage/libxpm）| 无 | 2（KERNEL-OS 列表 / OS 校验或名单）|

## 禁止策略

- 老版 config.sub 不插入 `-linux-ohos*)` 空 case → os 被改写为 linux-gnu-ohos。
- conandata 不用 dict-by-version 格式（L0f 判 wrong，实测 libxdamage/libxkbfile 因此失败）。
- 不因为 build==host 而让 works-check 运行 conftest（原生模式被沙箱拦截）。

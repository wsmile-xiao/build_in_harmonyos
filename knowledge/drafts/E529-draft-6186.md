# E529: OHOS memfd denies fstat; fall back to known size for mmap bounds check

## 基本信息
- **严重度**: 2
- **类别**: compat, memfd, syscall, fstat, ohos
- **来源**: pipewire 1.4.9 HarmonyOS PC 适配

## 错误特征
```
mempool_issue4884: FAILED COMPARISON: m1 != NULL
fstat(b->this.fd, &sb)  -> EACCES (Permission denied) on OHOS memfd
```

## 触发条件
- 构建系统: meson (pipewire data-loop / mempool)
- 阶段: testing (test-pw-utils mempool_issue4884)

## 根因分析
OHOS memfd 在内核/实现层面对 `fstat()` 返回 EACCES（即使 `mmap()` 本身成功）。
`pw_memblock_map()` 以 `fstat()` 做映射边界校验（offset+size <= st_size），fstat 失败
直接返回 NULL，导致 memfd 映射功能被破坏。

## 解决方案

### 推荐方案
```c
if (fstat(b->this.fd, &sb) != 0) {
    /* OHOS memfd denies fstat(); fall back to known block size. */
    memset(&sb, 0, sizeof(sb));
    sb.st_size = b->this.size;
}
```
用分配时已知的 block size 做边界校验，不放弃 mmap。

### 禁止做法
- ❌ 直接 `return NULL` 于 fstat 失败（破坏 memfd 映射语义）
- ❌ 用 `__OHOS__` 平台宏硬编码（应使用运行时行为回退）


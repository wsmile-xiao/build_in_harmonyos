# E545-draft-3028 — 脚本产物硬编码 `${TMPDIR:-/tmp}`：鸿蒙只读 `/tmp` 下运行期全功能不可用

> 状态：草稿（contributor 3028）｜ 触发事件：clitest 0.5.0 适配
> 关联：E002（构建期 `/tmp` 只读）——本条是其**运行期 / 产物侧**镜像面

## 现象

安装后的脚本工具在鸿蒙设备上，用户未设置 `$TMPDIR` 时一执行就退出：

```
clitest: Error: cannot create temporary dir: /tmp/clitest.0.97017.2257289
mkdir: cannot create directory '/tmp/clitest.0.97017.2257289': Read-only file system
```

关键特征：**构建期一切正常**。`conan create` 通过、产物结构检查通过、
`--version`/`--help` 之类的 smoke test 也通过（它们不创建临时目录），缺陷只在
真实使用路径上暴露。

## 根因

E002 说的是构建期：configure/make 往 `/tmp` 写东西，鸿蒙 `/tmp` 是只读挂载，
对策是给构建过程设 `TMPDIR`。

当**交付产物本身**是脚本时，情况变成镜像面：

```sh
tt_temp_dir=$(mktemp -d "${TMPDIR:-/tmp}/clitest.XXXXXX" 2> /dev/null) && return 0
tt_temp_dir="${TMPDIR:-/tmp}/clitest.$(awk 'BEGIN { srand(); print rand() }').$$" &&
    mkdir -m 700 "$tt_temp_dir" || tt_error "cannot create temporary dir: $tt_temp_dir"
```

`/tmp` 被写死成默认基路径。构建期设的 `TMPDIR` 不会随产物进设备；用户在设备上
运行时，`mktemp -d` 与手工 `mkdir` 双双撞上只读挂载，脚本在干活之前就退出。

## 修法（推荐）

只替换「`$TMPDIR` 未设置」这一个分支的默认值：

```sh
if test -n "${TMPDIR:-}"; then
    tmp_base="$TMPDIR"           # 显式设置：原样透传，不做任何兜底
elif test -d /tmp && test -w /tmp; then
    tmp_base='/tmp'              # 可写的 /tmp：与上游行为完全一致
else
    tmp_base="${HOME:-.}"        # 只读 /tmp（鸿蒙）：回退 $HOME
fi
```

随后把脚本内所有 `${TMPDIR:-/tmp}` 引用改成 `$tmp_base`。

这个写法有三个好处：

1. 平台中立——补丁里没有任何平台宏或鸿蒙路径，在 Linux 上行为与上游逐字节一致；
2. 可上游化——是通用健壮性改进，不是下游私货；
3. **不动上游语义**——显式设置的 `$TMPDIR` 依旧原样使用。

## 关键陷阱：不要把「显式无效 TMPDIR」也一起回退

初版补丁写成了「基路径不可写就回退 `$HOME`」，看似更健壮，实测直接打挂上游用例：

```
[FAILED #15, line 52] ./clitest test/ok-1.sh 2>&1 | grep ^clitest | sed 's/clitest\..*$/clitest.XXXXXX/'
@@ -1 +0,0 @@
-clitest: Error: cannot create temporary dir: /notfound/clitest.XXXXXX
```

上游 `test.md:52` 专门断言 `TMPDIR=/notfound` 必须**大声失败**。把用户的显式配置
错误静默吞掉，是改契约，不是健壮性。正确反应是收窄补丁范围，而不是去改上游用例
——后者在 PR 评审里属于高风险改动，且会掩盖自己引入的回归。

收窄后：上游 286 用例 286/286 通过（bash / dash / zsh / busybox sh 均如此）。

## 验证

```bash
# ① 静态定位
grep -n '${TMPDIR:-/tmp}' <script>

# ② 复现 / 验证修复（构造只读 /tmp，不需要真机）
unshare -rm sh -c 'mount -t tmpfs -o ro,size=1m tmpfs /tmp; unset TMPDIR; <script> <args>'
#   未修复 → cannot create temporary dir: /tmp/...    非零退出
#   已修复 → 正常执行

# ③ 语义回归（必须仍然失败）
TMPDIR=/notfound <script> <args>
```

clitest 0.5.0 实测对照：

| 版本 | 只读 `/tmp` + 未设 `$TMPDIR` |
|---|---|
| 未打补丁 | `cannot create temporary dir` → 非零退出 |
| 打补丁 | `OK: 1 of 1 test passed` |

## 禁止

- **禁止**把显式设置的无效 `$TMPDIR` 一并回退（改上游语义 + 打挂上游用例）。
- **禁止**只在构建期 `export TMPDIR` 就认为问题已解决——那不会随产物进设备。

## 适用范围

所有以脚本为交付产物的包（测试器、包装器、审计工具、辅助脚本等），只要脚本里
写死了 `${TMPDIR:-/tmp}`；Perl/Python 脚本把 tempfile 目录写死为 `/tmp` 是同构问题。

`prescan_pattern` 已随本条目登记，预扫描会在源码阶段直接命中该写法。

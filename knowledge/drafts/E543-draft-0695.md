# E543 — OHOS libc++ 裁剪版缺 std::pmr 与 C++20 ranges

## 错误特征
```
../source/heapstring.h:13:10: fatal error: 'memory_resource' file not found
../source/layout/flexiblebox.cpp:316:43: error: no member named 'views' in namespace 'std'
ld.lld: error: undefined symbol: std::experimental::fundamentals_v1::pmr::get_default_resource()
```

## 触发条件
- 构建系统: meson（Conan 交叉构建 OHOS aarch64；其他构建系统同理）
- 阶段: compilation / linking
- 前提: 源码 `#include <memory_resource>`，或使用 `std::pmr::*` / `std::views::*`

## 根因分析
OHOS SDK 自带 libc++ 为**裁剪版**（实测 SDK CLT 26.0.0.821 / API 26）：
- 无顶层 `<memory_resource>`；`std::pmr` 容器别名在 `<vector>/<map>/<forward_list>/<string>` 中也不存在（grep 'pmr' 计数 0）
- `<experimental/memory_resource>` 只有抽象基类 `memory_resource` + `polymorphic_allocator`，具体资源（`monotonic_buffer_resource`/pool）未实现
- `libc++_shared.so` 无任何 pmr 符号；`get_default_resource()`/`new_delete_resource()` 仅在 `libc++experimental.a`
- `__config:255-256`：未定义 `_LIBCPP_ENABLE_EXPERIMENTAL` 时定义 `_LIBCPP_HAS_NO_INCOMPLETE_RANGES` → C++20 ranges 整体不生效
- 华为官方 FAQ 亦确认 HarmonyOS NDK 不支持 `#include <memory_resource>` 与 `std::pmr::vector`

## 解决方案

### 推荐方案
1. 用 `__has_include(<memory_resource>)` 做**特性探测**（不引入平台宏，非 OHOS 平台自动走原生 pmr）：
   ```cpp
   #include <string_view>
   #if __has_include(<memory_resource>)
   #include <memory_resource>
   #else
   #include "ohos_pmr_compat.h"
   #endif
   ```
2. 兼容头 `ohos_pmr_compat.h`：`namespace std { namespace pmr = experimental::pmr; }` +
   按标准语义实现 `monotonic_buffer_resource`（只增不减，析构/release 统一归还）
3. 配方补 `-lc++experimental`（pmr 容器默认构造引用 `get_default_resource()`，符号在 `libc++experimental.a`）
4. 配方补 `-D_LIBCPP_ENABLE_EXPERIMENTAL` 打开 C++20 ranges
（实证：plutobook 0.19.0，65/65 源文件编译通过、链接通过、打包成功）

### 禁止做法
- ❌ 只写 `namespace std { namespace pmr = experimental::pmr; }` 别名——OHOS 无 `monotonic_buffer_resource` 实现，且缺 `get_default_resource()` 链接符号
- ❌ 在补丁里用 `__OHOS__` 平台宏（R8：补丁应走特性探测/条件检查）
- ❌ 直接引用包内自带的 `.pc`/头文件路径绕过

## 验证
```bash
# 缺头复现
printf '#include <memory_resource>\nint main(){return 0;}' > /tmp/t.cc
$SDK/native/llvm/bin/aarch64-unknown-linux-ohos-clang++ -std=c++20 /tmp/t.cc -o /tmp/t
# 预期: fatal error: 'memory_resource' file not found

# ranges 复现
printf '#include <ranges>\nint main(){return 0;}' > /tmp/r.cc
$SDK/native/llvm/bin/aarch64-unknown-linux-ohos-clang++ -std=c++20 /tmp/r.cc -o /tmp/r
# 预期: no member named 'views' in namespace 'std'

# 修复后复验
conan create . -pr:h=ohos-aarch64-wsl -pr:b=default -r=ohpcd --build=missing   # 期望 rc=0
```

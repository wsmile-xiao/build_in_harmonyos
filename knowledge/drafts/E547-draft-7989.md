# E547 — automake all-local/clean-local 相对 cd 在 out-of-tree 构建失败

## 错误特征
```
cd libtap: No such file or directory
make[2]: *** [Makefile:1104: all-local] Error 1
make[1]: *** [Makefile:583: all-recursive] Error 1
make: *** [Makefile:383: all] Error 2
```

## 触发条件
- 构建系统: autotools（automake）
- 阶段: make all（conan create G2 / W3 本地 CI）

## 根因分析
上游 `t/Makefile.am` 的 all-local/clean-local 写死 `cd libtap && $(MAKE)` 相对路径，
用于内嵌独立子目录（如测试框架 t/libtap）。in-tree 构建可用；但 conan basic_layout
把构建放到独立 `build-release` 目录（out-of-tree），该目录下没有 `libtap` 子目录，
`cd libtap` 失败导致整树 make 中止。

## 推荐方案
将 all-local/clean-local 的 `cd libtap` 改为 `cd $(top_srcdir)/t/libtap`，使构建目录
不再需要镜像源码子目录。属 VPATH 友好的最小补丁，无平台宏。

## 验证
修复后 `make -j1` 通过，`conan create` 通过 G2 门禁。

## 适用边界
一切 automake all-local/clean-local 内嵌相对子目录 cd 且采用 out-of-tree 构建的项目。
in-tree 构建不触发，故上游 CI 常无法发现，适配端需主动修复。

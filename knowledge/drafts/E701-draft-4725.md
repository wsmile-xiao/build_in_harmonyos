# E701 — 平台无 raw socket/真实网卡 → 用上游官方 SKIP_* 环境变量机制跳过平台阻塞测试

## 错误特征

```
error/network ETH | Could not find the interface
error/pubsub | Could not open an ETH recv channel
error/pubsub | Could not create the PubSubConnection. The connection parameters did not validate.
```

`check_pubsub_connection_ethernet` 每次尝试打开 AF_PACKET raw ETH socket 均失败，
套件整体 Failed（非 SEGFAULT、非断言失败）。

## 触发条件

- 构建系统: CMake（conan create 内嵌 ctest）
- 阶段: testing
- 前提: 测试套件需要真实以太网接口 + raw socket 能力（/sys/class/net 不可
  访问、无 `ip` 工具、无 CAP_NET_RAW 的 OHOS/CI worker）

## 根因分析

ETH PubSub 连接需要在真实 NIC 上打开 AF_PACKET raw socket；OHOS worker 无
以太网接口且无 raw-socket 能力，任何 ETH recv 通道必然失败。该用例是上游
真实测试，但平台不提供运行前提。open62541 上游在 `tests/pubsub/ethernet_config.h`
自带官方跳过机制：`#define SKIP_ETHERNET getenv("SKIP_ETHERNET")`，`main()`
检测到该环境变量即返回 EXIT_SUCCESS（不注册任何用例、不伪造通过）。

## 解决方案

### 推荐方案
- 方案: conanfile.py `generate()` 中设 `env.define("SKIP_ETHERNET", "1")`，
  复用上游官方跳过机制；台账把该用例如实记录为 not-run/platform-blocked，
  附恢复条件（有网卡/raw socket 权限的环境可取消该变量并真实执行）
- 验证: `conan create` exit_code=0，146/146（ethernet 套件经官方机制
  EXIT_SUCCESS）；`reports/conan-create-r11.log`、`test-ledger.md`

### 禁止策略
- 禁止把平台阻塞写成通过或失败
- 禁止手写跳过逻辑替代上游自带机制；上游未提供跳过机制时须走
  feature-gate（参考 E334）并在 PR 说明

## 适用范围与边界

- 适用: 上游自带 env 跳过机制的平台阻塞测试（raw socket / 真实外设类）
- 边界: 仅为「平台缺硬件/权限」的确定性阻塞；可运行但失败的用例不得跳过

# E430 — conan conf 嵌套子键 compiler_executables:c 直接 get 报错

## 错误特征
```
ConanException: [conf] 'tools.build:compiler_executables:c' does not exist
```
profile 中明确配置了 `tools.build:compiler_executables={'c': ..., 'cpp': ...}`，
但配方中 `self.conf.get("tools.build:compiler_executables:c")` 抛异常。

## 触发条件
- 阶段: configuration（conanfile build() 取编译器路径）
- Conan 2.x，profile 的 `[conf]` 中 `tools.build:compiler_executables` 为 dict 值

## 根因分析
`tools.build:compiler_executables` 在 profile 中是**一个整体 dict 值**，
Conan conf 的点号寻址只解析 conf 键名本身（顶层键），不支持对 dict **内部**的子键寻址。
`conf.get("...:c")` 会去找一个名为 `tools.build:compiler_executables:c` 的顶层 conf 键，
不存在即抛 `does not exist in configuration list`。

## 解决方案

### 推荐方案
先整体取出 dict，再用 Python 的 `.get()` 取子键：

```python
comp_execs = self.conf.get("tools.build:compiler_executables", default={}, check_type=dict)
cc = comp_execs.get("c") or "clang"
```

### 禁止做法
- ❌ `self.conf.get("tools.build:compiler_executables:c")` —— 嵌套子键不可点号寻址

## 实例
sluice/0.03.01（OHOS aarch64, Conan 2.29）：脚手架模板生成写法触发此错误，
改为整体 get dict 后 conan-verify G2 进入编译并通过（来源：sluice-0.03.01，2026-09-21）

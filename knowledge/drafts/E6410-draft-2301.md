# E6410 - OHOS ELF owner execute bit

The DOSBox r50 device run built the package and emitted all 24 upstream test
records, then the installed test_package binary failed with `Error 126`.
The signing helper used `mode | 0o055`; for a 0644 input this produces 0655,
which lacks the owner execute bit. The candidate fix changes both signing
paths to `mode | 0o755`.

The local negative/positive mode checks pass. Target r67 then completed
upstream 24/24 and the installed consumer flow 1/1 from candidate HEAD
`226472fc71c00d0d73a2a5604665fce3fda8e02b`; its release and two clean scans
also passed.

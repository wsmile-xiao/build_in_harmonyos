# E6440 草稿：上游 `make test` 运行时 curl|bash 拉取浮动引用的测试框架（shunt）

## 错误特征
shml 1.1.0 的 `make test` 依赖 `test/shunt.sh`，而它由 Makefile 在运行时下载：

```
test/shunt.sh:
	cd test && curl -L https://raw.githubusercontent.com/odb/shunt/latest/install.sh | bash -s latest local
```

`install.sh` 再从 `.../shunt/master/shunt.sh` 取文件。引用是浮动的（`latest` 标签、`master` 分支），没有校验和，且必须能出站。离线 / 无 curl 的构建机上表现为 `test/shunt.sh: No such file or directory`；放进 Conan 配方则被 CI L0o（`conanfile.py` 不得用 curl/wget 下载）拦截。

## 触发条件
- 构建系统: 无（纯 Bash 库，Makefile 只有 test/install/docs 目标）
- 阶段: testing（R51 上游测试三步法：清点 → 实跑 → 回填 N/N′）

## 根因分析
1. **测试框架是运行时下载物**：无版本固定、无 sha256，本地与 CI 拿到的框架可能不同，离线环境根本拿不到。
2. **shunt 的参数解析陷阱（已实测复现）**：`shunt.sh` 用 `echo "$options" | grep "\-h"` 判断 `--help`，而 `options` 含全部测试文件路径。任何路径里出现 "-h" 片段（`my-http/`、`foo-hidden/`、带连字符的包名）都会执行 `__usage`：打印 Usage 后 `exit 0`，**0 个测试被执行、退出码为 0**。shunt 的退出码还是失败数（`exit $__failed`），256 的倍数会回绕成 0。只看退出码会把「没跑」当成「全过」。

## 解决方案

### 推荐方案
1. 先证明浮动引用与固定 tag 字节一致（`master/shunt.sh` 与 `v0.3.1` 的 `shunt.sh` 同为 sha256 `b166a8e45cfc939b55defbf85b48e97ab33d68c621f9fabe907727083601f90e`），再在 `conandata.yml` 固定官方 tag 归档：

   ```yaml
   shunt:
     url: "https://github.com/odb/shunt/archive/refs/tags/v0.3.1.tar.gz"
     sha256: "0bc3d556918edf85a0d0885cd84ca358dc5786b81c30bde92ad340be0353d6da"
   ```
2. `source()` 用 `get(..., destination=os.path.join(self.source_folder, "shunt"))` 自包含下载；`build()` 用显式 bash 在源码根目录运行 `shunt/shunt.sh --plain --verbose test/*_tests.sh`（**相对路径**）。
3. 解析汇总行 `Total: N  Passed: P  Failed: F`，同时断言 rc==0、F==0、N==预期断言数（shml 1.1.0: 172，来自 9 个文件 142 处 `assert_equal` 调用点）。N 不符 = 测试被静默跳过。日志打印 `SHML UPSTREAM TEST PASS/FAIL: 172/172`，notes 与 PR 如实回填。

### 禁止做法
- ❌ 在 `conanfile.py` / 测试脚本里 `curl … | bash` 拉框架（L0o、供应链、不可复现）。
- ❌ 给 shunt 传绝对路径（Conan 缓存路径中的 "-h" 片段会让它静默跳过）。
- ❌ 只看退出码就宣称上游测试通过；用自制 shim 替代框架却不在 PR「上游测试用例修改说明」里声明。

## 验证
```bash
# ① 固定 tag 与浮动引用一致（两行哈希相同）
curl -fsSL https://raw.githubusercontent.com/odb/shunt/master/shunt.sh | sha256sum
curl -fsSL https://github.com/odb/shunt/archive/refs/tags/v0.3.1.tar.gz | tar xzO shunt-0.3.1/shunt.sh | sha256sum
# ② 复现陷阱：绝对路径含 "-h" → 打印 Usage 且 rc=0；相对路径 → Total: 8  Passed: 8  Failed: 0
mkdir -p /tmp/my-http/test && cp shml.sh /tmp/my-http/ && cp test/elements_tests.sh /tmp/my-http/test/
bash shunt.sh --plain --verbose /tmp/my-http/test/elements_tests.sh; echo rc=$?
( cd /tmp/my-http && bash /path/to/shunt.sh --plain --verbose test/elements_tests.sh ); echo rc=$?
# ③ 配方内：conan create 日志应含 "SHML UPSTREAM TEST PASS/FAIL: 172/172"
```

# Python curses 模块静态链接编译经验

## 问题背景

在鸿蒙系统上编译 Python 3.9.0 的 curses 模块时遇到以下问题：

1. **动态库链接问题**：setup.py 硬编码了 `/usr/include/ncursesw` 路径，该路径在鸿蒙上不存在
2. **宽字符函数未定义**：编译时提示 `cchar_t`、`setcchar`、`mvwadd_wch` 等未定义
3. **系统崩溃风险**：创建共享库符号链接时导致系统 shell (zsh) 崩溃

## 解决方案

### 1. 编译 ncurses 为静态库

```bash
cd /path/to/ncurses-6.4
./configure --prefix=$HOME/usr/local \
    --without-shared \
    --without-cxx \
    --without-cxx-binding \
    --enable-widec \
    --enable-overwrite \
    --without-debug \
    --without-profile \
    --without-ada \
    --without-manpages \
    --without-progs \
    --without-tests
make -j$(nproc)
make install.libs
```

**关键选项说明**：
- `--without-shared`：只生成静态库，不生成共享库
- `--enable-widec`：启用宽字符支持
- `--enable-overwrite`：头文件安装到顶层目录

### 2. 手动编译 Python curses 模块（静态链接）

```bash
# 编译 _cursesmodule.c
clang -c -fPIC \
    -DHAVE_NCURSESW=1 \
    -D_XOPEN_SOURCE_EXTENDED \
    -D_XOPEN_SOURCE=600 \
    -I$HOME/usr/local/include \
    -I./Include -I. \
    Modules/_cursesmodule.c \
    -o build/temp.ohos-aarch64-3.9/_cursesmodule.o

# 静态链接创建 _curses.so
clang -shared -L. -lpython3.9 \
    build/temp.ohos-aarch64-3.9/_cursesmodule.o \
    $HOME/usr/local/lib/libncursesw.a \
    -o build/lib.ohos-aarch64-3.9/_curses.so

# 编译 _curses_panel.c
clang -c -fPIC \
    -DHAVE_NCURSESW=1 \
    -D_XOPEN_SOURCE_EXTENDED \
    -D_XOPEN_SOURCE=600 \
    -I$HOME/usr/local/include \
    -I./Include -I. \
    Modules/_curses_panel.c \
    -o build/temp.ohos-aarch64-3.9/_curses_panel.o

# 静态链接创建 _curses_panel.so
clang -shared -L. -lpython3.9 \
    build/temp.ohos-aarch64-3.9/_curses_panel.o \
    $HOME/usr/local/lib/libpanelw.a \
    $HOME/usr/local/lib/libncursesw.a \
    -o build/lib.ohos-aarch64-3.9/_curses_panel.so
```

### 3. 关键编译选项

| 选项 | 作用 |
|------|------|
| `-DHAVE_NCURSESW=1` | 指定使用 ncurses 宽字符版本 |
| `-D_XOPEN_SOURCE_EXTENDED` | 启用 X/Open 宽字符扩展函数 |
| `-D_XOPEN_SOURCE=600` | 设置 X/Open 标准版本 |

**注意**：缺少 `-D_XOPEN_SOURCE_EXTENDED` 会导致 `cchar_t` 等类型和函数未定义。

## 静态链接 vs 动态链接

| 方式 | 优点 | 缺点 |
|------|------|------|
| **静态链接** | 不影响系统；无运行时依赖；更稳定 | 文件较大；更新需重新编译 |
| **动态链接** | 文件小；多程序共享；更新方便 | 可能影响系统；需正确配置库路径 |

**建议**：在鸿蒙系统上优先使用静态链接，避免共享库问题影响系统稳定性。

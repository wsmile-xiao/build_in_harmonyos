# 上下文裁剪协议

> 控制上下文膨胀：编译过程中每次调试都会产生大量日志、错误输出、尝试过程，如果全部留在上下文中，几轮后就无法工作。

## 核心问题

编译调试过程会产生大量中间信息（错误日志、sed/diff 尝试、编译输出），全部保留在上下文中会导致 AI 无法正常工作。

## 问题解决后必须执行 4 步

```
1. 沉淀知识 → 判断层级（L1/L2/L3），写入对应位置
2. 写索引行 → 在 notes.md 中写一行摘要
3. 裁剪遗忘 → 向上下文压缩系统声明可遗忘的内容
4. 后续查图谱 → 遇同类问题先查 graph/index.tsv，不重新调试
```

## notes.md 索引行格式

```markdown
### 对话 #N — YYYY-MM-DD HH:MM
**操作**: 修复 C_INCLUDE_PATH 导致的 pkg-config 问题
**结果**: ✅ unset C_INCLUDE_PATH 后通过
**知识图谱**: E075 → graph/E075.kv + doc/E075.md
**上下文状态**: 已裁剪（调试过程已遗忘，保留索引）
```

## 可遗忘的内容

调试完成后从上下文中丢弃：
- 错误日志原文（已沉淀到 .kv/.md）
- sed/diff 尝试过程
- 失败的修复方案
- 编译输出的中间产物

## 必须保留的内容

- 问题一句话描述
- 最终修复方案
- 知识图谱索引编号
